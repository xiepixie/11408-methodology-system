\newcommand{\qLYBZeroOneFiveStem}{复数 \(z = i^3 - \dfrac{2}{i}\)，则 \(z + z^2 + z^3 + \dots + z^9 =\) \hfill （\quad）}

\newcommand{\qLYBZeroOneFiveOptions}{%
  \mcoptions[4]{\(-1\)}{\(-i\)}{\(1\)}{\(i\)}%
}

\newcommand{\qLYBZeroOneFiveAnswer}{D}

\newcommand{\qLYBZeroOneFiveSolution}{%
  因为 \(z = i^3 - \dfrac{2}{i} = -i - 2(-i) = i\)。
  因为虚数单位 \(i\) 的幂具有周期性，周期为 4，且有 \(i + i^2 + i^3 + i^4 = i - 1 - i + 1 = 0\)。
  因此，求和式可按每 4 项为一组进行化简：
  \(z + z^2 + z^3 + \dots + z^9 = (i + i^2 + i^3 + i^4) + (i^5 + i^6 + i^7 + i^8) + i^9 = 0 + 0 + i^9\)。
  由于 \(i^9 = i^1 = i\)，
  所以 \(z + z^2 + z^3 + \dots + z^9 = i\)。
  故选 D。%
}
