\section{教学核心理念与主线}

对于高一学生，解三角形的难点不在于背诵正弦定理和余弦定理，而在于\textbf{“读懂条件、选准工具、防范陷阱、写清步骤”}。

本节课的主线为：
\[
  \boxed{
  \text{读题（找触发词）}
  \Rightarrow
  \text{判断自由变量}
  \Rightarrow
  \text{齐次化/建方程}
  \Rightarrow
  \text{全角化（三角函数）/ 全边化（基本不等式）}
  \Rightarrow
  \text{规范作答}
  }
\]

\subsection{防坑指南：锐角三角形的三重枷锁}
当题目出现“锐角三角形”时，切记提醒学生：
\begin{enumerate}
  \item $B < 90^\circ \implies \theta < 90^\circ$（若将 $B$ 设为 $\theta$）。
  \item $C < 90^\circ \implies 180^\circ - A - \theta < 90^\circ \implies \theta > 90^\circ - A$。
  \item 故自由变量的定义域范围为：$\boxed{90^\circ - A < \theta < 90^\circ}$。
\end{enumerate}
这个不等式范围是解答题中能否拿到满分的关键得分点。

\section{课堂题目与教学分析}

\subsection{1. 开场检测讲法}

\teacherproblem{检测 1}{边角混合先翻译}

在 \(\triangle ABC\) 中，若
\[
  b\sin A+a\cos B=0,
\]
求 \(B\)。

\answerblank[3.5cm]{学生演算与思考区}

\begin{paracol}{2}
\teachblock{标准解答}{
  由正弦定理边化角，得：
  \[
    \sin B \sin A + \sin A \cos B = 0
  \]
  因为 $A \in (0, \pi) \implies \sin A > 0$，所以：
  \[
    \sin B + \cos B = 0 \implies \tan B = -1
  \]
  又因 $B \in (0, \pi)$，故 $B = \frac{3\pi}{4}$。
}

\switchcolumn
\teachblock{学生问题}{
  \begin{itemize}
    \item 容易漏掉 $\sin A > 0$ 的除法说明。
    \item 三角方程求解时，算出 $\tan B = -1$ 误写成 $B = -\frac{\pi}{4}$，暴露出角范围意识弱。
  \end{itemize}
}

\teachblock{课堂处理与追问}{
  追问学生：为什么你可以两边同除以 $\sin A$？三角形的内角正弦值可能为 0 吗？
}
\end{paracol}

\teacherproblem{检测 2}{锐角条件筛分支}

在锐角 \(\triangle ABC\) 中，若
\[
  2a\sin B=\sqrt3 b,
\]
求 \(A\)。

\answerblank[3.5cm]{学生演算与思考区}

\begin{paracol}{2}
\teachblock{标准解答}{
  由正弦定理，原式化为：
  \[
    2\sin A \sin B = \sqrt{3}\sin B
  \]
  因为 $B \in (0, \pi) \implies \sin B > 0$，同除以 $\sin B$ 得：
  \[
    \sin A = \frac{\sqrt{3}}{2}
  \]
  又因三角形为**锐角三角形**，所以 $A = \frac{\pi}{3}$（排除 $\frac{2\pi}{3}$）。
}

\switchcolumn
\teachblock{学生问题}{
  \begin{itemize}
    \item 容易遗漏“锐角”条件，直接写出两个答案。
    \item 对于特殊三角函数值对应的双解缺乏本能的警惕性。
  \end{itemize}
}

\teachblock{课堂处理与追问}{
  追问：如果题目没说“锐角三角形”，这道题的答案是什么？引导学生建立双解检查机制。
}
\end{paracol}

\teacherproblem{检测 3}{看见结构合并}

在 \(\triangle ABC\) 中，若
\[
  a\sin A\sin B+b\cos^2 A=\sqrt2 a,
\]
求 \(\dfrac ba\)。

\answerblank[3.5cm]{学生演算与思考区}

\begin{paracol}{2}
\teachblock{标准解答}{
  等式两边同除以 $a$，得：
  \[
    \sin A \sin B + \frac{b}{a}\cos^2 A = \sqrt{2}
  \]
  由正弦定理 $\frac{b}{a} = \frac{\sin B}{\sin A}$，代入得：
  \[
    \sin A \sin B + \frac{\sin B}{\sin A}\cos^2 A = \sqrt{2} \implies \frac{\sin B}{\sin A}(\sin^2 A + \cos^2 A) = \sqrt{2}
  \]
  因为 $\sin^2 A + \cos^2 A = 1$，所以：
  \[
    \frac{\sin B}{\sin A} = \sqrt{2} \implies \frac{b}{a} = \sqrt{2}.
  \]
}

\switchcolumn
\teachblock{学生问题}{
  \begin{itemize}
    \item 不懂得两边除以 $a$ 进行比例化简。
    \item 展开计算极其繁琐，没有发现 \(\sin^2 A + \cos^2 A = 1\) 的合并结构。
  \end{itemize}
}

\teachblock{课堂处理与追问}{
  引导：圈出 \(\sin A\sin B\) 与 \(\frac{b}{a}\cos^2 A\)。如何利用正弦定理让它们系数一致？
}
\end{paracol}

\subsection{2. 核心母题讲法}

\teacherproblem{母题}{锐角三角形中的隐性边界}

在锐角 \(\triangle ABC\) 中，已知
\[
  \sin A=\frac45,
\]
求 \(\dfrac{b}{2c}\) 的取值范围。

\answerblank[10cm]{学生演算与思考区}

\newpage

\begin{paracol}{2}
\teachblock{标准解答（全角化代数法）}{
  由正弦定理，有：
  \[
    \frac{b}{2c} = \frac{\sin B}{2\sin C}
  \]
  因为 $A + B + C = \pi$，且 $\sin A = \frac{4}{5}, \cos A = \frac{3}{5}$，
  \[
    \sin B = \sin(A+C) = \sin A\cos C + \cos A\sin C = \frac{4}{5}\cos C + \frac{3}{5}\sin C
  \]
  代入目标式：
  \[
    \frac{b}{2c} = \frac{\frac{4}{5}\cos C + \frac{3}{5}\sin C}{2\sin C} = \frac{2}{5\tan C} + \frac{3}{10}
  \]
  由于三角形为锐角三角形，必须满足：
  \[
    \begin{cases}
      C < 90^\circ \\
      B = 180^\circ - A - C < 90^\circ \implies C > 90^\circ - A
    \end{cases}
  \]
  所以 $90^\circ - A < C < 90^\circ$。
  因为 $\tan(90^\circ - A) = \frac{1}{\tan A} = \frac{3}{4}$，
  故 $\tan C \in (\frac{3}{4}, +\infty)$。\par
  令 $t = \tan C$，函数 $f(t) = \frac{2}{5t} + \frac{3}{10}$ 在 $t \in (\frac{3}{4}, +\infty)$ 上单调递减。
  \[
    f(t) \in \left(\frac{3}{10}, \frac{2}{5 \cdot \frac{3}{4}} + \frac{3}{10}\right) \implies \frac{b}{2c} \in \left(\frac{3}{10}, \frac{5}{6}\right).
  \]
}

\switchcolumn
\teachblock{学生问题与诊断}{
  \begin{itemize}
    \item \textbf{建模意识不深（漏掉隐性约束）}：刘亚博同学计算细节扎实沉稳，但容易漏掉图形隐含的“角范围”约束。做题时喜欢见招拆招地堆砌代数步骤，而对“锐角三角形”这一已知条件对自由变量的制约深度建模不足（极易忽略 $B < 90^\circ$ 传递给 $C$ 的下界约束，导致范围上限算错）。
    \item \textbf{代数变形卡顿}：在化简 \(\frac{\sin B}{2\sin C}\) 时，对于展开并两边同除以 \(\sin C\) 构造 \(\tan C\) 这一消元建模手段敏感度不够。
  \end{itemize}
}

\teachblock{课堂处理与落实建议}{
  1. \textbf{数形结合直观突破}：带他亲手建系画出直角坐标系中的几何动点图（见讲义第三部分），直观看到 $C$ 只能在线段 $C_1C_2$ 上滑动。用几何的“轨道与边界”帮他打破公式套用局限，理解已知条件的深刻含义。
  2. \textbf{“三重枷锁”规范化}：强迫刘亚博每次看到“锐角三角形”时，第一步先在草稿纸上写出三个角小于 $90^\circ$ 的不等式组，将其作为建模的“必填项”，强化数学思想的严密性。
}
\end{paracol}

\subsection{3. 题目补充与月考重做讲法}

\teacherproblem{月考 Q16}{角平分线与倒数最值}

{\small \qTriangleBisectorMinStem}
\begin{center}
  \qTriangleBisectorMinFigure[1.2]
\end{center}

\answerblank[11.5cm]{学生演算与思考区}

\newpage

\begin{paracol}{2}
\teachblock{标准解答}{
  (1) 由 \(\vec{AD} = \dfrac{1}{5}\vec{AC}\) 知 \(AD : DC = 1 : 4\)。
  因为 \(BD\) 是平分线，由角平分线定理：
  \[
    \frac{c}{a} = \frac{AB}{BC} = \frac{AD}{DC} = \frac{1}{4} \implies a = 4c
  \]
  由正弦定理得 \(\sin A : \sin C = a : c = 4 : 1\)。\par
  (2) 由 $b\cos C + \sqrt{3}b\sin C = a + c$ 边化角，化简得：
  \[
    \sin B \cos C + \sqrt{3}\sin B \sin C = \sin(B+C) + \sin C
  \]
  展开后同除以 $\sin C$（$\sin C > 0$），解得：
  \[
    2\sin(B - \frac{\pi}{6}) = 1 \implies B = \frac{\pi}{3}
  \]
  由面积割补关系 \(S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle CBD}\)：
  \[
    \frac{1}{2}ac\sin B = \frac{1}{2}c \cdot BD \sin\frac{B}{2} + \frac{1}{2}a \cdot BD \sin\frac{B}{2}
  \]
  代入 $B = \frac{\pi}{3}, BD = 2$ 整理得：
  \[
    \frac{1}{a} + \frac{1}{c} = \frac{\sqrt{3}}{2}
  \]
  利用常数代换求 \(c+9a\) 最小值：
  \[
    c + 9a = (c + 9a)\frac{2}{\sqrt{3}}\left(\frac{1}{a} + \frac{1}{c}\right) = \frac{2}{\sqrt{3}}\left(10 + \frac{c}{a} + \frac{9a}{c}\right)
  \]
  因为 \(\frac{c}{a} + \frac{9a}{c} \ge 6\)，所以最小值为 \(\frac{32\sqrt{3}}{3}\)（当且仅当 $c = 3a$ 时等号成立）。
}

\switchcolumn
\teachblock{学生问题与诊断}{
  \begin{itemize}
    \item \textbf{模型转化能力薄弱}：第一问能通过向量比例关系，结合认真踏实的习惯，顺利联想到角平分线定理得出 $a=4c$；但第 (2) 问中，完全没有想到利用“面积分割法”（即 $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle CBD}$）去建立 $a,c$ 的倒数模型。这反映出对图形整体结构（角平分线分割三角形）与代数目标之间的建模转化不够深刻。
    \item \textbf{最值路线中断}：即使求出 $B = \frac{\pi}{3}$，由于没有面积法建立的 \(\frac{1}{a} + \frac{1}{c} = \text{常数}\) 不等式约束，最值求解卡壳，缺乏对不等式应用“前置条件”的结构理解。
  \end{itemize}
}

\teachblock{课堂处理与落实建议}{
  1. \textbf{模型方法总结}：引导他将“角平分线长度”与“面积割补关系”在脑海里强绑定，提炼出通用的“倒数模型构造”模板：
  \[
    \frac{1}{a} + \frac{1}{c}
    =
    \frac{\sin B}{BD\sin\frac{B}{2}}
    =
    \frac{2\cos\frac{B}{2}}{BD}
  \]
  帮他理清最值转化的链条，增强条件理解的深刻度。
  2. \textbf{等号条件与几何自洽性验证}：追问他均值不等式等号成立条件为 $c=3a$。既然 $c=3a$ 且 $B=\frac{\pi}{3}$，能否算出此时各边的长是多少？这三条边能构成三角形吗？通过这一验证过程，引导他进行深入的数学思想反思，而不只停留在代数算完的层面。
}
\end{paracol}

\teacherproblem{月考 Q18}{公式证明与二次函数配方}

{\small \qTriangleTrigProofMaxStem}

\answerblank[11.5cm]{学生演算与思考区}

\newpage

\begin{paracol}{2}
\teachblock{标准解答}{
  (1) 证明：建直角坐标系，在单位圆上设角 $\alpha, \beta$ 终边交点为 $A(\cos\alpha,\sin\alpha)$，$B(\cos\beta,\sin\beta)$。
  则 \(\vec{OA} = (\cos\alpha, \sin\alpha)\)，\(\vec{OB} = (\cos\beta, \sin\beta)\)。
  数量积坐标表示为：
  \[
    \vec{OA}\cdot\vec{OB} = \cos\alpha\cos\beta + \sin\alpha\sin\beta
  \]
  根据数量积几何定义，由于圆半径为 1，且夹角为 $|\alpha-\beta|$：
  \[
    \vec{OA}\cdot\vec{OB} = |\vec{OA}||\vec{OB}|\cos(\alpha-\beta) = \cos(\alpha-\beta)
  \]
  由此得：\(\cos(\alpha-\beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta\)。\par
  (2) 由第 (1) 问公式及和角余弦公式：
  \[
    \cos(\alpha-\beta)
    =
    \cos\alpha\cos\beta+\sin\alpha\sin\beta
    =
    \frac35,
  \]
  \[
    \cos(\alpha+\beta)
    =
    \cos\alpha\cos\beta-\sin\alpha\sin\beta
    =
    \frac15.
  \]
  两式相加，得：
  \[
    2\cos\alpha\cos\beta=\frac45
    \implies
    \cos\alpha\cos\beta=\frac25.
  \]
  两式相减，得：
  \[
    2\sin\alpha\sin\beta=\frac25
    \implies
    \sin\alpha\sin\beta=\frac15.
  \]
  所以：
  \[
    \tan\alpha\tan\beta
    =
    \frac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}
    =
    \frac{\frac15}{\frac25}
    =
    \frac12.
  \]\par
  (3) 在三角形中，将 $C = \pi - (A+B)$ 代入：
  \[
    \cos A + \cos B + \cos C = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2} - \cos(A+B)
  \]
  设 $x = \sin\frac{C}{2} = \cos\frac{A+B}{2}$，$\cos C = 1 - 2\sin^2\frac{C}{2} = 1 - 2x^2$。
  \[
    \cos A + \cos B + \cos C = -2x^2 + 2x\cos\frac{A-B}{2} + 1
  \]
  因为 $\cos\frac{A-B}{2} \le 1$ 且 $x > 0$，所以：
  \[
    \cos A + \cos B + \cos C \le -2x^2 + 2x + 1 = -2\left(x - \frac{1}{2}\right)^2 + \frac{3}{2}
  \]
  当且仅当 $x = \frac{1}{2} \implies C = \frac{\pi}{3}$ 且 $A=B=\frac{\pi}{3}$ 时等号成立。
  最大值为 \(\frac{3}{2}\)。
}

\switchcolumn
\teachblock{学生问题与诊断}{
  \begin{itemize}
    \item \textbf{证明逻辑不够深刻（偏口头化）}：第 (1) 问证明两角差余弦公式时，存在用和差角公式反推的逻辑循环。刘亚博习惯把公式看作“既定事实”而忽略其公理化的构建过程；第 (3) 问求余弦和最值时，直接口头默写“等边三角形时取最大值”，这虽然是正确的结论，但他无法自主用“二次函数配方与不等式放缩”将其证明出来，暴露出他“用结论代替证明”的思维惯性，需要强化严密建模的数学思想。
  \end{itemize}
}

\teachblock{课堂处理与落实建议}{
  1. \textbf{逻辑链条梳理}：在黑板上以单位圆与向量数量积为起点，带他严格写一遍两角差余弦的几何+坐标证明。强调公理化证明是从“已知真理”推出“未知真理”，必须严禁循环论证。
  2. \textbf{配方手算与放缩建模}：带他手算 $f(x) = -2x^2 + 2x\cos\frac{A-B}{2} + 1$ 的配方过程，重点指出 $\cos\frac{A-B}{2} \le 1$ 这一步不等式放缩的作用。通过这一具体步骤，提升他对不等式建模和边界判断的深刻理解。
}
