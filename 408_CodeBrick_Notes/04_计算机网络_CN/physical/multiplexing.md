## 知识框架

本节回答 6 个问题：

- 三类介质访问控制里，"信道划分"和另外两类的根本分界是什么？
- 四种复用方式各自在划分哪个"维度"？为什么维度不同就不会互相干扰？
- 复用（FDM）和多址（FDMA）是同一件事吗？
- 时分复用帧的长度为什么恰好是 125 µs？这个数从哪来？
- 统计时分复用省下了空闲时隙，代价是什么？为什么这个代价是不可避免的？
- 给定用户数和每用户速率，怎么算出复用后的总带宽 / 时隙宽度 / 线路速率？

## 一、先定位：信道划分在介质访问控制里的位置

多个站要共用一条链路，避免互相打架的办法一共三类：

| 类别 | 做法 | 会不会发生冲突 | 代表技术 |
| --- | --- | --- | --- |
| **信道划分**（本篇） | **事先**把信道按某个维度切成互不重叠的份，每个站独占一份 | **绝不会** | FDM、TDM、WDM、CDM |
| **随机访问** | 不预先分配，谁想发就发，撞了再退避重发 | **会**，靠协议解决 | [[04_计算机网络_CN/datalink/aloha.md|ALOHA]]、[[04_计算机网络_CN/datalink/csma-cd.md|CSMA/CD]]、[[04_计算机网络_CN/datalink/csma-ca.md|CSMA/CA]] |
| **轮询访问** | 不预先分配，但发送权按顺序传递，同一时刻只有一个站有权发 | **不会** | [[04_计算机网络_CN/datalink/token-passing.md|令牌传递]] |

分界判据是两句话：

- **信道划分 vs 另外两类**：划分是**静态**的、发生在通信开始之前；后两类是**动态**的、在通信过程中决定谁发。
- **随机访问 vs 轮询访问**：前者允许冲突再解决，后者从机制上根本不产生冲突。

信道划分的优点是无冲突、时延确定；缺点是**站没数据可发时它那一份也空着**，链路利用率低。这个缺点会在统计时分复用那一节被部分修补，也正是随机访问方式存在的理由。

## 二、复用的基本思路

通信线路建设成本高，一条物理链路只给一对用户用，利用率太低。复用的核心思想是：**让多个用户共享同一条物理链路，每个用户占用链路的不同"维度"**。

**复用器（multiplexer, MUX）与分用器（demultiplexer, DEMUX）总是成对使用**，中间夹着用户共享的高速信道。

复用不是免费的：共享信道因为带宽大，本身就更贵，再加上两端的复用器与分用器。**只有当复用的信道数量足够大时，摊薄下来才划算。**

**四种复用方式的分野只有一句话：它们在切哪个维度。** 切得开就互不干扰——因为两个信号只要在**任何一个**维度上不重叠，接收端就有办法把它们分开。

| 复用方式 | 切的维度 | 各用户占用的时间 | 各用户占用的频带 |
| --- | --- | --- | --- |
| FDM | **频率** | 全部（同时） | 各占一段 |
| TDM | **时间** | 各占一段 | 全部（轮到时独占） |
| WDM | **波长**（本质仍是频率） | 全部（同时） | 各占一个波长 |
| CDM | **编码** | 全部（同时） | 全部（同时） |

CDM 是最反直觉的一个：**时间和频率都不切，全体用户同时同频**。它凭什么还能分开？靠码片序列的正交性——这是**第四个维度**。详见[[04_计算机网络_CN/physical/cdma.md|CDMA 码分多址]]。

## 三、频分复用 FDM

**Frequency Division Multiplexing**

### 原理

把链路的**频带**划分成多个互不重叠的子频带，每个用户独占一个子频带。做法是用调制把各路信号分别搬移到合适的频率位置，使彼此不产生干扰。**所有用户的信号同时在链路上传输**，各自使用不同的频率。

**一句话记法**：频分复用的各路信号**在同样的时间占用不同的频带资源**。

```
频率 ↑
     │  ┌────────┐
     │  │ 用户3  │
     │  ├────────┤ ← 保护频带
     │  │ 用户2  │
     │  ├────────┤ ← 保护频带
     │  │ 用户1  │
     │  └────────┘
     └──────────────→ 时间
       所有用户始终占着各自的频带
```

### 为什么必须留保护频带

理想滤波器不存在。实际滤波器的过渡带有一定宽度，相邻两个子频带如果紧挨着，一路信号的能量会溢进邻路的通带里——这叫**邻道干扰**。**保护频带就是花掉一段带宽，换取相邻两路之间的隔离度。**

代价是实打实的：传统电话通信中每个标准话路的语音带宽是 3.1 kHz，但复用时**每路要占 4 kHz**——多出来的 0.9 kHz 就是两边的保护频带。

| 项目 | 说明 |
| --- | --- |
| 划分维度 | 频率 |
| 同时传输 | **是**，所有用户同时发送 |
| 是否需要时钟同步 | **不需要**（各路互不相干，没有"轮到谁"的问题） |
| 保护措施 | 相邻子频带之间留**保护频带** |
| 典型应用 | 有线电视、广播、ADSL |

### 例题 1：FDM 的总带宽

用频分复用把 1000 路标准电话复用到一条链路上，每个标准话路占 4 kHz。求复用后链路的总带宽。

**第一步：确认每路占多少。** 4 kHz（3.1 kHz 语音 + 两边保护频带）。

**第二步：相加。**W总=1000×4 kHz=4000 kHz=4 MHz

*这一步在做什么*：**频分复用的总带宽是各路带宽之和**——因为各路在频率轴上首尾相接摆开。用户数增加，总带宽就跟着变宽。

**答：4 MHz。**

**边界追问：如果链路的可用带宽只有 2 MHz，还能复用 1000 路吗？** 不能。频分复用没有"挤一挤"的余地——每路占的频段是物理隔离的，砍掉一半带宽就只能少放一半用户（500 路），或者压缩每路的带宽（牺牲话音质量）。**这是频分复用与统计时分复用最本质的差别：前者的资源分配是刚性的。**

## 四、时分复用 TDM

**Time Division Multiplexing**

### 原理

把时间划分成一段段**等长的时分复用帧（TDM 帧）**，每一路信号在**每一个 TDM 帧中占用固定序号的时隙**。轮到某路时，它**独占整个链路带宽**。

**一句话记法**：时分复用的所有用户**在不同的时间占用同样的频带宽度**。

```
时间 →
┌──────┬──────┬──────┬──────┬──────┬──────┐
│用户A │用户B │用户C │用户A │用户B │用户C │ ...
└──────┴──────┴──────┴──────┴──────┴──────┘
 ├──── 一个 TDM 帧 ────┤├──── 下一个 TDM 帧 ────┤
```

因为每一路占用的时隙**周期性地出现**（周期就是 TDM 帧的长度），TDM 信号也称为**等时（isochronous）信号**。

| 项目 | 说明 |
| --- | --- |
| 划分维度 | 时间 |
| 同时传输 | **否**，用户轮流使用 |
| 是否需要时钟同步 | **需要严格的时钟同步** |
| 缺点 | 某用户没有数据时，它的时隙**空着也不能让给别人** |
| 典型应用 | T1／E1 数字电话线路 |

### 为什么 TDM 必须严格同步、FDM 不用

因为 TDM 靠**位置**区分用户：接收端是数着"这是本帧的第几个时隙"来判断这段比特属于谁的。时钟一旦偏移，数错一个时隙，**所有用户的数据全部串位**。FDM 靠**频率**区分用户，滤波器认的是频率不是时刻，收发时钟差一点无所谓。

这条差别直接决定了后面 STDM 必须付出的代价。

### TDM 帧长为什么是 125 µs

这个数不是随便定的，它由[[04_计算机网络_CN/physical/channel-basics.md|通信基础]]里的 PCM 推出来：一路标准数字电话的采样频率=8000 次/秒⟹采样周期=18000 s=125 μs

**每一路语音每 125 µs 产生一个样本，所以 TDM 帧必须每 125 µs 来一轮**——来早了没样本可放，来晚了样本就堆积。**帧长由业务的采样周期钉死，与复用了多少路无关。**

于是有一个重要推论：**用户数增加时，TDM 的帧长不变，变的是每个时隙的宽度。** 1000 个用户做时分复用，每个用户分到的时隙宽度就是 125 µs 的千分之一，即 0.125 µs。时隙越窄，脉冲越尖，**它所占的频谱范围就越宽**——所以时分复用同样要付出带宽代价，只不过代价体现在"脉冲变窄"而不是"频段变多"。

### 例题 2：TDM 的时隙宽度与线路速率

用同步时分复用把 8 路 64 kbit/s 的数字电话复用到一条链路上，帧长 125 µs。求：(a) 每个时隙的宽度；(b) 每个时隙携带多少比特；(c) 链路的数据传输速率。

**(a) 时隙宽度**时隙宽度=125 μs8=15.625 μs

*这一步在做什么*：帧长固定 125 µs，8 个用户平分。**用户数是分母**。

**(b) 每时隙比特数**

每路 64 kbit/s，每 125 µs（即每帧）应当送出：64000×125×10−6=8 bit

*这一步在做什么*：反过来验证 PCM——每路每次采样量化成 8 bit，每帧放一个样本，正好 8 bit。**这个 8 就是 PCM 的量化位数**，两处对上了说明理解没跑偏。

**(c) 线路速率**R=8 路×64 kbit/s=512 kbit/s

或者等价地按帧算：每帧 8×8=64 bit，每秒 8000 帧，得 64×8000=512000 bit/s，两条路子结果一致。

**答：15.625 µs；8 bit；512 kbit/s。**

### 例题 3：T1 载波的速率是怎么来的

北美的 T1 载波把 24 路 64 kbit/s 的话音做同步时分复用，每帧在 24 个时隙之外再加 1 个帧同步位。求 T1 的数据传输速率。

**第一步：算一帧有多少比特。**24×8+1=193 bit

*这一步在做什么*：24 路各贡献 1 个样本（8 bit），再加 1 位帧同步位——**这一位就是"TDM 必须严格同步"的开销**，接收端靠它对齐帧边界。

**第二步：乘以每秒的帧数。**R=193×8000=1544000 bit/s=1.544 Mbit/s

**答：1.544 Mbit/s**，正是教材给出的 T1 速率。

**同样的算法适用于欧洲的 E1**：32 个时隙（30 路话音 + 2 个用于帧同步与信令的时隙），每时隙 8 bit，无额外帧同步位：RE1=32×8×8000=2048000 bit/s=2.048 Mbit/s

也与教材一致。**能自己推出这两个数，比背下来牢靠得多**——推的依据只有三条：帧长 125 µs、每样本 8 bit、加几位同步开销。

### 统计时分复用 STDM

同步时分复用最大的问题是**时隙固定分配**：计算机数据是突发性的，某个用户正在敲键盘或看屏幕时根本没有数据，但它的时隙照样空着，**别的用户即使一直有数据也用不了**。

**统计时分复用（Statistical TDM，STDM）** 的改法是：**不预先固定分配时隙，而是按需动态分配。**

工作方式（教材里的集中器就是典型例子）：

- 各用户有数据就随时发往集中器的**输入缓存**；
- 集中器按顺序依次扫描各输入缓存，把有数据的缓存内容放进 STDM 帧，**对没有数据的缓存直接跳过**；
- 一个帧放满就发出去。

关键结构差别：**一个 STDM 帧中的时隙数小于连接在集中器上的用户数**——正因为不是人人有份，才能不留空档。

**代价：每个时隙必须额外携带地址信息。**

这个代价是**不可避免**的，原因很硬：同步 TDM 靠**位置**认人（第 3 个时隙一定是用户 C 的），而 STDM 里"第 3 个时隙"这次可能是 C 的、下次可能是 A 的，**位置信息被跳过机制破坏了，就必须换一种方式说明"这段数据是谁的"**。教材图上每个时隙前面那个短短的白色小格，就是放地址的地方。

同一件事的另一个说法：STDM 的输出线路上，**某个用户占用的时隙不再周期性出现**。所以 STDM 又称**异步时分复用**，普通 TDM 称**同步时分复用**。

| 对比项 | TDM（同步） | STDM（异步/统计） |
| --- | --- | --- |
| 时隙分配 | 预先固定 | 按需动态 |
| 帧内时隙数 | = 用户数 | **< 用户数** |
| 用户空闲时 | 时隙浪费 | 跳过，不浪费 |
| 靠什么认人 | **位置** | **地址字段** |
| 每时隙开销 | 无 | 有（地址） |
| 线路利用率 | 较低 | 高 |
| 实现复杂度 | 简单 | 复杂（要缓存、要排队） |

**STDM 的前提条件**：输出线路的速率**小于**各输入线路速率之和，但从平均角度看两者是平衡的。所以集中器能正常工作的前提是**各用户都是间歇工作的**——若所有用户都不间断地发送，集中器的缓存必然溢出。

### 例题 4：STDM 的复用增益

20 个用户接到一台集中器上，每个用户的峰值速率为 10 Mb/s，但平均只有 20% 的时间在发送数据。(a) 若用同步 TDM，输出线路至少要多快？(b) 若用 STDM，按平均需求配置，输出线路要多快？

**(a) 同步 TDM**R=20×10=200 Mb/s

*这一步在做什么*：同步 TDM 必须为**每个用户的峰值**留出固定时隙——不管它用不用。

**(b) STDM**R=20×10×20%=40 Mb/s

*这一步在做什么*：STDM 只需承载**总的平均负载**。

**答：200 Mb/s vs 40 Mb/s，线路速率省了 5 倍**（正好是占空比的倒数）。

**边界必须说清**：40 Mb/s 只在"用户之间的忙闲错开"时才够用。**如果某一瞬间恰好有 5 个以上的用户同时发送，集中器就必须靠缓存把超出的部分排队**——这带来**排队时延**，而且缓存有限，持续过载会**丢数据**。所以 STDM 换来的高利用率，代价是**时延不再确定**：同步 TDM 的时延是恒定可算的，STDM 的时延取决于当时有多少人在抢。

**这条权衡在整门课里反复出现**：预留资源 → 时延确定、利用率低；共享资源 → 利用率高、时延不确定。[[04_计算机网络_CN/overview/network-overview.md|电路交换与分组交换]]的分野正是同一件事的另一个版本。

### 一处必须分清的同名概念

**TDM 帧和 STDM 帧，都是在物理层传送的比特流中划分出来的"帧"。** 它和[[04_计算机网络_CN/datalink/framing.md|数据链路层的帧]]是**完全不同的概念**：

|  | TDM/STDM 帧 | 数据链路层的帧 |
| --- | --- | --- |
| 在哪一层 | 物理层的比特流划分 | 数据链路层 |
| 长度 | 固定（由采样周期定，如 125 µs） | 可变，有最大最小限制 |
| 里面装什么 | 若干路用户的时隙 | 一个网络层分组 + 首部尾部 |
| 有无差错控制 | 无 | 有（帧检验序列） |

教材专门为这一点加了强调，因为两者同名极易混淆。

## 五、波分复用 WDM

**Wavelength Division Multiplexing**

### 原理

**波分复用就是光的频分复用。** 在一根光纤上同时传输多个频率很接近的光载波信号，各路互不干扰。

由于光载波的频率非常高（可见光约 108 MHz 量级），工程上习惯用**波长**而不是频率来标识光载波（两者由 c=λf 一一对应），于是有了"波分复用"这个名字。

- 发送端用**光复用器**（又称**合波器**）把不同波长的光信号合进一根光纤
- 接收端用**光分用器**（又称**分波器**）把各波长分离出来

### 密集波分复用 DWDM

随着技术进步，一根光纤上能复用的波长数越来越多，波长间隔越来越小，于是有了 **DWDM（Dense WDM，密集波分复用）**。密集波分复用的光载波间隔一般是 **0.8 nm 或 1.6 nm**。

| 对比项 | WDM | DWDM |
| --- | --- | --- |
| 波长间隔 | 较大 | 很小（0.8 nm 或 1.6 nm） |
| 通道数 | 最初只有 2 路 | 几十到上百路 |
| 传输容量 | 一般 | 极大 |
| 应用 | 早期光纤通信 | 现代骨干网 |

### 例题 5：波分复用的总容量

一根光纤上用密集波分复用承载 64 路光载波，每路的数据率为 40 Gb/s。求这根光纤的总数据率。若一条光缆中放入 100 根这样的光纤，光缆的总数据率是多少？

**第一步：单根光纤。**64×40=2560 Gb/s=2.56 Tb/s

**第二步：整条光缆。**100×2.56=256 Tb/s

*这两步在做什么*：波分复用与"一缆多纤"是**两个互相独立的倍增维度**，可以直接相乘。铺设光缆的土建成本极高，所以工程上总是"一根光缆里塞尽可能多的光纤，每根光纤再上密集波分复用"——**两个维度一起用，才把土建成本摊到最薄**。

**答：单根光纤 2.56 Tb/s，整缆 256 Tb/s。**

### 光信号的中继问题

光信号传一段距离就会衰减，必须放大。早期做法是"光 → 电 → 放大 → 电 → 光"，环节多、成本高、还会限制速率。现在用**掺铒光纤放大器（EDFA）**，**不做光电转换、直接放大光信号**，在 1550 nm 附近提供较均匀的增益。两个光纤放大器之间的光缆线路长度可达 120 km，而光复用器与光分用器之间的无光电转换距离可达 600 km。

## 六、码分复用 CDM

**Code Division Multiplexing**

### 原理

每个用户分配一个**唯一的码片序列（chip sequence）**，所有用户使用**相同的频带**、在**相同的时间**同时发送。接收端利用码片序列之间的**正交性**，从叠加信号中把某个特定用户的数据"提取"出来。

### 和其他复用方式的本质区别

FDM 在频率维度上分离用户，TDM 在时间维度上分离用户，而 **CDM 在编码维度上分离用户——所有用户共享全部时间和全部频率**。

这听上去像是"什么都不划分"，但它确实是一种划分：**划分的是"信号空间里的方向"**。m 位码片序列可以看作 m 维空间里的向量，互相正交的向量最多有 m 个——**这就是码分复用的"信道数上限"，与频分复用能切几段、时分复用能分几个时隙是同一个位置的量。**

代价也在这里：为了给每个比特套上一个 m 位的码片序列，**发送出去的码片速率是原数据率的 m 倍，占用的带宽也扩大到 m 倍**。这就是"扩频"这个名字的来历。

CDM 用于多址接入时叫 **CDMA（Code Division Multiple Access）**。**码片序列的正交性、内积解码的完整计算、以及如何自己构造一组正交序列，全部在 [[04_计算机网络_CN/physical/cdma.md|CDMA 码分多址]] 展开**，本篇不重复。

## 七、复用与多址：一组容易混的缩写

这一组词几乎每年都在概念题里出现，而且区分方法非常简单：

| 缩写 | 全称 | 强调什么 |
| --- | --- | --- |
| **FDM** / TDM / WDM / CDM | Frequency/Time/Wavelength/Code Division **Multiplexing** | 强调**在哪个域上做复用**（频域？时域？），**不关心**复用出来的信道是给多个用户还是给同一个用户 |
| **FDMA** / TDMA / CDMA | Frequency/Time/Code Division **Multiple Access** | 后面的 "MA" 表示**多址**——强调这条复用信道可以**让多个（可能位于不同地点的）用户接入进来** |

两句话记法：

- **"FD/TD/CD" 说的是用什么技术**（频分／时分／码分）；
- **"M" 是 Multiplexing（复用），"MA" 是 Multiple Access（多址）**——多出来的那个 A 就是"接入"。

举例：图上的频分信道，可以让 N 个用户各使用一个频带，也可以让更多用户**轮流**使用这 N 个频带——这种"让多个用户接入进来"的用法就叫 **FDMA**。同一条链路，如果只是把一个用户的多路信号合起来传（比如一台设备的多个传感器数据），那就只是 **FDM**，谈不上多址。

**判据一句话：涉及"多个站点／多个用户争用接入"就是 MA，只是"多路信号合并传输"就是 M。**

## 八、四种复用方式总对比

| 对比项 | FDM | TDM | WDM | CDM |
| --- | --- | --- | --- | --- |
| 划分维度 | 频率 | 时间 | 波长（光的频率） | 编码 |
| 同时传输 | 是 | 否（轮流） | 是 | 是 |
| 共享频带 | 否（各占一段） | 是（轮到时独占全部） | 否（各占一个波长） | **是（全部共享）** |
| 需要时钟同步 | 否 | **是（严格）** | 否 | 是（码片序列要对齐） |
| 靠什么区分用户 | 频率 | **时隙位置** | 波长 | **码片序列** |
| 主要开销 | 保护频带 | 帧同步位 | 光复用/分用器 | 带宽扩大 m 倍 |
| 适用介质 | 电缆、无线 | 电缆 | **仅光纤** | 无线 |
| 典型应用 | 广播、有线电视、ADSL | T1/E1 线路 | 光纤骨干网 | CDMA 移动通信 |
| 信道利用率 | 中等 | 低（TDM）／高（STDM） | 高 | 高 |

## 易混淆知识点

**1. WDM 和 FDM 的关系**

**WDM 本质上就是光纤中的 FDM**，原理完全相同，只是因为光载波频率太高，用波长标识比用频率方便。做题时按介质区分：**看到"光纤"就是 WDM，看到"电缆／无线"就是 FDM**。

**2. TDM 中"同步"的两层含义**

- 第一层：**收发双方必须时钟同步**，否则接收端数错时隙，所有用户的数据全部串位。这是 TDM 必须付出的代价（T1 每帧那 1 位同步位就是干这个的）。
- 第二层："**同步**时分复用" vs "**统计**时分复用"里的"同步"，指的是**时隙固定分配、周期性出现**。

两层含义指向的是同一个根源：**TDM 靠"位置"认人**，所以位置必须严格对齐、必须周期出现。

**3. STDM 的利用率高于 TDM，但时延不再确定**

TDM 预分配时隙，用户没数据时时隙浪费；STDM 按需分配，利用率更高。但代价有两个，都要说全：① **每时隙必须带地址**（因为位置信息不再能认人）；② **突发同时到达时要排队**，时延不确定甚至可能丢数据。只说"利用率高"是答不全的。

**4. FDM 的总带宽是各路之和，TDM 的帧长与用户数无关**

这两条是对称的，别记反：

- **FDM**：用户数增加 → **总带宽变宽**，每路带宽不变；
- **TDM**：用户数增加 → **帧长不变（125 µs）**，每个时隙变窄、线路速率变高。

**5. TDM/STDM 帧 ≠ 数据链路层的帧**

前者是物理层比特流上的划分（长度由采样周期定死、无差错控制），后者是数据链路层的协议数据单元（长度可变、有首尾定界与帧检验序列）。同名不同物。

**6. CDM 里所有用户真的是"同时同频"**

CDM 既不切频率也不切时间，所有用户在同一时间使用同一频带。接收端能从叠加信号中分离出各用户的数据，靠的是码片序列的**正交性**。**代价是带宽扩大到码片长度 m 倍**——"不划分时间和频率"不等于"不占资源"，资源以另一种形式被消耗掉了。

**7. 复用（M）与多址（MA）**

"MA" 里的 A 是 Access（接入），强调**多个用户接入同一条信道**；只说"M"时只强调在哪个域上做复用，不关心用户数。判据：题干里出现"多个站点争用""多个用户接入"就是多址。

## 本节小结

- **信道划分是介质访问控制的三类之一**（另两类是随机访问与轮询访问）。分界判据：划分是**静态、事先分配、绝不冲突**；随机访问是动态、允许冲突再解决；轮询访问是动态但机制上无冲突。信道划分的通病是**用户空闲时它那一份也空着**。
- **复用的核心是切维度**：两个信号只要在任一维度上不重叠，接收端就能分开。FDM 切频率、TDM 切时间、WDM 切波长（本质仍是频率）、CDM 切编码。**复用器与分用器成对使用**，复用只有在信道数足够多时才经济。
- **FDM**：各路**在同样的时间占用不同的频带**，需留**保护频带**（标准话路语音 3.1 kHz、复用占 4 kHz），不需时钟同步。**总带宽 = 各路带宽之和**，用户数增加则总带宽变宽。资源分配是刚性的。
- **TDM**：各路**在不同的时间占用同样的频带**，轮到时独占全带宽，信号是**等时的**。靠**时隙位置**认人，因此**必须严格时钟同步**。**帧长 125 µs 由 PCM 采样周期（1/8000 s）钉死，与用户数无关**；用户数增加时变窄的是时隙，脉冲变窄意味着频谱变宽——带宽代价换了个形式仍在。
- **T1/E1 都能自己推**：T1 = (24×8+1)×8000=1.544 Mb/s；E1 = 32×8×8000=2.048 Mb/s。依据只有三条：帧长 125 µs、每样本 8 bit、加几位同步开销。
- **STDM**：按需动态分配时隙，**帧内时隙数 < 用户数**，跳过无数据的用户，故又称**异步时分复用**。**必须为每个时隙加地址字段**——因为跳过机制破坏了"位置认人"。利用率高（占空比 20% 时线路速率可省 5 倍），代价是**排队时延不确定、过载会丢数据**，前提是各用户间歇工作。
- **TDM/STDM 帧是物理层比特流的划分，与数据链路层的帧完全不是一回事**。
- **WDM = 光的 FDM**，用波长标识光载波；**DWDM** 波长间隔 0.8 nm 或 1.6 nm、可复用上百路。**波分复用与一缆多纤是两个独立的倍增维度，可以相乘**。EDFA 掺铒光纤放大器直接放大光信号、无需光电转换，放大器间距可达 120 km。
- **CDM**：全体用户同时同频，靠码片序列**正交性**分离。m 位码片序列 = m 维空间的向量，**最多 m 个互相正交**，这就是它的信道数上限；代价是**带宽扩大 m 倍（扩频）**。计算见 [[04_计算机网络_CN/physical/cdma.md|CDMA 码分多址]]。
- **复用（M）与多址（MA）的分界**：前缀 FD/TD/CD 说的是"用什么技术"，后缀 M 说的是"在哪个域复用"，MA 多出来的 A 是 **Access**——强调让多个（可能异地的）用户**接入**同一条信道。

- 谢希仁《计算机网络》（第 7 版）**p56**（2.4.1 频分复用、时分复用和统计时分复用）：给出复用器与分用器的配对关系，以及"复用要付出一定代价（共享信道由于带宽较大因而费用也较高，再加上复用器和分用器）。但如果复用的信道数量较大，那么在经济上还是合算的"；并给出两句判据式的定义——"**频分复用的各路信号在同样的时间占用不同的带宽资源**（请注意，这里的'带宽'是频率带宽而不是数据的发送速率）"，"**时分复用的所有用户是在不同的时间占用同样的频带宽度**"。
- 同书 **p56–p57**：区分复用与多址——"这种方式称为频分多址接入 FDMA……**FDMA 或 TDMA 中的 'MA' 表明'多址'，意思是强调这种复用信道可以让多个用户（可以在不同地点）接入进来。而 'FD' 或 'TD' 则表示所使用的复用技术是'频分复用'或'时分复用'。但术语 FDM 或 TDM 则说明是在频域还是在时域进行复用，而并不强调复用的信道是用于多个用户还是一个用户**"。
