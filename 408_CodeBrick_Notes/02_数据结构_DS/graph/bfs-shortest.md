# BFS 求无权图最短路径

## 大纲定位

本篇对应 2026 大纲 **五、图 （四）图的基本应用 2. 最短路径**。

**分工边界**：这一条由三篇分担，各管一类图：

| 篇 | 适用图 | 求什么 |
| --- | --- | --- |
| **本篇** | **无权图**（或所有边权相等） | 单源，边数最少 |
| [Dijkstra](./dijkstra.html) | 带权图，**权非负** | 单源，权和最小 |
| [Floyd](./floyd.html) | 带权图，可含负权边（不含负权回路） | **所有顶点对**，权和最小 |

- **本篇**负责：为什么 BFS 求出来的一定是最短、d[] 与 path[] 的设计与实现、 路径还原、以及"无权"这个前提被打破时会发生什么。
- **BFS 遍历本身**（队列机制、生成树、层次性质、复杂度来历）属五（三）2，见 [BFS](./bfs.html)； 本篇把它当作已知，只讲"如何把遍历改造成最短路径算法"。
- 三种最短路径算法的选型对照表放在**本篇的《易混淆知识点》**。

## 知识框架

本节回答四个问题：

- 遍历只关心"访问到没有"，最短路径要关心"用了几条边"。要在 BFS 上加哪两个数组？
- "首次到达即最短"为什么成立？这一步的证明依赖队列的哪条性质？
- 只有 d[] 没有 path[] 会怎样？怎样从 path[] 还原出完整路径？
- 把边权从"全为 1"改成"全为 5"，算法还对吗？改成"有 1 有 5"呢？

## 核心思想：层号就是距离

BFS 按"距源点由近到远"的次序访问顶点：第 k 层的顶点距源点恰好 k 条边（见 [BFS](./bfs.html)）。 所以只要在遍历时**把层号记下来**，就得到了最短距离——不需要任何额外的搜索。

改造只有两处：

- **距离数组 `d[]`**：`d[v]` 记录源点到 v 的最短距离。初始化为 −1， 兼作"未访问"的标记（−1 同时表示"没访问过"和"不可达"）。
- **前驱数组 `path[]`**：`path[v]` 记录最短路径上 v 的**前一个顶点**。初始化为 −1。

```
层次 0:  源点 s         → d[s] = 0
层次 1:  s 的邻接顶点    → d[v] = 1
层次 2:  层次 1 的未访问邻接顶点  → d[v] = 2
  ...
```

**为什么记前驱而不是记整条路径**：记整条路径要为每个顶点存一个变长序列， 空间 O(n2)；而"每个顶点在最短路径树上只有一个父亲"，所以只需一个 O(n) 的父指针数组， 顺着它往回走就能还原路径。这与 [BFS 生成树](./bfs.html) 是同一件事—— **`path[]` 存的就是 BFS 生成树的父指针**。

## 算法步骤与实现

- `d[]` 全置 −1，`path[]` 全置 −1。
- `d[s] = 0`，源点 s 入队。
- 队列非空时：取出队头 u，遍历 u 的每个邻接点 v； 若 v 未被访问，则 `d[v] = d[u] + 1`、`path[v] = u`、v 入队。
- 结束后 `d[]` 即为源点到各顶点的最短距离，`d[v] == -1` 表示不可达。c

```
#define MAX_V 100

int d[MAX_V];        // 源点到各顶点的最短距离，-1 表示未访问 / 不可达
int path[MAX_V];     // 最短路径上各顶点的前驱，-1 表示无前驱

// BFS 求无权图单源最短路径
// 邻接表存储，n 个顶点（编号 0 ~ n-1），源点为 s
void BFS_ShortestPath(int s, int n) {
    for (int i = 0; i < n; i++) {
        d[i] = -1;      // -1 同时承担"未访问"与"不可达"两个含义
        path[i] = -1;
    }

    Queue Q;
    InitQueue(&Q);
    d[s] = 0;           // 置 d[s] 就等于把 s 标记成已访问
    EnQueue(&Q, s);

    while (!IsEmpty(&Q)) {
        int u;
        DeQueue(&Q, &u);
        // 遍历 u 的所有邻接顶点 v
        for (int v = FirstNeighbor(u); v >= 0; v = NextNeighbor(u, v)) {
            if (d[v] == -1) {       // 未访问 → 这是第一次到达 v
                d[v] = d[u] + 1;    // 距离 = 前驱距离 + 1
                path[v] = u;        // 记录前驱
                EnQueue(&Q, v);     // 置 d[v] 与入队同时完成，等价于"入队即置位"
            }
        }
    }
}
```

**这里不再需要单独的 `visited[]`**：`d[v] != -1` 已经完整承担了"已访问"的语义， 因为 `d[v]` 是在入队的同一时刻被赋值的。多维护一个 `visited[]` 不会错，但是冗余； 反过来，**如果把 `d[v]` 的赋值挪到出队之后，`d[v] == -1` 就不再等价于"未访问"**， 同一个顶点会重复入队，距离也会被覆盖成错的。这正是 [BFS](./bfs.html) 里"入队即置位"那条纪律。

### 路径还原

从目标顶点 t 沿 `path[]` 一路回溯到源点，得到的是**逆序**路径， 所以要么压栈后再弹出，要么用递归"先打印前面的"。c

```
// 输出从 s 到 t 的最短路径（借助栈把逆序翻正）
void PrintPath(int s, int t) {
    if (d[t] == -1) { printf("不可达\n"); return; }   // d[] 是全局的，可直接判可达性
    int stack[MAX_V], top = -1;
    for (int v = t; v != -1; v = path[v])
        stack[++top] = v;            // 从 t 回溯到 s，依次压栈
    while (top >= 0)
        printf("%d ", stack[top--]); // 弹栈即为 s → t 的正序路径
    printf("\n");
}
```

**循环终止条件是 `v != -1`**，靠的是 `path[s] == -1`（源点没有前驱）这一初始化。 若把 `path[s]` 初始化成 s 自己，循环条件必须相应改成 `v != s` 并在循环外补上源点， 否则会死循环——**两种写法各自自洽，但不能混用**。

## 完整走查

以下图为例（无向图，顶点 0∼5）：E={(0,1),(0,2),(1,3),(1,4),(2,4),(4,5)}

```
    0 --- 1 --- 3
    |     |
    2 --- 4 --- 5
```

邻接表按编号升序：0:1,21:0,3,42:0,43:14:1,2,55:4

| 步骤 | 出队顶点 u | 检查 u 的邻居 | 新发现 | d 更新 | path 更新 | 队列（出队后） |
| --- | --- | --- | --- | --- | --- | --- |
| 初始 | — | — | 0 | d[0]=0 | — |  |
| 1 | 0 | 1, 2 | 1, 2 | d[1]=1, d[2]=1 | path[1]=0, path[2]=0 |  |
| 2 | 1 | 0(已), 3, 4 | 3, 4 | d[3]=2, d[4]=2 | path[3]=1, path[4]=1 |  |
| 3 | 2 | 0(已), 4(已) | — | — | — |  |
| 4 | 3 | 1(已) | — | — | — |  |
| 5 | 4 | 1(已), 2(已), 5 | 5 | d[5]=3 | path[5]=4 |  |
| 6 | 5 | 4(已) | — | — | — |  |

**最终结果**：

| 顶点 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| d | 0 | 1 | 1 | 2 | 2 | 3 |
| path | −1 | 0 | 0 | 1 | 1 | 4 |

**还原 0→5 的最短路径**：path[5]=4→path[4]=1→path[1]=0→path[0]=−1 停。 压栈序列为 5,4,1,0，弹栈得 **0→1→4→5**，长度 3 = d[5] ✓。

注意第 3 步：顶点 2 检查到邻居 4 时，4 已经在第 2 步被 1 发现了，所以**跳过，不更新**。 如果这里改成"更新"，d[4] 会被写成 d[2]+1=2——数值上碰巧还是 2， 但 path[4] 会被改成 2，路径变成 0→2→4→5。 这条路径长度同样是 3，**同样是一条最短路径**——说明最短路径可能不唯一， 而 `path[]` 只记录了 BFS 实际走出的那一条。

## 正确性：为什么"首次到达即最短"

**命题**：BFS 结束后，对任意可达顶点 v，`d[v]` 等于源点 s 到 v 的最短距离。

**证明的两个支点**：

- **`d[]` 沿队列非递减**。队列是 FIFO，入队时赋的值总是"队头的 d 值 +1"。 队头的 d 值随出队单调不减，所以整个队列里的 d 值构成一个非递减序列， 且首尾相差至多 1。这意味着**BFS 严格按层号从小到大处理顶点**。
- **d[v] 是可达的上界，且不可能更小**。 `d[v] = d[u] + 1` 说明确实存在一条长度为 `d[v]` 的 s→v 路径（沿 `path[]` 回溯即得）， 所以 d[v]≥ 真实最短距离。 反过来，假设真实最短距离是 δ<d[v]，那么最短路径上 v 的前一个顶点 u′ 满足 d[u′]=δ−1<d[v]−1=d[u]。由支点 1，u′ 会**先于** u 出队； u′ 出队时检查到邻居 v，若 v 那时还没被访问，就会立刻被赋值 δ； 若 v 那时已被访问，说明 v 更早被赋了一个不超过 δ 的值。 两种情况都与"v 最终的值是 d[v]>δ"矛盾。∎

**这个证明用到的唯一图性质是"每条边长度都是 1"**。这就是下一节要谈的边界。

## 边界：什么时候不能用

**能用的情形**：

- 无权图（求边数最少）。
- **所有边权相等**的带权图。若每条边权都是 c，最小权和 =c×（最少边数）， 跑 BFS 再把 d[] 乘 c 即可。这是最常被忽略的一种可用情形。

**不能用的情形**：边权不全相等。

**反例**：有向图 0→1 权 100，0→2 权 1，2→1 权 1。 BFS 从 0 出发：第 1 层是 {1,2}，得到 d[1]=1（一条边），认为 0→1 是"最短"。 但按权值算，0→1 代价 100，而 0→2→1 代价只有 2。 **"边最少"与"权和最小"在这里指向了不同的路径。**

根因很直接：BFS 的正确性依赖"每走一步代价增加相同的量"， 一旦步长不同，"先到达"就不再意味着"代价最小"。带权图必须用 [Dijkstra](./dijkstra.html)。

反过来理解 Dijkstra 会更容易：**Dijkstra 就是把 BFS 的普通队列换成"按当前距离取最小"的 优先队列**。当所有边权相等时，普通队列本来就是按距离递增出队的，两者退化为同一个算法。

## 两个常见变体

这两个变体都只改动几行，却能检验你是不是真的理解了"层号即距离"。

### 变体一：边权全为常数 c

若每条边的权都是同一个常数 c（不必是 1），最小权和 =c× 最少边数， 所以**照跑 BFS，最后把 d[] 整体乘以 c 即可**，完全不需要 Dijkstra。

上例若把每条边的权都设成 5，则 0 到各顶点的最短距离是 0, 5, 5, 10, 10, 15——就是原来的 d[] 乘 5。

**推广判据**：只要"每走一步付出的代价相同"，BFS 就适用；代价不同才必须换 Dijkstra。

### 变体二：统计最短路径的条数

只加一个计数数组 `cnt[]`，在遍历时按两种情形更新：c

```
int cnt[MAX_V];      // cnt[v] = 从源点到 v 的最短路径条数

void BFS_CountPaths(int s, int n) {
    for (int i = 0; i < n; i++) { d[i] = -1; cnt[i] = 0; }
    Queue Q; InitQueue(&Q);
    d[s] = 0; cnt[s] = 1;                 // 源点到自己算 1 条（空路径）
    EnQueue(&Q, s);

    while (!IsEmpty(&Q)) {
        int u; DeQueue(&Q, &u);
        for (int v = FirstNeighbor(u); v >= 0; v = NextNeighbor(u, v)) {
            if (d[v] == -1) {             // 情形 A：第一次到达 v
                d[v] = d[u] + 1;
                cnt[v] = cnt[u];          // 条数继承 u 的
                EnQueue(&Q, v);
            } else if (d[v] == d[u] + 1) { // 情形 B：又发现一条同样短的路
                cnt[v] += cnt[u];         // 累加，不能覆盖
            }
            // d[v] < d[u] + 1 的情形：这条路更长，忽略
        }
    }
}
```

**两处关键**：

- **情形 B 不能漏**。只写情形 A 会漏掉"从另一个同层前驱走过来"的路径。
- **`d[v] == d[u] + 1` 这个条件必须写死**，不能只判"已访问"—— 已访问的顶点也可能是 u 的**同层**邻居（d[v]=d[u]），那条边不构成最短路径的一步。

用本篇走查那张图跑一遍：cnt[0]=1；cnt[1]=cnt[2]=1； cnt[3]=cnt[1]=1；cnt[4] 先由 u=1 置为 1，之后 u=2 出队时发现 d[4]=2=d[2]+1，于是 cnt[4]+=cnt[2]=1，得 cnt[4]=2 （对应 0→1→4 与 0→2→4 两条）； 最后 cnt[5]=cnt[4]=2。**这正好印证了前面说的"最短距离唯一、最短路径不唯一"。**

## 复杂度分析

| 指标 | 复杂度 | 来历 |
| --- | --- | --- |
| 时间（邻接表） | O(n+e) | 每个顶点入队/出队各一次（O(n)）+ 每个边结点检查一次（O(e)） |
| 时间（邻接矩阵） | O(n2) | 每个顶点出队一次，每次扫一整行 n 格 |
| 空间 | O(n) | 队列、`d[]`、`path[]` 各 O(n)；队列长度上界为 n |
| 路径还原 | O(路径长度)，最坏 O(n) | 沿 `path[]` 回溯，每步 O(1) |

与遍历相比**没有增加任何量级开销**——`d[]` 与 `path[]` 的维护都是每个顶点一次的 O(1) 操作。 这是 BFS 求最短路径最漂亮的地方：**免费**。

## 易混淆知识点

**1. 三种最短路径算法怎么选？**

| 算法 | 适用图 | 求什么 | 时间 | 判别依据 |
| --- | --- | --- | --- | --- |
| **BFS** | 无权 / 边权全相等 | 单源 | O(n+e) | 问"每条边代价是不是一样"，是则用 BFS，最快 |
| **Dijkstra** | 带权，**权非负** | 单源 | O(n2) 或 O(elog⁡n) | 有正权、只要一个源点 |
| **Floyd** | 带权，允许**负权边**，不允许负权回路 | 所有顶点对 | O(n3) | 要的是全部点对，或存在负权边 |

选择的第一问永远是"**图有没有权、权是不是全相等**"，第二问才是"要单源还是全源"。

**2. `d[v] == -1` 表示未访问还是不可达？**

**在算法运行中表示"未访问"，在算法结束后表示"不可达"。** 这不是二义性，而是同一个事实在两个时刻的两种读法：结束时仍未被访问，就说明确实到不了。 用 −1 而不用 0 做初值，是因为 0 已经被源点自己占用了（d[s]=0）。

**3. `path[]` 可以省吗？**

只求距离可以省；只要题目问"写出最短路径"就不能省。 判据：**d[] 是一个"多少"，path[] 是一个"怎么走"，两者不能互相导出**—— 从 d[] 反推路径需要再次遍历找"距离恰好小 1 的邻居"，那是另一次 O(n+e) 的搜索。

**4. 最短路径唯一吗？`path[]` 记录的是哪一条？**

一般不唯一。`path[v]` 记录的是**实际首次发现 v 的那个顶点**， 所以它取决于邻接表中边的次序。上例中 0→5 既可以是 0→1→4→5， 也可以是 0→2→4→5，长度都是 3。 **"最短距离唯一，最短路径不唯一"**——这与[图的基本概念](./concepts.html)里"距离是图的固有量"一致。

**5. BFS 求最短路径和 BFS 生成树是什么关系？**

`path[]` 就是 BFS 生成树的父指针数组，两者是同一个东西的两种叫法。 BFS 树上从根到 v 的路径长度就是 d[v]。

## 本节小结

学完本篇，你应该能够：

- 给定无权图与源点，**填出完整的 d[] 与 path[] 表**，并画出每一步的队列状态。
- 由 path[] 还原任意一条最短路径，并说清"为什么要借助栈翻转"。
- 完整叙述"首次到达即最短"的证明，指出它依赖队列的哪条性质。
- 判断一道题能否用 BFS 求最短路径：**判据是"每条边的代价是否相同"，不是"图上有没有写权值"**。
- 说清 BFS 与 Dijkstra 的关系：后者是前者把普通队列换成优先队列的推广。

三条最关键的结论：

- **层号即距离**：BFS 逐层扩展，顶点首次被发现时的层号就是最短距离，且这一改造是零额外开销的。
- **`d[]` 与 `path[]` 必须在入队的同一时刻赋值**，否则会重复入队并写坏距离。
- **只适用于边权全相等的图**；边权不等时"边最少"不等于"权和最小"，必须换 Dijkstra。
