## 知识框架

本节要回答四个问题：

- 转换到底是"变换"还是"换个读法"？为什么这个对应关系是**一一**的？
- 一棵**树**转出来的二叉树，根为什么一定没有右子树？
- 树的先根 = 二叉树的先序、树的后根 = **中序**——为什么是中序而不是后序？
- 森林转成二叉树后，空指针域有多少个？分别是哪些结点贡献的？

## 一、转换的本质

转换的理论基础是**孩子兄弟表示法**（又称二叉链表表示法）：

- **左指针**（`firstchild`）指向该结点的**第一个孩子**
- **右指针**（`nextsibling`）指向该结点的**下一个右兄弟**

```
孩子兄弟表示法的结点结构：
┌────────────┬──────┬──────────────┐
│ firstchild │ data │ nextsibling  │
└────────────┴──────┴──────────────┘
      ↓                     ↓
   第一个孩子           下一个右兄弟
```

**关键认识：转换不是"把一棵树变成另一棵树"，而是"同一份存储换一种读法"。**

一个结点在内存里就是"数据 + 两个指针"。把这两个指针**读作**"第一个孩子 / 右兄弟"，看到的是一棵一般树；把它们**读作**"左孩子 / 右孩子"，看到的是一棵二叉树。存储一个字节都没动。

这解释了三件事：

- **为什么对应是一一的**：同一份存储只有一种读法结果，反过来也只有一种
- **为什么转换是 O(n) 且原地**：本质上什么都不用做
- **为什么转换后可以直接套用二叉树的全部算法**：因为它本来就是一棵二叉链表

## 二、树 → 二叉树

口诀：**"兄弟相连留长子"**。

**三个步骤**：

- 在所有**相邻兄弟结点**之间加一条连线
- 对每个结点，只保留它与**第一个孩子**的连线，删除它与其他孩子的连线
- 以根结点为轴心，将整棵树**顺时针旋转 45°** 调整形态

**图示**：

```
第 0 步：原树              第 1 步：兄弟相连           第 2 步：只留长子
      A                        A                          A
    / | \                    / | \                        |
   B  C  D                  B—-C—-D                      B—-C—-D
  / \    |                 / \    |                      |     |
 E   F   G               E—-F     G                      E—-F  G

第 3 步：顺时针旋转 45°（横线变成右指针、竖线变成左指针）
      A
     /
    B
   / \
  E   C
   \    \
    F    D
        /
       G
```

**逐个核对这棵二叉树**：A 的左孩子是 B（A 的长子）、A 无右孩子（A 无兄弟）；B 的左孩子是 E（B 的长子）、右孩子是 C（B 的右兄弟）；E 无左孩子、右孩子是 F（E 的右兄弟）；C 无左孩子（C 是叶子）、右孩子是 D；D 的左孩子是 G、无右孩子。✓

### 树转出来的二叉树，根一定没有右子树

**证明**：转换规则规定"右指针指向右兄弟"。树只有一个根，**根没有兄弟**，所以它的右指针必为空。

教材把这句话写成："任何一棵和树对应的二叉树，其根结点的右子树必空。"

**这条性质是逆变换的判据**（见第四节），也是"森林转出来的二叉树根有右子树"的对照面。

### 转换的唯一性

一棵树对应**唯一**一棵二叉树。原因还是"同一份存储的两种读法"——孩子的次序（有序树）唯一决定了长子与兄弟链，因此二叉树的形态被完全钉死。

## 三、森林 → 二叉树

### 直观做法

- 将森林中每棵树各自转换为二叉树
- 将**第二棵**二叉树作为**第一棵**二叉树根结点的**右子树**
- 将**第三棵**作为**第二棵**根结点的右子树
- 依此类推，所有树的根通过右指针串成一条链

**等价的一句话理解**：把森林中各棵树的根**看作互为兄弟**，然后整体按孩子兄弟表示法处理即可——因为"右指针指向右兄弟"，各树根自然被串起来。

### 教材的递归定义

设森林 F={T1,T2,…,Tm}，对应的二叉树 B=(root,LB,RB)：

- 若 F 为空（m=0），则 B 为空树
- 若 F 非空，则

- B 的根 root 即为森林中**第一棵树的根** ROOT(T1)
- B 的**左子树** LB 是由 T1 中根结点的**子树森林** F1={T11,T12,…,T1m} 转换而成的二叉树
- B 的**右子树** RB 是由森林 F′={T2,T3,…,Tm} 转换而成的二叉树

**这个递归定义比三步做法更有用**——第五节的遍历对应关系全部由它直接推出。请记住这三行的对应：二叉树的根↔第一棵树的根,左子树↔第一棵树的子树森林,右子树↔剩余树的森林

### 示例

```
森林 F = { T1, T2, T3 }

   T1         T2        T3
    A          E         G
   / \         |        / \
  B   C        F       H   I
      |
      D

转换后的二叉树（左指针 = 长子，右指针 = 右兄弟）：

        A
       / \
      B   E
       \  / \
        C F  G
       /     /
      D     H
             \
              I
```

**逐个核对**：A 的长子是 B → 左孩子 B；A 的"右兄弟"是 E（T2 的根）→ 右孩子 E。B 无孩子 → 无左孩子；B 的右兄弟是 C → 右孩子 C。C 的长子是 D → 左孩子 D；C 无右兄弟 → 无右孩子。E 的长子是 F → 左孩子 F；E 的右兄弟是 G（T3 的根）→ 右孩子 G。G 的长子是 H → 左孩子 H；G 无右兄弟 → 无右孩子。H 无孩子；H 的右兄弟是 I → 右孩子 I。✓

**根 A 有右子树**（因为 A 有"兄弟" E），这与"一棵树转出来的根没有右子树"形成对照。

## 四、二叉树 → 树 / 森林

### 判据：看根有没有右子树

| 二叉树的根 | 还原结果 |
| --- | --- |
| **没有**右子树 | 一棵**树** |
| **有**右子树 | 一片**森林**（森林中树的棵数 = 沿根的右链能走多少步 + 1） |

### 二叉树 → 树

- 若某结点 p 是其双亲的**左孩子**，则把 p 的右孩子、右孩子的右孩子……**全部**与 p 的双亲连线（这些结点原本都是 p 的兄弟，即同一个双亲的孩子）
- 删除原二叉树中所有结点与其**右孩子**的连线
- 调整层次，使之成为一棵树

### 二叉树 → 森林

- 从根开始，沿**右指针链**逐个断开，得到若干棵二叉树（根、根的右子树、根的右子树的右子树……）
- 将每棵二叉树分别按上面的规则还原成树
- 所有树按原次序构成森林

**教材的递归定义**（与正变换严格互逆）：设 B=(root,LB,RB)，对应森林 F={T1,T2,…,Tm}：

- 若 B 为空，则 F 为空
- 若 B 非空，则 F 中第一棵树 T1 的根 ROOT(T1) 即为 B 的根；T1 中根结点的子树森林 F1 由 LB 转换而成；F 中除 T1 之外的森林 F′={T2,…,Tm} 由 RB 转换而成

## 五、遍历对应关系的推导

这是本篇的核心。结论是：

| 树（一般树）的遍历 | 森林的遍历 | 对应二叉树的遍历 |
| --- | --- | --- |
| 先根遍历 | 先序遍历 | **先序遍历** |
| 后根遍历 | 中序遍历 | **中序遍历** |

下面把它**推出来**，不是背下来。

### 记号

设 B(F) 表示森林 F 转换成的二叉树。由第三节的递归定义，若 F={T1,…,Tm} 非空，则B(F)=( root(T1)⏟根, B(children(T1))⏟左子树, B({T2,…,Tm})⏟右子树 )

其中 children(T1) 表示 T1 的根的子树森林。

### 对应一：森林的先序 = 二叉树的先序

二叉树的先序按定义展开：Pre(B(F))=root(T1)⋅Pre(B(children(T1)))⋅Pre(B({T2,…,Tm}))

由归纳假设，后两项分别等于"先序遍历 T1 的子树森林"和"先序遍历剩余树构成的森林"。于是整式变成

访问第一棵树的根 → 先序遍历第一棵树的子树森林 → 先序遍历剩余树构成的森林

**这恰好逐字就是[森林先序遍历的定义](./general-tree.html)。** 证毕。

### 对应二：森林的中序 = 二叉树的中序

二叉树的中序按定义展开：In(B(F))=In(B(children(T1)))⋅root(T1)⋅In(B({T2,…,Tm}))

即

中序遍历第一棵树的子树森林 → 访问第一棵树的根 → 中序遍历剩余树构成的森林

**这恰好逐字就是森林中序遍历的定义。** 证毕。

**这两条对应之所以是"逐字相同"，不是巧合**——森林的这两种遍历本来就是照着"二叉树的根 / 左子树 / 右子树"的三段式**定义出来的**。第三节末尾框起来的那三条对应，就是全部原因。

### 对应三：树的先根 = 二叉树的先序

一棵树 T（根为 r、子树森林为 Fr）转换后的二叉树是 B({T})，其根为 r、左子树为 B(Fr)、**右子树为空**（T 之后没有别的树）。于是Pre(B({T}))=r⋅Pre(B(Fr))⋅ε=r⋅(先序遍历 Fr)

而树的先根遍历定义为"先访问根，再依次先根遍历根的每棵子树"——正是 r 后接"依次遍历子树森林"。证毕。

### 对应四：树的后根 = 二叉树的**中序**（不是后序）
In(B({T}))=In(B(Fr))⋅r⋅ε=(中序遍历 Fr)⋅r

还需要一步：**森林的中序遍历，等于依次对每棵树做后根遍历**。对 m 归纳：

- m=0：两边都是空串
- m≥1：InForest({T1,…,Tm})=InForest(children(T1))⋅root(T1)⋅InForest({T2,…,Tm})。由归纳假设，第一项 = 依次后根遍历 T1 的各棵子树；再接上 root(T1)，**恰好就是 T1 的后根遍历**；第三项 = 依次后根遍历 T2,…,Tm

所以 In(B({T}))=[依次后根遍历 T 的各棵子树]⋅r，这正是树的后根遍历定义。证毕。

### 为什么是中序而不是后序

**根源在于"树转出来的二叉树，根没有右子树"这条性质。**

树的后根遍历要求"根在它的所有子树之后"。转换后，一棵树的**全部子树**都被塞进了二叉树的**左子树**，右子树是空的。于是：

- **中序**（左 → 根 → 右）：左子树（= 全部子树）→ 根 → 空。根排在所有子树之后 ✓
- **后序**（左 → 右 → 根）：左子树 → 空 → 根。在**根这一层**看，后序和中序给出的位置相同——但在**内部结点**上就不同了，因为内部结点的右子树（= 它的兄弟们）非空

**用具体例子看得最清楚**。取第二节那棵树，它转换后的二叉树是：

```
A
└─左─ B
       ├─左─ E
       │      └─右─ F
       └─右─ C
              └─右─ D
                     └─左─ G
```

| 二叉树遍历 | 序列 | 树上的对应 |
| --- | --- | --- |
| 先序 | **A B E F C D G** | = 树的先根遍历 ✓ |
| 中序 | **E F B C G D A** | = 树的后根遍历 ✓ |
| 后序 | **F E G D C B A** | 树上**没有**任何一种遍历给出这个序列 |

**后序把 B 排在了 C、D、G 之后**——可是在原树里，C、D 是 B 的**兄弟**，不是 B 的子树；"访问完兄弟才访问自己"在树上没有任何语义。这就是二叉树的后序在树 / 森林上找不到对应的原因。

## 六、转换后的结点数与空指针数

设森林（或树）共 n 个结点。转换后的二叉树同样是 n 个结点（转换不增删结点），因此它作为一棵[二叉链表](./concepts.html)有 **n+1 个空指针域**。

更细致地，可以说清这 n+1 个空指针分别是谁贡献的：

| 空指针 | 什么时候为空 | 个数 |
| --- | --- | --- |
| 左指针（`firstchild`） | 该结点**没有孩子**，即它是原森林中的**叶结点** | n0（叶结点数） |
| 右指针（`nextsibling`） | 该结点是其双亲的**最后一个孩子**，或是**最后一棵树的根** | （分支结点数）+1=(n−n0)+1 |
| **合计** | — | n0+(n−n0)+1=n+1 ✓ |

**验算**（用第三节那片 9 个结点的森林）：叶结点是 B、D、F、H、I 共 5 个 → 空左指针 5 个；分支结点是 A、C、E、G 共 4 个 → 空右指针 4+1=5 个；合计 10 =9+1 ✓。逐个数转换后的二叉树，空指针也正是 10 个。

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 树 → 二叉树 | O(n) | O(1) | 只是改变对两个指针的解释；若真的重建，每个结点处理一次 |
| 森林 → 二叉树 | O(n) | O(1) | n 为森林中所有结点总数 |
| 二叉树 → 树 | O(n) | O(1) | 逆向解释同样是常数工作 |
| 二叉树 → 森林 | O(n) | O(1) | 沿右链断开是 O(树棵数)，其余 O(n) |
| 由树 / 森林求对应二叉树的遍历序列 | O(n) | O(h) | 直接对原树做先根 / 后根遍历即可，递归栈 O(h) |

**空间为什么是 O(1)**：转换只需修改（或重新解释）指针，不申请新结点。若用递归实现，另需 O(h) 的栈空间。

## 易混淆知识点

| 对比项 | 一方 | 另一方 | 判别依据 |
| --- | --- | --- | --- |
| 树转二叉树后根有无右子树 | **树**：根无右子树 | **森林**：根有右子树（森林至少两棵树时） | 根有没有兄弟 |
| 二叉树还原成树还是森林 | 根无右子树 → 还原为**树** | 根有右子树 → 还原为**森林** | 只看根的右指针 |
| 树的后根对应哪种二叉树遍历 | **中序** | 不是后序 | 树的所有子树都在二叉树的左子树里，右子树装的是"兄弟" |
| 二叉树的后序在树上的对应 | **没有对应** | — | 后序会把结点排在其兄弟之后，树上无此语义 |
| 森林的中序 vs 依次对每棵树后根遍历 | 二者相等 | — | 可对树的棵数归纳证明 |
| 转换是否唯一 | 树 ↔ 二叉树是**一一对应** | — | 同一份存储的两种读法，两边都只有一种结果 |
| 森林与二叉树的对应 vs 树与二叉树的对应 | 森林 ↔ **任意**二叉树 | 树 ↔ **根无右子树**的二叉树 | 二叉树的全体对应森林的全体，树只对应其中一个子集 |
| 转换后结点数 | 不变，仍为 n | — | 转换不增删结点，只改变指针的解释 |
| 空左指针 vs 空右指针 | 空左指针数 = 叶结点数 | 空右指针数 = 分支结点数 +1 | 左指针空 ⟺ 无孩子；右指针空 ⟺ 是最后一个孩子或最后一棵树的根 |
| 求"转换后二叉树的先序"的两种走法 | 画出二叉树再遍历 | 直接对原树做先根遍历 | 结果相同；后者更快，前者更便于核对 |

## 本节小结

学完本篇，应该能够：

- **说清转换的本质**：不是"变换成另一种结构"，而是把孩子兄弟表示法的两个指针**换一种读法**——正因如此，转换是一一对应的、O(n) 的、原地的
- **执行树 → 二叉树的三步**（兄弟相连、只留长子、顺时针旋转 45°），并**证明**树转出来的二叉树根没有右子树（根没有兄弟）
- **执行森林 → 二叉树**，并默写它的递归定义（根 ↔ 第一棵树的根、左子树 ↔ 第一棵树的子树森林、右子树 ↔ 剩余树的森林）
- **由二叉树还原**：先看根有无右子树以判定还原为树还是森林，再沿右链断开、逐棵还原
- **推导四条遍历对应关系**，而不是死记：森林先序 / 中序的定义本来就是照着二叉树的三段式写出来的，所以对应是"逐字相同"
- **解释树的后根为什么对应中序而不是后序**：树的全部子树都在二叉树的左子树里、右子树装的是兄弟；并能给出具体反例说明二叉树的后序在树上没有对应
- **数出转换后二叉树的空指针**：共 n+1 个，其中空左指针 = 叶结点数、空右指针 = 分支结点数 +1

**两条最关键的结论**：**"根有没有右子树"是树与森林的分水岭**，正变换和逆变换都靠它；**树的后根 = 二叉树的中序**，二叉树的后序在树 / 森林上没有对应物。
