# 存储器的分类

## 大纲定位

**三（一）存储器的分类**

要求：掌握按存取方式、存储介质、信息可保存性、在系统中的位置等维度对存储器的分类，知道各类的典型器件与用途。

层次化结构本身见 [[03_计算机组成原理_CO/storage/memory-hierarchy.md|层次化存储器的基本结构]]；各类半导体存储器的内部原理见 [[03_计算机组成原理_CO/storage/sram-dram.md|半导体随机存取存储器]]。

## 知识框架

本节回答三个问题：

- 存储器有哪几种分类维度？同一个器件在不同维度下分别属于什么？
- "随机存取"的确切含义是什么？分界线在哪里？
- 为什么 CPU 不能直接访问辅存？

## 一、按存取方式分类

这是最重要的一个维度，判据是**存取时间与物理位置的关系**。

| 存取方式 | 定义 | 典型器件 |
| --- | --- | --- |
| **随机存取**（RAM） | 存取时间与单元的物理位置**无关**，各单元相同 | SRAM、DRAM、ROM、EPROM、**Flash** |
| **顺序存取**（SAM） | 必须从头顺序查找，存取时间与位置**强相关** | 磁带 |
| **直接存取**（DAM） | 先直接定位到某个区域，再在区域内顺序查找 | **磁盘、光盘** |
| **相联存取**（CAM） | 按**内容**而非地址访问 | 相联存储器、**TLB** |

> [!WARNING]
>

分界线在有无机械部件，不在能不能写

两处常见的误判：

- **CD-ROM**：名字里有 ROM，但它带机械寻道机构，读不同位置的时间差别很大，属于**直接存取**
- **Flash / EPROM**：虽属"只读"家族，但访问任一单元的时间相同，属于**随机存取**

**"RAM"与"ROM"这组名称是历史遗留**——ROM 同样是随机存取的，两者的真正差别在可写性与易失性，与存取方式无关。

### 相联存取为什么单列一类

前三类都是"给地址、取内容"，相联存取反过来——**给内容、找位置**。

TLB 就是典型：拿一个虚页号去比对全部表项的标记，命中则返回对应的实页号。它不是"读第 n 项"，而是"找出标记等于某值的那一项"。

实现方式是让所有表项**同时**参与比较，因此硬件开销大，只用于表项很少的场合。

## 二、按存储介质分类

| 介质 | 典型器件 | 特点 |
| --- | --- | --- |
| 半导体存储器 | SRAM、DRAM、Flash | 速度快，无机械部件 |
| 磁表面存储器 | 磁盘、磁带 | 容量大，非易失，有机械部件 |
| 光存储器 | CD、DVD | 非易失，可移动 |

## 三、按信息的可保存性分类

| 类别 | 含义 | 器件 |
| --- | --- | --- |
| **易失性存储器** | 断电后信息**丢失** | SRAM、DRAM（即全部 RAM） |
| **非易失性存储器** | 断电后信息**保留** | ROM 家族、Flash、磁盘、光盘 |

另一组相关但不同的概念：

| 类别 | 含义 |
| --- | --- |
| **破坏性读出** | 读出操作会破坏原信息，**读后必须重写** |
| 非破坏性读出 | 读出不影响原信息 |

**DRAM 是破坏性读出**——读取时电容上的电荷被放掉，必须再充回去。这正是 DRAM 的存储周期大于存取时间的原因。SRAM 与 ROM 都是非破坏性读出。

> [!TIP]
>

易失性与破坏性读出是两回事

- **易失性**说的是**断电**之后会不会丢
- **破坏性读出**说的是**读一次**之后会不会丢

DRAM 两者都占；SRAM 易失但非破坏性读出；Flash 两者都不占。

## 四、按在系统中的位置分类

| 类别 | 范围 | 能否被 CPU 直接访问 |
| --- | --- | --- |
| **主存储器**（内存） | DRAM 内存条 | **能** |
| **辅助存储器**（外存） | 磁盘、SSD、光盘 | **不能** |
| **高速缓冲存储器** | Cache（SRAM） | 能 |
| 寄存器 | CPU 内部 | 能 |

> [!WARNING]
>

CPU 不能直接访问辅存

这是一条硬性结论：**辅存中的数据必须先调入主存，CPU 才能访问**。

原因在于寻址方式的根本不同。CPU 通过地址总线发出的是**主存地址**，主存能按此直接定位到某个单元；而辅存的定位需要"柱面号 + 磁头号 + 扇区号"这类几何地址，且要经过机械寻道——CPU 的地址总线上根本无法表达这种寻址方式。

因此辅存只能作为 I/O 设备，由 I/O 接口或 DMA 控制器负责搬运。

## 五、同一器件在各维度下的归属

把前面四个维度合起来看，同一个器件可以有多重身份：

| 器件 | 存取方式 | 易失性 | 位置 |
| --- | --- | --- | --- |
| SRAM | 随机存取 | 易失 | Cache |
| DRAM | 随机存取 | 易失 | 主存 |
| Flash | **随机存取** | **非易失** | 辅存（SSD）/ BIOS |
| 磁盘 | **直接存取** | 非易失 | 辅存 |
| 磁带 | **顺序存取** | 非易失 | 脱机备份 |
| TLB | **相联存取** | 易失 | CPU 内部 |

**分类维度是相互独立的**——Flash 既是随机存取又是非易失，磁盘既是直接存取又是非易失，两者的差别在存取方式而非可保存性。

## 易混淆知识点

**1. RAM 和 ROM 的区别到底是什么？**

不是"能不能随机访问"（两者都能），而是：

|  | RAM | ROM |
| --- | --- | --- |
| 可写性 | 可随时读写 | 只读或写入受限（需专门的编程/擦除操作） |
| 易失性 | **易失** | **非易失** |

**2. Flash 属于 RAM 还是 ROM？**

按传统分类归入 ROM 家族（由 EPROM 发展而来），但它可以电擦除并重写，性质上介于两者之间。**按存取方式它是随机存取的**，这一点与 RAM 相同。

**3. Cache 属于主存吗？**

不属于。Cache 是主存内容的副本，与主存共用同一个地址空间但物理上是独立的 SRAM。程序无法通过地址直接指定"访问 Cache"——命中与否由硬件判断，对程序完全透明。

## 本节小结

- 四个分类维度：**存取方式、存储介质、信息可保存性、在系统中的位置**，相互独立
- **随机存取**指存取时间与物理位置无关；分界线是**有无机械部件**
- **Flash 与 ROM 都是随机存取**；**CD-ROM 是直接存取**
- **相联存取**按内容访问，典型是 TLB，硬件开销大
- 易失性说的是**断电**，破坏性读出说的是**读一次**，两者不同；**DRAM 两者都占**
- **CPU 不能直接访问辅存**——辅存需几何地址与机械寻道，必须先调入主存
- 同一器件在不同维度下有不同归属，Flash 是随机存取 + 非易失的组合
