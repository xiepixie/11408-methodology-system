# 算术逻辑单元（ALU）

## 大纲定位

**二（二）1　基本运算部件**

大纲原文：「加法器，算术逻辑部件（ALU）。」

要求：能从一位全加器推出多位加法器，说清串行进位与先行进位的差别在哪、后者为什么快，知道 ALU 由哪几部分构成、除结果外还输出哪些信息。

标志位的具体表达式与用法在 [[03_计算机组成原理_CO/data-repr/complement-add.md|补码加减运算与溢出判别]]，本篇只讲它们从电路的哪个位置引出。

## 知识框架

本节回答四个问题：

- 为什么"几乎所有算术运算都要用到加法器"，加法器的速度就成了整台机器的瓶颈？
- 串行进位加法器慢，慢在哪一根线上？
- 先行进位是怎么把这根线剪断的？剪断之后代价是什么？
- ALU 里除了加法器还有什么？为什么移位器反而被挪到 ALU 外面？

## 一、加法器为什么是核心

减法靠[[03_计算机组成原理_CO/data-repr/complement-add.md|求补转成加法]]，乘法靠"移位 + 加"，除法靠"移位 + 加/减"，浮点运算的尾数部分同样落回定点加减。**整个运算体系最后都压到加法器身上**，所以加法器的延迟直接决定了机器的运算速度——这是本节所有优化的出发点。

## 二、一位全加器：唯一的原子

全加器（Full Adder, FA）三个输入 Ai、Bi、Ci，两个输出：本位和 Si、向高位的进位 Ci+1。Si=Ai⊕Bi⊕CiCi+1=AiBi+(Ai+Bi)Ci

进位表达式读起来就是两句人话：

- AiBi：**两位都是 1，不管低位来不来进位，本位一定往高位送进位**
- (Ai+Bi)Ci：两位中有一个是 1，则低位送来的进位会**穿过本位继续往上走**

把这两项各起个名字：Gi=AiBi(进位生成函数)Pi=Ai+Bi(进位传递函数)Ci+1=Gi+PiCi

> [!TIP]
>

Pi 用"或"还是"异或"

教材定义 Pi=Ai+Bi（或），也有资料定义 Pi=Ai⊕Bi（异或）。

两者对**进位**的计算结果完全相同——只有 Ai=Bi=1 时两式取值不同，而这时 Gi=1 已经让 Ci+1=1 了，Pi 取什么无关紧要。

差别在于用途：用异或定义时，Pi 可以直接复用于求和（Si=Pi⊕Ci），省一个异或门；用或定义时，Pi 的"传递"含义更直白。看到哪一种都不必慌，先看它给的定义式。

## 三、串行进位：慢在一根链条上

把 n 个全加器级联，第 i 位的进位输出直接接到第 i+1 位的进位输入：C1=G0+P0C0,C2=G1+P1C1,⋯,Cn=Gn−1+Pn−1Cn−1

最低位的进位 C0 像投进水面的一块石头，涟漪一圈圈往外扩——所以这种结构叫**行波进位加法器**（Carry Ripple Adder, CRA）。

**慢的根源是一句话：高位进位依赖低位进位。** 全加器内部从进位输入到进位输出是**两级门延迟**，于是 n 位加法器从 C0 一路走到 Cn 就是 2n 级门延迟；最高位的和还要在这之后再过一个异或门才出来。

延迟与位数**成正比**。位数一多，速度显著变慢。

要提速，只能从这句话下手：**尽量避免进位之间的依赖关系。**

## 四、先行进位：把依赖链拆成一层展开式

方法很直接——把递推式一层层代入，直到每个 Ci 都只依赖 G、P 和最初的 C0：C1=G0+P0C0C2=G1+P1G0+P1P0C0C3=G2+P2G1+P2P1G0+P2P1P0C0C4=G3+P3G2+P3P2G1+P3P2P1G0+P3P2P1P0C0

现在每个 Ci 都是一个**两级与或式**：所有 Gj、Pj 在同一级门延迟内并行产生，C0 从一开始就有。只要输入到齐，C1∼C4 **几乎同时**出现。

实现这组表达式的电路叫**先行进位部件**（Carry Lookahead Unit, CLU），用它构成的加法器叫**先行进位加法器**（CLA），也称并行进位加法器。

**4 位全先行进位加法器的关键路径**（异或门按 3 级门计）：

| 阶段 | 门延迟 |
| --- | --- |
| 由 Xi、Yi 产生 Pi、Gi | 1 |
| 由 Pi、Gi、C0 产生全部进位 C1∼C4 | 2 |
| 由 Pi、Ci 异或产生全部和 | 3 |
| **合计** | **6** |

**注意这个 6 与位数无关**——这正是先行进位的价值。

### 代价：扇入与连线

理论上 32 位也可以做成一级全先行进位，还是 6 级门延迟。但代价是：C32 的与门和或门要有**三十多个输入端**，还要驱动海量连线。这种大扇入门在物理上做不出来。

所以实际做法是**分组 + 分层**：

| 结构 | 说明 | 延迟 |
| --- | --- | --- |
| 组内串行 + 组间串行 | 纯行波加法器 | O(n) |
| 组内并行 + 组间串行 | 4 位一组 CLA，组间行波 | 约 O(n/4) |
| **组内并行 + 组间并行** | 两级先行进位 | **与位数无关** |

**两级先行进位加法器的延迟与位数无关**，这是计算机内部普遍采用两级或多级先行进位的原因。

## 五、从加法器到 ALU

### 第一步：带标志加法器

一个纯粹的 n 位加法器只会算两个数的和，**既不能做减法，也不能告诉你结果有没有溢出**。要让它支持无符号数和带符号数的加减，得在它外面补两样东西：

- **求补通路**：Y 输入端串一排反相器接二选一多路器，控制端 Sub 同时作为最低位进位送入，Sub=1 时电路算 X+Y―+1=X−Y
- **标志生成逻辑**：从进位链和结果上引出四条信息图 3.6　用全加器实现 n 位带标志加法器的电路（袁春风《计算机组成与系统结构》第 3 版，见文末教材出处）

| 标志 | 表达式 | 从哪儿引出 | 对谁有意义 |
| --- | --- | --- | --- |
| **ZF** | ZF=1⟺F=0 | 结果全零检测（一个或非门） | 两者都有 |
| **SF** | SF=Fn−1 | 结果最高位，直接引线 | 带符号数 |
| **OF** | OF=Cn⊕Cn−1 | 进位链最高两级，一个异或门 | 带符号数 |
| **CF** | CF=Sub⊕Cout | 进位输出与 Sub 异或 | 无符号数 |

> [!WARNING]
>

CF 不等于 Cout

减法在硬件上是 X+Y―+1，够减时最高位**反而**会产生进位。而 CF 在减法里的语义是「借位」，够减时不该置位，所以要把 Cout 取反。加法时 CF=Cout、减法时 CF=Cout―，合起来就是 CF=Sub⊕Cout。

完整推导、减法版 OF 的独立表达式与三种溢出判别方法的统一，见 [[03_计算机组成原理_CO/data-repr/complement-add.md|补码加减运算与溢出判别]]。

教材图中用全加器画加法器只是为了讲清标志怎么产生；真正的电路一定用多级先行进位方式。

### 第二步：加上逻辑运算

**ALU 是一种能进行多种算术运算与逻辑运算的组合逻辑电路，其核心部件是带标志加法器。**

一位 ALU 的内部结构其实很朴素：一个全加器算加法，若干逻辑门分别算「与」「或」，再用一个**多路选择器**按 ALUop 挑一路输出。n 位 ALU 就是 n 个这样的单元加上进位链。

**ALUop 的位数决定了 ALU 能做多少种操作**——3 位最多 8 种。这是一条可以直接反推的关系：题面给出 ALU 支持的运算种类，就能定出控制字段至少几位。

### 第三步：移位器为什么在 ALU 外面

ALU 内部可以顺带实现左移/右移一位或两位（把加法器输出错位取即可）。但移位指令常常要求**一次移动若干位**，这种情况用一个单独的**桶形移位器**（barrel shifter）实现——它用大量多路选择器直接把每一位选到目标位置，**一次完成任意位数的移位**，而不是移一位重复若干次。

把桶形移位器放在 ALU 之外有两个好处：

- **简化 ALU 的控制逻辑**（ALUop 不必再编码移位位数）
- **移位与 ALU 运算可以并行执行**

这解释了一个在数据通路图上常见的现象：移位器往往画成 ALU 旁边的独立方块，而不是画在 ALU 里面。移位规则本身见 [[03_计算机组成原理_CO/data-repr/shift-operations.md|定点数的移位运算]]。

## 例题

**例 1**：4 位 CLA，A=1010，B=0111，C0=0，求各级进位与和。

先算辅助函数（i 从最低位起编号为 0）：

| i | Ai | Bi | Gi=AiBi | Pi=Ai+Bi |
| --- | --- | --- | --- | --- |
| 0 | 0 | 1 | 0 | 1 |
| 1 | 1 | 1 | 1 | 1 |
| 2 | 0 | 1 | 0 | 1 |
| 3 | 1 | 0 | 0 | 1 |

代入展开式：C1=G0+P0C0=0+1⋅0=0C2=G1+P1G0+P1P0C0=1+0+0=1C3=G2+P2G1+P2P1G0+P2P1P0C0=0+1+0+0=1C4=G3+P3G2+P3P2G1+P3P2P1G0+P3P2P1P0C0=0+0+1+0+0=1Si=Ai⊕Bi⊕Ci⇒S=0001,C4=1

核对：10102+01112=100012，即 10+7=17 ✓

**注意这四个式子没有先后顺序**——它们同时求值。行波加法器里必须先有 C1 才能算 C2，这里不必。

**例 2**：16 位加法器采用 4 位一组的两级先行进位结构，设一级门延迟为 T（此例中异或门也按 1T 计），估算总延迟。

| 阶段 | 延迟 | 说明 |
| --- | --- | --- |
| 各位产生 Gi、Pi | 1T | 由 Xi、Yi 经一级门 |
| 组内 CLU 产生组级 G∗、P∗ | 2T | 与、或两级 |
| 组间 CLU 产生各组的**进位输入** C4、C8、C12 | 2T | 由 G∗、P∗、C0 算出 |
| 组进位回灌后，**各组内部再算其余进位** | 2T | ← 最容易漏的一级 |
| 求和 Si=Pi⊕Ci | 1T |  |
| **合计** | 8T | 对比 16 位行波约 32T |

> [!WARNING]
>

组进位和组内其余进位不是同时产生的

组间 CLU 只算出每一组的**进位输入**（C4、C8、C12）。组内其余各位的进位（C1,C2,C3,C5,…）必须**等组进位回来之后**再算一级才产生。

漏掉这 2T 会得到 6T 的错误结果。

另外注意本例把异或门按 1T 计；教材在算 4 位全先行进位的 6 级门延迟时，异或门按 3 级门计。**两套计法各自内部自洽，比较延迟时必须先统一口径**，看题面怎么规定。

## 易混淆知识点

**1. 串行加法器和串行进位加法器是一回事吗？**

不是，这是两个完全不同的结构，只差一个字。

|  | 串行加法器 | 串行进位加法器（行波） |
| --- | --- | --- |
| 全加器数量 | **1 个** | **n 个** |
| 数据怎么进 | 每个时钟周期送 1 位 | n 位同时送入 |
| 进位怎么传 | 存进触发器，下个周期用 | 沿导线逐级传到高位 |
| n 位加法耗时 | **n 个时钟周期** | **1 个时钟周期内的 O(n) 级门延迟** |
| 硬件成本 | 最低 | 中等 |

**串行加法器是分时复用一个全加器，串行进位加法器是空间上排开 n 个全加器。** 前者省硬件、慢在周期数上；后者快在一拍出结果、慢在这一拍很长。

**2. 先行进位既然快，为什么不做成 64 位一级全先行？**

理论延迟确实不随位数增加，但**门的扇入数**会爆炸：32 位全先行进位的 C32 表达式需要三十多输入端的与门和或门，再加上巨量连线和驱动要求，物理上做不出来。

所以先行进位的实际形态永远是**分组分层**：组内先行、组间再先行。这是"理论上的常数延迟"与"工艺可实现性"之间的妥协。

**3. Gi 和 Pi 到底谁"生成"、谁"传递"？**

- Gi=AiBi：**生成**。本位自己造出一个进位，与低位来不来无关。
- Pi=Ai+Bi：**传递**。本位自己不造进位，但如果低位送来一个，它会原样放行。

一句话记法：**G 是"我自己就有"，P 是"你给我我就传"**。展开式里的每一项 PkPk−1⋯Gj 读起来就是「第 j 位生成了一个进位，然后被第 j+1 到第 k 位一路传上来」。

**4. ALU 和加法器是包含关系吗？**

是，但不能反过来说。**加法器是 ALU 的核心部件**，ALU = 带标志加法器 + 逻辑运算门 + 多路选择器。

一个纯加法器：只出和与进位，不能减、不出标志。 一个带标志加法器：能加能减，出四个标志，但不做逻辑运算。 一个 ALU：上述全部，再加按位与/或/异或等，由 ALUop 选择。

**5. 移位运算算不算 ALU 的功能？**

算，但**多位移位通常不在 ALU 内做**。ALU 顺带能移一位或两位；一次移任意位数要用 ALU 外部的桶形移位器，理由是简化 ALU 控制逻辑并让移位与运算并行。看数据通路图时，ALU 旁边单独画的移位方块就是它。

## 本节小结

- 减法、乘法、除法、浮点尾数运算最终都落到加法器上，**加法器的延迟就是运算速度的瓶颈**
- 全加器：Si=Ai⊕Bi⊕Ci，Ci+1=Gi+PiCi；Gi=AiBi 是**生成**，Pi 是**传递**（用或或异或定义都不影响进位结果）
- **串行进位（行波）慢的唯一原因是高位进位依赖低位进位**，延迟 O(n)，与位数成正比
- **先行进位把递推式展开**，使每个 Ci 只依赖 G、P、C0，全部进位并行产生；4 位全先行进位关键路径 6 级门延迟，与位数无关
- 全先行进位受**扇入数**限制无法做大，实际采用组内并行 + 组间并行的两级结构，其延迟与位数无关
- 两级 CLA 中，**组内其余进位要等组进位回灌后再算一级**，不与组进位同时产生
- ALU = **带标志加法器**（核心）+ 逻辑运算门 + 多路选择器；**ALUop 的位数决定操作种类上限**
- 一次移多位由 ALU 外部的**桶形移位器**完成，好处是简化 ALU 控制逻辑并支持移位与运算并行
- 区分**串行加法器**（1 个 FA 分时复用，n 个周期）与**串行进位加法器**（n 个 FA 空间排列，1 个周期）
