\section{本讲目标}

\begin{itemize}[itemsep=0.35em]
  \item 能用\textbf{点积、叉积、混合积}统一表达长度、面积和体积。
  \item 能用\textbf{投影与垂距}理解两空间直线最短距离公式。
  \item 能识别“到两条射线距离和/差”的\textbf{分区线性结构}，把最值问题降到角点与边界。
  \item 能把球、柱、三棱锥交线问题翻译为“一个点到一个平面的距离 + 截面圆”。
  \item 能区分“特殊对称模型的快速公式”与“一般情形必须先找公垂线/投影”的边界。
\end{itemize}

\section{公式与结构速查}

\begin{tcolorbox}[enhanced,colback=gray!5,colframe=black!60,boxrule=0.7pt,arc=1mm,title=\bfseries 1. 向量几何的三层结构]
\[
\boxed{\text{长度}}
\quad
\boxed{\text{面积}}
\quad
\boxed{\text{体积}}
\]
\[
|\vec a|,
\qquad
|\vec a\times\vec b|,
\qquad
|\vec a\cdot(\vec b\times\vec c)|.
\]

其中：
\[
\vec a\cdot\vec b=|\vec a||\vec b|\cos\theta,
\]
\[
|\vec a\times\vec b|=|\vec a||\vec b|\sin\theta.
\]
\end{tcolorbox}

\begin{tcolorbox}[enhanced,colback=gray!5,colframe=black!60,boxrule=0.7pt,arc=1mm,title=\bfseries 2. 点到直线、点到平面、两异面直线]
点 \(P\) 到直线 \(AB\)：
\[
d(P,AB)
=
\frac{|\overrightarrow{AP}\times\overrightarrow{AB}|}{|\overrightarrow{AB}|}.
\]

点 \(P\) 到平面 \(\alpha\)（法向量 \(\vec n\)，平面上一点 \(A\)）：
\[
d(P,\alpha)
=
\frac{|\overrightarrow{AP}\cdot\vec n|}{|\vec n|}.
\]

两异面直线 \(l_1,l_2\)，方向向量分别为 \(\vec u,\vec v\)，连接两直线上一点的向量为 \(\vec w\)：
\[
d(l_1,l_2)
=
\frac{|\vec w\cdot(\vec u\times\vec v)|}{|\vec u\times\vec v|}.
\]
\end{tcolorbox}

\begin{tcolorbox}[enhanced,colback=gray!5,colframe=black!60,boxrule=0.7pt,arc=1mm,title=\bfseries 3. 球截面与圆截面]
若球半径为 \(R\)，球心到截面平面的距离为 \(d\)，截面圆半径为 \(r\)，则
\[
\boxed{R^2=r^2+d^2}.
\]

因此只要能求出球心到截面平面的距离，就能把空间球问题压缩成平面圆问题。
\end{tcolorbox}

\section{模型五：对称题的快速距离公式（有边界）}

\begin{tcolorbox}[enhanced,colback=gray!5,colframe=black!60,boxrule=0.7pt,arc=1mm,title=\bfseries 快速公式不是万能公式]
某些高对称几何体中，两条异面直线长度相等，连接端点的对称线段与两直线构成特殊正交结构，此时常能化出类似
\[
d=\frac{ab\sin\theta}{\sqrt{a^2+b^2-2ab\cos\theta}}
\]
的形式。

但这类公式必须满足非常具体的对称/端点结构，\textbf{不能把它当成一般两异面直线距离公式}。
\end{tcolorbox}

\begin{exbox}{练习}
在正方体 \(ABCD-A_1B_1C_1D_1\) 中，棱长为 \(a\)。求异面直线 \(AC\) 与 \(B_1D_1\) 的距离。
\end{exbox}

\answergrid[8.5cm]{解：}

\studentthink{
  \item 这题能否直接看出两直线分别位于两个平行平面内？
  \item 我是否可以把问题转化为两个平行平面的距离？
  \item 如果我上来套一般异面直线公式，是否比几何法更繁琐？
}
