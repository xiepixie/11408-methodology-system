\section*{一、核心引子与题感诊断}

\textbf{1. 看到这些条件，应立刻想到什么}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{看到“必须相邻”}：优先考虑捆绑成整体，再排列整体，最后处理内部顺序。但要注意是否要求“恰好相邻”，以及捆绑整体是否可能与其他同类对象继续连在一起。
    \item \textbf{看到“互不相邻”}：优先考虑先排数量较多或起分隔作用的一类，再把另一类插入不同空隙。
    \item \textbf{看到“恰好有两人相邻”}：不能只把两人捆绑，还必须把捆绑整体与剩余同类对象插入不同空隙，防止三人连在一起。
    \item \textbf{看到“不能在端点或正中间”}：直接用容斥原理排除禁位，通常比先排后插更加稳定。
    \item \textbf{看到“一奇一偶交替”}：先确定位置类型只有两种，再分别安排奇数和偶数。
    \item \textbf{看到“连续命中”}：不能只使用普通二项分布公式，必须研究命中段的个数、各命中段的长度，以及不命中如何把各段隔开。
    \item \textbf{看到“围成一圈”}：先确认使用圆排列公式 $(n-1)!$。随后插空时，已经形成的圆形位置和空隙是固定的，分配对象时按有标号位置直线排列处理。
    \item \textbf{看到“最短路径”}：把路径翻译为一串固定数量的横步和竖步，只需选择哪些步向右或向上，其余步数会自动确定。
\end{itemize}

\textbf{2. 本类题的常见切入点}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{先确定“先排谁，后插谁”}：通常先排列能形成分隔的对象。例如第 6 题，无论“男插女”还是“女插男”都能做，关键是选择流程更清楚的一种。
    \item \textbf{把每个乘数对应到一个明确动作}：看到 $4!\cdot C_6^2\cdot 2!\cdot 5!$，必须说明谁是整体排列、谁是选人、谁是内部顺序。无法解释的乘数往往意味着重复计数。
    \item \textbf{识别自动确定步骤}：如选定向上步位置后向右步自动确定；选出连续段后内部无需排列；固定交替奇偶位置后数字相对方向自动确定。这些都不应额外计数。
    \item \textbf{限制条件多时考虑容斥}：直接逐步插入可能导致端点、中心位置不断变化，从全部排列中排除禁位通常更稳定。
\end{itemize}

\section*{二、应试方法联系与深度思考}

\textbf{1. 方法的横向联系}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{捆绑法与连续段}：捆绑法不仅用于人员相邻，还可迁移到连续命中的一段、相同字母连续出现、圆排列相邻对象。
    \item \textbf{插空法与隔板法}：插空法处理不相邻；隔板法处理相同对象数量分配及连续段长度的分配（如 $x_1+x_2+x_3=5$）。
    \item \textbf{插空法与圆排列}：圆排列中 $n$ 个对象只产生 $n$ 个空隙。先排好的圆形对象已经固定了空隙的相对位置，后续插入就是普通直线排列。
    \item \textbf{“自动确定”与设而不求}：只选择能够唯一决定整个结果的最少信息。
\end{itemize}

\textbf{2. 实战做题启发}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{先写流程文字，再写组合数}：例如第一题写出“捆绑甲乙$\to$排列男生$\to$挑选相邻女生$\to$女生单位插空”，流程清楚后再写式子。
    \item \textbf{连续性问题必须研究“段”}：不能只数出现次数，必须引入连续段长度、个数及分隔对象位置。
\end{itemize}
