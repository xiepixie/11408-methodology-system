# 专题课教学设计规格

## 基本信息

- 专题名称: 立体几何_几何直觉
- 时长: 120 分钟
- 适用对象: 高一/高二同步或一轮复习

## 教学目标

- [ ] 能从直观图中快速识别线面位置关系
- [ ] 能用斜二测画法还原直观图为平面图
- [ ] 能在复杂立体图形中找到所需的辅助线和截面

## 专题边界

### 覆盖范围

- 空间直线与平面的位置关系判断
- 斜二测画法的还原与应用
- 常见几何体（正方体、棱柱、棱锥）的结构特征
- 截面识别的基本方法

### 不覆盖

- 空间角计算（→ 立体几何_空间角）
- 空间距离（→ 立体几何_距离）
- 外接球与内切球（→ 立体几何_外接球与内切球）

## 方法链条

```
读题 → 标注已知的线面关系
  → 在图中用符号标出垂直/平行
  → 还原直观图的实际比例
  → 找到目标线/面
  → 用判定定理逐步推理
  → 写出完整证明链
```

## 例题规划

| 序号 | 角色 | 功能描述 | 建议难度 |
|---:|---|---|---|
| 1 | 引入 | 斜二测画法还原，建立空间→平面的转换意识 | 基础 |
| 2 | 巩固 | 正方体中线面平行/垂直的快速判断 | 基础 |
| 3 | 综合 | 需要作辅助线才能看出的截面问题 | 中档 |
| 4 | 提高 | 多步推理 + 空间想象，综合判断多个结论 | 中档~难题 |

## 核心公式

- 线面垂直判定: 一条直线垂直于平面内两条相交直线
- 线面平行判定: 平面外一条直线平行于平面内一条直线
- 面面垂直判定: 一个平面内有一条直线垂直于另一个平面
- 斜二测画法: x 轴不变，y 轴缩为 1/2 且旋转 45°

## 易错点

- 斜二测画法还原时忘记 y 轴要乘以 2
- 判断线面关系时漏写"相交"条件
- 把直观图中的角度直接当成实际角度
