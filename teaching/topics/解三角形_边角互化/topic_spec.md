# 专题课教学设计规格

## 基本信息

- 专题名称: 解三角形_边角互化
- 时长: 120 分钟
- 适用对象: 高一/高二同步或一轮复习

## 教学目标

- [ ] 能判断何时用正弦定理、何时用余弦定理
- [ ] 能在一道题中完成"边→角→化简→求解"的完整链条
- [ ] 能处理条件中边角混合出现的综合题

## 专题边界

### 覆盖范围

- 正弦定理的边角互化（边化角、角化边）
- 余弦定理的边角互化
- 边角混合条件的统一方向选择
- 面积公式与边角互化的结合

### 不覆盖（留给相邻专题）

- 解三角形的多解判定（→ 解三角形_多解判定）
- 三角恒等变换证明（→ 三角恒等变换）
- 解三角形应用题建模（→ 解三角形_实际应用）

## 方法链条

```
观察条件结构
  → 判断含边多还是含角多
  → 选择方向：边化角 or 角化边
  → 正弦定理统一 或 余弦定理降次
  → 化简（和差化积 / 辅助角 / 约分）
  → 求解目标量
  → 检验（角度范围、边长正负、三角形存在性）
```

## 例题规划

| 序号 | 角色 | 功能描述 | 建议难度 |
|---:|---|---|---|
| 1 | 引入 | 最简单的单步边角互化，建立方向选择意识 | 基础 |
| 2 | 巩固 | 边角混合条件，需要先统一再化简 | 基础~中档 |
| 3 | 综合 | 多步互化 + 面积/最值，考察完整链条 | 中档 |
| 4 | 提高 | 需要两次选择方向的复杂条件 | 中档~难题 |

## 核心公式

- 正弦定理: $a/\sin A = b/\sin B = c/\sin C = 2R$
- 余弦定理: $c^2 = a^2 + b^2 - 2ab\cos C$
- 面积公式: $S = \frac{1}{2}ab\sin C$
- 和角关系: $A + B + C = \pi$

## 易错点

- 边化角后忘记角的范围约束
- 余弦定理降次后没有继续化简就停住
- 条件中有 $a\cos B + b\cos A$ 时不知道可以合并为 $c$

## 学生常见问题（基于教学经验）

- 不确定该用正弦定理还是余弦定理，犹豫浪费时间
- 边化角后得到 $\sin(A+B)$，不会展开成 $\sin C$
- 最后一步忘记检验三角形是否存在
