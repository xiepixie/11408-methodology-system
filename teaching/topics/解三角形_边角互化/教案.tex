\section{120 分钟课堂流程}

105--120 分钟 & 总结 & 方法链条复盘，布置课后重做。\\

\section{方法链条}

\begin{itemize}[itemsep=0.2em]
  \item 观察条件结构
  \item → 判断含边多还是含角多
  \item → 选择方向：边化角 or 角化边
  \item → 正弦定理统一 或 余弦定理降次
  \item → 化简（和差化积 / 辅助角 / 约分）
  \item → 求解目标量
  \item → 检验（角度范围、边长正负、三角形存在性）
\end{itemize}
