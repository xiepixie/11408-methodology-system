\section{本讲目标}

完成本讲后，你应当能够：
\begin{itemize}
  \item 识别球的截面直角三角形模型；
  \item 区分正方体、长方体、直棱柱、圆柱与正四面体的外接球半径公式；
  \item 判断何时用补形法，何时直接找截面圆心；
  \item 在球与多面体综合题中，把空间半径关系转化为平面勾股关系。
\end{itemize}

\topicformula{
\textbf{统一母模型：}
若球心为 $O$，截面圆圆心为 $O_1$，球半径为 $R$，截面圆半径为 $r$，球心到截面距离为 $d$，则
\[
  R^2=r^2+d^2.
\]
球相关公式尽量统一回到这个直角三角形，而不是孤立背结论。
}
