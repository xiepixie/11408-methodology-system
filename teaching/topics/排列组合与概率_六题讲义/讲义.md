# 全局板块索引

本讲义围绕六道排列组合与概率题，重点训练以下能力：

1. **相同元素放入不同盒子**：把分配问题转化为整数拆分，并处理“数量互不相同”。
2. **平均分配的概率计算**：统一样本空间，利用直接计数或补集判断选项。
3. **人数上下限分配**：先由总人数确定各组容量类型，再分类计数。
4. **成对位置的大小关系**：利用交换对称性快速求概率。
5. **多日排课问题**：先固定高频课程，再按课程重合天数分类。
6. **带有同行、不同组条件的人员分配**：先安排特殊对象，再分配普通对象。

# 第一部分：核心引子与题感诊断

## 1. 本组题用到的核心公式、定理或二级结论

### 1.1 正整数有序解
方程 $x_1+x_2+\cdots+x_m=n,\qquad x_i\geqslant1$ 的正整数有序解个数为 $\binom{n-1}{m-1}$。
它适用于“相同物品放入有标号盒子，且每个盒子非空”的普通情形。
但若附加“各盒数量互不相同”等条件，就不能直接套用隔板法，需要进一步筛选或枚举。

### 1.2 等容量分配
将 $n$ 个互不相同的对象分配到若干个有标号单位，分配方法数为 $\frac{n!}{n_1!n_2!\cdots n_r!}$。

### 1.3 古典概型
当所有基本分配结果等可能时，$P(A)=\frac{\lvert A\rvert}{\lvert\Omega\rvert}$。
分子与分母必须使用同一种计数口径。

### 1.4 补集与容斥原理
若坏事件之间存在交集，则使用 $\lvert A\cup B\rvert = \lvert A\rvert+\lvert B\rvert-\lvert A\cap B\rvert$。

### 1.5 成对交换的对称性
若若干对对象的位置已经固定，而每对内部交换后两种次序等可能，则一对满足指定大小关系的概率为 $\frac12$。

### 1.6 两个三元素日期集合的交集
若两门课程都在五天中出现三天，设对应日期集合为 $S,T$，则 $\lvert S\cap T\rvert \geqslant \lvert S\rvert+\lvert T\rvert-5=1$。因此两门课程的共同上课天数只能是 $1,\ 2,\ 3$。

## 2. 看到这些条件，应立刻想到什么

### 看到“完全相同的球”
一种放法只由各盒中的数量决定，不需要选择具体是哪几个球。若盒子有编号，则数量向量有顺序。

### 看到“数量均不同”
普通隔板法只处理正整数或非负整数条件，不能自动保证变量互不相同。优先把数量从小到大排列，枚举无序数量类型，再分配给有标号盒子。

### 看到“平均分配到甲、乙、丙”
甲、乙、丙有标号。总分配数可写成 $\binom93\binom63$，不需要再除以 $3!$。

### 看到“每组至少一人、至多两人”
先由总人数确定容量类型。例如五人分到三个单位，容量只能是 $(2,2,1)$。

### 看到“对应位置高于”
优先考虑每一列内部交换。如果每列中的两棵树已经确定，则一前一后的两种放法中，恰有一种满足后高前低。

### 看到“某两人同行、某两人不同组”
先安排这些特殊对象，形成一个“基础占位结构”，再把普通对象补入各单位。

## 3. 本类题的常见切入点

### 切入点一：先明确计数对象
必须先判断：对象是否互不相同；单位是否有标号；交换两组后是否得到新方案；每组内部是否区分顺序。

### 切入点二：先确定容量结构
若人数上下限较严格，应先解方程并结合上下界列出所有可能容量。

### 切入点三：先安排限制最强的对象
限制越强的对象越应优先安排。

### 切入点四：寻找自动确定的步骤
若某一步在此前选择完成后只有一种合法结果，就不能额外乘计数因子。

# 第三部分：应试方法联系与深度思考

## 1. 方法的横向联系
### 1.1 数量拆分与隔板法
普通隔板法解决基础条件，附加的互异、奇偶、上下界条件需要另行处理。
### 1.2 容量类型与分组问题
先确定 $(2,2,1)$ 的容量结构，是分配题的常见入口。
### 1.3 补集与容斥
当条件中出现“每个”“至少”“都不缺少”时，应主动检查补集是否更简洁。
### 1.4 局部交换对称
利用三列内部独立交换，避免对复杂排列的分类。
### 1.5 固定高频对象与交集分类
先固定结构最强、出现次数最多的对象，再按交集大小分类。
### 1.6 特殊对象锚定
先安排同行和不同组的特殊对象，再补入普通对象。

## 4. 实战做题启发
### 启发一：先写“容量”，再写组合数
遇到分配题，先写每个单位可能有多少人。后续分类就会非常明确。
### 启发二：每乘一个因子，都要说明它对应哪次选择
无法说明具体选择含义的乘数，往往会造成重复计数。
### 启发三：先处理限制最强的对象
优先处理必须同行、必须分开、不能出现、出现次数最多、可选位置最少的对象。
