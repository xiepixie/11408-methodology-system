# 专题课教学设计规格：解三角形——自由度视角与结构化解题

> 本文件是 AI 生成专题课讲义/学案/教案的约束依据。

## 一、 基本信息

- 专题名称: 解三角形_自由度方法论
- 时长: 3 课次 $\times$ 120 分钟（或 1 个 120 分钟精华专题）
- 适用对象: 高一/高二同步拔高或一轮复习
- 核心理念: 三角形 = 形状的两个自由度 + 大小的一个自由度

---

## 二、 教学目标

- [ ] 能用自由度观点（$2+1$ 模型）识别题目的四种状态：确定型 ($\text{DOF}=0$)、齐次型 ($\text{DOF}=2$)、范围最值型 ($\text{DOF}=1$)、离散分支型 (SSA)。
- [ ] 掌握考场“四问”解题决策 SOP，能自主选择边坐标、角坐标或比例坐标。
- [ ] 熟练运用三大发动机（正弦定理比例翻译、余弦定理二次翻译、面积公式耦合器）。
- [ ] 能结合几何图像（相似族、圆弧滑动轨迹、SSA交点圆弧、倍长中线）进行直观化推导与变型分析。

---

## 三、 专题边界

### 覆盖范围
- 三角形自由度分解与条件控制分析
- 齐次条件的识别与比例/角坐标求解（如 $b+c=2a, 5c\sin B = 6a\sin C$）
- 剩余 1 个自由度的单变量消元参数化与定义域裁切（如固定 $C$ 求 $\sin A + \sin B$ 范围）
- SSA 多解与解的个数几何圆弧判定模型
- 中线、角平分线、向量数量积在三角形中的自由度传递

### 不覆盖（留给相邻专题）
- 三角函数纯图像变换（$\omega, \varphi$ 移动）
- 复杂空间立体几何中的解三角形应用

---

## 四、 考场“四问”决策 SOP

1. 第一问：这道题在求“形状”还是“大小”？
2. 第二问：当前条件是齐次还是非齐次？
3. 第三问：应该在哪种坐标系统（边/角/比例）中计算？
4. 第四问：化简做完后还剩几个自由度？

## 六、 核心公式与工具

- 自由度等式: $A + B + C = \pi$
- 正弦定理 (比例翻译器): $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$
- 余弦定理 (二次翻译器): $a^2 = b^2 + c^2 - 2bc\cos A$
- 面积公式 (形状-尺度耦合器): $S = \frac{1}{2}bc\sin A = \frac{abc}{4R} = rs$
- 平行四边形恒等式 (中线结构): $2(b^2+c^2) = a^2 + 4m_a^2$
