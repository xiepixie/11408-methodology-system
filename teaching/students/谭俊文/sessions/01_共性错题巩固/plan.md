# 课次计划

学生：谭俊文
专题：01_共性错题巩固（包含解三角形与立体几何全部错题）
总时长：120 分钟

## 本次课目标
1. **立体几何小题突破**：彻底解决空间异面直线夹角求法、斜二侧画法还原、多面体外接球半径计算。
2. **立体几何大题规范**：熟练掌握点到平面的向量法距离公式；五面体面面垂直与线面角“作—证—算”的建系法模板。
3. **解三角形综合**：攻克多选两解边界判定；熟练应用正余弦定理进行大题中的边角互化。

## 讲课顺序
1. **课前公式回顾** (5min)
2. **第一板块：立体几何小题 (25min)**
   - Q11(斜二测) -> Q01(异面夹角精讲) -> Q02(异面夹角学案自练) -> Q08(外接球与表面展开)
3. **第二板块：解三角形综合 (33min)**
   - Q05(多选陷阱排雷) -> Q13(解答题边角互化精讲) -> Q14(投影定理自练)
4. **第三板块：立体几何大题 (30min)**
   - Q12(点面距离公式应用) -> Q16(五面体线面角建系法规范)
5. **第四板块：机动时间与错因复盘 (27min)**
   - 学生总结“建系法三步走”和“解三角形多选排雷指南”，处理遗留疑问。
