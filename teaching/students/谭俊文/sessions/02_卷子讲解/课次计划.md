# 课次计划

学生：谭俊文
专题：02_卷子讲解（第 1—16 题）
总时长：120 分钟

## 本次课目标
1. **三角与向量综合排雷**：掌握单位向量夹角、和差化积的应用。在多选题中能避开“投影向量系数”与“等边内角”的陷阱，掌握利用基底分解平面向量并比较共线系数求交点比值的计算方法。
2. **空间几何线面分析**：建立正方体空间直角坐标系，求解平面方程、交线方向向量并计算线线夹角；熟练掌握线面/面面平行与垂直的判定与性质，并能举出经典反例进行排雷。
3. **空间旋转体与球**：牢固掌握正方体外接球直径与棱长的体对角线模型，熟练计算圆锥表面积和圆台体积公式，并掌握轴截面提取高度的计算方法。
4. **填空与解答题专项**：熟练掌握向量起点/终点坐标计算；应用解三角形知识解决测量湖中小岛距离问题；利用截面法求球与正四面体表面交线长度；掌握向量平行、垂直判定、夹角与模长计算；熟练求出正弦型函数解析式、单调区间与区间最值。
5. **综合大题思想拓展**：掌握立体几何中的“中点构造学”和平移线面角；提升解三角形的“面积分割敏锐度”；运用“中线模型”的降维打击——向量法；在求范围问题时熟练进行“边角抉择”。
6. **动点最值与高级角模型**：掌握“二面角三余弦公式”以及通过“体积比转距离比”进行空间动点轨迹分析的能力。

## 公式清单
1. 正切定义域：$\{x \mid x \ne \dfrac{\pi}{2} + k\pi, k \in \mathbb{Z}\}$。
2. 正方体外接球：$2R = \sqrt{3}a$。
3. 三角面积：$S = \dfrac{1}{2}ab\sin C$。
4. 圆锥表面积：$S_{\text{锥}} = \pi r^2 + \pi rl$；球表面积：$S_{\text{球}} = 4\pi R^2$。
5. 向量夹角与模长：$|\vec{a}+\vec{b}|^2 = |\vec{a}|^2 + |\vec{b}|^2 + 2\vec{a}\cdot\vec{b}$。
6. 圆台体积：$V = \dfrac{1}{3}\pi h(R^2+Rr+r^2)$。
7. 空间直线夹角：$\cos\theta = \dfrac{|\vec{u}\cdot\vec{v}|}{|\vec{u}||\vec{v}|}$。
8. 和差化积：$\sin A + \sin B = 2\sin\dfrac{A+B}{2}\cos\dfrac{A-B}{2}$。
9. 投影向量公式：$\operatorname{proj}_{\vec{u}}\vec{v} = \dfrac{\vec{v}\cdot\vec{u}}{|\vec{u}|^2}\vec{u}$。
10. 三点共线定理：若 $E, B, D$ 三点共线，且 $\overrightarrow{AE} = x\overrightarrow{AB} + y\overrightarrow{AD}$，则 $x+y = 1$。
11. 向量坐标公式：$\overrightarrow{AB} = (x_B - x_A, y_B - y_A)$。
12. 正四面体高线：$h = a\sqrt{\dfrac{2}{3}}$，等边三角形内切圆半径 $r_{\text{内}} = \dfrac{\sqrt{3}}{6}a$。
13. 二面角三余弦公式：$\cos\angle CPD = \cos^2\phi + \sin^2\phi\cos\theta$。
