## 本次课目标

1. **掌握齐次化与尺度缩放**：理解当题目目标是边长比值时，整体大小不影响结果，能主动设 $c=1$ 进行齐次化消元。
2. **掌握全角化与全边化流派**：在消元到只剩一个自由变量时，能熟练运用正弦定理（转化为三角函数求值域）或余弦定理（结合基本不等式）进行求解。
3. **理解锐角三角形的三重枷锁**：掌握如何将所有角的锐角条件（$< 90^\circ$）转化为自由变量的边界范围，防止漏解。
4. **建立几何动点直觉**：通过建立平面直角坐标系，将三角形形状范围问题转化为射线上的动点活动区间与圆/直线边界问题。

## 讲课顺序与课堂主线

1. **概念引入（自由度与齐次化）**：通过六个量与三个独立条件的几何全等判定，引入“用条件减少自由度”的本质。
2. **核心母题讲解**：
   - **几何直观法**：设 $c=1$，建系 $A(0,0), B(1,0)$，射线 $y=\frac{4}{3}x$。讲解 $\angle C=90^\circ$ 对应直径半圆边界，$\angle B=90^\circ$ 对应垂直边界线。得出 $AC$ 范围，再除以 $2$。
   - **代数标准法**：全角化为 $\tan C$ 的函数，讲解锐角条件如何卡死 $C$ 的范围（$90^\circ-A < C < 90^\circ$）。
3. **月考 Q16 纠偏**：重点梳理角平分线常用的面积关系 $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle CBD}$，求出倒数关系后使用常数代换法求最小值。
4. **月考 Q18 纠偏**：在黑板上板书单位圆坐标和向量数量积证明差角公式的规范步骤；推导 $\cos A + \cos B + \cos C$ 配方成关于 $\sin\frac{C}{2}$ 的二次函数求最大值。

## 学生本次暴露的问题

1. **锐角边界限制意识不足**：代数法中，容易忘记 $B = 180^\circ - A - C < 90^\circ$ 带来的下界约束，导致遗漏 $\tan C > \frac{3}{4}$ 这一条件。
2. **最值转换链条薄弱**：面对角平分线题目，知道面积公式，但无法自主建立 $\frac1a+\frac1c=\text{常数}$ 的倒数约束，阻碍了基本不等式的应用。
3. **证明过程流于表面**：证明题喜欢写“显然”或者直接写结论，差角公式证明中存在用待证公式反推的循环论证倾向，余弦和最大值只会记“等边时取最大”。
