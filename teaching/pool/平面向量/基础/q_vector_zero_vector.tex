\newcommand{\qVectorZeroVectorStem}{下列式子，化简后结果为零向量的有 \hfill （\quad）}

\newcommand{\qVectorZeroVectorOptions}{%
  \mcoptions[2]{%
    \(\vec{AB} + \vec{BC} + \vec{CD} + \vec{DA}\)
  }{%
    \(\vec{OA} - \vec{OD} + \vec{AD}\)
  }{%
    \(\vec{NQ} + \vec{OP} + \vec{MN} - \vec{MP}\)
  }{%
    \(\vec{AB} - \vec{AD} - \vec{DC}\)
  }%
}

\newcommand{\qVectorZeroVectorAnswer}{A, B}

\newcommand{\qVectorZeroVectorSolution}{%
  对于 A，根据向量的加法首尾相接法则，有 \(\vec{AB} + \vec{BC} + \vec{CD} + \vec{DA} = \vec{AA} = \vec{0}\)，化简结果为零向量，符合题意；\\
  对于 B，因为 \(\vec{OA} - \vec{OD} = \vec{DA}\)，代入原式得 \(\vec{DA} + \vec{AD} = \vec{0}\)，化简结果为零向量，符合题意；\\
  对于 C，重排加数并利用相反向量：\(\vec{NQ} + \vec{OP} + \vec{MN} - \vec{MP} = (\vec{MN} + \vec{NQ}) + (\vec{OP} + \vec{PM}) = \vec{MQ} + \vec{OM} = \vec{OQ} \neq \vec{0}\)，不合题意；\\
  对于 D，因为 \(\vec{AB} - \vec{AD} = \vec{DB}\)，原式为 \(\vec{DB} - \vec{DC} = \vec{CB} \neq \vec{0}\)，不合题意。
  综上，化简后结果为零向量的为 AB。
  故选 AB。%
}
