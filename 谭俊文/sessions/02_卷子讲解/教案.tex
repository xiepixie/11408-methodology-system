\section{备课补充：公式来源与数学直觉}

\teachblock{圆锥与球表面积比例模型}{
  圆锥表面积：\(S_{\text{锥}} = \pi r^2 + \pi rl\)。球的表面积：\(S_{\text{球}} = 4\pi R^2\)。
  当底面直径和母线都等于球直径 \(2R\) 时，圆锥底面半径 \(r=R\)，母线 \(l=2R\)。
  通过参数化 \(R\) 统一表达，可直接代数约分，避免复杂的几何转换。
  \coneSphereModel
}

\teachblock{圆台的轴截面与高度还原}{
  圆台母线与底面所成角为母线与底面半径的夹角。
  在轴截面（等腰梯形 \(ABCD\)）中，做高线 \(BE, CF\)，底边直角三角形的底边为半径之差 \(R-r=1\)。
  高 \(h = (R-r)\tan 45^\circ = 1\)。
  \frustumSectionModel
}

\teacherproblem{1}{正切函数定义域}

{\small \qTJWTanDomainStem}
\qTJWTanDomainOptions

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：A
}

\teachblock{标准解答}{
  正切函数 \(\tan x = \dfrac{\sin x}{\cos x}\) 的定义域要求分母不为零，即：
  \[
    \cos x \ne 0.
  \]
  由于余弦函数为 0 的解为：
  \[
    x = \frac{\pi}{2} + k\pi, \quad k \in \mathbb{Z}.
  \]
  因此，正切函数的定义域为：
  \[
    \left\{x \;\middle|\; x \ne \frac{\pi}{2} + k\pi, \ k \in \mathbb{Z}\right\}.
  \]
  故选 A。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  学生易错选 B。原因在于用 \(2\pi\) 周期进行排除，从而漏掉了 \(\dfrac{3\pi}{2} + 2k\pi\) 等无意义的半轴位置点。
}

\teachblock{课堂处理 / 追问}{
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item \(\tan \dfrac{3\pi}{2}\) 在计算器中为何报错？在单位圆中，这个角对应的终边有横坐标吗？
    \item 正切函数的最小正周期是多少？定义域的排除周期应该与它一致吗？
  \end{itemize}
}
\end{paracol}

\teacherproblem{2}{正方体外接球半径}

{\small \qTJWCubeInscribedSphereStem}
\qTJWCubeInscribedSphereOptions

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：C
}

\teachblock{标准解答}{
  【解法一：几何体对角线法】
  正方体的 8 个顶点都在外接球球面上，因此球心即为正方体的中心。
  正方体的体对角线 \(d\) 穿过球心，且长度等于外接球的直径 \(2R\)。
  棱长为 \(a = 2\)，则体对角线长为：
  \[
    d = \sqrt{a^2 + a^2 + a^2} = \sqrt{3} a = 2\sqrt{3}.
  \]
  所以球的半径为：
  \[
    R = \frac{d}{2} = \sqrt{3}.
  \]
  故选 C。

  【解法二：坐标系建系法】
  以正方体中心为原点建立空间直角坐标系，8个顶点坐标为 \((\pm 1, \pm 1, \pm 1)\)。
  外接球半径 \(R\) 为中心到顶点的距离：
  \[
    R = \sqrt{1^2 + 1^2 + 1^2} = \sqrt{3}.
  \]
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  学生易将球半径误记为体对角线本身，或者错套为内切球半径（\(R = a/2\)）或棱切球半径（\(R = \sqrt{2}a/2\)）。
}

\teachblock{课堂处理 / 追问}{
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 正方体中心到顶点、到棱中点、到面中心的距离，这三者哪一个最大？
    \item 外接球必须穿过所有顶点，所以球的半径应该对应这三个距离中的哪一个？
  \end{itemize}
}
\end{paracol}

\teacherproblem{3}{已知两边一角的三角形面积}

{\small \qTJWTriangleAreaSimpleStem}
\qTJWTriangleAreaSimpleOptions

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：B
}

\teachblock{标准解答}{
  在 \(\triangle ABC\) 中，已知 \(AB=4\)，\(AC=3\)，且夹角 \(\angle BAC=\dfrac{\pi}{6}\)。
  代入三角形面积公式：
  \[
    S = \frac{1}{2} \cdot AB \cdot AC \cdot \sin \angle BAC = \frac{1}{2} \cdot 4 \cdot 3 \cdot \sin\frac{\pi}{6} = 3.
  \]
  故选 B。
}

  【错因分析】
  偶尔因计算 \(\sin\dfrac{\pi}{6} = \dfrac{1}{2}\) 粗心算错，或未确认给出的角是否确实为两边的夹角。
}

  \end{itemize}

\teacherproblem{4}{圆锥与球表面积之比}

{\small \qTJWConeSphereRatioStem}
\qTJWConeSphereRatioOptions

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：C
}

\teachblock{标准解答}{
  设球的半径为 \(R\)，则球的直径为 \(2R\)。
  圆锥的底面直径和母线都等于球的直径 \(2R\)。
  所以圆锥底半径 \(r = R\)，母线长 \(l = 2R\)。
  
  圆锥的表面积为：
  \[
    S_{\text{锥}} = \pi r^2 + \pi rl = \pi R^2 + \pi R \cdot 2R = 3\pi R^2.
  \]
  球的表面积公式为：
  \[
    S_{\text{球}} = 4\pi R^2.
  \]
  因此，圆锥与球的表面积之比为：
  \[
    \frac{S_{\text{锥}}}{S_{\text{球}}} = \frac{3\pi R^2}{4\pi R^2} = \frac{3}{4}.
  \]
  故选 C。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  极易漏算底面积，误认为圆锥表面积仅指侧面积 \(\pi rl = 2\pi R^2\)。从而算出比值为 \(1/2\)，在选项中找不到而慌乱。
}

\teachblock{课堂处理 / 追问}{
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 几何体的“表面积”定义是什么？对于圆锥来说，它包含了几个底面？侧面积和表面积有何区别？
  \end{itemize}
}
\end{paracol}

\teacherproblem{5}{单位向量夹角}

{\small \qTJWVectorUnitAngleStem}
\qTJWVectorUnitAngleOptions

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：D
}

\teachblock{标准解答}{
  【解法一：代数平方】
  设单位向量 \(\vec{e}_1, \vec{e}_2\) 夹角为 \(\theta\)。两边平方：
  \[
    |\vec{e}_1 + \vec{e}_2|^2 = |\vec{e}_1|^2 + |\vec{e}_2|^2 + 2\vec{e}_1 \cdot \vec{e}_2 = 1.
  \]
  \[
    1 + 1 + 2\cos\theta = 1 \implies 2\cos\theta = -1 \implies \cos\theta = -\frac{1}{2}.
  \]
  由于 \(\theta \in [0, \pi]\)，所以 \(\theta = \dfrac{2\pi}{3}\)。
  
  【解法二：几何法】
  两单位向量及合成向量模长都是 1，构成等边三角形。两向量共起点平移后，其夹角与等边三角形内角互补，为 \(\pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}\)。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  高频错题。学生极易误选 B（即 \(\dfrac{\pi}{3}\)），原因在于只看到等边三角形的内角是 \(60^\circ\)，忽视了向量夹角要求“平移共起点”的定义限制。
}

\teachblock{课堂处理 / 追问}{
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 为什么两个长度为 1 的向量加起来之后长度还是 1？如果夹角是 \(60^\circ\)，长度应该变大还是变小？
    \item 作图画出两个向量的夹角，它们的起点是否必须对齐？
  \end{itemize}
}
\end{paracol}

\teacherproblem{6}{圆台体积与轴截面计算}

{\small \qTJWFrustumVolumeStem}
\qTJWFrustumVolumeOptions
\begin{center}
  \qTJWFrustumVolumeFigure[1.1]
\end{center}

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：B
}

\teachblock{标准解答}{
  圆台体积公式：\(V = \dfrac{1}{3}\pi h (R^2 + Rr + r^2)\)，其中 \(R=2, r=1\)。
  做轴截面等腰梯形的高，底边直角三角形中，底边长度为半径之差 \(R-r = 2-1 = 1\)。
  因为倾角为 \(\dfrac{\pi}{4}\)，所以高为：
  \[
    h = 1 \cdot \tan\frac{\pi}{4} = 1.
  \]
  代入公式：
  \[
    V = \frac{1}{3}\pi \cdot 1 \cdot (2^2 + 2\cdot 1 + 1^2) = \frac{7\pi}{3}.
  \]
  故选 B。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  对圆台体积公式的记忆不牢，容易丢掉中间项 \(Rr\)。在割补法求高时，对直角三角形底边为半径差（而不是直径差或底面直径）反应慢。
}

\teachblock{课堂处理 / 追问}{
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 圆台的轴截面是什么形状？高线、母线和半径差构成了一个怎样的三角形？
  \end{itemize}
}

\teacherproblem{7}{正方体线线夹角}

{\small \qTJWCubePlaneIntersectionAngleStem}
\qTJWCubePlaneIntersectionAngleOptions
\begin{center}
  \qTJWCubePlaneIntersectionAngleFigure[1.0]
\end{center}

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：B
}

\teachblock{标准解答}{
  以 \(A\) 为原点，\(AB, AD, AA_1\) 为轴建立坐标系，棱长设为 1。各点坐标为：
  \[
    A(0,0,0),\ B(1,0,0),\ C(1,1,0),\ D(0,1,0),\ A_1(0,0,1),\ D_1(0,1,1).
  \]
  平面 \(BDD_1B_1\) 经过点 \(B(1,0,0), D(0,1,0)\)，方程为 \(x+y=1\)。
  平面 \(\alpha \parallel BDD_1B_1\) 且过直线 \(AA_1\)（即 \(x=0,y=0\)），故方程为：
  \[
    x + y = 0.
  \]
  平面 \(ACD_1\) 的法向量可求得为 \(\vec{n} = (1, -1, 1)\)，方程为：
  \[
    x - y + z = 0.
  \]
  直线 \(l\) 是它们的交线，联立可得其方向向量为：
  \[
    \vec{l} = (1, -1, -2).
  \]
  直线 \(AA_1\) 方向向量为 \(\vec{a} = (0,0,1)\)。
  \[
    \cos\theta = \frac{|\vec{l} \cdot \vec{a}|}{|\vec{l}||\vec{a}|} = \frac{2}{\sqrt{6}} = \sqrt{\frac{2}{3}}.
  \]
  \[
    \sin\theta = \frac{1}{\sqrt{3}} \implies \tan\theta = \frac{\sqrt{2}}{2}.
  \]
  故选 B。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  这道题对于空间想象力的要求极高，因为平面 \(\alpha\) 在正方体外部。学生如果采用传统的几何平移法极难找到交线 \(l\) 并求角，建系法则能避免这种困难。
}

\teachblock{课堂处理 / 追问}{
  【课堂处理】
  带领学生按“建系——求平面方程——联立求交线方向向量——计算夹角正切”的标准化坐标流程走一遍，规范写出每一步的方程。
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 如果不建系，你能看出 \(AC \perp l\) 吗？为什么？（因为 \(AC \perp BDD_1B_1 \implies AC \perp \alpha \implies AC \perp l\)）
  \end{itemize}
}
\end{paracol}

\teacherproblem{8}{解三角形和差化积}

{\small \qTJWTriangleSumToProductStem}
\qTJWTriangleSumToProductOptions

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：A
}

\teachblock{标准解答}{
  由和差化积公式：
  \[
    \sin A + \sin B = 2 \sin\frac{A+B}{2} \cos\frac{A-B}{2}.
  \]
  代入 \(A-B = \dfrac{\pi}{3}\) 得 \(\cos\dfrac{A-B}{2} = \cos\dfrac{\pi}{6} = \dfrac{\sqrt{3}}{2}\)。
  所以：
  \[
    2 \sin\frac{A+B}{2} \cdot \frac{\sqrt{3}}{2} = 1 \implies \sin\frac{A+B}{2} = \frac{1}{\sqrt{3}}.
  \]
  设 \(S = A+B\)。则由倍角公式：
  \[
    \cos(A+B) = 1 - 2\sin^2\frac{A+B}{2} = 1 - 2 \cdot \frac{1}{3} = \frac{1}{3}.
  \]
  根据诱导公式：
  \[
    \cos C = \cos(\pi - (A+B)) = -\cos(A+B) = -\frac{1}{3}.
  \]
  故选 A。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  学生由于长期不写和差化积公式，在看到 \(\sin A+\sin B=1\) 和角差时，想不到利用和差化积化简。另外容易在诱导公式 \(\cos(\pi-S) = -\cos S\) 中漏掉负号。
}
\end{paracol}

\teacherproblem{9}{三角函数图象与性质}

\teacherproblem{11}{平面向量综合大题}

{\small \qTJWVectorTriangleIntersectionStem}
\qTJWVectorTriangleIntersectionOptions
\begin{center}
  \qTJWVectorTriangleIntersectionFigure[1.1]
\end{center}

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：ACD
}

\teachblock{标准解答}{
  设 \(\overrightarrow{AB}=\vec{u}\)，\(\overrightarrow{AC}=\vec{v}\)，且 \(\vec{u}\cdot\vec{v}=0\)，\(|\vec{u}|=|\vec{v}|\)。
  
  对于 A：由分点公式 \(\overrightarrow{BP}=\dfrac{2}{3}\overrightarrow{BC} = \dfrac{2}{3}(\vec{v}-\vec{u})\)，
  \(\overrightarrow{AP} = \vec{u} + \overrightarrow{BP} = \dfrac{1}{3}\vec{u}+\dfrac{2}{3}\vec{v}\)，正确。
  
  对于 B：投影向量公式为 \(\dfrac{\overrightarrow{AP}\cdot\vec{u}}{|\vec{u}|^2}\vec{u} = \dfrac{\frac{1}{3}|\vec{u}|^2}{|\vec{u}|^2}\vec{u} = \frac{1}{3}\vec{u}\)，错误。
  
  对于 C：\(D\) 为中点 \(\implies \overrightarrow{BD} = \dfrac{1}{2}\vec{v}-\vec{u}\)。
  \(\overrightarrow{AP}\cdot\overrightarrow{BD} = \left(\frac{1}{3}\vec{u}+\frac{2}{3}\vec{v}\right)\cdot\left(\frac{1}{2}\vec{v}-\vec{u}\right) = -\frac{1}{3}|\vec{u}|^2 + \frac{1}{3}|\vec{v}|^2 = 0\)，正确。
  
  对于 D：设 \(\overrightarrow{AE} = \lambda \overrightarrow{AP} = \dfrac{\lambda}{3}\vec{u} + \dfrac{2\lambda}{3}\vec{v}\)。
  又因 \(E \in BD\)，设 \(\overrightarrow{AE} = \overrightarrow{AB} + \mu \overrightarrow{BD} = (1-\mu)\vec{u} + \dfrac{\mu}{2}\vec{v}\)。
  联立：
  \[
    \begin{cases}
      \dfrac{\lambda}{3} = 1 - \mu \\
      \dfrac{2\lambda}{3} = \dfrac{\mu}{2}
    \end{cases}
    \implies \mu = \frac{4\lambda}{3} \implies \lambda = \frac{3}{5}.
  \]
  \(\overrightarrow{AE} = \dfrac{3}{5}\overrightarrow{AP}\)，正确。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  本题考查平面向量的四大核心内容。
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 学生对投影向量的公式容易记错（混淆了投影长度标量与投影向量）；
    \item 对 C 项中垂直判定，反应慢，不会利用基底代数点积为 0 计算；
    \item 对 D 项中的比例求解，容易卡住，不知道如何设参数列出方程组。
  \end{itemize}
}

\teachblock{课堂处理 / 追问}{
  【课堂处理】
  重点板书 D 项的系数比较法和共线和为 1 法。
  
  二元一次方程组的消元计算要让学生亲自在黑板上算出来。
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 投影向量究竟是一个数还是一个向量？
    \item 在 D 项中，为什么我们可以直接令基底 \(\vec{u}, \vec{v}\) 前面的系数对应相等？（因为基底是不共线的，平面向量表示法唯一）
  \end{itemize}
}
\end{paracol}

\teacherproblem{13}{解三角形实际测量问题}

{\small \qTJWTriangleLakeMeasurementStem}
\begin{center}
  \qTJWTriangleLakeMeasurementFigure[1.0]
\end{center}

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：\(\sqrt{6}\)
}

\teachblock{标准解答}{
  【解法一：几何解法】
  在 \(\triangle ABC\) 中，\(\angle CAB = 45^\circ\)，\(\angle CBA = \angle DBA + \angle DBC = 90^\circ\)，
  已知 \(AB = 2\)，得 \(AC = 2\sqrt{2}\)。
  
  在 \(\triangle ABD\) 中，\(\angle DAB = 105^\circ\)，\(\angle DBA = 30^\circ \implies \angle ADB = 45^\circ\)。
  由正弦定理：
  \[
    \frac{AD}{\sin 30^\circ} = \frac{2}{\sin 45^\circ} \implies AD = \sqrt{2}.
  \]
  在 \(\triangle ACD\) 中，由余弦定理：
  \[
    CD^2 = AD^2 + AC^2 - 2 AD \cdot AC \cos 60^\circ = 2 + 8 - 2\sqrt{2}\cdot 2\sqrt{2}\cdot\frac{1}{2} = 6.
  \]
  所以 \(CD = \sqrt{6}\)。
  
  【解法二：坐标系解法】
  建系：\(A(0,0)\)，\(B(2,0)\)。
  直线 \(AC\) 方程：\(y = x\)；直线 \(BC\) 方程：\(x = 2 \implies C(2,2)\)。
  直线 \(BD\) 倾角为 \(150^\circ\)，过 \((2,0)\)，方程：\(y = -\dfrac{\sqrt{3}}{3}(x-2)\)。
  直线 \(AD\) 倾角为 \(105^\circ\)，方程：\(y = -(2+\sqrt{3})x\)。
  联立求得 \(D\left(\dfrac{1-\sqrt{3}}{2}, \dfrac{1+\sqrt{3}}{2}\right)\)。
  由两点距离公式，\(CD^2 = 6 \implies CD = \sqrt{6}\)。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  学生容易卡在图形中多个三角形的边角转化上，例如不知道先在哪个三角形中求哪条边。
  对 \(\angle CBA = 90^\circ\) 这一隐含条件反应慢。
}

\teachblock{课堂处理 / 追问}{
  【课堂处理】
  引导学生使用“几何解法”和“坐标系解法”双重验算。特别在“几何解法”中，写出明确的求解链条：
  \[
    \triangle ABC \xrightarrow{\text{求 } AC} AC \quad \text{和} \quad \triangle ABD \xrightarrow{\text{正弦定理求 } AD} AD \quad \xrightarrow{\triangle ACD \text{ 余弦定理}} CD.
  \]
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 为什么 \(\angle CBA = 90^\circ\)？它是怎么由已知角拼出来的？
    \item 坐标法在这里的优势是什么？（不需要找复杂的三角形转换，直接解析化）
  \end{itemize}
}
\end{paracol}

\teacherproblem{14}{球与多面体表面截线长度}

{\small \qTJWSolidSphereTetrahedronIntersectionStem}
\begin{center}
  \qTJWSolidSphereTetrahedronIntersectionFigure[0.9]
\end{center}

\begin{paracol}{2}
\teachblock{标准结论}{
  答案：\(5\sqrt{3}\pi\)
}

\teachblock{标准解答}{
  【解法：截面圆分析法】
  球心为 \(O\)，半径为 \(R = 3\sqrt{3}\)，正四面体棱长为 \(6\)。
  
  1. 与侧面相交：
  在侧面 \(\triangle OAB\) 内，交线是圆心在 \(O\)、半径为 \(3\sqrt{3}\) 的圆弧。
  由于侧面是等边三角形，顶角为 \(\angle AOB = 60^\circ = \dfrac{\pi}{3}\)。
  且棱长 \(6 > 3\sqrt{3}\)，所以圆弧在面内。
  一段弧长为 \(l_{\text{弧}} = R \theta = 3\sqrt{3} \cdot \dfrac{\pi}{3} = \sqrt{3}\pi\)。
  三个侧面交线总长为 \(L_{\text{侧}} = 3\sqrt{3}\pi\)。
  
  2. 与底面相交：
  正四面体的高为 \(h = 6\sqrt{\dfrac{2}{3}} = 2\sqrt{6}\)。
  球心 \(O\) 到底面 \(ABC\) 所在平面的距离为 \(h = 2\sqrt{6}\)。
  球面与底面所在平面的交线圆半径为 \(r = \sqrt{R^2 - h^2} = \sqrt{27 - 24} = \sqrt{3}\)。
  而边长为 6 的等边三角形的内切圆半径为 \(r_{\text{内}} = \dfrac{\sqrt{3}}{6} \cdot 6 = \sqrt{3}\)。
  由于 \(r = r_{\text{内}}\)，且投影点为中心，底面交线恰好为等边三角形 \(ABC\) 的内切圆。
  底面交线长度为内切圆周长：\(L_{\text{底}} = 2\pi r = 2\sqrt{3}\pi\)。
  
  总长度为 \(L_{\text{侧}} + L_{\text{底}} = 5\sqrt{3}\pi\)。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  本题为难题。学生极易忽略底面交线的存在，或错把底面截圆当成外接圆。
  对正四面体的高线计算公式（\(h = \sqrt{6}a/3\)）和底面内切圆半径公式不熟练，导致无法求出底面截圆半径。
}

\teachblock{课堂处理 / 追问}{
  【课堂处理】
  使用投影图展示球切到底面的瞬间。
  重点推导底面内切圆半径 \(r_{\text{内}} = \sqrt{3}\) 与截面圆半径 \(r = \sqrt{3}\) 完全相等这一巧合，帮助学生理解“刚好相切且内切”的物理直观。
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 为什么底面的截线是一个完整的圆，而侧面上只有一段圆弧？
    \item 如果球半径变大为 \(4\)，底面的截线还会是内切圆吗？它与等边三角形的边会有什么位置关系？
  \end{itemize}
}
\end{paracol}

\teacherproblem{15}{平面向量平行与垂直综合问题}

{\small \qTJWVectorParallelPerpendicularNormStem}

\begin{paracol}{2}
\teachblock{标准结论}{
  （1）\(m = 2\)；（2）证明见左栏；（3）\(|\vec{c}| = \sqrt{10}\)
}

\teachblock{标准解答}{
  （1）由 \(\vec{a} \parallel \vec{b}\)，得 \(2(4-2m) - 1(m-2) = 0 \implies m = 2\)。
  
  （2）因为 \(\vec{c} = \vec{a} + \vec{b} \implies \vec{a} - \vec{c} = -\vec{b}\)。
  所以 \(\lambda(\vec{a} - \vec{c}) = -\lambda \vec{b}\)。
  计算点积：
  \[
    \vec{a} \cdot \vec{b} = 2(m-2) + (4-2m) = 0.
  \]
  所以 \(\vec{a} \perp \vec{b}\)。
  因为 \(\lambda \ne 0\)，所以 \(\vec{a} \perp \lambda(\vec{a}-\vec{c})\) 恒成立。
  
  （3）因为 \(\vec{a} \perp \vec{b}\)，所以直角三角形中 \(\vec{c}\) 为斜边。
  由夹角 \(\theta = \dfrac{\pi}{4}\)，等腰直角三角形有：
  \[
    |\vec{a}| = |\vec{c}| \cos\frac{\pi}{4} \implies |\vec{c}| = \sqrt{2}|\vec{a}|.
  \]
  因为 \(\vec{a} = (2,1) \implies |\vec{a}| = \sqrt{5}\)。
  所以 \(|\vec{c}| = \sqrt{2} \cdot \sqrt{5} = \sqrt{10}\)。
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  学生往往难以发现第（2）问中 \(\vec{a} \cdot \vec{b} = 0\) 这一隐藏的不变性条件，从而在求点积时因含有 \(m\) 而感到困惑。
  在第（3）问中，如果不采用几何直角三角形投影法，用坐标代数化简会产生非常复杂的代数方程，容易算错。
}

\teachblock{课堂处理 / 追问}{
  【课堂处理】
  展示几何多视角分析。在黑板上画出以 \(\vec{a}, \vec{b}\) 为直角边，\(\vec{c}\) 为斜边的直角三角形，展示“夹角为 \(\pi/4\)”即对应等腰直角三角形这一极其简便的几何法。
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 观察 \(\vec{a} = (2,1)\) 和 \(\vec{b} = (m-2, 4-2m) = (m-2)(1, -2)\)，你发现了什么？它们的斜率有什么关系？
    \item 在第（3）问中，如果不用等腰直角三角形性质，用纯代数代入 \(5 = \sqrt{5}|\vec{c}|\cos\dfrac{\pi}{4}\)，计算过程是怎样的？
  \end{itemize}
}
\end{paracol}

\teacherproblem{16}{三角函数解析式与单调最值综合大题}

{\small \qTJWTrigGraphPropertiesStem}

\begin{paracol}{2}
\teachblock{标准结论}{
  （1）\(f(x) = 2\sin\left(2x - \dfrac{\pi}{3}\right)\)；\\
  （2）递增区间为 \(\left[-\dfrac{\pi}{12} + k\pi, \dfrac{5\pi}{12} + k\pi\right]\) (\(k \in \mathbb{Z}\))，在 \([0, \pi/2]\) 上最大值为 \(2\)，最小值为 \(-\sqrt{3}\)

\teachblock{标准解答}{
  （1）由最大值为 2，得 \(A = 2\)。
  两相邻零点为 \(\dfrac{\pi}{6}\), \(\dfrac{2\pi}{3}\)，半周期 \(\dfrac{T}{2} = \dfrac{\pi}{2} \implies T = \pi\)。
  \(\omega = \dfrac{2\pi}{T} = 2\)。
  由上升沿穿过零点，\(2 \cdot \dfrac{\pi}{6} + \varphi = 0 \implies \varphi = -\dfrac{\pi}{3}\)。
  so \(f(x) = 2\sin\left(2x - \dfrac{\pi}{3}\right)\)。
  
  （2）递增区间：
  \(-\dfrac{\pi}{2} + 2k\pi \le 2x - \dfrac{\pi}{3} \le \dfrac{\pi}{2} + 2k\pi\)

  最值：因为 \(x \in \left[0, \dfrac{\pi}{2}\right]\)，所以 \(2x - \dfrac{\pi}{3} \in \left[-\dfrac{\pi}{3}, \dfrac{2\pi}{3}\right]\)。
  当 \(2x - \dfrac{\pi}{3} = \dfrac{\pi}{2} \implies x = \dfrac{5\pi}{12}\) 时，\(f(x)_{\max} = 2\)。
  当 \(2x - \dfrac{\pi}{3} = -\dfrac{\pi}{3} \implies x = 0\) 时，\(f(x)_{\min} = 2\sin\left(-\dfrac{\pi}{3}\right) = -\sqrt{3}\)。
}

  求最值时，学生容易粗心地直接代入区间端点 \(x=0\) 和 \(x=\pi/2\) 作为最值点，忽视了正弦函数在区间内部能取到最大值点 \(\pi/2\) 的情况。
}

\teachblock{课堂处理 / 追问}{
  【课堂处理】
  画出辅助的 \(t = 2x - \dfrac{\pi}{3}\) 的正弦曲线段图。
  强调“换元法”在处理复合三角函数最值问题中的绝对重要性，规范大题的书写格式。
  【追问】
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item 为什么不能直接认为区间端点 \(x = \dfrac{\pi}{2}\) 对应最小值？
    \item 如果题目中的区间变为 \(\left[\dfrac{\pi}{3}, \dfrac{2\pi}{3}\right]\)，最大值和最小值会发生什么变化？
  \end{itemize}
}

  【追问】

    \item 采用建系法时，这道题的基底应该如何选取最方便？
  \end{itemize}
}

\teachblock{标准解答}{
  \qTJWTriangleSineAreaMedianSolution
}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  1. 对角关系和边关系转化不熟练，或者计算出错。
  2. 遇到“大角被线段分割”时，习惯用角差公式和正弦定理联立硬算，导致计算极其复杂。
  3. 处理中线问题时缺乏将长度平方转化为向量平方的想法，且在最后一步求范围时，不会运用基本不等式统一成边的范围，而是执着于化为角的三角函数，卡在变形上。
}

\teachblock{课堂处理 / 追问}{
  【思想拓展：解三角形的“面积分割敏锐度”】
  遇到“大角被线段分割成两个已知小角”时，第一反应必须是等面积法！\(S_{\text{总}} = S_1 + S_2\) 这种代数方程的建立，远比纯粹的三角函数变形要高级、直接得多。
  
  【思想拓展：“中线模型”的降维打击——向量法】
  遇到中线条件，要总结“中线三板斧”。强烈推崇\textbf{向量平方法}：\(\overrightarrow{AD} = \dfrac{1}{2}(\overrightarrow{AB} + \overrightarrow{AC})\)，直接两边平方，瞬间将长度关系与夹角余弦融合，是处理中线最不容易出错的“降维”手段。
  
  【思想拓展：求范围问题时的“边角抉择”】
  在解三角形求取值范围的压轴部分，面临一条十字路口：统一成“角”还是“边”？出现了平方和与乘积关系时，利用基本不等式 \(b^2+c^2 \ge 2bc\) 极为高效。引导学生在考场上要“双腿走路”，这条路卡住了，迅速切换视角。
}
\end{paracol}

\switchcolumn
\teachblock{学生问题}{
  【错因分析】
  1. 第（i）问二面角求法，许多学生只知道建系，但本题不便建系时，无法利用对称性找到二面角的平面角，或者不懂利用“三余弦公式”快速转化。
  2. 第（ii）问体积相等条件转化，学生缺乏“体积比转化为高之比（距离比）”进而“确定动点轨迹”的代数与几何联动思想，导致对动点 \(Q\) 的位置束手无策。
}

\teachblock{课堂处理 / 追问}{
  【思想拓展：二面角求解的模型与三余弦】
  第一遍按标准答案讲“利用对称性作二面角的平面角”；第二遍拓展尖子生的高阶模型“二面角三余弦公式”：\(\cos\angle CPD = \cos^2\phi + \sin^2\phi\cos\theta\)，这是由向量投影思想衍生出的“降维”秒杀公式。
  
  【思想拓展：体积比转距离比】
  同底的四面体体积比等于高之比：\(V_{P-ADQ} = 2V_{B-ADQ} \implies\) 点 \(P\) 到底面 \(ADQ\) 的距离是 \(B\) 的 2 倍，从而得到截点在棱上的分点比。这是处理体积等式最直接的几何转化工具。
  
  【思想拓展：空间最值转平面最值】
  本题将 \(Q\) 限制在线段 \(MN\) 上后，\(|PQ|\) 的最小值即为三角形 \(PMN\) 中 \(P\) 到对边的距离，利用等面积法一步解出。
}
