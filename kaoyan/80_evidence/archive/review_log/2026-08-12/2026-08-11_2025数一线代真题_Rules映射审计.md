# 2025 数一线性代数真题 × Rules 映射审计

> 日期：2026-08-11
>
> 来源性质：公开网络整理的 2025 全国硕士研究生招生考试数学（一）真题与解析；本文件只保留题型结构和 Rule 映射，不复制整题正文。
>
> 目的：检查当前线性代数 Rules 是否覆盖真实考试表面，并寻找 Control 缺口。**这仍不是使用者本人未提示做题的表现证据，因此不把任何 Rule 自动晋升为“已采用”。**

## 1. 选择题：二次型只问正惯性指数

真题结构：给一个三元二次型，只问正惯性指数，不要求正交变换或特征向量。

### 当前 Rule

R-LA18：二次型先按目标选“谱”还是“合同”。

### 最短路径

题目只要惯性，不需要主轴方向。直接配方即可把二次型压成“一正、一负、一零”的规范结构，从而读取正惯性指数；完整求特征多项式属于可行但偏重的路径。

### 结论

**支持 R-LA18 的任务分流。** 这道真题说明“只问惯性 → 不自动求谱”不是风格偏好，而是能真实减少计算的考场动作。

## 2. 选择题：线性方程组解集的几何形状

真题结构：给四个向量之间的线性相关 / 无关关系，再研究一个三未知量非齐次线性方程组的解集究竟是直线还是平面、是否经过原点。

### 当前 Topic 能生成什么

由 Topic04：

1. 先判断右端向量是否属于 coefficient matrix 的 image；
2. 有解后，用
   \[
   \dim\ker A=n-r(A)
   \]
   决定仿射解集的维数；
3. 非齐次解集经过原点当且仅当 $b=0$。

### Control 缺口

当前 Rules 没有一条把“直线 / 平面 / 是否过原点”直接翻译成上述三步。

### 决定

新增候选 Rule：

\[
\boxed{
\text{可达性}
\rightarrow
n-r(A)
\rightarrow
\text{是否经过原点}
}
\]

这条属于 Topic04 的调用协议，不重新拥有 rank-nullity 或仿射空间机制。

## 3. 选择题：三矩阵 rank 等式与不等式链

真题结构：已知 $r(A),r(B),r(C),r(ABC)$ 满足一个恰好达到 Sylvester/Frobenius 下界总量的等式，判断哪些中间 rank 等式必然成立。

### 当前 Rule

R-LA05：乘积 rank 先看中间空间；若只给数值 rank，再退回 Sylvester/Frobenius 上下界。

### 真题暴露出的更强动作

这里没有具体子空间，最短入口不是构造 $\operatorname{Im}B\cap\ker A$，而是直接串不等式：

\[
r(ABC)\ge r(AB)+r(C)-n,
\]
\[
r(AB)\ge r(A)+r(B)-n.
\]

如果题设给出的总等式正好让整条链的首尾相等，那么每个中间“$\ge$”都必须取等。

### 决定

**修订 R-LA05**：对纯 rank 数值关系，明确加入“先串上下界；首尾相等时强制中间逐层取等”的动作。

## 4. 填空题：$A^2x=0$ 与 $Ax=0$ 不同解

真题结构：参数矩阵 $A$ 满足 $N(A^2)\ne N(A)$，目标只问两个参数的某个线性组合。

### 当前 Rule

R-LA07：齐次同解 / 包含先翻译 kernel，再选计算表示。

### Rule 映射

永远有
\[
N(A)\subseteq N(A^2).
\]
题设“不同解”因此意味着严格包含。至少可以立即推出 $A$ 不可逆；否则 $N(A)=N(A^2)=\{0\}$。

这道题的考试决策还有一个额外信息：题目只问参数组合，因此一个**必要条件**如果已经唯一确定目标值，就没有义务继续求完整参数集合。

### 决定

- R-LA07 的“先翻译 kernel 关系”得到真题支持；
- “目标已唯一确定就停止”更像 Exam Control 的通用规则，不在本轮新建线代专属 Rule。

## 5. 解答题：重特征值 + 抽象向量关系

真题结构：三阶参数矩阵先给一个重特征值；第二问给 $A\alpha$ 与 $A^2\alpha$ 的关系，要求求非零向量。

### 当前 Rule 映射

第一层：重特征值参数题可调用 R-LA10，利用 characteristic polynomial 的重根条件。

第二层：参数确定后，$A-I$ 呈现明显 rank-one 结构。令
\[
B=A-I.
\]
其非零行彼此成比例，可写成外积；又有
\[
\operatorname{tr}B=0.
\]
R-LA06 立即生成
\[
B^2=0.
\]
因此原本看似需要继续展开 $A^2$ 的关系，被压缩成 $B$ 上的一阶关系。

### 结论

**强支持 R-LA06。** 真实真题中的 rank-one 并不一定以“秩一矩阵”四个字出现，而可能藏在 $A-\lambda I$、全相同行或外积结构里。Rule 的触发信号应该继续保持“看结构”，不能只等待题目明说 rank one。

## 6. 这套真题对当前 21 条 Rule 的信息量

这组线代题至少真实触发了：

- R-LA05：乘积 rank / 不等式链；
- R-LA06：隐藏 rank-one；
- R-LA07：齐次 kernel 比较；
- R-LA10：重特征值；
- R-LA18：二次型方法选择。

同时暴露一个新 Control 缺口：

- **线性方程组几何形状：可达性 → 自由度 → 是否过原点。**

这说明当前 Rules 已覆盖不少真实表面，但 Topic04 的“仿射解集几何”还缺一个明确考场入口。

## 7. 本轮动作

1. 修订 R-LA05 的纯数值 rank 等式处理；
2. 新增 R-LA22《方程组几何形状先读“可达 + 自由度 + 基点”》；
3. 其余相关 Rule 继续保持“待验证”；
4. 下一轮应再抽 2024 / 2023 真题，重点寻找 determinant、实对称正交对角化、同解与二次型配方的不同表面，避免只在 2025 一套卷上过拟合。
