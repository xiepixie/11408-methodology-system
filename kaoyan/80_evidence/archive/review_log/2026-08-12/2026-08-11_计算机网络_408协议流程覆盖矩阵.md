## 1. 专题手册的协议流程最低契约

任何 408 协议进入 Topic Canonical 正文时，至少回答：

    Scope / participants
    -> initial local state
    -> trigger (message or timer)
    -> packet/message fields
    -> receiver validation
    -> local state transition
    -> response/next message
    -> success stop / timeout / failure branch
    -> exam calculation or table state

只写协议目的、概念边界或一条抽象箭头，不算完成 Protocol Flow。

## 4. 人工与真题检查点

1. 协议流程是否能逐报文回答“谁发、发什么、谁更新什么状态”；
2. 经典 408 模型与版本/实现特例是否分层；
3. 是否包含 timeout、丢包、重复、失序、缓存命中等异常分支；
4. 是否能直接支持报文序号、字段、时延、表项和状态机题；
5. Integration 是否只调用流程，没有重新拥有它们。
