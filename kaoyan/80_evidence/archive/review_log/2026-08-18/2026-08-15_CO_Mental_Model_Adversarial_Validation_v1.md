# 2026-08-15 计组微架构心智模型对抗验证（v1）

## 验证对象

本轮验证的不是某一册的记忆量，而是计组统一坐标能否处理未见过的组合题：

```text
ISA State -> Data Location -> Datapath / Control -> Timing -> Commit -> Cost
```

408 适配器进一步把每道题读成：

```text
Object -> State -> Event -> Rule -> New State -> Cost
```

判定标准：若题面没有给出架构/时序假设，模型必须保留参数或明确停止；若信息足够，模型应能指出检测者、处理者、状态变化、提交边界和成本来源，而不是只报一个结论。

## Case A：有限位宽运算与状态提交

### 题面

8 位寄存器执行 `0x80 + 0x80`。分别按 unsigned 与 two's complement 解释，要求给出结果、carry、signed overflow，并说明 ALU 后哪些状态可以提交。

### 模型重建

| 层 | 推导 |
|---|---|
| ISA State | 源状态是两个 8-bit 位串；题面同时要求两种解释，不能先把 `0x80` 固定翻译成一个十进制数 |
| Data Location | 两个操作数在寄存器/ALU 输入；结果寄存器和 flags 是不同的写回对象 |
| Datapath / Control | 8-bit 加法器保留低 8 位；额外产生最高位进位；控制器分别生成 C、V、Z、N |
| Timing | 组合加法完成后，在写使能时钟边界锁存结果与允许更新的 flags |
| Commit | 结果位串为 `0x00`；unsigned 解释为 256 溢出后的低位，C=1；signed 解释为 $-128+(-128)$，V=1，N=0，Z=1 |
| Cost | 若保留 8 位结果，低位写回成本不变；若要无溢出精确乘加等语义，必须扩大中间宽度或报告异常 |

### Verdict

模型能把“位串、解释、标志、写回”分开，并发现 `C=1` 不等于 `V=1`。这是对 CO-01 → CO-03 接口的有效通过。

## Case B：陌生 ISA 指令反推单总线微操作

### 题面

定义新指令 `LOADINC R1,[R2]`：先把内存 $M[R2]$ 读入 `R1`，再令 `R2\leftarrow R2+4`。教学机只有单总线、一个 ALU、Y/Z 中间寄存器、单端口寄存器堆和“内存数据返回后才可用”的 `MFC` 信号。要求指出至少需要哪些阶段。

### 模型重建

1. Read Set：`R2`、内存 `M[R2]`；Derived Values：地址、读回数据、`R2+4`。
2. 第一条依赖链是 `R2 -> MAR/地址接口 -> MemRead -> MFC -> MDR`；第二条是 `R2 -> Y`、常数 4 到 ALU、`Z -> R2`。
3. 单总线不能同拍让 `R2` 同时驱动地址接口和 ALU 两个独立输入，也不能让同一个写端口在没有题设多写口的情况下无条件提交两个目的地。
4. 合法排程至少包括：取 `R2` 形成地址并发起读；等待 `MFC` 并锁存 `MDR`；`MDR -> R1` 写回；另一个阶段完成 `R2+4 -> R2`。若教学机允许在等待期间保存 Y 并运算，可合并部分阶段，但不能省掉依赖和两个写回边界。

### Verdict

模型没有假设“新指令一定一个周期完成”，而是从 Read/Derived/Write Set 和资源冲突推出拆拍。这是对 CO-02 → CO-03 的有效通过；也验证了固定节拍不是稳定知识。

## Case C：TLB、页表与 Cache 的反事实组合

### 题面

系统 VA/PA 分别为 32/24 位，页大小 4 KiB；一次访问出现 TLB miss，page walk 读到 PTE 的 valid=0，但题干又声称“对应物理地址在 Cache 中命中”。判断是否可能，并说明检测者和重试点。

### 模型重建

1. VA 拆为 VPN/12-bit offset；TLB miss 只说明翻译副本缺失。
2. Page walk 发现 valid=0，MMU 产生同步 Page Fault；此时尚未得到合法 PA，不能进入以 PA 为标签的普通 Cache 命中判定。
3. 若 Cache 只保存主存数据，页不在主存时“Cache hit”与有效映射不相容；只有题面明确给出陈旧/别名/非标准缓存语义时才可另建模型。
4. 处理者是 OS 缺页路径，返回点是触发 fault 的原指令；修复映射并完成必要 TLB 失效后重试。Cache miss/hit 属于后续 Cache 控制器状态，不承担缺页修复。

### Verdict

模型用依赖顺序排除了“TLB miss + invalid PTE + PA Cache hit”的默认组合，并保留了陈旧翻译这一显式前提的例外。这是对 CO-06 ↔ CO-07 ↔ OS 边界的有效通过。

## Case D：流水线数据冒险、分支清空与精确提交

### 题面

五级流水执行：`LW R1,0(R2)`、`ADD R3,R1,R4`、随后一条条件分支。数据 Cache 命中，只有 EX/MEM 与 MEM/WB forwarding，分支在 EX 判定。要求判断停顿、转发和错误预测时的状态边界。

### 模型重建

1. `LW` 的 Produced/Ready 在 MEM 末端；紧随其后的 `ADD` 在 EX 入口 Need `R1`，因此普通 forwarding 不能消除 load-use 冲突，至少插入一个 stall/bubble。
2. `ADD` 的结果可在适当流水寄存器通过 forwarding 供后继使用，但 forwarding 不改变 `R3` 的 Commit 时刻。
3. 分支在 EX 得到方向后，若预测错误，清空尚未提交的年轻指令；已提交的老指令效果保留，错误路径的架构写回不得可见。
4. CPI/总时间应把填充、排空、stall 和 flush 惩罚分别计数，不能只用“级数=5”直接给出加速比。

### Verdict

模型把“值何时产生/可达/提交”分开，并能把 forwarding、stall、flush 放进同一时间表。这是对 CO-04 的有效通过。

## Case E：DMA、总线仲裁与有效带宽

### 题面

设备每秒产生 $R$ 字节，DMAC 每次传输 64 B；CPU 也会请求主存。问 DMA 请求和设备中断分别争什么，DMA 周期挪用是否等于 CPU 被中断，以及为何峰值带宽不等于一次块的有效速率。

### 模型重建

1. DREQ 是设备向 DMAC 提出的搬运请求；DMAC 作为 initiator 参与总线仲裁，争的是总线控制权，不是 CPU 的执行权。
2. 块完成/错误后产生 IRQ，CPU 在 ISA 规定的精确边界进入 ISR；IRQ 不是每个 beat 的数据通路。
3. 若一次块有 $D=64$ B，DMA 介入频率约为 $R/D$；CPU 占比还需乘预处理、后处理和中断成本，不能只说“DMA 恒为 O(1)”。
4. 峰值带宽只由数据 beat 宽度、工作传输频率和每周期 beat 数决定；一次块的有效速率还要加入仲裁、地址、等待、响应、方向切换和设备准备时间。

### Verdict

模型区分 request、grant、transaction、completion 和 IRQ，并把“让出总线”与“让出 CPU 控制流”分开。这是对 CO-08 的有效通过。

## Case F：低位交叉存储的延迟与稳态吞吐

### 题面

有 $m=4$ 个存储体，单体存储周期 $T=200\,\mathrm{ns}$，总线传送一个字的时间 $\tau=50\,\mathrm{ns}$，每字 4 B，按低位交叉编址连续读取 4 个字。要求判断单体是否变快、总时间和平均带宽，以及何时可以使用“最大带宽”口径。

### 模型重建

1. 地址低 $\log_2 4=2$ 位选择体号；连续地址轮转四体。$T=4\tau$，满足无冲突临界条件。
2. 各体的器件延迟仍是 $200\,\mathrm{ns}$，只是启动时刻错开；第一个字在 $T$ 后到达，随后每 $\tau$ 输出一个。
3. 四字总时间为 $T+(4-1)\tau=350\,\mathrm{ns}$，平均带宽为 $16\,\mathrm{B}/350\,\mathrm{ns}\approx45.7\,\mathrm{MB/s}$。
4. 只有在流水稳态、忽略首字启动成本时，才能用 $B_{max}=mW/T=W/\tau=80\,\mathrm{MB/s}$；不能把它当成这四个字的平均带宽。

### Verdict

模型把“器件 latency、总线启动间隔、稳态 throughput”拆成三个量，能避免把多体交叉误写成单次访问加速。这是对 CO-05 的有效通过。

## 失败模式与模型修正

| 反例 | 若模型失效会怎样 | 本轮修正/稳定边界 |
|---|---|---|
| 未说明 ISA 的 PC 基准、对齐或 MMIO 属性 | 误把某一架构习惯当普适定律 | 保留参数，明确需要题面/ISA 条件 |
| 把 TLB miss、Page Fault、Cache miss 都称“缺失” | 错写检测者、处理者和重试点 | 先标缺失对象，再沿依赖链推进 |
| 只看 CPI 或总线峰值 | 漏掉填充、等待、仲裁和提交边界 | Cost 必须注明时间口径与重叠假设 |
| 把模拟器/教材图当唯一硬件实现 | 用一张图否定同语义的另一实现 | 用状态差、资源和不变量重建，而不是复制部件名 |

## 验证结论

六类陌生题均能由同一骨架生成可检查路径；模型最有价值的地方不是减少知识点，而是把“对象位置、状态变化、触发事件、时序证据、提交边界、成本”串成一条可追踪链。当前仍保留两个诚实边界：

1. 未给出 ISA/平台时，PC 基准、MMIO 排序、TLB 失效和异常入口不能强推；
2. 多核一致性、具体微架构实现和 OS 策略若不在 408 题面范围内，只能作为明确标注的 Extension，不能伪装成统一定理。

因此，本轮判断为：**心智模型在跨 Topic 推理和反事实排错上有效；下一轮应以真实历年题/新题的错误样本继续验证，而不是继续无证据增加 Topic。**
