## 2. First Divergence

X-B03 旧文包含几处把经典 408 DMA 简化模型泛化成跨平台定义的表述：

1. “驱动向 DMA 写目标物理地址 PA”被写成唯一模型；
2. “DMA 全程 CPU 不介入 / 完全释放 CPU”把逐字搬运卸载夸成零系统成本；
3. “传输完成必拉高中断”把 completion evidence 与 discovery method 合并；
4. “Buffer ownership 完全让渡，CPU 严禁访问”缺少方向、DMA API、cache-coherence/IOMMU 等边界；
5. “DMA ⇒ 阻塞当前进程”把 data movement 与 caller behavior 合并。

这些说法在经典教材简化题中可作为局部模型，但不应由 Cross-Subject Bridge 提升为通用 handoff contract。

## 3. Canonical Update

X-B03 改为：

```text
prepare buffer / mapping
→ publish DMA-visible descriptor
→ device/DMA transfer
→ device writes completion evidence
→ interrupt OR polling discovers completion
→ driver validates/synchronizes
→ software completion: wake / CQ / callback
→ unmap/reuse when lifetime ends
```

稳定边界：

- DMA 只意味着 CPU 不用通用指令逐字节参与主要数据搬运；setup/submission/completion 仍由 CPU/driver 承担；
- 经典 408 可按题设令 DMA address = 主存物理地址；现代平台允许 IOMMU/bus translation，因此通用 Bridge 使用 “DMA-visible mapping/address”；
- interrupt 是 completion discovery 方式之一，不是 DMA 的定义组成；
- blocking / nonblocking / async 是 caller/API 轴，与 DMA 正交；
- buffer lifetime 的不变量是“设备仍可能访问期间 mapping 不失效、内存不错误回收/复用、CPU/device 按方向与一致性协议访问”，不写成跨平台绝对禁读写。
