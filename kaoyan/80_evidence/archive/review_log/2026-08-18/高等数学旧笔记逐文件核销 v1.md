## 1. 核销口径

每份 Source 必须落入以下至少一种结论：

- **已承接**：当前 Canonical 已完整拥有其稳定机制，本轮无需重复写入；
- **Canonical Update**：发现真实缺口或硬错误，已回写唯一 Topic / Bridge / Integration Owner；
- **Source Fixed**：用户自有且可编辑的原 Source 已确认存在事实、机制、边界或计算硬错误，已直接回修原笔记，并在此保留勘误证据；
- **Rules Update**：知识机制已有 Owner，但旧稿中的题面信号、第一动作或退出条件需要进入 Control；
- **Extension**：真结构且有未来价值，但不进入数学一默认主干；在相关 Owner 中保留最小可恢复接口；
- **Reject / Corrected**：不适合进入 Canonical 的过度推广、证据不足或外部不可编辑材料；若错误位于用户自有可编辑 Source，则不能停在此状态，必须继续进入 **Source Fixed**；
- **Derived / Navigation**：Canvas / MOC 只做导航或视觉组织，不另立知识 Owner。

本轮共核销 **37 / 37** 份 Source 资产。状态“Source 已核销”不等于 Handbook “已采用”；所有当前 `待人工确认` 的 Topic / Bridge 仍需使用者审阅与陌生题验证。

- `II-11`：原 Source 已把“列表积分/复指数/正交是首选或终极工具”改写成机制选择：多项式次数下降、二维闭环、不同频率完整周期抵消；端点代值降为计算收尾，不再冒充 Fourier 的结构来源。
- `I-10`：原 Source 已把“参数方程万能钥匙”“质心捷径秒杀”改成资格化解释：参数式是统一表示接口但可能重复覆盖；质心法来自重力势能积分的线性性，只在统一终点高度且只计重力功时压缩成立。
- `I-04`：原 Source 已把“无穷远必对应参数边界”补成可复原直觉：内部连续邻域不能让坐标突然逃逸，因此必须扫描定义域端点、有限缺口/奇点与 $\pm\infty$ 这些边界事件。
- 旧稿中的高级定理名称、经验口诀和公式表，若没有改变主干机制或调用行为，只作为 Source/Extension 证据，不升级成新的 Canonical Owner。

## 12. 第二轮细节与直觉审阅

第一轮核销回答“知识有没有归宿”；第二轮进一步回答“这种写法会不会培养坏直觉”。本轮采用的检查顺序是：

$$
\boxed{\text{先预测}\to\text{钉死对象}\to\text{放大易错细节}\to\text{只改一个条件校准}\to\text{正式结论}}
$$

已同步到 Canonical 的代表性增强：

- H-B01：用“竖直平移不改变轴对称、却会搬动中心对称中心”解释积分常数为何只破坏奇性方向；
- Topic09：用“场分量决定数值，法向/有向微元决定符号”解释 $z=0$ 面的通量错误；原 Source 同步修正“中心反演把外法向变成内法向”的错误直觉，改为“对径点的新外法向等于原外法向取负”；
- Topic07 对应 Source：把“距离极值位置向量必与法向共线”补上正则约束资格，并把简化的“不等式约束内部/边界两分”与完整 KKT 条件明确分层；
- Topic11：新增“不同频率在完整周期内正负抵消，同频率平方留下稳定正贡献”的正交筛频直觉；
- H-I01：新增质心法的势能积分推导与失效条件，禁止把它当经验捷径；
- Topic05 对应 Source：清理最后一处“万能代换”命名，改回具体的正切半角换元，避免把一种表示变换误学成无条件默认路线。

这类修改的目标不是增加篇幅，而是让学生在公式出现前已有可检验预判，并知道最容易在哪一个符号、方向、边界或量词上走偏。

## 13. 第三轮做题技巧与资格成本审阅

第三轮把审阅对象从“结论与直觉”进一步推进到**考场动作**。每条技巧都按同一模板检查：

$$
\boxed{\text{题面信号}\to\text{候选路线}\to\text{资格/分支/覆盖成本}\to\text{执行}\to\text{停止条件}\to\text{独立复核}}
$$

本轮拒绝两种伪技巧：一是靠省略资格检查制造出来的“快”；二是把“理论上通用”偷换成“考场上默认优先”。代表性修订如下。

### 13.1 极限、一元微分与中值定理

- `I-02`：修正 L'Hospital 的资格直觉。目标点本身不可导不自动禁用；真正检查的是合法去心/单侧邻域内可导、未定式和分母导数条件。绝对值与分段函数先拆单侧，不再以“点上不可导”作为错误退出条件。
- `I-02`：修正复合极限“直接代内层极限”的捷径。只有外层在内层实际输出路径上连续，或对应单侧极限已确认时，才能把 $\lim\varphi(f(x))$ 写成 $\varphi(\lim f)$。
- `I-02`：修正倒数尺度。$f\to0$ 只先推出 $|1/f|$ 进入无界尺度；要得到确定的 $+\infty/-\infty$ 还需最终保号。
- `I-02`：修正缩小割线的 MVT 伪捷径。由
  $$\frac{f(x+x^2)-f(x)}{x^2}=f'(\xi_x),\qquad \xi_x\to0$$
  不能只凭 $f'(0)$ 存在就推出 $f'(\xi_x)\to f'(0)$；还需导函数邻域极限。该边界同步进入 H-R15。
- `I-02`：把“等价无穷小 / L'Hospital / Taylor 精度排行榜”改成三种不同信息读取方式；$1^\infty$ 快捷式补最终正底数与对数资格；收缩变限积分改为“局部平均 × 有向宽度”的成本选择。
- `I-06`：有限阶导数只需要有限 Taylor 局部模型，不要求先证明无限 Taylor 级数恢复原函数；反正切和差公式补 $k\pi$ 分支；一般有理函数分母不再滥用二次判别式；高阶导数方法按目标信息量选择而非固定排名。
- `I-07.2` / H-B02：构造插值余项常数 $K$ 前先检查目标点是否就是插值节点；若是节点，余项已为零，禁止为了套构造去除以 $\Pi(x)=0$。
- `I-08`：双曲代换补 $x\ge a$ / $x\le-a$ 分支；“反对幂指三”降为候选记忆；正切半角只作为通用有理化兜底，不再叫“万能代换”。
- `I-09` / H-R30：区分一维有向换元与多维一一坐标变换。一元链式法则型定积分换元不要求 $\phi$ 单调，回头段由 $\phi'$ 的符号抵消；只有逐点比较、无向几何量或坐标覆盖问题才额外要求单调/一一与覆盖审计。

### 13.2 积分比较、反常积分与微分方程

- `I-10.1` / H-R31：积分比较不再机械“先统一区间”。目标改成把 $I-J$ 变成符号透明的净面积；同一函数不同区间先看新增区段，只有逐点比较确有收益时才换元。
- `I-12` / H-R34：振荡积分不再要求“先证明绝对值发散才能用 Dirichlet/Abel”。若题目只问普通收敛，哪条资格链更短就先走哪条；只有要求绝对/条件分类时才必须补齐绝对值分支。
- `I-13` / H-R98～99：一阶 ODE 类型表改成结构扫描，不设固定优先级；路线成本把积分难度、分支数和丢解风险一起计算。$v=y/x$ 明确只在 $x\ne0$ 连通区间工作；Bernoulli 的 $y^{1-n}$ 补零解、实数幂符号分支与非 Lipschitz 边界。

### 13.3 多元极值、重积分与几何建模

- `II-03` / Topic07 / H-R52A：消去 Lagrange 乘子改用无除法式 $f_xg_y-f_yg_x=0$，避免先除以可能为零的偏导再回收分支；$\nabla g=0$ 的奇异约束点另列候选。
- `II-03`：对称性只保证候选按对称轨道成对出现，不能推出极值必在 $x=y$。参数化降维后仍要检查端点、周期识别、奇异参数与重复覆盖。
- `II-04`：极/球坐标补角度范围与重复覆盖检查；$r\ge0$ 时无理由扫过超过一整圈会重复计数，负半径约定还需处理 $(r,\theta)\sim(-r,\theta+\pi)$。
- `II-05`：质心对称从“几何对称”收紧为“几何载体 + 密度共同对称”；古尔丁公式补轴相交/覆盖资格；方法表改为“高价值候选 + 使用前确认”，不再用固定星级。
- `I-10` / H-I01 / H-R116：修复旋转体壳层的跨轴重复覆盖硬错误。壳层真正按半径 $r$ 编号，轴两侧 $x=k\pm r$ 可能生成同一圆柱壳；跨轴时应先把同半径产生的高度区间取并集，或直接换圆盘/垫圈。矩形 $[-1,1]\times[0,1]$ 绕 $y$ 轴的最小反例能把错误公式从 $\pi$ 算成 $2\pi$。
- `I-10` / H-I01：圆盘/垫圈改用“切片旋转后的半径集合”理解；切片跨轴时内半径为 $0$。旋转曲面 $2\pi r\,ds$ 还需检查不同生成段是否扫出重叠曲面，否则得到的是按生成重数计的扫掠面积。

### 13.4 定向积分、向量场与级数

- `II-06` / Topic09 / H-R69：把椭圆缩放旋转场精确识别为角度微分，闭路积分由绕数控制，不再记“通常是 $\pi$ 的倍数”；局部辐角势与全局单值势函数分开。
- `II-06`：删除 Stokes 三形式的固定星级。是否换面/投影由“新区域 + 完整 integrand + 定向 + 补偿项”总成本决定。
- `II-06`：替换一个对象定义不完整的空间对称例，并修正一处代表性 Stokes 计算硬错误：对 $\mathbf F=(2y,z,x)$，旋度应为 $(-1,-1,-2)$，与向上法向 $(1,1,1)$ 点乘得 $-4$，三角形边界线积分结果为 $-2$，不是旧稿的 $-1$。H-R71 同步加入“先写旋度三元组，再与法向点乘”的符号分层检查。
- `II-07`：修正“Gauss 是降维打击”的坏直觉；曲面积分转三重积分实际上升维，收益来自把复杂法向/分片边界换成简单散度与体域。
- `II-07`：2020 数一曲面积分例题按真实题面回修。旧 Source 把 $f(xy)$ 抄成 $f(x,y)$、把第三项正号抄成负号并出现错误消项；正确直接投影后抽象函数结构性抵消，结果为 $14\pi/3$。同时提炼“题目只给连续，就优先找不要求偏导的路线”，同步进入 Topic09 / H-R67 / H-R73。
- `II-08` / `II-08.1`：Green/Stokes/Gauss 统一改成“边界对象产生候选 → 资格门 → 总成本比较”；可用不等于该用，更不等于降维。
- `II-09` / H-R95A：两个幂级数加减若 $R_1\ne R_2$，半径必为 $\min(R_1,R_2)$；只有相同半径时系数抵消才可能推大。Cauchy 乘积则即使半径不同也可能因奇性抵消增大半径，不能机械取最小值。
- `II-10` / Topic11：求和与积分交换先验资格，再谈是否能降低计算成本；M-test 的“一致收敛”与“和函数连续”资格分开。
- H-R76 / H-R80 / H-R83：数项级数不再固定“变号先查绝对值”；按同号尺度与抵消机制的证据成本分流。分组、任意重排与 Cauchy 乘积也按不同资格等级处理，不再用“都先证明绝对收敛”一刀切。

第三轮的统一结论是：**真正高质量的做题技巧不是少写几步，而是在不增加未给资格、不制造额外分支、不重复覆盖的前提下，让目标信息更早暴露。**
