## 1. 核销原则

本轮专门防止四种“假吸收”：

1. **标题吸收**：新手册有同名章节，但缺少源稿的成立条件、反向边界或恢复推导；
2. **上游吸收**：理论在某 Topic 已出现，但下游区间、检验或题型调用没有接线；
3. **例题吸收**：只保留公式，却丢掉例题贡献的独立动作（例如双向条件密度相除、抽签位置对称）；
4. **错误吸收**：旧稿存在错误、非标准约定或过强表述时，不能为了“零遗漏”把错误原样复制到 Canonical。

同构例题不要求逐题搬运；若多个例题只重复同一对象、同一动作和同一边界，则合并为 `Merge Evidence`。但凡例题贡献新的触发信号、第一动作、校验或停止条件，就必须进入 Practice 或 Canonical。

### 3.2 本轮补强

- **CDF 凸组合闭包**：`aF_1+(1-a)F_2` 对 `0<=a<=1` 仍为 CDF，并解释为先随机选择总体的混合生成模型；补入 Topic 03 Canonical。

- **几何/指数的双版本无记忆性**：离散试验次数与连续等待时间并列，并明确不能推广到一般负二项、Gamma 或寿命模型。补入 Topic 03 Canonical 与 Practice。
- **Weibull 反向边界**：由 `S(t)=exp[-(t/theta)^m]` 直接算剩余寿命条件概率，只有 `m=1` 时过去等待量消失，从机制上识别指数分布是 Weibull 中的无记忆特例。补入 Topic 03 Canonical 与 Practice。
- **连续均匀端点边界**：单点概率为零，所以 `(a,b)`、`[a,b]`、半开区间在普通连续均匀模型下给出同一分布；若端点另带原子则不同。补入 Topic 03 Canonical。
- **标准分布识别三闸门**：旧稿“$k$ 从 1 开始，所以 $c\lambda^k/k!$ 不能直接认作 Poisson”的例题被提升为“公式核 + 支撑 + 归一”三重验收。熟悉的核函数若支撑截断、起点改变或归一常数改变，就必须重新归一并禁止偷套标准分布性质。补入 Topic 03 Canonical 与 Practice。

- 离散--离散、连续--连续、离散--连续混合计算；
- `Z=g(X,Y)` 的 CDF 原像、截面积分、Jacobian、多分支与混合输出；
- 条件生成模型、离散选择层、条件均匀、混合边缘；
- 最大/最小、和/差/积/商、卷积及可加族。

### 4.2 本轮补强

- **二维均匀分布的面积模型**：`f=I_D/|D|`，事件概率为 `|A∩D|/|D|`；强调面积比只是常数联合密度积分的结果，仍需先与真实支撑取交。补入 Topic 04 Canonical。
- **离散独立表的秩一视角**：`P=p q^T`，任意 `2x2` 子式为零；作为 `p_ij=p_iq_j` 的线性代数恢复线索和快速复核。补入 Topic 04 Canonical 与 Practice。
- **双向条件密度相除反推边缘**：`f_{X|Y}/f_{Y|X}=f_X/f_Y`；只有比例可分离且两组条件密度相容时才可归一化重建。补入 Topic 04 Canonical 与 Practice。
- **联合交换对称的反向条件化**：`f(x,y)=f(y,x)` 且支撑交换对称时先得 `f_X=f_Y`，再由变量角色交换恢复另一侧条件密度；同时明确边缘相同不足以反推联合对称。补入 Topic 04 Canonical 与 Practice。
- **指数竞争模型**：独立 `Exp(lambda_i)` 的最小值速率为 `sum lambda_i`，第 `j` 个最先发生的概率为 `lambda_j/sum lambda_i`；把旧稿 `P(X<Y)` 积分题提升为可恢复的风险率竞争模型。补入 Topic 04 Canonical 与 Practice。
- **离散 + 连续之和的平移密度混合**：一般式 `f_Z(z)=sum_i p_i f_{Y|X}(z-x_i|x_i)`；独立时化为 `sum_i p_i f_Y(z-x_i)`。吸收旧稿“先写多个平移 CDF 再求导”的快捷结论，并直接升级到条件版。补入 Topic 04 Canonical 与 `和的分布与卷积.md`。
- **联合正态的矩阵线性映射**：`Z=A X+c` 仍联合正态，均值 `A mu+c`，协方差 `A Sigma A^T`；`det A=0` 时说明退化到低维子空间，而不是简单宣布“不是正态”。补入 Topic 04 Canonical。
- **随机正负号乘法的反射混合**：若独立随机符号 `S∈{-1,1}` 与连续变量 `X` 相乘，`Z=SX` 的密度是原密度与原点反射密度的加权混合 `q f_X(-z)+(1-q)f_X(z)`；`X` 对称时可立即得到 `Z d= X`，但同分布绝不推出 `X` 与 `Z` 独立。旧稿指数/正态随机变号题被统一压缩到这条规则；补入 Topic 04 Canonical 与 `随机变量变换.md`。
- **条件标准化消去隐藏层**：若 `Y|G=k` 的参数随层变化，但目标变换 `Z=g(G,Y)` 使 `Z|G=k` 对所有正概率层都变成同一个分布，则直接由条件分布得到 `Z` 的边缘，并进一步得到 `Z ⟂ G`。旧稿 `P(G=k)=2^{-k}`、`Y|G=k~Exp(k)`、`Z=GY` 的无穷混合题被提升为这一通用机制；补入 Topic 04 Canonical 与 `随机变量变换.md`。
- **边缘化的不可逆性显式化**：旧稿“联合已知能推出边缘，边缘已知通常推不回联合”不再只作为计算常识，而是提升为“边缘化是有损投影”的信息模型；只有独立、条件分布、联合事件概率或其他依赖结构足够时才可反向重建。Practice 原有该规则，本轮补入 Topic 04 Canonical。

### 5.3 Source Anomaly：已审计但不原样继承

- 旧稿把 `E(XY)=EX EY` 与 `rho=0` 直接写成充要条件，没有先检查相关系数是否定义。Canonical 统一用 `Cov(X,Y)=0` 表示不相关，并要求相关系数的两个方差正且有限。

### 6.2 已在上一轮修正的心智模型

旧教材编排容易产生“先 LLN、再由 LLN 推出 CLT”的视觉误解。Canonical 已改成同一重复随机结构向两条问题分叉：

- LLN：是否稳定到常数；
- CLT：标准化误差趋于何种非退化分布。

两者不是前后推导关系。

### 6.3 Source Anomaly：切比雪夫界不能无条件当等式反解

旧稿若干例题从“真实概率满足某个上/下界”直接令 $D(X)/\varepsilon^2$ 与给定尾概率取等号，再反求 $\varepsilon,n,p$。严格来说，Chebyshev 只给保守界：

`P(|X-EX|>=epsilon) <= D(X)/epsilon^2`。

由左侧概率小于某值不能推出右侧界恰好等于该值。只有题意明确把“用 Chebyshev 设计出来的保证界”本身设为目标值时，才可对界表达式取等号反推设计参数。Topic06 Practice 已把这条反向边界显式写入。

## 8. 第 07 章：参数估计

### 8.1 已完整吸收

- 顺序统计量进入估计的接口。

### 8.2 本轮补强

- **矩估计不是机械使用前 k 阶矩**：k 个参数需要 k 个存在、含目标参数且提供独立信息的矩方程；一阶矩不含参数时可跳到二阶/更高阶，也可使用中心矩。补入 Topic 08 Canonical 与 Practice。
- **归一化恒等式不是样本信息方程**：已声明为合法参数族时，`∫f(x;theta)dx=1` 是模型定义而非观测信息；只有未归一化常数尚未闭合时才先用归一化确定模型。吸收旧稿多次强调“归一性恒为 1，不能替代矩估计”的方法点。补入 Topic 08 Canonical 与 Practice。
- **表面参数个数 ≠ 自由参数维数**：旧补充题中密度同时含 `a,b`，但归一化先给出 `b=h(a)`，故真正只需估计一个自由参数。已补“先用模型合法性约束确定参数空间维数，再用样本信息估计自由参数”的规则；同时明确归一化提供结构约束而非观测证据。补入 Topic 08 Canonical 与 Practice。
- **无偏性不经一般非线性变换传递**：明确 `E(hat theta)=theta` 一般不推出 `E[g(hat theta)]=g(theta)`，并用 `E(bar X^2)=mu^2+sigma^2/n` 恢复旧稿关键反例。补入 Topic 08 Canonical 与 Practice。

### 8.3 Source Anomaly：MLE 的“驻点即结束”快捷话术不继承

旧稿有“通常不必再算二阶导，求导得到解即可下结论”的课堂型快捷表述。它只有在其他证据已经建立全局最大时才安全，例如对数似然严格凹、导数在候选点两侧变号、可行域上单调并由边界取最大，或已经比较全部驻点与边界。单独由 `ell'(theta)=0` 只能得到内部驻点候选，不能证明 MLE。Canonical / Practice 已统一为“MLE 是全局优化问题，求导只是候选生成器”。

### 10.3 Source Anomaly：已审计但不原样继承

旧抽样分布稿中有“分母出现根号下若干平方和，故为 t 分布”一类形状口诀。该表述条件过弱，不继承。Canonical 要求完整生成资格：分子先标准化成 $N(0,1)$，分母平方部分标准化成独立的 $\chi^2(\nu)$，再除以自由度并开方，而且分子与分母必须独立；$F$ 分布同样必须检查两个标准化卡方及独立性。
