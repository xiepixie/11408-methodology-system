# Review Log

这里保存**当前仍直接影响决策的活动证据**，不是永久流水账。历史记录只归档，不删除；知识 Source 与 Canonical Handbook 也不因日志归档而改变状态。

## 生命周期

1. 新记录必须对应一个可执行问题：Source Diff、Rule 验证、Bridge 接口验证或发布阻塞。
2. 同一工作流只维护一份主记录；小更新追加到原记录，不为每次检查新建文件。
3. 当结论已写入 Canonical Handbook / Atlas / Syllabus，且没有未决动作时，将原文件移动到 `../archive/review_log/YYYY-MM-DD/`，保留原文和日期。
4. 归档后若重新打开，不改写历史记录；新建一份带新日期的记录，并链接回归档文件。
5. 每次归档最多保留一份工作流摘要；重复的逐题明细留在原始日志。

## 记录边界

- Review log 是 Evidence，不是第二个 Knowledge Owner。
- `Canonical Update` 只表示物理资产或 Owner 发生变化，不表示 Rules 已被使用者验证。
- `No Update`、`Candidate`、`Reject` 和未决项必须保留理由；归档不能把它们改写成完成。
