## 3. 母模型结论

### 3.1 缓冲的稳定定义

缓冲首先不是某一种数据结构，而是一个系统角色：

> 当两端无法在同一时刻、以同一速率、同一粒度或同一顺序直接完成交接时，用有限中间状态暂存对象，使两端可以在约束下异步推进。

对可用库存模型描述的有界缓冲，稳定骨架为：

$$
0\le q\le K,\qquad q'=q+a-d.
$$

其中 $K$ 是容量，$q$ 是当前占用，$a/d$ 分别表示进入/离开量。真正决定系统行为的是两个边界：`empty` 与 `full`。

### 3.2 六类不匹配

1. 速率不匹配：快端与慢端；
2. 时相不匹配：两端不能同时占有/工作，需要阶段重叠；
3. 粒度不匹配：小单位与块/批次单位之间聚合或拆分；
4. 顺序/完整性不匹配：对象先到，但必须等缺口/前驱条件后才能交付；
5. 突发与平均负载不匹配：短 burst 需要临时容量吸收；
6. 资源独占与提交时刻不匹配：任务先提交排队，资源随后串行服务，SPOOLing 是典型扩展。

### 3.3 最重要的性能边界

$$
\boxed{\text{Buffer buys slack / overlap, not service capacity}}
$$

缓冲容量可以增加可吸收突发量、允许更多重叠、减少前端逐次等待，但不能单独改变慢级长期服务率。若长期平均到达率持续高于平均服务率，有限缓冲最终必然触及满边界，随后只能阻塞、反压、丢弃、覆盖或溢写到其他层。

这条结论能够同时解释：

- Cache 写缓冲满后 CPU 仍需等待；
- OS 多加几个循环缓冲不会让慢设备本体更快；
- TCP 接收缓冲最终通过 `rwnd` 把容量压力反馈给发送端；
- router 加大 buffer 可以延后 drop，却可能增加 standing queue / latency；
- 外部排序的更多输入缓冲受总内存预算约束，不能把归并路数无限增大。

## 4. 概念边界

- Buffer ≠ Queue：前者说明为什么需要有限中间态，后者说明对象的组织/出入次序；Queue 常作为 Buffer 的实现。
- Buffer ≠ Cache：前者主要服务当前交接解耦，后者主要保留可复用副本以减少未来慢路径访问；Page Cache 可同时承担两种角色。
- Buffer ≠ Window：Window 是逻辑许可/反馈范围；实际缓存对象和可接受范围相关但不是同一状态。TCP `rwnd` 是典型“把接收缓冲剩余容量外显为窗口”。
- Buffer Pool ≠ Kernel Buffer：Pool 是一组对象的分配/回收管理策略；Kernel/User 描述地址空间、权限和 Owner。
- Buffer ≠ DMA：Buffer 是承载/暂存；DMA 回答谁搬运以及怎样访问内存。
- Buffer ≠ SPOOLing：SPOOLing 还包含持久中转存储、任务队列、后台服务与独占设备虚拟化。
- 流水寄存器与 DRAM 行缓冲可以从“时间解耦/暂存”得到类比，但不能强套完整生产者—消费者队列模型；其本地不变量仍由 CO Topic Own。

## 5. Bridge Gate 结论

**Reject：不新增“缓冲 Bridge”。**

理由：缓冲没有稳定的单一“A 学科输出 → 翻译层 → B 学科输入”接口。它是多个 Topic 独立采用的重复设计关系，类似课程总图已有的 Scarcity / Sharing、Locality / Caching。因此：

- Course Atlas-owned 跨科母模型补充拥有：母问题、六类不匹配、概念边界、四科映射、通用生命周期和“禁止错误类比”；它不是第五种 Handbook；
- 课程总图拥有：入口、压缩结论与路由，不再重复长正文；
- 各专题拥有：具体结构、公式、状态机、性能口径；
- 408 做题规则只保存陌生缓冲题的首次定位协议；
- 不复制局部机制到新的 Bridge 手册。

## 7. 下一验证门槛

通用七问暂不进入“已采用”。至少用以下九类代表题验证：

- 循环队列：不同 front/rear 约定、空满消歧与回绕；
- 外部排序：缓冲块数如何约束 $k$ 路归并；
- Cache 写直达 + write buffer：突发写与持续写两种负载；
- OS 单/双/循环缓冲：严格按时间线比较可重叠阶段；
- IPC：管道空/满、端点关闭/EOF，消息通道零容量/有界容量与阻塞；
- 虚拟内存：页框有限、缺页、置换与脏页写回；
- GBN/SR：发送端未确认数据保留、失序 frame 缓存与连续前缀交付；
- TCP：应用不读取导致 receive buffer 填满、`rwnd\to0`，并区分 `cwnd`；
- 交换/路由：端口输入/输出队列、HOL、持续 $\lambda>C$ 与有限 buffer。

若七问在这些题中不能缩短定位过程，或诱导把本地机制强行同构，则回退/拆分；通过后才能迁入 408 做题规则的“已采用”。
