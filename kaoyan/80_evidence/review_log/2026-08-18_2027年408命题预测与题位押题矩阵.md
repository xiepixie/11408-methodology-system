## 一、预测方法

本轮不采用“去年没考，所以今年一定考”的机械轮换，而同时看五个信号：

1. **题位稳定性**：同一题号长期承担什么角色，例如第 13～14 题长期承担数值表示，第 21～22 题长期承担中断 / DMA / I/O，第 40 题长期承担应用层；
2. **近年饱和度**：2024～2026 连续强考的同型题适当降权，但母模型不降权；
3. **空窗年数**：考纲明确存在、历史上长期未直接命题的点，适合成为 2 分选择题偷袭；
4. **考纲结构信号**：当前官方原件中明确标出“信号”“页框分配与回收”等新增或强化项，必须提高优先级；
5. **综合生成能力**：能够自然连接多个模块、要求状态跟踪、时间线、数据通路或算法设计的点，提高大题权重。

### 置信等级

- **极高**：题位长期高度稳定，且近期仍维持该角色；
- **高**：历史频率和题位结构均支持；
- **中高**：轮换与空窗支持，但题位本身较灵活；
- **防守**：低频、冷门，但考纲明确且用很低成本即可覆盖。

# 二、选择题第 1～40 题：每题押 3 个具体考点

## 第一部分 数据结构：第 1～11 题

### 第 1 题

**主押：代码时间复杂度分析【极高】**
- 多重循环中变量倍增 / 倍减；
- 对数级循环次数；
- 简单递归式的数量级；
- 区分“执行次数”与“渐近复杂度”。

**次押：顺序表插入删除代价【高】**
- 表头 / 表尾 / 中间插删移动元素数量；
- 最好、最坏、平均时间复杂度；
- “保持相对次序”对移动的约束。

**防守：单链表基本操作复杂度【中高】**
- 已知结点指针与只知序号时复杂度不同；
- 插入、删除、查找的前驱条件；
- 头结点 / 无头结点边界。

**判断依据**：18 年中第 1 题以复杂度分析出现次数最高；2025 回到复杂度、2026 转顺序表，2027 再回“算法复杂度 + 基础结构”的概率高。

---

### 第 2 题

**主押：栈的合法出栈序列与容量【极高】**
- 判断某序列能否由给定入栈顺序产生；
- 模拟 push / pop；
- 求最小栈容量或某时刻栈深度。

**次押：中缀 / 后缀表达式与栈【高】**
- 中缀转后缀；
- 后缀表达式求值；
- 运算符优先级与结合性。

**防守：循环队列状态判断【高】**
- `front / rear` 含义；
- 队满 / 队空判定；
- 队列长度计算；
- 牺牲一个存储单元与计数器方案的区别。

**判断依据**：第 2 题历史上“入栈出栈序列”最集中；2026 已考双向链表，2027 回到受限访问结构的概率更高。

---

### 第 3 题

**主押：二叉树遍历序列关系【高】**
- 先序 / 中序 / 后序 / 层序互推；
- 已知两种遍历恢复结构；
- 判断某序列是否可能。

**次押：特殊矩阵 / 多维数组地址计算【中高】**
- 行优先 / 列优先；
- 对称矩阵、三角矩阵、三对角矩阵压缩；
- 下标到存储位置映射。

**防守：线索二叉树【防守】**
- 前驱 / 后继；
- 线索标志位；
- 中序线索化后空指针语义。

**判断依据**：第 3 题长期偏树与数组；2026 再考遍历，若不连续重复，则特殊矩阵 / 线索树是很自然的轮换。

---

### 第 4 题

**主押：完全二叉树 / 满二叉树节点数量关系【高】**
- 高度与最少 / 最多结点数；
- 叶结点与度为 2 结点数量关系；
- 顺序编号下父子下标。

**次押：树、森林与二叉树转换【高】**
- 左孩子右兄弟表示；
- 转换后的高度 / 结点度数；
- 森林中树的数量与二叉树右链关系。

**防守：AVL 树高度与最少结点数【中高】**
- 高度递推；
- 平衡因子；
- 插入后旋转类型判断。

**判断依据**：第 4 题历史上平衡树最集中，但 2026 刚在第 8 题考 AVL；因此 2027 更适合回完全二叉树或树森林基本性质。

---

### 第 5 题

**主押：哈夫曼树与哈夫曼编码【高】**
- 带权路径长度；
- 构造过程；
- 编码长度；
- 前缀编码判定。

**次押：二叉树节点性质 / 遍历【高】**
- 叶结点数量；
- 高度；
- 遍历访问次序；
- 由结构性质反推结点数量。

**防守：并查集【重点冷押】**
- `find` / `union` 的语义；
- 路径压缩；
- 按秩 / 按大小合并；
- 判断若干集合操作后的根或集合数量。

**判断依据**：并查集在当前考纲中明确列入“树与二叉树的应用”，但 2009～2026 真题库没有形成成熟直接考法，非常适合用 2 分首次偷袭。

---

### 第 6 题

**主押：图的存储结构与度计算【高】**
- 邻接矩阵 / 邻接表；
- 有向图入度 / 出度；
- 无向图边数；
- 求某操作的时间复杂度。

**次押：DFS / BFS 遍历【高】**
- 访问序列；
- 生成树；
- 邻接表顺序改变对遍历结果的影响；
- 时间复杂度。

**防守：最小生成树与并查集接口【中高】**
- Kruskal 选边；
- 判断是否形成环；
- MST 唯一性；
- 用并查集维护连通分量。

**判断依据**：第 6 题长期位于树与图的交界；2026 考邻接表求入度，若继续图模块，遍历 / MST 是最自然的变体。

---

### 第 7 题

**主押：拓扑排序与有向无环图【高】**
- 入度变化；
- 拓扑序是否唯一；
- 判断图中是否存在环；
- 基于拓扑序判断前驱约束。

**次押：最短路径【中高】**
- Dijkstra 的适用边界；
- 每轮已确定集合；
- 距离更新；
- 负权边为什么破坏 Dijkstra。

**防守：关键路径【中高】**
- `ve / vl`；
- 活动余量；
- 关键活动判定；
- 项目工期。

**判断依据**：第 7 题历史上图概念、拓扑排序最集中；2025～2026 没在小题核心位置直接打拓扑，存在回归空间。

---

### 第 8 题

**主押：B 树 / B+ 树【高】**
- 阶数与关键字数范围；
- 查找路径；
- 插入分裂；
- B 树与 B+ 树数据存放位置区别。

**次押：红黑树性质【重点冷押】**
- 根 / 叶颜色；
- 红结点不能连续；
- 任一路径黑高相同；
- 高度保持 `O(log n)`；
- 与 AVL 的“严格平衡 vs 较弱平衡”区别。

**防守：AVL 插入旋转【中高】**
- LL / RR / LR / RL；
- 插入后局部修复；
- 最小结点数递推。

**判断依据**：第 8 题是历年最典型的“高级查找树坑位”。红黑树考纲明确但 18 年未形成直接真题，是本年度最值得低成本防守的冷点之一。

---

### 第 9 题

**主押：散列表查找性能【高】**
- 装填因子；
- 线性探测 / 二次探测；
- 成功 / 失败平均查找长度；
- 聚集现象。

**次押：堆与优先队列【高】**
- 插入 / 删除堆顶后的调整；
- 大根堆 / 小根堆序列判断；
- Top-K 使用哪种堆。

**防守：分块查找【中】**
- 索引表有序；
- 块内可无序；
- 查找长度估算；
- 分块大小对性能的影响。

**判断依据**：第 9 题历史上散列表与堆最集中；2026 异常落到直接插入排序，因此 2027 回归“查找 / 堆”的概率更高。

---

### 第 10 题

**主押：内部排序性质比较【极高】**
- 稳定性；
- 是否原地；
- 最好 / 最坏复杂度；
- 与初始序列相关性。

**次押：快速 / 归并 / 堆排序一趟过程【高】**
- partition 后序列；
- merge 一趟结果；
- heapify 调整结果。

**防守：希尔 / 基数排序【中高】**
- 希尔增量；
- 基数排序按位处理顺序；
- 稳定性与非比较排序性质。

**判断依据**：第 10 题长期是排序主坑位，几乎不需要依赖轮换假设。

---

### 第 11 题

**主押：外部排序【极高】**
- 初始归并段；
- 多路归并趟数；
- 败者树作用；
- 增大归并路数对 I/O 与比较次数的影响。

**次押：置换选择生成初始归并段【高】**
- 工作区 / 冻结元素；
- 下一归并段边界；
- 初始段长度不必固定。

**防守：内部排序综合判断【高】**
- 插入 / 归并 / 快排 / 堆排序比较；
- 某趟排序后是否可能得到给定序列。

**判断依据**：2024 败者树、2026 外部排序都说明第 11 题已经稳定承担“排序收尾 / 外排”角色。

## 第二部分 计算机组成原理：第 12～22 题

### 第 12 题

**主押：CPU 性能公式【极高】**
- `CPU 时间 = 指令数 × CPI × 时钟周期`；
- 主频变化与 CPI 变化不能混；
- 加速比；
- MIPS 的适用边界。

**次押：计算机系统层次结构【高】**
- 高级语言、汇编、机器语言；
- 编译器、汇编器、链接器；
- ISA 是软硬件接口。

**防守：存储程序与指令执行过程【中高】**
- 取指、译码、执行；
- 指令与数据同存储器；
- 程序执行的基本状态变化。

**判断依据**：第 12 题是计组最稳定的开场坑位之一，长期集中在系统层次与性能指标。

---

### 第 13 题

**主押：补码范围、移位与溢出【极高】**
- `n` 位补码范围；
- 算术右移；
- 左移导致溢出；
- 补码加减与溢出判断。

**次押：C 语言有符号 / 无符号类型转换【高】**
- 相同比特模式的不同解释；
- 整型提升；
- signed / unsigned 比较结果。

**防守：标志位生成【中高】**
- OF / CF / SF / ZF；
- 有符号溢出与无符号进位不能混。

**判断依据**：第 13 题历史上补码出现最集中，是非常强的题位先验。

---

### 第 14 题

**主押：IEEE 754 单精度编码 / 解码【极高】**
- 符号位；
- 偏置阶码；
- 隐含最高位；
- 十六进制与浮点值互转。

**次押：浮点数范围与精度【高】**
- 规格化数；
- 最小 / 最大数量级；
- 尾数位数决定有效精度；
- 舍入影响。

**防守：整数与浮点转换【中高】**
- 大整数转 float 是否精确；
- float 转 int 的截断 / 范围；
- 浮点加减对阶与尾数舍入。

**判断依据**：18 年中第 14 题单独考 IEEE 754 的次数极高；2022、2023、2024、2026 都在附近反复出现。

---

### 第 15 题

**主押：DRAM / SRAM / 存储芯片组织【高】**
- 地址线与数据线；
- DRAM 行列地址复用；
- 芯片扩展后的容量；
- SRAM 与 DRAM 基本差异。

**次押：主存低位交叉编址【高】**
- 模块号与块内地址；
- 连续访问落在哪些模块；
- 带宽与冲突。

**防守：大小端与数据对齐【高】**
- 多字节对象在地址空间中的字节顺序；
- 结构体 / 基本类型对齐；
- 地址增加方向与“高低位”不能混。

**判断依据**：2026 已直接考低位交叉，2027 更可能转回芯片组织或大小端 / 对齐，但存储器硬件仍是第 15 题主战场。

---

### 第 16 题

**主押：指令格式与寻址方式【高】**
- 立即数 / 寄存器 / 寄存器间接 / 基址 / 变址；
- 有效地址计算；
- 位移量符号扩展。

**次押：ISA 与微体系结构边界【高】**
- 哪些是 ISA 可见状态；
- Cache、流水线等是否属于 ISA 语义；
- 软件可观察结果与内部实现区别。

**防守：CISC / RISC【中高】**
- 指令长度；
- 寻址方式数量；
- 寄存器使用；
- 流水线友好性。

**判断依据**：第 16～17 题长期承担 ISA 区域；2026 已考 ISA / 微架构边界，2027 仍大概率不离开指令系统，只会换切口。

---

### 第 17 题

**主押：PC 相对寻址与控制转移【高】**
- 分支目标地址；
- PC 已经指向下一条指令还是当前指令；
- 位移字段的单位与符号扩展。

**次押：C 控制结构到机器级代码【中高】**
- if / loop 对应 branch / jump；
- 比较结果与条件跳转；
- 循环边界。

**防守：函数调用的机器级表示【中高】**
- 返回地址；
- 栈帧；
- 调用者 / 被调用者保存寄存器；
- 参数与局部变量。

**判断依据**：当前考纲明确强化“高级语言程序与机器级代码之间的对应”；相比 2026 的 PC 控制转移，函数调用仍有较大出题空间。

---

### 第 18 题

**主押：流水线基本性能【高】**
- 流水段数；
- 第一条指令完成时间；
- 稳态吞吐率；
- 总周期数。

**次押：Cache 映射【高】**
- 直接映射 / 组相联 / 全相联；
- Tag / Index / Offset 位数；
- 主存块映射到哪一组。

**防守：数据通路中的组合逻辑与状态元件【中高】**
- ALU / MUX；
- PC / 寄存器；
- 控制信号决定路径。

**判断依据**：第 18～19 题是数据通路、Cache、流水线的竞争区域；2026 第 18 题已考 Cache，因此 2027 第 18 题更偏流水线的概率上升。

---

### 第 19 题

**主押：流水线数据冒险【极高押位】**
- RAW 依赖；
- forwarding 能消除哪些停顿；
- load-use 冒险；
- 插入气泡数量。

**次押：控制冒险【高】**
- 分支决策阶段；
- 错误路径清空；
- 分支罚时；
- 静态 / 动态预测的基本概念。

**防守：数据通路控制信号【中高】**
- 寄存器读写；
- ALU 输入选择；
- PC 更新；
- MemRead / MemWrite 一类信号。

**判断依据**：历史上第 19 题“流水线冒险”出现最集中；2023、2024 连续考后，2025～2026 已空窗两年，具备明显回归条件。

---

### 第 20 题

**主押：总线带宽、事务与定时【高】**
- 总线时钟；
- 每次事务传输字节数；
- 突发传输；
- 理论带宽。

**次押：CPI 与整机性能【高】**
- 各类指令比例；
- 平均 CPI；
- 改进某类指令后的总体加速比。

**防守：总线仲裁与共享资源【中】**
- 主设备 / 从设备；
- 总线占用；
- DMA 与 CPU 竞争主存 / 总线。

**判断依据**：第 20 题历史上总线指标极强；2023～2025 连续总线，2026 转 CPI，2027 两者仍是最合理的二选一区域。

---

### 第 21 题

**主押：中断请求与响应时机【极高】**
- 一条指令执行结束后检测外中断；
- 可屏蔽 / 不可屏蔽；
- 中断允许 / 屏蔽；
- 硬件自动保存的最小现场。

**次押：程序查询 / 中断 I/O 对比【高】**
- CPU 是否忙等；
- 数据搬运主体；
- 中断开销与并行性。

**防守：I/O 接口 / 端口编址【中高】**
- 统一编址 / 独立编址；
- 状态 / 控制 / 数据寄存器；
- CPU 如何访问。

**判断依据**：第 21 题长期被中断 / I/O 占据，是和第 13～14 题类似的强题位。

---

### 第 22 题

**主押：DMA 传送过程【极高】**
- DMA 请求；

**防守：多处理器 / 多核 / 硬件多线程【防守】**
- SISD / SIMD / MIMD；
- 多核属于 MIMD 的典型形式；
- 硬件多线程不要求多核。

**判断依据**：第 22 题历史上异常中断、DMA 最集中；多处理器仅零散出现，很适合作为概念型第三押点。

# 三、综合应用题第 41～47 题：每题押 2 个具体考点

> 大题预测采用“题号角色 + 近三年饱和度 + 历史空窗 + 当前考纲强化 + 能否形成 7～13 分完整推理链”综合判断。

## 第 41 题：数据结构算法设计

### 第一押：单链表原地算法设计【高】

具体押法：

- 单链表按某谓词稳定 / 非稳定分区；
- 原地重排、区间反转、奇偶分离、去重；
- 找公共后缀 / 交点；
- 一趟扫描维护前驱、尾指针或双指针；
- 要求 `O(n)` 时间、`O(1)` 额外空间；
- 必须说明循环不变量、边界与复杂度。

**为什么押**：2025 第 41 题是顺序表，2026 第 41 题是 BST；链表作为 408 最适合考 C 指针与算法契约的结构，近年大题空窗较长，具备明显回归价值。

### 第二押：图上的 BFS / DFS 算法设计【中高】

具体押法：

- 无权最短路 / 层次距离；
- 连通分量 / 可达性；
- 判断环或某种路径约束；
- 邻接表 + `visited` / `dist` 状态；
- 分析 `O(V+E)`。

**为什么押**：若命题人不想再出“线性结构 / 查找树”连续三年算法题，图遍历是最自然的算法设计替代。

---

## 第 42 题：数据结构综合分析

### 第一押：最短路径 / 最小生成树状态推演【高】

具体押法：

- 给图和邻接矩阵 / 邻接表；
- Dijkstra 某轮 `dist / visited`；
- Prim / Kruskal 选边过程；
- 判断唯一性；
- 算法复杂度与存储结构选择。

**为什么押**：2024 第 41 题拓扑、2025 第 42 题关键路径、2026 第 42 题栈 / 卡特兰，图综合仍是高频母题，但最短路径 / MST 在近三年大题并未饱和。

### 第二押：查找结构综合——散列 / B 树 / 红黑树【中高】

具体押法：

- 散列表构造与平均查找长度；
- B 树插入分裂 / 删除基本过程；
- AVL / 红黑树高度与平衡代价比较；
- 给定工作负载选择索引结构。

**为什么押**：2026 已考 BST，但“有序索引 / 动态查找”仍可能换结构继续命题；红黑树尤其适合第一次从冷点升级成大题中的一个小问，而不是独立整题。

## 第 43 题：计算机组成原理综合一

### 第一押：C 语言数据与机器级代码【高】

具体押法：

- 补码 / 无符号 / IEEE 754 与 C 类型转换；
- 大小端、对齐；
- 指令寻址；
- 分支 / 循环的机器代码；
- PC 相对位移；
- 计算某条指令执行后的寄存器 / 内存状态。

**为什么押**：2026 第 43 题已经把“定长指令格式设计”考得很完整，2027 更适合把 ISA 落回“高级语言 ↔ 机器级执行”的考纲目标。

### 第二押：Cache / TLB / 页表联合地址投影【中高】

具体押法：

- 虚拟地址拆分；
- TLB 命中 / 未命中；
- 页表得到物理页框；
- 物理地址再拆 Cache 的 Tag / Set / Offset；
- 判断某次访问 hit / miss；
- 平均访存时间。

**为什么押**：这是计组最稳定的综合母题之一。2025 已考得较重、2026 分散成选择题，因此 2027 仍有回归综合题的可能，但排在流水线之后。

---

## 第 44 题：计算机组成原理综合二

### 第一押：流水线 + 冒险 + CPI【极高】

具体押法：

- 给一段汇编；
- 标出 RAW 依赖；
- 判断 forwarding；
- 插入 stall / bubble；
- branch 造成 flush；
- 计算总周期数、平均 CPI、加速比；
- 比较有 / 无旁路。

**为什么押**：2026 第 44 题已完整考数据通路与微操作；流水线大题长期空窗，而 2023～2024 只在选择题露面，2025～2026 又没有直接打冒险，轮换条件很强。

### 第二押：DMA / 中断 / 总线与 I/O 传送【高】

具体押法：

- 设备缓冲区大小与 DMA 请求次数；
- 周期挪用；
- DMA 与 CPU 总线竞争；
- 传送完成后中断；
- 计算总线带宽或 CPU 被占用比例。

**为什么押**：I/O 是计组综合题常客，但 2026 两道计组大题都集中在指令 / 数据通路，没有打 DMA / I/O，存在明显轮换空间。

---

## 第 45 题：操作系统综合一

### 第一押：同步互斥 + 信号量 + 最大并发度【极高】

具体押法：

- 先从题目构造前驱依赖；
- 区分资源互斥与事件同步；
- 定义尽可能少的信号量；
- 给初值；
- 正确放置 `wait / signal`；
- 临界区只覆盖真正共享资源；
- 证明无死锁且尽量并发。

**为什么押**：2009～2025 同步大题出现极其频繁，而 2026 第 45 题转为调度时间线。2027 回归同步是最强的轮换判断之一。

### 第二押：IPC 信号 / 条件变量与状态转换【中高】

具体押法：

- signal 产生、屏蔽、pending、递达；
- handler 与进程执行流；
- 条件变量 wait / signal；
- 阻塞→就绪；
- 与信号量 / 中断区分。

**为什么押**：若考纲中的“信号”为本轮新增强化，综合题可能不是单独写 API，而是嵌入“进程状态 + IPC + 同步”场景。

---

## 第 46 题：操作系统综合二

### 第一押：页框分配回收 + 工作集 + 页面置换【极高】

具体押法：

- 多个进程竞争有限页框；
- 固定 / 可变分配；
- 局部 / 全局置换；
- 给访问串与工作集窗口；
- 动态调整驻留集；
- 缺页、淘汰、回收时间线；
- 判断是否发生抖动。

**为什么押**：当前考纲明确强化“页框分配与回收”；2026 第 46 题刚考 inode / 目录，因此文件系统同型题应降权，而虚存资源管理正适合接替。

### 第二押：阻塞 I/O 完整生命周期【高】

具体押法：

- 进程调用 `read`；
- 系统调用进入内核；
- 设备驱动发起 I/O；
- 进程阻塞；
- DMA / 设备工作；
- 中断完成；
- 唤醒进入就绪队列；
- 再调度后返回用户态。

**为什么押**：这一题可以自然连接进程状态、系统调用、I/O 软件层次、中断 / DMA，是当前 408 强调“应用程序—内核—硬件协作”的典型综合题。

## 第 47 题：计算机网络综合题

### 第一押：CIDR / VLSM + 路由表 + ARP / DHCP / NAT【极高】

具体押法：

- 根据主机需求划分子网；
- 写网络号 / 掩码 / 可用地址范围；
- 路由聚合；
- 最长前缀匹配；
- 判断目的主机是否同网段；
- 跨网段时 ARP 查询默认网关 MAC；
- DHCP 初始地址获取；
- NAT / NAPT 修改地址与端口。

**为什么押**：2026 第 47 题已经把 TCP 握手、挥手、滑动窗口打得非常完整；2027 网络层重新成为整题主体的轮换概率高。

### 第二押：DNS + TCP + HTTP 跨层时延链【高】

具体押法：

- DNS 递归 / 迭代查询；
- DNS 缓存；
- TCP 建连 RTT；
- HTTP 非持久 / 持久连接；
- 并行连接；
- 计算页面获取总时延；
- 必要时混入拥塞窗口或接收窗口约束。

**为什么押**：相比“再来一整道纯 TCP”，把 DNS / HTTP 与 TCP 组合成真实网络事件链更符合近年跨层命题趋势。

如果复习时间有限，不按 134 个押点平均投入，而按下面顺序：

# 五、这份预测不能被误用成什么

1. **不能把“每题 3 押点”理解成固定题号模板。** 题位只有统计倾向，不是命题合同。
2. **不能因 2026 已考某母模型就删除。** 408 经常连续考同一母模型，但换作用域、换接口、换题面。
3. **不能把冷门空窗直接等同于高概率。** 红黑树、并查集、组播、移动 IP 的价值主要来自“低成本防守收益”，不是因为它们一定出现。
4. **大题预测应优先训练生成能力。** 真正应该押的是“能否从模型重新推导”，而不是背一道预测题答案。
5. **2027 真题发布后必须回测。** 逐题记录命中、擦边、失误，并区分：题位判断错、知识点轮换判断错、考纲权重判断错，还是具体考法判断错。
