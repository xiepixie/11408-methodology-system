# 数据结构 KMP 与图算法心智模型深度复审

日期：2026-08-12  
类型：Canonical Update  
范围：DS03、DS07、DS08

## 复审问题

代码与正文是否已经把复杂算法压缩成可复原、可模拟、可迁移的心智模型，而不只是给出正确实现和算法名称？

本轮使用四项静态标准：

1. 状态变量能否用一句语义明确的话解释；
2. 学习者能否在小例子上逐步手算状态变化；
3. 循环不变量、提交时刻和失败条件是否显式；
4. 相近算法能否通过同一比较维度区分，而不是分别死记模板。

这些标准只能证明材料具备教学条件，不能证明用户已经记牢。后者仍需无提示复原和陌生题证据。

## 发现的事实缺口

### DS03 KMP

- 旧正文解释了 `prefix` 的含义与失配回退，但缺少一条完整、可逐格复算的前缀表构造轨迹。
- 缺少“连续回退后仍复用当前文本字符”的完整匹配例子，学习者容易把 `j = prefix[j-1]` 错写为文本指针回退。
- 测试只有若干样例，尚未系统攻击短串中的重叠前后缀组合。

### DS07 图遍历

- BFS/DFS 的容器差异已有说明，但 `Unseen -> Discovered -> Expanded` 状态链不够显式。
- “发现即标记”与“出队才标记”的差异没有用菱形图暴露重复入队后果。

### DS08 图结构算法

- 旧正文只有若干算法的口头不变量，缺少统一的候选域、提交时刻与失败证据比较。
- Floyd 没有进入正文主线；关键路径只计算最早时间，不能判断关键活动。
- 旧接口描述暗示 Dijkstra 直接调用 DS05 具体堆实现，与代码事实不符。
- 路径代价使用 32 位整数会把算法正确性暴露给数值溢出风险。

## Canonical Update

### DS03

- 增加 `ababaca` 前缀函数逐步构造，显式呈现 `3 -> 1 -> 0` 失败链。
- 增加文本片段 `abababaca` 与模式 `ababaca` 的完整失配恢复，强调模式状态回退而文本字符不回退。
- 对长度不超过 6 的二进制文本、长度不超过 4 的二进制模式做 KMP 与朴素匹配穷举一致性测试。

### DS07

- 将遍历统一为 `Discover -> Mark -> Enqueue/Push -> Expand`。
- 增加菱形图反例，说明延迟标记会让同一顶点重复进入前沿。
- 用 `Unseen / Discovered / Expanded` 区分“已发现”和“已完成扩展”。
- 修正迭代 DFS 原先“弹栈才标记”的实现，使 BFS 与 DFS 都严格在首次入前沿时标记；增加共享后继的菱形图断言。

### DS08

- 建立统一主链：`Goal -> Candidate Domain -> Local Action -> Commit Point -> Invariant -> Global Result`。
- 用相同六列比较 Prim、Kruskal、Dijkstra、Bellman--Ford、Floyd、拓扑排序和关键路径。
- 补齐 Floyd 的中间点集合不变量，以及关键路径的正向最早、反向最迟、零时差活动判定。
- 路径代价升级为 `long long`；测试增加 40 亿路径、负边、负环、非连通、有环、不可达和完整关键路径结果。
- 澄清 Kruskal 对 DS06 是直接代码复用；Prim/Dijkstra 对 DS05 只是抽象候选优先级契约复用。

## 当前判定

- `DS03 / DS07 / DS08`：Canonical Update。
- 静态深度：满足“状态可解释、过程可手算、不变量可陈述、边界可攻击”的最低心智模型标准。
- 学习效果：仍是待验证假设。下一步应让学习者在无提示条件下复原 KMP 失败链，并在同一张图上分别口述 Prim、Kruskal、Dijkstra 的候选域与提交条件。

## 最小后续验证

1. 给出一个含多层 border 的陌生模式串，要求不运行代码手算全部 `prefix` 值，并解释每次回退复用了什么事实。
2. 给出含重边、不可达点和一个负边的图，要求先选算法再写适用性理由。
3. 给出同一无向图，分别模拟 Prim 与 Kruskal，检查是否把“单树边界”和“全局森林”混为一谈。
4. 给出 AOE 网，只提供正向最早时间，追问为何还不能确定关键活动。
