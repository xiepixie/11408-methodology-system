# 高数基础生成层完整性复审

日期：2026-08-18  
场景：handbook depth review / post-source-migration  
状态：**全 Topic 重新进入“基础生成层 + Reference + Counterexample”复审；Topic01/03/05/10 已完成当前轮定向补强**

## 1. 为什么重新开这一轮复审

上一轮《高数上册进阶》Source Diff 解决的是：Source 中的高价值训练知识是否有唯一 Owner、Practice 入口、资格与边界。

这仍不足以证明一本基础手册已经成熟。一个 Topic 可能同时满足：

- 母模型正确；
- 训练题型已经迁移；
- 但基础公式只能查表，不能重建；
- 特殊函数的常用性质分散；
- 概念反例不足以阻断错误逆推；
- 学生忘记某个公式后仍无法从定义/机制推出。

因此本轮不再按“缺哪个考法补哪个考法”审，而按每个 Topic 的**知识层级完整性**复审。

## 2. 新的七层验收模型

每个 Depth Topic 至少检查七层；Bridge/Integration 按自身身份缩减，不强行变成教材。

| 层 | 要回答的问题 | 失败表现 |
|---|---|---|
| 1. Object / Mother Model | 这一 Topic 真正操作什么对象？为什么需要这个模型？ | 只有章节目录或定义堆叠 |
| 2. Definition / Mechanism | 核心概念怎样从定义产生？关键机制为什么成立？ | 结论直接从天而降 |
| 3. Derivation / Reconstruction | 忘掉核心公式后，能否从更少的母式重新推出？ | 公式只能死背 |
| 4. Reference Coverage | 高频公式、特殊对象、典型表示是否有稳定反查入口？ | 理解很深但做基础题仍要到处翻资料 |
| 5. Boundary / Counterexample | 每个危险逆推能否给出最小反例或资格门？ | 只知道正向定理，不知道不能反推什么 |
| 6. Operational Practice | 题面信号、第一动作、路线、退出、验证是否可执行？ | 会解释但不会做题 |
| 7. Compression / Rebuild | 能否压成少量生成原则，并从压缩页重建主体？ | 压缩后只剩口诀 |

完整目标不是“每一层都写很多”，而是：

$$
\boxed{\text{Mechanism}\to\text{Reconstruction}\to\text{Reference}\to\text{Boundary}\to\text{Practice}}
$$

其中箭头表示**学习调用顺序**：先知道为什么，再能重新生成；生成成本高时允许快速反查；反查同时带边界；最后进入题目调用。

## 3. Canonical 与 Reference 的职责重新划分

### Canonical 正文必须拥有

- 定义与母问题；
- 公式的生成机制；
- 至少一个完整推导；
- 关键表示之间的转换；
- 不能反推的边界；
- 贯穿母例和独立验证。

### Canonical 附录 / Reference 锚点必须拥有

- 高频基础公式族；
- 常见特殊函数的当前 Topic 输出；
- 低阶 Taylor / 标准积分 / 坐标公式等速查；
- “该公式从哪个母式重建”的反查来源。

Reference 不是第二套知识 Owner。它只能保存结果和重建入口，不能重新解释一遍 Canonical 机制。

### Practice 必须拥有

- 题面识别；
- 第一动作；
- 分支选择；
- 具体例题；
- 陌生题重建训练。

## 4. 特殊函数必须按 Owner 切开，不再散落重复

以反三角函数为例：

| 信息 | 唯一 Owner |
|---|---|
| 为什么需要主值分支、定义域/值域、单射性、复合后的主值代表 | Topic01 |
| 导数为什么是倒数型、根号正负怎样由主值区间决定、有限局部展开 | Topic03 |
| 无限 Taylor series、收敛域、端点 | Topic11 / H-B05 |
| 用它做极限尺度或中值运输 | Topic02 / Topic04 只调用 |

同样的 Owner 切分要推广到指数、对数、三角、有理根式、特殊积分核、标准曲面等对象。

## 5. Topic03 第一轮复审结论

### 5.1 已有强项

当前 Canonical 已有稳定母模型：

$$
\text{Anchor}\to\text{Increment}\to\text{Normalize}\to\text{Coefficient}\to\text{Residual}\to\text{Order Upgrade}.
$$

点导数、微分、有限 Taylor、高阶导数、绝对值三结构、可导层级和局部几何的机制已较强。

### 5.2 暴露的真实缺口

1. 和差/乘积/商/复合/反函数/隐函数/参数方程虽有公式或简要推导，但缺少一张统一的“为什么这样记”的生成模型。
2. 商法则只有“倒数 + 乘积”的说明，没有完整展示倒数局部模型如何产生负号和平方分母。
3. 反函数/隐函数/参数式缺少足够具体的 worked example，基础规律与资格门没有完全粘在一起。
4. 常用导数附录过薄：没有系统覆盖一般指数/对数、cot/sec/csc、反三角导数及其重建来源。
5. 常见有限 Taylor 锚点过薄，没有形成“母式 → 可派生函数”的重建树。
6. 反例虽然正文已有多个，但缺少快速反查的“错误逆推 → 最小反例 → 缺失条件”索引。

### 5.3 本轮已完成更新

- Canonical 新增“局部增益”统一模型：并联、串联、倒数、取逆、约束、参数换速率。
- 显式推导商法则的倒数来源。
- 用 $\arcsin$ 演示“主值反函数 → 导数 → 根号符号”，并加入 $x^3$ 的逆导数边界。
- 隐式关系加入完整总微分示例及 $F_y=0$ 的表示边界。
- 参数曲线加入一阶/二阶导完整示例及 $x'=0$ 的边界。
- 附录扩充常用导数族与有限 Taylor 母式，并为每个公式族登记重建来源。
- 新增反例锚点表。
- 新增 Practice `求导法则与特殊函数.md`，专门训练忘公式后的重建。
- 追加双曲/反双曲函数：从 $e^x,e^{-x}$ 的奇偶分解生成 $\sinh,\cosh,\tanh$，再由反函数机制生成 $\operatorname{arsinh},\operatorname{arcosh},\operatorname{artanh}$ 的导数与有限展开；$\operatorname{arcosh}(1+h)\sim\sqrt{2h}$ 作为端点边界。

## 7. 优先顺序

按“基础公式调用频率高 + 当前 Reference 层相对薄 + 容易死记”的风险排序：

1. **Topic03**：本轮已补；做陌生题验证。
2. **Topic05**：积分公式和方法最容易退化成口诀，下一重点。
3. **Topic10 + Topic11**：判别法/展开式如果没有反例网络与母函数生成，很容易变成列表。
4. **Topic12**：ODE 分类与标准解法需要从状态/算子统一，而不是题型名词表。
5. Topic02 / Topic04：补定理反命题、资格和 Reference 层。
6. Topic06 / 07 / 08 / 09：按对象—表示—微元/线性映射逐册复审。
7. Topic01：现有对象/反函数结构已经较强，主要检查特殊函数族的 Reference 与向后接口，不因文件很长就默认完整。

## 8. 本轮完成标准

一个 Topic 不能再仅因“Source Diff 完成”或“Canonical 有母模型”标记为基础知识已充分迁移。至少要同时通过：

1. **Generation Test**：随机遮住核心公式，能从更少的母式重新推出；
2. **Reference Test**：基础公式和特殊对象能在唯一位置快速反查；
3. **Counterexample Test**：关键错误逆推至少有一个最小边界对象；
4. **Worked-Example Test**：每个非平凡机制/分支至少有一个具体例；
5. **Owner Test**：定义、有限局部模型、无限展开、区间性质没有重复拥有；
6. **Practice Test**：看到题能进入明确训练入口；
7. **Compression Test**：一页压缩仍能重新生成主体，而不是只剩公式表。

在这些测试完成前，状态只能写“机制已有 / 待基础生成层复审”，不能写“完整”。
