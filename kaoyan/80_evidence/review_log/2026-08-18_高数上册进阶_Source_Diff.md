| `(0,1)+(1,∞)` 后只倒代换尾部 | 同上 | Update |
| `ln x/(1+x^2)` 一类乘法反对称 | 同上 | Update；$x↔1/x$ 产生 `I=-I` |
| $x=tan t` 把 `(0,∞)` 压成 `(0,π/2)` | 同上 | **Update**；仅在 Jacobian 消掉 `1+x^2` 且有限区间对称有收益时使用 |
| 反常积分中直接制造 `∞-∞` | 同上 | **Reject 作为计算步骤**；退回有限截断层完成抵消 |

## 15. Source 级纠偏 / 不按原话迁移的内容

1. **递减递推绝对化**：Source 中“递减函数迭代必使原数列不单调、奇偶子列必分别单调”不稳定；已改为 `φ∘φ`、不变轨道、二周期与单调性分别证明。
2. **半角‘万能代换’**：保留“理论上可把三角有理式局部有理化”，但降级为统一保底；奇偶代换、线性配对、积化和差、缩分母通常先查。
3. **积分中值点默认开区间**：不保存无条件口号；见证点位置由具体定理资格和非退化条件决定。
4. **无限区间 Rolle 把 `∞` 当端点**：改为“极限信息 → 选择有限截断 `R` → 内点极值/Fermat”。
5. **反常积分的代数拆分与分部**：任何可能出现发散项相减的步骤都先保留共同截断；不把形式恒等式自动升级成反常积分可分性。
6. **导函数无穷间断表述**：限定在函数在该开区间处处可导的内部点；单向 `±∞` 极限被阻断，但无界振荡型第二类间断允许出现。
7. **几何面积与带符号积分**：曲线跨轴/振荡时，实际面积要按绝对值/分区；不把有向定积分值当几何面积。
