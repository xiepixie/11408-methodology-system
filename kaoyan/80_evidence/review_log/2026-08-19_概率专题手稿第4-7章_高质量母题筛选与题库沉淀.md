## 1. 本轮目标

上一轮已经完成“源稿知识是否有唯一 Owner”的核销。本轮不再重复问知识有没有出现，而改问：

> 哪些题能够作为少量、高生成力的母题，训练识别、第一动作、边界和校验？

筛选时优先保留同时满足以下条件的题：

1. 能代表一个稳定机制，而不是只换数字；
2. 至少能生成两种以上常见变式；
3. 能暴露识别、路径、执行或检查中的典型断点；
4. 能与当前 Canonical / Practice 的母模型形成明确 Model Anchor；
5. 题面能够从 Source 中可靠恢复；明显 OCR 污染处只保留可独立确认的数学语义；
6. Smart Error Archive 中没有已经承担同一训练责任的高质量重复题。

因此，本轮不是“源稿有多少题就入多少题”，而是把几十道同构练习压缩成少量代表性问题族。

## 3. 为什么这 11 道比逐题搬运更有价值

### P05：数字特征

源稿在数字特征部分有大量“给密度求 E/D”“相关系数”“条件期望”“max/min”练习。若逐题搬运，会形成大量只换数字的重复题。

本轮压成三种真正不同的母模型：

- 极值只问数字特征时先做代数降维；
- 只有一二阶信息时只能输出概率界；
- 条件生成结构优先全期望/全方差，不先恢复完整联合密度。

普通的固定和 `X+Y=c -> ρ=-1`、重复的直接积分题继续作为 Merge Evidence，不单独占用题库入口。

### P06：大数定律与中心极限定理

源稿中 Poisson、Uniform、Bernoulli 的 CLT 题非常多，但底层动作高度同构。保留一题“非标准系数标准化”即可攻击最核心的执行断点：

```text
先写标准 CLT
-> 再把题中量化成标准量的常数倍
-> 最后移动 Φ 的自变量
```

二项/Poisson 换皮继续作为变式，不重复入库。

### P07：抽样分布

源稿中的 χ²/t/F 练习数量很多，其中大部分其实都在考同一条生成链。将“绝对值分母得到 t”“t² 与 1/t²”“两总体方差比”合并成一个三问母题，可以一次攻击：

- 标准化尺度；
- 独立资格；
- 自由度来源；
- F 分子/分母顺序；
- 平方与倒数变换。

现有 Archive 已有若干单独的 χ²/F 构造题，因此不再复制同构题。

### P08：统计推断

MLE 的十题组被压成三种真正不同的结构：

1. 固定支撑、内部驻点型：现有 Archive 已有多个代表题，不再重复；
2. 参数进入支撑、边界型：本轮用 `U(0,θ)` 与 `[η,1]` 两题合并成“max/min 对照母题”；
3. 多样本共同估计同一参数：保留 2022 双指数总体型，训练统一参数账本。

估计量评价不再只背“无偏、有效、相合”三个名词，而由两道题分别覆盖有限样本无偏/方差与大样本相合性。

区间估计保留对数正态参数函数题，因为它不仅会套区间公式，还要求把置信集合通过严格单调参数映射继续传递。

假设检验不再重复录入普通 Z/t 单侧题，而保留复合原假设 + α/β 的题，强制区分“边界最不利参数”与“原假设本身是一个集合”。

## 4. 明确没有逐题入库的内容

以下 Source 内容已审阅，但不单独进入 Smart Error Archive：

- 多道只更换样本值的离散型 MLE；
- 多道固定支撑连续 MLE，只重复“log likelihood -> 求导”；
- 置信区间长度随 `σ/n/1-α` 变化的多个选择题：保留为结果趋势检查，不单独占一个母题；
- 显著性水平从 0.05 改成 0.01 的多个同构选择题：机制已经下沉到 `假设检验.md` 的拒绝域嵌套规则；
- 相关系数 `X+Y=c -> ρ=-1` 的硬币/木棒多题：作为固定线性约束的同构证据合并；
- `D(S²)`、`E(S⁴)` 等只重复 χ² 矩计算的题：已由母题 7 和抽样分布训练入口承接；
- Source 中把 CLT 写成有限样本“直接服从正态”、以及二项近似的粗阈值口诀：不按原文入库，只保留修正后的渐近/近似身份；
- OCR 导致符号、分母、自由度或区间端点损坏的题：只有能由题面与当前 Canonical 独立恢复的部分才进入母题。

## 6. 当前结论

本轮继续审阅后，前一轮“知识 Owner 无遗漏”的结论仍成立，但训练证据层确实新增识别出两个值得独立入库的缺口：

- 条件生成模型的全期望/全方差闭环；
- `MLE -> 样本矩 -> LLN -> 相合性` 的跨 Topic 评价闭环。

两题已补入 Smart Error Archive。当前第 4--7 章的 Source 不再存在“明显高价值、机制独立、且尚未被训练手册或母题池承接”的题组；剩余内容主要是同构变式、基础演算、公式复述或 Source/OCR 噪声。
