# B10｜样本中心化与正交投影：自由度与抽样分布

> 类型：Bridge
> 状态：待人工确认；本轮由跨学科 Bridge Gate 新增的 Canonical 候选。

## 定位

本 Bridge 连接线性代数的正交投影/子空间维数与概率统计的样本均值、样本方差、卡方分布、自由度和正态样本下的独立性。

## 为什么会想到这座桥

- **表面现象**：统计里同时出现“样本方差除以 $n-1$”“离差平方和服从 $\chi^2(n-1)$”“正态样本下 $\bar X$ 与 $S^2$ 独立”“再组合出 $t$ 分布”。
- **解释断点**：这些结论若分别记忆，会显得像四条无关定理；尤其“为什么少一个自由度”很容易退化成口诀。
- **抽象提升**：样本向量 $X$ 可正交分成均值方向 $PX$ 与残差方向 $(I-P)X$；前者占一维，后者只剩 $n-1$ 维。对联合正态随机向量，正交/零协方差分量进一步独立，于是几何维数、卡方自由度和统计独立性被同一分解串起来。

B10 因此是从概率 Topic07 中多个反复出现的“$n-1$ 现象”反向寻找共同上游模型后得到的；它代表一种典型的**由多个孤立结论倒推出缺失 Bridge** 的发现方式。

## 两侧 Owner

- 线代 Topic01/B00：内积、正交投影；Topic03：子空间、秩与自由度；

## 母接口

对样本向量 $X=(X_1,\ldots,X_n)^T$，令 $\mathbf 1=(1,\ldots,1)^T$，则

$$
P=\frac1n\mathbf1\mathbf1^T,
\qquad R=I-P.
$$

$PX=\bar X\mathbf1$ 是均值方向上的投影向量，$RX=X-\bar X\mathbf1$ 是正交残差；若用单位均值方向 $e_1=\mathbf1/\sqrt n$，对应投影坐标其实是 $e_1^TX=\sqrt n\,\bar X$。因此“样本均值、单位方向坐标、投影向量”必须分开。$R$ 的秩为 $n-1$，这给出残差自由度的几何来源；独立同分布且二阶矩有限时再得到 $E[S^2]=\sigma^2$，正态样本下两个正交投影分量才进一步独立。

## 边界

- “正交推出独立”只在联合正态等额外结构下成立；
- $n-1$ 不是一般“估计一个参数就减一”的万能口诀，而来自当前线性约束/投影的秩；
- 本 Bridge 不展开一般线性模型、Cochran 定理或回归 ANOVA，只作为 Extension 指针。
