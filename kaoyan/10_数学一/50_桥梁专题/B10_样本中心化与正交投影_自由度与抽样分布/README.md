# B10｜样本中心化与正交投影：自由度与抽样分布

> 类型：Bridge

## 定位

本 Bridge 连接线性代数的正交投影/子空间维数与概率统计的样本均值、样本方差、卡方分布、自由度和正态样本下的独立性。

- 线代 Topic01/B00：内积、正交投影；Topic03：子空间、秩与自由度；
- 概率 Topic07：总体、样本、样本均值、样本方差与抽样分布；
- 本 Bridge 只 Own “均值方向 + 正交残差子空间”的几何分解及其统计翻译。

## 母接口

对样本向量 $X=(X_1,\ldots,X_n)^T$，令 $\mathbf 1=(1,\ldots,1)^T$，则

$$
P=\frac1n\mathbf1\mathbf1^T,
\qquad R=I-P.
$$

$PX=\bar X\mathbf1$ 是投影到均值方向，$RX=X-\bar X\mathbf1$ 是正交残差；$R$ 的秩为 $n-1$，这就是样本离差平方和的自由度来源。正态样本下，两个正交投影分量进一步独立。

## 边界

- “正交推出独立”只在联合 Gaussian 等额外结构下成立；
- $n-1$ 不是一般“估计一个参数就减一”的万能口诀，而来自当前线性约束/投影的秩；
- 本 Bridge 不展开一般线性模型、Cochran 定理或回归 ANOVA，只作为 Extension 指针。
