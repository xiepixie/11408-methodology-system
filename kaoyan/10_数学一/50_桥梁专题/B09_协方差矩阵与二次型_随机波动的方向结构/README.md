# B09｜协方差矩阵与二次型：随机波动的方向结构

> 类型：Bridge
> 状态：待人工确认；本轮由跨学科 Bridge Gate 新增的 Canonical 候选。

## 定位

本 Bridge 连接概率论“协方差/二维正态/线性组合方差”与线性代数“二次型、正半定、正交主轴”。核心问题是：为什么一张协方差矩阵能够同时编码任意方向上的波动强度？

## 为什么会想到这座桥

- **表面现象**：概率里线性组合方差总写成二次展开；二维正态等密度线又是旋转椭圆；协方差矩阵还会在线性变换下变成 $A\Sigma A^T$。
- **解释断点**：为什么协方差矩阵一定半正定？为什么零特征值表示某个线性组合没有随机波动？为什么特征向量会变成“主波动方向”？
- **抽象提升**：对任意方向 $a$，$a^T\Sigma a=\operatorname{Var}(a^TX)\ge0$。因此 $\Sigma$ 本身就在编码一个随机方向上的正半定二次型；谱分解只是把这套波动几何转到彼此正交的主方向上。

B09 最初正是从 Anti-Bridge“方差不是范数”附近继续追问出来的：表面类比是错的，但更精确的真实连接是**方向方差 = 协方差二次型**。

- 本 Bridge 只 Own `Var(a^T X)=a^T\Sigma a`、`Cov(AX)=A\Sigma A^T` 及其方向/正半定翻译。

## 母接口

若随机向量 $X$ 的协方差矩阵为 $\Sigma$，则任意确定方向 $a$ 上的线性观测 $a^TX$ 满足

$$
\operatorname{Var}(a^TX)=a^T\Sigma a\ge0.
$$

因此协方差矩阵天然是正半定二次型；正交对角化后，特征方向给出互不相关的主波动方向，特征值给出这些方向上的方差。

## 边界

- 不相关一般不推出独立；联合正态是额外加强条件；
- 协方差矩阵半正定不等于正定，退化时存在零方差线性组合；
- 本 Bridge 不展开主成分分析等超纲算法。
