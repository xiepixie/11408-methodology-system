# 特征结构：相似与对角化

> 状态：本轮审阅与训练闭环补全完成；已发布。Canonical LaTeX、Active Practice 与 Published PDF 已同步，等待最终人工确认。

## 为什么值得读

特征值不是“矩阵里一组特殊数字”。真正的问题是：**一个同空间线性算子有没有作用后仍停在原方向的一维自然轴；这些自然方向是否足够组成整个空间的一组基？**

一旦这件事说清，相似、特征方程、重特征值、对角化、矩阵幂与实对称矩阵都落到同一条主线上。

## 母问题

> **怎样找到算子不混合的自然方向，并判断这些方向能否组成完整坐标系？**

主线是：

```text
同空间算子
-> Av = λv
-> (A-λI)v = 0
-> χ_A(λ)=0
-> E_λ = ker(A-λI)
-> 数独立特征方向
-> 是否能组成特征基
-> 对角化
```

## 本册覆盖到哪里

本 Topic 负责：

- 同空间算子与相似关系；
- 特征值、特征向量、特征子空间；
- 特征多项式、trace / determinant 的谱摘要；
- 不同特征值特征向量的无关性；
- 代数重数、几何重数与可对角化判据；
- 同谱不等于相似及可对角化情形下的反向判定；
- 矩阵幂与矩阵多项式在特征方向上的降维，以及由完整谱信息反求矩阵；
- 实对称矩阵的标准正交特征基；
- $AB$ 与 $BA$ 的非零谱/trace 关系、一方可逆时的相似构造；
- 可交换矩阵保持特征子空间与同时对角化的边界；
- Jordan 形只作为超出数学一主线的 Extension 边界。

本 Topic **不负责**：

- 一般矩阵等价与 rank 分类；
- 二次型合同、惯性和正定判别；
- Jordan 标准形的具体计算。

以下均为 Active Practice；Canonical `.tex` 只拥有理论机制，不重复拥有题面路由。各训练册保留源手稿代表母题，让“触发信号 → 第一动作 → 停止 → 验算”能在具体题面上完整运行；专题22–29 的逐项覆盖见 [源资料母题覆盖索引](../源资料母题覆盖索引.md)。

- [特征值速算与对角化判定](特征值速算与对角化判定.md) —— 可见特征方向、抽象基作用、矩阵多项式与谱映射、trace/determinant 摘要、重根几何重数、相似边界与实对称正交化；明确阻断“秩一必有非零特征值”“同谱即相似”以及“正交矩阵全部特征值只能为 $\pm1$”。
- [特殊矩阵的多项式约束](特殊矩阵的多项式约束.md) —— 对合/幂等/幂零矩阵统一读成低次零化多项式，训练加法/乘法闭包为何受交换性控制，并用实对称谱结构阻断错误反推。
- [反求矩阵与矩阵幂](反求矩阵与矩阵幂.md) —— 已知谱、行和、kernel、rank 或部分特征方向时先补齐完整特征基，再用 $A=P\Lambda P^{-1}$ / $A=Q\Lambda Q^T$ 反构；矩阵幂只在自然坐标中对特征值做幂。
- [$AB$ 与 $BA$ 及可交换矩阵](AB与BA及可交换矩阵.md) —— 区分“比较 $AB,BA$”与“已知 $AB=BA$”两类题；覆盖非零谱、trace、rank 边界、一方可逆时相似，以及可交换到共同特征基的升级条件。
