# 线性代数训练闭环索引

> 性质：Practice System 的总索引，不拥有稳定理论。六册 Canonical `.tex` 负责机制与证明；本索引只回答“这个知识在什么题面出现、第一动作去哪本训练手册、最后怎样验证”。  
> 覆盖原则：**核心知识不遗漏，理论不重复拥有。** 某结论若只用于证明或 Extension，不强行复制成题型技巧；只要它进入数学一主线的独立决策，就必须有明确 Practice Owner。

## 1. 全科调用协议

任何线代题先执行：

```text
交付目标
→ 数学对象
→ 当前表示
→ 允许的变换
→ 可靠不变量
→ 最简合法表示
→ 原关系独立校验
```

具体问题族再进入下面对应 Practice。这里的箭头表示**做题检查顺序**，不是数学蕴含。

### 母题保留规则

Practice 不能只剩“触发信号 + 口诀”。对每个会改变第一动作的独立机制，至少保留一个能完整运行

$$
\text{题面}\to\text{识别}\to\text{第一动作}\to\text{核心计算}\to\text{独立校验}
$$

的母题。母题用于把抽象模型落地并支持以后重建；同一机制的换皮题不为了数量重复保存。上传资料进入仓库时，先做“机制 → Owner → 母题”映射，再决定是否需要新增例题。第五章与第六章本轮逐专题审计见：[源资料母题覆盖索引](源资料母题覆盖索引.md)。

## 2. Topic01｜向量空间：生成、基与坐标

|---|---|---|---|

| Core | Schmidt、规范正交基、正交矩阵参数约束 | [正交化与正交矩阵](01_向量空间_生成基与坐标/正交化与正交矩阵.md) | 检查两两正交/单位长度与 span 保持；determinant 只作 Topic02 后的 Integration Check |

**Canonical-only / Bridge 边界**：内积与投影的跨学科调用由 B00 Own；Fourier 正交投影接口由 B08 Own。

## 5. Topic04｜线性方程组：可达性与解空间

| 核心训练对象 | Active Practice Owner | 交付/退出 |
|---|---|---|
| 普通/参数系统相容性、无/唯一/无穷多、基础解系、通解、多个非齐次解 | [参数方程组与通解结构](04_线性方程组_可达性与解空间/参数方程组与通解结构.md) | 先判 fiber 是否存在；$A$ 固定而 $b$ 变时优先用 left-kernel 兼容条件，$A$ 变时先找 rank 跳变；有解后交付 $x_0+\ker A$ |
| $AX=B$、$XA=B$、矩阵通解、Cramer 资格与边界 | [矩阵方程与 Cramer 边界](04_线性方程组_可达性与解空间/矩阵方程与Cramer边界.md) | $AX=B$ 看列空间，$XA=B$ 看行空间；只问存在/唯一/自由度时停在子空间/rank 层；Cramer 失格后回到 fiber |
| 公共解、解集包含、齐次/非齐次同解 | [公共解与同解问题](04_线性方程组_可达性与解空间/公共解与同解问题.md) | 统一为 fiber 的交/包含/相等；公共解堆叠为 product-map fiber，齐次看 kernel/row，非齐次看基点 + 方向；优先最高信息量表示 |

**统一母模型**：

$$
\mathcal F_A(b)=
\begin{cases}
\varnothing,&b\notin\operatorname{Im}A,\\
x_0+\ker A,&b\in\operatorname{Im}A,
\end{cases}
\qquad
\mathbb R^n/\ker A\cong\operatorname{Im}A.
$$

训练时把它拆成三个连续问题：**fiber 是否存在 → fiber 内部还有多少自由方向 → 多个 fiber 之间是交、包含还是相等**。若需要不可达的独立证书，可转为 $y^TA=0$ 但 $y^Tb\ne0$ 的 left-kernel 关系。

## 9. 完成一次训练后必须记录的五个节点

对陌生题或错题，不只记录“答案错了”，至少标记：

1. **目标**：最终交付是什么；
2. **对象**：向量组、一般映射、算子、逆像还是二次型；
3. **第一动作**：第一次真正改变问题难度的动作；
4. **停止条件**：什么时候已经够了；
5. **独立验证**：不用原路线重算一遍，怎样检查结果。

若错误发生，记录第一次偏离正确链的位置（First Divergence），再决定是补知识、补边界还是补训练接口。

## 10. Canonical 主干覆盖审计：没有独立 Practice 不等于知识遗漏

Practice 只拥有题面路由与行动控制；下面这些内容继续由 Canonical 唯一拥有，因为它们主要承担定义、证明或生成机制，已经被相应 Practice 调用，不应复制成第二套理论正文。

| Topic | Canonical-only 主干机制 | 为什么不另建 Practice |
|---|---|---|
| 01 | 向量空间公理、基存在后的维数一致性、内积定义与投影证明 | 题面动作已落在表示/基/子空间/正交 Practice；证明仍回 Canonical |
| 02 | 矩阵加法数乘的类型来源、determinant 的排列定义与交替多线性证明、Laplace 合法性、常见结构矩阵的对象解释 | 运算路线、方向、determinant 与伴随题族已有 Active Practice；复制证明会产生双 Owner |
| 03 | rank--nullity、行秩=列秩、等价标准形存在性的证明 | Practice 直接调用这些定理做维数账本、RREF、rank 边界，不重复证明 |
| 04 | 消元为何保持原变量解集、逆像/仿射解集的统一证明 | 三本 Topic04 Practice 已分别覆盖相容性通解、矩阵方程/Cramer、公共解/同解 |
| 05 | 不同特征值特征向量无关性的证明、特征子空间在相似下的搬运、实对称谱定理证明 | 训练文件负责何时调用与怎样验证；证明仍只由 Canonical Own |
| 06 | 对称矩阵表示唯一性、Sylvester 惯性定理及合同下 rank/determinant 机制的证明 | Practice 已覆盖标准化、惯性、正定/半定与相似—合同边界，不复制理论 |

因此本体系中的“完整”定义为：**数学一主线每个独立做题决策都有 Active Practice；每个定义/定理/证明都有唯一 Canonical Owner；Extension 被显式标记而不偷偷进入默认路线。**

## 11. 全科最后压缩

```text
向量组 → span / 基 / 坐标
一般映射 → 矩阵表示 / 等价
自由度 → kernel / image / rank
给定目标 → 可达 + x0 + kernel
同空间算子 → 特征方向 / 相似 / 对角化
二次型 → 合同 / 惯性 / 正定
```

遇到陌生题，先问：

$$
\boxed{
\text{我现在研究的对象是什么？允许怎样换表示？什么结构必须保持？题目到底要我交付什么？}
}
$$
