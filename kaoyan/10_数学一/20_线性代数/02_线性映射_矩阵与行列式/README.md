# 线性映射、矩阵与行列式

> 状态：待人工确认；已发布。Canonical LaTeX 第一版正文与 PDF 已建立，等待内容确认。

## 为什么值得读

矩阵为什么要这样乘？为什么同一个线性映射换一组基以后，矩阵会变成左右同时乘可逆矩阵？为什么行列式能判断可逆，却不能告诉你究竟丢了多少个自由度？

这些不是三组孤立公式。它们都来自同一个事实：**矩阵是线性作用在选定坐标系中的记录。**

## 母问题

> **怎样把抽象线性作用变成可计算的有限数据；当作用由方阵表示时，又怎样判断它是否把满维信息压扁？**

主线是：

```text
线性映射
-> 选定定义域/陪域基
-> 矩阵表示
-> 矩阵运算 = 映射运算
-> 两端换基 Q^{-1} A P
-> 方阵可逆
-> determinant 检测满维塌缩
```

## 本册覆盖到哪里

本 Topic 负责：

- 线性映射怎样由基向量的像唯一确定；
- 矩阵表示及矩阵尺寸的映射意义；
- 加法、数乘、矩阵乘法与复合；
- 一般线性映射的两端换基公式；
- 左乘、右乘、初等矩阵与逆矩阵；
- 行列式的交替多线性与有向体积解释；
- determinant 的基本性质、余子式展开与伴随矩阵；
- 三角、正交、反对称、分块等直接服务上述机制的结构结论。

本 Topic **不负责**：

- rank-nullity、kernel/image 与矩阵等价的完整机制；
- 给定 $Ax=b$ 的相容性、通解和基础解系；
- 相似、特征结构与对角化；
- 二次型合同、惯性与正定性。

这些内容分别交给 Topic03、Topic04、Topic05、Topic06。
