# 置信区间与假设检验

> 训练定位：训练参数推断题中先锁定输出类型，再从抽样分布构造枢轴、区间或拒绝域，并把“覆盖率、第一类/第二类错误、不拒绝”放在正确的概率语义层。  
> 模型归属：[参数估计与假设检验.tex](参数估计与假设检验.tex)；区间估计、检验与错误概率的理论机制仍由该 Canonical 正文拥有，本文只维护局部训练动作。

## 决策地图

```text
参数推断
→ 目标是估计量 / 区间 / 检验？
→ 样本模型与统计量
→ 精确还是渐近标尺
→ 枢轴 / 拒绝域
→ 反解参数或计算错误概率
→ 检查覆盖、尾部与结论语义
```

### 局部规则：每个子问先锁定唯一输出类型

**触发信号**：同一题连续要求估计、无偏/MSE、置信区间、检验或错误概率。

**第一动作**：在草稿写清当前交付物：估计量、评价结论、区间/限、拒绝域、$p$ 值或错误概率；完成一个子问后重新读下一问，不沿用上一个损失函数/约束。

**检查与退出**：无偏系数不自动用于最小 MSE；“构造估计量”与“评价估计量”是两步。当前交付物闭合后停止向下一推断层越级。

### 局部规则：区间估计先找无未知参数枢轴

**触发信号**：置信区间、置信限、覆盖率。

**第一动作**：根据总体条件与已知/未知方差，先找分布不含未知参数的 $Z,t,\chi^2,F$ 或渐近枢轴，再按规定尾部反解参数。

**检查与退出**：覆盖率描述重复抽样随机区间，不把固定参数写成“以某概率落入已算出的区间”；偏态分布的上下分位点顺序按不等式实际反解。端点、置信水平、单/双侧和精确/渐近性质齐全后停止。

### 局部规则：检验先由备择方向决定尾部

**触发信号**：给 $H_0,H_1$、显著性水平或要求构造拒绝域。

**第一动作**：先固定 $H_0,H_1$；备择 $>$ 走右尾，$<$ 走左尾，$\ne$ 走双尾，再在 $H_0$ 下校准统计量和拒绝域使尺寸不超过 $\alpha$。

**检查与退出**：不能看完样本后改变尾部；检验统计量的精确/渐近资格必须与 Topic07 输出一致。拒绝域闭合后再代观测值，不反过来调阈值。

### 局部规则：第一类与第二类错误必须在不同参数世界计算

**触发信号**：要求 $\alpha,\beta$、功效或给定具体备择参数。

**第一动作**：第一类错误在 $H_0$ 参数下计算拒绝概率；第二类错误在指定备择参数下计算“不拒绝”概率，功效为 $1-\beta$。

**检查与退出**：第二类错误不能继续使用 $H_0$ 的抽样分布参数；若备择是复合的，$\beta$ 一般随真实参数变化。目标参数点的错误概率得到后停止泛化成全备择结论。

### 局部规则：$p$ 值只在 $H_0$ 下衡量“至少同样极端”

**触发信号**：要求 $p$ 值或用 $p$ 值作检验结论。

**第一动作**：在 $H_0$ 下按备择方向计算观测统计量及更极端区域的概率。

**检查与退出**：$p$ 值不是 $H_0$ 为真的概率，也不是效应大小；比较 $p$ 与预先给定的 $\alpha$ 后给“拒绝/不拒绝”结论即可。

### 局部规则：推断结论最后做独立合理性检查

**触发信号**：已经得到区间、错误概率或检验结论。

**第一动作**：至少做一个不同于原推导的检查：概率在 $[0,1]$、区间端点顺序、样本量增大时区间宽度/功效趋势、备择远离零假设时功效趋势。

**检查与退出**：不拒绝 $H_0$ 不能改写为“接受/证明 $H_0$”；合理性检查失败时优先回到尾部、标准化尺度和真实参数世界，而不是只调数值。
