## 待验证

### 复合题结束前运行全科概念边界与结果终检

**触发信号**：一道题跨过事件、分布、数字特征、极限定理、抽样分布或统计推断中的两个以上层级，或者计算已经结束但存在多个条件、自由度、支撑或结论语言需要同时回检。

**第一动作**：先用下面的跨专题边界表检查自己有没有把“相似对象”偷换成同一个对象：

| 概念 A | 概念 B | 真正区别 | 最常见误用 |
|---|---|---|---|
| 互斥 | 独立 | 不能同时发生；知道一个是否发生不改变另一个概率 | 把交概率既写成 $0$ 又写成乘积 |
| 条件概率 | 联合概率 | 在给定信息世界重新归一化；同时发生的概率 | 漏除条件事件概率或把条件方向交换 |
| 全概率 | 贝叶斯公式 | 沿来源正向汇总结果；观察结果后反向重分配来源权重 | 把“原因到结果”和“结果追原因”写反 |
| 分布函数 | 概率密度 | 累积概率；单位长度上的概率强度 | 把 $f(x_0)$ 当作 $P(X=x_0)$ |
| 二项计数 | 超几何计数 | 固定次数独立重复；固定有限总体不放回 | 只看“成功次数”就套二项 |
| 边缘分布 | 条件分布 | 忽略另一个变量；固定另一个变量后重新归一化 | 把积分消元与条件除法混用 |
| 独立 | 不相关 | 联合分布完全解耦；只消除线性协变 | 由协方差为零直接推出独立 |
| 大数定律 | 中心极限定理 | 平均稳定到哪里；标准化误差是什么形状 | 把两者画成前后推出关系 |
| 参数 | 统计量 | 固定但未知的模型量；抽样前仍随机的样本函数 | 对参数谈抽样概率，或让统计量含未知参数 |
| 统计量 | 估计量 | 任意合法样本函数；承担参数估计任务的统计量 | 看见样本函数就自动讨论无偏性 |
| 估计量 | 估计值 | 抽样前的随机规则；代入本次样本后的具体数值 | 对固定数值再讨论期望与方差 |
| 无偏性 | 相合性 | 有限样本平均偏差为零；样本量增大时收敛到真值 | 把两种评价标准当成同义词 |
| 正态标尺 | $t$ 标尺 | 总体方差已知时可直接标准化；未知且正态样本时用 $S$ 引入额外随机尺度 | 只按样本量大小选择 $Z/t$ |
| $\chi^2$ 标尺 | $F$ 标尺 | 标准化平方和；两个独立方差尺度之比 | 没检查独立性和自由度就套分布 |
| 置信水平 | 后验概率 | 构造程序在重复抽样中的目标覆盖率；经典参数本身不是随机变量 | 把“95% 置信”解释成参数有 95% 概率落在已经算出的固定区间内 |
| 显著性水平 | $P(H_0\text{ 为真})$ | 第一类错误风险上限；不是原假设的后验概率 | 把 $\alpha$ 解释成“原假设为真概率” |
| 不拒绝 $H_0$ | 证明 $H_0$ 为真 | 当前证据不足以拒绝；逻辑上证明命题成立 | 把检验结论写成“接受并证明原假设正确” |

随后跑八项结果终检：

1. 概率是否落在 $[0,1]$；离散质量和、连续密度积分或混合总质量是否为 $1$？
2. 分布函数是否单调不减、右连续，并具有正确两端极限；跳跃是否与点质量一致？
3. 支撑、事件原像、积分区域和变换后的值域是否前后一致？
4. 期望/矩是否存在；方差是否非负；相关系数只在两个方差正且有限时使用，并落在 $[-1,1]$？
5. 独立性是否真的有乘积分解、条件恒等式或联合结构证据，而不是由零协方差、边缘相同或函数外形猜测？
6. 统计量/估计量表达式是否偷偷含未知参数；估计结果是否落在参数空间并满足样本可行域？
7. 标准化尺度、自由度、分位点方向、单侧/双侧与“精确/近似/上界”身份是否一致？
8. 最终输出是否回答题目真正要求的层级，并使用“拒绝/不拒绝”等准确统计语言而不过度下结论？

**检查与退出**：这是一层复合题终检，不替代局部 Topic 的验算。若某项失败，回到对应 Owner 修正；八项均通过且最终输出与目标一致后停止，不为“检查完整”重新做已经闭合的中间计算。

**现有支持**：旧版概率总图的概念边界与八项校验、1987--2025 真题 Owner/证据矩阵都支持这组跨层控制；仍缺使用者无提示陌生题表现，因此暂不升级为“已采用”。

### 复合题按层交接，不跳过中间随机对象

**触发信号**：一题中先由连续变量或分段赔付生成事件，再给出事件次数的 Poisson/二项条件模型，最后要求总次数或总赔付分布。

**第一动作**：为每层写出明确输出：
$$
X\xrightarrow{\text{变换}}Y\xrightarrow{\text{事件指示}}I=1_{\{Y>0\}}
\xrightarrow{\text{条件计数}}M\mid N=n\sim\operatorname{Bin}(n,p)
\xrightarrow{N\sim\operatorname{Pois}(\lambda)}M.
$$
先求 $p=P(Y>0)$ 或 $E(Y)$，再在条件层写二项，最后对 $N$ 全概率求和；只有条件闭合后才调用 Poisson thinning 得 $M\sim\operatorname{Pois}(\lambda p)$。

**检查与退出**：支撑、事件阈值与成功事件必须前后一致，$p\in[0,1]$；薄化参数应为 $\lambda p$。只问理赔次数时在 thinning 结果停止；若问总赔付额，必须保留正赔付额的条件分布并转复合 Poisson/卷积。题面没有明确条件生成链时，不凭“发生次数”套薄化。

**现有支持**：2001 Q十一、2025 复合题等跨表面题面支持这条交接结构；仍缺使用者无提示调用与明确采用决定。

### 独立性按信息阶数逐项验收

**触发信号**：题面出现“两两独立、相互独立、独立于某事件/某组”，或需要把交集、协方差、联合密度拆成乘积。

**第一动作**：先标注题面实际给出的独立阶数；两两独立只处理二重交，不能自动处理三重或更高阶交；“$A$ 分别独立于 $B,C$”也不能推出 $B\perp C$。复杂并集/交集先拆成可核对的块，再逐块注明使用的是独立、互斥还是条件信息。

**检查与退出**：三事件至少分别检查二交与三交；条件独立先在每层乘法，再混合检查边缘交集；独立性证据必须来自乘积结构、联合分布分解或条件概率恒等式，不能由零协方差或边缘相同猜出。目标已由题面给定阶数完全确定后停止继续假设。

**现有支持**：跨年代真题反复支持“阶数闸门”，但仍缺使用者无提示调用与明确采用决定。

### 先定目标层与随机对象，再选择表示

**触发信号**：题目同时给出多个概率对象或多个潜在出口，尚未明确究竟要求概率、分布、数字特征、抽样标尺还是统计推断结论。

**第一动作**：先写清目标类型、当前对象（事件/随机变量/随机向量/样本/统计量）与已知条件，再判断当前核心操作是条件化、边缘化、变换、摘要、近似还是推断，最后选择事件代数、CDF/PMF/PDF、联合支撑、期望或抽样分布等表示。

**检查与退出**：每个式子的对象类型应与最终目标一致；若题目只求一个数字却开始构造远强于目标的完整分布，重新比较路径成本。对象和操作明确后立即进入实质计算，不把清单变成形式负担。

### P01--P05 跨主题交接：中间对象决定下一步 Owner

**触发信号**：同一道题连续调用事件/计数、条件分层、联合或混合对象、完整分布与数字特征中的多个层级。

**第一动作**：每次交接都写出已经验收的中间对象，再决定下一 Owner：固定计数状态交 P01/P03；来源/阶段条件与权重交 P02；原子、连续段或 CDF 端点交 P03；联合支撑、截面或变换原像交 P04；只要求 $E,D,\operatorname{Cov}$ 或上界时交 P05。

**检查与退出**：交接前至少写清生成机制、支撑、质量是否归一与目标输出类型；交接后只执行下一个 Owner 的动作。目标在数字特征处已闭合时停止继续构造完整分布；目标要求完整分布或联合结构时才继续交接。
