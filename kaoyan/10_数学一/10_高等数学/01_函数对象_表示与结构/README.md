# 函数对象、表示与结构

> 状态：待人工确认；已建立唯一规范 LaTeX 工作稿，尚未完成使用者审阅。

## 为什么值得先学

“看见一个解析式”不等于“已经确认了函数对象”。定义域、分支、对应关系和输入变换决定了后续极限、微分、积分与展开究竟在研究什么。

## 母问题

怎样先确定当前函数对象，并在表示变换不改变对象的前提下，用四个问题组织函数性质：哪些输入合法？哪些输出可达？给定输出的原像是否唯一？输入之间的关系经过函数映射后对应什么函数值关系？

## 范围与停止边界

本册拥有：

- 定义域、陪域/值域、对应关系与“表达式不是函数”的对象边界，并用“输入合法性—输出可达性—原像唯一性—输入关系的映射规律”统一函数对象的四个基本问题；
- 显式、分段、隐式、参数表示及表示变换的信息损失；
- 根式、对数、分母、反三角等表达式的定义域条件，把“先写公式”改成“先检查输入是否合法”；
- 复合接口、反函数存在的单射/双射条件、限制定义域与分支选择、反三角主值分支为什么必要，以及反射、平移、奇偶、中心/轴对称；周期统一放进“固定平移下的函数值关系”中处理：$f(x+T)=f(x)$ 才定义周期，$f(x+L)=2b-f(x)$ 是可迭代生成周期的平移翻转关系，$f(x+L)=f(x)+C$ 则是纵向漂移；具体反解题型、主值代表的分段公式与局部技巧转由同目录训练 Markdown 承接；复合结构统一通过内函数在输入变换下的变化规律，以及外函数在对应变换下的函数值关系来判断；
- 单调、有界、单射等基础结构，以及坐标变换后的结构迁移；
- 两次反射生成平移、周期与已知对称轴/对称中心的联动、任意函数的奇偶分解和专题01最小调用接口。

本册不拥有结构经过极限、求导、积分、变上限积分、泰勒/傅里叶展开后的传播规律；这些交给 [H-B01｜函数结构在运算中的传播](../50_桥梁专题/H-B01_函数结构在运算中的传播/README.md)。单调性判定、极值、凹凸和零点的区间机制由 [专题04](../04_局部到整体_中值定理与函数形状/README.md) 负责。

## 归属与调用

- **本册拥有**：函数对象的确定条件、表示边界、复合与反函数的定义和基本机制（含接口、单射/双射条件、分支选择、主值分支与结构迁移）、反射与平移结构、基础函数结构；具体母题、反解技巧和主值分段公式由同目录训练文档拥有。
- **本册调用**：数学一课程总图与高等数学学科总图的母模型。
- **被调用**：专题02的极限与连续、专题03的一元局部模型、专题05的一元累积、专题11的函数展开，以及 H-B01。
