# 函数对象、表示与结构

> 状态：待人工确认；已建立 Canonical LaTeX 工作稿，尚未完成使用者审阅。

## Hook

“看见一个解析式”不等于“已经确认了函数对象”。定义域、分支、对应关系和输入变换决定了后续极限、微分、积分与展开究竟在研究什么。

## Mother Question

怎样确认函数对象的身份，在不改变对象的前提下切换表示，并从输入之间的稳定关系推出奇偶、对称、周期、单调和可逆等结构？

## Scope / Stop Boundary

本册拥有：

- 定义域、对应关系、值域与“表达式不是函数”的对象边界；
- 显式、分段、隐式、参数表示及表示变换的信息损失；
- 复合、反函数、反射、平移、奇偶、中心/轴对称、周期与半周期翻转；
- 单调、有界、单射等基础结构，以及坐标变换后的结构迁移；
- 两次反射生成平移、任意函数的奇偶分解和 Topic01 调用协议。

本册不拥有结构经过极限、求导、积分、变上限积分、Taylor/Fourier 后的传播规律；这些交给 [H-B01｜函数结构在运算中的传播](../50_桥梁专题/H-B01_函数结构在运算中的传播/README.md)。单调性判定、极值、凹凸和零点的区间机制由 [Topic04](../04_局部到整体_中值定理与函数形状/README.md) 负责。
