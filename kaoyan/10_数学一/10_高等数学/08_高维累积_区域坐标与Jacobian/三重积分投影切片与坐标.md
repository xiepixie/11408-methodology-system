# 三重积分投影切片与坐标

> 训练定位：训练三重积分中投影法/切片法分流、柱坐标/球坐标范围与结果复核，重点把空间区域编码成不重不漏的积分参数。  
> 模型归属：[高维累积_区域坐标与Jacobian.tex](高维累积_区域坐标与Jacobian.tex)；三维区域、坐标变换与高维累积机制仍由该 Canonical 正文拥有，本文只维护局部训练动作。

## 决策链

```text
空间区域
→ 比较投影法 / 切片法
→ 必要时选择柱坐标 / 球坐标
→ 写完整参数范围与微元
→ 计算
→ 用体积、量纲、对称与粗界复核
```

### 局部规则：三重积分先比较投影法与切片法

**触发信号**：空间区域、六种积分次序、旋转体、截面积，或被积函数主要依赖某一个坐标。传统题解若出现“先一后二 / 先二后一”，分别把它翻译成“投影穿针 / 截面切片”，不要把术语当成第三、第四种方法。

**第一动作**：并列试写两种降维表示：一个方向穿针得到上下曲面（先一后二）；固定高度先处理二维截面（先二后一）。比较哪一种分区更少、内层更易积。

**检查与退出**：投影域必须完整；切片法必须给出高度范围和每层真实截面。若被积函数只依赖外层坐标，优先检查能否直接写成“函数值 × 截面积”。某一路已经让区域不重不漏且内层最简时停止比较。

### 局部规则：柱坐标与球坐标先固定约定和角度范围

**触发信号**：圆柱、球、圆锥、径向函数，或大量出现 $x^2+y^2$、$x^2+y^2+z^2$。

**第一动作**：先写本题采用的坐标约定，再把每条几何条件逐条翻译成半径、角度和高度范围。

**检查与退出**：极/柱坐标微元保留 $r$；球坐标保留 $\rho^2\sin\phi$；角度不得重复覆盖。参数范围和微元闭合后再代入被积函数。

### 局部规则：三重积分结果用独立不变量闭环

**触发信号**：已经得到体积、质量、质心或复杂换元后的三重积分值。

**第一动作**：至少选一个不同于原推导的检查：令被积函数为 $1$、利用对称、检查量纲、做粗上下界或检查质心位置。

**检查与退出**：体积/质量不能无故为负；质心应落在质量分布凸包内；只有区域与密度共同保持相应对称时才可据此定位质心。独立检查通过后停止无目的化简。
