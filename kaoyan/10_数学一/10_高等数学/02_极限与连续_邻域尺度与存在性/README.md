# 极限与连续：邻域、尺度与存在性

> 状态：待人工确认；已建立唯一规范 LaTeX 工作稿，尚未完成使用者审阅。

## 为什么值得打开

极限不是把“无穷”当成一个数代进去，而是控制所有足够靠近的合法输入。连续性则要求这份邻域控制最终与点值接上。

## 母问题

在指定的趋近方式下，怎样证明所有足够靠后的输入都进入同一个输出邻域？当主导尺度发生抵消、路径分裂或点值错位时，怎样判断极限不存在、连续性失败或必须切换到其他知识归属专题？

## 范围与停止边界

本册拥有：

- 数列/函数/单侧/无穷远极限与存在性控制；
- 有限极限的局部有界性、保号性与不等式/次序传递；
- 夹逼、归结原则、无穷小阶与等价关系；
- 未定式判别、七类未定式的标准化与极限计算的知识层方法地图；
- 主导尺度、相消升级与连续接缝；
- 连续、间断分类、复合与运算的资格边界；
- 一阶递推数列的合法轨道、收敛发动机与不动点筛选。

本册不拥有：

- 函数对象、定义域与表示本体，交给 [专题01](../01_函数对象_表示与结构/README.md)；
- 有限泰勒、导数定义与局部线性模型，交给 [专题03](../03_一元局部模型_导数微分与Taylor/README.md)；
- 中值定理、闭区间存在性与函数形状，交给 [专题04](../04_局部到整体_中值定理与函数形状/README.md)；
- 变限积分、黎曼和、反常积分与级数尾部，交给 [专题05](../05_一元累积_原函数定积分与反常积分/README.md)、[专题10](../10_数项级数_尾部与敛散/README.md)；
- 单一极限/递推问题族中“看到什么信号先做什么、什么时候换路、什么时候停止”的控制动作由同目录训练 Markdown 维护；只有跨多个训练专题稳定复用并经证据验证的控制才晋升高等数学学科做题规则。未定式为什么要标准化、各种表示变换保留什么信息、各工具需要什么资格以及何时信息不足，仍属于本册规范正文，不能下沉到训练层代替机制解释。
