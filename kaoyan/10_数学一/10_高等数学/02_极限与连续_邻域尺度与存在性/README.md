# 极限与连续：邻域、尺度与存在性

> 状态：待人工确认；已建立 Canonical LaTeX 工作稿，尚未完成使用者审阅。

## Hook

极限不是把“无穷”当成一个数代进去，而是控制所有足够靠近的合法输入。连续性则要求这份邻域控制最终与点值接上。

## Mother Question

在指定的趋近方式下，怎样证明所有足够靠后的输入都进入同一个输出邻域？当主导尺度发生抵消、路径分裂或点值错位时，怎样判断极限不存在、连续性失败或必须切换 Owner？
