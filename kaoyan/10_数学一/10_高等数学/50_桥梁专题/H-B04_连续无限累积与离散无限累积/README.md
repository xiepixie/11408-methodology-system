## Position

高数 Topic05 ↔ Topic10 的内部 Bridge。

## Mother Interface

研究反常积分与数项级数如何共享同一个“有限截断 → 尾部稳定 → 无限对象”的构造逻辑。

## Owns

只拥有连续/离散无限累积之间的结构翻译：截断、Cauchy 尾部、比较、绝对收敛、条件抵消以及积分判别等接口。

## Uses

Topic05、Topic10。

## Boundary / Anti-Bridge

- “积分与级数同敛散”只在满足具体判别条件时成立；
- 连续与离散对象共享构造思想，不代表每个判别法可以逐字互换；
- 奇点、无穷远和级数尾部要分别处理其定义域结构。
