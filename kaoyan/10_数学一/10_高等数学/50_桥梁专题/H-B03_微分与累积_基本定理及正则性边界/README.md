## Position

高数 Topic03 ↔ Topic05 的内部 Bridge。

## Mother Interface

研究导数、原函数、Riemann 可积、变上限积分和 Newton–Leibniz 之间究竟在哪些条件下能够双向接通。

## Owns

只拥有“局部变化率 ↔ 累积函数”的接口契约和正则性边界；导数本体归 Topic03，积分本体归 Topic05。

## Uses

Topic03、Topic05。

## Boundary / Anti-Bridge

- 可导、存在原函数、Riemann 可积是不同资格；
- “积分和求导互逆”必须写清作用对象与成立条件；
- 不能把变上限积分可导性无条件推广到任意被积函数；
- 导函数不必连续，但必满足 Darboux 介值性；可去、跳跃、无穷间断不能直接作为导函数的内部间断，振荡间断则只表示“可能”，不是存在原函数的充分条件；
- 变上限积分在某点的导数可能由邻域极限决定，而不等于被积函数人为指定的单点值。
