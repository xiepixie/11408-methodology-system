# Exam Profiles

Exam Profile 只保存**考试制度层面稳定不变的结构**，避免每一套真题重复写同一批元数据。

## 责任边界

Profile 可以拥有：

- 总分、题量、考试时长等稳定结构；
- 题型区间；
- 固定的学科题号区间；
- 固定的学科分值配额；
- 由题号可确定的路由规则。

Profile 不拥有：

- 某一年的具体题干；
- 某题是否有图、代码或表格；
- 综合题当年的逐题分值；
- 答案、难度、知识点标签；
- Topic / Rules / Evidence Mapping。

一套具体真题使用同目录的 `exam.json` 保存**年度实例元数据**，并通过 `profile_id` 引用这里的 Profile。

## 版本原则

如果考试结构发生真实变化，不在旧 Profile 中堆大量年份例外，而是建立新 Profile，例如：

```text
math1-v1
math1-v2
```

Profile ID 一旦被真题实例引用，应保持稳定。

## 当前 Profiles

- `408.json`：计算机学科专业基础（408）；四门学科的选择题与综合题题号均固定。
- `math1.json`：全国硕士研究生招生考试 数学（一）；涵盖 1987～2025 年历次大纲时期与分值结构。
