# 408 算法拓展训练：考纲内的经典题

## Intro

[「从暴力解到最优解」真题专题](./brute-to-optimal.html)把 2009–2026 年 408 数据结构的算法设计题讲完了，一共 22 道。真题就这么多，练完就没了——但那套「先写对暴力解、再判断要不要优化、需要时找出浪费」的方法，值得用更多题目继续练。

本模块是沿着该思路解决这个问题：

- **主要内容**：从 408 数据结构**考纲范围内**精选的经典算法设计题——KMP、链表判环、判断平衡二叉树、由遍历序列构造二叉树、拓扑排序判环……这些都是大纲明确覆盖的知识点，只是真题的代码大题还没有直接考过。它们是练方法论的好载体。
- **和真题的关系**。这些题来自教材和机试里反复出现的经典题型，用来练手、补考点空白，但它们没有真题的地位。
- **能压题么？**。选这些题的唯一理由是「考纲内 + 经典 + 能练那套判断力」，不是「预测明年会考」。其实内容就这么多，再继续看更多的其实roi很低。

## 题目价值

真题的算法设计题分布并不均匀：链表、数组、树、图、排序都考过，但**串（KMP）的代码题一次没考过**，二叉树里「判平衡」「构造」这类高频操作也没进过大题。真题的空白，恰恰是拓展训练的价值所在——它把方法论覆盖到真题够不着的考点上。

更重要的是，这些题和真题共享同一批**优化手段**：链表判环用的快慢指针，是 2009·42 的兄弟；判断平衡二叉树的「自底向上一遍算完」，和真题里「消除重复计算」是同一招；KMP 消除的「模式串回退时主串指针也跟着退」的浪费，本质和数组题里「重复扫描」是一回事。**练拓展题，就是把真题里学到的手段，迁移到新场景里再打一遍。**

## 学习思路

每一篇的结构和真题专题完全一样，分两类：

- **暴力→最优型**：先写对暴力解、按判分口径估分、找出浪费、升级成最优解，两版代码可视化对照。用于有真实分差的题（判环、回文、判平衡、KMP、二分边界、逆序对……）。
- **直观即满分型**：直观写法就是最优解，重点在「为什么不用优化」和「别画蛇添足」。用于遍历/统计即达下界的题（合并链表、括号匹配、二叉树遍历应用、连通分量……）。

建议先练真题专题、把两套模板的手感建立起来，再用这个系列扩大练习面。
