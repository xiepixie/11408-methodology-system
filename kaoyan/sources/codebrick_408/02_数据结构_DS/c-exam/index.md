# 408 代码题需要会多少 C 语言？

本专题目标不是如何成为 C 程序员，只解决一个问题：**在 408 数据结构大题里，把已经想到的算法写成阅卷人能判分的 C 代码。**

我们逐题核对了 2009—2026 年**全国统考 408** 真题。18 年里，每年恰好有一道算法设计题要求用 C 描述算法（题号见文末地图，可自行核对）；这些题合计 245 分，平均每题 13.6 分。但没有一道要求从 `main`、键盘输入、菜单系统开始写完整程序。

（本专题只针对 408 统考卷面。若你考的是自命题院校，题面对"完整程序"的要求可能不同，需另行确认。）

因此，408 所需的 C 语言不是一门独立课程，而是一套很窄的**算法表达语法**。绝对不多学一个知识点。

## 真题到底用了哪些语法

| 语法能力 | 对应真题 | 必须做到什么 |
| --- | --- | --- |
| 函数、变量、分支、循环 | 18 道全部 | 看懂函数原型，写出初始化、循环不变量和返回值 |
| 一维数组与下标 | 2010、2011、2013、2016、2018、2020、2025 | 不越界，分清正向、反向和多指针扫描 |
| 结构体与指针 | 2009、2012、2014、2015、2017、2019、2021—2024、2026 | 会用 `.`、`->`、`NULL`，不把地址和值混为一谈 |
| 递归 | 2014、2017、2022 | 写对出口、当前层工作和递归方向 |
| 二维数组 | 2021、2023、2024 | 邻接矩阵中分清行、列、出度和入度 |
| 动态内存 | 2015、2018 | 知道 `calloc`、`free` 和删除结点的安全顺序 |
| 字符与输出 | 2009、2017、2023、2026 | 会输出结果，不需要系统学习字符串库 |

按大纲章节落点，18 道里线性表占 10 道，树 4 道、图 3 道、排序 1 道——**一半以上出在线性表**。若换成存储结构口径，则是数组类 7 道、链表 4 道、树 4 道、邻接矩阵图 3 道。两种口径都指向同一句话：**数组下标和结点指针决定了绝大多数卷面代码的生死。**

近四年（2021—2024）连续考图的邻接矩阵，2025 回到线性表、2026 回到树。图题的行列出入度统计是新的高频重心，本专题在数组篇单独讲。

## 这个专题的范围边界

以下内容不是 408 代码大题的投入重点

- 从 Hello World 开始的完整 C 课程；
- `main`、`scanf` 的系统用法和命令行参数；
- 文件操作、位域、联合体、函数指针、可变参数；
- 复杂指针运算和工程项目组织；
- 为了“像程序”而补写题目没要求的输入、建表和测试代码。

Playground 中会出现 `main` 和输入代码，那只是为了让函数能够在线运行。**考试卷上只写题目要求的函数。**

## 建议学习顺序

- [函数、表达式与控制流](./functions-control-flow.html)：先能写出一段不越界、会返回的算法。
- [数组、下标与二维矩阵](./arrays-matrices.html)：覆盖出现次数最多的一类真题。
- [结构体、指针与链式结点](./structs-pointers.html)：解决链表和链式树的语法门槛。
- [递归与状态传递](./recursion-state.html)：把树的自然语言步骤翻译成函数。
- [动态内存、字符与输出](./memory-io.html)：只补少量但会造成致命错误的语法。
- [卷面答题模板与 18 题训练路线](./answering.html)：把语法变成稳定得分。

如果你完全没写过 C，按顺序阅读；如果只是指针或递归薄弱，直接跳到对应篇。

## 学到什么程度算够

看到题目给出的类型定义，你应该能在 3 分钟内完成四件事：

- 圈出函数输入、输出和是否允许修改原结构；
- 写出游标、下标或递归参数的初始化；
- 写出主体循环或递归出口；
- 用一句话说明时间、空间复杂度。

不要求代码具有工业级异常处理，但必须逻辑自洽、边界明确、复杂度与实现一致。
