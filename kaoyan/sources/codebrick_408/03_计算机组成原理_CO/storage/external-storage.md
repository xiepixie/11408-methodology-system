# 外部存储器

## 大纲定位

**三（五）外部存储器**

- 磁盘存储器
- 固态硬盘（SSD）

要求：掌握磁盘的物理结构与地址组成、容量与存取时间的计算，了解 SSD 的组织方式及其与磁盘的本质差异。

**RAID 已不在现行大纲内**，本文仅保留一张对照表供了解，不必投入精力。

## 知识框架

本节回答六个问题：

- 柱面是什么？为什么磁盘地址要把柱面号放在最高位？
- 磁盘地址的三段各占几位，怎么算？
- 一次磁盘存取的时间由哪几部分组成？哪一部分最慢？
- 为什么非格式化容量大于格式化容量？
- SSD 没有机械部件，为什么随机写反而不快？
- SSD 的寿命由什么决定？给一组参数能不能算出来？

## 一、磁盘的物理结构

磁盘由多个**盘片**叠装而成，每个盘片有一至两个**记录面**，每面划分为若干同心圆**磁道**，每条磁道再划分为若干**扇区**。

图 7.15　磁盘驱动器的物理组成（袁春风《计算机组成与系统结构（第 3 版）》）

图中最关键的一点是：**移动臂上叠着一组磁头，它们固定在一起、只能一起移动**。

> [!TIP]
>

柱面的由来

既然所有磁头一起动，任一时刻它们必然停在**相同半径**上。各记录面上这些编号相同的磁道，纵向贯穿构成的虚拟集合就是**柱面**。

由此可得两条结论：

- **柱面数 = 单面的磁道数**
- **同一柱面内更换磁头不需要重新寻道**——磁头组不用移动，只需电子切换

第 2 条解释了磁盘地址为什么把柱面号放在最高位：地址连续递增时，会先在同一柱面内换磁头（快），换完所有盘面才移动到下一柱面（慢）。这样能把最耗时的寻道动作降到最少。

其他几个对应关系：

- **记录面数 = 磁头数**，每个磁头负责一个记录面
- **扇区**是磁盘读写的最小单位（通常 512 B 或 4 KB）

### 记录密度：每道扇区数到底相不相同

描述"信息排得多密"的量有两个，方向不同，别混：

| 名称 | 沿哪个方向数 | 定义 |
| --- | --- | --- |
| **道密度** | **半径**方向 | 单位长度内的**磁道数** |
| **位密度** | **磁道**方向 | 单位长度内存放的**二进制位数** |

由此分出两种记录方式，"每道扇区数是否相同"的答案随之相反：

| 方式 | 约束的是 | 结果 |
| --- | --- | --- |
| **低密度（等角）方式** | 各道**扇区数相同**（按固定圆心角划分） | 各道位数相同，周长小的**内道位密度更高**；整盘能力受限于内道能达到的最大位密度 |
| **高密度（等密度）方式** | 各道**位密度相同** | 周长大的**外道扇区数更多**，容量更大 |

> [!WARNING]
>

容量公式默认的是低密度方式

容量=面数×柱面数×每道扇区数×每扇区字节数 这个乘法能成立，前提是"**每道扇区数是同一个数**"——也就是低密度方式。

条件里若写明"外道扇区数多于内道"，就不能再套这条乘法，只能按各道分别累加。判据很简单：**题目给不给得出唯一的"每道扇区数"**。

## 二、磁盘地址
[ 柱面（磁道）号⏟最高位  |  盘面（磁头）号⏟  |  扇区号⏟ ]

每段的位数由该维度的数量决定：某字段位数=⌈log2⁡(该维度的数量)⌉

**例**：20000 个柱面、每道 500 个扇区、4 个**双面**盘片。214=16384<20000≤32768=215⟹柱面号=⌈log2⁡20000⌉=15 位磁头数=4 盘片×2 面=8⟹磁头号=log2⁡8=3 位28=256<500≤512=29⟹扇区号=⌈log2⁡500⌉=9 位

共 15+3+9=27 位。

> [!WARNING]
>

两个易错点

**一是取整方向。** 位数**只能向上取整**——14 位表示不了 20000 个柱面。各段要**分别**取整后再相加，不能先把三个数量相乘再统一取对数。

**二是盘片与盘面的区别。** 给出"N 个双面盘片"时，磁头数是 2N 而不是 N。直接拿盘片数取对数会少一位。

## 三、磁盘容量
格式化容量=记录面数×柱面数×每道扇区数×每扇区字节数

### 为什么非格式化容量更大

扇区里存的不只是用户数据。一个完整扇区的物理格式为：[ 间隙  同步字段  ID（柱面号 / 磁头号 / 扇区号）⏟地址信息  数据  CRC⏟校验 ]

图 7.17　温切斯特磁盘的磁道记录格式（袁春风《计算机组成与系统结构（第 3 版）》）

教材给出的实际数字：一个扇段共 **600 字节**，其中数据域 515 字节（同步字节 1 + 数据 **512** + CRC 2），其余 85 字节是间隙与 ID 域。

用户能用的是 512 B，磁道上实际占了 600 B——**多出的部分就是格式化开销**，这正是"非格式化容量 > 格式化容量"的来源。

扇区中带有 ID 地址信息，也解释了磁盘为何属于**直接存取**：磁头可以先定位到大致位置，再顺序读取 ID 直到找到目标扇区。

## 四、磁盘存储器的三层组成

| 层次 | 是什么 |
| --- | --- |
| **盘片** | 记录介质本身，多片叠装，各面镀磁性材料 |
| **磁盘驱动器** | 主轴电机 + 磁头组 + 寻道伺服机构，负责全部机械动作 |
| **磁盘控制器** | 接收主机命令、控制驱动器、与总线通信。DMA 方式下向 CPU 发出总线请求的正是它 |

## 五、磁盘存取时间
存取时间=寻道时间+旋转等待时间+数据传输时间 (+ 控制器延时)

| 分量 | 含义 | 平均值 |
| --- | --- | --- |
| **寻道时间** | 磁头移动到目标磁道 | 约为最大寻道时间的一半（机械动作，**最慢的一项**） |
| **旋转等待时间** | 目标扇区转到磁头下方 | 转半圈的时间 =12r（r 为转/秒） |
| **数据传输时间** | 读写数据本身 | 见下 |
| 控制器延时 | 控制器处理命令的开销 | 题目给出时才计入 |

> [!TIP]
>

控制器延时是独立的一项

它不包含在前三项里。判断方法很直接：**条件里给了几个时间量，结果中就应当出现几个**。

### 数据传输时间的两种算法

**算法一**（已知字节数与传输速率）：t=读写字节数数据传输速率,其中 Dr=r×N (N 为每磁道字节数)

**算法二**（只知道每磁道扇区数）：读一个扇区的时间=转一圈的时间每磁道扇区数

两者等价——读一个扇区就是磁头划过 1扇区数 圈，字节数在推导中被约掉了。当条件里没有给出每扇区字节数时，只能用算法二。

> [!WARNING]
>

单位口径要全程一致

磁盘容量与速率习惯上取 1 MB=106 B、1 GB=109 B。

**同一道题里口径必须自始至终一致**。若中途从 ÷1024 切换到 ÷1000，得到的数在两种口径下都不成立。

## 六、固态硬盘（SSD）

SSD 由**闪存芯片阵列**与**闪存翻译层**组成，没有任何机械部件。它的全部特性都源自 Flash 的物理约束（详见 [[03_计算机组成原理_CO/storage/sram-dram.md|半导体随机存取存储器]]）。

### 组成：闪存翻译层相当于磁盘控制器

SSD 对外的接口规范与传统硬盘完全相同，主机发出的仍然是"读第几个逻辑块"这样的请求。把这种请求翻译成对底层闪存芯片的读写控制信号的部件，就是**闪存翻译层**——它在 SSD 中扮演的角色**相当于磁盘中的磁盘控制器**。

正因为有这一层翻译，"页/块""不能原地更新"这些闪存特性对主机是隐藏的，操作系统可以像用磁盘一样用 SSD。

存储部分是三级组织：闪存芯片→区块（block）→页（page）

| 层级 | 典型规模 | 它是什么单位 |
| --- | --- | --- |
| 页 | 512 B ~ 4 KB | **读 / 写**的单位 |
| 区块 | 32 ~ 128 页，即 16 ~ 512 KB | **擦除**的单位，也是**寿命**的计数单位 |

> [!TIP]
>

与磁盘的结构对照

| 磁盘 | SSD |
| --- | --- |
| 扇区 —— 读写最小单位 | **页** |
| （无对应物） | **区块** —— 擦除与寿命的单位 |
| 磁盘控制器 —— 逻辑块号 → 柱面/磁头/扇区 | **闪存翻译层** —— 逻辑块号 → 物理页 |

多出来的"区块"这一级，是 SSD 与磁盘一切行为差异的源头。

### 三条硬约束

| 约束 | 内容 | 后果 |
| --- | --- | --- |
| ① 写前必须擦除 | 编程只能把 1 改成 0；要把某位改回 1，只能**擦除该页所在的整个区块** | 不能原地更新 → 写放大 |
| ② 区块内按顺序写 | 一个区块被擦除后，块内各页必须**按顺序**写入 | 无法把某一页单独回填，进一步逼出"整块搬迁"的做法 |
| ③ 擦除次数有限 | 每个区块只能承受有限次擦除/编程，重复写几千到几万次后即成为坏块 | 寿命有限 → 需磨损均衡 |

后面两小节讲的写放大与磨损均衡，分别是约束 ①② 与约束 ③ 的直接产物。

### 为什么随机写反而不快

这是 SSD 最反直觉的一点——它没有机械部件，随机读确实极快，但**随机写**不然。

原因在于"不能原地更新"：要修改某一页的数据，必须

- 把该块中**仍然有效的页**复制到一个新块
- 在新块中写入更新后的页
- 擦除旧块

这套"搬迁 + 擦除"的动作由闪存翻译层在后台完成，称为**垃圾回收**。

于是**实际写入闪存的数据量远大于主机请求写入的数据量**，这一现象称为**写放大**：写放大系数=实际写入闪存的数据量主机请求写入的数据量>1

写放大既拖慢写性能，又加速寿命消耗——因为闪存的擦写次数是有限的。

> [!TIP]
>

顺序写为什么没有这个问题

顺序写是把整块从头写到尾，块内不存在"还有效的旧页"需要搬迁，写放大系数接近 1。

随机写则是零散地改动分布在各块里的少数页，每改一页都可能触发一次整块搬迁。**同样是写，代价差在有没有搬迁量**——这就是"顺序写快、随机写慢"的判据，也解释了为什么约束 ②（块内必须顺序写）会把代价推高。

### 磨损均衡

若某些块被反复擦写，它们会远早于其他块损坏，导致整盘容量提前缩水。SSD 控制器用**磨损均衡**来对冲：

| 方式 | 做法 |
| --- | --- |
| 动态磨损均衡 | 写入时优先选择擦写次数较少的空闲块 |
| 静态磨损均衡 | 定期把高磨损块中的数据迁移到低磨损块，使高磨损块转为以读为主 |

磨损均衡的效果可以直接量化：**它让"总擦除次数"这个预算可以按整盘来算，而不是被某几个热点块提前耗光**。下一小节的寿命估算正是建立在这个前提上。

### 容量与寿命的估算

容量由三级结构直接相乘：容量=区块数×每块页数×每页字节数

寿命的算法则要绕两道弯——先算闪存**能承受**多少写入量，再折回主机**能发出**多少写入量：闪存可承受写入总量=容量×每块可擦写次数主机可写入总量=闪存可承受写入总量写放大系数,寿命=主机可写入总量每天写入量

> [!WARNING]
>

两处符号含义要盯住

**一是"擦写次数"乘的是容量而不是块数。** 每块能擦 N 次，意味着每块累计能写 N× 块容量的数据；全盘加起来就是 N× 整盘容量。

**二是写放大系数出现在分母。** 它衡量的是"主机写 1 字节，闪存实际写几字节"，所以从闪存预算折算回主机预算要**除**以它，不是乘。方向搞反会把寿命高估 k2 倍。

前提是磨损均衡有效——否则热点块先坏，实际寿命远低于这个上界。

**算例**：某 SSD 有 4096 个区块，每块 64 页，每页 4 KB；每块可擦写 10000 次，写放大系数为 2，主机每天写入 10 GB。容量=4096×64×4 KB=1048576 KB=1 GB闪存可承受=1 GB×10000=104 GB⟹主机可写=1042=5000 GB寿命=500010=500 天≈1.4 年

把写放大系数从 2 压到 1.1，寿命立刻涨到 104/1.1/10≈909 天——**降低写放大与提高擦写次数上限，对寿命是等效的两条路**。

### SSD 与磁盘的对比

| 对比项 | SSD | 磁盘 |
| --- | --- | --- |
| 随机读 | **极快**，几十微秒 | 慢，几毫秒到几十毫秒（需寻道 + 旋转） |
| 顺序写 | 快 | 较快 |
| **随机写** | **较慢**，几百微秒（需先擦后写） | 慢 |
| 抗震性 | 强 | 弱（有机械部件） |
| 功耗 / 噪声 | 低 / 无 | 高 / 有 |
| 价格 | 高 | 低 |
| 寿命的限制因素 | **擦写次数** | 机械磨损 |

整体上 **SSD 的随机读写时延比磁盘低约两个数量级**——差距全部来自磁盘的机械动作，而不是数据传输本身。

## 七、磁盘阵列（RAID，纲外了解）

RAID 把多个物理磁盘组合成一个逻辑磁盘，通过并行访问提高性能、通过冗余提高可靠性。

| 级别 | 特点 |
| --- | --- |
| RAID0 | 条带化，无冗余，速度最快 |
| RAID1 | 镜像备份，有效容量减半，可靠性高 |
| RAID2 | 海明码纠错 |
| RAID3 | 位交叉 + 独立校验盘 |
| RAID4 | 块交叉 + 独立校验盘 |
| RAID5 | 分布式奇偶校验，无独立校验盘 |

## 例题

**例**：某磁盘转速 7200 转/分，平均寻道时间 8 ms，每磁道 500 个扇区、每扇区 512 B。求读取一个扇区的平均存取时间与数据传输速率。

**解**：

**第一步，把转速换成每转时间。**r=720060=120 转/秒,T一圈=1120 s≈8.33 ms

**第二步，逐项求三个分量。**

| 分量 | 计算 | 结果 |
| --- | --- | --- |
| 平均寻道时间 | 条件给出 | 8 ms |
| 平均旋转等待 | 转半圈 =8.33/2 | 4.17 ms |
| 传输一个扇区 | 算法二：8.33/500 | 0.017 ms |

平均存取时间=8+4.17+0.017≈12.19 ms

**第三步，求数据传输速率。**每磁道容量=500×512=256000 BDr=120×256000=30720000 B/s=30.72 MB/s

用算法一验算传输时间：512÷(30.72×106)≈1.67×10−5 s=0.017 ms，与算法二一致。

三个分量的量级差别极大：**寻道 8 ms、旋转 4.17 ms、传输 0.017 ms**。机械动作占了 99.9% 的时间，数据传输本身几乎可以忽略——这正是磁盘慢的根源，也是 SSD 快的原因。

## 易混淆知识点

**1. 柱面数和磁道数是一回事吗？**

数值上相等（柱面数 = 单面磁道数），但指代不同：磁道是**单个记录面上**的一个同心圆，柱面是**所有记录面上**同编号磁道的集合。

**2. 磁盘为什么是"直接存取"而不是"随机存取"？**

随机存取要求任意单元的存取时间**相同**。磁盘的存取时间取决于磁头当前位置与目标位置的距离，差别可达数十倍，因此不满足。

它先由寻道机构定位到大致位置（这一步类似随机），再在磁道内顺序查找目标扇区——两种方式的结合，故称直接存取。

**3. 平均寻道时间为什么取最大值的一半？**

假设目标磁道在全盘上均匀分布，磁头移动距离的期望约为最大距离的一半。这是一个统计平均值，不是某次访问的实际值。

**4. SSD 既然更快，为什么还没完全取代磁盘？**

价格与寿命。单位容量成本仍显著高于磁盘，且擦写次数有限——对于以顺序写入为主的大容量冷数据存储，磁盘依然更经济。

## 本节小结

- 所有磁头**固定在一起移动**，因此同编号磁道构成**柱面**；**柱面内换磁头不需要寻道**
- 磁盘地址为「柱面号 + 盘面号 + 扇区号」，柱面号在最高位以减少寻道
- 各段位数 =⌈log2⁡(数量)⌉，**分别向上取整**；**N 个双面盘片对应 2N 个磁头**
- **道密度**沿半径方向数磁道，**位密度**沿磁道方向数二进制位，两者方向不同
- **低密度方式各道扇区数相同**（内道位密度更高），**高密度方式外道扇区数更多**；容量乘法公式默认前者
- 格式化容量 = 记录面数 × 柱面数 × 每道扇区数 × 每扇区字节数
- 扇区含间隙、同步、ID、数据、CRC，故**非格式化容量 > 格式化容量**
- 三层组成：盘片、磁盘驱动器、磁盘控制器；**DMA 请求由控制器发出**
- 存取时间 = 寻道 + 旋转等待 + 传输（+ 控制器延时）；**平均旋转等待 = 转半圈**
- 传输时间两种算法等价；只给扇区数时用"转一圈时间 ÷ 每道扇区数"
- 机械动作占存取时间的绝大部分，传输本身几乎可忽略
- SSD 的**闪存翻译层**把逻辑块号翻译成物理页，地位**相当于磁盘控制器**
- 三级结构：闪存芯片 → 区块（32~128 页，擦除与寿命的单位）→ 页（512 B~4 KB，读写的单位）
- 三条硬约束：**写前必须擦整块**、**块内必须顺序写**、**擦除次数有限**
- 因**不能原地更新**产生**垃圾回收**与**写放大**，随机写因而不快；顺序写无搬迁量，写放大接近 1
- **磨损均衡**对冲擦写寿命有限的约束，也是按整盘算寿命预算的前提
- 容量 = 区块数 × 每块页数 × 每页字节数；**寿命 =容量×擦写次数写放大系数×每天写入量**，写放大在**分母**
- SSD 随机读写时延比磁盘低约**两个数量级**
