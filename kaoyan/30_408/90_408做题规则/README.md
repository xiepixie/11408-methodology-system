### 408 首次定位链

这条链是通用九问在 408 状态/路径题中的候选适配，不替代各科 Adapter：

```text
Target
-> Subject / Scope
-> Given State
-> Event / Operation
-> Invariant / Boundary
-> Mechanism / Path
-> Cost
```

- `Target`：先确定要求数值、状态、结构选择还是完整路径；
- `Subject / Scope`：先切到数据结构、计组、OS 或网络的正确观察语言；
- `Given State`：抄出真正会变化的表、队列、寄存器、指针、窗口或缓存行；
- `Event / Operation`：没有触发依据，不擅自改变状态；
- `Invariant / Boundary`：先区分相邻但不同的状态机，再调用机制；
- `Mechanism / Path`：只画当前题实际经过的最小路径；
- `Cost`：最后把路径换算成比较、cycle、I/O、时延或吞吐。

候选停止条件：若前三步已经唯一定位到某一 Subject Topic，立即切换到该学科 Rules，不继续机械填写七项。

### 缓冲类问题首次定位七问

这是一条跨科候选规则，生成依据见[跨科母模型：缓冲与有限中间态](../00_统一总图/跨科母模型_缓冲与有限中间态.md)。它只负责识别“有限中间态”中的共同结构；一旦定位到具体机制，必须切回对应学科专题，不用它覆盖缓存、TCP、直接存储器访问或外部排序自己的规则。

1. **对象是什么？** 当前暂存的是字节、记录、帧、分组、页、写请求、脏块，还是整个任务？对象不同，容量单位和完成条件就不同。
2. **两端是谁？** 明确生产者、消费者或相邻服务阶段；若无法指出两端，就先怀疑这里其实是 Cache、映射表或普通寄存器，而不是典型生产者—消费者缓冲。
3. **为什么不能直接交接？** 在速率、时相、粒度、顺序/完整性、突发或资源独占六类不匹配中定位首要矛盾。
4. **容量状态怎样表示？** 写出容量 $K$、当前占用 $q$，以及题设中的队头/队尾、读写指针、空闲槽、接收窗口或输入/输出块等状态；能用库存模型时检查 $0\le q\le K$。
5. **空与满分别意味着什么？** 空时谁等、谁继续；满时是阻塞、反压/缩窗、丢弃、覆盖、溢写到慢层还是触发回收？只说“有缓冲所以不会阻塞/丢失”视为未完成。
6. **所有权何时转移？** 哪个事件使内容从“正在填充”变为“有效可消费”，消费后何时允许复用；并发、DMA、缓冲池和环形队列题尤其要防止双方同时修改同一槽。
7. **它买来了什么，又付出了什么？** 分开判断吞吐、等待时延、额外空间、复制/管理开销和突发容忍度。容量增加通常只能提高可吸收的突发量或重叠程度，不能单独突破长期服务率瓶颈。

高频边界复核：`buffer != cache`（当前交接解耦 vs 未来副本复用）；`buffer != queue`（暂存角色 vs 出入次序）；`buffer != window`（实际存储状态 vs 许可/反馈范围）；`buffer pool != kernel buffer`（管理一组对象 vs 单个缓冲及其地址空间）；`DMA != buffer`（搬运者 vs 数据暂存位置）；`SPOOLing != 普通 buffer`（任务中转存储 + 排队 + 后台服务 + 独占设备虚拟化）。

候选验证集至少覆盖：循环队列与外部排序输入/输出缓冲、Cache 写缓冲、OS 单/双/循环缓冲与缓冲池、管道/消息通道容量与阻塞、虚拟内存页框/置换、SR 发送与接收缓存、TCP `rwnd`、交换机/路由器有限队列。只有这些题型都能用七问正确定位、且不会抢走本地知识归属后，才进入“已采用”。
