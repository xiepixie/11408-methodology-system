# 图表示、BFS 与 DFS 状态推演

> 训练定位：解决“给邻接矩阵/邻接表，要求读度、判断可达、写 BFS/DFS 序列、分量数或无权最短边数”的题目族。  
> 模型归属：[DS07｜图的表示与遍历](DS07_图的表示与遍历_方法论手册.tex)。图表示、visited、frontier、连通分量与 BFS 距离机制由 Canonical 正文拥有；本文件只训练纸面状态账本和独立核验。

## 母题表示：图遍历永远维护三个顶点状态

```text
Unseen       尚未发现
Discovered   已发现、已标记、正在 frontier 中等待展开
Expanded     已取出并扫描完邻接关系
```

统一动作：

$$
\boxed{Discover\to Mark\to Push/Enqueue\to Expand}
$$

DFS 与 BFS 的核心区别只在 frontier：

- DFS：LIFO；
- BFS：FIFO。

## 问题一：先把矩阵/表里的“关系语义”读对

### 邻接矩阵

无向图：矩阵通常对称；一行非零边项可读该顶点度。  
有向图：

- 行 → 出边/出度；
- 列 → 入边/入度。

带权图必须先确认“无边”用什么表示：$\infty$、特殊值还是 0。若允许零权边，0 不能再自动解释为无边。

### 邻接表

- 有向图普通邻接表通常保存出边；
- 无向边在两端各登记一次；
- 遍历复杂度按真实关系数量写 $O(V+E)$。

### 表示题先数“顶点头 + 边记录”，不要把 $E$ 和弧结点数混成一个量

若只计教材中的主要逻辑单元，不计对齐和容器额外开销：

| 表示 | 顶点部分 | 关系记录数 | 典型总量级 |
|---|---:|---:|---:|
| 邻接矩阵 | $V$ 个顶点信息 | $V^2$ 个矩阵槽 | $O(V^2)$ |
| 无向图邻接表 | $V$ 个表头 | 每条边登记两次，共 $2E$ 个边结点 | $O(V+E)$ |
| 有向图邻接表 | $V$ 个表头 | 每条弧登记一次，共 $E$ 个弧结点 | $O(V+E)$ |

因此无向图若每个顶点表头占 $a$ 个单元、每个边结点占 $b$ 个单元，总存储量应写成 $aV+2bE$；有向图普通邻接表则是 $aV+bE$。若题目使用逆邻接表、十字链表或邻接多重表，关系记录的复用方式会改变，必须按字段定义重新计数。

对邻接矩阵，若题目只问“零元素个数”，无向简单图且主对角线为 0 时，非零边项有 $2E$ 个，所以零元素数是 $V^2-2E$；有向简单图则通常只有 $E$ 个非零弧项。这里仍要先确认 0 是否真的表示“无边”。

### 局部规则：图存储计数先锁“每条关系登记几次”

**触发信号**：题目给顶点数、边/弧数和每个表头/边结点占用空间，要求比较邻接矩阵与邻接表，或要求矩阵中零元素个数。

**第一动作**：先写“无向边在邻接表中登记 2 次；有向弧通常登记 1 次”，再分别数顶点头和关系记录。

**检查与退出**：若题目换成十字链表、邻接多重表或带权矩阵，停止套 $2E$；先按当前表示中一条真实关系到底对应几个存储结点重新计数。

### 局部规则：看到“不可达/无边”先认哨兵

**触发信号**：矩阵里有 0、$\infty$、-1 等特殊值。

**第一动作**：把“自身距离”“零权边”“无边”三者的编码规则写在草稿上。

**检查与退出**：若题面允许零权边，就不能再用 0 同时表示“无边”；一旦哨兵语义冲突，停止套矩阵公式，先按题设重建编码约定。

## 问题二：BFS 必须在入队时标记 visited

经典流程：

```text
mark start
enqueue start
while queue not empty:
    u = dequeue
    for v in neighbors(u):
        if unseen(v):
            mark v
            parent/dist update
            enqueue v
```

### 为什么不能等出队再标记

若 1、2 都连接 3：

```text
1 discovers 3 -> enqueue
2 later also sees 3
```

若此时 3 还没标记，就会重复入队。

**不变量**：一个顶点一旦进入 frontier，就已经被某条发现路径“预约”，其他边只能再次看见它，不能再创建第二份待处理项。

## 问题三：DFS 序列不唯一，除非邻接顺序被固定

递归 DFS：

```text
visit u
for v in neighbors(u) in specified order:
    if unseen(v): dfs(v)
```

若题目没有给邻接表顺序、矩阵扫描顺序或“按编号从小到大”，多个 DFS 序列都可能合法。

### 局部规则：遍历序列先找邻接访问顺序

**触发信号**：题目问“DFS 序列唯一吗”或选择可能序列。

**第一动作**：先找邻接访问顺序约束；没有约束时只用“深度优先 + visited”检查合法性，不擅自指定唯一输出。

**检查与退出**：若同一顶点存在多个尚未访问邻接点且题面未给选择顺序，应保留多种合法分支；只有邻接顺序被固定后才继续推出唯一序列。

## 问题四：BFS 首次发现层数为什么是无权最短边数

从源 $s$：

$$
dist[s]=0.
$$

首次由 $u$ 发现 $v$：

$$
dist[v]=dist[u]+1.
$$

FIFO 保证先展开较浅层，因此首次发现时已经得到最少边数路径。

### 重要边界

- 所有边权相同正数 $c$：实际最短代价为 $c\cdot dist$；
- 边权不同：BFS 层数不再代表最小总代价，转 DS08。

## 问题五：非连通图必须加外层扫描

从单一起点遍历，只覆盖它的可达分量。

求遍历森林/连通分量数：

```text
components = 0
for each vertex v:
    if unseen(v):
        components++
        BFS/DFS(v)
```

每启动一次新的遍历根，就发现一个新分量。

### 检查

若题目有孤立顶点，单起点遍历序列没有它并不表示算法漏了；只有题目要求“遍历全图”时才需要外循环。

## 问题六：边数与连通性先看前提，不做过强推断

无向简单图：

$$
\sum_v degree(v)=2E.
$$

且：

- $E<V-1$ → 必不连通；
- 连通且 $E=V-1$ → 树；
- $E>V-1$ → 必有环；
- 但 **仅有** $E=V-1$ 不能单独推出连通或无环。

### 局部规则：任何“边数推出结构”都写条件

**触发信号**：题目只给顶点数、边数，就要求判断树、连通或有环。

**第一动作**：把边数结论拆成“数量必要条件 + 连通/无环等独立结构条件”；例如 $E=V-1$ 只有再加连通（或无环）才能推出无向树。

**检查与退出**：若只掌握 $E=V-1$ 而没有连通性/无环性证据，停止推出“必为树”；反例可以是一个带环分量加一个孤立点。

## 问题七：有向图的 DFS 判环要用三色，而不只是 visited

状态：

```text
white = unseen
gray  = discovered, recursion not finished
black = fully expanded
```

沿有向边遇到 gray 顶点：当前递归栈出现 back edge → 有向环。

遇到 black 顶点不能据此判环，它可能只是另一条已经完成的路径。

## 问题八：邻接矩阵幂数的是 walk，不是简单路径

无权图邻接矩阵 $A$：

$$
(A^k)_{ij}
$$

表示从 $i$ 到 $j$ 长度恰为 $k$ 的 **walk** 数量，允许重复顶点/边。

### 停止条件

题目若明确问“简单路径数”，不能直接拿矩阵幂答案，因为矩阵乘法没有排除重复访问。

## 代表母题：BFS 状态账本

图：

```text
0: 1,2
1: 0,3
2: 0,3
3: 1,2,4
4: 3
```

从 0 开始，邻接按升序。

```text
初始化：mark 0, Q=[0], dist[0]=0
展开0：发现1,2 -> Q=[1,2], dist=1
展开1：发现3   -> Q=[2,3], dist[3]=2
展开2：3 已是 Discovered，不重复入队
展开3：发现4   -> Q=[4], dist[4]=3
展开4：结束
```

访问序列：

```text
0,1,2,3,4
```

最短边数：

$$dist[4]=3.$$

## 陌生图遍历题固定落笔协议

```text
1. 先写 directed/undirected、是否重边/自环、矩阵无边哨兵。
2. 明确邻接扫描顺序。
3. 顶点状态固定为 Unseen/Discovered/Expanded。
4. Discover 后立即 Mark，再进入 frontier。
5. DFS 用栈/递归；BFS 用队列。
6. 无权最短边数才给 BFS 的 dist 语义。
7. 全图覆盖要加外层 unseen 扫描。
8. 有向判环使用 gray/black，而不只是一个 visited 位。
9. 最后检查：每顶点是否最多首次发现一次、是否遗漏非连通分量。
```

## 最短压缩

> **图遍历只做“关系表示 → frontier → visited → 覆盖”：发现即标记；BFS 的 FIFO 才给无权最短层数，DFS/BFS 本身不自动等于最短路或 MST。**
