# DS01｜线性关系与存储表示

状态：LaTeX 工作稿，待人工确认；已建立并发布 Canonical 深度正文。

## Position
数据结构 Topic。

## Mother Problem
同一线性逻辑关系为什么需要连续、链接等不同物理表示？

## Mother Model

同一线性逻辑关系与操作契约允许选择不同物理表示；表示决定局部更新要维护的不变量与成本向量。Canonical 不再用一条裸箭头把建模顺序、因果和状态流混成同一种关系。

## Owns
顺序表、链式表示、插入删除访问的结构差异、地址/指针关系及边界状态；多维数组的线性化地址映射，以及对称/三角/稀疏矩阵的压缩表示基础。

## Uses
Atlas Foundation 的 complexity / cost vector。

## Does Not Own
栈队列的受限访问语义；Cache/页式存储等机器级地址转换由组成原理/操作系统专题拥有。数组线性化与特殊矩阵压缩属于本 Topic，具体手算技巧放在同目录训练层。
