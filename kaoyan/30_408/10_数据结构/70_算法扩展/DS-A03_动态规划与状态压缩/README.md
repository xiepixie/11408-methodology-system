# DS-A03｜动态规划与状态压缩

状态：Canonical 正文已建立；算法 Extension Topic，不纳入 408 Core Topic 列表。Published PDF 见下方链接。  
本册不改写数据结构 12 个 Core Topic，而是补上“重复子问题怎样被压缩成可验证状态”的算法设计层。

## Hook

DP 不是一张转移表，也不是“看到最优值就套 `max/min`”。它解决的是：原问题的不同历史，何时可以被同一个状态合并；合并后怎样保证未来选择完全相同；怎样按照依赖关系只计算每个状态一次。

## Mother Question

> 怎样找到一个对未来足够、对过去尽量压缩的状态，使所有合法方案的最优值/计数/可行性都能由更小状态无遗漏地推出？

## Scope / Stop Boundary

Owns：状态充分性、最后一步分解、递归记忆化、依赖 DAG、计算次序、滚动数组与状态机压缩，以及 补充笔记中的背包、网格、线性/环/树形、编辑距离、股票、LIS/LCS 模型。  
Uses：DS01 的序列/矩阵表示、DS04 的树后序、DS07/08 的图状态、DS09 的二分、DS-A01 的扫描与前缀摘要。
