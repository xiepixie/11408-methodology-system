# DS03｜串与模式匹配

状态：Canonical 正文、C++17 伴随实现与边界测试已建立；Published PDF 见下方链接。

## 定位
数据结构专题。

## 母问题
模式匹配失败后，怎样复用已经获得的匹配信息，而不是把搜索完全退回重来？

## 母模型
先确认已经匹配了多少字符；失配后寻找仍可复用的最长模式前缀；只缩短模式状态，不倒退主串；继续比较直到匹配成功或主串耗尽。

## 本册负责
串的基本对象、朴素匹配、KMP、前缀函数、`next` / `nextval` 以及失配后的状态迁移。

## 调用
数据结构总图中的成本模型与表示—操作—不变量语言。

## 边界
一般序列存储机制由 DS01 负责；完整自动机理论、多模式匹配与文本索引只作为扩展，不在本册展开。

## 代码契约
代码必须让读者看得出三个对象：主串、模式串、当前已匹配长度。朴素匹配保留“每个起点重新比较”的基线；KMP 则先计算模式串自己的最长相等真前后缀长度，普通失配时只缩短模式状态，主串位置不倒退。

本册同时保留三种可互相验证的实现：直接使用前缀函数的版本、与 408 手算同构的 `next` 哨兵版本，以及使用 `nextval` 跳过必败比较的版本。记忆锚点不是数组首项，而是：**已经匹配成功的主串后缀等于模式前缀；失配以后只沿模式自身的边界链缩短这个状态。**
