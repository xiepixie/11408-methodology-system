# 排序过程、稳定性与基数排序

> 训练定位：解决“给一趟后的序列、问属于哪种排序/比较移动次数/稳定性/基数排序过程”的题目族。  
> 模型归属：[DS11｜内部排序](DS11_内部排序_方法论手册.tex)。插入、交换、选择、快排、堆排、归并、基数排序的机制和复杂度由 Canonical 正文拥有；本文件只训练中间状态证据、成本分栏和稳定性检查。

## 母题表示：先找“这一趟提交了什么事实”

排序过程题不要先看数组“像不像更有序”。先问：

| 算法 | 一趟后不可逆/稳定扩大的事实 |
|---|---|
| 插入 | 已处理前缀整体有序 |
| 冒泡 | 一个极值进入未排序区末端 |
| 选择 | 一个极值进入未排序区前端 |
| 快排 | 枢轴进入最终位置，两侧满足 partition 关系 |
| 堆排 | 根极值提交到末端，已排序后缀扩大 |
| 归并 | 若干相邻有序段被合并成更长有序段 |
| 基数 | 已处理位上的稳定次序成立 |

## 问题一：插入排序的移动次数与逆序对

直接插入时，每次把待插元素左侧比它大的记录向右移动。

因此整个排序的后移总次数等于初始逆序对数。

### 直接推论

- 已有序：移动 0，最好线性；
- 完全逆序：

$$
\frac{n(n-1)}2
$$

次后移量级。

### 折半插入边界

折半只能降低“找插入点”的比较次数，连续数组仍要移动后缀，所以最坏总时间仍：

$$O(n^2).$$

## 问题二：稳定性检查只看“相等 key 会不会越过”

稳定：原来先出现的等 key 记录，排序后仍在前。

常见保证方式：

- 插入：只移动严格大于 key 的元素；
- 冒泡：只交换严格逆序；
- 归并：相等时先取左段；
- LSD 基数：每一位分配/收集必须稳定。

常见不稳定来源：

- 选择排序的远距离交换；
- 堆排序的根—末端远距离交换；
- 快排 partition 的跨区交换；
- Shell 的跨增量移动。

> **停止条件：**“原地”只说额外空间，不等于稳定；“稳定”也不意味着原地。

## 问题三：冒泡与选择都固定极值，但位置方向不同

升序：

- 冒泡从左到右，一趟通常把当前最大值送到右端；
- 简单选择一趟在未排序区找最小值，放到左端。

### 局部规则：中间序列先找已确定端

**触发信号**：题目给排序若干趟后的中间序列，要求判断可能使用的算法。

**第一动作**：先找哪一部分已经获得不可逆的“最终位置”证据：

- 右侧逐趟增长的极值后缀 → 优先怀疑冒泡/堆；
- 左侧逐趟增长的全局最小前缀 → 优先怀疑选择；
- 还需要题面交换轨迹/堆性质继续区分。

**检查与退出**：单凭“末尾最大”不能唯一判算法；若多种算法都满足当前提交区域，保留多解，继续寻找 partition、堆性质或有序 run 等额外证据。

## 问题四：快排一趟只保证 partition，不保证两侧有序

一次 partition 后，枢轴处于最终位置；典型语义：

```text
左侧 <= pivot
pivot
右侧 >= pivot
```

但左右两侧内部仍可能无序。

### 局部规则：判断快排中间状态先找候选枢轴

**触发信号**：题目给一趟后的数组，问可能是哪种排序。

**第一动作**：找是否存在某个位置，其左侧所有元素都不大于它、右侧都不小于它。

**检查与退出**：不能要求左右子区间已经各自完全排序，那是把 partition 和递归结果混了。

## 问题五：堆排序同时维护“堆区”和“已排序区”

升序用最大堆：

```text
有效堆 | 已排序后缀
```

每轮：

1. 根最大值与有效堆末端交换；
2. 有效堆长度减 1；
3. 对新根下滤；
4. 已排序后缀扩大 1。

### 检查

已提交后缀不再参加 heapify。中间状态若前半仍满足最大堆、后半已升序且都不小于堆内元素，是很强的堆排证据。

## 问题六：归并排序中间状态看“有序段长度”

自底向上二路归并：

```text
长度1段
-> 长度2段
-> 长度4段
-> 长度8段
...
```

最后一组不足标准长度也可以存在。

### 局部规则：归并中间态先按 run 长度切段

**触发信号**：序列不是全局有序，但看起来每隔固定长度局部有序。

**第一动作**：尝试按 $1,2,4,8,...$ 的 run 长度切分，检查每段是否有序。

**检查与退出**：若同一轮中标准长度的相邻段并非各自有序，或 run 长度不能由上一轮成倍合并得到，就停止把该状态解释为自底向上二路归并。

## 问题七：LSD 基数排序必须“稳定地处理每一位”

最低位优先：

```text
个位稳定分配/收集
-> 十位稳定分配/收集
-> 百位稳定分配/收集
-> ...
```

为什么后一趟要稳定：同一高位桶里的元素必须保留前面低位已经建立的次序。

若有 $d$ 位、基数 $r$：

$$
T=O(d(n+r)).
$$

它不是比较排序，所以不受比较决策树的 $\Omega(n\log n)$ 下界直接约束。

## 问题八：基数排序的“独立位”不是二进制编码的所有位都能随便拆

上传速记稿强调了“每一位有独立类别意义”和“普通二进制数值位”的区别，这个方向值得保留，但做题要落到**排序键的位分解是否与最终全序兼容**。

LSD 对普通非负整数可以按个位、十位或固定基数 digit 处理，因为高位权重严格高于低位，稳定处理各位能恢复数值全序。

若字段只是若干独立类别，需要先确认题目定义的主次关键字顺序；不能因为“有多个 bit/字段”就自动声称任意位序的 LSD 都得到目标顺序。

## 问题九：比较次数、移动次数、空间要分栏

同为 $O(n^2)$：

- 简单选择比较次数固定约 $n(n-1)/2$，交换少；
- 插入的移动量依赖逆序对，近有序时很少；
- 冒泡交换次数与逆序对相关；
- 折半插入比较少但移动不消失。

所以题目只问“关键字比较次数”时，不要把赋值/交换也算进去；问移动次数时也要先确认一次 swap 题目按几次赋值计。

## 问题十：并行性要看“这一阶段是否已经拆成相互独立的子问题”

排序算法是否能并行不能只按算法名字背。408 选择题通常讨论的是**粗粒度主流程**：

- 归并排序：同一层上互不重叠的子段可以分别排序/归并，天然有并行子任务；
- 快速排序：一次 partition 完成后，左右子区间互不重叠，可以并行递归；
- 冒泡排序：经典逐趟版本相邻交换存在强数据依赖，后一趟依赖前一趟状态；
- 堆排序：连续“取根极值 → 末尾交换 → 恢复堆”的主循环存在前后依赖，不能把每轮独立执行；
- LSD 基数排序：高一位处理必须建立在低位稳定次序已经形成的结果上，所以各 digit 趟不能任意并行。

但这只是考试粒度的判断，不表示这些算法内部绝无并行实现。例如一趟基数分配可以并行计数，建堆的同层子树也能做局部并行。题目若明确给更细的并行模型，应按依赖图重新判断，而不是把“算法可/不可并行”当成永久属性。

### 局部规则：并行题先画阶段依赖

**触发信号**：题目给多核 CPU，问某排序的若干子任务能否同时执行。

**第一动作**：把本阶段写成“前一步输出 → 下一步输入”的依赖图；只有彼此不读写同一未决状态、也不依赖对方结果的子任务才可并行。

**检查与退出**：不要把“某实现内部有可并行循环”偷换成“整个排序的各趟彼此独立”；题目若只采用教材经典流程，就按经典阶段依赖回答。

## 代表母题：LSD 基数

待排：

```text
170, 45, 75, 90, 802, 24, 2, 66
```

个位稳定收集后：

```text
170, 90, 802, 2, 24, 45, 75, 66
```

十位稳定收集后：

```text
802, 2, 24, 45, 66, 170, 75, 90
```

百位稳定收集后得到最终升序：

```text
2, 24, 45, 66, 75, 90, 170, 802
```

关键不是桶编号本身，而是每一趟都保留同桶中前一趟的相对次序。

## 代表母题：从中间状态反推

若某趟后：

```text
[2, 4, 7, 9 | 1, 3, 6, 8]
```

两段都各自有序，但整体未合并。它很像“存在长度 4 的有序 runs”的归并中间状态；但如果题目没给“第几趟”或初始状态，还不能仅凭这一条证据唯一断言算法。

## 陌生排序题固定落笔协议

```text
1. 先写排序契约：升/降、重复、稳定性、空间。
2. 中间状态先找已确定前缀/后缀/枢轴/有序段/已处理位。
3. 再认算法，不按“看起来更有序”猜。
4. 比较、移动、交换、递归栈分开计数。
5. 折半插入只优化定位，不消除连续表移动。
6. 快排一趟只保证 partition；堆排要缩有效堆区。
7. LSD 每一位必须稳定，最终位顺序要与目标全序一致。
8. 最后用稳定性反例、最坏输入和已提交区域做独立检查。
```

## 最短压缩

> **排序过程题先找“本趟提交了什么”：前缀、后缀、枢轴、有序 run 或已处理 digit；稳定性只检查相等记录会不会跨越。**
