# CPU 数据通路与控制：把指令契约落实为状态转移

状态：待人工确认；Canonical LaTeX 候选正文已建立并发布。

## 为什么读这册

会背取指、译码、执行、访存、写回，不等于会设计或分析处理器。本册从一条指令承诺的架构状态变化出发，反推所需的值、通路、资源、微操作、控制信号与提交边界。

## Mother Question

怎样用寄存器、组合逻辑、存储接口和控制器，把一条 ISA 指令实现成正确且可计时的状态转移？

## Scope / Stop Boundary

本册负责单条指令的数据通路、微操作、单周期/多周期调度、硬布线/微程序控制和关键路径。

本册不拥有指令编码与 ABI，不展开多指令流水重叠，不定义 Cache、地址翻译或 OS 异常处理策略。

## Owns / Uses

- **Owns**：架构状态与内部状态边界；状态差到通路的生成方法；资源可行性；控制字与阶段转换；单周期和多周期权衡。
- **Uses**：CO02 的 ISA 语义；CO05 的存储接口；后续向 CO04 流水线、CO-B01 和 CO-I01 输出单指令依赖图。
