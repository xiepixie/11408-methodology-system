# 文件索引与 I/O 计算

> 训练定位：面对 inode 混合索引、最大文件大小、字节偏移定位、路径访问与磁盘 I/O 次数题时，训练先锁定逻辑编号和缓存假设，再调用 Canonical 的 block mapping 机制完成计算。  
> 模型归属：[OS-06/07 文件系统与持久化方法论手册](OS-06_OS-07_文件系统与持久化_方法论手册.tex)。direct/single/double/triple、LBN→PBN、页缓存与块映射的定义和公式由 Canonical 正文拥有；本文件只负责落笔流程、变式与检查。

## 局部规则：先把字节位置变成 LBN

**触发信号**：题目给文件内字节偏移、block size，并要求判断落在哪一级索引或访问哪个数据块。

**第一动作**：先写

$$
LBN=\left\lfloor\frac{x}{B}\right\rfloor,
$$

再把 LBN 与 direct / single / double / triple 各自覆盖的逻辑块区间比较。

**检查与退出**：不要直接拿字节偏移和“第几个指针”比较；索引结构映射的是逻辑块编号，不是字节编号。

## 最大文件大小：公式由 Canonical 生成，训练只负责套入边界

设每个索引块可容纳 $K=B/a$ 个块地址，inode 中 direct/single/double/triple 指针数量分别为 $d,s,q,t$。计算题的执行顺序是：

1. 求 $K$；
2. 分别写出各层覆盖的数据块数；
3. 相加得到最大可寻址数据块数；
4. 乘 block size；
5. 最后检查题设是否还有文件长度字段、块号位宽或其他更小上限。

### 局部规则：先数“数据块”，最后再乘块大小

**触发信号**：多级索引公式中同时出现块大小、地址项大小和多重幂次。

**第一动作**：先只在“块的数量”这一单位下计算 direct、$K$、$K^2$、$K^3$ 的覆盖量。

**检查与退出**：如果中间步骤的单位已经变成字节，又继续与块数相加，立即回退；所有覆盖项先统一为 data blocks。

## I/O 次数题：先写假设表

同一个逻辑访问，在不同缓存状态下答案可以不同。正式计数前至少写清：

| 对象 | 当前是否已在内存 / 缓存 |
|---|---|
| 目录块 / dentry | 题设是否需要逐级读盘 |
| inode | 是否已在内存 |
| 单/双/三级间接索引块 | 哪些已经缓存 |
| 数据页 / 页缓存 | hit 还是 miss |
| FAT | 是否假设常驻内存 |
| 写回元数据 | 本题是否计入 |

### 局部规则：先画访问序列，再删缓存命中

**触发信号**：题目问“访问某字节需要几次磁盘 I/O”，并给出若干“已在内存/未缓存”的条件。

**第一动作**：先按机制画出完整对象访问序列，例如 `目录 → inode → 一级索引 → 二级索引 → 数据块`；然后把题设明确已缓存的节点划掉。

**检查与退出**：不要从“二级间接所以三次 I/O”这类记忆直接报数。那只在特定前提下成立。

## 路径查找 I/O：路径层级不是 I/O 次数

`/a/b/c` 有三个 component，不代表固定 3 次或 6 次磁盘访问。每一级解析可能涉及目录对象、目录数据块、目标 inode，还受 dcache/inode cache 影响。

### 局部规则：component 与磁盘对象分开计数

**触发信号**：绝对/相对路径 + “磁盘 I/O 次数”。

**第一动作**：逐 component 写“当前目录对象 → 查目录记录 → 得到下一个对象”，再标记哪些对象已在内存。

**检查与退出**：如果答案只由斜杠数量决定，基本说明没有建模实际访问对象。

## 页缓存与 block mapping：不要把顺序写反

普通 buffered file read 更自然的观察顺序是先按 `(file, page index)` 查页缓存；miss 后才需要文件系统继续建立到存储块的位置关系。

### 局部规则：题目出现页缓存时先判 hit/miss

**触发信号**：同一道题既出现 file offset/LBN/PBN，又明确给 page cache 状态。

**第一动作**：先判断所需文件页是否已经在页缓存；hit 时不应机械继续计底层 block mapping 的磁盘读取。

**检查与退出**：只有 miss 且确实需要后端存储内容时，才继续追到索引块和设备 I/O。

## 常见变式

- 多个 direct / single 指针：先算每一类指针的总覆盖区间，不要默认各只有一个；
- 块地址项大小不整除 block size：按题设使用整数地址项数；
- 访问范围跨块：同时求起止 LBN，不只算起点；
- 写文件增长：除数据块外可能需要新索引块与 free-space metadata；
- ext4 extent 等工程结构：只用于理解边界，408 经典题按题设 mixed indexing 模型计算。

## 最短压缩

```text
byte offset
→ LBN / file page index
→ 当前层级覆盖区间
→ 完整对象访问序列
→ 根据缓存条件删除无需 I/O 的节点
→ 最后计数并检查单位/边界
```

真正容易错的通常不是 $K^2$，而是**没先锁定题目正在数哪一种对象、哪些对象已经在内存**。
