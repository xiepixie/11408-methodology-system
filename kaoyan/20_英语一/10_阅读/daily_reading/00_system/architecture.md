# 系统总架构与职责边界

> **核心原则**：三层分别保存三种不同对象。文章层保存真实材料与单篇训练现场，表达层保存可复用语言工具，能力层保存跨文章的长期能力状态。能用链接表达关系，就不要复制成第二份事实。

---

## 1. 三层母模型

```text
真实材料
   ↓
┌──────────────────────────────┐
│ 1. 文章层                    │
│ 原文 · 来源 · 单篇训练现场     │
└──────────────┬───────────────┘
               │ 萃取 / 引用
               ↓
┌──────────────────────────────┐
│ 2. 表达层                    │
│ 可复用表达 · 语体 · 声音 · 触发 │
└──────────────┬───────────────┘
               │ 调用 / 验证
               ↓
┌──────────────────────────────┐
│ 3. 能力层                    │
│ 长期状态 · 稳定缺陷 · 证据链    │
└──────────────┬───────────────┘
               │ 暴露新的表达需求
               └──────────────→ 表达层
```

三层不是“同一份内容的三种写法”，而是三个不同的数据对象：

- **文章层**回答：这篇文章是什么？我在这篇文章上发生了什么训练？
- **表达层**回答：我拥有哪些以后还会反复使用的语言工具？
- **能力层**回答：跨越多篇文章之后，我目前真正能做到什么，还稳定卡在哪里？

---

## 2. 文章层：原文与单篇训练现场

文章层内部再分成两个职责完全不同的文件对象。

### 2.1 `article.md`：干净的阅读材料

`article.md` 是**原文章本身**。它面向第一次阅读和以后回看，因此应尽量保持干净。

只保存：

- 标题；
- 杂志 / 网站 / 栏目；
- 作者；
- 原始发布日期；
- 必要的来源定位信息；
- 原文正文。

它默认不保存：

- 一句话总结；
- 文章结构分析；
- 生词表；
- 表达卡；
- 发音讲解；
- 复述答案；
- AI 润色结果；
- 能力评级。

原因很简单：`article.md` 的任务是让学习者面对一篇尽可能接近真实阅读环境的文章，而不是面对一份已经被解释过的教材。

### 2.2 `reading_view.tex`：这篇文章的精读训练手札

`reading_view.tex` 保存**只属于这一篇文章的训练内容**，并负责 Cornell 6:4 等适合集中阅读、批注和打印的版式。

它可以保存：

- 原文段落与右栏的局部理解点拨；
- 首读暴露的句法、指代、搭配等断点；
- 本篇值得练的声音句及韵律标注；
- 本篇的结构梳理；
- 复述提纲、口语尝试与必要的 AI 反馈；
- 本篇发现的候选表达，以及它们在表达层中的 ID / 链接；
- 能力层需要引用的训练证据锚点。

它**不负责**长期定义一个表达，也不负责长期维护某项能力等级。

### 2.3 `reading_view.pdf`：纯派生产物

`reading_view.pdf` 由 TeX 编译得到，只用于阅读、平板批注、打印与归档，不承担任何独立事实职责。

### 2.4 `assets/`：原始辅助材料

按需保存：

- 杂志原页截图；
- 原生音频；
- 文章附图；
- 其他无法直接写入正文的辅助材料。

---

## 3. 表达层：长期可复用语言工具

表达层按**沟通功能**组织，而不是按文章来源组织。

一个表达节点的长期信息只在表达层维护，例如：

- 核心沟通功能；
- 典型含义与边界；
- 正式书面 / 中性通用 / 自然口语之间的语体关系；
- 声音形式与常见发音注意点；
- 触发情境；
- 可替换的句型骨架；
- 来源文章链接；
- 调用证据与生命周期。

文章手札若需要使用这些信息，应以 `EXP-xxx` 和链接引用为主，只保留当前语境下理解所必需的简短说明，不再复制整张表达卡。

---

## 4. 能力层：跨文章的长期状态

能力层不是单篇学习记录，也不是每日打卡日志。

它维护的是跨文章逐渐稳定下来的信息：

- 当前能独立完成哪些任务；
- 哪些问题反复出现；
- 当前最值得训练的能力瓶颈；
- 哪些文章 / 对话 / 录音能够作为证据；
- 某个能力判断何时、因何证据发生改变。

例如，某次复述中的一次停顿属于文章层训练现场；只有“多次复述都出现逐词拼接”时，才值得在能力层形成稳定缺陷条目。

---

## 5. 每类文件的唯一职责

| 位置 | 主要对象 | 应保存 | 不应长期维护 |
|---|---|---|---|
| `01_articles/.../article.md` | 原始文章 | 来源信息 + 原文 | 解释、表达卡、能力判断 |
| `01_articles/.../reading_view.tex` | 单篇训练手札 | 本篇精读、声音、复述、对谈、局部反馈 | 表达的长期定义、能力的长期状态 |
| `01_articles/.../reading_view.pdf` | 阅读产物 | TeX 的排版结果 | 任何独立事实 |
| `02_expressions/*.md` | 表达节点 | 可复用表达的完整长期信息 | 整篇文章分析、单日训练流水 |
| `03_capabilities/*.md` | 能力状态 | 稳定能力、缺陷、代表性证据 | 单篇全文、完整对话记录 |
| `00_system/*.md` | 系统规则 | 架构、规范、模板规则 | 具体文章学习内容 |

## 6. 跨层关系：链接优先，复制最小化

### 6.1 文章 → 表达

文章训练手札中发现一个值得长期保留的表达时：

```text
reading_view.tex
  “这里值得积累：an open question → EXP-008”
                      ↓
02_expressions/...md
  EXP-008 的完整长期定义
                      ↓
  来源链接回 article.md 的具体段落
```

文章手札只解释“它在这里为什么重要”；表达层才解释“以后应该怎样使用它”。

### 6.2 文章 → 能力

一次训练如果暴露了值得长期观察的问题：

```text
reading_view.tex
  本次 1 分钟复述出现多次逐词拼接
                      ↓ 作为证据引用
03_capabilities/oral_retell.md
  P01：逐词拼接（若已形成稳定模式）
```

能力层只保留代表性证据链接，不复制整段复述和整份 AI 反馈。

### 6.3 允许的“展示性重复”

TeX 为了排版必须再次呈现部分原文，这是**展示性重复**，不是第二份事实源。

允许重复：

- TeX 标题栏中的来源信息；
- Cornell 左栏中的原文段落；
- 为解释当前语境而引用的一小段表达。

不允许重复维护：

- 两份不同版本的原文正文；
- 文章手札和表达层各自维护一整套表达定义；
- 文章层和能力层各自维护一套能力评级。

一旦原文转写有纠错，先改 `article.md`，再同步到 TeX 阅读视图。

## 7. 内容数量采用自适应原则

系统不规定“每篇必须提取几条表达、几句黄金句、几轮对谈”。数量由以下因素共同决定：

1. 文章篇幅；
2. 语言密度；
3. 文章本身的表达质量；
4. 学习者当前能力与目标；
5. 当天可投入时间；
6. 新内容与现有表达网络的重复程度。

原则是：

> **短文少取，长文可多取；低价值不凑数，高质量也不因固定上限被迫丢掉。**

完成标准因此应以“训练功能是否闭环”为主，而不是以数量打卡为主。

---

## 8. 最终飞轮

```text
article.md：先真实阅读
        ↓
reading_view.tex：处理本篇理解与输出
        ↓
值得长期保存？
   ├─ 否 → 留在单篇训练现场
   └─ 是 → 进入表达层
                  ↓
              真实调用
                  ↓
       稳定能力变化 / 稳定缺陷？
           ├─ 否 → 仍留作单次证据
           └─ 是 → 更新能力层
```

系统追求的不是“每篇都做成一本教材”，而是让三类信息各归其位：

> **原文保持干净，单篇训练保持具体，长期表达保持可复用，能力判断保持有证据。**
