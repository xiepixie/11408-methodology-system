# 单篇文章训练规范

> **定位**：本文只规定文章层如何工作：原文如何保存、单篇训练手札如何组织、哪些信息应该留在本篇，哪些信息应该链接到表达层或能力层。

---

## 1. 文章层包含两个不同对象

一篇文章目录下至少区分：

```text
文章本身                单篇训练手札
article.md        +      reading_view.tex
   ↓                         ↓
真实阅读材料                精读、声音与输出训练
```

这两个文件不能混成一份“大而全笔记”。

### `article.md`

面向学习者直接阅读。

保存：

- 文章标题；
- 作者；
- 杂志 / 网站 / 栏目；
- 原始发布日期；
- 必要的来源信息；
- 原文正文。

不保存：

- 总结；
- 结构拆解；
- 生词讲解；
- 表达提取；
- 发音标注；
- 复述答案；
- AI 反馈；
- 能力判断。

### `reading_view.tex`

面向精读训练与打印 / 平板学习。

保存这一篇文章独有的训练信息，例如：

- 原文与局部理解点拨；
- 首读真实断点；
- 文章结构；
- 候选表达及表达层引用；
- 语音与韵律训练；
- 复述、观点、对谈；
- 本篇暴露出的主动表达缺口；
- 可供能力层引用的训练证据。

它是“本篇训练现场”的所有者，但不是表达节点和能力状态的长期所有者。

---

## 2. `article.md` 的推荐结构

保持极简即可：

```markdown
# Article Title

## 来源

- 杂志 / 网站：...
- 栏目：...
- 作者：...
- 原始发布日期：...
- 原文定位：...

---

正文第一段……

正文第二段……
```

不要在正文中插入训练入口、学习答案、表达编号或解释标记，以免破坏第一次阅读。训练文件通过同目录结构和 `01_articles/README.md` 统一导航。

---

## 3. `reading_view.tex` 应该承载什么

Cornell 6:4 的核心不是“左边原文、右边塞满知识”，而是让**原文和当前段落真正需要的训练信息紧邻出现**。

### 3.1 题头

只放必要信息：

- 标题；
- 来源；
- 作者 / 日期；
- 主题；
- 返回 `article.md` 的定位信息。

题头不需要提前给出整篇答案式总结。

### 3.2 双栏精读区

左栏：

- 原文段落；
- 必要的轻量锚点。

篇幅较短或需要逐段训练时，可以完整呈现全文；篇幅很长时，只呈现真正需要精读的段落，并通过段落编号回链 `article.md`。不要为了让 TeX “看起来完整”机械复制整篇长文。

右栏优先放：

- 为什么这里难懂；
- 结构如何挂接；
- 当前语境下某个词 / 搭配真正是什么意思；
- 一句更自然的口语重构；
- 候选表达的 `EXP-xxx` 引用。

右栏不复制表达层的完整六维节点。

### 3.3 文章结构区

训练完成后，用适合当前文本类型的方式还原结构。

不要强行套统一模板。比如：

- 新闻：发现 → 证据 → 解释 → 不同观点 → 后续；
- 评论：问题 → 立场 → 理由 → 让步 / 反方 → 结论；
- 科普：现象 → 原理 → 例子 → 限制 → 启示；
- 叙事专栏：场景 → 经历 → 转折 → 观察 → 判断。

这部分属于本篇训练，因此保留在 TeX 手札中即可。

### 3.4 语调与韵律剖析区

选取真正值得剖析的句子，记录：

- 原句；
- 意群切分（`\chunk`、`\majorpause`）；
- 信息重音焦点（`\stress{...}`）；
- 典型功能词弱读（`\weak{...}`）与连读（`\phonlink`）；
- 语调走向（`\tonefall`、`\tonerise`）；
- 句子发音难点与朗读节奏要点。

句子数量根据文章长度、句法语调价值和训练时间自适应决定，不为凑数设置固定配额。

### 3.5 输出训练区

根据文章长度和目标选择适合的输出任务，例如：

- 极短概括；
- 结构化复述；
- 更完整的长复述；
- 个人观点；
- AI 多轮对谈。

常用的 30 秒、1 分钟只是训练尺度，不是所有文章都必须机械完成同样时长。

### 3.6 本篇沉淀区

这里只记录“这篇文章最后向外输送了什么”：

- 进入表达层的 `EXP-xxx`；
- 仍只保留为本篇候选的表达；
- 值得能力层引用的证据；
- 需要后续复习的关键问题。

详细表达定义去 `02_expressions/` 看；长期能力判断去 `03_capabilities/` 看。

## 4. 信息数量采用自适应原则

不为单篇文章设置统一硬上限。

决定提取深度时，综合考虑：

- 篇幅长短；
- 信息密度；
- 原文语言质量；
- 当前学习目标；
- 已有表达库是否已有同类表达；
- 当天训练时间。

原则：

> **文章本身决定训练密度，学习价值决定保留密度。**

因此可能出现：

- 短文章只有少量真正值得长期保留的内容；
- 一篇语言极好的长文值得多练几处；
- 一篇主题很重要但语言迁移价值一般的文章，理解可以深入，表达却少入库。

不要为了满足固定数字破坏文章的自然差异。

---

## 5. 哪些内容只留在本篇

通常只属于本篇训练现场的内容包括：

- 某一句的句法挂接；
- 某段的指代关系；
- 当前文章才需要的背景解释；
- 本篇结构图；
- 本次复述原始版本；
- 本次 AI 对话中的局部纠错；
- 只在当前主题中出现的专业词。

它们没有必要全部上升成长期知识资产。

---

## 6. 哪些内容应该离开本篇

### 进入表达层

当某个表达具备明显跨语境复用价值时，在 TeX 中留下引用，然后在表达层维护完整节点。

```text
本篇：
“remain an open question → EXP-008”

表达层：
EXP-008 的沟通功能、语体、声音、触发、骨架、调用证据……
```

### 进入能力层

单次失误默认不进入能力层。只有某个问题逐渐成为稳定模式，或者某次表现是很有代表性的能力证据时，能力层才建立条目并链接回来。

---

## 7. 一篇文章什么时候算训练闭环

不用按固定条数打勾，而看以下功能是否完成：

- **理解闭环**：关键阅读断点已经真正解释清楚；
- **结构闭环**：能脱离原文说清文章如何展开；
- **声音闭环**：最值得练的声音问题已经得到针对性练习；
- **表达闭环**：真正有长期价值的表达已经筛出并正确归档；
- **输出闭环**：能用自己的英语复述或讨论，而不是只会重新阅读；
- **反馈闭环**：本次训练暴露出的重要问题有去处——留在本篇、进入表达层，或成为能力层证据。

文章长短不同，完成这些闭环所需的练习量自然不同。

## 8. 推荐目录

```text
01_articles/
└── YYYY/
    └── YYYY-MM-DD_short_title/
        ├── article.md          # 干净原文 + 来源
        ├── reading_view.tex    # 本篇精读训练手札
        ├── reading_view.pdf    # 编译产物
        └── assets/             # 原页、音频、附图等（按需）
```

这里没有额外的 `study.md`。如果未来确实需要网页化、数据库化，再根据实际需求引入中间结构；当前阶段优先保持对象少、职责清楚。
