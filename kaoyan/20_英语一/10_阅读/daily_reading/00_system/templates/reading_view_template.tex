\readingsection{二、文章结构与主旨复原}

\begin{coretakeaway}[训练后主旨]
  用自己的英语写下文章最核心的命题。不要照抄导语；如果还说不清，说明结构尚未真正建立。
\end{coretakeaway}

\begin{itemize}
  \item \textbf{结构节点 1}：根据真实文体填写，例如发现 / 场景 / 问题。
  \item \textbf{结构节点 2}：证据 / 原因 / 经历 / 转折。
  \item \textbf{结构节点 3}：不同观点 / 限制 / 结果 / 判断。
\end{itemize}

\readingsection{四、脱稿输出与观点}

\oralblock{快速概括}{
  用最短的完整表达讲清“这篇文章到底在说什么”。短文可以很短，长文可以适当延长。
}

\oralblock{结构复述}{
  按上一节的真实结构脱稿复述。记录学习者真实版本，而不是直接写 AI 的成品答案。
}

\oralblock{个人观点 / 迁移讨论}{
  选择最值得讨论的问题。重点观察是否能够自然调用已有表达网络，而不是追求词汇华丽。
}

\end{aiinteraction}
