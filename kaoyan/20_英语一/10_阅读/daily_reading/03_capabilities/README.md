# 能力层总览

> **定位**：能力层记录跨文章逐渐稳定下来的能力状态、主要问题和代表性证据，不保存每天的训练流水账。

---

## 1. 能力层只回答三类问题

1. **现在能做到什么**：例如能否独立概括、结构化复述、展开观点或完成无提示多轮对谈；
2. **当前稳定卡在哪里**：例如逐词拼接、意群内部停顿、已学表达长期无法主动调用；
3. **什么证据说明状态发生了变化**：必须来自真实复述、录音、对谈、写作或迁移任务。

没有经过对应标准化评估时，不填写 CEFR 等正式等级。优先使用可观察、可验证的内部描述。

## 3. 一个问题什么时候进入能力层

单次口误、一次停顿或 AI 的推测，默认留在对应文章的训练现场。

只有当同类现象在不同训练中反复出现，并且同时满足下面两个条件时，才建议升级为长期能力问题：

- 对真实沟通或任务表现有明显影响；
- 值得在后续训练中持续观察或专门处理。

推荐记录结构：

```markdown
### `[PXX] 问题名称`

- **可观察症状**：实际发生了什么；
- **常见触发条件**：什么任务中更容易出现；
- **可能原因**：如果只是推测，明确标注为假设；
- **当前训练动作**：下一次优先怎么练；
- **代表性证据**：链接到能够说明问题的具体文章或任务。
```

## 5. 能力文件怎样维护

能力文件保持“当前状态优先”：

- 当前基线和当前问题放在前面；
- 已解决的问题移入简短历史记录；
- 训练证据只保留代表性样本；
- 完整复述、逐句纠错、长对话和原始录音仍留在对应文章或原始材料中；
- 每个结论都能回答“我是根据哪次真实任务得出的”。

能力层的价值不在于建立复杂评级，而在于让下一次训练立刻知道：

> **现在最值得改什么，以及用什么任务验证它是否真的改善。**
