# 能力层总览

> **定位**：能力层记录当前能力状态、稳定出现的缺陷模式和代表性任务证据，不保存每天的训练流水账。

---

## 1. 能力层回答什么问题

能力层只回答三类问题：

1. **现在能做到什么**：例如能否完成快速概括、结构化脱稿复述、无提示多轮对谈；
2. **当前稳定卡在哪里**：例如逐词拼接、从句重启、目标表达长期无法主动调用；
3. **什么证据说明状态发生了变化**：必须来自真实复述、录音、对谈、写作或迁移任务。

不要因为某次练习“感觉不错”就填写 CEFR 等正式能力等级。若没有经过对应标准化评估，应使用内部、可观察的能力描述。

## 3. 缺陷模式如何建立

只有当同一问题在不同训练中反复出现，并且已经表现出一定稳定性时，才建议升级为能力层的长期缺陷模式。

单次口误、一次卡顿或 AI 推测，不应直接写成长期结论；这类现象可以先留在文章训练现场，等待后续证据确认。

推荐格式：

```markdown
### `[PXX] 缺陷名称`

- **可观察症状**：实际发生了什么；
- **触发条件**：什么任务中更容易出现；
- **可能原因**：若只是推测，要明确标注为假设；
- **当前对策**：下一阶段训练第一动作；
- **代表证据**：链接到能够说明问题的具体文章或任务。
```

## 5. 能力状态的更新原则

能力文件应保持“当前状态优先”：

- 当前基线放在最前面；
- 已解决的问题移入简短历史记录，不长期占据正文中心；
- 训练证据只保留代表性样本；
- 原始长对话、逐句纠错和完整录音记录留在文章层或原始训练材料中；
- 每个结论都能回答“我是根据哪次真实任务得出的”。

能力层的最终目的不是制造一套复杂评级，而是帮助下一次训练立刻知道：

> **我现在最应该改哪一个问题，以及用什么任务验证它是否真的改善。**
