# 文章层

> **职责**：保存真实文章，并记录只属于某一篇文章的训练现场。文章层不长期定义表达，也不维护跨文章能力结论。

---

## 1. 单篇文章目录

```text
YYYY-MM-DD_short_title/
├── article.md
├── reading_view.tex
├── reading_view.pdf
└── assets/
```

### `article.md`：Obsidian 原文阅读与首读标记页

面向第一次阅读和以后回看。

保存：

- Obsidian Properties 中的必要来源信息；
- 标题与原文；
- 段落块标识 `^p01`、`^p02`……；
- 学习者自己的 `==高亮== [标记]` 首读痕迹。

允许学习者直接标记；AI 不得把学习答案写回正文。总结、结构、表达讲解、发音与纠错统一进入训练手札。

推荐标记：

- `==...== [?]`：确实不懂；
- `==...== [!]`：结构 / 指代断开；
- `==...== [★]`：主动想学；
- `==...== [~]`：理解不确定。

完整交互规范见 [`../00_system/obsidian_interaction.md`](../00_system/obsidian_interaction.md)。

### `reading_view.tex`：单篇精读训练手札

面向训练。

可以保存：

- Cornell 双栏精读；
- 理解断点；
- 本篇结构；
- 声音与韵律训练；
- 复述和观点输出；
- AI 对谈中的关键反馈；
- 候选表达及其 `EXP-xxx` 引用；
- 能力层可以引用的证据。

具有跨文章长期价值的表达，应在 `02_expressions/` 中建立完整节点；TeX 只保留当前语境所需的简短说明和链接。

### `reading_view.pdf`：阅读与批注产物

由 TeX 编译，不直接维护内容。

### `assets/`：辅助材料

只有实际需要时才创建，用于保存原页截图、文章音频、附图等辅助材料。

---

## 2. 文章层内部的数据边界

```text
article.md
   │ 提供原文
   ↓
reading_view.tex
   │ 产生候选表达 / 训练证据
   ├────────→ 02_expressions/
   └────────→ 03_capabilities/
```

TeX 中再次呈现原文是排版需要，不代表 TeX 拥有另一份独立原文。原文转写若有纠错，以 `article.md` 为准，再同步训练版。

跨层引用优先使用 Obsidian 原生块链接，例如 `article.md#^p04`，而不是额外插入 HTML 锚点。

---

## 3. 不新增 `study.md`

当前阶段不再增加一个与 TeX 平行的 `study.md`。

原因是：

- `article.md` 已承担原文阅读与学习者首读标记；
- `reading_view.tex` 已承担单篇训练手札；
- 表达和能力又分别有自己的长期所有者。

再增加一份结构化学习笔记，会让同一训练内容出现第三个维护位置。只有未来确实需要网页或数据库自动渲染，并且已经有明确生成链路时，再评估是否引入中间数据层。
