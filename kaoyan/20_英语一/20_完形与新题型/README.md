# 英语一完形填空与新题型方法论

> 类型：Topic Group  
> 状态：索引/导航；本目录聚合两个独立 Topic，不拥有英语一全局 Atlas。

## 1. Canonical Topics

- **完形填空**：[`英语一_完形填空_多层语言约束下的词项恢复方法论手册_v1.tex`](英语一_完形填空_多层语言约束下的词项恢复方法论手册_v1.tex)
  - Canonical Object：被删除的词项 / 短语。
  - 核心问题：哪个候选能使句法、搭配、句义、关系与语篇约束重新同时成立？
  - 母模型：`Missing Word + Context -> Constraints -> Best-Supported Candidate`。

- **新题型**：[`英语一_新题型_衔接连贯与语篇结构重构方法论手册_v1.tex`](英语一_新题型_衔接连贯与语篇结构重构方法论手册_v1.tex)
  - Canonical Object：语篇单元之间的关系、顺序与功能。
  - 核心问题：怎样根据可验证关系恢复被删除、打乱或隐藏的语篇结构？
  - 母模型：`Discourse Unit + Relation + Function -> Reconstructed Structure`。

两册共享语言资源与“证据必须解释结论”的纪律，但不互相拥有对方机制。
