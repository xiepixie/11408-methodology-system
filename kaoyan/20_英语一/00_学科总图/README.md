## 2. Atlas 的 Canonical Responsibility

本册只 Own：

1. 英语一的母问题与学科坐标；
2. Activity / Resource System / Processing 三个坐标及其关系；
3. Proficiency / Performance / Score 的边界；
4. Exam Adapter；
5. 各 Topic / Control 的位置与 Canonical Owner；
6. 新知识进入体系时的路由规则。

完整的 `How / Mechanism / Boundary / Cost` 下沉 Topic；题目信号、第一动作、Route、Verify 进入 Control；个人错题、训练闭环与 First Breakpoint 属于 Practice / Evidence System。
