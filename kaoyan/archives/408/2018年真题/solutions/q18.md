# 408-2018-Q18

## Model Anchor

- Topic：数组地址生成与变址寄存器语义。
- 题目信号：`EA = base + index × sizeof(double)`，问进入该次循环时 index。
- 第一动作：先算地址差，再除元素宽度；不要把十六进制地址差直接当数组下标。

## 解题链

数组首地址为 `2000H`，本次元素地址为 `2100H`，因此字节偏移为

$$\mathtt{2100_H}-\mathtt{2000_H}=\mathtt{100_H}=256.$$

`double` 占 8 B，所以

$$index=\frac{256}{8}=32.$$

题目说明“取完后变址寄存器自动加 1”，因此进入这次循环时寄存器仍保存当前元素下标 32。

## 选项判断

故选 $\boxed{B}$。

## Verification

$2000_H+32\times8=2000_H+100_H=2100_H$，可直接回代地址生成式。

## Compression

```text
EA-base -> byte offset -> divide element size -> index
```

## 易错边界

自动加 1 发生在“取完后”，不要误用下一次循环的 33。
