# 408-2018-Q22

## Model Anchor

- Topic：外部 I/O 中断的检测、响应与现场保护边界。
- 题目信号：四个选项分别混入优先级、硬件响应、现场保护和响应时机。
- 第一动作：按 `request -> mask/priority -> instruction boundary -> hardware response -> software handler` 分层判断。

## 解题链

A 错：中断优先级由中断控制逻辑/优先级策略决定，不是简单按请求先后排队。

B 错：中断隐指令通常负责保存断点和必要状态、转入中断入口；通用寄存器的完整保护一般由中断服务程序软件完成。

C 对：对可屏蔽的外部设备中断，CPU 必须处于中断允许状态且请求未被屏蔽，才会响应。

D 错：CPU 不会在任意指令执行到一半时立刻转走，通常在当前指令执行结束后的边界检测并响应。

## 选项判断

故选 $\boxed{C}$。

## Verification

若 D 成立，就可能留下半提交的体系结构状态，破坏精确执行边界；这与通常的中断响应模型矛盾。

## Compression

```text
IRQ -> eligible? -> instruction boundary -> hardware saves minimum -> handler saves rest
```

## 易错边界

“硬件中断响应”与“中断服务程序保存现场”不是同一阶段。
