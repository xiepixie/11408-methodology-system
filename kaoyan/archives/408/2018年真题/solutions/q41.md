# 408-2018-Q41

## Model Anchor

- Topic：最小缺失正整数（First Missing Positive）的候选域压缩与直接寻址标记。
- 题目信号：数组长度为 $n$，元素值可任意，但只问“未出现的最小正整数”，并要求时间尽可能高效。
- 第一动作：先证明答案的候选范围只有 $[1,n+1]$，把无限整数域压缩成有限状态，再选择能 $O(1)$ 查询“是否出现”的表示。

## Problem Representation

题目真正需要维护的不是所有整数，而是集合

$$\{1,2,\ldots,n\}$$

中哪些数出现过。

为什么只需看这个范围？数组只有 $n$ 个位置：

- 若 $1\sim n$ 中有任意一个没出现，答案就在 $1\sim n$；
- 若 $1\sim n$ 全部出现，那么最小缺失正整数只能是 $n+1$。

因此所有 $\le0$ 或 $>n$ 的元素对答案没有直接贡献，可以忽略。

### Operation Contract

```text
Input : n 个任意整数
State : present[v] 表示正整数 v 是否出现，1<=v<=n
Output: 第一个 present[v]=false 的 v；若不存在则 n+1
```

## Decision Points

若排序后扫描，需要 $O(n\log n)$；逐个候选回原数组查找会退化到 $O(n^2)$。

由于题目只要求时间尽可能高效，没有要求 $O(1)$ 辅助空间，使用长度为 $n$ 的布尔标记数组最直接：一次扫描建立状态，一次扫描生成答案，总时间 $O(n)$。任何算法至少需要检查输入中的元素，因此 $O(n)$ 已达到线性下界。

## Solution Chain

### (1) 基本思想

建立 `present[1..n]`，初始全为 false。扫描原数组：若

$$1\le A[i]\le n,$$

则令 `present[A[i]] = true`。

随后从 1 开始寻找第一个未出现的位置；若 1～n 都出现，则返回 n+1。

### (2) C 语言描述

```c
int findMissMin(const int A[], int n)
{
    int *present = (int *)calloc(n + 1, sizeof(int));
    if (present == NULL) return -1;   // 工程性失败处理，考试可省略

    for (int i = 0; i < n; ++i) {
        if (A[i] >= 1 && A[i] <= n)
            present[A[i]] = 1;
    }

    for (int v = 1; v <= n; ++v) {
        if (!present[v]) {
            free(present);
            return v;
        }
    }

    free(present);
    return n + 1;
}
```

### State / Invariant

扫描完前 $i$ 个元素后，对任意 $v\in[1,n]$：

```text
present[v] = 1
iff
v 已经在 A[0..i-1] 中出现过
```

第二次扫描从小到大寻找第一个 false，因此找到的第一个 $v$ 必然是“最小”缺失正整数。

### Why Correct

候选域证明保证答案不会落在 $n+2$ 或更大值；状态不变量保证 `present` 与原数组中 $1\sim n$ 的出现关系完全一致；按升序找第一个缺口，因此输出同时满足“正整数、未出现、最小”。

### (3) 复杂度

两次线性扫描：

$$T(n)=O(n).$$

辅助标记数组：

$$S(n)=O(n).$$

这是标准评分路径下的线性时间方案。

## Verification

对 `{ -5,3,2,3 }`，`present[1..4] = [0,1,1,0]`，第一处缺口为 1。

对 `{1,2,3}`，`present[1..3]` 全为 1，因此返回 4。

还可用边界样例 `{100,100}`：所有超出 `[1,2]` 的值都应忽略，立即得到答案 1。

另外，legacy 旧代码只判断 `num > 0` 后直接访问 `vis[num-1]`，当 `num>n` 时会越界；本题正确边界必须是 `1 <= num <= n`。

## Compression

```text
n elements
-> answer must be in [1,n+1]
-> ignore <=0 and >n
-> mark presence of 1..n in one pass
-> first unmarked value; otherwise n+1
-> O(n) time
```

## 易错边界

- 先证明候选域，再开数组；否则容易让超大正整数造成越界。
- “时间尽可能高效”并不自动要求 $O(1)$ 空间；标准解用 $O(n)$ 空间换到最优 $O(n)$ 时间。
- 若题目额外允许修改输入数组，还可用原地位置交换做到 $O(n)$ 时间、$O(1)$ 额外空间，但那是更强约束下的扩展，不应覆盖本题标准评分路径。
