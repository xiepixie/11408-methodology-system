# 408-2018-Q10

## Model Anchor

- Topic：希尔排序的分组插入状态。
- 题目信号：给出连续两趟结果，反推增量序列。
- 第一动作：对候选增量 $d$ 按下标模 $d$ 分组，检查每个子序列在该趟结束后是否已经组内有序。

## 解题链

第一趟结果是

```text
1,3,7,5,2,6,4,9,11,10,8
```

用增量 5 分组时，下标相差 5 的元素分别做插入排序，可以得到这一状态；增量 3 无法保持该结果中的组内次序。

在第一趟结果基础上再用增量 3，三个模 3 子序列分别有序化，得到

```text
1,2,6,4,3,7,5,8,11,10,9
```

与题给第二趟完全一致。

## 选项判断

两趟增量依次为 `5,3`，故选 $\boxed{D}$。

## Verification

希尔排序每一趟的必要条件是：结果对该趟增量而言，每个等距子序列都已排序。用这一不变量可以反向检验，而不必猜具体交换过程。

## Compression

```text
candidate gap d -> split indices by mod d -> every subsequence must be sorted -> match next state
```

## 易错边界

一趟希尔排序不是“整体接近有序”就够了；必须检查对应增量下的所有分组。
