# 408-2018-Q38

## Model Anchor

- Topic：CIDR 路由聚合与公共前缀。
- 题目信号：4 个连续 `/21` 网络、转发接口相同，要求聚合成一条。
- 第一动作：比较网络地址发生变化的最高有效位，找四个网络的最长公共二进制前缀。

## 解题链

第三字节依次为 32、40、48、56：

```text
32 = 0010 0000
40 = 0010 1000
48 = 0011 0000
56 = 0011 1000
```

四者前 3 位 `001` 相同，而第 4 位已经分叉。因此原来 `/16` 之后还能共同保留 3 位，聚合前缀长度为

$$16+3=19.$$

公共前缀从第三字节 32 开始，所以聚合网络为

$$\boxed{35.230.32.0/19}.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

`/19` 覆盖第三字节 32～63，恰好完整包含 32/21、40/21、48/21、56/21，没有额外跨出到 0～31 或 64 以上。

## Compression

```text
same next hop + contiguous CIDR blocks
-> binary common prefix
-> aggregate at first differing bit
```

## 易错边界

聚合不能只按“4 个 /21 所以减 2 位”机械处理；还必须确认四个块按正确边界连续对齐。
