# 408-2018-Q27

## Model Anchor

- Topic：进程状态迁移的触发事件。
- 题目信号：问“可能导致当前进程阻塞”，要区分 Blocked 与 Ready。
- 第一动作：逐项问：事件发生后，进程是在**等待某条件**，还是只是失去 CPU 使用权？

## 解题链

I 申请临界资源：若资源已被占用，P 必须等待资源可用，可由 Running 转入 Blocked，成立。

II 从磁盘读数据：若发出 I/O 后需等待完成，P 会阻塞，成立。

III CPU 分配给更高优先级进程：这是抢占，当前 P 通常从 Running 转为 Ready；它仍具备运行条件，只是暂时没有 CPU，因此不是阻塞。

## 选项判断

仅 I、II，故选 $\boxed{C}$。

## Verification

状态不变量：Blocked 表示“即使现在给 CPU 也无法继续”，Ready 表示“只缺 CPU”。III 显然只缺 CPU。

## Compression

```text
waiting for event/resource -> Blocked
only preempted from CPU -> Ready
```

## 易错边界

“没有运行”不等于“阻塞”。调度题最重要的第一问是：进程当前缺的是 CPU，还是某个外部条件？
