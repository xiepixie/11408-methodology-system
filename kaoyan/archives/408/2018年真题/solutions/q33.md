# 408-2018-Q33

## Model Anchor

- Topic：应用层协议与传输层服务选择。
- 题目信号：问哪个应用层协议“可以使用无连接服务”。
- 第一动作：先找传输层 Owner：UDP 提供无连接服务，TCP 提供面向连接的可靠字节流；再映射常见应用协议。

## 解题链

FTP、SMTP、HTTP 的经典工作方式依赖 TCP。

DNS 的普通查询/响应通常可直接使用 UDP，以较小开销完成一次请求—响应；在需要更大报文或特定场景时也可使用 TCP，但题目问的是“可以使用无连接服务”。

## 选项判断

故选 $\boxed{B}$。

## Verification

DNS 查询天然是短请求—短响应事务，不要求先建立长期传输连接；这与 UDP 的低开销模型匹配。

## Compression

```text
connectionless transport -> UDP -> DNS can use UDP
```

## 易错边界

“可以使用 UDP”不等于“只能使用 UDP”；协议在不同场景可以有多种传输方式。
