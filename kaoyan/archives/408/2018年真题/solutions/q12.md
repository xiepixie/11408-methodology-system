# 408-2018-Q12

## Model Anchor

- Topic：二进制表示的工程动机。
- 题目信号：问“主要原因”，三个判断都涉及 Representation 与 Physical Realization 的对应。
- 第一动作：把抽象编码优势与硬件实现优势分别检查，而不是只背“0/1 容易表示”。

## 解题链

I：二进制只有 0、1，两类基本运算规则简单，正确。

II：实际电子器件构造两个稳定状态比构造大量精确稳定状态容易，正确。

III：布尔逻辑与二进制天然匹配，算术运算可分解为逻辑门网络实现，正确。

## 选项判断

I、II、III 均成立，故选 $\boxed{D}$。

## Verification

从“抽象规则简单 + 物理状态可靠 + 逻辑电路可组合”三个层面都能独立支持二进制作为机器表示。

## Compression

```text
binary -> simple algebra + robust two-state devices + Boolean circuits
```

## 易错边界

“二进制最省存储”不是普遍成立的核心理由；这里考的是表示与硬件实现之间的匹配。
