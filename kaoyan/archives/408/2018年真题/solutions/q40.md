# 408-2018-Q40

## Model Anchor

- Topic：SMTP 的消息表示边界与 MIME 扩展。
- 题目信号：问“无需转换即可直接传输”的内容。
- 第一动作：先锁定经典 SMTP 的文本传输合同：原生面向 ASCII 文本；二进制/多媒体内容需额外编码封装。

## 解题链

JPEG、MPEG、EXE 都包含任意二进制字节序列。经典 SMTP 直接传输的消息体按 ASCII 文本模型设计，这些二进制对象通常需要 MIME 等机制进行编码后再传输。

ASCII 文本本身已经满足 SMTP 的直接文本表示要求，无需再做二进制到文本的转换。

## 选项判断

故选 $\boxed{D}$。

## Verification

JPEG/MPEG/EXE 都可能包含控制字节或任意 8 位模式；ASCII 文本则天然落在 SMTP 的基础字符域内。

## Compression

```text
classic SMTP -> ASCII text contract
binary media/executable -> encode via MIME
ASCII -> direct
```

## 易错边界

现代邮件系统能发送附件，是因为 MIME 等扩展完成了表示转换；不能反推 SMTP 基础协议原生就是任意二进制传输。
