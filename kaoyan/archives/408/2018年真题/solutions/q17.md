# 408-2018-Q17

## Model Anchor

- Topic：DRAM 地址复用与刷新成本。
- 题目信号：总容量固定为 2K×1，既要求地址引脚最少，又要求尽量减少刷新开销。
- 第一动作：把两个目标分开：地址引脚数由 `max(log2 r, log2 c)` 决定；刷新次数主要由行数 `r` 决定。

## 解题链

存储单元总数满足

$$r\times c=2048=2^{11}.$$

DRAM 行、列地址复用同一组地址引脚，因此所需引脚数为

$$\max(\log_2 r,\log_2 c).$$

`64×32` 与 `32×64` 都只需 6 根地址引脚，已经达到给定选项中的最小值。

在引脚数相同的前提下，刷新按行进行；行数越少，完整刷新一遍所需行刷新次数越少。因此应选

$$r=32,\quad c=64.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

A 需要 11 根地址引脚；D 需要 11 根。B/C 都需 6 根，但 C 只有 32 行，刷新负担更小。

## Compression

```text
capacity fixed -> balance row/column for pin count -> tie-break by fewer rows for refresh
```

## 易错边界

“行列越接近越好”只解决地址引脚目标；题目还有刷新成本这一第二目标，必须继续比较。
