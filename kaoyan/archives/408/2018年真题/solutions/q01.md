# 408-2018-Q01

## Model Anchor

- Topic：栈的状态演化与后缀求值。
- 题目信号：两个栈分别保存操作数与运算符，函数固定执行 `b op a`。
- 第一动作：逐次写出两个栈顶被谁消费、结果回到哪里，绝不能把 `a op b` 与 `b op a` 对调。

## 解题链

初始 S1 从栈底到栈顶为 `5,8,3,2`，S2 为 `×,-,+`。

```text
F1: a=2, b=3, op=+  -> 3+2=5   => S1: 5,8,5
F2: a=5, b=8, op=-  -> 8-5=3   => S1: 5,3
F3: a=3, b=5, op=×  -> 5×3=15  => S1: 15
```

## 选项判断

最终栈顶为 `15`，故选 $\boxed{B}$。A/C/D 都来自操作数顺序或中间状态维护错误。

## Verification

三次 F() 每次使 S1 元素数减 1；4 个操作数经过 3 次运算后应恰好剩 1 个结果，与状态链一致。

## Compression

```text
pop a -> pop b -> pop op -> compute b op a -> push result
```

## 易错边界

减法、除法等非交换运算必须保留题目规定的操作数方向。
