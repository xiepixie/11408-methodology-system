# 408-2018-Q19

## Model Anchor

- Topic：减法的无符号借位 CF 与有符号溢出 OF。
- 题目信号：同一个 32 位减法同时问 CF、OF。
- 第一动作：把两种解释分开：CF 看无符号借位；OF 看补码有符号结果是否越界。

## 解题链

计算

$$\mathtt{FFFFFFFF_H}-\mathtt{FFFFFFF0_H}=\mathtt{0000000F_H}.$$

按无符号数看，$FFFFFFFF_H > FFFFFFF0_H$，减法不需要向最高位借位，因此

$$CF=0.$$

按有符号补码看：

$$-1-(-16)=15,$$

15 在 32 位有符号范围内，因此

$$OF=0.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

结果 `0000000FH` 同时符合两种解释：无符号结果为 15；有符号结果也为 15，均无异常边界。

## Compression

```text
same subtraction
-> unsigned view checks borrow/CF
-> signed view checks representability/OF
```

## 易错边界

CF 与 OF 不属于同一数值语义，不能因为结果符号或最高位状态相同就同步判断。
