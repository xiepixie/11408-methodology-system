# 408-2018-Q16

## Model Anchor

- Topic：逻辑移位与算术移位的符号语义。
- 题目信号：同一 8 位机器数分别做逻辑右移和算术右移。
- 第一动作：先区分“空出的最高位由谁填”：逻辑右移补 0；算术右移复制原符号位。

## 解题链

原机器数：

```text
11011000
```

逻辑右移 1 位：最高位补 0：

```text
01101100
```

算术右移 1 位：原最高位为 1，复制符号位：

```text
11101100
```

## 选项判断

故选 $\boxed{B}$。

## Verification

若把原数按 8 位补码解释为负数，算术右移应近似实现除以 2，并保持负号；`11101100` 仍为负，逻辑右移结果则变成正数，符合两种操作的语义差异。

## Compression

```text
logical >> -> zero fill
arithmetic >> -> sign fill
```

## 易错边界

算术右移是否补 1 取决于原符号位，不是固定补 1。
