# 408-2018-Q14

## Model Anchor

- Topic：IEEE 754 单精度规格化边界。
- 题目信号：问“最小规格化正数”，关键是最小非零规格化阶码，而不是非规格化数。
- 第一动作：固定规格化尾数最小为 $1.0$，再取最小规格化指数。

## 解题链

单精度指数域 8 位，偏置为 127。规格化数的指数域不能为全 0，因此最小规格化指数域为 `00000001`：

$$E=1-127=-126.$$

规格化尾数最小为 $1.0$，故最小规格化正数为

$$1.0\times 2^{-126}.$$

## 选项判断

故选 $\boxed{A}$。$2^{-149}$ 对应最小正非规格化数，不属于本题对象。

## Verification

规格化/非规格化的边界正由 exponent field 是否为 0 决定；A 的 exponent field 为 1。

## Compression

```text
normalized -> exponent field min=1 -> E=1-bias=-126 -> significand min=1.0
```

## 易错边界

不要把“最小正数”与“最小规格化正数”混在一起；前者会落到非规格化区。
