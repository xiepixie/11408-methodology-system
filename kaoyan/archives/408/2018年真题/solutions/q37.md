# 408-2018-Q37

## Model Anchor

- Topic：跨网段转发中的 IP 端点与二层下一跳地址。
- 题目信号：H1 与 H2 位于不同 IP 网络，中间经过路由器 R，问两段以太网帧的 MAC。
- 第一动作：先定每一跳的 Scope：IP 源/目的保持端到端，MAC 源/目的每过一个路由器就按当前链路重新封装。

## 解题链

H1 位于 `192.168.3.0` 网络，H2 位于 `192.168.4.0` 网络，因此 H1 不能直接把帧发给 H2，而是先交给默认网关 R。

第一段链路 H1→R：目的 MAC 是 R 在 H1 所在网段接口的 MAC：

```text
00-1a-2b-3c-4d-51
```

R 解封装 IP 分组后从另一接口转发，在 R→H2 这段链路上，H2 收到帧的源 MAC 是 R 的出接口 MAC：

```text
00-a1-b2-c3-d4-61
```

## 选项判断

两者组合对应 $\boxed{D}$。

## Verification

路由器是二层帧的终点与新帧的起点，所以经过 R 后 MAC header 必然重建；这正好解释两问都落在 R 的两个接口上。

## Compression

```text
different subnet -> next hop = gateway
-> L2 dst = ingress-side router MAC
-> router re-encapsulates
-> next frame src = egress-side router MAC
```

## 易错边界

IP 地址通常保持端到端不变（无 NAT 时），MAC 地址只在当前链路有效。
