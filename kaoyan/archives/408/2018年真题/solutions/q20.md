# 408-2018-Q20

## Model Anchor

- Topic：流水线时钟周期的关键阶段约束。
- 题目信号：给出各功能段组合逻辑延迟和流水段寄存器延迟。
- 第一动作：时钟周期由“最慢组合逻辑段 + 流水寄存器开销”决定，不把五段时间求和。

## 解题链

各功能部件延迟为

```text
80, 50, 50, 70, 50 ps
```

最慢阶段为 80 ps。流水段寄存器额外需要 20 ps，因此最小时钟周期

$$T_{clk}=80+20=100\text{ ps}.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

若时钟周期小于 100 ps，最慢的 A 阶段加寄存器建立/传播开销无法在一个周期内完成，流水线状态会在数据稳定前提交。

## Compression

```text
pipeline clock = max(stage logic delay) + pipeline-register overhead
```

## 易错边界

总指令延迟可能涉及多段，但**流水线节拍**由最慢单段决定；不要把所有阶段延迟相加。
