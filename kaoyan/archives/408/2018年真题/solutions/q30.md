# 408-2018-Q30

## Model Anchor

- Topic：磁盘调度策略与磁臂黏着（arm stickiness）。
- 题目信号：持续偏爱当前附近请求会让远处请求长期得不到服务。
- 第一动作：问算法是否可能因为“距离/扫描位置”不断选择新近邻请求，而不是按到达顺序兑现等待资格。

## 解题链

SSTF 会不断选择离当前磁头最近的请求；若当前磁道附近持续出现新请求，远处请求可能长期饥饿。

SCAN/C-SCAN 的服务顺序与磁头扫描位置相关，也属于按空间位置组织请求的算法。

FCFS 则严格按请求到达顺序处理。即使某磁道持续产生新请求，新请求也只能排到已有请求之后，不会因为位置近而反复抢占前面的远端请求，因此不会产生题目所述“总黏在某磁道”的现象。

## 选项判断

故选 $\boxed{A}$。

## Verification

构造持续到达的本地请求：FCFS 中先到的远端请求仍有有限队列位置；SSTF 则可能不断被更近的新请求截胡。

## Compression

```text
arm stickiness -> location-biased scheduling starvation
FCFS ignores distance -> preserves arrival order -> no stickiness
```

## 易错边界

“平均寻道性能好”与“不会饥饿”是不同目标；局部最优策略可能牺牲公平性。
