# 408-2018-Q34

## Model Anchor

- Topic：OSI 分层职责与地址作用域。
- 题目信号：问“物理层接口规范不定义什么”。
- 第一动作：把物理层限制在机械、电气、功能、过程特性；凡涉及链路身份寻址，就上移到数据链路层。

## 解题链

物理层接口规范会定义接口形状、引脚功能、信号电平等，分别对应机械/功能/电气特性。

“物理地址”通常指 MAC 地址，它是数据链路层用于同一链路范围内标识接口的地址，不属于物理层接口电气规范。

## 选项判断

故选 $\boxed{C}$。

## Verification

若把 MAC 地址放在物理层，就会混淆“比特如何通过接口传输”与“帧送给链路上的哪个接口”两个不同责任层。

## Compression

```text
physical layer -> mechanical/electrical/functional/procedural
MAC address -> data-link identity
```

## 易错边界

“物理地址”这个名称容易误导；它并不因为带“物理”二字就属于 OSI 物理层。
