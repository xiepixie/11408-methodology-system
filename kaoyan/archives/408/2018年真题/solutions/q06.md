# 408-2018-Q06

## Model Anchor

- Topic：BST 的全局次序约束。
- 题目信号：给出二叉排序树形状，要求判断若干关键字大小关系。
- 第一动作：把树结构转成中序序列；BST 的中序遍历必须严格递增。

## 解题链

由图做中序遍历得到

$$x_1,\ x_3,\ x_5,\ x_4,\ x_2.$$

因此整条全序关系为

$$x_1<x_3<x_5<x_4<x_2.$$

题目不需要逐个局部比较父子关系；一旦得到中序全序，就可以直接检查选项。

## 选项判断

只有 C 的

$$x_3<x_5<x_4$$

与全序一致，故选 $\boxed{C}$。

## Verification

BST 的每个结点左子树都小于结点、右子树都大于结点；中序递增正是这些局部不变量的全局展开。

## Compression

```text
BST shape -> inorder -> strictly increasing sequence -> compare options
```

## 易错边界

只比较相邻父子会漏掉“祖先对子树中所有结点”的全局约束；中序序列更稳。
