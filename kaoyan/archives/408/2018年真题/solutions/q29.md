# 408-2018-Q29

## Model Anchor

- Topic：时钟中断驱动的内核时间状态更新。
- 题目信号：问 timer interrupt 后由时钟中断服务程序维护哪些状态。
- 第一动作：把系统时钟、进程累计 CPU 时间、时间片剩余量都看成由“时钟 tick”驱动的状态变量。

## 解题链

I 内核时钟变量：每次时钟中断用于推进系统时间，需更新。

II 当前进程占用 CPU 的时间：进程在本 tick 期间实际运行，应累计其 CPU 使用量。

III 时间片剩余执行时间：时间片轮转等调度策略需要随 tick 递减剩余时间，以判断是否触发调度。

## 选项判断

三者均需要更新，故选 $\boxed{D}$。

## Verification

若 III 不更新，系统无法仅凭定时器判断时间片是否耗尽；若 I/II 不更新，系统时间与 CPU accounting 都会失真。

## Compression

```text
timer tick -> global clock + per-process CPU accounting + quantum countdown
```

## 易错边界

时钟中断服务程序负责更新“时间相关状态”；是否立即切换进程则属于之后的调度决策。
