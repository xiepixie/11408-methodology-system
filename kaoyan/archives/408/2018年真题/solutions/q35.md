# 408-2018-Q35

## Model Anchor

- Topic：802.11 CSMA/CA 的虚拟载波侦听与信道预约。
- 题目信号：关键词“预约信道”。
- 第一动作：区分冲突避免中的四类机制：载波侦听、退避、确认、RTS/CTS；其中只有 RTS/CTS 明确把未来占用时长通知周围站点。

## 解题链

发送方先发 RTS，请求发送并携带预计占用信道的信息；接收方返回 CTS。听到 RTS 或 CTS 的其他站点据此设置 NAV，在预约期间推迟发送。

ACK 用于确认数据接收；二进制指数退避用于冲突概率控制；多个 MAC 地址也不是预约机制。

## 选项判断

故选 $\boxed{D}$。

## Verification

“预约”需要让潜在竞争者在真正 DATA 到来前知道信道将被占用；RTS/CTS 正好提供这一提前反馈链。

## Compression

```text
802.11 reservation -> RTS/CTS -> neighbors set NAV -> defer access
```

## 易错边界

RTS/CTS 不能保证无线网络绝无冲突，它主要降低隐藏站等场景下长数据帧冲突的代价。
