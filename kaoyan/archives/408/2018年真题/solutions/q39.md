# 408-2018-Q39

## Model Anchor

- Topic：UDP 端点分用的 State Owner。
- 题目信号：问接收端如何把到达的 UDP 数据报交给正确应用进程。
- 第一动作：站在接收主机视角找“本地端点身份”：目的端口号标识应把报文交给哪个 socket/进程。

## 解题链

UDP 首部包含源端口、目的端口、长度和校验和。

- 源端口用于标识发送端应用端点，便于对端回复；
- 目的端口用于接收端分用，把 UDP 数据报交给对应应用；
- 长度和校验和分别服务于边界与差错检测，不承担进程选择。

## 选项判断

故选 $\boxed{B}$。

## Verification

若没有目的端口，同一主机同时运行 DNS、DHCP 等多个 UDP 应用时，传输层无法知道该把到达数据交给谁。

## Compression

```text
UDP receive -> local endpoint identity -> destination port -> demultiplex to socket/process
```

## 易错边界

“源端口”也是端点信息，但分用问题问的是**接收端当前该交给谁**，Owner 是目的端口。
