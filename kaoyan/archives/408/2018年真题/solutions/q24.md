# 408-2018-Q24

## Model Anchor

- Topic：非抢占优先级调度的事件时间线与周转时间。
- 题目信号：已有等待时间 + 调度/切换开销 + 不同优先权。
- 第一动作：先按优先权确定执行顺序，再从同一时间原点画 completion timeline；最后把 T 时刻之前已等待的时间补回周转时间。

## 解题链

优先权从高到低：`P2(30) -> P3(20) -> P1(10)`。每次调度/切换开销 1 μs。

从 T 开始：

```text
1 μs 调度 + P2 24 μs -> P2 在 T+25 完成
1 μs 切换 + P3 36 μs -> P3 在 T+62 完成
1 μs 切换 + P1 12 μs -> P1 在 T+75 完成
```

三者周转时间分别为

$$15+25=40,$$
$$18+62=80,$$
$$30+75=105\ \mu s.$$

平均周转时间

$$\frac{40+80+105}{3}=75\ \mu s.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

最后一个完成的 P1 从到达系统到完成已经等待 30 μs，再经历 T 后 75 μs，总周转 105 μs；时间原点一致。

## Compression

```text
priority order -> timeline including switch cost -> completion since T -> add pre-T waiting -> average
```

## 易错边界

题给“等待时间”不是从 T 开始重新计 0；若漏掉这部分会系统性低估周转时间。
