# 408-2018-Q08

## Model Anchor

- Topic：m 阶 B 树的最小占用率。
- 题目信号：3 阶 B 树、高度固定、问最少关键字数。
- 第一动作：先锁定“最少孩子数”，再按层数做最稀疏合法结构计数。

## 解题链

3 阶 B 树中，非根内部结点至少有

$$\left\lceil\frac{3}{2}\right\rceil=2$$

个孩子，也就是至少 1 个关键字；非叶根结点也至少有 2 个孩子、1 个关键字。

高度为 5，根为第 1 层。要使关键字最少，每个内部结点都只取 2 个孩子，于是各层结点数为

$$1,2,4,8,16.$$

每个结点至少 1 个关键字，因此总关键字数最少为

$$1+2+4+8+16=31.$$

## 选项判断

故选 $\boxed{B}$。

## Verification

这是满二叉形态的“最稀疏 3 阶 B 树”；高度每增加 1，最少结点数翻倍，数量级正确。

## Compression

```text
m=3 -> min children=2 -> height 5 -> 1+2+4+8+16 -> 31 keys
```

## 易错边界

“3 阶”表示最多 3 个孩子，不是每个结点必须 3 个孩子；求最少时用下界而不是上界。
