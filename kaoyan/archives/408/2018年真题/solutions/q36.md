# 408-2018-Q36

## Model Anchor

- Topic：停-等协议利用率的发送—等待时间合同。
- 题目信号：给数据率、单向传播时延、忽略 ACK 发送时间、指定利用率。
- 第一动作：先写一个完整发送周期：`数据发送时间 + 往返传播等待`，再令有效发送时间占比等于 40%。

## 解题链

设数据帧长度为 $L$ bit，则发送时间

$$T_t=\frac{L}{3000}.$$

单向传播时延 0.2 s，忽略 ACK 发送时延，一个停-等周期近似为

$$T_t+2T_p=T_t+0.4.$$

利用率

$$\frac{T_t}{T_t+0.4}=0.4.$$

解得

$$0.6T_t=0.16,\qquad T_t=\frac{4}{15}\text{s}.$$

故

$$L=3000\times\frac{4}{15}=800\text{ bit}.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

800 bit 在 3 kbps 下发送约 0.2667 s；周期约 0.6667 s，比例正好 0.4。

## Compression

```text
stop-and-wait -> U = Tx / (Tx + 2Tp [+ AckTx]) -> solve frame length
```

## 易错边界

题目只忽略 ACK 的**发送时延**，并没有忽略 ACK 返回所需的传播时延。
