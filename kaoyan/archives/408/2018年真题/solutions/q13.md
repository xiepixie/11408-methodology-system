# 408-2018-Q13

## Model Anchor

- Topic：32 位补码解码与减法结果。
- 题目信号：给出机器数而非十进制值，要求同时判断数值与运算结果。
- 第一动作：先按位宽解释两个操作数，再做模 $2^{32}$ 的机器级减法，最后检查有符号范围。

## 解题链

`x = FFFFFFDFH` 最高位为 1。其绝对值可由取反加一得到 `21H=33`，故

$$x=-33.$$

`y=00000041H=65`。

因此

$$x-y=-33-65=-98.$$

$98=62H$，32 位补码为

$$2^{32}-98=\mathtt{FFFFFF9E_H}.$$

该结果仍在 32 位有符号整数范围内，不溢出。

## 选项判断

故选 $\boxed{C}$。

## Verification

`FFFFFF9EH` 取反加一得到 `00000062H=98`，符号为负，反解正好是 -98。

## Compression

```text
hex bits -> signed value -> arithmetic -> re-encode to fixed-width two's complement
```

## 易错边界

补码机器数的十六进制形式不能直接按无符号值解释；同时“最高位为 1”也不等于发生溢出。
