# 408-2018-Q21

## Model Anchor

- Topic：同步总线有效吞吐的资源模型。
- 题目信号：判断哪些机制真正提高“单位时间可传有效数据量”。
- 第一动作：分别看每项改变的是每次传输的数据量、单位时间传输次数，还是只改变引脚复用方式。

## 解题链

I 增加总线宽度：一次传输携带更多数据，提高传输率。

II 提高工作频率：单位时间可完成更多总线节拍，提高传输率。

III 突发传输：一次地址阶段后连续传多个数据，摊薄地址/控制开销，提高有效数据率。

IV 地址/数据线复用主要减少引脚数，但地址阶段和数据阶段需要时分占用同一线路，并不天然提高吞吐，通常还会增加时间开销。

## 选项判断

I、II、III 正确，故选 $\boxed{B}$。

## Verification

用近似模型 `bandwidth ≈ width × transfers/s × payload efficiency`：I 提升 width，II 提升 transfers/s，III 提升 efficiency；IV 不直接增加三者。

## Compression

```text
throughput -> width × rate × payload efficiency
-> wider / faster / burst help
-> multiplexing is pin-saving, not throughput mechanism
```

## 易错边界

地址/数据复用优化的是物理接口成本，不等价于带宽优化。
