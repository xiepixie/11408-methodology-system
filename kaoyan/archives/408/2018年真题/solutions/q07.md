# 408-2018-Q07

## Model Anchor

- Topic：拓扑序列与偏序约束。
- 题目信号：判断某序列是否可能由 DAG 的拓扑排序产生。
- 第一动作：不要完整枚举所有拓扑序；从图中提取关键前驱关系，逐项寻找第一个被违反的约束。

## 解题链

拓扑序的核心不变量是：对任意有向边 $u\to v$，$u$ 必须出现在 $v$ 之前。

从图中检查四个候选，A/B/C 均能保持全部前驱关系；D 把存在直接或传递前驱约束的结点顺序反了，因此不是合法拓扑序。

## 选项判断

故选 $\boxed{D}$。

## Verification

若按候选序列逐个“删除当前入度为 0 的顶点”，A/B/C 每一步都能找到对应零入度顶点；D 在某一步会要求删除仍有未消除前驱的顶点。

## Compression

```text
DAG -> extract precedence constraints -> scan candidate -> any edge reversed => invalid
```

## 易错边界

拓扑序不要求相邻顶点之间存在边；只要求所有有向边的前后关系不被违反。
