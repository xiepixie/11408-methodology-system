# 408-2018-Q43

## Model Anchor

- Topic：查询 I/O、中断 I/O、DMA 三种机制的 CPU 占用成本比较。
- 题目信号：主频、CPI、设备数据率、32 位缓冲寄存器、每次服务的指令/周期成本全部给出。
- 第一动作：统一成同一个成本单位：先算“设备每产生一份 4 B 数据的时间”，再算 CPU 每次服务这份数据要占多少周期/时间，最后比较服务速度与到达速度。

## Problem Representation

CPU 主频 500 MHz：

$$T_{clk}=\frac{1}{500\times10^6}=2\text{ ns}.$$

CPI=4，所以一条普通指令平均耗时

$$T_{inst}=4\times2=8\text{ ns}.$$

两个设备接口的缓冲寄存器都是 32 bit=4 B，因此题目的核心队列模型是：

```text
设备每产生 4 B -> 缓冲寄存器获得一份新数据
CPU/中断/DMA 必须在下一份覆盖它之前完成相应处理
```

## Decision Points

三问不能混用同一个“每 4 B 都由 CPU 搬”的模型：

- 查询 I/O：CPU 主动轮询，成本按查询频率 × 每次至少 10 条指令；
- 中断 I/O：每份缓冲数据都可能触发一次中断，必须比较中断服务时间与数据到达间隔；
- DMA：数据块由 DMA 控制器搬运，CPU 只承担每个**数据块**一次预处理/后处理。

## Solution Chain

### (1) 设备 A：定时查询 I/O

设备 A 速率 2 MB/s。4 B 缓冲区被填满所需时间：

$$T_A=\frac{4\text{ B}}{2\times10^6\text{ B/s}}=2\ \mu s.$$

若查询间隔再长，下一份数据可能覆盖尚未读取的数据，因此最多每

$$\boxed{2\ \mu s}$$

查询一次。

每秒至少查询

$$\frac{1}{2\ \mu s}=5\times10^5$$

次。

每次 I/O 至少执行 10 条指令，每条平均 4 个周期，因此每次至少 40 个周期。每秒 CPU 用于 A 的周期数：

$$5\times10^5\times10\times4=2\times10^7.$$

CPU 每秒拥有 $5\times10^8$ 个周期，所以最低占比

$$\frac{2\times10^7}{5\times10^8}=0.04=\boxed{4\%}.$$

也可直接算时间：10 条指令耗时 $10\times8=80$ ns；每 2 μs 一次，$80/2000=4\%$。

### (2) 设备 B：中断 I/O 是否可行

设备 B 速率 40 MB/s，4 B 数据到达间隔

$$T_B=\frac{4}{40\times10^6}=0.1\ \mu s=100\text{ ns}.$$

一次中断响应+处理至少 400 个时钟周期：

$$400\times2\text{ ns}=800\text{ ns}=0.8\ \mu s.$$

也就是说，CPU 处理一次中断的时间里，设备已经产生约

$$\frac{0.8}{0.1}=8$$

份 4 B 数据，而接口只有一个 4 B 缓冲寄存器。

因此按题设这种“一份缓冲数据需要一次中断服务”的模型，设备 B

$$\boxed{\text{不能采用中断 I/O 而保证不丢数据}}.$$

### (3) 设备 B：DMA

DMA 每次传 1000 B。设备 B 每秒产生 40 MB 数据，所以 DMA 数据块频率最多为

$$\frac{40\times10^6}{1000}=4\times10^4\text{ 次/s}.$$

每块 CPU 预处理+后处理共 500 周期，因此每秒 CPU 开销

$$4\times10^4\times500=2\times10^7\text{ cycles}.$$

占 CPU 总周期

$$\frac{2\times10^7}{5\times10^8}=\boxed{4\%}.$$

## Verification

三问都可用“CPU 服务能力 vs 数据到达能力”独立检查：

- A：每 2 μs 一份数据，CPU 仅需 80 ns，来得及；
- B 中断：每 0.1 μs 一份数据，但每次中断至少 0.8 μs，显然跟不上；
- B DMA：每 1000 B 才让 CPU 付 500 周期控制成本，CPU 开销被块级摊薄到 4%。

## Compression

```text
clock=2 ns, instruction=8 ns
buffer=4 B
A polling: 4B/2MBps=2us -> 10 inst/query -> 4%
B interrupt: 4B/40MBps=0.1us < 400 cycles=0.8us -> impossible
B DMA: 1000B/block -> 40k blocks/s -> 500 cycles/block -> 4%
```

## 易错边界

- MB/s 与 Mb/s 不同；本题设备速率按字节每秒。
- 中断方式的瓶颈不是“CPU 总体还有多少空闲时间”这么粗，而是 4 B 缓冲是否能在覆盖前被及时服务。
- DMA 的 CPU 成本按**块**计，不再按每 4 B 计；这正是 DMA 降低 CPU 干预频率的机制。
