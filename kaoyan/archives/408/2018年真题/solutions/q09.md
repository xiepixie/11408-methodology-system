# 408-2018-Q09

## Model Anchor

- Topic：开放定址散列表的探测成本。
- 题目信号：线性探测、按给定顺序插入、问成功 ASL。
- 第一动作：先真实构造表，再对每个已插入关键字数它从哈希地址到命中位置经历了几次比较。

## 解题链

散列函数 $H(k)=k\bmod7$：

```text
22 -> 1，直接放入，ASL=1
43 -> 1，1 已占 -> 2，ASL=2
15 -> 1，1、2 已占 -> 3，ASL=3
```

成功查找平均长度

$$ASL_s=\frac{1+2+3}{3}=2.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

三个关键字形成从槽 1 开始长度为 3 的连续聚集，三者成功探测长度自然为 1、2、3。

## Compression

```text
linear probing -> build actual slots -> count probes per stored key -> average
```

## 易错边界

成功 ASL 的平均对象是“已存关键字”，不是所有散列地址；不要与失败 ASL 的统计范围混淆。
