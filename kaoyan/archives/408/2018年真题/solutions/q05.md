# 408-2018-Q05

## Model Anchor

- Topic：哈夫曼树的权重合并与码长约束。
- 题目信号：给定频率并要求判断“可能的哈夫曼编码”。
- 第一动作：先用最小权值反复合并得到各字符应处的深度，再检查候选是否同时满足码长分布与前缀特性。

## 解题链

权值排序为 `2,3,4,6,8,10`。依次合并：

```text
2+3=5
4+5=9
6+8=14
9+10=19
14+19=33
```

因此码长结构应为：权值 6、8、10 的字符深度 2；权值 4 的字符深度 3；权值 2、3 的字符深度 4。

A 中：

```text
a(6): 00      len=2
b(3): 1011    len=4
c(8): 01      len=2
d(2): 1010    len=4
e(10):11      len=2
f(4): 100     len=3
```

与哈夫曼树深度完全一致，且任一码字都不是另一码字前缀。

## 选项判断

故选 $\boxed{A}$。其余选项至少违反码长分配或前缀码约束。

## Verification

频率越高的字符不应比明显更低频的字符拥有更长码；A 满足这一成本方向。

## Compression

```text
weights -> repeated two-min merge -> leaf depths -> code lengths -> prefix check
```

## 易错边界

哈夫曼编码不唯一，但**各叶子的最优深度结构受权值合并过程约束**；不能只检查“前缀码”就判为哈夫曼码。
