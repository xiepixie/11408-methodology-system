# 408-2018-Q02

## Model Anchor

- Topic：队列输入流 + 单栈缓冲的可达输出序列。
- 题目信号：队列只能按 `1→2→…→6` 消费，进入栈后的元素只能按 LIFO 释放。
- 第一动作：把“直接输出”看成 bypass，把“入栈后输出”看成受 LIFO 约束的延迟输出，检查目标排列能否保持栈序。

## 解题链

A：直接输出 1、2；3、4 入栈；直接输出 5、6；再弹出 4、3，可行。

B：1 入栈，随后 2～6 直接输出，最后弹出 1，可行。

D：1～6 全部入栈，再依次弹出 6～1，可行。

C 要先输出 3，因此 1、2 都必须先压栈。输出 3、4、5、6 后，栈顶必然是 2，只能先输出 2 再输出 1，不可能得到末尾 `1,2`。

## 选项判断

故唯一不可达的是 $\boxed{C}$。

## Verification

关键不变量：一旦两个尚未输出的较早元素按 `1` 后 `2` 入栈，它们未来的弹出相对次序固定为 `2,1`。

## Compression

```text
queue fixes input order
-> stack can only reverse a delayed subsequence
-> target tail violates LIFO => impossible
```

## 易错边界

不能把栈当成任意重排缓冲区；栈只允许对被缓存元素形成嵌套式逆序。
