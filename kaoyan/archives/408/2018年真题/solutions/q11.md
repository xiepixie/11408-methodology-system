# 408-2018-Q11

## Model Anchor

- Topic：顺序表建大根堆的自底向上下滤。
- 题目信号：问“建堆过程”，不是逐个插入堆。
- 第一动作：从最后一个非叶结点向根依次 `siftDown`，每次只维护当前根子树的大根堆不变量。

## 解题链

初始序列 `(6,1,5,9,8,4,7)` 对应完全二叉树。最后一个非叶结点是下标 3 的元素 5：与较大孩子 7 交换，得到

```text
6,1,7,9,8,4,5
```

随后处理元素 1：其孩子 9、8 中选 9，得到

```text
6,9,7,1,8,4,5
```

最后处理根 6：先与较大孩子 9 交换，再继续向下与 8 调整：

```text
9,6,7,1,8,4,5
-> 9,8,7,1,6,4,5
```

## 选项判断

完整状态链与 A 一致，故选 $\boxed{A}$。

## Verification

终态每个父结点都不小于其孩子；并且每一步只对一个当前非叶结点执行标准下滤，符合建堆算法。

## Compression

```text
build heap != repeated insertion
-> last nonleaf to root
-> siftDown with larger child
```
