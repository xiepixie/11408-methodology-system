# 408-2018-Q03

## Model Anchor

- Topic：特殊矩阵压缩存储的二维→一维映射。
- 题目信号：对称矩阵、只存上三角、按行优先、C 数组下标。
- 第一动作：先数目标行之前已经存了多少元素，再加目标元素在本行的相对位置。

## 解题链

上三角第 $i$ 行保存 $12-i+1$ 个元素。`m[6][6]` 是第 6 行第一个被保存的元素，因此其前面共有

$$12+11+10+9+8=50$$

个元素。

C 数组从 0 开始编号，所以 `m[6][6]` 的下标就是 50。

## 选项判断

故选 $\boxed{A}$。B 常见于把下标误按 1 起算；C/D 则没有正确按上三角逐行压缩。

## Verification

前 5 行共存 $50$ 个元素，所以下一个元素必然写入 `N[50]`。

## Compression

```text
upper triangle + row-major
-> sum previous row lengths
-> add in-row offset
-> convert to 0-based index
```

## 易错边界

矩阵下标从 1 开始不代表 C 数组下标也从 1 开始。
