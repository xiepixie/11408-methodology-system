# 408-2018-Q47

## Model Anchor

- Topic：`CIDR Scope -> usable hosts` 与 `MTU -> IPv4 fragmentation` 的两段式网络推理。
- 题目信号：`192.168.1.0/24` 均分两个子网；跨 MTU=800 B 网络转发 1500 B IP 分组。
- 第一动作：第 (1) 问先把 `/24` 均分得到两个 `/25` Scope；第 (2) 问先把“总长度”拆成 IP header 与 payload，再应用“除最后一片外，数据长度必须是 8 B 的整数倍”。

## Problem Representation

题图给出的两个部门对应两个独立广播域：

```text
销售部：192.168.1.0/25
技术部：192.168.1.128/25
```

路由器接口：

```text
F0 = 192.168.1.126   // 销售部
F1 = 192.168.1.254   // 技术部
```

技术部链路 MTU=800 B，因此从销售部来的 1500 B IP 数据报必须在 R 的 F1 出口满足该链路的最大帧载荷约束。

## Decision Points

1. “均分”意味着借 1 位子网位：`/24 -> /25`，不是再按已分配主机数量动态计算掩码。
2. 可连接主机数要扣除网络地址、广播地址，以及已经被主机/路由器接口占用的可用地址。
3. IPv4 `Fragment Offset` 单位是 8 B，因此非最后一个分片的数据部分必须按 8 B 对齐；MTU 约束作用于“IP header + fragment data”的总长度。

## Solution Chain

### (1) 两个子网

把 `192.168.1.0/24` 均分，得到：

```text
192.168.1.0/25     -> 地址范围 .0 ~ .127
192.168.1.128/25   -> 地址范围 .128 ~ .255
```

题图中销售部已分配 `.1~.20`，且路由器 F0=`.126`，因此销售部属于前一个 `/25`；技术部已分配 `.129~.208`，F1=`.254`，属于后一个 `/25`。

#### 销售部广播地址

前一个 `/25` 的最后地址是

$$\boxed{192.168.1.127}.$$

#### 技术部子网地址

后一个 `/25` 的首地址是

$$\boxed{192.168.1.128/25}.$$

#### 技术部还能连接多少主机

`/25` 有 $2^7=128$ 个地址，扣除网络地址和广播地址，可分配地址数为

$$128-2=126.$$

题图已经为主机分配 `.129~.208`，共

$$208-129+1=80$$

个地址；路由器 F1=`.254` 还占用 1 个可分配地址。

因此剩余可分配给新主机的地址数

$$126-80-1=\boxed{45}.$$

### (2) IPv4 分片

原 IP 分组总长度 1500 B，首部 20 B，所以原始 payload 为

$$1500-20=1480\text{ B}.$$

技术部 MTU=800 B。每个分片也需要 20 B IP 首部，因此理论数据上限

$$800-20=780\text{ B}.$$

但除最后一片外，分片数据长度必须是 8 B 的整数倍，所以最大合法数据量为

$$\left\lfloor\frac{780}{8}\right\rfloor\times8
=97\times8
=\boxed{776\text{ B}}.$$

第一片装 776 B 后，剩余

$$1480-776=704\text{ B}.$$

704 本身也是 8 B 的整数倍，且加 20 B 首部后总长 724 B <800 B，因此只需 2 片：

$$\boxed{2\text{ 个分片}}.$$

#### 片偏移量

Fragment Offset 以 8 B 为单位。

第一片从原始 payload 第 0 字节开始：

$$\boxed{offset_1=0}.$$

第二片从第 776 字节开始：

$$offset_2=\frac{776}{8}=\boxed{97}.$$

若补充 MF 语义：第一片 `MF=1`，第二片为最后一片，`MF=0`。

## Verification

### 子网地址校验

`/25` 掩码是 `255.255.255.128`：

```text
.0   ~ .127  -> first subnet
.128 ~ .255  -> second subnet
```

广播地址 `.127`、技术部网络地址 `.128` 恰好位于边界两侧。

### 分片守恒校验

两个 payload 长度：

$$776+704=1480\text{ B},$$

正好恢复原始数据部分。

两个分片总长度分别是：

$$776+20=796\text{ B},$$

$$704+20=724\text{ B},$$

均不超过 MTU=800 B。

第二片 offset=97 对应字节位置

$$97\times8=776,$$

与第一片数据长度无缝衔接。

## Compression

```text
/24 equally split -> /25 + /25
-> broadcast = first subnet last address
-> usable hosts = 126 - allocated hosts - router interface

fragmentation:
1500 total -> 1480 payload
-> MTU800 => floor((800-20)/8)*8 = 776 data
-> remain704 -> 2 fragments
-> offsets 0, 776/8=97
```

## 易错边界

- MTU 约束的是 IP 分片**总长度**，所以要先扣每片 IP 首部。
- 8 B 对齐约束作用于除最后一片外的数据长度，不是把整个 IP 分片长度凑成 8 的倍数。
- Fragment Offset 的单位不是字节，而是 8 B。
- Legacy 旧题解题面曾把“进行了分片”写成“进行了分配”；Canonical Source 当前已是正确的“进行了分片”。题解只沿 Canonical 语义推导。
