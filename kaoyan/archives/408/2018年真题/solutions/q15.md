# 408-2018-Q15

## Model Anchor

- Topic：补码立即数与小端字节序。
- 题目信号：给出同一条 `mov imm32` 指令，只改变 `int i` 的立即数。
- 第一动作：先求 -64 的 32 位补码，再按 little-endian 把 4 个立即数字节逆序落入机器代码。

## 解题链

32 位整数 `-64` 的补码是

$$\mathtt{FFFFFFC0_H}.$$

小端存放多字节立即数时，最低有效字节先出现，因此 4 字节编码为

```text
C0 FF FF FF
```

指令前 3 字节 `C7 45 FC` 不变，所以完整机器代码是

```text
C7 45 FC C0 FF FF FF
```

## 选项判断

故选 $\boxed{A}$。C 是把 32 位机器数按大端顺序直接写入。

## Verification

把内存字节 `C0 FF FF FF` 按小端重新拼回 32 位数，得到 `FFFFFFC0H`，即 -64。

## Compression

```text
-64 -> 32-bit two's complement FFFFFFC0 -> little endian -> C0 FF FF FF
```

## 易错边界

“补码位模式”和“字节在内存/指令流中的排列”是两层问题：先编码数值，再处理 endian。
