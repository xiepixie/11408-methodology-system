# 408-2018-Q31

## Model Anchor

- Topic：文件访问性能的预取、布局与缓存机制。
- 题目信号：四项分别作用于“等待 I/O 的时机、磁头移动、写回时机、重复访问”。
- 第一动作：把文件访问总成本拆成 `I/O 次数 + 寻道/旋转 + 等待暴露程度`，判断每种方法是否减少其中一项。

## 解题链

I 提前读：利用顺序访问/局部性，在真正请求前把后续数据调入，隐藏部分 I/O 等待。

II 连续簇：降低随机跳转和寻道开销，并有利于顺序传输。

III 延迟写：合并多次写、避免短时间内反复写盘，可降低实际 I/O 次数。

IV 磁盘高速缓存：重复或局部访问可直接在内存缓存命中，减少真实磁盘访问。

## 选项判断

I～IV 都可能提高文件访问速度，故选 $\boxed{D}$。

## Verification

四项分别作用于不同成本 Owner，并不存在互相排斥：它们可以同时出现在现代文件系统/I/O 路径中。

## Compression

```text
file I/O cost -> access count + placement + latency exposure
-> prefetch / contiguous allocation / delayed write / cache all help
```

## 易错边界

“延迟写”优化的是写 I/O 合并和暴露时间，不代表数据已经持久化；性能与可靠性语义要分开。
