# 408-2018-Q42

## Model Anchor

- Topic：最小生成树的 cut/cycle 约束，以及 MST 拓扑向 IP hop count 的跨科映射。
- 题目信号：无向带权图、要求“所有最经济方案”，随后把生成树直接当成路由器拓扑并询问 TTL。
- 第一动作：第一问先锁定 MST 的 `V-1` 条边与最小总权；第三问再把“树上 TL→BJ 唯一路径”转换为路由器转发次数，不能把边权当 TTL。

## Problem Representation

8 个城市是 8 个顶点，备选光缆是无向带权边。若既要全部连通又只最小化铺设费用，目标就是求最小生成树：

```text
connected
+ no redundant cycle
+ exactly 8-1 = 7 edges
+ minimum total edge weight
```

从题图可见，大量权值为 2 的边构成低成本骨架；连接剩余部分时存在等权为 3 的替代边，因此 MST 不唯一。

## Decision Points

使用 Kruskal 最自然：按权值从小到大选边，只要不形成环就加入。所有权值 2 的安全边优先进入；在最后连接两个连通分量时，有两条权值同为 3 的合法选择，产生两棵不同但同价的 MST。

图较稀疏，邻接表适合保存；邻接矩阵也能表示，但若题目问更合适的存储结构，优先邻接表。

## Solution Chain

### (1) 所有最经济铺设方案

根据题图以及给出的两张方案图，两个 MST 为：

**方案 1**

```text
XA--BJ  (2)
XA--WH  (2)
WH--QD  (3)
CS--QD  (3)
QD--JN  (2)
QD--NJ  (2)
JN--TL  (2)
```

总费用

$$2+2+3+3+2+2+2=\boxed{16}.$$

**方案 2**

```text
XA--BJ  (2)
XA--WH  (2)
BJ--TL  (3)
TL--JN  (2)
JN--QD  (2)
QD--NJ  (2)
QD--CS  (3)
```

总费用同样为

$$\boxed{16}.$$

两者的核心差别是：方案 1 用 `WH--QD(3)` 把左右低成本骨架接起来；方案 2 改用 `BJ--TL(3)`。由于两条候选边成本相同且都能在不成环的前提下完成连通，所以得到两个等价最优解。

### (2) 存储结构与算法

该图是稀疏无向带权图，可采用

$$\boxed{\text{邻接表}}$$

保存。

求最小生成树可使用

$$\boxed{\text{Kruskal 算法}}$$

（Prim 也能求出 MST；这里 Kruskal 与“按边费用选择光缆”的表示最直接）。

### (3) TTL=5 时 H2 是否能收到

这里必须分别看两个最经济方案，因为树上 TL 到 BJ 的唯一路径不同。

#### 方案 1

TL 到 BJ 的路由器路径为

```text
TL -> JN -> QD -> WH -> XA -> BJ
```

H1 发出的 IP 分组初始 `TTL=5`。每经过一个执行转发的路由器，TTL 减 1：

```text
TL : 5 -> 4
JN : 4 -> 3
QD : 3 -> 2
WH : 2 -> 1
XA : 1 -> 0  => 丢弃
```

因此在到达 BJ 前 TTL 已经耗尽，

$$\boxed{\text{方案 1 中 H2 不能收到}}.$$

#### 方案 2

TL 与 BJ 直接相连：

```text
TL -> BJ
```

TTL 足以跨越该路径并由 BJ 转发到直接连接的 H2，因此

$$\boxed{\text{方案 2 中 H2 可以收到}}.$$

## Verification

### MST 校验

两个方案都满足：

- 8 个顶点；
- 恰有 7 条边；
- 图连通；
- 无环；
- 总费用均为 16。

任何再用权值 4 的边替换当前 2/3 边都不会降低总费用；而图中导致非唯一性的替代边恰好同为权 3。

### TTL 校验

TTL 的 Cost Owner 是**路由器转发次数**，不是边权，也不是物理链路条数的费用总和。方案 1 的长路径在第五次转发处归零；方案 2 路径显著更短。

## Compression

```text
weighted connected graph
-> MST = 7 edges + no cycle + minimum cost
-> equal-cost connector => two MSTs, cost 16
-> for TTL ignore weights
-> follow unique tree path and decrement once per router forward
```

## 易错边界

- MST 的最小“费用”与 IP 的 TTL 没有数值关系。
- “所有最优方案”要求识别等权替代边，不能只画出第一棵 MST 就停止。
- 第 (3) 问必须随方案分别回答；两棵 MST 的 TL→BJ hop 结构不同。
