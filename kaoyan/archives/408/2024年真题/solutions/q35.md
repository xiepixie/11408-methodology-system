# 408-2024-Q35

> 原题：[[../2024 年全国硕士研究生招生考试#35|Q35]]

## Model Anchor

- Topic：VLAN 广播域与 ARP 状态作用域。
- 题目信号：问 H4 的 ARP 表“不会出现谁”，图中同时给 VLAN 归属、IP、MAC。
- 第一动作：先定 ARP 的二层广播作用域，再看候选 IP/MAC 所属主机是否与 H4 位于同一 VLAN；不要因为 IP 前缀相似就跨 VLAN 推 ARP。

## 解题链

题图中：

```text
VLAN 1: H1, H2, H3, H4
VLAN 2: H5
VLAN 3: H6, H7
```

A、B、C 分别对应 H2、H1、H3，它们与 H4 同属 VLAN 1，H4 在直接二层通信过程中可能通过 ARP 学到这些 IP→MAC 映射。

D 对应 H6（`192.168.3.129 / 00-08-6E-05-A7-82`），H6 位于 VLAN 3。没有三层转发时，H4 的 ARP 请求不会跨 VLAN 1 广播到 VLAN 3，因此不会直接学习 H6 的 MAC 映射。

故选 **D**。

## 选项判断

A/B/C 的对象都在 H4 的同一二层广播域；D 跨 VLAN，Scope 不成立。

## Verification

ARP Request 的目的 MAC 是广播地址，但交换机只在**同一 VLAN** 内泛洪；“广播 MAC”不意味着能跨 VLAN 传播。

## Compression

VLAN + ARP → **先定 broadcast domain -> ARP 只解析同域下一跳 -> 再匹配候选主机**。

## 易错边界

真实跨网段通信时，主机会 ARP 默认网关的 MAC，而不是远端主机 MAC；本题直接考 H4 ARP 表中的二层邻居作用域。
