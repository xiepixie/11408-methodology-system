# 408-2024-Q09

> 原题：[[../2024 年全国硕士研究生招生考试#9|Q9]]

## Model Anchor

- Topic：大根堆删除堆顶后的下滤修复。
- 题目信号：已给合法大根堆，连续执行两次删除。
- 第一动作：每次都固定做 `末元素补根 -> 与较大孩子交换 -> 直到父 >= 两孩子`，不要把数组直接做普通删除。

## 解题链

初始堆：

```text
28, 22, 20, 19, 8, 12, 15, 5
```

第一次删除 28：末元素 5 补到根，向下调整：

```text
5,22,20,19,8,12,15
-> 22,5,20,19,8,12,15
-> 22,19,20,5,8,12,15
```

第二次删除 22：末元素 15 补根：

```text
15,19,20,5,8,12
-> 20,19,15,5,8,12
```

最终为

$$\boxed{20,19,15,5,8,12},$$

选 **B**。

## 选项判断

只有 B 同时满足两次删除后的元素集合和大根堆父子偏序；其余项至少有一个父结点小于孩子或下滤路径错误。

## Verification

最终数组对应完全二叉树：20 的孩子 19、15；19 的孩子 5、8；15 的孩子 12。所有父结点均不小于孩子，堆不变量成立。

## Compression

大根堆删顶 → **末元素补根 -> 每次和较大孩子交换 -> 恢复父子偏序**；连续删除就重复该状态机。

## 易错边界

堆只保证父子偏序，不要求层内从左到右有序；不要用“看起来更降序”的选项替代真实下滤过程。
