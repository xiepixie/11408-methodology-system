# 408-2024-Q32

> 原题：[[../2024 年全国硕士研究生招生考试#32|Q32]]

## Model Anchor

- Topic：C-SCAN 的单向扫描状态机。
- 题目信号：当前在 200、方向向小号、磁道范围 0～399。
- 第一动作：先按方向把请求分成两组；当前方向服务到底，再做一次端点跳转，之后继续同一方向。

## 解题链

小于 200 的请求按下降顺序服务：

```text
200 -> 160 -> 120 -> 110 -> 0
```

距离：

$$40+40+10+110=200.$$

C-SCAN 到 0 后跳到另一端 399：

$$399.$$

然后仍按“磁道号减小”方向服务剩余请求：

```text
399 -> 300 -> 210
```

距离：

$$99+90=189.$$

总移动距离：

$$200+399+189=\boxed{788}.$$

故选 **C**。

## 选项判断

A、B、D 都来自漏算端点跳转、漏服务某请求或把 C-SCAN 当成普通 SCAN 反向折返。

## Verification

把每段差值逐项相加：

$$|200-160|+|160-120|+|120-110|+|110-0|+|0-399|+|399-300|+|300-210|=788.$$

## Compression

C-SCAN → **只沿一个方向服务 -> 到端点后整段跳到另一端 -> 仍按原方向继续**；距离按真实磁头移动全计。

## 易错边界

C-SCAN 的端点回卷不是“瞬移”，题目问磁头移动距离时必须计入 `0 -> 399` 的 399 个磁道。
