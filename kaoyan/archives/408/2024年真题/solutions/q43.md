# 408-2024-Q43

> 原题：[[../2024 年全国硕士研究生招生考试#43（13 分）|Q43]]

## Model Anchor

- Topic：指令字段预算、ALU 标志位与 `ISA semantics -> datapath control`。
- 题目信号：同一道题连续问字段宽度、MUX 控制、OF/CF、立即数扩展和机器码解码。
- 第一动作：先把 32 位指令按题图固定字段切开，再对每条指令写 `Read Set -> Derived Value -> Write Set`；只有路径确定后才读控制信号值。

## Problem Representation

题图给出的三种指令格式：

```text
add : 0000000 | rs2   | rs1 | 000 | rd | 0110011
slli: 0000000 | shamt | rs1 | 010 | rd | 0010011
lw  : imm[11:0]       | rs1 | 010 | rd | 0000011
```

数据通路中：

```text
ALUBsrc=0 -> ALU B端取寄存器 B
ALUBsrc=1 -> ALU B端取扩展后的 IR[31:20]
Ext=0     -> 零扩展
Ext=1     -> 符号扩展
ALUctr=000 -> 加
ALUctr=001 -> 减
ALUctr=010 -> 逻辑左移
```

## Decision Points

- 寄存器数量只看寄存器编号字段宽度；`shamt` 宽度由 32 位操作数的有效移位范围决定。
- OF 与 CF 分别服务 signed / unsigned 两种解释，不能互相代替。
- `lw` 解码优先检查 opcode + funct3；地址再由符号扩展的 imm 与 `R[rs1]` 相加得到。

## Solution Chain

### (1) 最大通用寄存器数与 `shamt` 为何 5 位

`rs1`、`rs2`、`rd` 都是 5 位字段，因此最多可编码

$$2^5=\boxed{32}$$

个通用寄存器。

32 位数据逻辑左移时，有意义的移位量为 0～31，共 32 种状态，所以

$$\log_2 32=5,$$

故 `shamt` 需要 **5 位**。

### (2) `add` 的 `ALUBsrc`、F、OF、CF

`add` 语义为

$$R[rd]\leftarrow R[rs1]+R[rs2],$$

ALU B 端应选择寄存器 `rs2` 的输出 B，因此

$$\boxed{ALUBsrc=0}.$$

计算：

$$
\texttt{87654321H}+\texttt{98765432H}
=\texttt{11FDB9753H}.
$$

32 位 ALU 保留低 32 位：

$$\boxed{F=\texttt{1FDB9753H}}.$$

最高位产生进位，因此

$$\boxed{CF=1}.$$

若按 32 位补码解释，两个操作数最高位均为 1，即都是负数；结果 `1FDB9753H` 最高位为 0，即为正数。两个同号负数相加得到异号正数，发生 signed overflow：

$$\boxed{OF=1}.$$

若 `add` 处理**无符号整数**，应依据

$$\boxed{CF}$$

判断溢出。

### (3) `slli` 时 Ext 为什么 0/1 均可

`slli` 的高 12 位是

```text
0000000 | shamt
```

其最高位 `IR[31]=0`。因此把这 12 位做零扩展或按其最高位做符号扩展，补入的高 20 位都全为 0，得到同一个 32 位数值。

所以

$$\boxed{Ext=0\text{ 或 }1\text{ 均不影响结果}}.$$

### (4) `lw` 的 Ext 与 ALUctr

`lw` 的地址语义：

$$EA=R[rs1]+SEXT(imm).$$

`imm` 是补码有符号偏移量，因此需要符号扩展：

$$\boxed{Ext=1}.$$

有效地址通过加法形成：

$$\boxed{ALUctr=000}.$$

### (5) 为什么 `A040 A103H` 一定是 `lw`

对机器码 `A040A103H` 解字段：

```text
opcode = bits[6:0]   = 0000011
funct3 = bits[14:12] = 010
```

题图中只有 `lw` 同时具有 `opcode=0000011`、`funct3=010`；`add` 的 opcode 是 `0110011`，`slli` 的 opcode 是 `0010011`。

因此它一定是

$$\boxed{lw}.$$

### (6) 读取数据的存储地址

`A040A103H` 的字段为：

```text
imm = A04H
rs1 = 01H
rd  = 02H
```

12 位 `A04H` 最高位为 1，作为补码：

$$SEXT(\texttt{A04H})=\texttt{FFFFFA04H}=-1532.$$

已知

$$R[01H]=\texttt{FFFFA2D0H},$$

有效地址：

$$
EA=\texttt{FFFFA2D0H}+\texttt{FFFFFA04H}\pmod{2^{32}}
=\boxed{\texttt{FFFF9CD4H}}.
$$

## Verification

1. 加法的 full precision 结果 `11FDB9753H` 同时给出低 32 位 `1FDB9753H` 与进位 `CF=1`；两个负补码数得到正结果又独立验证 `OF=1`。
2. `lw` 立即数 `A04H` 按 12 位补码为 $0xA04-0x1000=-0x5FC$；`0xFFFFA2D0-0x5FC=0xFFFF9CD4`，与位串加法一致。
3. 机器码的 opcode/funct3 与题图格式完全闭合，没有靠汇编名称猜测。

## Compression

```text
指令综合题
-> 先切字段
-> 写 Read/Write Set
-> 位宽/扩展解释
-> 沿数据通路选 MUX/ALU
-> signed 看 OF，unsigned 看 CF
-> 地址 = base + SEXT(imm)
```

## 易错边界

- `CF=1` 与 `OF=1` 本题恰好同时发生，但二者语义不同：CF 看无符号出位，OF 看补码有符号范围。
- `slli` 的 Ext 可任意不是“移位量永远无需扩展”，而是因为本题 `IR[31]=0`，零扩展与符号扩展碰巧相同。
- `A04H` 作为 12 位立即数不是正数 2564，而是补码负数 $-1532$。
