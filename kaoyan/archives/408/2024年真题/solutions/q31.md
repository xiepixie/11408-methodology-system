# 408-2024-Q31

> 原题：[[../2024 年全国硕士研究生招生考试#31|Q31]]

## Model Anchor

- Topic：中断驱动输入的数据路径。
- 题目信号：问“键盘中断服务例程**执行结束时**”数据在哪，而不是最终应用程序看到数据在哪。
- 第一动作：画三段数据路径：`device/controller register -> kernel buffer -> user buffer`，再定位 ISR 负责哪一段。

## 解题链

键盘控制器先把输入放入设备数据寄存器并产生中断。CPU 进入键盘 ISR 后，从控制器读取该输入，并交给内核输入子系统/缓冲区保存，尽快结束中断处理。

用户进程之后通过 `read()` 等系统调用从内核缓冲区取得数据，才进入用户缓冲区。

因此 ISR 结束时数据位于

$$\boxed{\text{内核缓冲区}},$$

选 **C**。

## 选项判断

A 是后续用户态 I/O 阶段；B 只是处理中可能出现的临时寄存器状态；D 是 ISR 读取前的设备端状态；C 对应 ISR 完成后的稳定内核状态。

## Verification

若 ISR 结束后数据仍只留在键盘控制器寄存器，下一个输入可能覆盖它；若直接写任意用户缓冲区，又缺少当前进程/读请求等上下文。因此先进入内核缓冲区最符合分层职责。

## Compression

中断输入题 → **controller register -> ISR -> kernel buffer -> syscall -> user buffer**。

## 易错边界

“中断完成”只表示内核已接收设备事件，不等于用户进程已经获得数据；completion 与 user-visible return 是两个事件。
