# 408-2024-Q17

> 原题：[[../2024 年全国硕士研究生招生考试#17|Q17]]

## Model Anchor

- Topic：TLB 组相联地址分解。
- 题目信号：给 VA 位数、页大小、TLB 项数与路数，问 Tag 位数。
- 第一动作：严格按 `VA -> VPN | page offset`，再把 `VPN -> TLB tag | set index`；物理地址位数与 TLB tag 计算无关。

## 解题链

页大小

$$1\text{ KB}=2^{10}\text{ B},$$

所以 32 位虚拟地址中页内偏移为 10 位，VPN 为

$$32-10=22\text{ 位}.$$

TLB 共 32 项、4 路组相联，组数

$$32/4=8=2^3,$$

因此组索引需要 3 位。VPN 的其余高位作为 Tag：

$$22-3=\boxed{19\text{ 位}}.$$

选 **C**。

## 选项判断

A、B、D 都来自把页内偏移、路数或物理页号错误纳入 Tag 预算。Tag 的来源只有 VPN 去掉 TLB set index 后的剩余位。

## Verification

地址预算闭合：

```text
VA = TLB tag 19 + set index 3 + page offset 10 = 32 bit
```

## Compression

TLB 组相联 → **先拆 VA 得 VPN -> TLB 组数=项数/路数 -> VPN 再拆 tag/index**。

## 易错边界

主存地址 30 位用于确定 PPN 宽度，并不决定 TLB 的虚拟 Tag；TLB 查找入口来自虚拟页号。
