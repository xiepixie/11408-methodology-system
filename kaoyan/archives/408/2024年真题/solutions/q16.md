# 408-2024-Q16

> 原题：[[../2024 年全国硕士研究生招生考试#16|Q16]]

## Model Anchor

- Topic：Cache—主存与主存—外存两级层次的机制对照。
- 题目信号：同一选项同时比较“交换单位、替换主体、写策略、映射方式”。
- 第一动作：先分别写两层的 Owner 与成本目标，再逐维比较；不要因为都叫“存储层次”就强行套同一种机制。

## 解题链

- Cache—主存按 **block** 搬运；虚拟存储主存—外存按 **page** 搬运，A 正确。
- Cache 替换处在高速访问关键路径，通常由硬件完成；页面置换由 OS 软件策略管理，B 正确。
- Cache 可 write-back；脏页被换出时也采用回写外存的思路，C 正确。
- Cache 可以直接映射，因为每个主存块可固定落到某一 Cache 行；虚拟页却不能固定映射到唯一页框，否则物理页框空闲与置换灵活性都会被破坏。页表支持任意合法页框映射。

故错误的是 **D**。

## 选项判断

D 把 Cache 的直接映射机制错误搬到了虚拟页—页框关系；主存—外存层次需要动态页框分配和替换。

## Verification

若虚拟页只能直接映射到固定物理页框，那么该页框被其他页占用时无法利用其它空闲页框，需求分页的核心灵活性就消失了。

## Compression

两级存储层次对照 → **先分交换粒度、Owner、写回、映射自由度**；相似目标不代表实现机制相同。

## 易错边界

“页式映射”不是 Cache 意义上的直接/全相联/组相联分类；这两套映射语义属于不同层次。
