# 408-2024-Q41

> 原题：[[../2024 年全国硕士研究生招生考试#41（13 分）|Q41]]

## Model Anchor

- Topic：拓扑排序的 frontier 与唯一性。
- 题目信号：不是“输出一个拓扑序”，而是判断**拓扑序是否唯一**。
- 第一动作：把 Kahn 算法中的“当前所有入度为 0 的顶点”看成 frontier；唯一性的判据不是最后得到几个序列，而是**每一步 frontier 是否恰好只有 1 个候选**。

## Problem Representation

拓扑删除过程的状态：

```text
indeg[v] = 尚未删除子图中 v 的当前入度
processed = 已经输出/删除的顶点
frontier  = 所有未处理且 indeg=0 的顶点
```

核心不变量：删除一个 frontier 顶点及其出边后，`indeg[]` 必须准确表示剩余子图的入度。

唯一性判据：

- `|frontier| = 0`：剩余子图有环，连拓扑序都不存在；
- `|frontier| >= 2`：当前至少有两个合法选择，会产生至少两条不同拓扑序；
- 每一轮始终 `|frontier| = 1`：每个位置的顶点都被强制确定，拓扑序唯一。

## Decision Points

- 不需要枚举所有拓扑序；枚举会指数爆炸。
- 题目使用邻接矩阵，所以计算入度与删除某顶点出边都直接扫描矩阵。
- 入度是“边的条数”，因此对 `Edge[i][j] != 0` 计 1，而不是把矩阵值本身累加成入度。

## Solution Chain

### (1) 基本设计思想

1. 扫描邻接矩阵，计算每个顶点的入度；
2. 重复 $n$ 轮：
   - 找所有尚未处理且当前入度为 0 的顶点；
   - 若数量不是 1，立即返回 0；
   - 将唯一候选删除，并把它所有后继顶点的入度减 1；
3. 若 $n$ 轮均成功，则返回 1。

### (2) C/C++ 描述

```c
int uniquely(MGraph G)
{
    int n = G.numVertices;
    int indeg[MAXV] = {0};
    int used[MAXV] = {0};

    /* 初始入度 */
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            if (G.Edge[i][j] != 0)
                ++indeg[j];

    for (int step = 0; step < n; ++step) {
        int cnt = 0;
        int u = -1;

        /* 当前所有可被拓扑删除的候选 */
        for (int v = 0; v < n; ++v) {
            if (!used[v] && indeg[v] == 0) {
                ++cnt;
                u = v;
            }
        }

        /* cnt==0: 有环；cnt>1: 拓扑序不唯一 */
        if (cnt != 1)
            return 0;

        used[u] = 1;

        /* 删除 u 的所有出边 */
        for (int v = 0; v < n; ++v) {
            if (!used[v] && G.Edge[u][v] != 0)
                --indeg[v];
        }
    }

    return 1;
}
```

### Why Correct

若某一步存在两个不同的零入度顶点 $u,v$，二者都没有尚未满足的前驱约束，所以此时先选 $u$ 或先选 $v$ 都合法；至少产生两条不同拓扑序，因此不唯一。

反过来，若每一步都只有一个零入度顶点，那么拓扑序当前位置没有任何选择自由度；从第 1 个位置到第 $n$ 个位置都被唯一决定，因此整个拓扑序唯一。若某一步没有零入度顶点，则剩余图含环，不存在完整拓扑序，也应返回 0。

### Complexity

邻接矩阵初始计算入度为 $O(n^2)$；每轮寻找唯一候选和删除出边各扫描 $O(n)$，共 $n$ 轮，因此

$$\boxed{T(n)=O(n^2)},\qquad \boxed{S_{extra}(n)=O(n)}.$$

## Verification

用两个最小反例检查：

```text
1 -> 3 <- 2
```

初始 frontier={1,2}，立即判“不唯一”；

```text
1 -> 2 -> 3 -> 1
```

初始 frontier 为空，立即判“无拓扑序”。两种失败原因都由 `cnt != 1` 捕获。

## Compression

拓扑唯一性 → **Kahn frontier** → 每轮零入度候选必须 `==1` → 删除唯一候选并更新入度 → `0=有环，>1=不唯一`。

## 易错边界

- “能得到一个拓扑序”不等于“拓扑序唯一”。
- legacy 思路里“进行 numEdges 轮”是不对的；拓扑排序输出的是顶点，应进行至多 `numVertices` 轮。
- 若邻接矩阵只是 0/非0 表示有边，入度按边条数计数，不能把非零权值直接相加。
