# 408-2024-Q26

> 原题：[[../2024 年全国硕士研究生招生考试#26|Q26]]

## Model Anchor

- Topic：磁盘空闲空间的表示方式。
- 题目信号：问的是“额外外存空间大小是否随**当前空闲块数量**变化”。
- 第一动作：先找每种表示的 State Owner：它是“为每个磁盘块固定留一位”，还是“只为当前空闲对象建立记录”。

## 解题链

位示图对磁盘中的每一个盘块固定分配 1 bit：

```text
block 0 -> bit 0
block 1 -> bit 1
...
```

因此位示图大小只由**磁盘总盘块数**决定。当前空闲块从多变少，只改变 bit 的 0/1 状态，不改变位示图长度。

空闲表、空闲链表以及成组链接都要对当前空闲空间建立表项/链接组织，其记录规模会随空闲空间状态变化。

故选 **A**。

## 选项判断

A 是固定槽位表示；B、C、D 都以当前空闲空间实体/分组为组织对象。

## Verification

假设磁盘有 $N$ 个块，位示图始终需要 $N$ bit，无论空闲块是 1 个还是 $N-1$ 个。

## Compression

空闲空间表示题 → **问元数据是按“总资源”固定分配，还是按“当前空闲对象”动态记录** → bitmap 大小只看总块数。

## 易错边界

位示图“大小固定”不等于磁盘空间固定不变；固定的是**描述空闲状态的元数据长度**。
