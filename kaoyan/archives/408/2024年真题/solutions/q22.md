# 408-2024-Q22

> 原题：[[../2024 年全国硕士研究生招生考试#22|Q22]]

## Model Anchor

- Topic：DMA 的数据所有权与传输路径。
- 题目信号：问 DMA 控制器“控制的数据传输通路”位于哪里。
- 第一动作：把 CPU 配置、DMA 搬运、完成中断三个事件分开；只追真正的数据 payload 从哪里到哪里。

## 解题链

DMA 的核心价值是让 CPU 不再逐字/逐字节参与设备数据搬运。CPU 负责初始化 DMA 描述信息，DMA 控制器取得总线控制权后，数据直接在

```text
设备接口 <-> 主存
```

之间传送。

因此 DMA 控制的数据通路是

$$\boxed{\text{设备接口和主存之间}},$$

选 **C**。

## 选项判断

- A 是 CPU 正常访存通路；
- B 是控制/配置关系，不是设备数据 payload 的主搬运路径；
- C 正确；
- D 只到 DMA 控制器，没有落到最终内存目的地。

## Verification

如果 payload 仍必须经过 CPU 才到主存，就退化成程序查询/中断驱动的 CPU 搬运，失去 “Direct Memory Access” 的核心机制。

## Compression

DMA → **CPU 配置，DMA 搬运，完成后中断** → payload 路径是 `device interface <-> memory`。

## 易错边界

DMA 控制器参与总线仲裁和地址/计数控制，不意味着数据的最终源/目的变成“CPU—DMA”或“设备—DMA”；题目问的是被控制的数据传输通路。
