# 408-2024-Q08

> 原题：[[../2024 年全国硕士研究生招生考试#8|Q8]]

## Model Anchor

- Topic：快速排序一趟 partition 的不变量。
- 题目信号：强调“第一趟”“除枢轴外”“P、Q 均非空”。
- 第一动作：先写 partition 完成后的保证，不要把“枢轴就位”误扩成“两块都排好序”。

## 解题链

一次划分完成后，枢轴已经放到最终位置，并且两侧满足跨块偏序：

```text
P 中元素 <= pivot <= Q 中元素
```

因此任取 $p\in P,q\in Q$，都有 $p\le q$，即 **P 与 Q 块间有序**。

但划分并不保证：

- P 内部有序；
- Q 内部有序；
- 两块规模接近；
- 不存在重复关键字。

故选 **A**。

## 选项判断

A 是 partition 的核心不变量；B 把块间偏序偷换成块内全序；C 只有枢轴接近中位数时才可能成立；D 与是否存在重复 key 无关。

## Verification

取数组 `[1,3,2,5,4]`，以 4 为枢轴，一趟后左块完全可能仍是 `[1,3,2]`，内部无序，但其中每个元素都不大于右侧/枢轴边界。

## Compression

快排第一趟 → **只保证 pivot 就位 + 左右块跨块有序；块内仍待递归**。

## 易错边界

“块间有序”不是“整个 P、Q 各自已经有序”。这是快排题最常见的层级偷换。
