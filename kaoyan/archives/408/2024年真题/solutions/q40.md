# 408-2024-Q40

> 原题：[[../2024 年全国硕士研究生招生考试#40|Q40]]

## Model Anchor

- Topic：非持久 HTTP 的连接生命周期与串行对象获取。
- 题目信号：HTTP/1.0 非持久、7 个嵌入图像、**不支持并行 TCP**。
- 第一动作：先数对象数，再写“每个对象独占一条 TCP 连接”的最短 RTT 合同；关闭连接不参与“接收完内容”的关键路径计数。

## 解题链

对象总数：

$$1\text{ 个 HTML}+7\text{ 个图像}=8\text{ 个对象}.$$

非持久 HTTP 对每个对象都单独建立 TCP 连接。在忽略传输时延且不并行时，一个对象至少需要：

```text
1 RTT：TCP 三次握手完成到可发送 HTTP 请求
1 RTT：HTTP request 到 response 到达
```

因此每个对象至少 2 RTT。8 个对象串行获取：

$$8\times2=\boxed{16\text{ RTT}}.$$

故选 **D**。

## 选项判断

A、B、C 都少算了至少一部分对象的连接建立或请求—响应 RTT。题设禁止并行，所以 7 张图不能把 RTT 重叠掉。

## Verification

主 HTML 先花 2 RTT；只有收到 HTML 后浏览器才知道 7 个图像 URL。之后 7 个对象各 2 RTT 串行，总计

$$2+7\times2=16.$$

## Compression

非持久 HTTP + 无并行 → **对象数 N -> 每对象 1 RTT 建连 + 1 RTT 请求响应 -> 总计 2N RTT**。

## 易错边界

legacy 解析把第二个 RTT 说成“关闭连接 RTT”，这不是这里的正确成本来源。题目截止到“接收完全部内容”，关键的第二个 RTT 是 **HTTP 请求—响应**；TCP 关闭可在内容接收后进行，不决定该截止时刻。
