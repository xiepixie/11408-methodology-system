# 408-2024-Q47

> 原题：[[../2024 年全国硕士研究生招生考试#47（9 分）|Q47]]

## Model Anchor

- Topic：RIP 的逐轮距离向量传播、TTL 的逐跳生命周期，以及 eBGP/iBGP 的跨域信息传播与选路。
- 题目信号：同一张图同时出现 AS 内 IGP、AS 间 BGP、AS_PATH 和 next hop。
- 第一动作：先定 Scope：第 (1)(3) 问在 AS 内，第 (4)(5) 问跨/内 AS 控制平面；每问只使用该层拥有的状态，避免把 RIP hop、TTL、BGP AS_PATH 混成一种“距离”。

## Problem Representation

题图中 AS1 运行 RIP，内部关键拓扑可压成：

```text
R11 --- R12 --- R13
 |               |
R14 --- R15 --- R16
          \---- R13

210.2.3.0/24 -- R14
R16 -- 210.2.4.0/24
```

外部 BGP 邻接：

```text
AS2:R22 -- R11:AS1
AS3:R33 -- R12:AS1
AS4:R44 -- R13:AS1
```

## Decision Points

- RIP 的 15 是**最大可达 hop count**，不是适合所有规模的性能建议；AS4 可能超过 20 个路由器，直接越过协议可达边界。
- TTL 在每个路由器转发时递减；要经过 15 个路由器并最终交付，初值必须让第 15 个路由器处理后仍不为 0。
- RIP 初始向量交换发生在 $t=0$，所以第 1 跳邻居可在 $t=0$ 学到直连网络；之后每 30 s 再向外扩一层。
- BGP 先按 AS_PATH 等属性筛选；当 AS_PATH 长度相同且其它属性无差异时，再比较到 BGP NEXT_HOP 的 IGP 成本。

## Solution Chain

### (1) AS4 应选择 RIP 还是 OSPF

RIP 用 hop count 作度量，16 表示不可达，因此有效最大 hop count 为 15。题目指出 AS4 内部任意两主机通信经过的路由器数可能超过 20，RIP 已不能保证全 AS 可达。

OSPF 使用链路状态与 SPF 计算，不受 RIP 的 15-hop 可达上限约束，更适合该规模。

所以：

$$\boxed{OSPF}.$$

### (2) AS3 中 IP 分组初始 TTL 至少是多少

最坏路径经过 15 个路由器。每经过一个路由器 TTL 减 1；若某路由器把 TTL 减到 0，则丢弃分组。

因此必须满足：

$$TTL_0-15\ge1,$$

即

$$\boxed{TTL_0\ge16}.$$

最小初值为

$$\boxed{16}.$$

### (3) AS1 全部 R11～R16 获得到 `210.2.4.0/24` 正确路由至少多久

目标网络直连 R16。把“正确路由信息离 R16 的最远传播层数”作为状态：

#### $t=0$：交换初始距离向量

R16 已知其直连网络，并立即把它通告给相邻 R15、R13：

```text
已知：R16, R15, R13
```

#### $t=30s$：第一次周期更新

R15、R13 把新学到的路由继续通告：

```text
R14 从 R15 学到
R12 从 R13 学到
```

此时：

```text
已知：R12,R13,R14,R15,R16
```

#### $t=60s$：第二次周期更新

R12 或 R14 将该网络信息传播给 R11，至此 R11～R16 全部获得正确路由。

因此至少：

$$\boxed{60\text{ s}}.$$

### (4) R44→R13 与 R13→R14/R15 的 BGP 会话和报文

R44 属于 AS4，R13 属于 AS1，跨 AS 建立的是：

$$\boxed{eBGP\text{ 会话}}.$$

网络可达性及路径属性通过：

$$\boxed{UPDATE\text{ 报文}}$$

通告。

R13 将外部学到的路由在同一个 AS1 内传播给 R14、R15，使用：

$$\boxed{iBGP\text{ 会话}}.$$

所以完整答案：

```text
R44 -> R13 : eBGP，UPDATE
R13 -> R14/R15 : iBGP
```

### (5) R14、R15 最终下一跳

三条候选：

| BGP NEXT_HOP | AS_PATH | 长度 |
|---|---|---:|
| R11 | AS2 AS8 AS19 | 3 |
| R12 | AS3 AS7 AS11 AS19 | 4 |
| R13 | AS4 AS10 AS19 | 3 |

在题设“无策略约束”且其它 BGP 属性无差异的口径下，先排除 AS_PATH 更长的 R12 候选。

剩余 R11 与 R13 的 AS_PATH 长度都为 3。接下来比较本 AS 内到 NEXT_HOP 的 IGP 代价：

- R14 与 R11 直接相邻，到 R11 更近；
- R15 与 R13 直接相邻，而到 R11 需经 R14，因此到 R13 更近。

所以：

$$\boxed{R14\text{ 的下一跳为 }R11}$$

$$\boxed{R15\text{ 的下一跳为 }R13}.$$

## Verification

### RIP 传播轮数检查

目标网从 R16 出发，最远的 R11 在拓扑上的最短路由器传播距离为 3 条内部链路：

```text
R16 -> R13 -> R12 -> R11
```

由于第 1 跳在 $t=0$ 初始交换即可完成，剩余 2 跳各需一次 30 s 周期更新，所以正好 $2\times30=60$ s。

### BGP 选路检查

R12 的 AS_PATH 长度 4 明显劣于另外两条长度 3；R14/R15 的差异只在本 AS 内到等价 NEXT_HOP 的成本，因此得到不同出口符合 hot-potato 式最近出口选择直觉。

## Compression

```text
路由综合题
-> 先定 Scope（hop / AS / BGP）
-> RIP：信息每轮扩一跳，初始交换算 t=0
-> TTL：每路由器 -1，必须到目的前仍 >0
-> BGP：eBGP 跨 AS，iBGP 同 AS，UPDATE 传可达性
-> 选路先 BGP 属性，再比到 NEXT_HOP 的 IGP 成本
```

## 易错边界

- RIP 的“15 跳”与 IP TTL 是两个完全不同的状态：前者是路由协议 metric 上限，后者是单个 IP 分组的生命周期字段。
- `AS_PATH` 短不代表物理距离一定短；这里只在题设无其它策略/属性差异时按给定 BGP 选路口径处理。
- iBGP 是控制平面会话，不要求两台路由器在物理拓扑上直接相邻；只要 IP 可达即可建立会话。
