# 408-2024-Q18

> 原题：[[../2024 年全国硕士研究生招生考试#18|Q18]]

## Model Anchor

- Topic：`VA -> TLB/page table -> PA -> Cache` 的阶段边界。
- 题目信号：问“**MMU 地址转换过程**检测什么”，选项混入 Cache miss。
- 第一动作：先画生命周期，再把每种 miss/fault 放回它真正的检测阶段。

## 解题链

地址翻译路径可压成：

```text
VA
-> TLB lookup
-> page-table / permission check
-> PA
-> Cache lookup
```

因此：

- TLB 缺失：发生在地址翻译加速结构中；
- 页面缺失：页表项无效时由地址翻译路径发现；
- 访问越权：页表权限检查阶段发现；
- Cache 缺失：必须在形成相应 Cache 查询地址并访问 Cache 时判断，属于缓存访问状态机，不是 MMU 页表翻译本身。

故选 **B**。

## 选项判断

A、C、D 都与 VPN、PTE 或 TLB 状态有关；B 属于 PA/Cache 访问层。

## Verification

即使关闭 Cache，虚拟地址仍然必须经过 MMU 转成物理地址；说明 Cache hit/miss 并不是完成地址翻译所必需的判定。

## Compression

MMU vs Cache → **先画 `VA -> translation -> PA -> cache` 顺序** → 权限/page/TLB 属于翻译，Cache miss 属于缓存访问。

## 易错边界

在 VIPT Cache 中 TLB 与 Cache 某些步骤可以并行，但“时间上并行”不等于“机制归属相同”；Cache miss 仍不是页表翻译事件。
