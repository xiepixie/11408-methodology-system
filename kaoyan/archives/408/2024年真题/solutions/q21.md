# 408-2024-Q21

> 原题：[[../2024 年全国硕士研究生招生考试#21|Q21]]

## Model Anchor

- Topic：中断响应优先级与中断处理优先级的分层。
- 题目信号：选项 A 把“中断屏蔽字”与“中断响应优先级”绑定。
- 第一动作：先区分两件事：**CPU 先响应谁** vs **进入处理中断后允许谁嵌套打断谁**。

## 解题链

中断响应优先级通常由硬件排队/优先级判定逻辑决定；中断屏蔽字控制哪些中断源当前被允许进入，从而可改变**处理优先级/嵌套关系**，但不能据此定义硬件响应优先级本身。

因此 A 错误。

其余项：

- 中断响应阶段硬件保存断点及必要的程序状态，B 正确；
- 通用寄存器保护、设置新的屏蔽关系通常由中断服务程序软件完成，C 正确；
- 单重中断不允许处理过程中再被中断，故处理中保持关中断，D 正确。

故选 **A**。

## 选项判断

A 混淆了“响应优先级”与“处理优先级”。这是本题唯一的层次偷换。

## Verification

若只有中断屏蔽字才能决定响应顺序，那么在 CPU 尚未进入任何 ISR、多个未屏蔽请求同时到来时就没有硬件判优依据；实际仍需硬件优先级逻辑选择首先响应的中断源。

## Compression

中断优先级题 → **先分 response priority / handling priority** → 硬件先判谁被响应，屏蔽字主要约束处理中谁还能嵌套。

## 易错边界

屏蔽某请求会影响“它能否被响应”，但不能把屏蔽位图直接等同于“硬件响应优先级编码”。
