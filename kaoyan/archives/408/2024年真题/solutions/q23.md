# 408-2024-Q23

> 原题：[[../2024 年全国硕士研究生招生考试#23|Q23]]

## Model Anchor

- Topic：异常/中断的“发生时刻”与“处理时刻”权限状态。
- 题目信号：A、C 只差一个时间点：`发生时` vs `处理程序开始执行时`。
- 第一动作：画 `event -> hardware entry -> handler` 三段，不把触发和处理混成同一状态。

## 解题链

中断或异常可以在 CPU 正执行用户程序时发生，此时触发瞬间 CPU 完全可能处于用户态。硬件响应后才保存必要现场、切换到内核态并转入处理例程。

所以 A“发生时 CPU 处于内核态”错误。

B：系统调用号会路由到相应内核服务处理；C：中断处理程序需要内核权限，开始执行时处于内核态；D：新设备类型需要把相应中断处理入口纳入系统中断处理机制。均可成立。

故选 **A**。

## 选项判断

A 偷换了 Event 与 Handler 两个时刻；C 描述的是完成硬件入口之后的状态，不能用 C 反推 A。

## Verification

最小反例：用户态程序执行普通指令时定时器中断到来。中断“发生”的瞬间显然仍在用户态，但几拍之后 ISR 已在内核态执行。

## Compression

异常/中断权限题 → **触发态 ≠ 处理态** → `event -> privilege entry -> handler`。

## 易错边界

异常也可能在内核态发生，因此正确表述不是“发生时一定用户态”，而是“发生时不一定内核态”。
