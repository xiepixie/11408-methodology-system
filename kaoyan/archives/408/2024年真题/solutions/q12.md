# 408-2024-Q12

> 原题：[[../2024 年全国硕士研究生招生考试#12|Q12]]

## Model Anchor

- Topic：有符号整数的窄化截断与符号扩展。
- 题目信号：`int -> short -> int`，且 32777 超过 16 位 signed short 上界。
- 第一动作：只追**位串**：先把 32 位 int 截成低 16 位，再按 short 的补码语义解释，最后符号扩展回 int。

## 解题链

$$32777=0x00008009.$$

转为 16 位 `short` 时保留低 16 位：

```text
si = 0x8009 = 1000 0000 0000 1001₂
```

最高位为 1，按 16 位补码解释：

$$0x8009-2^{16}=32777-65536=-32759.$$

再赋给 32 位 `int j` 时做符号扩展，数值保持为

$$\boxed{-32759}.$$

故选 **B**。

## 选项判断

A 把溢出误解为“只改变正负号”；C 忘了按 signed short 解读最高位；D 忽略了窄化截断。

## Verification

$-32759$ 的 16 位补码正是 `0x8009`；符号扩展为 `0xFFFF8009` 后按 32 位补码仍为 -32759。

## Compression

`宽 signed -> 窄 signed -> 再扩宽` → **截低位 -> 按目标位宽重新解释 -> 符号扩展保持该新值**。

## 易错边界

窄化不是“保值转换”；一旦原值超出目标位宽，必须先看截断后的位串，再谈数值。
