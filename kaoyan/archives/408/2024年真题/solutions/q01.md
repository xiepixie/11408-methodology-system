# 408-2024-Q01

> 原题：[[../2024 年全国硕士研究生招生考试#1|Q1]]

## Model Anchor

- Topic：单链表的局部改边。
- 题目信号：连续出现 `q=p->next`、修改 `p->next`、再修改 `q->next`。
- 第一动作：不要逐句翻译成中文；先画局部链 `... -> p -> q -> r ...`，追踪每次赋值后哪条边被断开、哪条边被接上。

## 解题链

初始局部结构记为：

```text
h -> first -> ... -> p -> q -> r -> ...
```

执行：

```c
q = p->next;        // q 指向 p 的直接后继
p->next = q->next;  // 摘下 q，p 直接连到 r
q->next = h->next;  // q 指向原首元结点
h->next = q;        // q 成为新的首元结点
```

最终：

```text
h -> q -> old_first -> ... -> p -> r -> ...
```

所以是把 **q 所指结点移动到头结点之后**，选 **D**。

## 选项判断

- A：q 已经从 p 后面被摘下，不是插回 p 后。
- B、C：整个过程中没有移动 p 本身。
- D：与最终指针关系一致。

## Verification

检查两个链表不变量：q 仍然可从 `h` 到达；原来 q 后面的结点由 `p->next=q->next` 接回，因此没有丢链。

## Compression

`保存后继 q -> p 跨过 q -> q 接旧首元 -> head 接 q` → **摘下 p 的后继并头插**。

## 易错边界

链表改边题最危险的不是“记操作名”，而是丢失原后继。这里先保存 `q=p->next`，再断边，所以链不断。
