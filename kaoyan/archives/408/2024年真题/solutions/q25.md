# 408-2024-Q25

> 原题：[[../2024 年全国硕士研究生招生考试#25|Q25]]

## Model Anchor

- Topic：进程切换时 CPU execution context 与 address-space context 的恢复。
- 题目信号：PC、栈基址、页表基址分别代表“下一条指令、当前栈、当前地址空间”。
- 第一动作：问“新进程要正确继续执行，哪些当前 CPU 状态必须切换成它自己的值”。

## 解题链

切换到另一个进程时：

- PC 必须恢复为新进程下一条执行指令的位置；
- 栈相关寄存器（题中 EBP）必须恢复为新进程上下文中的值；
- 不同进程拥有不同虚拟地址空间，页表基址寄存器也需切换到新进程页表。

因此 I、II、III 都需要，选 **D**。

## 选项判断

A、B、C 都漏掉了组成完整进程上下文的一部分；执行流与地址空间必须同时对齐到新进程。

## Verification

若只恢复 PC/栈而不换页表，同一个虚拟地址会按旧进程页表解释；若只换页表而不恢复 PC/栈，也无法从新进程正确断点继续。

## Compression

进程切换 → **execution context + stack context + address-space context 一起恢复**。

## 易错边界

线程切换若发生在同一进程内，地址空间可能不变；本题明确是“进程切换”，不能把线程级优化条件套进来。
