# 408-2024-Q02

> 原题：[[../2024 年全国硕士研究生招生考试#2|Q2]]

## Model Anchor

- Topic：表达式的树结构 / 运算符栈。
- 题目信号：中缀表达式要求转后缀。
- 第一动作：先恢复运算依赖，不要按字符顺序硬搬：括号最高，其次乘除，最后加法；同优先级按左结合。

## 解题链

原式：

$$x+y\times(z-u)/v.$$

先分解结构：

```text
(z-u)      -> zu-
y*(z-u)    -> yzu-*
y*(z-u)/v  -> yzu-*v/
x + ...    -> xyzu-*v/+
```

所以后缀表达式为

```text
xyzu-*v/+
```

选 **A**。

## 选项判断

- A：严格保持 `z-u -> 乘 y -> 除 v -> 加 x` 的依赖，正确。
- B：把 `/v` 的位置塞进了括号子表达式的生成链，依赖次序错误。
- C、D：运算符出现在操作数之前，是前缀式特征，不是后缀式。

## Verification

从 A 逆向用栈求值：读到 `-` 合成 `(z-u)`，读到 `*` 合成 `y(z-u)`，再 `/v`，最后与 `x` 相加，恰好还原原式。

## Compression

中缀转后缀 → **先找表达式树依赖，再按“左子树—右子树—根”输出**。

## 易错边界

乘法和除法同优先级且左结合，因此这里必须先得到 `y*(z-u)`，再除以 `v`。
