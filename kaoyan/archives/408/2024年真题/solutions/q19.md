# 408-2024-Q19

> 原题：[[../2024 年全国硕士研究生招生考试#19|Q19]]

## Model Anchor

- Topic：流水线 RAW 数据冒险与 `ready/need` 时序。
- 题目信号：选项比较“气泡、转发、重排/nop”能否解决**所有**数据冒险。
- 第一动作：找最小反例——经典 `load-use`：生产值到 MEM 末端才 ready，而下一条指令在 EX 就 need。

## 解题链

A 正确：相邻相关指令可能形成 RAW 冒险。

B 正确：插入足够气泡可把 consumer 的 need 推迟到 producer ready 之后。

C 错误：转发只能传送**已经产生**的值。对紧邻的 load-use，load 数据通常到 MEM 后才可用，而下一条指令在 EX 阶段已经需要，单靠旁路无法把未来值提前产生，仍需停顿。

D 正确：通过调度独立指令或插入足够 `nop` 可以推迟相关 consumer，消除时序冲突。

故选 **C**。

## 选项判断

C 把“转发能减少大量 RAW stall”扩大成“能解决所有数据冒险”，越过了 `ready <= need` 的必要条件。

## Verification

时间轴反例：

```text
lw   : IF ID EX MEM WB
use  :    IF ID EX  MEM WB
                 ^ need
lw data ready --------^ MEM末
```

consumer EX 需要值时，load 数据尚未产生，因此必须至少等待。

## Compression

流水线数据冒险 → **写 producer ready 与 consumer need** → `ready > need` 就必须 stall；forwarding 只能运送现成值。

## 易错边界

“数据相关”是程序关系，“数据冒险”是具体流水实现中的时序冲突；相关不一定冒险，冒险也取决于 forwarding/寄存器堆时序。
