# 408-2024-Q13

> 原题：[[../2024 年全国硕士研究生招生考试#13|Q13]]

## Model Anchor

- Topic：软件表示层、ISA 层与微程序控制层的边界。
- 题目信号：同时出现“伪指令、微指令、机器指令、汇编指令”。
- 第一动作：先问每一种对象的**执行者是谁**，而不是看名字里有没有“指令”二字。

## 解题链

- 伪指令：由汇编器处理，不进入 CPU 的机器指令流；
- 微指令：由微程序控制器读取并产生微操作控制信号，属于 CPU 内部控制层；
- 机器指令：CPU 从主存取指、译码并执行；
- 汇编指令：是机器指令的人类可读助记形式，需先由汇编器翻译。

所以 CPU 硬件直接处理的是 II、III，选 **B**。

## 选项判断

A、D 都把伪指令误当成运行时 CPU 对象；C 把汇编源码助记符当成 CPU 直接执行的二进制 ISA 编码。

## Verification

沿工具链检查：

```text
伪指令/汇编源码 -> 汇编器 -> 机器指令 -> CPU
                                  |
                                  -> 微程序控制器展开为微指令（若采用微程序控制）
```

层次没有交叉。

## Compression

“CPU 直接执行谁？” → **先标执行者：汇编器 / ISA CPU / 微程序控制器** → 机器指令和微指令属于硬件执行层。

## 易错边界

“汇编指令与机器指令一一对应”不意味着 CPU 直接读汇编文本；可读表示与机器编码仍是两个层次。
