# 408-2021-Q29

## Model Anchor

- Topic：多级页表与页表根指针。
- 题目信号：问 PTBR 中保存哪一级、哪种地址。
- 第一动作：从硬件页表遍历的起点反推：CPU 必须先能直接访问顶级页表。

## 解题链

二级页表地址翻译从一级页表开始。MMU 发起内存访问时使用的是物理地址，因此页表基址寄存器必须给出当前进程**一级页表的起始物理地址**。

二级页表地址由一级页表项继续获得，不需要 PTBR 直接保存。

## 选项判断

故选 $\boxed{B}$。

## Verification

若 PTBR 保存的是虚拟地址，翻译这个地址本身又需要页表，会形成递归依赖。

## Compression

```text
page-table walk root
-> top-level page table
-> hardware needs physical access
=> PTBR = L1 page table physical base
```

## 易错边界

现代体系结构实现细节可以更复杂，但 408 的分页模型中 PTBR 是页表遍历的物理根。
