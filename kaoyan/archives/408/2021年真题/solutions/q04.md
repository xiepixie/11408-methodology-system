# 408-2021-Q04

## Model Anchor

- Topic：森林与孩子-兄弟二叉树转换。
- 题目信号：给出二叉树先序、中序，问原森林有几棵树。
- 第一动作：先由遍历序列恢复二叉树的**右孩子链**；森林中各棵树的根正对应这条兄弟链。

## 解题链

先序首元素 `a` 是二叉树根。中序中 `a` 左侧为 `b,d`，右侧为 `e,g,c,f`。

据此继续恢复右子树，其根为 `c`；`c` 的右子树根为 `f`。因此根层的右兄弟链为

```text
a -> c -> f
```

孩子-兄弟表示中，根结点的右孩子表示下一棵树的根，所以森林共有 3 棵树。

## 选项判断

故选 $\boxed{C}$。

## Verification

只需检查根的连续右链长度，而不是统计二叉树叶子数或根的左右子树数。

## Compression

```text
pre+in -> rebuild binary tree
forest roots = root's right-sibling chain
a -> c -> f
=> 3 trees
```

## 易错边界

“左孩子=第一个孩子，右孩子=下一个兄弟”。问森林棵数时，应追踪根层右兄弟链。
