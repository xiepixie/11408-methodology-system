# 408-2021-Q27

## Model Anchor

- Topic：调度触发事件。
- 题目信号：问哪些事件“可能引起调度程序执行”。
- 第一动作：判断事件后当前 Running 是否失去 CPU、失去运行条件，或出现需要重新决策的候选集。

## 解题链

I. 中断处理结束后，可能发现更高优先级就绪进程，需要调度。  
II. 当前进程阻塞后不能继续运行，必须选别人。  
III. 当前进程结束后 CPU 空出，必须重新选择。  
IV. 时间片耗尽是典型抢占调度点。

四种事件都可能触发 scheduler。

## 选项判断

故选 $\boxed{D}$。

## Verification

题干说“可能”，并不要求每次中断结束都一定发生进程切换；只要存在合法场景会触发调度即可。

## Compression

```text
scheduler may run when
current stops / blocks / quantum expires
or interrupt completion changes runnable priority
=> all four
```

## 易错边界

“执行调度程序”和“最终切换到另一个进程”不是同一件事；调度后也可能继续选择当前进程。
