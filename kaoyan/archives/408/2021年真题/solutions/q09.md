# 408-2021-Q09

## Model Anchor

- Topic：B 树阶数、高度与结点数上界。
- 题目信号：3 阶 B 树、高度 3、已知第 2 层关键字总数，求最多结点数。
- 第一动作：把“关键字数”转换成“孩子数”，并在每层使用允许的最大分支数。

## 解题链

3 阶 B 树中，每个结点最多有 3 个孩子、2 个关键字。

为了让总结点数最大，根应尽可能有 3 个孩子，因此第 2 层最多有 3 个结点。题设第 2 层共有 4 个关键字，可分配为 `2+1+1`。

非叶结点有 $k$ 个关键字时有 $k+1$ 个孩子，因此第 3 层最多有

$$3+2+2=7$$

个结点。

总数为

$$1+3+7=11.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

构造 `2,1,1` 的第 2 层关键字分配满足每个非根结点至少 1、最多 2 个关键字，所以上界可达。

## Compression

```text
order 3 -> max keys 2, max children 3
level2: 4 keys over 3 nodes -> 2+1+1
level3 max = 3+2+2=7
nodes = 1+3+7=11
```

## 易错边界

B 树题要区分“关键字数”和“结点数”；结点的孩子数是关键字数加 1。
