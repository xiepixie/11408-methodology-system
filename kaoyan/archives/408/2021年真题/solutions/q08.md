# 408-2021-Q08

## Model Anchor

- Topic：Dijkstra 的“确定一个顶点，再松弛邻边”状态机。
- 题目信号：问“求出第二条最短路径后”的 `dist`，属于中间状态题。
- 第一动作：严格区分 `dist` 当前估计值与已经永久确定的最短路。

## 解题链

以 1 为源点，初始化后：

```text
dist(2,3,4,5) = (26, 3, ∞, 6)
```

第一次选出最小的顶点 3，松弛其邻边后得到

```text
(25, 3, 14, 6)
```

第二次选出当前最小的顶点 5（距离 6），再松弛后，顶点 2 的估计距离降为 21：

```text
(21, 3, 14, 6)
```

## 选项判断

故选 $\boxed{C}$。

## Verification

第二条“已确定最短路径”是到顶点 5 的路径；此时 `dist[2]` 仍只是候选值 21，并未要求已经确定。

## Compression

```text
Dijkstra
-> pick min unsettled
-> relax
-> pick next min
-> relax again
=> (21,3,14,6)
```

## 易错边界

题目问中间 `dist` 时，不要直接写最终最短距离；每轮只能使用刚刚确定顶点的出边做松弛。
