# 408-2021-Q38

## Model Anchor

- Topic：TCP 主动关闭状态机。
- 题目信号：客户先发 FIN，随后收到服务器 FIN 并回 ACK。
- 第一动作：先确定谁是 active closer，再沿该端状态迁移。

## 解题链

客户端主动关闭：

```text
ESTABLISHED
-> send FIN -> FIN_WAIT_1
-> receive ACK -> FIN_WAIT_2
-> receive FIN, send ACK -> TIME_WAIT
-> after 2MSL -> CLOSED
```

题目问的是“收到服务器 FIN 并发送 ACK 后”的状态，因此为 `TIME_WAIT`。

## 选项判断

故选 $\boxed{B}$。

## Verification

`CLOSE_WAIT` 属于被动关闭方收到对端 FIN 后的状态，不属于本题主动关闭客户端。

## Compression

```text
active close
FIN_WAIT_1 -> FIN_WAIT_2
peer FIN + ACK sent -> TIME_WAIT
```

## 易错边界

TCP 四次挥手不要只背四个报文；先标 active/passive owner，再沿各自状态机走。
