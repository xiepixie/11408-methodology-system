# 408-2021-Q14

## Model Anchor

- Topic：二进制浮点数的可精确表示性。
- 题目信号：问哪个十进制数不能被 IEEE 754 精确表示。
- 第一动作：把小数化成分数，检查约分后的分母是否只有因子 2。

## 解题链

有限二进制小数必须形如 $k/2^m$。

- $1.25=5/4$：可精确表示；
- $2.0=2$：可精确表示；
- $2.5=5/2$：可精确表示；
- $1.2=6/5$：分母含因子 5，二进制展开无限循环。

## 选项判断

故选 $\boxed{A}$。

## Verification

判断关键不是“位数够不够”，而是数在二进制中是否为有限展开。

## Compression

```text
exact binary fraction
-> reduced denominator must be 2^k
1.2=6/5 -> repeating binary
```

## 易错边界

IEEE 754 有限精度只是第二层问题；像 1.2 这种数即使尾数再长，也无法用有限二进制位精确表示。
