# 408-2021-Q35

## Model Anchor

- Topic：CIDR 子网块的对齐、覆盖与互斥。
- 题目信号：一个网络被**划分为 3 个子网**，已知其中一个 `/26`，判断另一个子网是否可能。
- 第一动作：不要只检查“与已知子网是否重叠”，还要检查三个子网能否共同构成一个连续父地址块。

## 解题链

已知子网 `192.168.9.128/26` 覆盖 `128～191`。

- A `0/25` 覆盖 `0～127`，再配 `192/26` 可恰好形成 3 个子网；
- C `192/26` 可与 `0/25`、已知 `/26` 组成 3 个子网；
- D `192/27` 可再配 `224/27`，与已知 `128/26` 一起覆盖 `128～255`；
- B `0/26` 覆盖 `0～63`。与已知 `128～191` 之间还剩 `64～127`，之后还有 `192～255`，至少还要两个子网才能补齐，因此无法只划成 3 个子网。

## 选项判断

故选 $\boxed{B}$。

## Verification

关键约束是“partition”：子网必须互不重叠，并共同覆盖某个父网络，而不是任取三个合法 CIDR 块。

## Compression

```text
known = 128/26
candidate B = 0/26
remaining gaps = 64/26 and 192/26
=> need 4 subnets total
```

## 易错边界

CIDR 题除了看前缀和对齐，还要看题目是在问“合法网络”还是“某父网络的完整划分”。
