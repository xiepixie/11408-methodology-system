# 408-2021-Q18

## Model Anchor

- Topic：数据通路的对象边界。
- 题目信号：判断哪些部件/功能属于 datapath。
- 第一动作：按 `state elements + combinational operators + paths + status/exception signals` 判断，而不是把数据通路缩成“ALU+寄存器”。

## 解题链

A、B 正确：ALU 属于组合逻辑操作元件，寄存器属于时序逻辑状态元件。

D 正确：数据在各部件之间如何流动，由控制信号选择和使能。

C 错误。异常检测往往直接依赖运算结果、地址、状态等数据通路内部信息，相应检测电路可以属于数据通路的一部分；不能绝对说数据通路不包含异常事件检测及响应相关电路。

## 选项判断

故选 $\boxed{C}$。

## Verification

只要异常条件由 ALU/访存等执行过程中产生，就必须有硬件路径把该状态送往控制逻辑。

## Compression

```text
datapath = operators + state + data paths + status generation
absolute “no exception circuitry” -> false
```

## 易错边界

控制部件和数据通路职责不同，但二者通过状态/异常信号紧密连接，不能理解成完全割裂。
