# 408-2021-Q20

## Model Anchor

- Topic：I/O 设备与 I/O 接口的层次边界。
- 题目信号：问“不属于 I/O 接口”的对象。
- 第一动作：判断对象是外部设备本体，还是连接 CPU/总线与设备的控制接口。

## 解题链

打印机适配器、网络控制器、可编程中断控制器都属于主机侧控制/接口部件。

磁盘驱动器是实际 I/O 设备本体，不是 I/O 接口。

## 选项判断

故选 $\boxed{A}$。

## Verification

“设备”和“设备控制器/接口”是两个 Owner；驱动器负责实际存储介质访问，接口负责主机侧通信与控制。

## Compression

```text
I/O interface != device itself
adapter/controller/PIC -> interface/controller
Disk drive -> device
```

## 易错边界

名称里有“控制器”的通常更接近接口层，但最终仍应按其在数据路径中的职责判断。
