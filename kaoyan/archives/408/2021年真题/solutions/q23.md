# 408-2021-Q23

## Model Anchor

- Topic：特权指令与 CPU 模式。
- 题目信号：问“只能在内核态执行”的指令。
- 第一动作：判断该指令是否能直接改变/控制系统级共享资源或硬件状态。

## 解题链

I/O 指令可直接操作设备控制器，若允许普通用户程序任意执行，会破坏系统的保护与资源仲裁，因此属于典型特权指令，只能在内核态执行。

`trap` 本身必须允许用户程序触发，否则用户态无法进入系统调用；普通数据传送和调试断点指令也不等同于特权 I/O 控制。

## 选项判断

故选 $\boxed{B}$。

## Verification

系统调用正是“用户态执行非特权 trap → CPU 切入内核态 → 内核执行受保护操作”。

## Compression

```text
privileged?
-> can directly control protected hardware/resource
I/O instruction -> kernel only
```

## 易错边界

“会导致进入内核态”的指令不一定是特权指令；trap 必须能由用户态合法发起。
