# 408-2021-Q21

## Model Anchor

- Topic：异常类型与返回点语义。
- 题目信号：问处理程序执行后“必须回到当前指令重新执行”的事件。
- 第一动作：判断事件属于 fault、trap 还是 interrupt，并追踪保存的返回 PC 指向哪里。

## 解题链

页缺失发生在当前指令访问尚未驻留页面时。异常处理程序把缺页调入、修复页表后，原指令此前并未成功完成，因此必须重新执行该指令。

系统调用通常是主动 trap，返回到后继指令；DMA 完成和打印机缺纸属于外部中断/设备事件，不要求重新执行刚完成的当前指令。

## 选项判断

故选 $\boxed{B}$。

## Verification

缺页处理的目标正是让**同一条失败的访存指令**在状态修复后能够再次成功执行。

## Compression

```text
page fault = recoverable fault
current instruction incomplete
repair page state -> restart same instruction
```

## 易错边界

“异常”不是都重执行当前指令；必须看异常类别以及指令是否已经提交完成。
