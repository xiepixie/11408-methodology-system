# 408-2021-Q12

## Model Anchor

- Topic：性能单位与数量级换算。
- 题目信号：`93.0146 PFLOPS`，问每秒浮点操作次数。
- 第一动作：先把 SI 前缀恢复成幂次，再比较数量级。

## 解题链

$$1\text{ PFLOPS}=10^{15}\text{ FLOP/s}.$$

因此

$$93.0146\times10^{15}\approx9.3\times10^{16}\text{ 次/s}.$$

“亿亿”对应 $10^{16}$，所以约为 9.3 亿亿次/秒。

## 选项判断

故选 $\boxed{D}$。

## Verification

93 PFLOPS 不是 $9.3\times10^{15}$，因为把 93 写成科学计数法还要再乘 10。

## Compression

```text
P = 10^15
93 P = 9.3×10^16
= 9.3 亿亿
```

## 易错边界

单位换算题先处理前缀，再处理小数点；不要只看到 `P=10^15` 就直接选 $10^{15}$ 量级。
