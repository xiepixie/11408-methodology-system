# 408-2021-Q10

## Model Anchor

- Topic：LSD 基数排序的一趟稳定分配/收集。
- 题目信号：只问第 1 趟后 372 的相邻元素。
- 第一动作：只看个位，并保持同桶内原相对次序。

## 解题链

按个位分桶：

```text
1: 151, 301
2: 372, 892
3: 93, 43
5: 485
6: 946, 146, 236
7: 327
9: 9
```

按 0～9 收集后，372 前面紧邻 301，后面紧邻 892。

## 选项判断

故选 $\boxed{C}$。

## Verification

372 与 892 个位同为 2，稳定排序要求 372 仍在 892 前。

## Compression

```text
LSD first pass -> units digit buckets
stable within bucket
... 301,372,892 ...
```

## 易错边界

基数排序每一趟必须稳定；若打乱同桶元素次序，后续高位排序不能保证正确。
