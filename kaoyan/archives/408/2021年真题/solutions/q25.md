# 408-2021-Q25

## Model Anchor

- Topic：时间片轮转调度的最小机制集合。
- 题目信号：问 RR 调度“需要使用”的内核对象/程序。
- 第一动作：从 `who is runnable -> how timer fires -> where context lives` 反推必要组件。

## 解题链

RR 至少需要：

- PCB：保存/恢复进程执行现场与调度状态；
- 时钟中断处理程序：检测时间片耗尽并触发调度点；
- 就绪队列：按轮转顺序维护可运行进程。

阻塞队列是处理等待事件所需的通用 OS 结构，但不是实现“时间片轮转策略”本身的必要组成。

## 选项判断

故 I、II、III，选 $\boxed{C}$。

## Verification

若没有时钟中断，就无法按固定时间片抢占；若没有就绪队列，就没有“轮转”候选集合。

## Compression

```text
RR = PCB state + timer interrupt + ready queue
blocked queue not required by RR policy itself
```

## 易错边界

题目问的是实现某**调度策略**所需机制，不是完整操作系统一定拥有的全部数据结构。
