# 408-2021-Q13

## Model Anchor

- Topic：同一位模式的有符号/无符号解释。
- 题目信号：给机器数，分别比较 unsigned 与 two's complement。
- 第一动作：位模式不变，只切换解释契约。

## 解题链

16 位机器数：

```text
x = FFFDH
 y = FFDFH
 z = 7FFCH
```

按无符号解释：`z < y < x`。

按补码解释：

$$x=-3,\qquad y=-33,\qquad z=32764,$$

所以

$$y<x<z.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

`FFxxH` 最高位为 1，按 16 位补码必须是负数；`7FFCH` 为正数，因此 z 一定最大。

## Compression

```text
same bits, different interpretation
signed: FFFD=-3, FFDF=-33, 7FFC=32764
=> y<x<z
```

## 易错边界

不要把十六进制机器数默认当成无符号数；题目指定补码时，最高位 1 的模式要按负数解释。
