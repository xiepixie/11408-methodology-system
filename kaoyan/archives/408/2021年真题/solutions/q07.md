# 408-2021-Q07

## Model Anchor

- Topic：拓扑排序与可选前沿。
- 题目信号：问拓扑序列个数，而不是求任意一个序列。
- 第一动作：每一步维护当前入度为 0 的顶点集合；只要某一步出现多个候选，就产生分支。

## 解题链

按图逐步删除当前入度为 0 的顶点。每次删除顶点及其出边后，下一步的零入度候选始终只有一个，因此整个过程中没有发生选择分叉。

也就是说，zero-indegree frontier 的大小在每个决策点都为 1，拓扑序唯一。

## 选项判断

故拓扑有序序列个数为 1，选 $\boxed{A}$。

## Verification

拓扑序唯一的充分且在此模拟中直接可检验的条件，就是 Kahn 过程中每轮候选集合始终是单元素。

## Compression

```text
count topological orders
-> track zero-indegree frontier
-> frontier size always 1
-> unique order
```

## 易错边界

“图是 DAG”只保证至少存在拓扑序，不保证唯一；唯一性必须看每一步是否出现多个合法候选。
