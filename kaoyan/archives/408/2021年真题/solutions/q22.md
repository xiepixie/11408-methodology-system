# 408-2021-Q22

## Model Anchor

- Topic：多重中断的检测、屏蔽与响应条件。
- 题目信号：判断 CPU 何时能检测/响应中断。
- 第一动作：把 `CPU mode / interrupt enable / mask / pending request` 四个状态分开。

## 解题链

A 错误。CPU 并非只有在用户态才能检测和响应中断；若允许中断嵌套，在内核态执行中断处理程序时也可能响应更高优先级中断。

B 正确：没有检测到请求，就不会进入中断响应周期。

C 正确：能够正式响应可屏蔽中断时，CPU 必须处于允许中断状态。

D 正确：若 CPU 已检测到可响应的中断请求，则至少存在一个未被屏蔽的有效中断源。

## 选项判断

故选 $\boxed{A}$。

## Verification

“内核态”与“关中断”不是同义词；二者是不同状态维度。

## Compression

```text
mode != interrupt enable
kernel mode can still accept nested interrupt
=> A false
```

## 易错边界

不要把“进入中断处理程序后通常会临时关中断”绝对化成“内核态永远不能响应中断”。
