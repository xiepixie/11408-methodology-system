# 408-2021-Q43

## Model Anchor

- Topic：机器字长、总线宽度、指令格式编码与补码运算。
- 题目信号：同一题同时给 `word size / address bus / data bus / R-I-J formats`。
- 第一动作：先把几个“宽度 Owner”分开，再按指令字段边界解码；不要把字长、数据线宽和寄存器宽度机械画等号。

## Problem Representation

题图的编码契约可写成：

```text
R type: 000000 | rs(2) | rt(2) | rd(2) | op1(4)
I type: op2(6) | rs(2) | rt(2) | imm(6)
J type: op3(6) | target(10)
```

机器 M：

```text
word size = 16 bit
address bus = 20 bit
 data bus = 8 bit
instruction = 16 bit
```

## Decision Points

1. ALU 宽度由运算字长决定；MAR 对齐地址线，MDR 对齐一次总线传输宽度。
2. R 型前 6 位 `000000` 已作为类型前缀，占用了一个 6 位操作码空间。
3. `01B2H/01B3H` 必须先按字段切分，再解释 op1；乘法溢出要按 16 位补码范围判断，而不是只看低 16 位结果。
4. 带符号偏移量参与地址加法时必须保持符号。

## Solution Chain

### (1) 各宽度

ALU 处理 16 位机器字，因此

$$\boxed{ALU=16\text{ bit}}.$$

20 根地址线、按字节编址，可寻址空间：

$$2^{20}\text{ B}=\boxed{1\text{ MB}}.$$

寄存器宽度：

- IR：一条指令 16 bit，故 $\boxed{16\text{ bit}}$；
- MAR：容纳主存地址，故 $\boxed{20\text{ bit}}$；
- MDR：与 8 bit 数据总线一次传输宽度匹配，故 $\boxed{8\text{ bit}}$。

### (2) 操作数与寄存器数量

R 型 `op1` 为 4 bit：

$$\boxed{2^4=16\text{ 种操作}}.$$

I/J 型使用 6 bit 的 `op2/op3` 操作码空间。`000000` 已作为 R 型前缀，因此二者合计最多：

$$\boxed{2^6-1=63\text{ 种操作}}.$$

`rs/rt/rd` 均为 2 bit，因此最多

$$\boxed{2^2=4\text{ 个通用寄存器}}.$$

### (3) `01B2H` 与 `01B3H`

`01B2H`：

```text
000000 | 01 | 10 | 11 | 0010
```

因此 `rs=1, rt=2, rd=3, op1=0010`。题设 `0010` 为带符号减法，所以

$$\boxed{R[3]\leftarrow R[1]-R[2]}.$$

已知

```text
R1 = B052H
R2 = 0008H
```

按 16 位补码，`B052H` 是负数。减法得到

$$B052H-0008H=\boxed{B04AH}.$$

其真值仍在 16 位补码范围内，故**不溢出**。

`01B3H` 仅 op1 改为 `0011`，表示带符号乘法：

$$R[3]\leftarrow R[1]\times R[2].$$

低 16 位结果为

$$B052H\times0008H\equiv\boxed{8290H}\pmod{2^{16}}.$$

但 $B052H=-20398$，乘 8 得

$$-163184<-32768,$$

超出 16 位补码范围，因此**发生溢出**。

### (4) imm 扩展

`imm` 是带符号偏移量，地址计算前必须

$$\boxed{\text{符号扩展}}$$

到运算所需宽度，才能保持负偏移量的数值不变。

### (5) 无条件转移

J 型格式的语义已经给出

```text
PC low 10 bits <- target
```

因此无条件转移可采用

$$\boxed{J\text{ 型格式}}.$$

## Verification

- `01B2H` 的前 6 位确为 `000000`，所以一定进入 R 型解释，不能误当 I/J 型。
- 乘法结果 `8290H` 只是截断后的机器数；判断溢出必须检查真实数学结果是否落在 $[-2^{15},2^{15}-1]$。
- MDR=8 bit 与“机器字长16位”不冲突：取一个 16 位字可能需要多次总线传送。

## Compression

```text
separate widths:
ALU=word=16, MAR=address=20, MDR=data-bus=8, IR=instruction=16
R ops=2^4=16
I+J ops=2^6-1=63
2-bit reg id -> 4 GPRs
01B2 -> R3=R1-R2=B04A, no OF
01B3 -> low16=8290, signed multiply overflows
signed imm -> sign extend
jump -> J type
```

## 易错边界

- “字长=16”不推出所有 CPU 寄存器都必须 16 位；MAR/MDR 分别受地址空间与外部数据通路约束。
- 截断后得到一个合法 16 位模式，不代表算术没有溢出。
- Legacy 对第 (4) 问曾用“跳转可前后”解释符号扩展，但题目说的是 I 型访存偏移；正确理由是**imm 本身定义为带符号地址偏移量**。
