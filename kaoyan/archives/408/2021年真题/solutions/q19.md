# 408-2021-Q19

## Model Anchor

- Topic：总线时序与事务粒度。
- 题目信号：同步/异步/突发传送混合判断。
- 第一动作：分别判断“谁定时”和“一次事务搬多少数据”，不要把握手次数等同于比特数。

## 解题链

A 正确：总线是多个部件共享的数据交换通道。

B 正确：同步总线由时钟协调事务，时钟频率和有效数据事务频率不必一一相等。

C 错误：异步总线利用请求/应答等握手信号协调一次**数据事务**，一次握手可以传送一个字节、一个字或其他总线宽度的数据，并非固定只传 1 bit。

D 正确：Burst 事务允许在一次地址/控制建立后连续传输多个数据。

## 选项判断

故选 $\boxed{C}$。

## Verification

总线数据线通常本来就有多位宽；若“一次握手只传一位”，会与数据总线宽度概念冲突。

## Compression

```text
sync -> clock timed
async -> handshake timed
handshake unit = transaction, not 1 bit
burst -> multiple data beats
```

## 易错边界

“异步”表示没有统一时钟约束，不表示串行逐位传输。
