# 408-2021-Q01

## Model Anchor

- Topic：带头结点单循环链表的删除。
- 题目信号：删除首元结点，同时给出尾指针 `p`。
- 第一动作：先写删除首元结点的局部指针修改，再单独检查“原链表只有一个数据结点”的边界。

## 解题链

设待删结点为

```c
q = h->next;
```

删除后，头结点应跨过 `q`：

```c
h->next = q->next;
```

若原链表只有一个数据结点，则 `p == q`。删除它以后，循环链表只剩头结点，尾指针必须回到 `h`：

```c
if (p == q) p = h;
```

最后才能释放 `q`。

## 选项判断

A 先改 `h->next` 再给 `q` 赋值，会释放错误结点；C 把尾指针更新条件写反。故选

$$\boxed{D}.$$

## Verification

用单元素链表验证：删除前 `h->next=q=p`，删除后应有 `h->next=h` 且 `p=h`，D 正好满足。

## Compression

```text
save first -> bypass it -> if it was tail, tail=head -> free
```

## 易错边界

涉及删除时，必须先保存待删结点地址；出现尾指针时，额外检查空表/单元素边界。
