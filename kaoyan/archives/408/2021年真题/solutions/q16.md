# 408-2021-Q16

## Model Anchor

- Topic：直接映射 Cache 行结构与写回状态位。
- 题目信号：32 KB Cache、32 B block、32 位地址、Write Back，问“Cache 行至少多少位”。
- 第一动作：先分 `data / tag / valid / dirty`，不要把组号、块内偏移存进 Cache 行。

## 解题链

Cache 行数：

$$32KB/32B=1024=2^{10}.$$

块内偏移 5 位，行号 10 位，所以 Tag 为

$$32-10-5=17\text{ 位}.$$

一行数据区为

$$32B=256\text{ bit}.$$

直接映射至少还需有效位；Write Back 还需脏位，因此总位数

$$256+17+1+1=275.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

地址中的 index 和 offset 用于定位，不作为每行元数据保存；需要保存的是用于命中比较的 Tag。

## Compression

```text
32KB/32B = 2^10 lines
offset=5, index=10, tag=17
line = 256 data +17 tag +V +D =275
```

## 易错边界

Write Back 必须记录 dirty；若题目改为 Write Through，则不一定需要该脏位。
