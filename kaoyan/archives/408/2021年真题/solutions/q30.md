# 408-2021-Q30

## Model Anchor

- Topic：文件删除与命名引用生命周期。
- 题目信号：删除 `dir/file1`，问内核“不必完成”的工作。
- 第一动作：沿 `pathname -> directory entry -> file object -> storage` 追踪真正被删除的引用。

## 解题链

删除文件名 `dir/file1` 至少要删除目录中的对应目录项。若这是文件的最后一个硬链接，文件系统随后释放其文件控制块及数据块。

所谓“快捷方式”若指独立的符号链接/快捷入口，它拥有自己的目录项和对象；删除原文件不会要求内核遍历并删除这些独立引用，它们可以成为悬空链接。

## 选项判断

故“不必完成”的是 A，选 $\boxed{A}$。

## Verification

删除一个 pathname 的核心语义是解除这个名字与文件对象之间的绑定，而不是全局寻找所有可能指向它的软链接。

## Compression

```text
unlink file1
-> remove dir entry
-> if last hard link: free metadata + data
-> do not chase/delete symbolic shortcuts
```

## 易错边界

释放 inode/数据块是否立即发生取决于是否仍有硬链接或打开引用；题目按教材中的“最后引用删除”口径作答。
