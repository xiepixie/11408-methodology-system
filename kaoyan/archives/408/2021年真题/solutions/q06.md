# 408-2021-Q06

## Model Anchor

- Topic：AVL 插入与失衡类型判定。
- 题目信号：插入 23 后问新根。
- 第一动作：沿插入路径向上找**第一个失衡结点**，再由“失衡方向 + 子树方向”判旋转类型。

## 解题链

23 的搜索路径为

```text
20 -> 30 -> 25 -> left
```

插入后，结点 20 右子树过高，而其右孩子 30 又是左侧增高，属于 RL 型失衡。

先对 30 右旋，再对 20 左旋，局部结构变为

```text
        25
       /  \
     20    30
    / \     \
   16 23     40
```

因此新根为 25。

## 选项判断

故选 $\boxed{D}$。

## Verification

旋转后各结点左右子树高度差均不超过 1，且中序序列仍保持 BST 有序性。

## Compression

```text
insert 23
-> first unbalanced node = 20
-> right-left growth
-> RL rotation
-> root = 25
```

## 易错边界

AVL 判断旋转类型看的是**插入路径**，不是只看新结点与根的大小关系。
