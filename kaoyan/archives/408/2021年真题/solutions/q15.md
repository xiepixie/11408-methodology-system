# 408-2021-Q15

## Model Anchor

- Topic：存储器位扩展与字扩展。
- 题目信号：地址范围、按字编址、32 位字长、给定芯片组织。
- 第一动作：把需求拆成“深度 × 位宽”，分别求字扩展倍数和位扩展倍数。

## 解题链

RAM 地址 `000000H～3FFFFFH` 共

$$2^{22}$$

个字。每字 32 bit，因此目标组织为 $2^{22}\times32$ bit。

单芯片为

$$512K\times8=2^{19}\times8\text{ bit}.$$

位宽需

$$32/8=4$$

片并联；深度需

$$2^{22}/2^{19}=8$$

组。故总芯片数

$$4\times8=32.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

`32 × 512K×8 bit = 128 Mbit = 16 MB`，与 $2^{22}$ 个 32 位字的容量一致。

## Compression

```text
required = 2^22 words × 32 bit
chip = 2^19 × 8 bit
width ×4, depth ×8
=> 32 chips
```

## 易错边界

本题按**字编址**，24 位地址不是 16 MB 字节地址空间；先锁定编址单位再算容量。
