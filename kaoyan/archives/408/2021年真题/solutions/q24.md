# 408-2021-Q24

## Model Anchor

- Topic：进程创建的对象生命周期。
- 题目信号：问创建新进程时“必须完成”的操作。
- 第一动作：从 `process identity -> PCB -> initial runnable state -> scheduling` 分层判断。

## 解题链

创建进程必须先获得一个新的 PCB，并初始化 PID、上下文、资源引用、状态等必要字段，所以 I、II 必须完成。

新进程创建完成后通常进入就绪态；是否立即执行由调度器决定，因此不能把状态直接设置为执行态作为创建的必要动作。

## 选项判断

故仅 I、II，选 $\boxed{B}$。

## Verification

`Ready -> Running` 需要一次调度/分派事件，不能由“创建”这个事件直接保证。

## Compression

```text
create process
-> allocate PCB
-> initialize PCB
-> Ready
-> scheduler may later dispatch
```

## 易错边界

“创建完成”不等于“立即获得 CPU”。对象建立和调度策略是两层机制。
