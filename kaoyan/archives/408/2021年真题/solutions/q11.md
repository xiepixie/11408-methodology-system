# 408-2021-Q11

## Model Anchor

- Topic：大根堆插入。
- 题目信号：按给定顺序逐个插入空堆。
- 第一动作：每插入一个元素，只沿其父链向上调整，不重新建堆。

## 解题链

依次插入 `6,9,1,5,8,4,7`：

```text
[6]
[9,6]
[9,6,1]
[9,6,1,5]
[9,8,1,5,6]
[9,8,4,5,6,1]
[9,8,7,5,6,1,4]
```

最终堆序列为 `9,8,7,5,6,1,4`。

## 选项判断

故选 $\boxed{B}$。

## Verification

逐结点检查父结点均不小于两个孩子，满足大根堆不变量。

## Compression

```text
insert at tail
-> bubble up on parent chain
-> [9,8,7,5,6,1,4]
```
