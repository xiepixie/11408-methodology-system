# 408-2021-Q32

## Model Anchor

- Topic：系统调用的接口边界。
- 题目信号：问哪项操作“通过系统调用完成”。
- 第一动作：判断动作是用户程序主动请求内核服务，还是内核内部机制自行触发。

## 解题链

创建新进程需要用户程序通过 OS 提供的进程创建接口请求内核分配 PCB、地址空间及相关资源，因此属于典型系统调用。

页置换和进程调度是内核内部机制；生成普通随机整数可以由用户态库函数/算法完成，并非必然通过系统调用。

## 选项判断

故选 $\boxed{C}$。

## Verification

系统调用的核心是 `user request -> trap -> kernel service`，而不是“只要 OS 参与就是系统调用”。

## Compression

```text
system call = explicit user->kernel service request
create process -> yes
replacement/scheduling -> kernel internal
```

## 易错边界

库函数和系统调用不是同义词；某些库函数内部可能调用 syscall，但题目问的是操作的基本实现边界。
