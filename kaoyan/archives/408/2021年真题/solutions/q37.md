# 408-2021-Q37

## Model Anchor

- Topic：距离向量 Bellman-Ford 更新。
- 题目信号：给 E 到各邻居的链路代价和邻居 distance vector。
- 第一动作：对每个目的网络独立计算

$$D_E(N)=\min_v\{c(E,v)+D_v(N)\}.$$

## 解题链

E 到邻居 A、B、C、D 的直接代价分别为 `8,10,12,6`。把各邻居通告值分别加上对应本地链路代价后，对 Net1～Net4 逐列取最小值，得到：

```text
Net1 -> 9
Net2 -> 20
Net3 -> 28
Net4 -> 20
```

因此新的距离向量为

$$(9,20,28,20).$$

## 选项判断

故选 $\boxed{D}$。

## Verification

DV 的比较单位必须是“经某邻居的完整候选代价”，不能只比较邻居自己通告的距离，也不能只比较到邻居的直连代价。

## Compression

```text
for each destination N:
neighbor advertised distance + local link cost
-> take minimum
=> (9,20,28,20)
```

## 易错边界

路由更新是按**每个目的网络**分别选最小候选；不存在“选一个整体最好的邻居，然后所有网络都走它”。
