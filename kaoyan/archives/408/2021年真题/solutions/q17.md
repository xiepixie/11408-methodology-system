# 408-2021-Q17

## Model Anchor

- Topic：ISA 可见状态与微体系结构内部状态。
- 题目信号：问“汇编语言程序员可见”的寄存器。
- 第一动作：判断该状态是否能被指令显式引用或影响程序语义。

## 解题链

- 指令寄存器 IR：CPU 内部取指状态，程序员不可直接访问；
- 微指令寄存器：微程序控制器内部状态，不属于 ISA；
- 基址寄存器：可被寻址方式/指令使用，属于体系结构可见状态；
- 标志状态寄存器：条件转移等指令依赖其标志，也属于可见状态。

故仅 III、IV 正确。

## 选项判断

选 $\boxed{D}$。

## Verification

“硬件里存在”不等于“程序员可见”；可见性的边界由 ISA 决定。

## Compression

```text
visible to assembly?
-> defined by ISA / affects instruction semantics
base register + flags yes
IR + microIR no
```

## 易错边界

不要把“CPU 寄存器”统称为程序员可见寄存器；很多寄存器只是实现细节。
