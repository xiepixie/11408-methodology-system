# 408-2021-Q40

## Model Anchor

- Topic：TCP 接收窗口与发送窗口边界。
- 题目信号：ACK=`501`、`rcvwnd=500 B`，此前已经发送 `seq=501` 的 200 B 数据。
- 第一动作：先由 ACK 和 rwnd 写出接收方当前允许的字节区间，再扣除已经在途的数据。

## 解题链

累计确认号 501 表示乙当前仍期待字节 501；通告窗口 500 B，因此允许的接收窗口为

$$[501,1000].$$

甲在 $t_0$ 已发送 200 B：

$$501\sim700.$$

且题设尚未收到新的确认，所以这些字节仍占用发送窗口。甲还能继续发送

$$701\sim1000.$$

共 300 B。

## 选项判断

故选 $\boxed{C}$。

## Verification

允许窗口总长度为 500 B；已占 200 B，再发送 300 B 恰好填满窗口。

## Compression

```text
ACK=501, rwnd=500
-> receive window [501,1000]
already sent [501,700]
-> can send [701,1000]
```

## 易错边界

ACK 是“下一个期望字节”，不是“最后确认字节”；发送窗口还要扣除未确认的在途数据。
