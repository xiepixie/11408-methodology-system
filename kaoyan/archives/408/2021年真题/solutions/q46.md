# 408-2021-Q46

## Model Anchor

- Topic：系统启动链与磁盘初始化生命周期。
- 题目信号：把 ROM、MBR、分区引导程序、OS 初始化程序以及物理/逻辑格式化混在同一题。
- 第一动作：分成两条生命周期：`boot execution chain` 与 `disk preparation chain`，不要把“启动时执行什么”和“制作启动盘时做什么”混在一起。

## Problem Representation

启动链的控制权逐级转移：

```text
firmware/ROM
-> disk MBR bootstrap
-> selected partition boot code
-> OS initialization
```

磁盘制作链则是从物理介质结构逐步建立到文件系统和 OS：

```text
physical sectors
-> partitions
-> filesystem structures
-> OS files
```

## Decision Points

1. 谁最先有执行权？上电后 CPU 只能从固化的 ROM/固件入口开始。
2. MBR 的任务是选择分区；分区引导程序才负责进一步引导该分区 OS。
3. “扇区划分”属于物理介质层；“根目录建立”属于文件系统层。

## Solution Chain

### (1) 启动程序执行顺序

上电后首先执行 ROM 中固化的引导程序；它装入并执行启动盘第一个扇区中的磁盘引导程序。磁盘引导程序依据分区表选择目标分区并装入该分区的引导程序，后者最终装载并转交控制权给 OS 初始化程序。

因此：

$$
\boxed{
\text{ROM 引导程序}
\to\text{磁盘引导程序}
\to\text{分区引导程序}
\to\text{OS 初始化程序}
}.
$$

### (2) 制作启动盘的操作顺序

先建立介质底层结构，再建立逻辑分区与文件系统，最后才能安装 OS：

$$
\boxed{
\text{物理格式化}
\to\text{磁盘分区}
\to\text{逻辑格式化}
\to\text{操作系统安装}
}.
$$

### (3) 两个结构分别在哪一步建立

- 磁盘扇区的物理划分：$\boxed{\text{物理格式化}}$；
- 文件系统根目录的建立：$\boxed{\text{逻辑格式化}}$。

逻辑格式化的本质是为某个分区建立文件系统所需的元数据结构、空闲空间管理和根目录等。

## Verification

依赖关系是单向的：没有扇区就无法可靠描述分区，没有分区就无从在目标区域建立文件系统，没有文件系统就不能按文件组织安装 OS。顺序与层次一致。

## Compression

```text
boot:
ROM -> MBR/disk boot -> partition boot -> OS init

make boot disk:
physical format -> partition -> logical format -> install OS

sector layout -> physical format
root directory -> logical format
```

## 易错边界

现代 UEFI/GPT/SSD 的真实实现与传统教材模型不同；本题已经明确给出 MBR、分区首扇区和多阶段引导，应严格按这一模型作答。
