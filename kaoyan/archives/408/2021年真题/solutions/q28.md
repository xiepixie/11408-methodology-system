# 408-2021-Q28

## Model Anchor

- Topic：缺页、固定页框与改进型 CLOCK。
- 题目信号：访问虚拟地址、页表存在/访问/修改位、2 个固定页框。
- 第一动作：先做地址拆分并判断是否缺页；**只有缺页且无空闲页框时才进入 replacement**。

## 解题链

页大小 4 KB，因此低 12 位为页内偏移：

$$02A01H\Rightarrow VPN=2,\ offset=A01H.$$

页 2 的存在位为 0，发生缺页。P 的两个页框当前由页 3、页 4 占用：

```text
page3: frame=60H, A=1, M=0
page4: frame=80H, A=1, M=1
```

改进型 CLOCK 优先寻找 `(A,M)=(0,0)`。首次扫描两页访问位都为 1，于是将 A 清零；下一轮页 3 成为 `(0,0)`，优先淘汰页 3。

新页 2 装入页框 `60H`，故物理地址为

$$\boxed{60A01H}.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

页内偏移在地址变换前后保持不变，仍为 `A01H`；改变的只有页框号。

## Compression

```text
02A01 -> VPN2 + A01
page2 absent -> fault
enhanced CLOCK: page3 (1,0), page4 (1,1)
clear A -> page3 first (0,0)
frame60 -> 60A01H
```

## 易错边界

不要一看到 CLOCK 就直接按环形顺序淘汰；改进型 CLOCK 还要结合访问位和修改位的类别优先级。
