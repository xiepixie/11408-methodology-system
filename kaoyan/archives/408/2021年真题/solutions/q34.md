# 408-2021-Q34

## Model Anchor

- Topic：差分曼彻斯特编码。
- 题目信号：给波形反推比特串。
- 第一动作：只看**每个码元起始边界是否发生跳变**；码元中点跳变是时钟特征，不用于区分 0/1。

## 解题链

采用本题约定：码元开始处发生跳变表示 0，不跳变表示 1。逐个观察波形边界，第 2～8 位可确定为

```text
0 1 1 1 0 0 1
```

第 1 位缺少前一码元末电平作为参照，单独无法由波形绝对电平确定；结合四个选项，唯一与后 7 位匹配的是

```text
10111001
```

## 选项判断

故选 $\boxed{A}$。

## Verification

差分曼彻斯特的信息由“是否跳变”承载，而不是高/低电平本身，因此整体反相不会改变译码结果。

## Compression

```text
Differential Manchester
-> check transition at bit boundary
-> suffix = 0111001
-> only A matches
```

## 易错边界

不要用普通曼彻斯特的“高到低/低到高代表 0/1”规则直接解差分曼彻斯特。
