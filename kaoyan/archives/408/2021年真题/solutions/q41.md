# 408-2021-Q41

## Model Anchor

- Topic：邻接矩阵、顶点度与欧拉路径存在性判定。
- 题目信号：题干已经给出 EL 路径存在的充要条件，输入图又保证无向、连通、$|E|>0$。
- 第一动作：不要真的构造路径；把目标压缩为**统计奇度顶点个数**。

## Problem Representation

无向图采用邻接矩阵 `Edge`：

$$\deg(v_i)=\sum_{j=0}^{n-1} Edge[i][j].$$

题目已经给出存在性不变量：

```text
oddDegreeCount ∈ {0, 2}
<=> 存在 EL 路径
```

因此算法只需扫描矩阵并维护一个计数器。

## Decision Points

1. 图已保证连通，不需要再额外跑 DFS/BFS 验证连通性。
2. 邻接矩阵的列数是 `numVertices`，不能把 `numEdges` 当成矩阵维数。
3. 只需判断奇偶性；一旦奇度顶点超过 2，可直接提前返回 0。

## Solution Chain

### (1) 基本思想

逐个顶点扫描其所在行，统计度数；若度为奇数则 `odd++`。扫描结束后：

- `odd==0`：存在欧拉回路，因此也存在满足题意的 EL 路径；
- `odd==2`：存在以两个奇度顶点为端点的欧拉路径；
- 其他情况：不存在。

### (2) C/C++ 描述

```c
int IsExistEL(MGraph G)
{
    int odd = 0;

    for (int i = 0; i < G.numVertices; ++i) {
        int degree = 0;

        for (int j = 0; j < G.numVertices; ++j)
            degree += G.Edge[i][j];

        if (degree % 2 != 0) {
            ++odd;
            if (odd > 2)
                return 0;
        }
    }

    return (odd == 0 || odd == 2) ? 1 : 0;
}
```

### (3) 复杂度

邻接矩阵需要检查至多 $|V|^2$ 个单元，因此

$$\boxed{T(n)=O(|V|^2)}.$$

只使用常数个辅助变量：

$$\boxed{S(n)=O(1)}.$$

## Verification

本算法与题干给出的存在性条件一一对应，没有引入额外充分条件。无向图邻接矩阵每一行的非零项数就是对应顶点的度，因此统计对象正确。

## Compression

```text
connected undirected graph
-> EL existence already reduced to odd-degree count
-> row sum = degree
-> odd count 0 or 2 => 1, otherwise 0
-> O(V^2), O(1)
```

## 易错边界

- Legacy 代码曾把内层循环上界写成 `numEdges`，这是对象维度错误；邻接矩阵是 `V×V`。
- 若题目没有保证连通，仅统计奇度顶点还不够，还必须检查所有有边顶点属于同一连通分量。
