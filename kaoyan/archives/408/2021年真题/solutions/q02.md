# 408-2021-Q02

## Model Anchor

- Topic：输出受限双端队列的可达出队序列。
- 题目信号：一端只能入队，另一端可入可出，本质是“输入可从两端进入，但输出端固定”。
- 第一动作：不要背排列结论；按目标出队序列反推每个新元素应放在输出端还是另一端，并检查是否存在合法状态演化。

## 解题链

固定右端为出队端。输入序列始终是 `1,2,3,4,5`，每个元素到来时可插到左端或右端，但只能从右端删除。

前三个选项都能构造出合法队列状态。例如 A 可在全部输入后形成：

```text
左 [2,1,3,4,5] 右
```

于是依次从右端得到 `5,4,3,1,2`。

对 D 做反推更直接。为了第一个输出 4，元素 4 必须从右端入队并立即成为右端元素。在 4 到来以前，为了让删除 4 后下一个右端元素恰好是 1，元素 1 必须先从右端进入，而随后到来的 2、3 都只能从左端进入，于是在 4 入队前队列只能形如

```text
左 [3,2,1] 右
```

4 从右端进入并输出后得到 `[3,2,1]`，再输出 1 后只剩 `[3,2]`，下一次右端出队**必然是 2**，不可能是题目要求的 3。即使此时 5 已经到来，它只能插在某一端，也无法把内部已有的 2、3 次序改成先 3 后 2。因此 D 不可实现。

## 选项判断

唯一不可得到的是

$$\boxed{D}.$$

## Verification

把问题视为状态搜索：状态只有“下一待输入元素 + 当前双端队列 + 下一待输出元素”。对 A/B/C 可找到完整路径，对 D 无合法路径。

## Compression

```text
output-restricted deque
-> enqueue both ends, dequeue one fixed end
-> simulate target output
-> D has no reachable state path
```

## 易错边界

这不是普通队列，也不是两端都可出队的完整 deque。必须先锁定“哪一端能出”，否则会把可达序列集合放大。
