# 408-2021-Q33

## Model Anchor

- Topic：TCP/IP 分层与功能 Owner。
- 题目信号：问传输层相邻的下一层负责什么。
- 第一动作：先定层级 Scope：TCP/IP 中传输层下面是网际层。

## 解题链

网际层的核心职责是 IP 分组转发和路由选择。

- 对话管理属于更高层语义；
- 端到端报文段传输是传输层；
- 结点到结点流量控制更接近数据链路层。

## 选项判断

故选 $\boxed{B}$。

## Verification

“下一层”不是“相邻结点链路层”，TCP/IP 四层模型中传输层直接下面是网际层。

## Compression

```text
TCP/IP transport
-> next lower = internet layer
-> routing / IP forwarding
```

## 易错边界

OSI 与 TCP/IP 层数不同；做题前先确认题目采用哪个模型，不能机械套层号。
