# 408-2021-Q26

## Model Anchor

- Topic：SSTF 磁盘调度。
- 题目信号：给当前磁道和按到达顺序的请求，要求磁头总移动距离。
- 第一动作：每一步都从**当前磁头位置**重新选择最近的未服务请求。

## 解题链

初始在 184，待服务 `184,187,176,182,199`：

```text
184 -> 184 : 0
184 -> 182 : 2
182 -> 187 : 5
187 -> 176 : 11
176 -> 199 : 23
```

总移动距离

$$0+2+5+11+23=41.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

在 182 时，187 距离 5，比 176 的 6 更近；这一处若选错，后续总距离会整体改变。

## Compression

```text
SSTF -> nearest from current head each step
184→184→182→187→176→199
move = 41 tracks
```

## 易错边界

SSTF 不是把请求按磁道号排序，也不是按原到达顺序执行；每完成一个请求都要重算最近项。
