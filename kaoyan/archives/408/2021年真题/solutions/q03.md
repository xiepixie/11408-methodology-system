# 408-2021-Q03

## Model Anchor

- Topic：二维数组行优先地址映射。
- 题目信号：给出两个元素地址，要求推出另一个元素地址。
- 第一动作：先设每行列数为 $m$，把地址差写成线性下标差。

## 解题链

行优先且每个元素占 1 个存储单元：

$$\operatorname{addr}(A[i][j])=100+i\,m+j.$$

由 $A[3][3]$ 地址为 220：

$$3m+3=220-100=120\Rightarrow m=39.$$

因此

$$\operatorname{addr}(A[5][5])=100+5\times39+5=300.$$

## 选项判断

故选 $\boxed{B}$。

## Verification

回代 $m=39$：$100+3\times39+3=220$，与题设一致。

## Compression

```text
row-major -> base + i*cols + j
3m+3=120 -> m=39
A[5][5] -> 300
```

## 易错边界

不要把下标差直接当地址差；二维数组必须先恢复“每行多少列”这一表示参数。
