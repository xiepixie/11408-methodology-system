# q01_数据结构

## 📋 题目要求 (题面)

求整数
 $n(n\ge 0)$
 阶乘的算法如下，其时间复杂度是（ ）。

```c
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```

- **A.** $O(log_{2}$
- **B.** $O(n)$
- **C.** $O(nlog_{2}$
- **D.** $O(n_{2}$

---

## 💡 答案与深度解析

**【正确答案】**：`B`

**正确答案：B**

本算法是一个递归运算，即算法中出现了调用自身的情形。递归的边界条件是
 $\le 1$
，每调用一次 fact()，传入该层 fact() 的参数值减 1。采用递归式来表示时间复杂度有

 $Tn$ ={O(1),n≤1 T(n−1)+1,n>1
