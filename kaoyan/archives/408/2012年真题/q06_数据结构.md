# q06_数据结构

## 📋 题目要求 (题面)

若用邻接矩阵存储有向图，矩阵中主对角线以下的元素均为零，则关于该图拓扑序列的结论是（ ）。

- **A.** 存在，且唯一
- **B.** 存在，且不唯一
- **C.** 存在，可能不唯一
- **D.** 无法确定是否存在

---

## 💡 答案与深度解析

**【正确答案】**：`C`

**正确答案：C**

对角线以下元素均为零，表明只有顶点
 $i$
到顶点
 $j$
(
 $i<j$
) 可能有边，而顶点
 $j$
到顶点
 $i$
一定没有边，即有向图是一个无环图，因此一定存在拓扑序列。对于拓扑序列是否唯一，试举一例：设有向图的邻接矩阵

  0 0 0100100
