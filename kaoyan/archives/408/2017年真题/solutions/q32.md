# 408-2017-Q32

## 模型锚点

- Topic：DMA I/O 生命周期。
- 题目信号：四个动作分别属于 CPU setup、DMA transfer、completion interrupt、ISR。
- 第一动作：按 Ownership handoff 排序：CPU 先配置并授权 DMA，DMA 完成数据搬运后再用中断把控制事件交还 CPU。

## 解题链

正确事件链为：

```text
② 初始化 DMA 控制器并启动磁盘
-> ③ DMA 把一块数据从磁盘传到内存缓冲区
-> ① DMA 控制器发出完成中断请求
-> ④ CPU 执行“DMA 结束”中断服务程序
```

初始化之前 DMA 不知道源/目的、长度等参数；数据尚未完成时也不应先发“结束”中断。

## 选项判断

因此顺序为 `②→③→①→④`，选 $\boxed{B}$。

## 校验

把每一步的 Owner 标出：CPU/驱动负责②，DMA 控制器负责③和触发①，CPU/OS 再负责④，控制权交接方向单调且闭合。

## 压缩

```text
CPU setup -> DMA data movement -> completion interrupt -> ISR cleanup
```

## 易错边界

DMA 减少的是 CPU 对“逐字/逐字节数据搬运”的参与，不代表 CPU 不需要预处理、后处理和完成中断。
