# 408-2017-Q15

## 模型锚点

- Topic：有效地址生成与数组访问模式。
- 题目信号：按下标顺序访问一维数组。
- 第一动作：把目标地址写成 `base + index × element_size`，再找哪种寻址方式把“基址 + 可变下标”作为原生机制。

## 解题链

顺序访问数组时，数组首地址基本不变，而下标随循环改变。变址寻址正是让有效地址由固定基准地址与变址寄存器内容组合得到，便于在循环中只更新 index。

相对寻址通常服务于 PC 相对目标；寄存器寻址不访问数组内存；直接寻址适合固定地址而非连续变化的下标。

## 选项判断

故选 $\boxed{D}$：变址寻址。

## 校验

对 `A[i]`，核心地址公式就是

$$
EA=base(A)+i\times sizeof(A[0]),
$$

其中唯一持续变化的状态是 $i$，与变址寄存器角色完全一致。

## 压缩

```text
array[index] -> fixed base + changing index -> indexed addressing
```

## 易错边界

“相对寻址”也包含加法，但其典型基准是 PC；判断寻址方式要看哪个对象拥有基准地址与变化量。
