# 408-2017-Q04

## 模型锚点

- Topic：二叉树遍历序列与结构约束。
- 题目信号：要求先序与中序完全相同。
- 第一动作：比较两种遍历中“根何时出现”，从根的位置反推左右子树能否存在。

## 解题链

先序是 `根 -> 左 -> 右`，所以任何子树的根一定最先出现；中序是 `左 -> 根 -> 右`。若两者在该子树上的序列要相同，则中序中根前面不能出现任何结点，因此该结点的左子树必须为空。

这个条件必须递归地对每个非叶结点成立，所以整棵树只能沿右孩子方向延伸，即每个非叶结点都只有右子树。

## 选项判断

故选 $\boxed{B}$。A 会使中序先访问左子树；C 允许“只有左孩子”的结点，条件过宽；D 更不可能使根在中序中最先出现。

## 校验

最小反例：根 `r` 只有左孩子 `x` 时，先序=`r,x`，中序=`x,r`，立即不同；只有右孩子时二者都是 `r,x`。

## 压缩

```text
pre 根最先，in 根在左子树之后 -> 要相同 => 每层 left 必为空
```

## 易错边界

题目要求的是“所有非叶结点”的递归结构条件，不能只检查根结点。
