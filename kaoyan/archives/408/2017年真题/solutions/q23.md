# 408-2017-Q23

## 模型锚点

- Topic：作业调度的候选集合与策略选择。
- 题目信号：调度在 $t=2$ 才发生，而作业到达时刻不同。
- 第一动作：先按时间建立“此刻已经到达”的 eligible set，再在同一个集合上分别应用 FCFS/SJF；不能把尚未到达的 $J_4$ 拿来比较。

## 解题链

在 $t=2$ 时已经到达的是：

```text
J1: arrival 0, run 3
J2: arrival 1, run 3
J3: arrival 1, run 2
```

$J_4$ 到 $t=3$ 才到达，不属于当前候选集。

FCFS 比较到达先后，最早的是 $J_1$；SJF 在已到达作业中比较运行时间，$J_3$ 的 2 最短，因此选择 $J_3$。

## 选项判断

组合为 `$J_1、J_3`，故选 $\boxed{D}$。

## 校验

任何在 $t=2$ 选择 $J_4$ 的方案都违反“先到达才能参与调度”的资格约束，可立即排除 B/C 中涉及 $J_4$ 的错误推理。

## 压缩

```text
time t -> build eligible set(arrival<=t) -> apply scheduling policy only inside set
```

## 易错边界

调度策略解决“候选者中选谁”，到达时间先决定“谁有资格成为候选者”；这是两个不同 Gate。
