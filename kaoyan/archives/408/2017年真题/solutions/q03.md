# 408-2017-Q03

## Model Anchor

- Topic：稀疏矩阵的压缩表示。
- 题目信号：题目问的是“只保存非零元并保留其行列关系”的专用结构。
- 第一动作：先问 Representation 是否随非零元个数增长，而不是随整个 $m\times n$ 矩阵增长。

## 解题链

三元组表把每个非零元表示成 `(row, col, value)`，空间与非零元数相关；十字链表进一步把同一行、同一列的非零元通过链连接，适合稀疏矩阵插入、删除与按行列遍历。

邻接矩阵面向图，仍是二维稠密表；二叉链表面向树，不承担矩阵行列坐标语义。

## 选项判断

故选 $\boxed{A}$：三元组表和十字链表。

## Verification

若一个 $10^6\times10^6$ 矩阵仅有 100 个非零元，真正的压缩表示应能把主要存储量压到 $O(100)$，三元组表和十字链表符合这一目标。

## Compression

```text
稀疏 -> 只为 nonzero 建对象 -> 坐标+值 / 行列双链
```

## 易错边界

“矩阵形式的数据结构”不等于“稀疏矩阵压缩结构”；邻接矩阵本质上仍为稠密存储。
