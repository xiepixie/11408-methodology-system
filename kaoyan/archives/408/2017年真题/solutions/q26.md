# 408-2017-Q26

## Model Anchor

- Topic：文件逻辑长度与簇分配粒度。
- 题目信号：文件 1026 B，而文件系统按 1 KB 簇分配空间。
- 第一动作：把“实际字节数”投影到分配单位：$\lceil file\_size/cluster\_size\rceil$，不要按扇区直接四舍五入。

## 解题链

1 KB = 1024 B。1026 B 已超过一个簇，因此需要

$$
\left\lceil\frac{1026}{1024}\right\rceil=2
$$

个簇。每簇 1024 B，所以实际分配磁盘空间为

$$
2\times1024=2048\text{ B}.
$$

虽然一个簇由两个 512 B 扇区组成，但文件分配的最小 Owner 是“簇”，不能只额外分配一个扇区。

## 选项判断

故选 $\boxed{D}$。

## Verification

一个簇最多容纳 1024 B，显然装不下 1026 B；两个簇容量 2048 B 足够，因此答案只能是 2048 B。

## Compression

```text
logical file size -> ceil by allocation unit(cluster) -> allocated disk space
```

## 易错边界

磁盘物理扇区是更底层单位；文件系统若规定以簇分配，则内部碎片也必须按簇计算。
