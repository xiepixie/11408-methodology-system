# 408-2017-Q17

## 模型锚点

- Topic：超标量的并行发射与动态调度。
- 题目信号：三个描述分别涉及“单段延迟、每周期发射数、指令级并行”。
- 第一动作：区分 latency 与 throughput：超标量主要提高同一周期可处理的指令数，不会自动缩短某个功能段自身的组合逻辑延迟。

## 解题链

II 正确：超标量处理器的核心特征之一就是每个时钟周期可发射多条指令。

III 正确：结合动态调度、乱序执行等技术，可在满足相关约束下挖掘更多指令级并行性。

I 错：增加并行功能部件并不等价于缩短某个流水段的处理时间；段延迟由该段关键路径等决定。

## 选项判断

故选 $\boxed{C}$：仅 II、III。

## 校验

若一个 ALU 操作本来需要 1 个周期，复制两套 ALU 可以同周期做两个独立操作，但单个操作的 latency 仍可保持 1 个周期；提升的是吞吐率而非必然降低延迟。

## 压缩

```text
superscalar -> multiple issue per cycle -> higher ILP throughput; not automatically shorter stage latency
```

## 易错边界

“更宽”与“更深/更快”是不同维度；超标量解决宽度，流水段缩短属于时钟周期/流水深度问题。
