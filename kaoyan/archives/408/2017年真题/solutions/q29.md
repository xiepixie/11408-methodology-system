# 408-2017-Q29

## Model Anchor

- Topic：磁盘初始化层次：分区、物理格式化、逻辑格式化。
- 题目信号：问“逻辑格式化程序做什么”，四个动作分属不同层次。
- 第一动作：给每个动作找 Owner：磁盘分区表、扇区物理格式、文件系统元数据分别由谁建立。

## 解题链

II 正确：逻辑格式化是在一个分区上建立文件系统，需要创建根目录等初始文件系统结构。

IV 正确：位图、空闲块链等空闲空间管理结构属于文件系统元数据，逻辑格式化时必须初始化。

I 错：磁盘分区是在建立具体文件系统之前进行的分区管理步骤，不属于该分区的逻辑格式化。

III 错：扇区校验码等属于更底层的物理格式化/磁盘控制层信息，不由文件系统逻辑格式化决定。

## 选项判断

故仅 II、IV 正确，选 $\boxed{B}$。

## Verification

把逻辑格式化理解成“让一个已有分区从原始块集合变成可挂载文件系统”，它必须生成目录和 free-space metadata，却不需要重新定义扇区物理记录格式。

## Compression

```text
partition exists -> logical format -> filesystem root + free-space metadata
```

## 易错边界

“格式化”是多层术语；物理格式化处理扇区层，逻辑格式化处理文件系统层，不能混用。
