# 408-2017-Q19

## 模型锚点

- Topic：流水线数据通路与控制通路的边界。
- 题目信号：问“数据通路”包含什么，而不是问整个处理器包含什么。
- 第一动作：给部件按职责分层：谁真正承载/变换数据，谁只生成控制信号。

## 解题链

ALU、通用寄存器组、取指相关部件以及连接它们的组合/时序部件都属于数据在流水线中流动和暂存的路径，因此 B、C、D 可以归入数据通路。

生成控制信号的控制部件负责决定多路选择、写使能、ALU 操作等，它属于控制通路/控制器，而不是数据通路本体。

## 选项判断

错误的是 A，故选 $\boxed{A}$。

## 校验

把控制器移除后，数据通路部件仍是“寄存器—ALU—存储器—流水寄存器”这张网络，只是失去正确驱动；这说明控制器控制数据通路，但不等于数据通路的一部分。

## 压缩

```text
data path = carry/store/transform values
control path = generate enable/select/op signals
```

## 易错边界

“处理器中存在某部件”不代表“该部件属于数据通路”；题目考的是职责边界。
