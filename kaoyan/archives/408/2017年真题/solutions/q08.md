# 408-2017-Q08

## 模型锚点

- Topic：折半查找判定树的递归区间结构。
- 题目信号：不是问“是不是二叉排序树”，而是问能否由折半查找的取中点过程生成。
- 第一动作：先给结点按中序赋上有序关键字，再递归检查每个根是否可能是当前有序区间的中点。

## 解题链

折半查找判定树首先是二叉排序树，但约束更强：每个结点都对应某个连续有序区间，左右子树分别来自中点左、右两段，因此子树规模必须符合不断“近似对半切分”的结果。

对题图四棵候选树按中序赋序号并逐层检查，只有 A 的根及其左右子树都能递归对应某次折半区间的中点选择；B、C、D 均在某个子区间出现无法由取中点产生的规模/位置关系。

## 选项判断

故选 $\boxed{A}$。

## 校验

判断树可行性必须同时通过两个 Gate：

```text
中序有序（BST）
AND
每个子树可由连续区间的 mid 递归生成
```

只满足第一个 Gate 的树仍可能不是折半查找判定树。

## 压缩

```text
candidate tree -> inorder label -> recursive interval split -> check root == possible mid
```

## 易错边界

“折半查找判定树是 BST”只是必要条件，不是充分条件；真正额外约束来自每次查找都选择当前区间中点。
