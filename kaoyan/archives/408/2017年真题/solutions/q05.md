# 408-2017-Q05

## Model Anchor

- Topic：已知树形 + 后序序列恢复结点身份。
- 题目信号：树形固定、结点标签未知，但给出完整后序序列。
- 第一动作：先按图形只写“左-右-根”的访问槽位，再把后序序列依次填回这些槽位；不要凭字母大小猜层次。

## 解题链

后序遍历严格遵循 `left -> right -> root`。结合题图的固定树形，自底向上填入序列

```text
e, a, c, b, d, g, f
```

可确定根为 `f`；左侧对应子树中的 `a` 与右侧对应子树中的 `d` 占据相同深度的结构位置，因此 `a` 与 `d` 同层。

## 选项判断

故选 $\boxed{B}$，与 `a` 同层的是 `d`。`c、g` 是相邻的上层内部结点，`f` 为根。

## Verification

把恢复出的标签按后序再读一遍，必须重新得到 `e,a,c,b,d,g,f`；若把 `c/g/f` 视为与 `a` 同层，会破坏题图给定的父子层级。

## Compression

```text
树形已知 + 遍历序列已知 -> 先建遍历槽位 -> 再按序列填标签 -> 读取目标层级
```

## 易错边界

这里只能由“树形 + 后序”联合恢复；单独一个后序序列不能唯一确定一般二叉树。
