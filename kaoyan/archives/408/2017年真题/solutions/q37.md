# 408-2017-Q37

## Model Anchor

- Topic：路由协议与直接下层协议的封装关系。
- 题目信号：问 RIP、OSPF、BGP 报文“直接封装”在哪个协议中。
- 第一动作：逐个找 Transport Owner：它需要可靠连接、无连接传输，还是自己就是 IP 上层协议；不要因为三者都叫路由协议就强行统一。

## 解题链

- RIP 使用 UDP，典型端口 520；
- OSPF 不经 TCP/UDP，直接封装在 IP 中，IP 协议号为 89；
- BGP 需要可靠的长期邻居会话，使用 TCP，端口 179。

因此顺序是：

```text
RIP  -> UDP
OSPF -> IP
BGP  -> TCP
```

## 选项判断

故选 $\boxed{D}$。

## Verification

BGP 要交换持续增长的路由信息并维护邻居会话，可靠字节流非常契合 TCP；OSPF 本身已有自己的可靠泛洪/序号机制，因此直接位于 IP 上，这两个机制特征可帮助反向记忆。

## Compression

```text
RIP=UDP, OSPF=IP protocol 89, BGP=TCP/179
```

## 易错边界

“应用层/网络层路由协议”的课程分类不等于其报文一定通过同一种传输层协议封装；题目问的是实际协议栈下一层。
