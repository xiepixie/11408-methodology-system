# 408-2017-Q18

## 模型锚点

- Topic：主存与控制存储器的 Owner / Access Contract。
- 题目信号：四个选项分别比较位置、访问方式、保存对象和实现介质。
- 第一动作：先明确 MM 保存程序可见的指令/数据，CS 保存控制器内部微指令；再判断两者如何寻址。

## 解题链

A 正确：典型微程序控制器中，控制存储器位于 CPU 控制器内部，主存位于 CPU 外部存储系统。

C 正确：MM 保存机器指令和数据；CS 保存微程序/微指令。

D 在本题教材模型下成立：主存可由 RAM/ROM 构成，控制存储器传统上可用 ROM 实现。

B 错：控制存储器同样由微地址寄存器等按地址访问，并不是“按内容访问”。按内容访问对应相联存储器的语义。

## 选项判断

故选 $\boxed{B}$。

## 校验

只要存在“下一微地址”字段/形成逻辑，就说明 CS 需要根据微地址取下一条微指令，这本身就是按地址访问。

## 压缩

```text
MM owner = program instruction/data
CS owner = microinstructions
both are addressed storage; CAM才是按内容访问
```

## 易错边界

“控制存储器”中的“控制”描述其内容用途，不表示它采用内容寻址。
