# 408-2017-Q36

## Model Anchor

- Topic：IPv4 特殊地址的 Source/Destination 合法性。
- 题目信号：要求“只能作为源地址、不能作为目的地址”。
- 第一动作：不要按数值形状猜；逐个问这个特殊地址的 Scope 和用途是谁拥有。

## 解题链

`0.0.0.0` 表示“本主机、本网络上尚未确定的地址”，主机在尚未获得正式 IP 地址的特定初始化阶段可以把它作为源地址使用，但不能把普通 IP 分组以 `0.0.0.0` 作为目标主机地址发送。

`127.0.0.1` 是环回地址，可作为本机协议栈通信的目的地址；普通单播 `200.10.10.3` 可作正常目的地址；`255.255.255.255` 是受限广播地址，典型角色正是目的地址而不是源地址。

## 选项判断

故选 $\boxed{A}$。

## Verification

DHCP 客户端尚无地址时发送发现报文就是典型例子：源可为 `0.0.0.0`，目的使用广播地址；两者角色刚好相反。

## Compression

```text
special IP -> identify scope/role -> unspecified address may source before configuration; limited broadcast is destination
```

## 易错边界

`0.0.0.0` 作为“默认路由前缀”时是路由表语义；本题问的是 IP 分组首部中的源/目的地址语义，Scope 不同。
