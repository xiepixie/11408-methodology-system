# 408-2017-Q44

## Model Anchor

- Topic：ISA 风格识别、Instruction Boundary、减法标志位与数据表示路径。
- 题目信号：同一段机器代码同时给虚拟地址、变长字节串、`cmp`、`shl`，四问分别攻击指令编码、地址跨度、ALU flags 和整数/浮点表示边界。
- 第一动作：每一问先找到真正的 Owner：指令长度由编码字节拥有，CF 由无符号减法借位拥有，`shl` 的语义由“位串按整数整体移位”拥有。

## Problem Representation

把题目拆成四个互不混淆的状态层：

```text
ISA encoding       -> 指令是否定长/变长
Instruction range  -> [first address, end address]
ALU subtraction    -> result + CF(borrow)
Data representation-> integer bits vs IEEE754 fields
```

共同点是：**先解释位串属于哪一种对象，再做运算**。

## Decision Points

### 1. 为什么用“指令长度不等”识别 CISC？

题图中 `push ebp` 只有 1 B，而 `cmp dword ptr [ebp-0Ch],ecx` 为 3 B，说明机器指令长度不是统一定长。这与典型 CISC（如 x86）的变长编码特征一致。

### 2. 代码长度为什么不能只做 `last-first`？

地址差给的是最后一条指令**起始地址**到第一条起始地址的距离。最后的 `ret` 自己仍占 1 B，因此必须计算半开区间终点或加上最后指令长度。

### 3. CF 为什么看借位而不是 signed overflow？

`cmp a,b` 本质做 `a-b` 而不保存结果。CF 服务无符号大小/借位关系；OF 才服务有符号溢出。题目问 CF，就必须按无符号减法资源解释。

## Solution Chain

### (1) M 是 RISC 还是 CISC？

是：

$$
\boxed{\text{CISC}}.
$$

最直接证据是机器指令长度可变：

```text
push ebp                  -> 1 B
cmp dword ptr [...], ecx  -> 3 B
shl edx,1                 -> 2 B
ret                       -> 1 B
```

变长编码、允许指令直接含内存操作数等都符合典型 CISC 特征。

### (2) f1 机器代码共多少字节？

第一条指令起始地址：

```text
00401020H
```

最后一条 `ret` 起始地址：

```text
0040107FH
```

`ret` 机器码 `C3` 占 1 B，所以代码覆盖到 `0040107FH` 这一字节为止：

$$
0040107F_H-00401020_H+1
=60_H
=\boxed{96\text{ B}}.
$$

### (3) f1(0)、i=0 时 `cmp` 后 CF

题 43 已知：

```text
n = 0
n - 1 as unsigned = FFFFFFFFH
 i = 0             = 00000000H
```

`cmp i,n-1` 执行的是：

$$
00000000_H-FFFFFFFF_H.
$$

按 32 位结果得到 `00000001H`，但无符号意义下 $0<2^{32}-1$，减法需要向高位借位，因此：

$$
\boxed{CF=1}.
$$

也可以从加法器角度写成：

$$
A-B=A+\overline B+1
=00000000_H+00000000_H+1,
$$

最高位无进位输出，而 x86 减法 CF 表示 borrow，故 CF=1。

### (4) f2 中能否用 `shl` 做 `power*2`？

不能直接沿用整数 `shl`。

对整数，左移一位在不溢出的前提下对应数值乘 2，因为位权整体提升一位。

但 IEEE 754 `float` 的 32 位布局是：

```text
sign | exponent | fraction
```

它不是一个按整数位权解释的 32 位二进制整数。对整个位串执行 `shl` 会同时移动/破坏符号位、阶码和尾数字段，结果一般完全不是“浮点值乘 2”。浮点乘 2 应由浮点运算单元按 IEEE 754 规则调整指数并处理规格化、舍入、异常等状态。

因此：

$$
\boxed{f2\text{ 不能用该整数 }shl\text{ 指令直接实现 }power\times2}.
$$

## Verification

独立检查四问：

1. **Instruction Boundary**：`0x107F-0x1020=0x5F`，再包含最后 1 B，得到 `0x60=96`，没有 off-by-one。
2. **CF sanity check**：无符号 $0-0xFFFFFFFF$ 显然需要借位，所以 CF 必为 1，不依赖具体加法器写法。
3. **Representation check**：float `1.0` 的机器码 `3F800000H` 若整体左移会变成 `7F000000H`，显然不是 `2.0` 的 `40000000H`，直接构成反例。

## Compression

```text
variable instruction bytes -> CISC
first addr + last instruction length -> code size
cmp -> subtraction -> CF = unsigned borrow
integer shl semantics != IEEE754 multiply semantics
```

## 易错边界

1. `CF` 与 `OF` 分别服务无符号借位/进位与有符号溢出，不能混用。
2. “左移乘 2”成立的前提是位串按整数位权解释且结果未发生不允许的溢出；浮点编码不是这种表示。
3. 地址区间长度计算必须明确末条指令的长度，不能把两个起始地址简单相减当成总字节数。
