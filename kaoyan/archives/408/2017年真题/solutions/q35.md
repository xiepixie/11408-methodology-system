# 408-2017-Q35

## Model Anchor

- Topic：802.11 基础设施模式的三地址语义。
- 题目信号：无线主机 H 通过 AP 访问 Internet，帧方向是 STA → DS。
- 第一动作：先确定这一 hop 的 `Receiver/Transmitter`，再区分端到端/DS 侧目的地址；不要把 Address1/2/3 当成固定“源/目的/第三个地址”背诵。

## 解题链

H 向分布系统发送数据时，`To DS=1, From DS=0`：

```text
Address1 = RA/BSSID = AP MAC = ...9b
Address2 = TA/SA     = H MAC  = ...9a
Address3 = DA        = DS侧下一跳/目的 MAC = ...9c
```

因此三地址依次是 `9b, 9a, 9c`。

## 选项判断

故选 $\boxed{B}$。

## Verification

无线介质上真正接收 H 发出的帧的是 AP，所以 Address1 必须是 AP；真正发射无线帧的是 H，所以 Address2 必须是 H。仅这两个物理事实就能先排除 A/C/D。

## Compression

```text
STA -> AP -> DS
Addr1 = receiver AP
Addr2 = transmitter STA
Addr3 = DS-side destination
```

## 易错边界

802.11 的地址字段由 ToDS/FromDS 决定语义；不能把以太网“源 MAC/目的 MAC”二字段模型直接套进无线三地址帧。
