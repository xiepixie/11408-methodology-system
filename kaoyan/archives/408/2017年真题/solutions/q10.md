# 408-2017-Q10

## Model Anchor

- Topic：排序算法选择的 Cost Model。
- 题目信号：不是比较“谁绝对更好”，而是问选择归并而非插入的可能理由。
- 第一动作：分别比较时间、额外空间和实现性质，拒绝把某一维优势扩展成全面优势。

## 解题链

III 正确：归并排序稳定保持 $O(n\log n)$，而直接插入排序平均/最坏为 $O(n^2)$；数据规模较大且无特殊近乎有序条件时，归并通常更快。

II 错：典型数组归并排序需要 $O(n)$ 辅助空间，而直接插入只需 $O(1)$。

I 也不是选择归并的普遍理由；归并需要递归/分治与合并逻辑，代码并不天然比插入排序更短。

## 选项判断

只有 III 成立，因此选 $\boxed{B}$。

## Verification

当 $n$ 扩大 10 倍时，$n^2$ 级工作量约扩大 100 倍，而 $n\log n$ 远小于此；空间方向则恰恰是插入更省。

## Compression

```text
algorithm choice -> compare time / space / input condition separately -> only claim the dimension actually improved
```

## 易错边界

插入排序在“小规模或基本有序”数据上可能非常有竞争力；本题只问“可能的理由”，不是宣布归并永远更快。
