# 408-2017-Q21

## Model Anchor

- Topic：I/O 指令的数据传送端点。
- 题目信号：问 I/O 指令“通常发生在哪两个对象之间”。
- 第一动作：先分清设备本体、I/O 接口中的端口寄存器和 CPU 通用寄存器三个层次。

## 解题链

CPU 执行 I/O 指令时，直接可寻址/读写的是 I/O 接口中的端口寄存器，而不是直接操纵外设内部物理装置。典型输入指令把 I/O 端口数据送入 CPU 寄存器，输出指令则把 CPU 寄存器数据写到 I/O 端口。

因此数据传送发生在“通用寄存器 ↔ I/O 端口”之间。

## 选项判断

故选 $\boxed{D}$。A 属于设备与接口内部的数据交换；B 把接口层省掉了；C 不符合普通 I/O 指令的数据路径。

## Verification

采用独立编址 I/O 时，`IN/OUT` 一类指令的显式操作对象就是 CPU 寄存器和端口地址，正好验证这一端点关系。

## Compression

```text
CPU instruction visible endpoint -> GPR <-> I/O port; device sits behind controller/interface
```

## 易错边界

“CPU 与设备交换数据”是系统级描述；落实到 I/O 指令的数据通路时，中间 Owner 是 I/O 端口寄存器。
