# 408-2017-Q20

## 模型锚点

- Topic：多总线层次与串/并行链路。
- 题目信号：四个描述混合总线层次、突发传输、桥接器和 PCIe 物理传输方式。
- 第一动作：逐个把名词映射到真实机制，尤其不要被 `×16` 误导成“16 位并行总线”。

## 解题链

A 正确：层次总线中靠近 CPU/内存的高性能总线通常速度更高。

B 正确：存储器总线可利用突发方式连续传送一个块，提高有效带宽。

C 正确：不同层次/协议的总线之间需要桥接器完成连接与转换。

D 错：PCI Express 是高速串行、点到点链路；`×16` 表示 16 条 lane 并行聚合带宽，每条 lane 本身是串行差分链路，并不是传统意义的并行总线传输。

## 选项判断

故选 $\boxed{D}$。

## 校验

PCIe 的 `×1/×4/×8/×16` 是 lane 数量而非单次并行传输的数据位宽；这与 PCI 的共享并行总线结构不同。

## 压缩

```text
PCIe xN -> N serial lanes -> aggregate bandwidth; not a parallel bus
```

## 易错边界

“多条串行 lane 同时工作”可以形成并行吞吐，但协议/物理层仍属于串行链路体系，不能据此称为并行总线。
