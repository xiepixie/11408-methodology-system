# 408-2017-Q38

## Model Anchor

- Topic：等长子网划分与 CIDR 主机容量。
- 题目信号：`/16` 网络平均划成 128 个子网。
- 第一动作：先把“子网数量”转成借位数，再重新确定 host bits；最后才扣网络地址和广播地址。

## 解题链

128=$2^7$，因此从原 `/16` 的主机位中借 7 位作为子网位，新前缀长度为

$$
16+7=23.
$$

每个 `/23` 子网还剩

$$
32-23=9
$$

位主机号，共 $2^9=512$ 个地址。普通 IPv4 子网中网络地址和广播地址不可分配给主机，因此最大可分配地址数为

$$
512-2=510.
$$

## 选项判断

故选 $\boxed{C}$。

## Verification

128 个子网 × 每子网 512 个地址 = 65536，正好等于原 `/16` 的 $2^{16}$ 个地址，地址空间守恒。

## Compression

```text
subnet count 2^s -> prefix += s -> host bits -> 2^h - 2
```

## 易错边界

题目问“可分配 IP 地址数”，不是子网总地址数；因此这里要扣掉网络地址和定向广播地址。
