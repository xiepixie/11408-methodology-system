# 408-2017-Q14

## 模型锚点

- Topic：访问轨迹与时间/空间局部性。
- 题目信号：嵌套循环反复访问数组前缀 `a[0..i]`。
- 第一动作：把源码翻译成地址访问序列，再分别问“近期地址会不会再次访问”和“相邻地址会不会连续访问”。

## 解题链

内层循环每次按 `a[0],a[1],...,a[i]` 顺序访问，连续数组元素地址相邻，因此具有空间局部性。

随着外层 `i` 增大，`a[0],a[1]...` 会在后续多轮内层循环再次被访问，例如 `a[0]` 几乎每轮都访问，因此也具有明显时间局部性。

## 选项判断

两种局部性都有，故选 $\boxed{A}$。

## 校验

只看 `a[0]`：它被重复访问 10 次，验证时间局部性；只看同一轮 `a[j] -> a[j+1]`，验证空间局部性。

## 压缩

```text
source code -> address trace -> repeated recent address = temporal; nearby sequential address = spatial
```

## 易错边界

“循环”本身不自动意味着时间局部性；必须确认循环是否真的再次访问同一数据对象。
