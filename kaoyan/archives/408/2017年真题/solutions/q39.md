# 408-2017-Q39

## Model Anchor

- Topic：TCP 有效发送窗口与慢启动增长。
- 题目信号：MSS=1 KB、RTT=5 ms、接收缓存 64 KB，目标发送窗口 32 KB。
- 第一动作：先写 $send\_wnd=\min(cwnd,rwnd)$，判断谁是当前瓶颈；再按 RTT 轮次推进拥塞窗口。

## 解题链

接收窗口上限为 64 KB，因此在达到 32 KB 之前 `rwnd` 不构成约束。按题目采用的慢启动模型，连接建立成功时 `cwnd=1 MSS=1 KB`，每经过一个 RTT 收到这一窗口数据的确认后，窗口约翻倍：

```text
start : 1 KB
1 RTT : 2 KB
2 RTT : 4 KB
3 RTT : 8 KB
4 RTT : 16 KB
5 RTT : 32 KB
```

因此至少需要 $5\times5\text{ ms}=25\text{ ms}$。

## 选项判断

故选 $\boxed{A}$。

## Verification

32 KB = $2^5$ KB，从 1 KB 出发需要 5 次翻倍；64 KB 接收缓存始终大于等于这些中间窗口，所以没有提前截断增长。

## Compression

```text
effective window=min(cwnd,rwnd) -> rwnd not binding -> count slow-start doublings -> RTT × rounds
```

## 易错边界

先确认题目的初始 `cwnd` 口径。408 这道题采用经典 `1 MSS` 起步；不能把不同年代实现中的较大初始窗口规则无条件带入。
