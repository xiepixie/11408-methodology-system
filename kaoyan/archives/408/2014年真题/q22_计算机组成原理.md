# q22_计算机组成原理

## 📋 题目要求 (题面)

若某设备中断请求的响应和处理时间为 100ns，每 400ns 发出一次中断请求，中断响应所允许的最长延迟时间为 50ns，则在该设备持续工作过程中，CPU 用于该设备的 I/O 时间占整个 CPU 时间的百分比至少是（ ）。

- **A.** 12.5%
- **B.** 25%
- **C.** 37.5%
- **D.** 50%

---

## 💡 答案与深度解析

**【正确答案】**：`B`

**正确答案：B**
每 400ns 发出一次中断请求，而响应和处理时间为 100ns，其中允许的延迟为干扰信息，因为在 50ns 内，无论怎么延迟，每 400ns 还是要花费 100ns 处理中断的，所以该设备的 I/O 时间占整个 CPU 时间的百分比为 100ns/400ns = 25%，选 B。
