# 408-2014-Q16

> 原题：[[../2014 年全国硕士研究生招生考试#16|Q16]]

## Model Anchor

- Topic：CO04/CO06｜Harvard-like split I/D Cache 与流水线结构冒险。
- 题目信号：问“指令 Cache 与数据 Cache 分离的主要目的”。
- 第一动作：先找共享资源冲突：取指和数据访存可能同周期发生；若共用一个 Cache 端口，就会争抢同一资源。

## 解题链

流水线中，取指阶段需要访问指令存储，而 Load/Store 的 MEM 阶段需要访问数据存储。

若二者共用同一个 Cache/存储端口，则某些周期会同时请求同一资源，产生结构冲突：

```text
IF needs Cache
MEM needs Cache
-> one shared resource
-> structural hazard
```

把 I-Cache 与 D-Cache 分开后：

```text
IF -> I-Cache
MEM -> D-Cache
```

两类访问可以并行进行，从而主要减少指令流水线中的资源冲突。

## 选项判断

故选 $\boxed{D}$。

## Verification

如果主要目标只是提高命中率或降低 miss penalty，并不必然要求把指令和数据 Cache 物理分离；真正与“分离”直接对应的是同时提供两个独立访问资源。

## Compression

```text
split I/D Cache
-> IF and MEM use different resources
-> remove shared-memory structural hazard
```

## 易错边界

“平均访存时间可能因此改善”是结果之一，但不是分离 I/D Cache 的最直接机制目标；本题问的是主要目的，应抓资源冲突 Owner。
