# 408-2014-Q07

> 原题：[[../2014 年全国硕士研究生招生考试#7|Q7]]

## Model Anchor

- Topic：DS08｜拓扑排序 = 零入度 frontier 演化。
- 题目信号：给 DAG，问哪个序列可能由拓扑排序得到。
- 第一动作：不要逐项凭感觉看“前后像不像”；维护每一步的 zero-indegree frontier，只允许从当前 frontier 中取下一个顶点。

## 解题链

根据题图的依赖关系：

- 初始只有顶点 3 入度为 0，因此第一位必须是 3；
- 删除 3 后，只有 1 新变为入度 0，因此第二位必须是 1；
- 删除 1 后，只有 4 满足条件，因此第三位必须是 4。

所以任何合法拓扑序列都必须以：

```text
3, 1, 4, ...
```

开头，A、B 立即排除。

删除 4 后，2 与 6 都可能进入 zero-indegree frontier，因此第四位可以选 2 或 6。

若先选 2，则后续在保持依赖关系的前提下可得到：

```text
3,1,4,2,6,5
```

与 D 一致。

## 选项判断

故选 $\boxed{D}$。

## Verification

对 D 做边约束检查：任意有向边 $u\to v$，u 都应出现在 v 前。D 满足全部先后关系；C 在后续 5/6 的先后约束上被破坏。

## Compression

```text
topological sort
-> maintain zero-indegree frontier
-> next vertex must come from frontier
-> delete it and update indegrees
```

## 易错边界

拓扑序列不是“任意满足大致先后关系的排列”；每一步可选集合由当前剩余图的入度状态动态决定。
