# 408-2014-Q04

> 原题：[[../2014 年全国硕士研究生招生考试#4|Q4]]

## Model Anchor

- Topic：DS04｜中序线索二叉树：空指针承载 predecessor / successor。
- 题目信号：问结点 x 的左、右线索指向谁。
- 第一动作：先写整棵树的中序序列，再只看 x 的直接前驱和直接后继；不要按图上的几何左右猜。

## 解题链

由题图进行中序遍历，得到：

```text
d -> e -> b -> x -> a -> c
```

中序线索化时：

- 若结点左孩子指针为空，则左线索指向其中序前驱；
- 若右孩子指针为空，则右线索指向其中序后继。

在序列中，x 的直接前驱是 b，直接后继是 a，因此：

$$
leftThread(x)=b,\qquad rightThread(x)=a.
$$

## 选项判断

故选 $\boxed{D}$。

## Verification

只需检查局部序列：

```text
... b, x, a ...
```

任何选项若不是这两个相邻结点，就不可能是 x 的中序前驱/后继。

## Compression

```text
inorder threading
-> write inorder sequence
-> empty left pointer -> predecessor
-> empty right pointer -> successor
```

## 易错边界

“左线索/右线索”不是“左子树里某个结点/右子树里某个结点”；它们由遍历序列中的前驱与后继关系决定。
