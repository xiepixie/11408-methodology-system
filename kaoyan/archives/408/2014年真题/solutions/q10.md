# 408-2014-Q10

> 原题：[[../2014 年全国硕士研究生招生考试#10|Q10]]

## Model Anchor

- Topic：DS11｜希尔排序一趟后的 gap-有序不变量。
- 题目信号：给“第 1 趟排序结果”，反推该趟可能使用的增量。
- 第一动作：对每个候选 gap，只检查所有同余类子序列是否分别有序；不需要恢复原始序列。

## 解题链

结果序列：

```text
9,1,4,13,7,8,20,23,15
```

若 gap=$d$，则第 1 趟结束后，每组：

```text
i, i+d, i+2d, ...
```

都应按升序有序。

检查候选：

- $d=2$：下标组 `1,3,5,...` 中出现 `9,4,7,...`，不有序，排除。
- $d=3$：
  ```text
  9,13,20
  1,7,23
  4,8,15
  ```
  三组均有序，可能成立。
- $d=4$：第一组含 `9,7,...`，不有序，排除。
- $d=5$：第一组含 `9,8`，不有序，排除。

## 选项判断

故选 $\boxed{B}$。

## Verification

gap=3 时每个同余类都满足单调性，这是希尔一趟排序完成后的结构性不变量；无需知道该趟之前的具体排列。

## Compression

```text
Shell pass result + candidate gap
-> split by index mod gap
-> every subsequence must be sorted
-> first violating group rejects gap
```

## 易错边界

“整个数组还没完全有序”并不影响判断。希尔排序一趟只保证各 gap 子序列有序，不保证全局有序。
