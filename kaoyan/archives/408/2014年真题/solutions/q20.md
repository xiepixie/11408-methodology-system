# 408-2014-Q20

> 原题：[[../2014 年全国硕士研究生招生考试#20|Q20]]

## 模型锚点

- 主题：CO08｜总线事务中的突发传输。
- 题目信号：主设备只给一个首地址，随后连续读写若干相邻单元。
- 第一动作：判断题目是在描述“数据怎样连续搬运”，还是在描述物理并串行或统一时钟；若首地址只给一次而后续地址自动推进，就是突发传输。

## 解题链

突发传输的关键不是“同时传几位”或“是否有统一时钟”，而是一次总线事务中：

1. 主设备先给出首地址；
2. 后续连续数据不必为每个数据重新完整给出地址；
3. 地址按协议自动递增或按预定序列推进；
4. 一次授权可连续完成多个数据传送。

题干正好符合这一事务特征，因此属于突发传输。

## 选项判断

- A 并行传输：描述多位数据是否同时在线路上传输，不描述地址是否只给一次。
- B 串行传输：描述数据位按时间先后传输，也不是本题关注的事务组织方式。
- C 突发传输：一次给首地址，连续完成多个数据传送，正确。
- D 同步传输：描述动作是否按统一时钟采样，和“首地址只给一次”不是同一分类维度。

故选 $\boxed{C}$。

## 校验

把题意反过来检查：如果不是突发方式，那么每搬运一个新的连续单元，通常都要重新承担一次寻址开销；这与“只需给出一个首地址”矛盾。

## 压缩

```text
一个首地址 + 连续多个数据
-> 先判断事务是否复用一次寻址
-> 地址自动推进
-> 突发传输
```

## 易错边界

“并行/串行”描述物理传输形式，“同步/异步”描述时序协议，“突发/非突发”描述一次事务如何组织多个数据，它们不是互斥在同一个分类轴上的四个概念。
