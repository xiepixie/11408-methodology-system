# 408-2014-Q18

> 原题：[[../2014 年全国硕士研究生招生考试#18|Q18]]

## 模型锚点

- Topic：CO03｜微程序控制器的控制存储器地址空间。
- 题目信号：32 条机器指令、公共取指 2 条微指令、每条指令平均 4 条微指令，采用下地址字段法。
- 第一动作：先算控制存储器至少需要容纳多少条微指令，再求能唯一编码这些微地址所需位数。

## 解题链

公共取指微程序：

$$2\text{ 条}.$$

32 条机器指令，每条平均 4 条微指令：

$$32\times4=128\text{ 条}.$$

因此至少需要：

$$128+2=130$$

个不同微地址。

下地址字段必须能编码至少 130 个位置。

7 bit 只能表示：

$$2^7=128<130,$$

不够；8 bit 可表示：

$$2^8=256\ge130.$$

## 选项判断

故选 $\boxed{C}$。

## 校验

这是一个典型容量下界题：如果选 7 bit，连 130 个控制存储单元都无法逐一寻址，必然不可能。

## 压缩

```text
microaddress bits
-> count total microinstructions
-> need 2^k >= count
-> k = ceil(log2 count)
```

## 易错边界

“32 条机器指令”只决定宏指令数量，不等于微地址只需 5 bit；真正要寻址的是所有微指令入口与后续微操作。
