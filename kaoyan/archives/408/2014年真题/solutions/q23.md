# 408-2014-Q23

> 原题：[[../2014 年全国硕士研究生招生考试#23|Q23]]

## 模型锚点

- 主题：OS01/02｜处理机调度中的公平性与饥饿。
- 题目信号：题目问“哪种调度算法不可能导致饥饿”。
- 第一动作：不要比较平均等待时间，而要问“后来到达的任务是否可能无限次插到某个旧任务前面”。

## 解题链

饥饿的本质是：系统整体仍在推进，但某个进程长期得不到 CPU。

时间片轮转按就绪队列循环分配 CPU。只要时间片有限、队列中的进程最终都会获得轮到自己的机会，新到达进程不能无限次插到一个已经在队列中的进程前面，因此经典时间片轮转不会产生饥饿。

其余算法都可能存在长期越过：

- 静态优先级调度中，如果高优先级进程持续到达，低优先级进程可能一直得不到 CPU；
- 非抢占式短作业优先中，如果短作业持续到达，长作业可能长期等待；
- 抢占式短作业优先中，长作业还可能被不断到来的更短作业反复推迟。

## 选项判断

故选 $\boxed{A}$。

## 校验

检验“是否会饥饿”最有效的反例构造是：不断加入策略更偏爱的任务。对静态优先级和短作业优先可以构造无限越过；对经典时间片轮转，已经入队的任务前方工作量不会被后来任务无限增加。

## 压缩

```text
问饥饿
-> 不看平均性能，先看是否存在无限越过
-> 新任务能否不断插队到旧任务前
-> 经典轮转给出有限推进边界，因此无饥饿
```

## 易错边界

- “平均等待时间小”不等于“不会饥饿”。
- “非抢占”也不等于“无饥饿”；只要调度决策持续偏向某一类任务，旧任务仍可能长期得不到服务。
