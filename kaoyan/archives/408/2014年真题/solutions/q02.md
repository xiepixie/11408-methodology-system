# 408-2014-Q02

> 原题：[[../2014 年全国硕士研究生招生考试#2|Q2]]

## 模型锚点

- Topic：DS02｜中缀转后缀：运算符栈不变量。
- 题目信号：扫描到表达式中间位置 `f`，问此时栈中有哪些符号。
- 第一动作：只模拟运算符栈；操作数直接输出，遇到左括号压栈，遇到运算符按优先级弹出，右括号才清理到左括号。

## 解题链

表达式：

```text
a/b+(c*d-e*f)/g
```

逐步追踪运算符栈：

```text
读 a      栈 []
读 /      栈 [/]
读 b      栈 [/]
读 +      弹出 /，压 +       -> [+]
读 (      -> [+, (]
读 c      -> [+, (]
读 *      -> [+, (, *]
读 d      -> [+, (, *]
读 -      * 优先级高，先弹出 *；压 -
          -> [+, (, -]
读 e      -> [+, (, -]
读 *      * 优先级高于栈顶 -，直接压栈
          -> [+, (, -, *]
读 f      栈保持不变
```

因此扫描到 `f` 时，自栈底到栈顶为：

```text
+ ( - *
```

## 选项判断

故选 $\boxed{B}$。

## 校验

若栈顶不是 `*`，就意味着 `e*f` 的乘法无法在减法之前完成，与运算符优先级冲突；若括号 `(` 不在 `+` 与 `-` 之间，则说明括号作用域被破坏。

## 压缩

```text
infix -> postfix
-> operand outputs immediately
-> '(' always push
-> operator pops >= precedence until '('
-> track operator stack only
```

## 易错边界

题目问的是“扫描到 f 时”的栈状态，不是“处理完 f 后再看到后续右括号”的状态；此时 `)` 尚未出现，所以 `(` 不能出栈。
