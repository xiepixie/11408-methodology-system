# 408-2014-Q01

> 原题：[[../2014 年全国硕士研究生招生考试#1|Q1]]

## 模型锚点

- Topic：DS｜嵌套循环复杂度：先数每层真实迭代次数。
- 题目信号：外层 `k*=2`，内层固定跑 n 次。
- 第一动作：先分别求外层次数 $\Theta(\log n)$ 与每次内层工作量 $\Theta(n)$，再乘。

## 解题链

外层 k 依次为：

$$1,2,4,\ldots,2^t\le n,$$

所以外层执行次数：

$$t+1=\Theta(\log n).$$

每次外层循环中，内层 `j=1..n` 固定执行 n 次，因此总基本操作次数：

$$n\cdot\Theta(\log n)=\Theta(n\log n).$$

## 选项判断

故选 $\boxed{C}$。

## 校验

若 n 翻倍，内层工作约翻 2 倍，而外层只增加约 1 轮；增长趋势符合 $n\log n$，明显不是 $n^2$。

## 压缩

```text
k *= constant -> log n rounds
inner fixed n work
-> n log n
```

## 易错边界

“两个 for”不等于 $O(n^2)$；复杂度由迭代次数决定，不由循环嵌套层数机械决定。
