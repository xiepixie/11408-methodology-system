# 408-2014-Q05

> 原题：[[../2014 年全国硕士研究生招生考试#5|Q5]]

## Model Anchor

- Topic：DS04｜森林 ↔ 孩子兄弟二叉树的指针语义。
- 题目信号：森林 F 转换为二叉树 T，问“森林叶子数”等于二叉树中哪类结点数。
- 第一动作：先恢复转换规则：`left = first child`，`right = next sibling`；再把“叶子 = 无孩子”翻译成二叉树指针条件。

## 解题链

森林转换为对应二叉树采用孩子兄弟表示：

```text
原森林结点的第一个孩子 -> 二叉树左孩子
原森林结点的下一个兄弟 -> 二叉树右孩子
```

森林中的叶结点定义为“没有任何孩子”。

在孩子兄弟表示中，“没有孩子”恰好意味着：

$$
leftChild = NULL.
$$

所以森林 F 的叶子个数，等于二叉树 T 中左孩子指针为空的结点个数。

## 选项判断

故选 $\boxed{C}$。

## Verification

一个森林叶子仍可能有兄弟，因此转换后它的右孩子指针不一定为空；这直接排除 D，也说明“二叉树叶结点”并不与“森林叶子”一一对应。

## Compression

```text
forest -> child-sibling binary tree
left  = first child
right = next sibling
forest leaf = no child
-> left pointer is NULL
```

## 易错边界

森林中的“叶子”看的是孩子关系；转换后二叉树里的“叶结点”要求左右孩子都空。两种叶子概念不能直接等同。
