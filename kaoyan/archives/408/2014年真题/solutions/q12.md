# 408-2014-Q12

> 原题：[[../2014 年全国硕士研究生招生考试#12|Q12]]

## Model Anchor

- Topic：CO01/CO04｜CPU 执行时间分解。
- 题目信号：优化后“指令数变为 70%”“CPI 变为 1.2 倍”，主频未变。
- 第一动作：只保留会变化的乘法因子：$T=IC\times CPI\times T_{clk}$；主频相同则时钟周期约掉。

## 解题链

原执行时间：

$$T=20\text{ s}.$$

优化后：

$$IC'=0.7IC,$$

$$CPI'=1.2CPI.$$

机器 M 不变，时钟周期不变，因此：

$$
\frac{T'}{T}=\frac{IC'\cdot CPI'}{IC\cdot CPI}=0.7\times1.2=0.84.
$$

所以：

$$
T'=20\times0.84=16.8\text{ s}.
$$

## 选项判断

故选 $\boxed{D}$。

## Verification

虽然 CPI 上升 20%，但指令数下降 30%，总时钟周期数仍变为原来的 84%，所以执行时间应略低于 20 s，而不是低到 8～14 s 的量级。

## Compression

```text
CPU time = IC * CPI / clock rate
same machine -> clock rate unchanged
-> multiply relative IC and CPI factors
```

## 易错边界

“指令数减少 30%”与“执行时间减少 30%”不是同义；CPI 同时变化时必须把两个因子一起计入。
