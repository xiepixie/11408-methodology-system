# 408-2014-Q15

> 原题：[[../2014 年全国硕士研究生招生考试#15|Q15]]

## Model Anchor

- Topic：CO05｜DRAM 地址引脚复用。
- 题目信号：单颗芯片规格 `4M×8 bit`，问地址引脚和数据引脚总数。
- 第一动作：先把 `4M` 转成地址单元数，再判断 DRAM 是否通过行/列地址复用减少物理地址引脚。

## 解题链

单颗 DRAM 有：

$$4M=4\times2^{20}=2^{22}$$

个存储单元，因此逻辑地址需要 22 bit。

但 DRAM 采用行地址/列地址分时复用。若行、列各 11 bit，则同一组 11 根地址引脚可先传行地址、再传列地址。

因此物理地址引脚只需：

$$11\text{ 根}.$$

芯片数据宽度为 8 bit，所以数据引脚：

$$8\text{ 根}.$$

合计：

$$11+8=19.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

若不复用地址，地址+数据应为 $22+8=30$ 根，对应选项 C；但题目明确是 DRAM，正是在考行/列地址复用，因此应把地址引脚减半为 11 根。

## Compression

```text
DRAM chip aM×w
-> logical address bits = log2(aM)
-> row/column multiplexing halves physical address pins
-> add w data pins
```

## 易错边界

逻辑地址位数不等于芯片物理地址引脚数。DRAM 的 RAS/CAS 复用正是把不同时间阶段的地址字段复用到同一组引脚上。
