# 408-2014-Q13

> 原题：[[../2014 年全国硕士研究生招生考试#13|Q13]]

## Model Anchor

- Topic：CO01｜8 位补码范围与有符号溢出。
- 题目信号：给 $x=103,y=-25$，问哪种表达式在 8 位补码中溢出。
- 第一动作：先在数学整数域算四个真值，再和 8 位有符号范围 $[-128,127]$ 比较；不要先做位串运算。

## 解题链

8 位补码可表示：

$$[-128,127].$$

逐项计算：

$$x+y=103+(-25)=78,$$

可表示。

$$-x+y=-103-25=-128,$$

刚好是最小可表示值，仍不溢出。

$$x-y=103-(-25)=128,$$

超过最大值 127，发生溢出。

$$-x-y=-103-(-25)=-78,$$

可表示。

## 选项判断

故选 $\boxed{C}$。

## Verification

边界检查最关键：`-128` 是 8 位补码合法值，而 `+128` 不可表示。因此 B 不溢出、C 溢出，正好卡在两个边界上。

## Compression

```text
signed overflow question
-> calculate mathematical result first
-> compare with representable range
-> 8-bit two's complement: [-128,127]
```

## 易错边界

不要把“绝对值达到 128”一律判溢出。8 位补码是不对称范围：能表示 -128，但不能表示 +128。
