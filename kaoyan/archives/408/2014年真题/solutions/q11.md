# 408-2014-Q11

> 原题：[[../2014 年全国硕士研究生招生考试#11|Q11]]

## Model Anchor

- Topic：DS11｜快速排序 partition 完成后的枢轴不变量。
- 题目信号：问“第 2 趟排序结果不可能是哪一个”。
- 第一动作：不要模拟未知原序列；利用每完成一次 partition，至少会有一个枢轴进入最终位置。第 2 趟结束后，至少应能识别出两个满足“左边都小、右边都大”的最终定位元素。

## 解题链

对一个位置上的关键字 $x$，若它已经处于最终位置，则必须满足：

```text
左侧所有关键字 < x
右侧所有关键字 > x
```

逐项检查：

- A：`2,3,5,4,6,7,9` 中 2、3、6、7、9 等多个位置已满足最终定位条件，可能。
- B：`2,7,5,6,4,3,9` 中至少 2 和 9 已最终定位，可能。
- D：`4,2,3,5,7,6,9` 中 5 和 9 已最终定位，可能。
- C：`3,2,5,4,7,6,9` 中只有 9 满足最终定位条件，找不到第 2 个已经完成 partition 后应固定的枢轴，因此不可能是第 2 趟结束状态。

## 选项判断

故选 $\boxed{C}$。

## Verification

第二趟 partition 不可能让“第一趟已经固定的枢轴”重新失去最终位置；而第二趟又会再固定至少一个枢轴。因此第 2 趟后最终定位元素数不可能仍只有 1 个。

## Compression

```text
quick-sort pass state
-> each completed partition fixes a pivot
-> fixed pivot: all left smaller, all right larger
-> after 2 passes, need >= 2 fixed positions
```

## 易错边界

“第 2 趟”不是“整个数组已经分成两个完全有序段”；只保证已完成 partition 的枢轴落在最终位置。另：legacy 文件名误标为计组，本题按 408 Profile 属于数据结构。
