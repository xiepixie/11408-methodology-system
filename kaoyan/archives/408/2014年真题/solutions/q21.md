# 408-2014-Q21

> 原题：[[../2014 年全国硕士研究生招生考试#21|Q21]]

## 模型锚点

- 主题：CO08｜I/O 接口寄存器与 I/O 编址方式。
- 题目信号：同时出现 I/O 端口、独立编址、统一编址以及 CPU 访问指令。
- 第一动作：先判断 I/O 端口属于哪一个地址空间，再判断 CPU 应使用普通访存指令还是专用 I/O 指令访问。

## 解题链

I/O 接口中，CPU 能直接访问的数据、状态、控制等寄存器统称为 I/O 端口。

两种编址方式的核心区别是地址空间和访问指令：

- 独立编址：I/O 端口拥有独立地址空间，通常使用专用 I/O 指令。因为端口空间和主存空间彼此独立，所以数值相同的地址可以分别存在于两个空间中而不冲突。
- 统一编址：I/O 端口被映射到主存地址空间，CPU 使用普通访存指令访问这些端口。

因此 D 所说“统一编址时 CPU 不能用访存指令访问 I/O 端口”恰好与统一编址的定义相反。

状态端口和控制端口在硬件上可以复用同一个寄存器，只要读写方向或位字段语义能够区分，因此 A 并不错误。

## 选项判断

- A：正确。状态与控制功能可以复用同一寄存器。
- B：正确。CPU 可访问的接口寄存器就是 I/O 端口。
- C：正确。独立编址拥有两个独立地址空间，同一个数值地址可以分别存在。
- D：错误。统一编址正是通过普通访存指令访问 I/O 端口。

故选 $\boxed{D}$。

## 校验

用最简单的定义反查：若 I/O 端口进入主存统一地址空间，却又禁止普通访存指令访问，那么“统一编址”就失去了其最核心的软件可见特征，因此 D 必错。

## 压缩

```text
出现 I/O 编址
-> 先问端口是否和主存共享地址空间
-> 独立编址：独立空间 + 专用 I/O 指令
-> 统一编址：共享空间 + 普通访存指令
```

## 易错边界

- 地址数值相同不等于地址对象相同；独立编址中，主存地址空间和 I/O 地址空间是两个不同命名空间。
- “端口”是 CPU 可访问的接口寄存器，不等于外设本体。
