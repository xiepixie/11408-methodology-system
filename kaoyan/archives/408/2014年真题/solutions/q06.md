# 408-2014-Q06

> 原题：[[../2014 年全国硕士研究生招生考试#6|Q6]]

## 模型锚点

- Topic：DS04｜前缀编码与编码树叶结点条件。
- 题目信号：给若干码字，问哪组不是 prefix code。
- 第一动作：不要构造完整树；直接检查是否存在某个码字是另一个码字的前缀。

## 解题链

前缀编码要求：任意两个不同码字 $x,y$，都不能满足“$x$ 是 $y$ 的前缀”。

检查 D：

```text
0, 100, 110, 1110, 1100
```

其中：

```text
110
```

正是：

```text
1100
```

的前缀。

因此若比特流读到 `110...`，在读完 `110` 时已经无法唯一判断究竟应该立刻译码成 `110`，还是继续等待成为 `1100`，即时译码唯一性被破坏。

## 选项判断

故选 $\boxed{D}$。

## 校验

把码字放到二叉 Trie 中：前缀编码要求所有码字都只能落在叶结点。D 中 `110` 已经是一个终止码字，却仍向下延伸到 `1100`，违反 leaf-only invariant。

## 压缩

```text
prefix code
-> no codeword may be ancestor/prefix of another
-> Trie terminal must be leaf
```

## 易错边界

“所有码字彼此不同”远远不够；前缀编码要求更强：短码字不能成为长码字的开头。
