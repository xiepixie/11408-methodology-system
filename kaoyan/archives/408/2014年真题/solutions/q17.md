# 408-2014-Q17

> 原题：[[../2014 年全国硕士研究生招生考试#17|Q17]]

## Model Anchor

- Topic：CO02｜定长指令字段预算。
- 题目信号：32 位指令、8 位操作码、16 个通用寄存器，Store 需要源寄存器和基址寄存器，剩余位给补码偏移量。
- 第一动作：先把两个寄存器字段各占多少位算清，再把剩余位数全部归给 displacement。

## 解题链

16 个通用寄存器需要：

$$\log_2 16=4\text{ bit}.$$

Store 指令中：

- 操作码（含寻址方式）8 bit；
- 源寄存器 4 bit；
- 基址寄存器 4 bit。

所以偏移量字段位数：

$$32-8-4-4=16\text{ bit}.$$

16 位补码范围为：

$$[-2^{15},2^{15}-1]=[-32768,32767].$$

## 选项判断

故选 $\boxed{A}$。

## Verification

若偏移量有 17 bit，整条指令至少需要 $8+4+4+17=33$ bit，超过题设 32 位定长指令，因此 C/D 量级不可能。

## Compression

```text
instruction field budget
-> register bits = log2(register count)
-> displacement bits = total - opcode - register fields
-> two's complement range
```

## 易错边界

“基址寻址”不是只需要一个寄存器字段；Store 仍需编码要写出的源寄存器，因此这里一共要两个 4 位寄存器号。
