# 408-2014-Q08

> 原题：[[../2014 年全国硕士研究生招生考试#8|Q8]]

## 模型锚点

- Topic：DS10｜开放定址中的堆积现象与查找成本。
- 题目信号：问“堆积现象直接影响什么”。
- 第一动作：先区分结构参数与运行成本：散列函数、装填因子是给定/统计属性；堆积真正改变的是一次查找要探测多少位置。

## 解题链

堆积意味着许多关键字在冲突处理后形成连续或密集的探测区域。

其直接结果是：

```text
successful/unsuccessful lookup
-> probe sequence becomes longer
-> average search length increases
```

但：

- 散列函数本身并不会因为堆积而改变；
- 装填因子由“已存元素数 / 表容量”决定，不由元素聚在何处分布决定；
- 存储效率的容量占用比例也不是堆积直接改变的对象。

## 选项判断

故选 $\boxed{D}$。

## 校验

构造两个装填因子相同的散列表：一个元素分散，一个出现长聚集区。两者占用元素数完全相同，但后者查找探测次数明显更大，说明被直接影响的是 ASL。

## 压缩

```text
clustering
-> longer probe chains
-> larger ASL
not -> hash function / load factor
```

## 易错边界

装填因子会影响冲突概率，但“冲突/堆积发生后”并不会反过来改变装填因子的定义值。因果方向不能倒置。
