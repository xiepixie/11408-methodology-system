# 408-2014-Q14

> 原题：[[../2014 年全国硕士研究生招生考试#14|Q14]]

## Model Anchor

- Topic：CO01｜IEEE 754 位模式比较：先符号，再指数/尾数。
- 题目信号：两个 32 位 float 原始位模式，问 x、y 大小关系和符号关系。
- 第一动作：先看最高位判断符号；若同为负数，再比较其绝对值大小，注意“绝对值更大 => 真值更小”。

## 解题链

两个位模式：

```text
x: CC90 0000H
y: B0C0 0000H
```

最高位都为 1，因此：

$$x<0,\qquad y<0,$$

两者符号相同。

再比较数量级。对于正常规格化负浮点数，除符号位外，指数越大，绝对值通常越大。

`CC...` 的指数明显大于 `B0...`，因此：

$$|x|>|y|.$$

两者都为负，所以：

$$x<y.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

也可粗略解码数量级：`CC90...` 对应一个绝对值很大的负数，而 `B0C0...` 是接近 0 的负数；因此前者数值更小。

## Compression

```text
IEEE float compare
-> sign first
-> same negative sign: larger magnitude means smaller value
-> exponent gives magnitude order quickly
```

## 易错边界

不能把 32 位浮点位串当作普通无符号整数直接比较；尤其两个负数时，编码数值大小与真实数值大小方向不同。
