# 408-2025-Q23

> 原题：[[../2025 年全国硕士研究生招生考试#23|Q23]]

## Model Anchor

- Topic：[[../../../../30_408/30_操作系统/10_进程线程调度与控制权/README|OS-01/02 进程、线程、调度与控制权]]。
- 题目信号：**进程上下文切换 + 哪个寄存器不需要更新**。
- 第一动作：不要背“上下文=一堆寄存器”。先问每个状态的 Owner：它是**当前进程私有执行/地址空间状态**，还是**整个内核共享的系统级状态**？

## 解题链

- A 通用寄存器：保存当前进程执行现场，换进程时需保存/恢复。
- B 页表基址寄存器：不同进程通常拥有不同虚拟地址空间，跨进程切换时需要切到新进程的页表根。
- C 程序计数器：决定新进程从哪里继续执行，属于执行上下文。
- **D 内核中断向量表基址寄存器：中断入口表是系统级内核状态，通常不随普通进程身份变化，因此进程切换无需更新。**

**答案：D。**

## 选项判断

按进程切换时真正需要保存/恢复的地址空间与处理器状态判断，正确选项为 $\boxed{D}$。

## Verification

设进程 A、B 来回切换。若 D 也必须每次改变，就意味着每个普通进程都有不同的内核中断入口表；这与题设常规单内核模型不符。反过来，若不恢复 PC/GPR/页表根，则 B 根本不能继续自己的控制流和地址空间。

## Compression

上下文切换问寄存器 → **按 Owner 分类：execution context / address-space context 随进程切；system-global kernel control 不随普通进程切**。

## 易错边界

模式切换不等于上下文切换。一次系统调用可以进入内核却仍执行同一进程，也就不必换页表根或进程现场。
