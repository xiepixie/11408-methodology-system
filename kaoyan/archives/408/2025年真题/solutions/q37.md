# 408-2025-Q37

> 原题：[[../2025 年全国硕士研究生招生考试#37|Q37]]

## Model Anchor

- Topic：[[../../../../30_408/40_计算机网络/04_IP地址_子网与分组转发/README|NET-04 NAT/NAPT]] + [[../../../../30_408/40_计算机网络/06_传输层_端点_UDP与TCP状态机/README|NET-06 UDP]]。
- 题目信号：私网主机经 NAT 访问 Internet，题目只问**UDP 首部哪些字段会改**。
- 第一动作：先区分 IP 层改写与 UDP 层改写；然后检查 UDP checksum 覆盖的 pseudo-header 是否受到牵连。

## 解题链

出站 NAPT 通常把内部源 tuple

```text
(private IP, private source port)
```

映射成

```text
(public IP, translated source port)
```

因此：

- I 源端口号：可能被 NAPT 改写，正确；
- II 目的端口号：服务器服务入口不因出站 NAT 改变，错误；
- III UDP 总长度：payload 和 UDP 首部长度未改变，错误；
- IV 校验和：UDP checksum 计算还覆盖 pseudo-header 中的源/目的 IP；NAT 又改了源 IP，若还改源端口则 UDP 首部本身也变，因此 checksum 必须相应更新，正确。

所以是 **I、IV**。

**答案：B。**

## 选项判断

按 NAPT 的五元组重写与 UDP 校验和覆盖范围判断，正确选项为 $\boxed{B}$。

## Verification

即便某次 NAT 恰好能保留原源端口，源 IP 的变化仍会进入 UDP pseudo-header，原 checksum 也不再对应修改后的报文，因此 IV 仍需处理。

## Compression

NAT 问传输层字段 → **先写 tuple rewrite，再沿 checksum coverage 追依赖** → 出站改 source tuple；长度不变；pseudo-header 变化迫使 UDP checksum 更新。

## 易错边界

pseudo-header 是 checksum 的计算输入，不是实际在线传输的 UDP 首部字段；NAT 改 IP 仍会影响 UDP checksum，正是因为存在这个跨层校验依赖。
