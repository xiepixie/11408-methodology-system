# 408-2025-Q47

> 原题：[[../2025 年全国硕士研究生招生考试#47（本题 9 分）|Q47]]

## Model Anchor

- Topic / Owner：本题不是三个互不相关的小计算，而是在同一张网络图上连续切换三个 Owner：NET-01 的 propagation / transmission / bottleneck，NET-03 的可靠传输窗口，NET-04 的 CIDR/VLSM 地址容量与不重叠边界。

题目信号分别是：

```text
卫星高度 + 传播速度 + 链路速率
-> 先画时延账本

GBN + frame size + 利用率
-> 先算一帧发送时间和反馈闭环周期

/24 + 三个子网容量 + H=10.10.10.33/26
-> 先由已知主机地址恢复管理区网络号，再做 VLSM
```

- 第一动作：**每进入一个小问先重置 Scope / Cost Owner**，把传播与发送、可靠传输窗口、CIDR 地址容量分成三张账，禁止在同一公式里混用。

## Problem Representation

```text
(1) Path ledger
    satellite height = 36 000 km
    propagation speed = 300 000 km/s
    bottleneck = 200 kb/s
    file = 4000 B

(2) GBN ledger
    frame = 1500 B
    one-way propagation = 0.24 s
    target utilization >= 80%
    sequence field = k bit, receive window = 1

(3) CIDR ledger
    pool = 10.10.10.0/24
    hosts needed = 60 / 60 / 120
    known management host H = 10.10.10.33/26
```

三个小问共享拓扑背景，但不共享同一个状态机；真正共享的只有“先确定当前 Scope，再找该 Scope 的限制条件”。

## Decision Points

- 传播时延与发送时延是两个不同成本；文件最少完成时间必须至少包含瓶颈链路 serialization + 单向 propagation。
- GBN 先由利用率反推最小窗口，再用 $W_s\le2^k-1$ 反推序号位数；不能把 sequence-space 公式倒过来当利用率公式。
- VLSM 先锁定已知主机所在的管理区 `/26`，再按主机容量从大到小分配剩余地址，并以“不重叠 + 容量足够”闭合。

## Solution Chain

### (1) 单向传播时延、最大吞吐量、4000 B 文件最少传输时间

#### 传播时延

R1 到 R2 的信号路径是：

```text
R1 -> TR1 -> 卫星 -> TR2 -> R2
```

题目给出的卫星轨道高度是 36 000 km，因此电磁波要经历一次上行和一次下行：

$$
d=2\times36\,000=72\,000\ \mathrm{km}.
$$

传播速度为 $300\,000\ \mathrm{km/s}$：

$$
T_{prop}=\frac{72\,000}{300\,000}=0.24\ \mathrm{s}.
$$

所以卫星链路单向传播时延为：

$$\boxed{0.24\ \mathrm{s}=240\ \mathrm{ms}}.$$

#### 最大吞吐量

从 H 到总部服务器的路径中，以太网是千兆级，而 R1—R2 卫星方向只有：

$$200\ \mathrm{kb/s}.$$

端到端稳定吞吐量不能超过路径瓶颈，因此：

$$\boxed{200\ \mathrm{kb/s}}.$$

注意：传播时延影响完成时间、在途数据量和窗口需求，但**不直接把一条 200 kb/s 链路的稳态容量变小**。

#### 4000 B 文件的最少时间

忽略协议首部和以太网传播开销。4000 B 文件经过瓶颈链路的发送时间：

$$
T_{tx}=\frac{4000\times8}{200\times10^3}
=0.16\ \mathrm{s}.
$$

最后一个 bit 到达 R2/总部侧，还需经历卫星单向传播：

$$
T_{min}=T_{tx}+T_{prop}
=0.16+0.24
=0.40\ \mathrm{s}.
$$

故：

$$\boxed{0.40\ \mathrm{s}}.$$

---

### (2) GBN 发送窗口与序号位数

这里真正决定利用率的是：发送方能否在第一个 ACK 返回前，连续发送足够多的数据帧。

#### 第一步：一帧的发送时间

SLP 数据帧长 1500 B：

$$
T_f=\frac{1500\times8}{200\times10^3}
=0.06\ \mathrm{s}.
$$

卫星单向传播时延是 0.24 s，忽略 ACK 帧发送时间，因此一个帧从开始发送到其 ACK 能回到发送方的闭环时间近似为：

$$
T_f+2T_{prop}
=0.06+0.48
=0.54\ \mathrm{s}.
$$

#### 第二步：由利用率反推窗口

若发送窗口为 $W$，在窗口未饱和链路前，发送方一轮最多连续发送 $W$ 帧，占用发送链路的时间为 $WT_f$。利用率：

$$
U=\min\left(1,\frac{WT_f}{T_f+2T_{prop}}\right).
$$

要求 $U\ge0.8$：

$$
\frac{W\times0.06}{0.54}\ge0.8.
$$

所以：

$$
W\ge7.2.
$$

窗口必须取整数，故最小：

$$\boxed{W=8}.$$

#### 第三步：GBN 序号空间约束

若序号字段有 $k$ 位，序号空间大小为 $2^k$。GBN 接收窗口为 1，为避免新旧帧在序号回绕后混淆，需要：

$$
W_s\le2^k-1.
$$

现在 $W_s=8$：

$$
8\le2^k-1
\Longrightarrow
2^k\ge9.
$$

因此：

$$\boxed{k=4\ \text{bit}}.$$

---

### (3) 三个子网的 CIDR 地址

总地址块：

$$10.10.10.0/24.$$

需求：

- 生活区：至少 120 个**可分配主机地址**；
- 作业区：至少 60 个；
- 管理区：至少 60 个；
- H 已配置为 `10.10.10.33/26`，位于管理区。

#### 管理区

`/26` 每个子网共有 64 个地址、62 个可用主机地址，满足“至少 60”。

`10.10.10.33/26` 的 `/26` 块边界每 64 个地址一段：

```text
0~63
64~127
128~191
192~255
```

33 落在 `0~63`，所以管理区网络号：

$$\boxed{10.10.10.0/26}.$$

#### 作业区

也至少需要 60 个可用主机地址，因此至少 `/26`。不能与管理区重叠，最自然的下一个 `/26`：

$$\boxed{10.10.10.64/26}.$$

#### 生活区

至少 120 个可用主机地址：

- `/26`：62 个，不够；
- `/25`：128 个地址，126 个可用，满足。

剩余连续半块 `128~255` 正好形成：

$$\boxed{10.10.10.128/25}.$$

按题目要求“作业区、管理区、生活区”顺序：

$$
\boxed{
10.10.10.64/26,\quad
10.10.10.0/26,\quad
10.10.10.128/25
}
$$

## Verification

### 时延与吞吐量检查

200 kb/s 发送 32 000 bit 本身就需要 160 ms；卫星传播又至少 240 ms，因此 400 ms 是无法突破的下界。若答案小于 240 ms，显然连传播下界都违反。

### GBN 窗口检查

$W=7$ 时：

$$
U=\frac{7\times0.06}{0.54}\approx77.78\%<80\%,
$$

而 $W=8$：

$$
U=\frac{8\times0.06}{0.54}\approx88.89\%,
$$

所以 8 确实是最小整数窗口。

### 子网检查

- `10.10.10.0/26`：主机 `.1~.62`，H `.33` 合法；
- `10.10.10.64/26`：主机 `.65~.126`，62 个；
- `10.10.10.128/25`：主机 `.129~.254`，126 个；
- 三段互不重叠，并且恰好覆盖整个 `/24`。

## Compression

```text
卫星高度题
-> 路径是“上行+下行”
-> propagation=d/v；throughput 看 bottleneck；文件完成时间再加 serialization

GBN 利用率题
-> 先算 Tframe 与 RTT
-> U = W*Tframe/(Tframe+RTT)
-> 反推最小整数 W
-> 再用 W <= 2^k-1 求序号位数

VLSM 题
-> 先把 host demand 转成最小 prefix
-> 已知 host/prefix 先锁死其 network block
-> 其余子网按边界不重叠分配
```

## 易错边界

- **Propagation delay ≠ transmission delay**：前者由距离和传播速度决定，后者由 bit 数和链路速率决定；
- **吞吐量 ≠ 文件大小 / (传播时延+发送时延)**：后者是这次短传输的平均完成速率，不是路径稳态瓶颈容量；
- **GBN 的窗口公式与 SR 不同**：GBN 要求 $W_s\le2^k-1$；
- **“可分配 IP 数”要扣除网络地址和广播地址**：60 个主机不能用 `/27`，120 个主机不能用 `/26`。
