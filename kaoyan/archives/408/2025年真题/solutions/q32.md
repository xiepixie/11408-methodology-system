# 408-2025-Q32

> 原题：[[../2025 年全国硕士研究生招生考试#32|Q32]]

## Model Anchor

- Topic：[[../../../../30_408/30_操作系统/50_文件系统/README|OS-06/07 文件系统]]，设备成本边界调用 OS-05。
- 题目信号：问 HDD 与 SSD **都需要由文件系统提供**的功能。
- 第一动作：把“文件系统逻辑块管理”与“设备介质特有机制”分开。相同的文件抽象可以落在不同物理介质上。

## 解题链

- A 划分扇区：扇区属于块设备/介质与格式化层的物理或设备级组织，不是文件系统对 HDD、SSD 都必须提供的共同职责。
- **B 确定盘块大小：文件系统必须确定自己的逻辑块/文件系统块粒度，用它组织分配、索引和 I/O；HDD 与 SSD 上都需要这一层抽象。**
- C 降低寻道时间：寻道是机械 HDD 的成本，SSD 没有磁头寻道。
- D 实现均衡磨损：磨损均衡针对闪存擦写寿命，通常由 SSD 控制器/FTL 等承担，并非 HDD 的共同需求。

**答案：B。**

## 选项判断

HDD 与 SSD 上的文件系统都必须确定自己的逻辑盘块/文件系统块粒度；寻道只属于机械盘，磨损均衡只属于闪存，扇区划分也不是文件系统共同职责，因此选 $\boxed{B}$。

## Verification

把底层介质从 HDD 换成 SSD，文件系统仍然必须知道“一个 allocation / mapping 单位多大”；但“磁头离下一个请求多远”这一问题直接消失，说明寻道不是共同职责。

## Compression

HDD vs SSD 共性题 → **先抽出文件系统逻辑层，再剔除介质特有成本** → block size 是共同逻辑组织；seek 属 HDD，wear leveling 属 flash/SSD。

## 易错边界

文件系统 block、设备 sector、SSD flash page/block 是不同粒度。题目只有明确说明它们相等时才能合并。
