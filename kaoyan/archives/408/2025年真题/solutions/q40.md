# 408-2025-Q40

> 原题：[[../2025 年全国硕士研究生招生考试#40|Q40]]

## Model Anchor

- Topic：[[../../../../30_408/40_计算机网络/08_应用层_DNS_HTTP与服务语义/README|NET-08 应用层服务语义]]。
- 题目信号：POP3 能力判断。
- 第一动作：先把邮件生命周期拆成两段：**SMTP 负责提交/服务器间传送；POP3/IMAP 负责用户访问 mailbox。**

## 解题链

- **I 正确。** POP3 用于用户代理从邮件服务器访问/下载邮件。
- II 错误。用户代理向邮件系统提交邮件使用 SMTP 等邮件提交机制，不由 POP3 负责。
- III 错误。邮件服务器之间的 relay/transfer 由 SMTP 负责。
- **IV 正确。** POP3 会话建立一条 TCP 连接后，可以在同一会话中执行多次 `RETR` 等命令收取多封邮件，不需要每封邮件重新建 TCP。

因此正确的是 **I、IV**。

**答案：A。**

## 选项判断

按 POP3 与 SMTP 的职责边界逐项判断，只有 I、IV 成立，故选 $\boxed{A}$。

## Verification

画完整责任链即可：

```text
sender UA -> SMTP -> sender/relay server -> SMTP -> recipient server/mailbox
                                              -> POP3/IMAP -> recipient UA
```

POP3 只位于最后的 mailbox access 段，因此 II、III 都越过了它的责任边界。

## Compression

邮件协议题 → **先分 transfer 与 mailbox access** → SMTP push/relay，POP3/IMAP pull/access；一条 POP3 TCP session 可操作多封邮件。

## 易错边界

“收邮件”这个自然语言太粗：服务器接收另一服务器推来的邮件属于 SMTP transfer；用户从自己 mailbox 取邮件才是 POP3/IMAP access。
