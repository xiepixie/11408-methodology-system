# 408-2025-Q15

> 原题：[[../2025 年全国硕士研究生招生考试#15|Q15]]

## Model Anchor

- Topic：[[../../../../30_408/20_计算机组成原理/10_数据表示与运算/README|CO-01 大小端与对齐]] + [[../../../../30_408/20_计算机组成原理/20_ISA与机器级程序/README|CO-02 数据布局]]。
- 题目信号：结构体数组 + 边界对齐 + 小端 + 指定机器数字节。
- 第一动作：先解决**对象地址**，再解决**对象内部的字节地址**；不要把对齐和 endian 混成一步。

## 解题链

结构体：

```c
struct record {
    int  id;       // 4 B
    char name[10]; // 10 B
    int  salary;   // 4 B，需要 4 B 对齐
}
```

按 4 字节边界对齐：

- `id`：偏移 0~3；
- `name`：偏移 4~13；
- 为让 `salary` 从 4 的倍数地址开始，偏移 14~15 填充 2 B；
- `salary`：偏移 16~19。

所以一个 `record` 大小为 20 B，即 `0x14`。

`employee` 首地址为 `A0B0H`，因此

$$
\&employee[1].id=0xA0B0+0x14=0xA0C4.
$$

`employee[1].id` 的机器数为 `12345678H`。小端存放时从低地址到高地址依次是：

| 地址 | 字节 |
|---|---|
| `A0C4H` | `78H` |
| `A0C5H` | `56H` |
| `A0C6H` | `34H` |
| `A0C7H` | `12H` |

因此 `56H` 位于 `0000 A0C5H`。

## 选项判断

由结构体对齐、数组步长与小端字节序共同定位到 `0000 A0C5H`，故选 $\boxed{C}$。

## Verification

结构体总大小必须是其最大对齐要求 4 的倍数。20 B 满足；若误算成 18 B，就已经违反数组中下一元素 `id` 的 4 字节对齐。

## Compression

结构体数组 + endian → **先画字段 offset / padding 求 stride -> 定位元素首地址 -> 再按 endian 展开该字段的字节表**。

## 易错边界

对齐决定“字段从哪个地址开始”；小端决定“多字节值的各字节怎样排列”。两者职责不同。
