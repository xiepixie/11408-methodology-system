# 408-2025-Q39

> 原题：[[../2025 年全国硕士研究生招生考试#39|Q39]]

## Model Anchor

- Topic：NET-06 UDP/TCP transport cost + NET-08 应用请求/响应依赖。
- 题目信号：同一 request/response 服务分别跑 UDP 与 TCP，只给 RTT，问**最少时间**。
- 第一动作：画串行依赖，不背“UDP 快一个 RTT”：UDP 可直接 request；TCP 在应用 request 之前必须先完成连接建立。

## 解题链

忽略数据发送时间等额外开销。

### UDP

UDP 无连接建立阶段。客户端发请求，服务器回复，完成一次 request/response：

$$T_{UDP}=1RTT=8\ ms.$$

### TCP

经典最小模型需要：

1. 约 1 RTT 完成 TCP 连接建立；
2. 再用 1 RTT 发送应用请求并收到响应。

因此

$$T_{TCP}=2RTT=16\ ms.$$

所以分别是 **8 ms，16 ms**。

## 选项判断

UDP 仅需一次请求/响应 RTT，而 TCP 还需一次建连 RTT，因此分别为 8 ms 与 16 ms，故选 $\boxed{B}$。

## Verification

如果 TCP 也只算 1 RTT，就等于假设应用请求在连接建立之前已经可以按普通 TCP 数据语义发送；题目未给 TCP Fast Open 等扩展，因此经典 408 模型下不能这样合并。

## Compression

短请求 RTT 题 → **先画 transport setup 是否存在，再画应用 request/response** → UDP 直接 1 RTT；新 TCP 连接通常 setup 1 RTT + service 1 RTT。

## 易错边界

“TCP 多 1 RTT”只针对这里的新连接、忽略发送时间的简化模型。已有持久连接时，TCP 不再重复支付建连 RTT。
