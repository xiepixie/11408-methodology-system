# 408-2025-Q22

> 原题：[[../2025 年全国硕士研究生招生考试#22|Q22]]

## Model Anchor

- Topic：[[../../../../30_408/20_计算机组成原理/80_总线与IO硬件/README|CO-08 中断硬件路径]]。
- 题目信号：判断“外部中断请求”的触发源。
- 第一动作：先区分 **异步外部事件** 与 **当前指令同步产生的异常/陷阱**。

## 解题链

- **A DMA 传送结束：** DMA 控制器完成一批数据搬运后可置完成状态并向 CPU 发出 IRQ，属于典型外部中断来源。
- B 总线事务结束：这是互连/控制器内部的一次事务完成，不等于必须向 CPU 产生外部中断请求。
- C 页故障处理结束：页故障本身是由当前访存触发的同步异常；其软件处理结束也不是新的外部中断源。
- D 执行断点指令：由当前指令主动触发，属于同步异常/陷阱，而非外部中断。

**答案：A。**

## 选项判断

只有 DMA 批量传送结束是典型外部中断来源；总线事务完成不是必然 CPU 中断，页故障和断点指令则属于同步异常，因此选 $\boxed{A}$。

## Verification

问“如果 CPU 当前换成执行另一条完全无关的指令，这个事件还会不会独立到来？”DMA/设备完成仍可能异步发生；断点和页故障则依赖当前正在执行的指令/访存。这正好区分 external interrupt 与 synchronous exception。

## Compression

外部中断判断 → **看事件是否由 CPU 当前指令之外的设备/控制器异步提出 IRQ** → DMA completion 是典型例子。

## 易错边界

`DREQ`、DMA 完成、`IRQ` 是不同事件：设备先请求 DMAC 搬运，真正完成后控制器才可能用 IRQ 通知 CPU。
