# 408-2025-Q18

> 原题：[[../2025 年全国硕士研究生招生考试#18|Q18]]

## Model Anchor

- Owner：[[../../../../30_408/20_计算机组成原理/90_做题规则/README|计组性能工具箱]]，并调用 CO-03/04/06 的局部成本。
- 题目信号：同时出现 CPI、时钟周期、Cache。
- 第一动作：先守住完整成本关系：`CPI` 是平均每条指令消耗的周期数，凡是会让处理器等待额外周期的事件都可能改变它。

## 解题链

- A 对：不同类型指令经过的路径、资源和等待不同，CPI 可以不同。
- **B 错：Cache 缺失会引入 miss penalty / stall，因此程序平均 CPI 通常与 Cache 缺失率有关。**
- C 对：单周期 CPU 一条指令必须在一个时钟周期内走完，所以时钟周期不能短于最慢合法指令路径。
- D 对：理想流水线中时钟周期至少覆盖最慢流水段（再加流水寄存器等题设若计入的开销）。

**答案：B。**

## 选项判断

把 CPI 视为包含流水停顿与 Cache 等动态代价后的平均周期数，正确选项为 $\boxed{B}$。

## Verification

若 Cache miss rate 从 0 变成非零而 miss 要额外等待很多周期，程序总执行周期显然增加；若 IC 不变，这些额外周期最终就会体现在平均 CPI 中。因此“无关”不可能成立。

## Compression

性能判断题 → **任何局部延迟先问会不会增加 stall / cycle，再看它进入 CPI 还是 $T_{clk}$** → Cache miss 典型进入 CPI 的等待项。

## 易错边界

CPI 与时钟周期是两个不同坐标：前者数“每条指令几个周期”，后者数“一个周期多长”。程序时间必须回到 $IC\times CPI\times T_{clk}$。
