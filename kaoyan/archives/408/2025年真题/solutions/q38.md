# 408-2025-Q38

> 原题：[[../2025 年全国硕士研究生招生考试#38|Q38]]

## Model Anchor

- Topic：NET-06 TCP byte state + NET-07 slow start；接口为 NET-B04 `flow control × congestion control`。
- 题目信号：同时给 `ack_seq`、`rcvwnd`、`cwnd`、`ssthresh`、MSS。
- 第一动作：绝不能只拿某一个 window 做除法。先更新 ACK 后的**已确认边界**和 `cwnd`，再计算：

$$
W_{usable}=\max\{0,\min(rwnd,cwnd)-FlightSize\}.
$$

## 解题链

$t_0$ 时甲已发送：

- `seq=2001`，1000 B，即字节 2001~3000；
- `seq=3001`，1000 B，即字节 3001~4000。

$t_1$ 收到：

```text
ack_seq = 3001
rcvwnd = 4000 B
```

`ack_seq=3001` 表示乙下一期待字节是 3001，因此第一段已经确认，第二段仍有 1000 B 在途：

$$FlightSize=1000\ B.$$

原来

$$cwnd=2000\ B<ssthresh=8000\ B,$$

处于 slow start。该 ACK 新确认了一个 MSS，所以教材模型下：

$$cwnd=2000+1000=3000\ B.$$

接收窗口为 4000 B，因此当前有效发送上限：

$$
\min(cwnd,rwnd)=\min(3000,4000)=3000\ B.
$$

扣除仍在途的 1000 B：

$$
W_{usable}=3000-1000=2000\ B.
$$

每段按 MSS=1000 B 发送，所以还能继续发送

$$\frac{2000}{1000}=2$$

个 TCP 段。

## 选项判断

按 `min(cwnd,rwnd)-FlightSize` 计算新增可发送量为 2000 B，即 2 MSS，故选 $\boxed{A}$。

## Verification

若错误地得到 3 段，通常是把 `min(rwnd,cwnd)=3000 B` 直接当“还能发 3000 B”，漏掉了第二个 1000 B segment 仍在 flight。发送窗口约束的是**总在途量**，不是仅限制“新发送量”。

## Compression

TCP 窗口综合题 → **ACK 推 confirmed boundary -> 更新 cwnd -> effective cap=min(rwnd,cwnd) -> 减 FlightSize -> 除 MSS**。

## 易错边界

`rwnd` 是接收端容量，`cwnd` 是发送端对网络容量的估计；它们共同限制实际发送，但更新 Owner 不同。`ack_seq` 又是 byte 序号，不是“确认了第几个报文段”。
