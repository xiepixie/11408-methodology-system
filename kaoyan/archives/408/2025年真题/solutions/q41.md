# 408-2025-Q41

> 原题：[[../2025 年全国硕士研究生招生考试#41（本题 13 分）|Q41]]

## Model Anchor

- Rules：数据结构算法大题的“**先写可证正确的暴力基线，再寻找可复用状态**”。
- 题目信号：对每个 `A[i]` 都要在后缀 `A[i..n-1]` 中选一个 `A[j]`，目标函数是乘积最大。
- 第一动作：先问：为了回答固定 `i`，真的需要知道整个后缀吗？

固定 `A[i]` 后，函数

$$f(x)=A[i]\cdot x$$

对 $x$ 是单调的：`A[i]>0` 时取后缀最大值，`A[i]<0` 时取后缀最小值，`A[i]=0` 时结果为 0。于是整个后缀可以压缩为两个摘要：

$$suffixMin(i),\quad suffixMax(i).$$

这就是从 $O(n^2)$ 暴力枚举到 $O(n)$ 扫描的关键状态复用。

## Problem Representation

暴力基线：

```text
for each i:
    scan j=i..n-1
    find max(A[i]*A[j])
```

重复工作在于相邻两个 `i` 的搜索区间高度重叠。反向扫描时有递推：

$$
max_i=\max(A[i],max_{i+1}),\qquad
min_i=\min(A[i],min_{i+1}).
$$

### 循环不变量

处理下标 `i` 时：

> `mn` 与 `mx` 分别等于当前后缀 `A[i..n-1]` 的最小值和最大值。

因此

$$
res[i]=\max(A[i]\cdot mn,\ A[i]\cdot mx).
$$

直接取两者最大值比按符号分支更短，也自然覆盖 `A[i]=0`。

## Decision Points

- 对固定 `A[i]`，目标 $A[i]\cdot A[j]$ 关于候选值 `A[j]` 是线性的，因此最优值只可能出现在当前后缀的最小值或最大值，不需要保留整个后缀。
- 题目查询的是每个位置的**后缀**，所以从右向左扫描能让 `suffixMin/suffixMax` 用 $O(1)$ 状态递推；从左向右则无法直接得到尚未访问部分的摘要。
- `res[]` 是题目要求的输出，不计入额外辅助空间；真正新增状态只有 `mn/mx/p1/p2` 等常数个变量。

## Solution Chain

### (1) 基本设计思想

从右向左扫描数组，维护当前后缀的最小值 `mn` 和最大值 `mx`。扫描到 `A[i]` 时先把它纳入这两个摘要，再用 `A[i]` 分别与 `mn`、`mx` 相乘，取较大者作为 `res[i]`。

### (2) C 语言实现

```c
void calMulMax(int A[], int res[], int n)
{
    if (n <= 0) return;

    int mn = A[n - 1];
    int mx = A[n - 1];
    res[n - 1] = A[n - 1] * A[n - 1];

    for (int i = n - 2; i >= 0; --i) {
        if (A[i] < mn) mn = A[i];
        if (A[i] > mx) mx = A[i];

        int p1 = A[i] * mn;
        int p2 = A[i] * mx;
        res[i] = (p1 > p2) ? p1 : p2;
    }
}
```

若工程实现需要考虑 `int` 乘法溢出，应把乘法提升到更宽类型；本题按题设 `int` 运算模型作答。

### (3) 复杂度

数组只反向扫描一次：

$$T(n)=O(n).$$

除输出数组 `res` 外只维护常数个变量：

$$S_{extra}(n)=O(1).$$

### Why Correct

由循环不变量，处理 `i` 时 `mn/mx` 已覆盖所有合法的 $j\in[i,n-1]$。线性函数 $A[i]x$ 在有限区间的极值必出现在最小或最大端点，因此比较 `A[i]*mn` 与 `A[i]*mx` 已覆盖最优候选，不会漏掉中间元素。

## Verification

题目样例 `A={1,4,-9,6}`：

- `i=3`：后缀 min=max=6，得 36；
- `i=2`：后缀 min=-9,max=6，得 max(81,-54)=81；
- `i=1`：min=-9,max=6，得 max(-36,24)=24；
- `i=0`：得 max(-9,6)=6。

恢复 `res={6,24,81,36}`。

## Compression

“每个 i 在后缀里求乘积最大” → **先问目标对候选值的单调性** → 后缀只保留 min/max → 反向一次扫描维护摘要。

## 易错边界

这里能压缩成两个极值，靠的是固定 `A[i]` 后乘积对 `A[j]` 是线性函数；若目标改成更复杂的二元函数，不能机械套“后缀 min/max”。
