# 408-2025-Q02

> 原题：[[../2025 年全国硕士研究生招生考试#2|Q2]]

## Model Anchor

- Topic：[[../../../../30_408/10_数据结构/02_栈队列与受限访问/README|DS02 栈、队列与受限访问]]。
- 题目信号：括号匹配 + 栈容量限制。
- 第一动作：把“栈里保存什么”说清楚——栈中只保存**尚未匹配的左括号**；因此所需容量等于扫描过程中最大的未决括号嵌套深度。

## 解题链

逐个扫描表达式，只数同时尚未闭合的左括号层数：

- A：最深可到 `( [ (`，深度 3；
- B：外层 `[`，再进入 `(`，内部 `(b+c)` 或 `(d-e)` 时最深为 3；
- C：外层 `[`，再进入 `(`，内部 `(c-d)` 或 `(f+g)` 时最深为 3；
- D：可出现

```text
[ -> ( -> [ -> (
```

即扫描到 `(d+e)` 时同时有 4 个未匹配左括号。

容量只有 3，所以 D 无法处理。

## 选项判断

由上述最大嵌套深度比较，只有 D 需要 4 个栈槽，故选 $\boxed{D}$。

## Verification

括号一旦遇到匹配的右括号就会弹栈，因此不是统计表达式里“总共有多少对括号”，而是统计任一前缀中的最大栈深。D 的四层嵌套在任何匹配发生前同时存在，确实需要第 4 个栈槽。

## Compression

括号匹配 + 固定栈容量 → **扫前缀，数最大“尚未闭合左括号数”** → 最大值超过容量即不能处理。

## 易错边界

“括号对数量”与“最大嵌套深度”不是一个量；栈容量约束的是后者。
