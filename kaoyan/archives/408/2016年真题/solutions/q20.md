# 408-2016-Q20

> 原题：[[../2016 年全国硕士研究生招生考试#20|Q20]]

## 模型锚点

- Topic：CO-03｜单周期数据通路的资源并行性与时钟合同。
- 题目信号：所有指令都必须在**一个时钟周期**内完成。
- 第一动作：先问一条最慢指令在同一周期里需要哪些数据传送/功能部件同时工作，再判断资源结构是否支持。

## 解题链

单周期处理器的一个周期必须覆盖取指、译码/读寄存器、执行、可能的数据访存、写回等必要动作。

- A 错：若内部只有一条共享单总线，同一周期中多个必要数据传送会争用同一资源，无法按单周期模型完成最慢指令；
- B 对：周期必须按最慢指令的最长组合路径设置，因此时钟周期较长、频率较低；
- C 对：一条指令在这个周期内使用由其操作码决定的一组控制信号；
- D 对：每条指令都恰占一个时钟周期，所以 CPI=1。

## 选项判断

错误的是 A，故选 $\boxed{A}$。

## 校验

若采用单总线把所有阶段串行化，就必须在不同节拍轮流占用总线，这已经变成多周期执行，与“所有指令一个周期完成”的题设矛盾。

## 压缩

```text
单周期
-> 最慢指令全部动作塞进 1 cycle
-> 资源要能并行供给
-> CPI=1，但 Tclk 由最长路径决定
```

## 易错边界

`CPI=1` 不等于“速度一定快”；单周期常以更长的时钟周期换取一条指令只用一个周期。
