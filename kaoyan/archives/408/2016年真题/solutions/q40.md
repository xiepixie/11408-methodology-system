# 408-2016-Q40

> 原题：[[../2016 年全国硕士研究生招生考试#40|Q40]]

## 模型锚点

- Topic：NET-08｜DNS 迭代解析与缓存停止条件。
- 题目信号：所有 DNS 服务器都采用**迭代查询**，问本地域名服务器 201.1.1.1 发出的最少/最多查询次数。
- 第一动作：先找两个边界：最好情况是否已缓存最终结果；最坏情况需要经过多少层委派才能到权威服务器。

## 解题链

最好情况：本地域名服务器已有 `www.abc.xyz.com` 的有效缓存记录，不需要向任何其他 DNS 服务器发查询：

$$Q_{min}=0.$$

最坏情况下缓存均无帮助，迭代解析依次需要查询：

```text
root
-> .com
-> xyz.com
-> abc.xyz.com authoritative server
```

共 4 次外部查询：

$$Q_{max}=4.$$

## 选项判断

最少 0 次、最多 4 次，故选 $\boxed{C}$。

## 校验

迭代查询中，每一级只返回下一步应去问谁，本地域名服务器必须自己继续追问；四个层级恰好对应 4 个请求。若已有最终缓存，则整条链都可跳过。

## 压缩

```text
DNS query count
-> min: final answer cached? -> 0
-> max: count delegation hops
-> root -> TLD -> domain -> authority
```

## 易错边界

不要把客户端→本地域名服务器的那次请求算进“201.1.1.1 发出”的查询次数；题目限定了计数 Owner。
