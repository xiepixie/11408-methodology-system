# 408-2016-Q13

> 原题：[[../2016 年全国硕士研究生招生考试#13|Q13]]

## 模型锚点

- Topic：CO-01｜定长整数位串与 signed/unsigned 解释。
- 题目信号：`short si=-32767` 赋给**同位宽** `unsigned short`。
- 第一动作：先固定 16 位位串，再换解释器；同位宽 signed→unsigned 不需要先猜数值符号。

## 解题链

16 位补码中：

$$-32767 \equiv 2^{16}-32767=32769 \pmod{2^{16}}.$$

因此 `si` 的机器位串为：

```text
1000 0000 0000 0001 = 0x8001
```

赋给同位宽 `unsigned short` 后，该 16 位模式对应无符号数：

$$32769.$$

## 选项判断

故选 $\boxed{D}$。

## 校验

无符号解释 `0x8001 = 0x8000+1 = 32768+1 = 32769`，与模 $2^{16}$ 推导一致。

## 压缩

```text
同位宽 signed -> unsigned
-> 位串保持/按模 2^w 转换
-> unsigned value = signed value mod 2^w
```

## 易错边界

不能把 signed 的“符号位”继续当成 unsigned 的符号；unsigned 没有独立符号位，所有位都贡献数值。
