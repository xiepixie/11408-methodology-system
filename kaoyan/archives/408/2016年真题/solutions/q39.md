# 408-2016-Q39

> 原题：[[../2016 年全国硕士研究生招生考试#39|Q39]]

## 模型锚点

- Topic：NET-04｜Same-Subnet Gate 与默认网关可达性。
- 题目信号：四台主机使用两个 `/25`，但 H1/H2 的默认网关配置与拓扑中的实际路由器接口不一致。
- 第一动作：对每一对通信先做 `destination & mask`；同子网直接二层交付，异子网才检查默认网关。

## 解题链

掩码 `255.255.255.128=/25` 把 `192.168.3.0/24` 分成：

```text
192.168.3.0/25      : .0  ~ .127
192.168.3.128/25    : .128~ .255
```

H1、H2 位于前一子网，因此彼此通信不需要默认网关，A 不会发生。

H3、H4 位于后一子网，因此彼此也可直接通信，D 不会发生。

H4 使用 `192.168.3.254` 作为默认网关，与拓扑中的 R2 接口一致，所以不能说 H2、H4 都无法访问 Internet，B 不成立。

H1 要访问另一个 `/25` 中的 H3，必须把分组交给默认网关；但 H1 配置的是 `192.168.3.1`，并非题图中可用的 R2 网关接口，所以跨子网转发失败。

## 选项判断

可能发生的是 H1 不能与 H3 正常 IP 通信，故选 $\boxed{C}$。

## 校验

把 H1→H2 与 H1→H3 对照：前者目的与 H1 同 `/25`，完全不需要 gateway；后者异网段，网关配置立刻成为必要条件。两条路径的差异正好解释选项。

## 压缩

```text
主机通信故障
-> Same-Subnet first
-> same subnet: ARP destination
-> remote subnet: ARP gateway
-> 再检查 gateway 是否真实可达
```

## 易错边界

默认网关配置错误不会破坏同一子网内的直接通信；只有跨子网流量才依赖它。
