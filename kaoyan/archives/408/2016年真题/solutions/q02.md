# 408-2016-Q02

> 原题：[[../2016 年全国硕士研究生招生考试#2|Q2]]

## Model Anchor

- Topic：DS01｜双向循环链表的不变量。
- 题目信号：删除 `p`，需要让 `p` 的直接前驱与直接后继重新互指。
- 第一动作：先写删除后的目标关系，再翻译成赋值语句：`prev.next = next`，`next.prev = prev`。

## 解题链

设：

```text
L = p->prev
R = p->next
```

删除 `p` 后必须恢复：

```text
L->next = R
R->prev = L
```

对应原指针表达式就是：

```c
p->next->prev = p->prev;
p->prev->next = p->next;
free(p);
```

循环链表是否带头结点不改变这组局部改边规则。

## 选项判断

只有 D 同时把两条跨过 `p` 的反向/正向链接接好，故选 $\boxed{D}$。

## Verification

删除后从前驱沿 `next` 应直接到后继，从后继沿 `prev` 应直接回到前驱；两条关系必须互为镜像。A/B/C 至少有一条边仍指向错误结点。

## Compression

```text
双链表删 p
-> L=p.prev, R=p.next
-> L.next=R
-> R.prev=L
-> free(p)
```

## 易错边界

不要按语句长相背代码；先写结构不变量。`p->prev->next=p->prev` 会让前驱自环，并不是删除。
