# 408-2016-Q38

> 原题：[[../2016 年全国硕士研究生招生考试#38|Q38]]

## 模型锚点

- Topic：NET-04｜NAT 后的端到端 IP 身份。
- 题目信号：H3 访问公网服务器 S，问的是 **R2 转发出去**的 IP 分组源/目的地址。
- 第一动作：先锁定观察点在 NAT 之后，再分别问：源地址是否被边界路由器改写？目的端点是否改变？

## 解题链

H3 在私网内使用 `192.168.3.x` 地址。分组到达边界 R2 后，访问 Internet 时需要把私有源 IP 改写为 R2 的公网侧接口地址。

点到点链路使用 `201.1.3.x/30`。由拓扑地址分配可知 R2 对外发送该分组的接口地址为：

$$201.1.3.10.$$

NAT 改写的是源身份；最终 Web 服务器仍是 S，因此目的 IP 仍为：

$$130.18.10.1.$$

## 选项判断

R2 发出时的源/目的 IP 为 `201.1.3.10，130.18.10.1`，故选 $\boxed{D}$。

## 校验

如果目的 IP 被改成 R1/R3 的点到点接口地址，分组的端到端目标就被破坏；路由器下一跳只影响二层/转发动作，不应替换最终 destination IP。

## 压缩

```text
NAT 观察点题
-> 先定是在 NAT 前还是 NAT 后
-> source private -> public interface
-> destination endpoint 保持不变
```

## 易错边界

next-hop IP / MAC 与最终 destination IP 是不同身份；跨路由器转发不能把“下一跳”偷换成“应用终点”。
