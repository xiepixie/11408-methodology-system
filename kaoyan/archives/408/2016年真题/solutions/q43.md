# 408-2016-Q43

> 原题：[[../2016 年全国硕士研究生招生考试#43|Q43]]

## Model Anchor

- Topic：DS11 / DS-I01｜选择问题、partition 与“只求边界不全排序”。
- 题目信号：先要求 $|n_1-n_2|$ 最小，再要求 $|S_1-S_2|$ 最大；输入全是正整数。
- 第一动作：先从目标函数推出**最优集合结构**，再问需要维护到什么有序程度；不要一看到“划分”就完整排序。

## Problem Representation

令：

$$k=\left\lfloor\frac n2\right\rfloor.$$

要让元素个数差最小，两组大小必须是：

```text
|A1| = k
|A2| = n-k
```

由于所有元素为正，要让两组和的绝对差尽可能大，应把较小的 $k$ 个元素放到一组、其余较大的元素放到另一组。

因此真正需要的不是完整次序，而是一个 rank boundary：

```text
A[0..k-1]  = k 个较小元素
A[k..n-1]  = 其余较大元素
```

## Decision Points

- 全排序是 $O(n\log n)$，但题目只需要找到第 k 个次序统计量对应的分界，排序了大量不需要的组内顺序。
- 使用 quickselect/partition：每次只递归/迭代到包含目标下标 k 的一侧，另一侧已经不影响最终分组。
- 普通枢轴 quickselect 的**期望**时间为 $O(n)$、最坏为 $O(n^2)$；若要求最坏线性可改用 deterministic selection，但 408 卷面通常以 partition 选择作为高效实现。

## Solution Chain

### (1) 设计思想

不断执行类似快速排序的 partition。设某次枢轴最终位置为 `p`：

- `p == k`：分界已经形成；
- `p < k`：只需继续处理右区间；
- `p > k`：只需继续处理左区间。

当结束时，前 k 个位置构成一组较小元素，其余构成另一组。

### (2) C 实现

```c
static int partition(int a[], int low, int high)
{
    int pivot = a[low];
    int i = low, j = high;

    while (i < j) {
        while (i < j && a[j] >= pivot) --j;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) ++i;
        a[j] = a[i];
    }
    a[i] = pivot;
    return i;
}

void splitMaxDiff(int a[], int n)
{
    int k = n / 2;          // A1 需要 k 个较小元素
    int low = 0, high = n - 1;

    while (low <= high) {
        int p = partition(a, low, high);
        if (p == k) break;
        if (p < k) low = p + 1;
        else       high = p - 1;
    }

    /* 现在 a[0..k-1] 放 A1，a[k..n-1] 放 A2 */
}
```

若题目还要求显式得到 $S_1,S_2$，再各扫描一次求和即可，仍是线性工作量。

### (3) 正确性

交换论证：若较小和那组中存在 $x$，较大和那组中存在 $y$，且 $x>y$，把 $x$ 与 $y$ 交换后，较小和那组减少 $x-y$，较大和那组增加 $x-y$，二者差值会再增大 $2(x-y)$。因此真正达到最大差值时不允许存在这种跨组逆序，最终必然是所有较小元素集中在一边、较大元素集中在另一边。

partition 只需恢复这条跨组次序，不需要组内全序。

### (4) 复杂度

普通 quickselect：

$$\boxed{E[T(n)]=O(n)},\qquad \boxed{S_{extra}=O(1)}$$

（使用上述迭代版本）。最坏枢轴序列下时间可退化为 $O(n^2)$。

## Verification

取 `A={1,2,3,100,101}`，$k=2$。按结论分为 `{1,2}` 与 `{3,100,101}`，和差为 201。若把大组中的 3 与小组中的 2 之外更大元素交换进小组，只会让两组和更接近，不能得到更大的绝对差。

同时组大小为 2 与 3，已达到 $|n_1-n_2|=1$ 的最小可能值。

## Compression

```text
双目标划分
-> 先锁 cardinality
-> 正数 + 最大 sum gap -> 小的一半 vs 大的一半
-> 只需 order-statistic boundary
-> quickselect，不必 full sort
```

## 易错边界

- “尽可能高效”不应无条件写完整快排；只需要第 k 个秩边界。
- 普通 quickselect 的 $O(n)$ 是期望复杂度，不应把最坏 $O(n^2)$ 隐去。
