# 408-2016-Q06

> 原题：[[../2016 年全国硕士研究生招生考试#6|Q6]]

## Model Anchor

- Topic：DS07｜DFS frontier 与回溯条件。
- 题目信号：问“哪个序列不可能是 DFS”，邻接点访问次序本身没有固定顺序。
- 第一动作：不要强行套唯一 DFS 序列；逐步检查当前栈顶顶点是否还有未访问邻接点。只要还有，就不能提前回溯到祖先换分支。

## 解题链

A、B、C 都可以通过选择不同的邻接点次序得到。

看 D：

```text
V1 -> V2 -> ...
```

从 $V_2$ 出发时，图中仍有未访问邻接点 $V_5$。DFS 的深度优先不变量要求先继续深入 $V_5$，直到当前分支无法扩展才回溯。

但 D 接下来直接访问 $V_3$，相当于在 $V_2$ 仍有可扩展邻居时提前返回到上层，因此不可能由 DFS 产生。

## 选项判断

不可能的序列是 D，故选 $\boxed{D}$。

## Verification

验证“不可能”只需找到第一次违反 DFS 栈规则的位置：D 在 `V1,V2` 后已经违反，无需把整棵 DFS 树全部画完。

## Compression

```text
判断 DFS 序列
-> 维护递归栈/当前路径
-> 栈顶还有未访问邻居：必须继续深入
-> 只有无路可走才允许回溯
```

## 易错边界

DFS 不规定“总要访问编号最小的邻居”；真正稳定的是**深度优先与回溯条件**，不是邻接点的固定次序。
