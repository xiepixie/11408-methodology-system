# 408-2016-Q01

> 原题：[[../2016 年全国硕士研究生招生考试#1|Q1]]

## Model Anchor

- Topic：DS01｜单链表表示与局部改边。
- 题目信号：**已知新结点地址 + 指定逻辑插入位置**，问链接字段而不是结点存放地址。
- 第一动作：把“`a -> e`”改写成插入后的局部不变量 `a -> f -> e`，只追三个 `next` 字段。

## 解题链

`f` 存放在 `1014H`，且逻辑上位于 `a` 与 `e` 之间，因此插入后：

```text
a.next = addr(f) = 1014H
f.next = addr(e)
```

由题图原链可读出 `e` 位于 `1010H`，且 `e` 原来的后继地址为 `1004H`，所以：

```text
a.next = 1014H
e.next = 1004H
f.next = 1010H
```

## 选项判断

三者链接地址依次为 `1014H，1004H，1010H`，故选 $\boxed{D}$。

## Verification

从 `a` 沿 `next` 走应依次到 `f`、`e`。若 `a.next` 不是 `1014H` 或 `f.next` 不是 `1010H`，新结点就不会处在二者之间；而 `e.next` 不应因前驱插入而改变。

## Compression

```text
单链表中间插入
-> 先写 a -> f -> e
-> a.next=addr(f), f.next=addr(e)
-> 其余旧边不动
```

## 易错边界

“结点地址”和“结点中的链接地址”不是一个对象；题目问的是 `next` 字段内容。
