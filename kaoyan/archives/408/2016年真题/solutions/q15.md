# 408-2016-Q15

> 原题：[[../2016 年全国硕士研究生招生考试#15|Q15]]

## 模型锚点

- Topic：CO-06｜Cache 块局部性与 miss rate。
- 题目信号：连续 `int` 数组、16 B block、每个元素执行一次读改写。
- 第一动作：先把“一个块能装几个数组元素”和“每个元素产生几次 Cache 访问”分开计数。

## 解题链

`int=4B`，Cache block 为 16 B，因此一块容纳：

$$16/4=4$$

个连续 `a[k]`。

语句：

```c
a[k] = a[k] + 32;
```

对 Cache 而言至少包含：

```text
load a[k]
store a[k]
```

Cache 初始为空。对每个新块，第一次读第一个元素时发生 1 次 compulsory miss，整块被装入；随后该块内 4 个元素的其余 load/store 都命中。因此每块对应：

$$1\text{ miss}/(4\times2\text{ accesses})=1/8=12.5\%.$$

顺序访问不会在复用同一块前被自身冲突淘汰，所以该比例稳定。

## 选项判断

故选 $\boxed{C}$。

## 校验

1000 个整数共 250 个 16 B 块；总 Cache 访问约 2000 次，miss 约 250 次：

$$250/2000=12.5\%.$$

## 压缩

```text
连续数组 Cache 题
-> elements/block
-> accesses/element
-> first touch per block miss
-> miss rate = misses / actual Cache accesses
```

## 易错边界

不能把“每 4 个元素一次 miss”直接写成 25%；题目这条读改写语句对每个元素有读和写两次 Cache 访问。
