# 408-2016-Q14

> 原题：[[../2016 年全国硕士研究生招生考试#14|Q14]]

## 模型锚点

- Topic：CO-01｜字节序与地址—字节映射。
- 题目信号：8 字节机器数 + 小端 + 给定起始字节地址。
- 第一动作：把机器数拆成 8 个字节，按“低有效字节放低地址”列地址表。

## 解题链

机器数：

```text
11 22 33 44 55 66 77 88 H
```

低有效字节是 `88H`。小端存储为：

| 地址 | 内容 |
|---|---|
| 8040H | 88H |
| 8041H | 77H |
| 8042H | 66H |
| 8043H | 55H |
| 8044H | 44H |
| 8045H | 33H |
| 8046H | 22H |
| 8047H | 11H |

所以 `0000 8046H` 中是 `22H`。

## 选项判断

故选 $\boxed{A}$。

## 校验

从 8040H 到 8047H 共 8 个连续字节；把表中内容按高地址到低地址重新拼接，恰好恢复 `1122334455667788H`。

## 压缩

```text
little endian
-> LSB byte at lowest address
-> 先画 address-byte table
```

## 易错边界

字节序改变的是**内存中字节排列**，不改变寄存器里该 64 位数的数学/位串整体含义。
