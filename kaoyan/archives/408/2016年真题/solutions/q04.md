# 408-2016-Q04

> 原题：[[../2016 年全国硕士研究生招生考试#4|Q4]]

## Model Anchor

- Topic：DS01｜特殊矩阵压缩存储。
- 题目信号：三对角矩阵 + 按行优先 + 一维数组从 0 编号。
- 第一动作：先数目标元素之前真正被存储的三对角元素，而不是套完整矩阵地址公式。

## 解题链

100 阶三对角矩阵中：

- 第 1 行存 2 个元素；
- 第 2～99 行各存 3 个；
- 第 100 行存 2 个。

目标是 $m_{30,30}$。在它之前：

1. 第 1 行有 2 个；
2. 第 2～29 行共 $28\times3=84$ 个；
3. 第 30 行先存 $m_{30,29}$ 这 1 个。

因此前面共有：

$$2+84+1=87$$

个元素。数组 N 从 0 开始编号，所以 $m_{30,30}$ 的下标正是 87。

## 选项判断

故选 $\boxed{B}$。

## Verification

第 30 行的三个压缩位置依次应为下标 `86,87,88`，分别对应 $m_{30,29},m_{30,30},m_{30,31}$，目标位于中间，和计数一致。

## Compression

```text
带状矩阵压缩
-> 先数目标前已存元素数
-> 0-based 下标 = 前置元素个数
```

## 易错边界

这里的行列下标从 1 开始，而压缩数组下标从 0 开始；两个编号体系不能混成一个。
