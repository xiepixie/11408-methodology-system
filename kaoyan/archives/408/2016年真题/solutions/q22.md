# 408-2016-Q22

> 原题：[[../2016 年全国硕士研究生招生考试#22|Q22]]

## 模型锚点

- Topic：CO-08 / X-B01｜同步异常与外部中断的事件来源。
- 题目信号：选项混合缺页、除零、DMA 完成、存储保护错。
- 第一动作：问事件是否由**当前指令执行/访存同步触发**；同步于当前指令的是异常，独立外设完成请求才是外部中断。

## 解题链

- 缺页：由当前访存的地址翻译发现页面不驻留，是同步异常；
- 整数除 0：由当前算术指令触发，是同步异常；
- DMA 传送结束：由外部 DMA/I/O 控制器异步通知 CPU，是中断；
- 存储保护错：由当前访存权限检查触发，是同步异常。

## 选项判断

A 把缺页误归为中断，因此错误项是 $\boxed{A}$。

## 校验

若同一条访存指令重复执行且页面状态未改变，缺页会在该指令上再次出现；这种“与当前指令位置绑定”的可重现性正符合同步异常，而不是独立外部请求。

## 压缩

```text
异常 vs 中断
-> 是否由当前 instruction/event 同步触发？
-> page fault / div0 / protection = exception
-> DMA completion = interrupt
```

## 易错边界

中文教材有时把异常称“内中断”，但题目已经明确把 exception 与 external interrupt 分开；作答必须服从当前分类合同。
