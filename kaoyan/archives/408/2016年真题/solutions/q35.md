# 408-2016-Q35

> 原题：[[../2016 年全国硕士研究生招生考试#35|Q35]]

## Model Anchor

- Topic：NET-02｜Hub 冲突域与 Switch 单播转发。
- 题目信号：先有 H2→H4 数据帧，再让 H4 **立即**回 ACK，问哪些主机“从物理层上能收到”。
- 第一动作：先用前一帧更新交换机 MAC 学习状态，再逐段判断 ACK 在 Hub 与 Switch 两侧的传播范围。

## 解题链

前一帧 H2→H4 经过交换机时，交换机会学习：

```text
MAC(H2) -> H2 所在端口
```

H4 的确认帧从其所在 Hub 发出。Hub 只做物理层复制，因此同一 Hub 上的 H3 也会收到这串比特；交换机也收到帧。

交换机查到 H2 的 MAC 已有已知端口，于是只向 H2 所在端口单播转发，不向其他交换端口泛洪。

因此除 H4 自己外，能在物理层收到 ACK 的主机是 H2、H3。

## 选项判断

故选 $\boxed{D}$。

## Verification

若交换机未学习 H2，未知单播会泛洪，范围会更大；题目特意给出“先 H2→H4，再 H4 立即 ACK”，就是在保证 H2 映射已经被学习。

## Compression

```text
二层回包题
-> 先处理前序帧的 MAC learning
-> Hub: repeat to all ports
-> Switch known unicast: only learned port
```

## 易错边界

“冲突域”和“谁能物理收到比特”都受 Hub/Switch 边界影响；交换机不会像 Hub 一样无条件复制已知单播帧。
