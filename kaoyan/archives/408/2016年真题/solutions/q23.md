# 408-2016-Q23

> 原题：[[../2016 年全国硕士研究生招生考试#23|Q23]]

## Model Anchor

- Topic：OS-00｜批处理系统与多道程序设计。
- 题目信号：三个判断分别问交互性、历史类型和 CPU/I/O 重叠机制。
- 第一动作：把“批处理”“多道”“分时”三个层次分开；不要因为多道程序能并发推进就误判为用户可直接交互。

## 解题链

I 错：批处理作业提交后通常按作业控制自动运行，不提供多个用户与运行中作业的直接交互；强交互是分时系统的重要目标。

II 对：批处理经历了单道批处理与多道批处理等阶段。

III 对：多道程序把多个作业同时装入内存，当一个作业等待 I/O 时，CPU 可切换到其他就绪作业；中断使设备完成后能异步通知 CPU，从而支持 CPU 与 I/O 重叠。

## 选项判断

正确的是 II、III，故选 $\boxed{A}$。

## Verification

若 I 成立，批处理就已经具备分时系统最核心的直接交互特征，两种系统的历史边界会被抹掉；这与模型不符。

## Compression

```text
批处理
-> 自动批量执行，不强调直接交互
多道批处理
-> 多作业驻留 + 中断
-> CPU/I-O overlap
```

## 易错边界

“多个作业并发推进”是系统内部执行并发，不等于“多个用户能够直接交互”。
