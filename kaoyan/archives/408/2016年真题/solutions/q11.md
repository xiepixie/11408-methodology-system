# 408-2016-Q11

> 原题：[[../2016 年全国硕士研究生招生考试#11|Q11]]

## 模型锚点

- Topic：DS12｜外部排序与 I/O 成本。
- 题目信号：待排文件达到 **10 TB**，显然不能整体驻留主存。
- 第一动作：先判断数据是否能一次放入内存；不能时立即切到“初始归并段 + 多路归并”的外部排序模型。

## 解题链

希尔、堆、快速排序通常讨论数据主体可随机访问于内存中的内部排序。

10 TB 文件远超普通主存容量，排序的主成本来自磁盘/外存数据交换。外部排序需要：

```text
分批读入内存生成有序 run
-> run 写回外存
-> 多路归并减少 I/O 趟数
```

归并排序天然适合这种顺序读写与分段合并。

## 选项判断

应采用外部归并排序，故选 $\boxed{D}$。

## 校验

如果算法要求整个 10 TB 数组随机驻留主存，它在题设规模下就已经违反存储边界；归并只需有限缓冲区并能顺序处理外存数据。

## 压缩

```text
数据远大于内存
-> 外部排序
-> run generation + multiway merge
```

## 易错边界

“快速排序平均很快”讨论的是内存计算成本；外部排序首先受 I/O 模型支配，不能只比较内部比较次数。
