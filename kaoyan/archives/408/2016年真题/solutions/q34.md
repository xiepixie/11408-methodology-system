# 408-2016-Q34

> 原题：[[../2016 年全国硕士研究生招生考试#34|Q34]]

## Model Anchor

- Topic：NET-01｜信道容量与单位转换。
- 题目信号：带宽 `8 kHz`、信噪比 `30 dB`、实际速率为理论上限 50%。
- 第一动作：先把 dB 还原成线性 SNR，再用 Shannon 上限；最后才乘 50%。

## 解题链

信噪比：

$$10\log_{10}SNR=30\Rightarrow SNR=10^3=1000.$$

Shannon 容量：

$$C=B\log_2(1+SNR).$$

代入 $B=8\text{ kHz}$：

$$C\approx8\times\log_2(1001)\text{ kb/s}\approx79.7\text{ kb/s}.$$

实际传输速率约为理论值的 50%：

$$R\approx39.9\text{ kb/s}\approx40\text{ kb/s}.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

30 dB 对应约 1000 倍功率比，$\log_2 1000\approx10$，所以理论容量应约为 $8\times10=80$ kb/s；取一半约 40 kb/s，数量级吻合。

## Compression

```text
Shannon 题
-> dB -> linear SNR
-> C=B log2(1+SNR)
-> 再乘实际利用比例
```

## 易错边界

`30 dB` 不是把 SNR 直接代成 30；dB 是对数量，必须先还原为线性比值。
