# 408-2016-Q21

> 原题：[[../2016 年全国硕士研究生招生考试#21|Q21]]

## Model Anchor

- Topic：CO-08｜总线吞吐、信号完整性与事务组织。
- 题目信号：四个选项都用“某设计一定更快/更省/利用率更高”的口吻描述总线。
- 第一动作：先区分**线数、每拍并行位数、可工作频率、协议占用率**，对绝对化性能命题优先找边界。

## 解题链

- A 错：并行总线每拍可传多位，但线间偏斜、串扰和同步难度会限制高频；高速串行链路完全可能通过更高符号率获得更高吞吐，因此“并行一定比串行快”不成立；
- B 对：地址/数据等信号线在不同时刻复用，可减少物理引脚/线路数量；
- C 对：突发传输把一次地址/控制开销摊到多个连续数据拍上，可提高有效传输率；
- D 对：分离事务把请求和响应阶段解耦，使等待响应时总线可服务其他事务，提高利用率。

## 选项判断

错误的是 A，故选 $\boxed{A}$。

## Verification

PCIe 等高速串行互连本身就是最小反例：串行不等于低吞吐。决定性能的是完整 signaling/protocol contract，而不是“串/并”一个标签。

## Compression

```text
总线性能绝对命题
-> 分开 width / frequency / protocol efficiency
-> 并行位宽大 ≠ 一定吞吐更高
```

## 易错边界

“并行一次传更多 bit”只是局部事实，不能越级推出在任意频率、距离和电气约束下总速度都更快。
