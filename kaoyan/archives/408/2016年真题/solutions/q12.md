# 408-2016-Q12

> 原题：[[../2016 年全国硕士研究生招生考试#12|Q12]]

## 模型锚点

- Topic：CO-02｜从源语言到机器目标代码的工具链。
- 题目信号：输入是**高级语言源程序**，输出是**机器目标代码文件**。
- 第一动作：按输入语言与是否生成目标文件区分 compiler / assembler / interpreter / linker。

## 解题链

- 编译程序：把高级语言源程序翻译为目标代码/目标文件；
- 汇编程序：输入是汇编语言，不是高级语言；
- 解释程序：通常边翻译边执行，不以生成完整机器目标文件为主要结果；
- 链接程序：把已有目标文件/库进一步解析组合为可执行映像，不负责把高级语言语句翻译成机器指令。

## 选项判断

题面定义的角色是编译程序，故选 $\boxed{C}$。

## 校验

把流水线写成 `source -> compiler -> object -> linker -> executable`，题目问的正是 source 到 object 的这一段。

## 压缩

```text
高级语言 source -> machine object
= compiler
assembly source -> machine object
= assembler
```

## 易错边界

编译与链接是两个阶段；“最终都参与生成可执行程序”不等于它们拥有同一输入/输出合同。
