# 408-2016-Q09

> 原题：[[../2016 年全国硕士研究生招生考试#9|Q9]]

## Model Anchor

- Topic：DS09｜有序数组查找的成本随目标位置变化。
- 题目信号：自定义算法每次让 `k += 3`，而折半查找复杂度基本不依赖目标在数组前、中、后的位置。
- 第一动作：先看该线性跳跃扫描什么时候会提前停止，再与折半查找约 $\log_2 n$ 次比较的稳定成本对照。

## 解题链

该算法从数组开头出发，每次跨 3 个元素。当第一次到达 `A[k] >= x` 时，再检查 `k,k-1,k-2`。

若 $x$ 接近数组开头，只需很少几次 `A[k] < x` 判断就能停止，比较次数可能小于折半查找的约 $\log_2 n$。

若 $x$ 位于中部或尾部，前向跳跃需要扫描 $\Theta(n)$ 个位置，明显不占优势；若 $x$ 不存在，也可能一直扫描到很后面。

## 选项判断

只有“$x$ 接近数组开头”存在更少比较次数的可能，故选 $\boxed{B}$。

## Verification

例如 $x=A[0]$ 时，第一次 `A[0] < x` 就为假，随后立即比较 `A[0]` 成功；而 $n>1000$ 的折半查找通常需要多层区间折半。

## Compression

```text
从头单向扫描 vs binary search
-> 单向法成本取决于目标位置
-> 只有目标非常靠前时可能赢
```

## 易错边界

“有可能更少”问的是存在情形，不是平均复杂度更优；该算法总体并没有优于折半查找。
