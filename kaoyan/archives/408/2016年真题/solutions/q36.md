# 408-2016-Q36

> 原题：[[../2016 年全国硕士研究生招生考试#36|Q36]]

## 模型锚点

- Topic：NET-02｜CSMA/CD 最小帧与往返碰撞检测预算。
- 题目信号：100Base-T Hub + 最短帧 64 B + Hub 再生延时 + 传播速度，问最大距离。
- 第一动作：先把 64 B 换成最短发送时间，再把它解释为**最坏往返碰撞检测窗口**，最后从单程预算中扣除 Hub 延时。

## 解题链

100 Mb/s 以太网发送最短 64 B 帧所需：

$$T_f=\frac{64\times8}{100\times10^6}=5.12\ \mu s.$$

为了让发送端在发送完最短帧前仍能检测到最远端碰撞，单程“线路传播 + Hub 再生”预算是：

$$T_{one}=5.12/2=2.56\ \mu s.$$

Hub 已占用：

$$1.535\ \mu s,$$

因此留给线路单程传播的时间：

$$2.56-1.535=1.025\ \mu s.$$

传播速度为 $200\text{ m}/\mu s$：

$$d=1.025\times200=205\text{ m}.$$

## 选项判断

故选 $\boxed{B}$。

## 校验

205 m 的单程线路传播时延正好为 1.025 μs；加 Hub 延时得 2.56 μs，往返恰为 5.12 μs，等于最短帧发送时间，达到碰撞检测极限边界。

## 压缩

```text
CSMA/CD 最大距离
-> min frame transmission time
-> /2 得单程碰撞预算
-> 扣设备延迟
-> × propagation speed
```

## 易错边界

不能把 Hub 延时当成额外可用传播时间；它与电缆传播共同消耗同一个 round-trip timing budget。
