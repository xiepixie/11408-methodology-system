# 408-2016-Q33

> 原题：[[../2016 年全国硕士研究生招生考试#33|Q33]]

## Model Anchor

- Topic：NET-02 / NET-04｜网络设备的最高功能层。
- 题目信号：Router、Switch、Hub 同时出现，问各自“实现的最高层”。
- 第一动作：按它们处理的最高层对象判断：IP packet、MAC frame、raw bit。

## 解题链

- R1 是路由器，根据 IP 网络层信息转发，最高到 OSI 第 3 层；
- Switch 是以太网交换机，根据 MAC 地址转发帧，最高到第 2 层；
- Hub 本质是多端口中继器，只再生比特流，位于第 1 层。

因此：

$$3,2,1.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

问“最高层”时，下层功能默认也包含在设备实现中；路由器当然也要收发帧和比特，但它能进一步解释 IP，因此最高层仍是 3。

## Compression

```text
Router -> IP -> L3
Switch -> MAC frame -> L2
Hub -> bit -> L1
```

## 易错边界

不要按设备外观看层次；稳定判据是它为了完成核心转发决策必须解释到哪一层的协议对象。
