# 408-2016-Q37

> 原题：[[../2016 年全国硕士研究生招生考试#37|Q37]]

## 模型锚点

- Topic：NET-05｜RIP 距离向量的逐事件更新与慢收敛。
- 题目信号：R3 刚检测到网络不可达，**只向 R2 通告一次**；其他路由器仍可能保留旧状态。
- 第一动作：画当前事件时间线，不要直接跳到最终收敛表；先更新“经 R3 的候选”，再比较 R2 仍知道的其他候选。

## 解题链

R3 检测到目标网络不可达后，把相应 RIP 距离通告为 16。

R2 收到这一次更新后，经 R3 的路径失效。但题目只发生了一次 R3→R2 通告，此时 R1 还保留旧路由，仍向 R2 表示自己到目标网络的距离为 2。

于是 R2 计算经 R1 的候选：

$$1+2=3.$$

并选择该候选作为当前路由。

## 选项判断

R2 更新后的距离为 3，故选 $\boxed{B}$。

## 校验

若直接答 16，就等于把“最终坏消息已经传播到所有节点”偷换成当前仅一次更新后的瞬时状态；这正是距离向量协议慢收敛问题的典型陷阱。

## 压缩

```text
RIP transient update
-> 按事件推进，不看最终表
-> 失效来自邻居的候选
-> 其他邻居旧候选仍可能存在
-> 重新取 min(cost-to-neighbor + advertised metric)
```

## 易错边界

“R3 已知道不可达”不等于“R1、R2 同时知道不可达”；分布式路由状态只能沿通告逐步传播。
