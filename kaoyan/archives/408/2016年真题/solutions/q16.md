# 408-2016-Q16

> 原题：[[../2016 年全国硕士研究生招生考试#16|Q16]]

## Model Anchor

- Topic：CO-05｜主存芯片的字扩展与位扩展。
- 题目信号：总存储空间中只有 RAM 区需要 SRAM 芯片，且芯片规格是 `8K × 4 bit`。
- 第一动作：先算 RAM 总字节数，再把芯片容量换成字节；不要把地址范围和数据位宽揉成一次除法。

## 解题链

ROM 地址范围：

$$4000H\sim5FFFH$$

大小为：

$$5FFFH-4000H+1=2000H=8\text{ KB}.$$

整个存储器 64 KB，所以 RAM 容量：

$$64-8=56\text{ KB}.$$

一片 SRAM：

$$8K\times4\text{ bit}=32K\text{ bit}=4\text{ KB}.$$

因此所需芯片数：

$$56/4=14.$$

也可理解为：先用两片并联做成 `8K×8 bit=8KB`，再做 7 组字扩展，共 14 片。

## 选项判断

故选 $\boxed{C}$。

## Verification

14 片总数据容量为 $14\times4KB=56KB$，恰好覆盖除 ROM 外的全部 RAM 地址空间。

## Compression

```text
memory chip 题
-> 先圈真正要由该芯片覆盖的地址容量
-> 再拆位扩展 × 字扩展
```

## 易错边界

`8K×4 bit` 不是 8 KB；4 bit 只是每个存储字的位宽，一片总容量只有 4 KB。
