# 408-2016-Q31

> 原题：[[../2016 年全国硕士研究生招生考试#31|Q31]]

## 模型锚点

- Topic：OS-05｜SPOOLing 的 Owner 与数据路径。
- 题目信号：选项分别问外存、多道程序、独占设备虚拟共享、谁控制 spool↔device 传送。
- 第一动作：把路径拆成 `user job -> spool file -> OS spooler/device -> physical device`，再判断每段由谁拥有。

## 解题链

SPOOLing 用磁盘上的输入井/输出井缓冲低速独占设备的数据，因此需要外存支持；为了让多个作业和设备传送重叠，也依赖多道程序设计。

它的核心价值是把一台物理独占设备包装成多个作业可提交请求的逻辑共享设备。

但用户作业只提交逻辑 I/O 请求，真正负责输入/输出井与物理设备之间搬运的是 OS 的 SPOOLing 进程/设备管理路径，而不是普通用户作业自己控制设备。

## 选项判断

D 的 Owner 归属错误，故选 $\boxed{D}$。

## 校验

如果由每个用户作业直接控制物理独占设备，就无法由 OS 统一排队和串行化输出，请求也就没有被 SPOOLing 虚拟成共享服务。

## 压缩

```text
SPOOLing
-> disk spool queue
-> OS controls physical device
-> users submit logical requests
-> exclusive device appears shareable
```

## 易错边界

“用户作业产生输出数据”不等于“用户作业拥有物理设备控制权”；数据内容 Owner 与设备调度 Owner 必须分开。
