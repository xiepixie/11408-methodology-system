# 408-2016-Q17

> 原题：[[../2016 年全国硕士研究生招生考试#17|Q17]]

## Model Anchor

- Topic：CO-02｜寻址方式与 EA 生成。
- 题目信号：题目明确给出“**先变址、后间址**”，顺序本身就是运算合同。
- 第一动作：把每一层都写成“得到地址”还是“再用地址访存取下一地址”，不要只凭括号外观猜答案。

## 解题链

先变址：

$$T=(I)+D,$$

其中 $(I)$ 表示变址寄存器 I 的内容，$T$ 只是一个中间地址。

再间址：把 $T$ 作为内存地址，取其中保存的真正有效地址：

$$EA=M[T]=M[(I)+D].$$

按题目选项的记号，即：

$$((I)+D).$$

## 选项判断

只有 C 表达“先加变址寄存器，再做一次间接访存”，故选 $\boxed{C}$。

## Verification

若去掉最后一次间址，得到的只是 $(I)+D$，对应 B；这恰好说明 C 比 B 多出的那层括号承担的是“address-of-address”解引用。

## Compression

```text
复合寻址
-> 按题面顺序逐层写 EA
-> 先变址：T=(I)+D
-> 后间址：EA=M[T]
```

## 易错边界

`(I)` 是“寄存器 I 的内容”，而 `M[(I)+D]` 才是“用中间地址访问内存后得到的有效地址”。
