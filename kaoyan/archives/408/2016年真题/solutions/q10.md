# 408-2016-Q10

> 原题：[[../2016 年全国硕士研究生招生考试#10|Q10]]

## Model Anchor

- Topic：DS09｜B 树与 B+ 树的叶层接口。
- 题目信号：问的是“B+ 树不同于 B 树”的特征，要找**二者真正不同的结构合同**。
- 第一动作：优先检查叶层是否保存全部关键字并按序链接；不要选择两者共有的平衡/多路性质。

## 解题链

B+ 树把所有关键字最终都放在叶结点，叶结点通常按关键字顺序链接，因此可以从第一个叶结点开始沿链顺序扫描。

其余选项不是区别：

- B 树和 B+ 树结点中都含关键字/索引信息；
- 非叶根结点至少有两个分支是多路平衡树共有约束；
- 所有叶结点位于同一层也是二者的平衡性质。

## 选项判断

“支持顺序查找”是 B+ 树叶链带来的突出差异，故选 $\boxed{A}$。

## Verification

数据库范围查询之所以偏好 B+ 树，正是因为定位到区间起点后可以沿叶链顺序访问后续关键字，无需反复回到内部结点。

## Compression

```text
B+ vs B
-> 先看 leaf contract
-> all keys at leaves + leaf links
-> 支持高效顺序/范围扫描
```

## 易错边界

“所有叶子同层”不是 B+ 树独有；判断差异时要排除两者共享的不变量。
