# 408-2016-Q19

> 原题：[[../2016 年全国硕士研究生招生考试#19|Q19]]

## Model Anchor

- Topic：CO-04｜流水线 RAW 依赖与 value ready / need。
- 题目信号：无转发五段流水线，问哪对指令存在数据冒险。
- 第一动作：先写每条指令的 Read Set / Write Set；后指令读前指令尚未写回的值才形成这里的 RAW hazard。

## 解题链

各指令关键集合：

```text
I1: W={R1}, R={R2,R3}
I2: W={R5}, R={R2,R4}
I3: W={R4}, R={R5,R3}
I4: W={R5}, R={R2,R6}
```

I2 产生 `R5`，紧随其后的 I3 需要读取 `R5`：

```text
I2 -> R5 -> I3
```

在无转发基本五段流水线中，I3 的 ID 读寄存器早于 I2 的 WB 写回完成，因此存在 RAW 数据冒险。

## 选项判断

对应 I2 与 I3，故选 $\boxed{B}$。

## Verification

I1→I2 没有前写后读同一寄存器；I2→I4 都写 R5，但基本顺序流水线中的这组 WAW 不构成本题所问的 RAW 读后依赖；I3→I4 也没有 I4 读取 R4。

## Compression

```text
流水线数据冒险
-> 先写 Read/Write Set
-> 找 producer write -> younger consumer read
-> 再比较 ready 与 need
```

## 易错边界

“两个指令都提到同一寄存器”不自动等于数据冒险；必须先区分它是读还是写、谁依赖谁。
