# 408-2016-Q32

> 原题：[[../2016 年全国硕士研究生招生考试#32|Q32]]

## 模型锚点

- Topic：OS-03｜管程：互斥入口 + 条件同步。
- 题目信号：问“错误的是”，四项分别描述用途、语言支持、互斥入口与封装。
- 第一动作：先回到管程对象合同：**共享数据 + 操作过程 + 隐式互斥 + condition synchronization**。

## 解题链

- A 错：管程不仅实现互斥，还能借助条件变量/等待—通知实现进程同步；
- B 对：经典管程是由语言/运行时提供结构化支持的高级同步机制；
- C 对：任一时刻至多一个进程在管程内部执行，以保护共享状态；
- D 对：管程内部数据被封装，只能通过管程定义的过程访问。

## 选项判断

错误的是 A，故选 $\boxed{A}$。

## 校验

若管程“只能互斥”，那么 `wait(condition)` / `signal(condition)` 这类用于表达“条件未满足则睡眠、条件变化则通知”的接口就没有存在意义，直接与管程的同步能力矛盾。

## 压缩

```text
monitor
= encapsulated shared state
+ implicit mutual exclusion
+ condition synchronization
```

## 易错边界

互斥只回答“谁能同时进入”，同步还回答“条件未满足时谁必须等待、何时再有资格继续”。
