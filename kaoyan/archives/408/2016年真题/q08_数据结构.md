# q08_数据结构

## 📋 题目要求 (题面)

使用迪杰斯特拉（Djkstra）算法求下图中从顶点 1 到其他各顶点的最短路径，依次得到的各最短路径的目标顶点是（ ）。

- **A.** $5,2,3,4,6$
- **B.** $5,2,3,6,4$
- **C.** $5,2,4,3,6$
- **D.** $5,2,6,3,4$

![题目图示](./assets/q08_fig1.svg)



---

## 💡 答案与深度解析

**【正确答案】**：`B`

**正确答案：B**

| 3 | $∞$ | $∞$ | 7 $v_{1}$ →v2→v3 |  |  |
| 4 | $∞$ | 11 $v_{1}$ →v5→v4 | 11 $v_{1}$ →v5→v4 | $11<br>v_{1}$ →v5→v4 | 11 $v_{1}$ →v5→v4 |
| 5 | 4 $v_{1}$ →v5 |  |  |  |  |
