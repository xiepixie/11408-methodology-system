# q37_计算机网络

## 📋 题目要求 (题面)

假设 R1、R2、R3 采用 RIP 协议交换路由信息，且均已收敛。若 R3 检测到网络 201.1.2.0/25 不可达，并向 R2 通告一次新的距离向量，则 R2 更新后，其到达该网络的距离是（ ）。

- **A.** 2
- **B.** 3
- **C.** 16
- **D.** 17

---

## 💡 答案与深度解析

**【正确答案】**：`B`

**正确答案：B**
因为 R3 检测到网络 201.1.2.0/25 不可达，故将到该网络的距离设置为 16（距离为 16 表示不可达）。当 R2 从 R3 收到路由信息时，因为 R3 到该网络的距离为 16，则 R2 到该网络也不可达，但此时记录 R1 可达（由千 RIP 的特点 坏消息传得慢，R1 并没有收到 R3 发来的路由信息），R1 到该网络的距离为 2，再加上从 R2 到 Rl 的 l 就是 R2 到该网络的距离 3。
