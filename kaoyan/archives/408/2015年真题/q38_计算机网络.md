# q38_计算机网络

## 📋 题目要求 (题面)

某路由器的路由表如下表所示：

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| 169.96.40.0/23 | 176.1.1.1 | S1 |
| 169.96.40.0/25 | 176.2.2.2 | S2 |
| 169.96.40.0/27 | 176.3.3.3 | S3 |
| 0.0.0.0/0 | 176.4.4.4 | S4 |

若路由器收到一个目的地址为 169.96.40.5 的 IP 分组，则转发该 IP 分组的接口是（ ）。

- **A.** S1
- **B.** S2
- **C.** S3
- **D.** S4

---

## 💡 答案与深度解析

**【正确答案】**：`C`

**正确答案：C**
根据 最长前缀匹配，169.96.40.5 与 169.96.40.0 前 27 位匹配最长，故选 C。选项 D 为默认路由，只有当前面的所有目的网络都不能和分组的目的 IP 地址匹配时才使用。
