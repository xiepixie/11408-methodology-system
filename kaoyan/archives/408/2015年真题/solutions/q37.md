# 408-2015-Q37

> 原题：[[../2015 年全国硕士研究生招生考试#37|Q37]]

## Model Anchor

- Topic：NET02/NET04｜以太网交换机的二层 Scope。
- 题目信号：判断交换机对冲突域、广播域和网络层协议的作用。
- 第一动作：先锁最高工作层：普通以太网交换机是多端口网桥，工作在数据链路层。

## 解题链

A 正确。交换机本质上是多端口网桥，根据 MAC 地址学习和转发二层帧。

B 错。交换机的每个端口形成独立冲突域，而不是整组工作站共用一个冲突域。

C 错。普通二层交换机默认不会把每个端口切成独立广播域；广播帧仍会在同一 VLAN 内泛洪。广播域通常由路由器/L3 边界或 VLAN 划分。

D 错。不同网络层协议之间的互联需要网络层或更高层的协议处理，普通二层以太网交换机只透明转发帧。

## 选项判断

故选 $\boxed{A}$。

## Verification

用 Scope 检查：交换机能隔离 collision domain，但不天然隔离 broadcast domain。这个二维边界能同时排除 B、C。

## Compression

```text
Ethernet switch
-> multiport bridge / L2
-> each port = collision domain
-> same VLAN still one broadcast domain
-> no L3 protocol interworking
```

## 易错边界

“交换机隔离冲突域”不等于“交换机隔离广播域”。这是二层设备题最常见的 Scope 偷换。
