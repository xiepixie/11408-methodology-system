# 408-2015-Q34

> 原题：[[../2015 年全国硕士研究生招生考试#34|Q34]]

## 模型锚点

- Topic：NET02｜物理层线路编码的状态语义。
- 题目信号：给定同一比特流的两种波形，要求辨认编码 1/2。
- 第一动作：不要按图形“像不像”判断；先问每个码元由什么状态表达：绝对电平、是否翻转，还是码元中点必翻转。

## 解题链

编码 1 中，一个码元周期内电平保持不变，0/1 由高低电平本身表示，符合 NRZ 的“绝对电平编码”特征。

编码 2 中，每个码元中点都发生跳变，且中点跳变方向区分 0/1，符合曼彻斯特编码。

若是 NRZI，信息由“码元边界处是否发生翻转”表达；若是差分曼彻斯特，则中点必翻转之外，还要用码元开始处是否翻转表示信息。题图不符合这两种状态合同。

## 选项判断

故选 $\boxed{A}$。

## 校验

用最强判据检查编码 2：**每一位中间都有跳变**，这是 Manchester / Differential Manchester 共有特征；再看位值由跳变方向而不是起始翻转决定，因此锁定 Manchester。

## 压缩

```text
line coding waveform
-> absolute level? NRZ
-> boundary transition? NRZI
-> mid-bit transition + direction? Manchester
-> mid-bit transition + start transition? Differential Manchester
```

## 易错边界

曼彻斯特与差分曼彻斯特都“中点必跳变”，不能只凭这一点区分；还要看 bit 信息由“跳变方向”还是“码元开始是否跳变”承载。
