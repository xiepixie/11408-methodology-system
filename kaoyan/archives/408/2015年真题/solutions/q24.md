# 408-2015-Q24

> 原题：[[../2015 年全国硕士研究生招生考试#24|Q24]]

## 模型锚点

- Topic：OS00｜用户态进入内核态的触发事件。
- 题目信号：问哪条已装入 IR 的指令“执行时不可能”导致 mode switch。
- 第一动作：逐条检查执行路径中是否可能产生 system call / trap / fault / exception，而不是只看指令本身是否特权。

## 解题链

A `DIV R0,R1`：若除数为 0，可产生内部异常，进入内核异常处理路径。

B `INT n`：目的就是触发软件中断/陷阱，进入内核处理。

C `NOT R0`：只对通用寄存器执行按位取反，没有访存、除法等会在题设常规模型下触发异常的操作，因此不会因该指令本身导致用户态进入内核态。

D `MOV R0,addr`：需要访存，可能发生缺页或访问保护异常，从而进入内核态。

## 选项判断

故选 $\boxed{C}$。

## 校验

把“可能”当成存在性判断：A、B、D 都能构造至少一种合法运行状态使其触发内核入口；C 在正常 ISA 定义下没有对应触发条件。

## 压缩

```text
user -> kernel?
-> look for trap / exception / fault on execution path
-> pure register NOT has none
```

## 易错边界

“普通指令”也可能因为缺页、保护错、除零等异常导致进入内核态；不要把 mode switch 只等同于显式系统调用。
