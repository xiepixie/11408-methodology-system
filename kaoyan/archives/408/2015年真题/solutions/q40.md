# 408-2015-Q40

> 原题：[[../2015 年全国硕士研究生招生考试#40|Q40]]

## 模型锚点

- Topic：NET08｜HTTP 请求字段语义：request target / Host / Connection / Cookie。
- 题目信号：直接给 HTTP/1.1 请求报文，问错误解释。
- 第一动作：逐字段找 Owner，不要用“HTTP/1.1 默认行为”覆盖显式头字段。

## 解题链

请求行：

```http
GET /index.html HTTP/1.1
```

说明浏览器请求 `/index.html`，A 正确。

`Host: www.test.edu.cn` 指定目标虚拟主机，B 正确。

关键字段：

```http
Connection: close
```

这是显式要求本次响应后关闭连接，因此不是持续连接；C 的说法错误。

`Cookie: 123456` 表示浏览器已经持有该站点设置的 Cookie，并在后续请求中回送；在本题语境下支持“此前与该站点发生过会话/访问”，D 正确。

## 选项判断

故选 $\boxed{C}$。

## 校验

即便 HTTP/1.1 默认倾向持久连接，显式 `Connection: close` 具有更直接的本次连接语义，因此不能因为版本号 1.1 就选择“持续连接”。

## 压缩

```text
HTTP request
-> request line: resource
-> Host: target host
-> Connection: explicit connection lifetime
-> Cookie: prior stored state returned
```

## 易错边界

“HTTP/1.1 默认持久”只是默认值；显式 `Connection: close` 会覆盖默认连接策略。
