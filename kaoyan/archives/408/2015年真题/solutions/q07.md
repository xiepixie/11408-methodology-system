# 408-2015-Q07

> 原题：[[../2015 年全国硕士研究生招生考试#7|Q7]]

## Model Anchor

- Topic：DS09｜折半查找判定树与区间不变量。
- 题目信号：给出“关键字比较序列”，问哪一条不可能出现。
- 第一动作：把每次比较结果转成当前合法区间；后续比较值必须始终落在前面比较共同限定的开区间内。

## 解题链

折半查找每比较一次，目标的候选区间就被压缩。

看 A：

```text
500 -> 200 -> 450 -> 180
```

若第 1 次比较 500 后去比较 200，说明目标小于 500；随后从 200 转到 450，说明目标又大于 200，因此此时候选区间已经是：

$$200 < x < 500.$$

下一次比较关键字必须落在这个区间中。但序列却给出 180，违反区间不变量，所以 A 不可能。

B、C、D 都可以为每一步选择相应的“小于/大于”分支，使下一比较关键字仍落在当前合法区间。

## 选项判断

故选 $\boxed{A}$。

## Verification

把比较序列看成 BST 搜索路径：A 中从 200 的右子树进入 450 后，后续结点必须仍大于 200；180 不可能出现在该子树路径上。

## Compression

```text
binary-search path
-> 每一步更新 (low, high)
-> 下一比较 key 必须落在当前区间
-> 也可视作 BST root-to-node path
```

## 易错边界

不是“数值忽大忽小就不合法”；只要始终满足所有祖先留下的区间约束，比较值可以上升也可以下降。
