# 408-2015-Q11

> 原题：[[../2015 年全国硕士研究生招生考试#11|Q11]]

## 模型锚点

- Topic：DS11｜希尔排序 = 增量分组 + 组内直接插入。
- 题目信号：问“希尔排序的组内排序采用什么方法”。
- 第一动作：不要只记“分组”；回到 Shell sort 的操作合同：固定 gap 后，每个同余类子序列怎样变成有序。

## 解题链

希尔排序在每个增量 $d$ 下，把下标相差 $d$ 的元素组成若干子序列，然后对每个子序列做**直接插入排序**。

随着增量逐步缩小，数组越来越接近整体有序；最终 $d=1$ 时就是一次普通直接插入排序。

因此组内排序方法是直接插入排序。

## 选项判断

故选 $\boxed{A}$。

## 校验

若组内使用快速排序或归并排序，“利用前几趟使序列基本有序，从而让最后一次插入排序很快”的经典 Shell 机制就不再是原算法定义。

## 压缩

```text
Shell
-> gap 分组
-> 每组 direct insertion
-> gap 逐步缩小
-> gap=1 收口
```
