# 408-2015-Q05

> 原题：[[../2015 年全国硕士研究生招生考试#5|Q5]]

## Model Anchor

- Topic：DS07｜DFS 邻接次序自由度。
- 题目信号：有向图从 $v_0$ 开始，问“可能得到多少种 DFS 序列”，邻接点选择次序未固定。
- 第一动作：以 $v_0$ 的第一个孩子分类；每选一个顶点后，必须先耗尽它可到达的未访问后继再回溯。

## 解题链

图中边为：

```text
v0 -> v1, v2, v3
v1 -> v3
```

按第一个访问的邻接点分类：

- 先 `v1`：`v0,v1,v3,v2`；
- 先 `v2`：之后可先 `v1` 或 `v3`，得到 `v0,v2,v1,v3`、`v0,v2,v3,v1`；
- 先 `v3`：之后 `v1,v2` 可交换，得到 `v0,v3,v1,v2`、`v0,v3,v2,v1`。

共 5 种。

## 选项判断

故选 $\boxed{D}$。

## Verification

若先访问 `v1`，其未访问后继 `v3` 必须在回到 `v0` 前访问，所以不会再产生 `v0,v1,v2,v3` 一类序列；分类没有重复或遗漏。

## Compression

```text
DFS 序列计数
-> 按当前 frontier 的首选邻居分类
-> 一旦深入，先耗尽该分支
-> 回溯后再排列剩余候选
```

## 易错边界

邻接表顺序未给定时 DFS 不唯一，但“任意排列”也不成立；递归栈约束仍必须满足。
