# 408-2015-Q30

> 原题：[[../2015 年全国硕士研究生招生考试#30|Q30]]

## 模型锚点

- Topic：OS04｜页框分配范围与置换范围的兼容性。
- 题目信号：问“页面分配策略 × 页面置换策略”哪个组合不可能。
- 第一动作：先写语义：fixed allocation = 每进程页框数固定；global replacement = fault 进程可从其他进程拿页框。检查两者是否冲突。

## 解题链

- 可变分配 + 全局置换：允许 fault 进程从全局选择 victim，页框数可变化，兼容。
- 可变分配 + 局部置换：虽然 victim 先在本进程中选，也可以由系统策略动态调整分配量，兼容。
- 固定分配 + 局部置换：进程只在自己固定数量的页框内替换，正好兼容。
- 固定分配 + 全局置换：全局置换会使某进程获得/失去页框，从而改变各进程固定页框数，直接与 fixed allocation 冲突。

## 选项判断

故选 $\boxed{C}$。

## 校验

用资源守恒看 C：若 P1 缺页并淘汰 P2 的页，把该页框交给 P1，则 P1 页框数 +1、P2 -1；“固定分配”立即被破坏。

## 压缩

```text
allocation says who owns how many frames
replacement says whose frame may be victim
fixed + global
-> ownership counts change
-> incompatible
```

## 易错边界

“局部/全局置换”描述 victim 的选择范围；“固定/可变分配”描述页框配额是否可变化。两个维度要交叉检查，不能分别背四个名词。
