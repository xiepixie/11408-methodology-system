# 408-2015-Q21

> 原题：[[../2015 年全国硕士研究生招生考试#21|Q21]]

## 模型锚点

- Topic：CO08｜Programmed/Interrupt I/O 的数据路径边界。
- 题目信号：中断 I/O 控制打印，问 CPU 与打印控制接口 I/O 端口之间“不可能交换”的信息。
- 第一动作：先画端点：`CPU <-> I/O controller`。中断 I/O 中真正的数据搬运 Owner 仍是 CPU，不是 DMA 控制器。

## 解题链

CPU 与打印控制接口之间可以交换：

- 要打印的字符数据；
- 设备状态；
- 启动、复位等控制命令。

但“主存地址”并不是普通中断 I/O 设备接口所需的数据对象。CPU 自己先从主存取出要打印的数据，再通过 I/O 端口交给设备。

若由设备控制器直接接收主存地址并据此访问主存，已经进入 DMA 一类的总线主控/直接存储器访问模型。

## 选项判断

故选 $\boxed{B}$。

## 校验

用 Owner 检查：中断 I/O 下，主存读写事务仍由 CPU 发起；设备控制器不拥有“下一主存地址”状态。因此 CPU 没必要把主存地址作为打印端口交互对象发送给它。

## 压缩

```text
interrupt I/O
-> CPU moves payload
-> CPU<->controller: data / status / command
-> memory address belongs to DMA-style direct memory access
```

## 易错边界

“中断方式”和“DMA 方式”都可在 I/O 完成后产生中断，但**谁搬数据、谁持有主存地址**完全不同。
