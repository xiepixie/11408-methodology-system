# 408-2015-Q17

> 原题：[[../2015 年全国硕士研究生招生考试#17|Q17]]

## Model Anchor

- Topic：CO05｜SRAM / DRAM 存储单元机制。
- 题目信号：问“工作期间需要刷新”的存储器。
- 第一动作：先看 bit 的 State Owner：是双稳态电路维持，还是电容电荷维持。

## 解题链

DRAM 以电容是否带电表示信息。电容会漏电，即使没有读写，电荷也会逐渐衰减，所以必须周期性刷新。

SDRAM 的 `D` 就是 Dynamic，本质仍是 DRAM，只是接口/时序与时钟同步，因此仍需要刷新。

SRAM 用双稳态触发器保存状态，通电期间无需刷新；ROM 和 Flash 属非易失存储，也不靠周期刷新维持工作状态。

## 选项判断

故选 $\boxed{B}$。

## Verification

把名称拆开检查：`SDRAM = Synchronous DRAM`。`Synchronous` 改变的是接口时序，不会把动态电容单元变成静态锁存单元。

## Compression

```text
needs refresh?
-> inspect storage cell
-> capacitor charge => DRAM/SDRAM => yes
-> bistable/nonvolatile => no periodic refresh
```

## 易错边界

“同步”与“静态”是不同维度。SDRAM 中的 S 是 synchronous，不是 static。
