# 408-2015-Q10

> 原题：[[../2015 年全国硕士研究生招生考试#10|Q10]]

## 模型锚点

- Topic：DS05｜堆删除与下滤。
- 题目信号：删除小根堆根结点，问重建过程中关键字比较次数。
- 第一动作：先把末元素搬到根，再逐层执行“先比较两个孩子，再让较小孩子与当前元素比较”的下滤。

## 解题链

初始小根堆：

```text
8, 15, 10, 21, 34, 16, 12
```

删除 8 后，把末元素 12 放到根：

```text
12, 15, 10, 21, 34, 16
```

第一次下滤：

1. 比较根的两个孩子 15 与 10：第 1 次比较，较小者是 10；
2. 比较 12 与 10：第 2 次比较，交换。

此时 12 下沉到原来 10 的位置，它还有一个孩子 16，因此：

3. 比较 12 与 16：第 3 次比较，无需交换，结束。

所以关键字比较次数为 3。

## 选项判断

故选 $\boxed{C}$。

## 校验

最终堆可写为：

```text
10, 15, 12, 21, 34, 16
```

每个父结点都不大于孩子，且比较账本正好是 `15 vs 10`、`12 vs 10`、`12 vs 16` 三次。

## 压缩

```text
heap delete root
-> last element to root
-> each level: choose smaller child + compare parent
-> count actual key comparisons
```

## 易错边界

不要把“交换次数”当“比较次数”。某一层即使不交换，也可能已经发生一次父子比较。
