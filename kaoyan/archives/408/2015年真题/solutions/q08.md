# 408-2015-Q08

> 原题：[[../2015 年全国硕士研究生招生考试#8|Q8]]

## 模型锚点

- Topic：DS03｜KMP 的前缀复用与失配回退。
- 题目信号：已给第一次失配位置 `i=j=5`，问下一次比较从哪里开始。
- 第一动作：主串指针 `i` 不回退；只用模式串已匹配前缀的最长 border 决定新的 `j`。

## 解题链

模式串为：

```text
index: 0 1 2 3 4 5
char : a b a a b c
```

当 `i=j=5` 时，说明此前已经成功匹配模式串前 5 个字符 `abaab`，当前用 `s[5]` 与 `t[5]='c'` 比较并失配。

KMP 不重新比较主串中已经确认过的字符，而是寻找 `abaab` 的最长“既是前缀又是后缀”的真子串。

`abaab` 的最长 border 是 `ab`，长度为 2，因此模式串回退到：

$$j=2.$$

主串指针保持：

$$i=5.$$

## 选项判断

故选 $\boxed{C}$。

## 校验

回退后即比较 `s[5]` 与 `t[2]`。这正利用了此前后缀 `ab` 已经与模式前缀 `ab` 对齐的事实；若把 `i` 退回，就重复比较已经确认过的主串字符，违背 KMP 的核心收益。

## 压缩

```text
KMP mismatch
-> i 不回退
-> 看已匹配前缀的最长 border
-> j = border length
```

## 易错边界

`next[j]` 的具体数值依赖下标与 next 定义版本；最稳的底层模型不是死背数组，而是“最长可复用前后缀”。
