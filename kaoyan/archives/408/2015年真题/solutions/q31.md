# 408-2015-Q31

> 原题：[[../2015 年全国硕士研究生招生考试#31|Q31]]

## Model Anchor

- Topic：OS07｜位图中的两级地址投影：磁盘块号 -> bitmap bit -> bitmap block/byte。
- 题目信号：位图本身从 32 号盘块开始，每块 1024 B，问释放 409612 号盘块时修改位图哪个盘块、哪个字节。
- 第一动作：先把目标磁盘块号当作**位图中的 bit index**，再分解成“位图盘块偏移 + 块内字节偏移”。

## 解题链

一个保存位图的磁盘块容量：

$$1024\text{ B}\times8=8192\text{ bit}.$$

因此目标 bit 位于第：

$$\left\lfloor\frac{409612}{8192}\right\rfloor=50$$

个位图块中。

位图从磁盘 32 号块开始，所以实际盘块号：

$$32+50=82.$$

块内 bit 偏移：

$$409612\bmod8192=12.$$

每字节 8 bit，块内字节号：

$$\left\lfloor12/8\right\rfloor=1.$$

## 选项判断

故选 $\boxed{C}$：82 号位图盘块、块内第 1 字节。

## Verification

82 号位图块覆盖的磁盘块号范围从

$$50\times8192=409600$$

开始。409612 与起点相差 12 bit，确实落在该块第 1 字节（bit 8～15）中。

## Compression

```text
block number
-> bitmap bit index
-> / (bitmap-block-bytes*8) => bitmap block offset
-> remainder / 8 => byte offset
-> add bitmap start block
```

## 易错边界

题目问的是**块内字节号**，不是块内 bit 号。算到余数 12 后还必须再除以 8。
