# 408-2015-Q09

> 原题：[[../2015 年全国硕士研究生招生考试#9|Q9]]

## Model Anchor

- Topic：DS11｜排序算法的成本对象：比较 vs 移动。
- 题目信号：问“元素移动次数是否依赖初始排列”，不是问时间复杂度。
- 第一动作：逐个看算法的数据搬运机制是否由逆序关系/划分位置触发。

## 解题链

- 直接插入排序：一个元素要向前插多远取决于前面有多少更大元素，移动量依赖初始逆序程度。
- 起泡排序：交换次数与逆序对数量直接相关，也依赖初始排列。
- 快速排序：交换/搬运量受枢轴划分结果和初始分布影响。
- 基数排序：每一趟都把所有记录按当前位稳定分配并收集；在位数和记录数固定时，每趟处理记录数固定，元素移动次数不由初始有序程度决定。

## 选项判断

故选 $\boxed{C}$。

## Verification

拿“已经完全有序”的输入做极端检查：插入、冒泡可以显著减少移动，而基数排序仍须逐趟分配/收集全部记录，机制不变。

## Compression

```text
问 move count
-> 看移动是否由逆序/partition 触发
-> radix 每趟全体分配+收集
-> 与初始排列无关
```

## 易错边界

“移动次数与初始排列无关”不等于“基数排序任何成本都无关”；这里只锁定元素搬运这一成本坐标。
