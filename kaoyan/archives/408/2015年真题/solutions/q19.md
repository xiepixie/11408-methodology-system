# 408-2015-Q19

> 原题：[[../2015 年全国硕士研究生招生考试#19|Q19]]

## Model Anchor

- Topic：CO08｜同步、异步与半同步总线定时。
- 题目信号：四个判断分别在比较握手完整性、可靠性和时钟 Owner。
- 第一动作：先问“谁拥有时序基准”：统一系统时钟，还是请求/应答握手；不要把设备各自时钟偷换成同步总线时钟。

## 解题链

- 异步全互锁：请求与应答的撤销都依赖对方状态，握手最完整、步骤最多，通常最慢，A 正确。
- 异步非互锁：部分状态无需等待对方确认，速度快但可靠性最差，B 正确。
- 同步通信：各设备依据**统一的同步时钟**完成动作；若“同步时钟由各设备分别提供”，就失去了统一时序基准，因此 C 错误。
- 半同步：总体仍受时钟约束，但允许用握手/等待信号扩展周期，相关信号在同步时钟边沿采样，D 正确。

## 选项判断

题目问错误项，故选 $\boxed{C}$。

## Verification

同步总线的核心就是共享 clock contract。若每个设备都独立给一个时钟而没有共同基准，就无法由固定时钟周期规定“第几拍采样”，概念上已退离同步通信。

## Compression

```text
bus timing
-> synchronous: shared clock owner
-> asynchronous: request/ack handshake
-> full interlock slower but safer
-> semi-sync: clock + wait/handshake
```

## 易错边界

“设备内部有自己的工作时钟”不等于“同步总线的同步时钟由各设备各自提供”。这里讨论的是总线事务的共同采样基准。
