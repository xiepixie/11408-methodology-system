# 408-2015-Q16

> 原题：[[../2015 年全国硕士研究生招生考试#16|Q16]]

## Model Anchor

- Topic：CO06/CO07｜TLB + Cache + Write Through 的访存路径。
- 题目信号：问完成 `x=x+3` 至少访问主存几次，并明确有 TLB、Cache、直写。
- 第一动作：分别追踪“读 x”和“写 x”两条路径，求**最有利命中条件**下的主存访问下界。

## 解题链

执行 `add xaddr,3` 至少包含：读取 x、ALU 加 3、把结果写回 x。

为了使主存访问次数最少，可以假设：

- 地址翻译 TLB 命中，因此无需为页表再访主存；
- 读取 x 时 Cache 命中，因此读阶段无需访问主存。

但题目明确 Cache 采用 Write Through。写回 x 时，即使 Cache 命中，也必须同时更新主存。

所以主存访问至少发生 1 次。

## 选项判断

故选 $\boxed{B}$。

## Verification

如果答案为 0，就等价于允许一次 Write Through 写操作完全不写主存，这与策略定义直接矛盾；因此 0 不可能。

## Compression

```text
minimum memory accesses
-> assume TLB hit + Cache read hit
-> write-through write still reaches memory
-> minimum = 1
```

## 易错边界

TLB 命中只消除页表访问；Cache 命中只可能消除读主存。Write Through 的写主存责任不会因 Cache 命中而消失。
