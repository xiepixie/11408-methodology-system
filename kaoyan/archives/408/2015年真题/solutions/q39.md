# 408-2015-Q39

> 原题：[[../2015 年全国硕士研究生招生考试#39|Q39]]

## Model Anchor

- Topic：NET06/NET07｜TCP `rwnd` 与 `cwnd` 双约束。
- 题目信号：初始阈值 32 KB、MSS=1 KB、接收缓存 16 KB，接收端只存不取，问 4 RTT 后发送窗口。
- 第一动作：同时维护两个账本：慢开始增长的 `cwnd`，以及被已接收数据持续吃掉的 `rwnd`；发送窗口取二者最小。

## 解题链

连接建立成功后按 408 经典慢开始模型：

```text
RTT 1: 发送 1 KB
RTT 2: 发送 2 KB
RTT 3: 发送 4 KB
RTT 4: 发送 8 KB
```

四轮累计到达接收端：

$$1+2+4+8=15\text{ KB}.$$

S 的接收缓存初始 16 KB，且数据只存入、不取出，所以第 4 RTT 后剩余接收窗口：

$$rwnd=16-15=1\text{ KB}.$$

另一方面慢开始下拥塞窗口已经增长到至少 16 KB 量级，仍不构成更小约束。

因此发送窗口：

$$W_s=\min(cwnd,rwnd)=1\text{ KB}.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

接收端只剩 1 KB 可用空间，因此无论网络拥塞允许发送多少，发送方都不可能合法拥有大于 1 KB 的有效发送窗口；flow-control 上界独立锁死结果。

## Compression

```text
TCP sender window
-> track cwnd growth
-> track rwnd consumption
-> effective window = min(cwnd, rwnd)
-> receiver buffer can become bottleneck first
```

## 易错边界

`cwnd` 管网络拥塞，`rwnd` 管接收端缓存，两者 Owner 不同。只算慢开始翻倍会漏掉本题真正的瓶颈。
