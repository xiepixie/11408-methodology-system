# 408-2015-Q32

> 原题：[[../2015 年全国硕士研究生招生考试#32|Q32]]

## Model Anchor

- Topic：OS05｜SCAN 磁盘调度与方向状态。
- 题目信号：当前磁头 58，方向“从外侧向内侧”，最外侧磁道号 0。
- 第一动作：先把方向翻译成磁道号变化方向：从外向内 = 磁道号增大；SCAN 要沿当前方向一直扫到端点，再反向。

## 解题链

请求序列：

```text
130, 42, 180, 15, 199
```

当前在 58，向内侧移动，因此先服务大于 58 的请求：

```text
58 -> 130 -> 180 -> 199
```

SCAN 继续到内侧端点 199（题目共有 200 个磁道，编号 0～199），然后反向服务剩余：

```text
199 -> 42 -> 15
```

总移动量可直接按两个大区间计：

$$
(199-58)+(199-15)=141+184=325.
$$

## 选项判断

故选 $\boxed{C}$。

## Verification

将分段距离相加也得到同样结果：

$$72+50+19+157+27=325.$$

两种计数一致。

## Compression

```text
SCAN
-> translate physical direction to track-number direction
-> serve all requests on current side
-> go to endpoint
-> reverse
-> sum head movement
```

## 易错边界

SCAN 与 LOOK 不同：SCAN 会继续到磁盘端点再反向；LOOK 只到当前方向最远请求。题目明确采用 SCAN，因此要把端点纳入路径。
