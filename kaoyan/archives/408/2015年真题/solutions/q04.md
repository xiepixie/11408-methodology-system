# 408-2015-Q04

> 原题：[[../2015 年全国硕士研究生招生考试#4|Q4]]

## 模型锚点

- Topic：DS09｜BST 有序不变量 × AVL 平衡只约束高度。
- 题目信号：中序遍历得到**降序**，说明这棵搜索树采用“左大右小”的方向约定。
- 第一动作：先恢复局部次序不变量，再判断最大/最小结点还能拥有哪些方向的孩子；AVL 不会额外保证结点度或插入后位置。

## 解题链

中序为降序意味着：

```text
left subtree keys > node > right subtree keys
```

因此最大关键字不可能再有左孩子，因为左孩子必须比它更大；但它仍可能有更小的右孩子，所以不一定是叶结点。

- A 错：两结点 AVL 根也可只有一个孩子；
- B 错：最小元素仍可能有更大的左孩子；
- C 错：插入后旋转会改变结点位置，最后插入结点不保证最终仍为叶；
- D 对：最大元素一定无左子树。

## 选项判断

故选 $\boxed{D}$。

## 校验

把普通“左小右大”BST 镜像一次即可：最大值从最右端变为最左端，相应地“最大无右子树”也镜像成“最大无左子树”。

## 压缩

```text
BST 性质题
-> 先从 inorder 恢复左右大小关系
-> AVL 只再加 height balance
-> 不额外推出度数/叶子身份
```

## 易错边界

“AVL”只保证每个结点左右子树高度差受限；它不会让根必为二叉、也不会让最后插入元素永久停在叶子。
