# 408-2015-Q01

> 原题：[[../2015 年全国硕士研究生招生考试#1|Q1]]

## Model Anchor

- Topic：DS02｜调用栈与 LIFO。
- 题目信号：递归 `S(1)->S(0)`，问的是**栈底到栈顶**的活动记录顺序。
- 第一动作：按真实调用时间列调用链；先调用者先入栈、后调用者压在上面。

## 解题链

执行链为：

```text
main()
-> S(1)
-> S(0)
```

每次未返回的调用都保留一个栈帧。`S(0)` 执行时三层都尚未返回，所以从栈底到栈顶依次是：

```text
main(), S(1), S(0)
```

## 选项判断

故选 $\boxed{A}$。

## Verification

返回时必须按相反顺序弹出：`S(0) -> S(1) -> main()`；这正好是上述栈底到栈顶顺序的逆序，符合 LIFO。

## Compression

```text
递归调用栈
-> 调用顺序 = 入栈顺序
-> 栈底最老 caller
-> 栈顶当前 callee
```

## 易错边界

题目问“栈底到栈顶”不是“返回顺序”；两者正好相反。
