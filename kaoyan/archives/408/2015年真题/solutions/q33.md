# 408-2015-Q33

> 原题：[[../2015 年全国硕士研究生招生考试#33|Q33]]

## Model Anchor

- Topic：NET08｜应用层协议与传输层服务 Owner。
- 题目信号：POP3 收邮件，问底层传输服务类型。
- 第一动作：先把应用协议映射到 transport：POP3 基于 TCP，因此继承 TCP 的连接与可靠性语义。

## 解题链

POP3 是电子邮件接收协议，运行在 TCP 之上。

TCP 提供：

- 面向连接；
- 可靠字节流；
- 按序交付与重传等可靠性机制。

因此 POP3 使用的是“有连接、可靠”的传输层服务。

## 选项判断

故选 $\boxed{D}$。

## Verification

如果 POP3 使用无连接不可靠服务，那么邮件内容丢包、乱序时应用层必须自己完整实现重传与排序；这与 POP3 依赖 TCP 的协议栈事实不符。

## Compression

```text
POP3
-> application protocol
-> runs over TCP
-> connection-oriented + reliable
```

## 易错边界

“邮件系统整体”会同时涉及 SMTP/POP3/IMAP 等应用协议，但本题只问 POP3 的传输层服务，不要扩成整个邮件架构。
