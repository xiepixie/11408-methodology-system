# 408-2015-Q14

> 原题：[[../2015 年全国硕士研究生招生考试#14|Q14]]

## 模型锚点

- Topic：CO01｜浮点加减的对阶、规格化与舍入。
- 题目信号：四个判断分别涉及 exponent 在不同阶段是否可能越界。
- 第一动作：按流水顺序逐阶段追踪“阶码向哪个方向变化”，不要把尾数溢出与最终数值溢出混为一谈。

## 解题链

I. 对阶时把较小阶码向较大阶码靠齐，通常通过右移小阶数的尾数实现，并不把公共阶码推到更大或更小范围，因此不会由对阶本身造成阶码上溢/下溢。

II. 结果若需右规，阶码要加 1；尾数舍入也可能产生进位，继而触发右规并使阶码加 1，因此两者都可能导致阶码上溢。

III. 左规时尾数左移、阶码递减，若已经接近最小阶码，继续递减可能下溢。

IV. 尾数产生进位后通常可以右规并增加阶码；只要调整后的阶码仍在可表示范围内，最终结果就不溢出，所以“尾数溢出”不等于“浮点结果溢出”。

四项均正确。

## 选项判断

故选 $\boxed{D}$。

## 校验

用方向账本检查：

```text
对阶：小阶 -> 大阶，不改变公共最大阶的范围
右规/舍入进位：exp + 1 -> 可能上溢
左规：exp - 1 -> 可能下溢
```

四个判断与方向完全一致。

## 压缩

```text
float add/sub
-> 先问本阶段让 exponent +1 / -1 / 不变
-> +1 看 overflow
-> -1 看 underflow
-> mantissa carry != final overflow
```

## 易错边界

“尾数溢出”是中间表示状态；“浮点数溢出”取决于规格化后阶码是否超范围，两者不是同一个 Owner。
