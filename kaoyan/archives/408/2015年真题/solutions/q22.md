# 408-2015-Q22

> 原题：[[../2015 年全国硕士研究生招生考试#22|Q22]]

## Model Anchor

- Topic：CO08｜Fault / Trap / Abort 的 restart contract。
- 题目信号：问“内部异常”的一般叙述，尤其关注处理后从哪里继续。
- 第一动作：不要把所有异常都想成可重启 fault；先区分异常类别决定保存的断点/返回语义。

## 解题链

A：内部异常由当前指令执行触发，例如缺页、除零、非法指令，成立。

B：是否发生异常由 CPU 内部执行/检查逻辑检测，成立。

C：异常是当前指令执行语义的一部分，会在该指令执行过程中被检测并转入异常处理，成立。

D：“处理后都返回发生异常的原指令继续执行”过度绝对化。

- fault 往往允许修复后重启原指令，例如缺页；
- trap 通常在指令完成后报告，返回到下一条指令；
- abort 甚至不保证可恢复。

因此 D 错误。

## 选项判断

题目问错误项，故选 $\boxed{D}$。

## Verification

最小反例就是系统调用/陷阱：若 trap 处理后再次回到触发 trap 的同一条指令，就会无穷重复触发，显然不符合其返回语义。

## Compression

```text
internal exception
-> classify fault / trap / abort
-> class decides restart point
-> never assume all exceptions restart same instruction
```

## 易错边界

“异常发生在当前指令执行相关路径”不等于“异常处理后一定重执行当前指令”。检测时刻和返回语义是两个不同问题。
