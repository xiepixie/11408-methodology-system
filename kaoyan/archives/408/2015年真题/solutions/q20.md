# 408-2015-Q20

> 原题：[[../2015 年全国硕士研究生招生考试#20|Q20]]

## 模型锚点

- Topic：CO08｜磁盘访问时间分解。
- 题目信号：转速、平均寻道时间、每磁道扇区数，问访问一个扇区平均存取时间。
- 第一动作：先拆成本 Owner：`seek + rotational latency + transfer`，不要把一圈时间直接全部算进去。

## 解题链

转速 7200 rpm：

$$T_{rev}=\frac{60}{7200}\text{s}=8.33\text{ ms}.$$

平均旋转等待约半圈：

$$T_{rot}=\frac{8.33}{2}\approx4.17\text{ ms}.$$

每磁道 1000 个扇区，顺序传一个扇区：

$$T_{trans}=\frac{8.33}{1000}\approx0.0083\text{ ms}.$$

加上平均寻道 8 ms：

$$T\approx8+4.17+0.0083=12.18\text{ ms}\approx12.2\text{ ms}.$$

## 选项判断

故选 $\boxed{B}$。

## 校验

数量级检查：平均访问不可能只等于 8 ms，因为还要等旋转；也不应额外再加完整一圈 8.33 ms。`8 + 半圈 ≈ 12.2 ms` 与答案量级吻合。

## 压缩

```text
random disk access
-> seek
-> average rotation = 0.5 revolution
-> sector transfer = 1/(sectors per track) revolution
-> sum
```

## 易错边界

平均旋转延迟是半圈，不是一圈；而扇区传输时间又是独立的第三项，不能与旋转等待混为一项。
