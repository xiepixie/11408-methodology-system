# 408-2015-Q18

> 原题：[[../2015 年全国硕士研究生招生考试#18|Q18]]

## 模型锚点

- Topic：CO05｜低位交叉编址与存储体忙状态。
- 题目信号：4 体交叉、给出一串连续总线地址，问哪对可能产生访存冲突。
- 第一动作：先把每个地址投影到 bank：`bank = address mod 4`；再看同一 bank 的两次请求间隔是否足够让该体完成上一周期。

## 解题链

4 体低位交叉时：

```text
8005 -> bank1
8006 -> bank2
8007 -> bank3
8008 -> bank0
8001 -> bank1
8002 -> bank2
8003 -> bank3
8004 -> bank0
8000 -> bank0
```

前面形成 `1,2,3,0`、`1,2,3,0` 的轮转。同一存储体两次被访问之间隔着完整的 4 体流水间距，可正常交叉。

但最后：

```text
8004 -> bank0
8000 -> bank0
```

连续两个请求落到同一存储体，后一请求到达时 bank0 仍可能忙，因此发生体冲突。

## 选项判断

故选 $\boxed{D}$。

A 中 8008 和 8004 虽同属 bank0，但在请求序列中相隔一个完整 4 体轮转，不构成本题所问的冲突；B、C 甚至不在同一 bank。

## 校验

只用“地址是否同模 4”还不够：A 与 D 都可出现同 bank 地址。加入**时间位置**后，只有 D 是相邻同 bank 请求，这正说明冲突由 `bank identity + request spacing` 共同决定。

## 压缩

```text
interleaved memory
-> bank = address mod m
-> mark request timeline
-> same bank + insufficient spacing => conflict
```

## 易错边界

“同一存储体”是冲突的必要条件，不是充分条件；还必须看两次访问之间是否给了该存储体足够的恢复/访问周期。
