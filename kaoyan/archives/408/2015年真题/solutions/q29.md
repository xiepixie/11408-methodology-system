# 408-2015-Q29

> 原题：[[../2015 年全国硕士研究生招生考试#29|Q29]]

## Model Anchor

- Topic：OS07｜inode 多级索引与访问路径长度。
- 题目信号：10 个 direct、一级/二级各 1 个，问两个文件偏移量对应数据块读入需几次磁盘访问。
- 第一动作：先把 offset 投影到 direct / single / double-indirect 区间；然后数“索引块路径 + 数据块”，且 inode 已在内存不计磁盘访问。

## 解题链

块大小 1 KB，每个索引指针 4 B，因此一个索引块容纳：

$$1024/4=256$$

个块号。

Direct 覆盖：

$$10\times1\text{ KB}=10\text{ KB}.$$

一级间接再覆盖：

$$256\text{ KB}.$$

所以：

### offset = 1234

1234 B < 10 KB，位于 direct 区。inode 已在内存，可直接得到数据块号，只需读数据块：

$$1\text{ 次}.$$

### offset = 307400

$$10\text{ KB}+256\text{ KB}<307400\text{ B},$$

已经进入二级间接区。

需要：

```text
读一级索引块
-> 读二级索引块
-> 读目标数据块
```

共 3 次。

## 选项判断

故选 $\boxed{B}$。

## Verification

访问次数不是“索引级数”本身：direct 虽有一个 inode 指针，但 inode 已在内存，所以只访问 1 个数据块；double indirect 则是 2 个索引块 + 1 个数据块 = 3。

## Compression

```text
offset
-> locate direct / single / double region
-> inode resident? yes => don't count inode
-> count index blocks on path + data block
```

## 易错边界

“二级索引”表示两层索引块，不是总共只访问 2 个磁盘块；最终数据块本身还要再访问一次。
