# 408-2015-Q13

> 原题：[[../2015 年全国硕士研究生招生考试#13|Q13]]

## 模型锚点

- Topic：CO01｜补码位模式与可表示范围。
- 题目信号：8 位补码、固定 3 个 `1` 和 5 个 `0`，要求最小整数。
- 第一动作：若要最小，符号位必须为 1；随后让剩余两个 `1` 尽量放在低权位，减少对负值幅度的抵消。

## 解题链

8 位补码的最高位权值是 $-2^7=-128$。

为了得到最小整数，最高位取 1。还剩两个 `1` 必须放在其余 7 位中。

数值为：

$$-128+\sum b_i2^i.$$

要让结果尽可能小，就让正权部分尽可能小，因此把两个 `1` 放到最低两位：

```text
10000011₂
```

其真值：

$$-128+2+1=-125.$$

## 选项判断

故选 $\boxed{B}$。

## 校验

若想得到 -126，需要位模式 `10000010`，但它只有两个 `1`；不满足题目“3 个 1”的约束。这个计数检查可以直接排除 A。

## 压缩

```text
fixed number of 1s in two's complement
-> minimum => sign bit = 1
-> remaining 1s put at smallest positive weights
-> evaluate weighted sum
```

## 易错边界

补码负数不是“符号位 + 绝对值位”。位权模型是 $-2^{w-1}+\sum b_i2^i$，用这个模型更不容易错。
