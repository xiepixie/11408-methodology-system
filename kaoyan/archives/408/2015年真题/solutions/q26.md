# 408-2015-Q26

> 原题：[[../2015 年全国硕士研究生招生考试#26|Q26]]

## 模型锚点

- Topic：OS03｜死锁避免 vs 死锁检测。
- 题目信号：比较 S1=deadlock avoidance、S2=deadlock detection 三个陈述。
- 第一动作：先写两种机制各自需要的状态：避免要在分配前预测安全性；检测允许先分配、之后再发现环/不可满足状态。

## 解题链

I 错。限制资源申请顺序是典型的**死锁预防**方法，不是死锁避免的必要特征。

II 对。银行家式避免需要知道进程最大资源需求，才能判断试分配后是否仍有安全序列；死锁检测不要求事先知道最大总需求，只需当前 Allocation/Request 等状态。

III 对。避免策略会拒绝使系统进入不安全状态的分配；检测策略允许系统进入可能死锁的状态，再通过检测与解除处理。

因此仅 II、III 正确。

## 选项判断

故选 $\boxed{B}$。

## 校验

把“预防、避免、检测”三层分别问一句：预防改规则以破坏必要条件；避免每次分配前预测安全性；检测不阻止危险分配，只负责事后发现。I 正是把预防特征误嫁接给避免。

## 压缩

```text
prevention = break deadlock condition by policy
avoidance = know max demand + keep safe state
detection = allow allocation + detect later
```

## 易错边界

“避免死锁”和“预防死锁”不是同义词。资源有序申请属于 Prevention，不是 Banker/Avoidance 的定义要求。
