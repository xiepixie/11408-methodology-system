# 408-2015-Q23

> 原题：[[../2015 年全国硕士研究生招生考试#23|Q23]]

## 模型锚点

- Topic：OS05 / CO08 Bridge｜中断响应的硬件最小保存 vs 软件现场保护。
- 题目信号：问“处理外部中断时应该由操作系统保存什么”。
- 第一动作：先分层：硬件必须自动保存可返回的最小状态；ISR/OS 再按软件使用需要保存通用现场。

## 解题链

PC（以及必要的程序状态）属于中断硬件响应为保证返回而自动保存的最小状态。

TLB 和 Cache 是硬件维护的性能结构，处理中断并不要求 OS 把它们逐项保存。

通用寄存器则属于被中断程序的软件可见执行现场。若中断服务程序会使用/覆盖它们，OS/ISR 需要在软件层保存并在返回前恢复。

## 选项判断

故选 $\boxed{B}$。

## 校验

若 OS 不保存被 ISR 改写的通用寄存器，返回用户程序后其寄存器值会无故改变；而 PC 已由中断入口机制处理，软件无需重复承担相同 Owner。

## 压缩

```text
interrupt entry
-> hardware: minimum return state (PC/PSW...)
-> software ISR/OS: GPR context as needed
```

## 易错边界

“中断现场都要保存”不等于“所有状态都由 OS 保存”。必须区分硬件自动响应与软件处理两个阶段。
