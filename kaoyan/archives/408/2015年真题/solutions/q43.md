# 408-2015-Q43

> 原题：[[../2015 年全国硕士研究生招生考试#43|Q43]]

## 模型锚点

- Topic：CO03｜单总线数据通路：State -> Path -> Control。
- 题目信号：给出 R0～R3、PC、T、ALU、SR、MUX 和端点①～⑨，连续问“可见状态、为什么要 T、控制字段位数、控制端点、补连线”。
- 第一动作：先把图上对象分成三类：**architectural state**、**temporary datapath state**、**control/path elements**；再判断每条数据流是谁驱动总线、谁锁存结果。

## 问题表征

单总线结构的核心约束：

```text
任一时刻只有一个部件能够驱动内部总线
```

但典型 ALU 二元运算需要同时获得两个输入。因此必须把操作数的生命周期拆开：

```text
operand 1 -> T 暂存
operand 2 -> bus
T + bus -> ALU
ALU -> SR
SR -> bus -> destination register
```

这就是设置 T 的机制原因。

同时：

- R0～R3、PC 属于程序执行语义可见或架构状态；
- T、SR 中间结果主要是微体系结构内部状态；
- `ALUop / SRop / *in / *out / MEMop` 属于控制信号；
- 三态门/MUX 属于数据路径选择结构。

## 关键决策

1. **程序员可见 != 图中所有寄存器。** 只有 ISA/程序语义能直接观察或使用的状态才算可见；T 是内部暂存。
2. **控制位数按可区分操作数取上整。** 不是“7 种操作就 7 位 one-hot”，题目问至少多少位。
3. **判断端点是否接 CU 输出，要看该端点表达的是控制，还是数据。** 数据连线不能误接控制器。
4. **补数据线要顺着数据生命周期判断方向。** 不能仅凭图上距离最近的端点相连。

## 求解链

### (1) 程序员可见寄存器与 T 的作用

程序员可见寄存器：

$$\boxed{R0,R1,R2,R3,PC}.$$

T 是暂存器。单总线一次只能提供一个总线源，而 ALU 二元操作需要 A、B 两个输入，因此先把第一个操作数锁存在 T，再让第二个操作数经总线送入 ALU 的另一输入。

可压缩为：

```text
single bus cannot carry two operands simultaneously
-> latch first operand in T
-> second operand comes from bus
-> ALU gets two distinct operands
```

### (2) `ALUop` 与 `SRop` 最少位数

ALU 有 7 种操作：

$$\lceil\log_2 7\rceil=3.$$

所以：

$$\boxed{ALUop=3\text{ bit}}.$$

SR 有 mov / left / right 3 种操作：

$$\lceil\log_2 3\rceil=2.$$

所以：

$$\boxed{SRop=2\text{ bit}}.$$

### (3) `SRout` 控制什么

`SRout` 控制 SR 输出端到内部总线之间的**三态门/总线输出门**。

它的职责是：

```text
SRout=1 -> allow SR to drive bus
SRout=0 -> disconnect SR from bus
```

这是单总线“同一时刻只能一个 source 驱动”的必要仲裁机制。

### (4) 哪些端点接控制部件输出

按题图端点语义，属于控制输入的端点为：

$$\boxed{①、②、③、⑤、⑧}.$$

其余 ④、⑥、⑦、⑨属于数据路径端点，不应接成 CU 控制输出。

### (5) 必要数据连线

题图需补的关键数据路径为：

$$\boxed{⑥\rightarrow⑨}$$

以及：

$$\boxed{⑦\rightarrow④}.$$

方向必须按数据流向书写，而不是只说“⑥和⑨相连”。

### (6) MUX 为什么有常数 2 输入

指令字长 16 bit，而主存按字节编址，因此每条定长指令占：

$$16/8=2\text{ B}.$$

顺序取下一条指令时：

$$PC\leftarrow PC+2.$$

所以 MUX 提供常数 2，正是为了给 PC 更新路径提供增量。

## 校验

可以用三个独立 Gate 检查：

1. **编码容量**：3 bit 可表示 8 种状态，足够编码 7 个 ALU 操作；2 bit 可表示 4 种，足够编码 3 个 SR 操作。
2. **总线安全**：设置 T 后，两个操作数不要求同时驱动单总线；SRout 通过三态门控制唯一总线 source。
3. **地址步长**：16 bit 定长指令 = 2 B，按字节编址时顺序 PC 必须 +2；若 MUX 常数为 1 就会落到指令中间字节。

## 压缩

```text
single-bus datapath
-> classify architectural / temporary / control state
-> one bus source per cycle
-> T stores first ALU operand
-> control width = ceil(log2 operations)
-> output-enable drives tri-state gate
-> instruction bytes decide PC increment
```

复原检查：若该机改成 32 位定长指令且仍按字节编址，MUX 的顺序取指常量必须从 2 改成 4；其他控制位数只有在 ALU/SR 操作集合变化时才需重算。

## 易错边界

- 程序员可见寄存器 ≠ CPU 内所有寄存器；T/SR 是内部实现状态。
- 单总线 ≠ ALU 只能做一元运算；T 允许把两个操作数错峰送入。
- 控制线和数据线是两类不同对象，端点不能按视觉位置乱连。
