# 408-2015-Q15

> 原题：[[../2015 年全国硕士研究生招生考试#15|Q15]]

## 模型锚点

- Topic：CO06｜Cache 总容量 = 数据位 + 标记/状态位。
- 题目信号：问“能存 4K 字数据的 Cache 总容量至少多少”，且给直接映射、块大小和 Write Back。
- 第一动作：先做 Geometry：块字节数、Cache 行数、offset/index/tag；再把每行 metadata 加回数据区。

## 解题链

每字 32 bit = 4 B，主存块有 4 字，因此：

$$B=4\times4=16\text{ B},\qquad \text{offset}=4\text{ bit}.$$

Cache 数据区能存 4K 字，每块 4 字，因此行数：

$$\frac{4K}{4}=1K=2^{10},$$

直接映射需要 10 位行号。

主存地址 32 位，所以 Tag 位数：

$$32-10-4=18.$$

Write Back 每行至少还要有：

- Valid：1 bit；
- Dirty：1 bit。

因此每行总位数：

$$4\times32+18+1+1=148\text{ bit}.$$

共有 1024 行：

$$148\times1024=148\text{ Kbit}.$$

## 选项判断

故选 $\boxed{C}$。

## 校验

只算数据区应为：

$$4K\times32=128\text{ Kbit}.$$

总容量必须大于 128 Kbit。再加每行 20 bit 元数据，共增加 20 Kbit，正好得到 148 Kbit。

## 压缩

```text
Cache total capacity
-> block bytes -> offset
-> lines -> index
-> tag = PA - index - offset
-> per-line = data + tag + valid + dirty(write-back)
```

## 易错边界

“Cache 数据区大小”不等于“Cache 芯片总容量”。题目问总容量时，Tag、Valid、Dirty 等元数据也必须计入。
