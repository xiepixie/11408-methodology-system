# 408-2015-Q12

> 原题：[[../2015 年全国硕士研究生招生考试#12|Q12]]

## Model Anchor

- Topic：CO02｜语言层次与 ISA 执行对象。
- 题目信号：问“计算机硬件能够直接执行的语言”。
- 第一动作：先找 CPU 真正取指的对象：必须是符合 ISA 编码的机器指令位串。

## 解题链

- 机器语言程序：已经是 ISA 规定的二进制指令编码，CPU 可以直接取指、译码、执行。
- 汇编语言程序：仍是符号化文本，需要汇编器翻译成机器代码。
- 硬件描述语言：用于描述/综合硬件结构，不是处理器运行时执行的 ISA 指令流。

因此只有 I 成立。

## 选项判断

故选 $\boxed{A}$。

## Verification

用“PC 下一步指向什么”做检查：PC 指向主存中的机器指令编码，而不会指向 `ADD R1,R2` 这样的汇编文本，更不会直接执行 HDL 源码。

## Compression

```text
CPU directly executes
-> ISA machine-code bit patterns
assembly/HDL
-> need translation/synthesis first
```

## 易错边界

“与硬件关系很近”不等于“可被 CPU 直接执行”。汇编语言和 HDL 都需要经过额外转换阶段。
