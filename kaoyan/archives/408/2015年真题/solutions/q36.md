# 408-2015-Q36

> 原题：[[../2015 年全国硕士研究生招生考试#36|Q36]]

## 模型锚点

- Topic：NET02｜CSMA/CD 的碰撞检测前提与适用介质。
- 题目信号：问“关于 CSMA/CD 的错误叙述”。
- 第一动作：先锁协议运行环境：共享有线以太网；发送端必须能在发送期间监听介质并检测碰撞。

## 解题链

A 正确。CSMA/CD 的 `CD` 就是 Collision Detection，发送时持续检测冲突。

B 错误。无线局域网中发送端很难在强自身发射信号下可靠检测远端碰撞，还存在隐藏站等问题，典型采用 CSMA/CA，而不是 CSMA/CD。

C 正确。为了保证最远端碰撞能在发送结束前反馈到发送方，最小帧发送时间必须覆盖往返传播时延，因此网络跨距、传播时延与速率共同约束最小帧长。

D 正确。在其他开销固定的抽象模型中，传播时延趋近 0，碰撞侦听代价趋近 0，CSMA/CD 信道利用率趋近 1。

## 选项判断

故选 $\boxed{B}$。

## 校验

把协议名拆成动作检查：无线网络若无法稳定实现“边发边听并检测碰撞”，就失去 CD 的物理前提，这比死记“有线/无线”更稳。

## 压缩

```text
CSMA/CD
-> shared wired medium
-> transmit while detecting collision
-> min frame >= round-trip collision budget
wireless -> collision avoidance instead
```

## 易错边界

CSMA/CD 与 CSMA/CA 都先监听信道，但后半段目标不同：前者“检测碰撞”，后者“尽量避免碰撞”。
