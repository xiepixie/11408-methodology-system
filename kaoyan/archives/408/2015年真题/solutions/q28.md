# 408-2015-Q28

> 原题：[[../2015 年全国硕士研究生招生考试#28|Q28]]

## Model Anchor

- Topic：OS05｜磁盘缓冲的 producer-consumer 速率桥接。
- 题目信号：问“在内存中设置磁盘缓冲区的主要目的”。
- 第一动作：先找它改变的成本 Owner：缓冲主要减少/合并实际设备 I/O，不改变磁头机械定位本身。

## 解题链

磁盘远慢于内存。把近期读入的数据保存在内存缓冲区后，后续再次需要同一数据时可以直接命中缓冲；写操作也可经过聚合后再批量下刷。

因此缓冲最直接减少的是**实际磁盘 I/O 次数**。

它不能改变磁盘硬件一次寻道所需的平均机械时间，也不是提高介质可靠性的主要机制；设备无关性属于 OS I/O 抽象接口的另一层责任。

## 选项判断

故选 $\boxed{A}$。

## Verification

若缓存命中，整次磁盘请求可以被消除，这直接减少 I/O 次数；但一旦真的访问磁盘，磁头寻道机械参数并没有因“有缓冲”而改变。

## Compression

```text
memory disk buffer
-> reuse / aggregate data in RAM
-> fewer physical disk I/Os
-> does not change mechanical seek time
```

## 易错边界

“减少 I/O 次数”和“减少一次 I/O 的寻道时间”是两个不同成本坐标；缓冲主要优化前者。
