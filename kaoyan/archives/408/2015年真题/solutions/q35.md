# 408-2015-Q35

> 原题：[[../2015 年全国硕士研究生招生考试#35|Q35]]

## 模型锚点

- Topic：NET03 / NET-B05｜滑动窗口的在途预算与序号空间。
- 题目信号：卫星链路、高传播时延、要求利用率 ≥80%，最后问序号位数。
- 第一动作：先求一帧发送时间和 `RTT + T_f` 的发送窗口预算，再把所需窗口映射到有限序号空间。

## 解题链

帧长 1000 B：

$$L=8000\text{ bit}.$$

链路速率 128 kbps，所以一帧发送时间：

$$T_f=\frac{8000}{128000}=0.0625\text{ s}=62.5\text{ ms}.$$

单向传播时延 250 ms，因此从开始发送一帧到其确认返回所占的基本周期约为：

$$T_f+2T_p=62.5+500=562.5\text{ ms}.$$

若发送窗口为 $W$，忽略 ACK 发送开销时：

$$U=\min\left(1,\frac{W T_f}{T_f+2T_p}\right).$$

要求 $U\ge0.8$：

$$\frac{W\times62.5}{562.5}\ge0.8$$

得到：

$$W\ge7.2,$$

所以至少需要 $W=8$ 个帧的发送窗口。

有限序号空间还必须能区分当前窗口与旧帧。按本题 408 滑动窗口模型要求：

$$W\le2^k-1.$$

若 $W=8$：

$$2^k-1\ge8\Rightarrow k\ge4.$$

## 选项判断

故选 $\boxed{B}$。

## 校验

3 bit 只有 8 个序号值，按 $W\le2^k-1$ 最大发送窗口只能为 7；此时利用率：

$$\frac{7\times62.5}{562.5}\approx77.8\%<80\%.$$

因此 3 bit 确实不够，4 bit 是最小可行值。

## 压缩

```text
long-delay sliding window
-> Tf = L/R
-> U = W*Tf/(Tf+RTT)
-> solve minimum W
-> sequence-space invariant
-> minimum k
```

## 易错边界

先求“为了吞吐需要多少在途帧”，再检查序号空间；不能直接拿 BDP 除帧长后忘记协议的序号安全约束。
