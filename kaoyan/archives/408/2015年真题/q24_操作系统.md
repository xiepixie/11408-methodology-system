# q24_操作系统

## 📋 题目要求 (题面)

假定下列指令已装入指令寄存器，则执行时不可能导致 CPU 从用户态变为内核态（系统态）的是（ ）。

- **A.** DIV R0, R1; (R0)/(R1)→R0
- **B.** INT n; 产生软中断
- **C.** NOT R0; 寄存器 R0 的内容取非
- **D.** MOV R0, addr; 把地址 addr 的内存数据放入寄存器 R0 中

---

## 💡 答案与深度解析

**【正确答案】**：`C`

**正确答案：C**
考虑到部分指令可能出现异常（导致中断），从而转到 内核模式。指令 A 有除零异常的可能，指令 B 为中断指令，指令 D 有缺页异常的可能，指令 C 不会发生异常。
