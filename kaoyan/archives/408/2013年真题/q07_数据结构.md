# q07_数据结构

## 📋 题目要求 (题面)

设图的邻接矩阵 A 如下所示。各顶点的度依次是（）

 $A=$ 0 0 0 1101001001100

- **A.** 1，2，1，2
- **B.** 2，2，1，1
- **C.** 3，4，2，3
- **D.** 4，4，2，2

---

## 💡 答案与深度解析

**【正确答案】**：`C`

**正确答案：C**
邻接矩阵 A 为非对称矩阵，说明图是有向图，度为入度加出度之和。各顶点的度是矩阵中此结点对应的行（对应出度）和列（对应入度）的非零元素之和。
