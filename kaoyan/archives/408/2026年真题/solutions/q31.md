# 408-2026-Q31

> 原题：[[../2026 年全国硕士研究生招生考试#31|Q31]]

## Model Anchor

- Topic：设备驱动层的职责与设备抽象。
- 题目信号：**区分“统一接口”与“底层设备差异”**。
- 第一动作：先判断哪一项把字符设备、块设备这两类不同抽象偷换成“完全相同”。

## 解题链

设备驱动程序负责把操作系统统一的设备访问抽象翻译成具体硬件控制操作，因此既需要遵循 OS 的统一接口，又必须针对具体硬件特性实现。

字符设备通常按字节/字符流访问，块设备则按可寻址数据块组织，缓存、调度和访问语义都不同，不可能采用完全相同的 I/O 控制方式。

故错误项为 **D**。

## 选项判断

- A：驱动位于 OS 与硬件之间，正确。
- B：硬件寄存器、协议和时序不同，需要定制，正确。
- C：OS 需要统一抽象接口屏蔽设备差异，正确。
- D：把字符设备和块设备的 I/O 模型说成完全相同，错误。

## Verification

磁盘支持按块随机访问并常配合块缓存；键盘/串口等字符设备通常表现为顺序字节流。两者的访问粒度和调度语义明显不同。

## Compression

驱动层 = **上接统一 OS 接口，下接具体硬件差异**；“所有设备 I/O 完全一样”通常违反这个分层目的。

## 易错边界

“统一接口”不等于“内部实现完全相同”；统一的是上层调用契约，不是底层设备机制。
