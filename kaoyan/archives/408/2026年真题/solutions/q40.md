# 408-2026-Q40

> 原题：[[../2026 年全国硕士研究生招生考试#40|Q40]]

## Model Anchor

- Topic：HTTP Cookie 的状态语义。
- 题目信号：**区分“保存/携带用户状态”与“降低对象传输时延”**。
- 第一动作：问该场景是否需要服务器把多次 HTTP 请求关联为同一用户/会话。

## 解题链

HTTP 本身是无状态协议。Cookie 通过客户端保存并在后续请求中携带标识/状态，使服务器能够关联多次交互，因此常用于：

- 用户会话跟踪；
- 个性化推荐；
- 虚拟购物车状态维护。

缩短 Web 对象响应时间主要依赖浏览器/代理缓存、CDN、连接复用等机制，不是 Cookie 的典型职责。

故答案为 **D**。

## 选项判断

- A：需要跨请求识别用户，典型 Cookie 用途。
- B：可基于用户标识/偏好做个性化，典型用途。
- C：需要维护跨请求购物状态，典型用途。
- D：属于缓存/CDN/传输优化目标，不是 Cookie 的典型用途。

## Verification

删除 Cookie 并不会让 10 MB Web 对象传输得更快；是否能缩短网络传输时间取决于对象是否缓存、路径和连接等，而不是会话标识本身。

## Compression

Cookie → **跨 HTTP 请求维持“谁/什么状态”**；缓存/CDN → **减少“传什么/从哪传/传多久”**。

## 易错边界

Cookie 可能间接影响个性化资源选择，但这不等于它本身是网络响应时间优化机制。
