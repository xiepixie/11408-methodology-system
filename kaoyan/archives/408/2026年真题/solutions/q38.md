# 408-2026-Q38

> 原题：[[../2026 年全国硕士研究生招生考试#38|Q38]]

## Model Anchor

- Topic：IGP / EGP 与 OSPF 分层区域。
- 题目信号：**“自治系统内部 + 可划分多个区域”**。
- 第一动作：先按协议 Scope 排除 BGP，再在 IGP 中判断谁原生支持 area hierarchy。

## 解题链

- OSPF 是链路状态 IGP，并支持把一个 AS 划分为骨干区域 Area 0 和多个非骨干区域；
- RIP 是距离向量 IGP，但没有 OSPF 这种区域层次结构；
- BGP 用于自治系统之间，是 EGP，不满足“内部网关协议”。

所以只有 I 正确，答案为 **A**。

## 选项判断

- I OSPF：正确。
- II RIP：属于 IGP，但不支持 OSPF 式 area 划分。
- III BGP：跨 AS 协议，不是 IGP。

因此 B、C、D 都包含错误项。

## Verification

看到 OSPF 的 `Area 0 / ABR` 就能直接确认它拥有区域层次；BGP 的核心对象则是 AS 间前缀与 AS_PATH，Scope 不同。

## Compression

“AS 内部分区” → **先锁定 IGP → OSPF 的 Area 机制** → 仅 I。

## 易错边界

BGP 也有层次化策略和路由反射等工程机制，但这不等价于 OSPF 的自治系统区域划分。
