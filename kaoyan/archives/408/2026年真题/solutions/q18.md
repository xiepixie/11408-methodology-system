# 408-2026-Q18

> 原题：[[../2026 年全国硕士研究生招生考试#18|Q18]]

## Model Anchor

- Topic：组相联 Cache 的 `block -> set` 映射。
- 题目信号：**1024 行、4 路组相联、块 32 B、给主存字节地址**。
- 第一动作：先算组数，再把字节地址变成主存块号，最后对组数取模。

## 解题链

Cache 共有

$$\frac{1024}{4}=256$$

组。

主存块大小为 32 B，所以地址 1028 所在主存块号为

$$\left\lfloor\frac{1028}{32}\right\rfloor=32.$$

组号为

$$32\bmod256=32.$$

因此答案为 **C**。

## 选项判断

A、B、D 都不是“块号对组数取模”的结果；只有 C=32 正确。

## Verification

块 32 覆盖字节地址 `1024～1055`，1028 确实在其中；而 32 小于 256，所以该块直接映射到组 32。

## Compression

组相联映射 → **组数 = 行数/路数 → 块号 = address/blocksize → set = block mod sets**。

## 易错边界

题目给的是**字节地址**，不能直接用 `1028 mod 256` 当组号；必须先去掉块内偏移。
