# 408-2026-Q41

> 原题：[[../2026 年全国硕士研究生招生考试#41（本题 13 分）|Q41]]

## Model Anchor

- Topic：BST 的有序分割性质与前驱/后继边界。
- 机制：BST 把全局有序关系压到一条搜索路径上。
- 题目信号：目标是最小化 $|key-K|$，并要求所有最优结点。
- 第一动作：不要先做整棵树中序遍历；先问“离 $K$ 最近的 key 在有序序列里可能是谁”。

若存在 key=$K$，最小差为 0，答案唯一；否则最近值只可能是：

- 小于 $K$ 的最大关键字——前驱 `pred`；
- 大于 $K$ 的最小关键字——后继 `succ`。

因此只需沿 BST 搜索路径同时维护这两个边界。

## Problem Representation

### Operation Contract

输入：BST 根指针 `T` 与整数 `K`。  
输出：最小绝对差，以及所有达到该最小差的关键字。

### State / Invariant

搜索到结点 `p` 时：

- `p->data < K`：`p` 是新的前驱候选；之后只有右子树可能给出更大的 `<K` 值；
- `p->data > K`：`p` 是新的后继候选；之后只有左子树可能给出更小的 `>K` 值；
- `p->data == K`：已经达到理论下界 $|key-K|=0$，立即结束。

### 循环不变量

在每轮搜索开始时：

> `pred` 是当前已经排除区域中最大的 `<K` 关键字，`succ` 是当前已经排除区域中最小的 `>K` 关键字；尚未搜索的子树包含所有仍可能改进它们的候选。

## Decision Points

- 竞争路径 A：整棵树中序遍历后在线性有序序列中找最近值，正确但需要 $O(n)$ 时间。
- 选择路径 B：利用 BST 的比较结果每次排除一整棵子树，只维护当前最优前驱/后继，可做到 $O(h)$。
- 停止条件：一旦命中 `key == K`，差值达到理论下界 0，无需继续搜索。

## Solution Chain

### (1) 基本思想

从根开始按 BST 查找 $K$。若当前关键字小于 $K$，记录为新的前驱候选并转向右子树；若大于 $K$，记录为新的后继候选并转向左子树；若等于 $K$，直接输出差值 0 和该关键字。

搜索失败后，比较前驱和后继与 $K$ 的距离。较小者为答案；若两者距离相等，则两个结点都要输出。

### (2) C/C++ 描述

```c
void FindMinDiff(BTNode *T, int K)
{
    BTNode *p = T;
    BTNode *pred = NULL;   // 最大的 < K
    BTNode *succ = NULL;   // 最小的 > K

    while (p != NULL) {
        if (p->data == K) {
            printf("0 %d\n", p->data);
            return;
        }
        else if (p->data < K) {
            pred = p;
            p = p->right;
        }
        else {
            succ = p;
            p = p->left;
        }
    }

    long long dp = pred ? (long long)K - pred->data : LLONG_MAX;
    long long ds = succ ? (long long)succ->data - K : LLONG_MAX;
    long long d = (dp < ds) ? dp : ds;

    printf("%lld", d);
    if (pred != NULL && dp == d)
        printf(" %d", pred->data);
    if (succ != NULL && ds == d)
        printf(" %d", succ->data);
    printf("\n");
}
```

若题目约定树非空，则无需额外处理空树；若允许空树，应在函数入口单独定义“无答案”的输出合同。

### Why Correct

若未找到 $K$，把 BST 的全部 key 按升序看成一个有序序列。任何小于 $K$ 的 key 都不可能比其最大者 `pred` 更接近 $K$；任何大于 $K$ 的 key 都不可能比其最小者 `succ` 更接近 $K$。因此全局最优只可能来自这两个边界。

搜索过程又恰好利用 BST 次序维护出 `pred=max{key<K}` 与 `succ=min{key>K}`，所以比较两者距离不会漏掉任何更优结点。若距离相同，同时输出即可覆盖“所有结点”。

### Complexity

只沿一条根到叶搜索路径：

$$T(n)=O(h),\qquad S_{extra}(n)=O(1),$$

其中 $h$ 为 BST 高度；平衡时为 $O(\log n)$，退化时最坏为 $O(n)$。

## Verification

例如 BST 中存在 `5,15`，取 $K=10$。搜索结束得到 `pred=5`、`succ=15`，两边距离均为 5，因此输出差值 5 和关键字 5、15；若树中存在 10，则立即输出 `0 10`。

## Compression

BST 最近值 → **不要全树扫描** → 搜索路径维护 `pred/succ` → 命中则差 0，否则比较两侧边界 → $O(h)$。

## 易错边界

- “中序遍历有序”能做出 $O(n)$ 解，但没有利用 BST 的搜索能力。
- 不能因为找到一个最近候选就立刻结束；若 $K$ 不存在，前驱和后继可能等距，题目要求输出全部最优结点。
- 复杂度是 $O(h)$，不能无条件写成 $O(\log n)$。
