# 408-2026-Q43

> 原题：[[../2026 年全国硕士研究生招生考试#43（本题 10 分）|Q43]]

## Model Anchor

- Topic：定长指令字的字段解释与 ISA 状态变化。
- 题目信号：**R/I/M 三种格式共享 16 bit，但字段位置和隐含寄存器不同**。
- 第一动作：先画 4 bit 一格的指令格式，再按“字段解释 -> Read Set -> Write Set”解码；数值运算最后做。

## Problem Representation

```text
R 型: 0000 | rt | rs/num | OP1
I 型: OP2  | rt | imm8
M 型: OP3  | offset(12)
```

语义：

```text
R add : R[rt] <- R[rt] + R[rs]
R shl : R[rt] <- R[rt] << num
I addi: R[rt] <- R[rt] + imm8
M load: R[0]  <- M[R[15] + offset]
M store:M[R[15] + offset] <- R[0]
```

## Decision Points

- 第 (2) 问不是比较操作码“数值是否相同”，而是比较**译码时是否位于同一判别位置**。
- 第 (3) 问先解字段，再做 16 位模运算；不能先凭十六进制结果猜寄存器。
- 第 (4) 问先把 $y=16x-5$ 拆成 `load -> shift -> add immediate -> store`，再反推机器码。

## Solution Chain

### (1) 主存单元和通用寄存器宽度

按字节编址意味着一个可寻址主存单元是 1 B：

$$\boxed{8\text{ bit}}.$$

机器字长/运算寄存器宽度为 16 bit，因此通用寄存器宽度：

$$\boxed{16\text{ bit}}.$$

### (2) `OP1/OP2/OP3` 能否同码

R 型先由最高 4 位固定 `0000` 判定格式，`OP1` 位于最低 4 位；I/M 型的主操作码都从最高 4 位进入译码。

因此：

- `OP1` 与 `OP2` 位于不同判别层次，可以取相同编码；
- `OP2` 与 `OP3` 都占最高 4 位，若编码相同，仅凭机器码无法区分 I 型和 M 型，所以不能相同。

$$\boxed{OP1\text{ 与 }OP2\text{ 可以相同；}OP2\text{ 与 }OP3\text{ 不能相同}}.$$

### (3) 执行 `0000 0010 1001 0001`

按 R 型切分：

```text
0000 | 0010 | 1001 | 0001
       rt=2   rs=9   OP1=ADD
```

所以：

$$R2\leftarrow R2+R9.$$

计算：

$$\texttt{ABCDH}+\texttt{F001H}=\texttt{19BCEH}.$$

寄存器只有 16 位，保留低 16 位：

$$\boxed{R2=\texttt{9BCEH}}.$$

R9 只读不写：

$$\boxed{R9=\texttt{F001H}}.$$

### (4) 写出 ①～④

变量 `x、y` 都是 16 位，即 2 B；连续存放时

$$addr(y)=addr(x)+2=R15+2.$$

#### 指令 11：取 `x`

```text
R0 <- M[R15+0]
```

M 型 load 的 `OP3=1110`，所以

$$\boxed{①=1110}.$$

#### 指令 12：左移 4 位

```text
R0 <- R0 << 4
```

R 型编码：

```text
0000 | rt=0000 | num=0100 | OP1=0010
```

所以

$$\boxed{②=0000\ 0100}.$$

#### 指令 13：加 -5

8 位补码：

$$-5=\texttt{FBH}=11111011_2.$$

因此

```text
0100 | rt=0000 | imm8=11111011
```

$$\boxed{③=1111\ 1011}.$$

#### 指令 14：存到 `y`

```text
M[R15+2] <- R0
```

12 位 offset=2：

$$\boxed{④=0000\ 0000\ 0010}.$$

## Verification

两条独立检查：

1. `9BCEH - F001H = ABCDH (mod 2^16)`，第 (3) 问算术闭合；
2. 四条指令的状态链为

```text
R0 <- x
R0 <- 16x
R0 <- 16x - 5
y  <- R0
```

恰好实现目标表达式。

## Compression

```text
定长机器码
-> 先按格式切字段
-> 写 Read/Write Set
-> 再算数值并按位宽截断

高级表达式
-> load -> ALU -> store
-> 逐条反推字段
```

## 易错边界

- Legacy 解析先正确算出 `9BCEH`，后面又误写成 `98CEH`；正确值是 **9BCEH**。
- `y` 与 `x` 都是 16 位，连续存放意味着地址差 **2 B**，不是 1。
- M 型本题隐含使用 R0 与 R15；不要按普通三地址 load/store 自行补 `rs/rt` 字段。
