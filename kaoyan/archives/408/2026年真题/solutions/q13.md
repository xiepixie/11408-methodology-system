# 408-2026-Q13

> 原题：[[../2026 年全国硕士研究生招生考试#13|Q13]]

## Model Anchor

- Topic：补码机器数的算术移位。
- 题目信号：**8 位机器数 + 算术右移 + 算术左移**。
- 第一动作：固定 8 位宽；右移复制符号位，左移低位补 0、高位丢弃。

## 解题链

初始机器数：

```text
1010 0110
```

最高位为 1。算术右移 3 位时左侧补 1：

```text
1010 0110
 -> 1101 0011
 -> 1110 1001
 -> 1111 0100
```

再算术左移 2 位，按 8 位宽保留低 8 位并在低位补 0：

```text
1111 0100 << 2 = 1101 0000
```

故答案为 **A**。

## 选项判断

- A `1101 0000B`：正确。
- B：把右移后的低位残留误保留。
- C、D：最高位变为 0，相当于把有符号算术移位误当成无符号逻辑处理。

## Verification

`10100110B` 按 8 位补码表示 $-90$。算术右移 3 位得到 $-12$（向负方向取整），再左移 2 位得到 $-48$；`11010000B` 正是 $-48$ 的 8 位补码。

## Compression

补码算术移位 → **位宽钉死** → 右移补符号位，左移补 0 丢高位 → 每一步都写完整位串。

## 易错边界

算术左移的位操作与逻辑左移相同，但数值意义可能因溢出而失真；本题问机器数结果，应按固定位宽执行。
