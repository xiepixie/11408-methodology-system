# 408-2026-Q15

> 原题：[[../2026 年全国硕士研究生招生考试#15|Q15]]

## Model Anchor

- Topic：低位交叉编址的模块选择。
- 题目信号：**8 个芯片 + 按字节编址 + 低位交叉**。
- 第一动作：8 个模块需要 3 位模块号；直接比较各地址最低 3 bit 是否相同。

## 解题链

8 个 DRAM 芯片低位交叉，因此地址最低 3 位决定落在哪个芯片：

$$chip=address\bmod8.$$

给定地址 `0018 001DH` 的最低十六进制位为 `D=1101_2`，最低 3 位是 `101`，即芯片号 5。

逐项看最低 3 位：

- A `...D5H`：`D5` 末 3 位为 `101`；
- B `...20H`：末 3 位 `000`；
- C `...1EH`：末 3 位 `110`；
- D `0101 0011B`：末 3 位 `011`。

只有 A 与目标地址位于同一芯片，故选 **A**。

## 选项判断

A 的 `address mod 8 = 5`，与目标一致；B/C/D 分别为 0、6、3，均不一致。

## Verification

低位交叉的目的就是让连续字节轮流落到不同模块，因此相差 8 的整数倍的地址会回到同一芯片；“最低 3 位相同”正是这个条件。

## Compression

低位交叉 + $2^k$ 个模块 → **最低 $k$ 位就是模块号** → 本题看最低 3 位。

## 易错边界

不要把 64 bit 总线宽度误当作模块选择位数；模块数是 8，所以模块号仍只需要 3 位。
