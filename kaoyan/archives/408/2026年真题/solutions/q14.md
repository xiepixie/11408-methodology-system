# 408-2026-Q14

> 原题：[[../2026 年全国硕士研究生招生考试#14|Q14]]

## Model Anchor

- Topic：IEEE 754 单精度编码与舍入。
- 题目信号：**十进制小数 12.1 + round-to-nearest ties-to-even**。
- 第一动作：先把数规格化为 $1.f\times2^e$，确定 sign/exponent，再只对 23 位 fraction 做舍入。

## 解题链

$$12.1=1.5125\times2^3.$$

因此：

- 符号位 $s=0$；
- 阶码 $E=3+127=130=10000010_2$；
- 尾数对应 $0.5125$ 的二进制展开无限循环，需要舍入到 23 位。

按 IEEE 754 就近舍入后，单精度编码为

```text
0 10000010 10000011001100110011010
```

按 4 bit 分组得到

$$\boxed{4141\ 999A_H}.$$

故选 **B**。

## 选项判断

- A：尾数少进 1，属于截断/错误舍入结果。
- B：正确的单精度最近舍入结果。
- C、D：指数段已不对应 12.1 的数量级。

## Verification

12.1 位于 $[8,16)$，规格化指数必为 $e=3$，偏置阶码必须是 130。凡高位阶码不对应 `10000010` 的选项可直接排除。

## Compression

十进制浮点 → **规格化定指数 → 尾数保留 23 位 → 最后做舍入** → 再拼 sign/exponent/fraction。

## 易错边界

不能先把十进制小数简单截断再转十六进制；IEEE 754 的最后一位由指定舍入模式决定。
