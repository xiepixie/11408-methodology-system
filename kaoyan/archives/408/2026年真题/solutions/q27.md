# 408-2026-Q27

> 原题：[[../2026 年全国硕士研究生招生考试#27|Q27]]

## Model Anchor

- Topic：并发执行的数据依赖冲突。
- 题目信号：**给出两个进程的 Read Set / Write Set，问安全并发充要条件**。
- 第一动作：只检查至少一方“写”的交集；读-读不会改变共享状态。

## 解题链

两个进程安全并发需要同时排除：

$$W(P)\cap R(Q)=\emptyset,$$

$$R(P)\cap W(Q)=\emptyset,$$

$$W(P)\cap W(Q)=\emptyset.$$

分别对应题目 I、IV、III。

而

$$R(P)\cap R(Q)$$

只是双方读取同一对象，不会产生写冲突，不要求为空。

因此正确组合为 I、III、IV，答案 **C**。

## 选项判断

- I：写-读冲突必须排除，正确。
- II：读-读可以安全重叠，不是必要条件。
- III：写-写必须排除，正确。
- IV：读-写必须排除，正确。

## Verification

若两个进程都只读变量 `x`，则 `R(P)∩R(Q)={x}` 非空，但执行结果仍与次序无关，直接说明 II 不是必要条件。

## Compression

Bernstein → **只盯包含 W 的三种交集：WR、RW、WW 都要空；RR 无所谓**。

## 易错边界

这里讨论的是“无同步时能否无冲突并发”的充分必要条件，不是说只要集合有冲突就一定无法通过锁/信号量正确并发。
