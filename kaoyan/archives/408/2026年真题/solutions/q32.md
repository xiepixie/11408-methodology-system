# 408-2026-Q32

> 原题：[[../2026 年全国硕士研究生招生考试#32|Q32]]

## Model Anchor

- Topic：设备硬件、ISR、驱动/输入子系统与用户程序之间的数据交付链。
- 题目信号：**问鼠标“中断处理程序”本身负责哪一步**。
- 第一动作：沿数据路径分层：`device -> controller register -> ISR -> kernel buffer -> higher-level decode -> user`。

## 解题链

鼠标硬件把数据送入设备控制器寄存器后产生中断。中断处理程序的关键职责是尽快读取控制器状态/数据寄存器，把原始数据转移到内核缓冲区，并完成必要确认后退出。

因此正确的是 **D**。

## 选项判断

- A：高层事件语义解析通常由后续驱动/输入子系统处理，不要求在硬中断上下文完成。
- B：ISR 不直接把数据同步写进某个用户进程缓冲区。
- C：设备到控制器数据寄存器的传送是硬件路径。
- D：控制器寄存器 → 内核缓冲区，是 ISR 的典型职责，正确。

## Verification

硬中断处理应尽量短；若在 ISR 中完成复杂业务解析或等待用户进程，会显著拉长不可抢占/中断上下文时间，不符合常见设计。

## Compression

I/O 中断路径 → **硬件先到寄存器，ISR 快速搬到内核缓冲，再交给后续软件处理**。

## 易错边界

中断处理程序属于驱动完成路径的一部分，但“驱动程序能做什么”不能全部等价成“硬中断处理程序当场做什么”。
