# 408-2026-Q19

> 原题：[[../2026 年全国硕士研究生招生考试#19|Q19]]

## Model Anchor

- Topic：TLB 组相联映射与页表/TLB 一致性。
- 题目信号：**VPN 要先拆成 TLB Tag + Set Index，再用 P/V 与 PPN 做一致性检查**。
- 第一动作：先由页大小求 VPN 位数，再由 TLB 组数求 index 位数。

## 解题链

页大小 256 B=$2^8$ B，16 位虚拟地址因此 VPN 为 8 位。

TLB 共 16 项、4 路组相联，所以有

$$16/4=4=2^2$$

组，VPN 低 2 位作组号，高 6 位作 Tag。

页号 22=`00010110₂`：

```text
Tag = 000101₂ = 05H
Set = 10₂ = 2
```

主存页表中该页 `P=0, PPN=2AH`。同步后，若组 2 中出现 Tag=05H 的有效 TLB 表项，就不能声称该页仍有效且映射到别的页框。

A 给出 `Tag=05H, V=1, PPN=1CH`，与页表状态直接冲突，因此不可能。

答案为 **A**。

## 选项判断

- A：正好对应 VPN 22，却给出错误的有效位/页框号，不可能。
- B、C、D：对应的是其他 VPN，其页表状态题目未给出，不能据此排除。

## Verification

把 A 的 Tag 和组号重新拼接：`05H << 2 | 2 = 22`，确认它确实就是题目指定的页号，而不是别的页。

## Compression

TLB 题 → **VPN = Tag | Set** → 先定位指定 VPN 对应哪一组/哪个 Tag → 再检查 V/PPN 与页表是否同步。

## 易错边界

TLB 的 `V` 是该 TLB 表项是否可用；页表的 `P` 表示页面是否驻留。两者不是同一个物理字段，但同步状态下必须保持语义一致。
