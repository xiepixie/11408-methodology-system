# 408-2026-Q24

> 原题：[[../2026 年全国硕士研究生招生考试#24|Q24]]

## Model Anchor

- Topic：地址翻译硬件与缺页处理软件的职责分工。
- 题目信号：**谁完成地址转换、谁维护页表、谁处理 Page Fault**。
- 第一动作：把路径拆成 `MMU translate -> detect fault -> trap to OS -> page-in/update -> retry`。

## 解题链

正常访存时，虚拟地址到物理地址的翻译由 MMU/TLB/页表硬件路径完成；页表内容由操作系统运行时管理，而不是编译器静态确定。

若页不在内存，硬件在翻译过程中检测到异常并陷入内核；真正的调页、分配页框、更新页表等由操作系统完成。

因此正确的是 **D**。

## 选项判断

- A：把正常地址翻译从硬件路径偷换成 OS 软件逐次执行，错误。
- B：页表项依赖运行时物理分配，编译器无法预先确定，错误。
- C：硬件负责检测/触发，不直接完成磁盘调页，错误。
- D：缺页异常由 OS 响应处理，正确。

## Verification

Page Fault 处理可能涉及磁盘 I/O、页框分配和页面置换，这些都需要全局资源策略，不能仅靠 MMU 的组合/时序逻辑独立完成。

## Compression

VA 访问 → **硬件翻译**；页不在内存 → **硬件报异常**；页面生命周期恢复 → **OS 处理**。

## 易错边界

“缺页异常由硬件触发”与“缺页由 OS 处理”可以同时成立；触发者和恢复机制 Owner 不是同一个对象。
