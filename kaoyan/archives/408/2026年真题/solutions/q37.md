# 408-2026-Q37

> 原题：[[../2026 年全国硕士研究生招生考试#37|Q37]]

## Model Anchor

- Topic：链路状态变化后的最短路重算与 CIDR 路由聚合。
- 题目信号：**先发生链路故障，再要求“重新计算路由并充分聚合”**。
- 第一动作：严格分两步：先确定故障后的每个目的网络从 $R_1$ 的哪个出口转发；再只对“出口相同且前缀可合法合并”的路由做聚合。

## 解题链

$R_1-R_2$ 链路断开后，$R_1$ 根据新的链路状态数据库重新计算最短路径。重算后共有 5 类需要保留的可达性：Internet、`199.10.20.128/25`，以及其余三个目标前缀。

关键在于重新计算后，下面两个相邻 `/27` 前缀采用相同的转发出口：

```text
199.10.20.0/27
199.10.20.32/27
```

它们的地址范围分别是：

```text
199.10.20.0  ~ 199.10.20.31
199.10.20.32 ~ 199.10.20.63
```

二者正好连续、大小相同，并且在 `/26` 边界上对齐，因此可以聚合为：

$$\boxed{199.10.20.0/26}.$$

于是原先重算后的 5 条路由减少 1 条，充分聚合后剩：

$$5-1=\boxed{4}.$$

答案为 **B**。

## 选项判断

- A 3：还需要再合并一组，但其余前缀并不同时满足“地址可聚合 + 转发出口一致”。
- B 4：`0/27` 与 `32/27` 合并为 `0/26` 后的正确条目数。
- C 5：只完成了最短路重算，没有继续执行题目要求的“充分路由聚合”。
- D 6：比重算后的未聚合路由还多，不符合聚合目标。

## Verification

把两个 `/27` 的第三、四字节低位写成二进制：

```text
199.10.20.0/27  : ... 00000000
199.10.20.32/27 : ... 00100000
```

前 26 位完全相同，第 27 位一条为 0、一条为 1，且二者共享相同出口，所以合并成 `199.10.20.0/26` 不会改变任何目的地址的转发行为。

## Compression

链路故障路由题 → **先 Dijkstra/最短路更新 next hop → 再按出口分组 → 只在同出口组内做 CIDR 聚合 → 最后数条目**。

## 易错边界

- “前缀连续”还不够；若下一跳/出口不同，就不能合并。
- `199.10.20.0/27` 与 `199.10.20.32/27` 是合法 `/26` 配对；`32/27` 与 `64/27` 虽数值相邻，却跨越 `/26` 对齐边界，不能直接聚合。
- 旧抓取题解把答案记为 C=5，实际上停在了“重算完成、尚未充分聚合”的中间状态。
