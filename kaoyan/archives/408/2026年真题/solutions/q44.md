# 408-2026-Q44

> 原题：[[../2026 年全国硕士研究生招生考试#44（本题 13 分）|Q44]]

## Model Anchor

- Topic：从 ISA 的状态变化反推数据通路与控制信号。
- 题目信号：**题目直接给 MUX 编号和控制线，要求取指/左移周期的选择码**。
- 第一动作：绝不先背 `0/1/2`；先写本周期必须完成的微操作，再沿图从源对象走到目标对象，最后读取 MUX 端口编号。

## Problem Representation

本题只需要两组微操作。

取指周期：

```text
MAR <- PC
IR  <- M[MAR]
PC  <- PC + 2
```

左移执行周期：

```text
R[rt] <- R[rt] << num
```

其中 `imm8/num/offset` 在进入 ALU 前都可能经过扩展器；`EXTOP` 只负责控制**零扩展还是符号扩展**。

## Decision Points

- ①②先看“多个输入选一路输出”的结构角色，判定 MUX，而不是根据编号猜具体寄存器。
- `EXTOP` 位数取决于扩展器需要区分多少种**扩展方式**，不是立即数字段一共有多少种来源。
- 控制信号值必须绑定本题图上的端口标号，不能脱离图记忆。

## Solution Chain

### (1) ①、②是什么部件

①、②都把多个候选寄存器编号选择一路送入寄存器组地址端，因此都是：

$$\boxed{\text{多路选择器（MUX）}}.$$

### (2) `EXTOP` 至少需要几位

本题扩展器需要区分两种扩展语义：

```text
zero extension
sign extension
```

2 种状态只需要 1 bit 即可编码：

$$2^1=2.$$

因此

$$\boxed{EXTOP\text{ 至少 1 位}}.$$

I 型无符号 `imm8` 使用零扩展；I 型带符号 `imm8`、M 型带符号 `offset` 使用符号扩展。

### (3) 取指周期控制信号

为了完成

```text
MAR <- PC
PC  <- PC + 2
```

按题 44 图的 MUX 输入编号：

- `MARSrc=0`：MAR 选择 PC；
- `ALUASrc=0`：ALU A 端选择 PC；
- `ALUBSrc=1`：ALU B 端选择常数 2；
- `RegWr=0`：取指周期不写通用寄存器。

所以

$$\boxed{MARSrc=0,\ ALUASrc=0,\ ALUBSrc=1,\ RegWr=0}.$$

### (4) 左移指令执行周期

左移指令要求

$$R[rt]\leftarrow R[rt]\ll num.$$

因此：

- ALU B 端要选择扩展后的 `num`：`ALUBSrc=2`；
- 写回数据来自 ALU：`RegWsrc=1`；
- 目的寄存器为 `rt`：`RegDst=1`；
- 本周期需要写寄存器：`RegWr=1`。

所以

$$\boxed{ALUBSrc=2,\ RegWsrc=1,\ RegDst=1,\ RegWr=1}.$$

左移量 `num` 是无符号量，需要**零扩展**；M 型 `offset` 是带符号偏移，需要**符号扩展**，所以二者的 `EXTOP`：

$$\boxed{\text{不能相同}}.$$

## Verification

把控制信号反向代回数据通路：

- 取指：A=PC、B=2，ALU 产生 `PC+2`；MAR 同时取得旧 PC，且 GPR 写使能关闭；
- 左移：B 端来自扩展器，ALU 结果经写回 MUX 返回 `rt`，目的地址也选择 `rt`。

两条路径都与 Q43 的 ISA 状态变化完全一致。

## Compression

```text
控制信号题
-> 先写微操作
-> 标出每个源/目标
-> 沿数据通路追线
-> 最后读 MUX 端口编号

EXTOP 位数
-> 数“扩展语义”而不是数“立即数来源”
```

## 易错边界

- `EXTOP` 至少 1 位，不是 2 位；本题只需要区分零扩展和符号扩展。
- “左移量来自 4 位字段、offset 来自 12 位字段”属于字段提取/布线差异；`EXTOP` 本身编码的是扩展方式。
- `ALUBSrc=2` 只说明 ALU B 端选扩展器输出，不代表扩展器对 `num` 与 `offset` 可以使用同一种扩展控制。
