# 408-2026-Q21

> 原题：[[../2026 年全国硕士研究生招生考试#21|Q21]]

## Model Anchor

- Topic：特权指令与受控陷入入口。
- 题目信号：**问“哪条指令用户态也必须能执行”**。
- 第一动作：区分“直接操作受保护机器状态”与“请求内核代为执行服务”。

## 解题链

I/O 指令、关中断指令和中断返回指令都会直接改变受保护硬件/处理器状态，通常只能在内核态执行。

系统调用指令则恰恰是用户程序进入内核的受控入口：用户态必须能够执行它，由硬件完成特权级切换后再由内核服务。

因此不属于特权指令的是 **D**。

## 选项判断

- A I/O 指令：直接控制设备，特权。
- B 关中断：可破坏系统可抢占/可响应能力，特权。
- C 中断返回：恢复特权状态和现场，特权。
- D 系统调用：用户态可合法触发，正确答案。

## Verification

如果系统调用指令本身只能在内核态执行，用户程序就无法用它作为进入内核的入口，系统调用机制失去意义。

## Compression

直接改受保护状态 → privileged；**合法请求内核服务的入口** → 用户态可执行 syscall/trap。

## 易错边界

系统调用进入内核后执行的服务代码是内核态；“系统调用指令本身可由用户态执行”与“系统调用服务在用户态执行”不是一回事。
