# 408-2023-Q34

> 原题：[[../2023 年全国硕士研究生招生考试#34|Q34]]

## Model Anchor

- Topic：无噪声信道的 Nyquist 上限。
- 题目信号：明确“无噪声理想信道”，给带宽与最大数据率。
- 第一动作：用 $R_{max}=2B\log_2M$，先求每码元承载 bit 数，再反推调制状态数。

## 解题链

$$48\text{ Mbps}=2\times4\text{ MHz}\times\log_2 M.$$

因此

$$\log_2 M=\frac{48}{8}=6,$$

$$M=2^6=64.$$

所以应采用 QAM-64。

## 选项判断

$$\boxed{C}$$

## Verification

4 MHz 理想信道的最大码元率为 8 Mbaud；每码元 6 bit 时恰有 $8\times6=48$ Mbps。

## Compression

```text
无噪声 + 带宽 + 数据率 -> Nyquist -> bits/symbol -> M=2^k
```

## 易错边界

Nyquist 针对无噪声码元速率；若题目给信噪比并问噪声信道上限，应考虑 Shannon，而不是混用公式。
