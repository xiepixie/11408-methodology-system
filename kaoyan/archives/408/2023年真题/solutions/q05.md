# 408-2023-Q05

> 原题：[[../2023 年全国硕士研究生招生考试#5|Q5]]

## Model Anchor

- Topic：已知树形 + 后序序列恢复先序。
- 题目信号：树的**结构已经由图给定**，后序只负责把结点标签放回对应位置。
- 第一动作：从后序最后一个元素确定根，再沿题图的左右子树结构递归分配标签。

## 解题链

后序序列为

```text
f d b e c a
```

后序的最后一个元素必为根，所以根为 `a`。按题图给出的左右子树形状继续把后序中的子序列分配到相应子树后，再按

```text
根 -> 左子树 -> 右子树
```

进行先序遍历，得到：

```text
a e d f b c
```

即 `aedfbc`。

## 选项判断

$$\boxed{A}$$

## Verification

把恢复出的树重新做后序遍历，应回到 `f,d,b,e,c,a`，与题设完全一致。

## Compression

```text
树形已知 + 后序 -> 最后一个先定根 -> 递归贴标签 -> 根左右得到先序
```

## 易错边界

只有遍历序列而没有树形/中序信息时，通常不能唯一恢复一般二叉树；本题能做是因为题图已经锁定结构。
