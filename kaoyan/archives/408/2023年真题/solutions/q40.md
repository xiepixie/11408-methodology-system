# 408-2023-Q40

> 原题：[[../2023 年全国硕士研究生招生考试#40|Q40]]

## Model Anchor

- Topic：IPv4 与 IPv6 的地址空间、首部和过渡机制。
- 题目信号：四个跨版本绝对命题。
- 第一动作：分别检查数量级、基本首部长度、迁移技术和同义字段，不把“更大/更简化”写成模糊印象。

## 解题链

I. IPv4 地址空间为 $2^{32}$，IPv6 为 $2^{128}$，后者是前者的

$$2^{96}$$

倍，不是 96 倍，错误。

II. IPv4 基本首部长度可变；IPv6 的基本首部固定为 40 B，扩展功能放在扩展首部，故错误。

III. 双协议栈和隧道都是 IPv4→IPv6 的典型过渡技术，正确。

IV. IPv6 的 Hop Limit 与 IPv4 的 TTL 都在每经过一跳时递减，用于限制分组生命周期，语义等价，正确。

## 选项判断

$$\boxed{D}$$

## Verification

只有 III、IV 同时成立；任一包含 I 或 II 的组合都可直接排除。

## Compression

```text
IPv6 vs IPv4
address: 2^128 vs 2^32
base header: 40B fixed vs IPv4 variable
transition: dual-stack/tunnel
HopLimit ~ TTL
```

## 易错边界

“IPv6 没有可变首部”应准确说成“基本首部固定”；可选功能通过扩展首部链实现。
