# 408-2023-Q07

> 原题：[[../2023 年全国硕士研究生招生考试#7|Q7]]

## Model Anchor

- Topic：B 树插入/删除后的结构变化。
- 题目信号：四个“可能/一定/最终”式绝对命题。
- 第一动作：分别拿**根分裂、内部命中、叶分裂提升、删除重平衡**做最小反例。

## 解题链

I. 插入可能使根结点分裂，从而树高增加，正确。

II. 删除关键字最终需要在叶层完成删除；若关键字原在内部结点，也会与前驱/后继关键字交换并落实到叶层，因此会引起叶结点内容变化，正确。

III. 查找关键字可能在内部结点就命中，不必到叶结点，错误。

IV. 新关键字最初插入叶结点，但分裂时中间关键字可能被提升到父结点，故最终不一定仍在叶结点，错误。

所以只有 I、II 正确。

## 选项判断

$$\boxed{B}$$

## Verification

“根满后插入”即可验证 I；“叶分裂后中间关键字上升”即可否定 IV。

## Compression

```text
B树绝对命题 -> 用 split / promote / internal-hit / delete-rebalance 逐条攻击
```

## 易错边界

不要把 B+ 树的“数据记录都在叶层”印象套到 B 树；B 树内部结点本身就可保存并命中关键字。
