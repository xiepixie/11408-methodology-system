# 408-2023-Q38

> 原题：[[../2023 年全国硕士研究生招生考试#38|Q38]]

## Model Anchor

- Topic：NAT 出站源地址改写。
- 题目信号：R2 是 NAT 边界，H 向 Internet 发包。
- 第一动作：先确定方向：inside -> outside；出站 NAT 改的是源端身份，并使用 NAT 路由器外侧可路由地址。

## 解题链

题图中 H 位于 R2 的内侧网络。分组经过 R2 向 Internet 转发时，R2 需要把 H 的私网源地址替换为自己外侧接口地址，使返回分组能够先到达 NAT 边界再按映射表反向转换。

题图给出的 R2 外侧地址为：

$$\boxed{192.168.0.33}.$$

因此经过 R2 后，IP 分组的源 IP 地址为 192.168.0.33。

## 选项判断

$$\boxed{A}$$

## Verification

NAT 出站后若仍保留 H 的内侧地址，Internet 侧就不能按该私有作用域地址正确返回；若改成其他路由器/主机地址，也不匹配 R2 所维护的映射 owner。

## Compression

```text
inside -> NAT -> Internet
源IP改写为 NAT outside-interface address
```

## 易错边界

NAT 不是“把源地址改成下一跳地址”；它改成 NAT 设备自身用于外部通信的地址，并维护反向映射状态。
