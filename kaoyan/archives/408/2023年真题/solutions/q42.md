# 408-2023-Q42

> 原题：[[../2023 年全国硕士研究生招生考试#42（10 分）|Q42]]

## Model Anchor

- Topic：Replacement Selection 生成初始归并段。
- 题目信号：工作区只能容纳 $m$ 个记录，但 run 可以长于 $m$。
- 第一动作：维护两个状态：`当前 run 的 lastOutput` 与工作区中记录是否仍有资格进入当前 run；每次输出当前可选的最小关键字。

## Problem Representation

```text
workspace capacity = m = 4
active record      = key >= lastOutput，可进入当前 run
frozen record      = key < lastOutput，只能留到下一 run
```

核心不变量：**同一个初始归并段中的输出必须保持非递减**。因此新读入记录若小于刚输出的关键字，就必须冻结。

## Decision Points

- 这不是“4 个一组排序”；工作区中的空位会被后续输入不断补充，所以 run 可以远长于 4。
- 不能只按输入序列切段；切换 run 的真正事件是“当前工作区已没有任何 active 记录”。

## Solution Chain

### (1) m=4 时生成的初始归并段

初始装入：

```text
51, 94, 37, 92
```

每次选择当前 run 中最小的 active 记录输出，并读入下一个输入。按 `newKey >= lastOutput` 决定 active/frozen，可得到：

#### Run 1

$$\boxed{37,\ 51,\ 63,\ 92,\ 94,\ 99}$$

后续小于当前 `lastOutput` 的 14、15、48、56 等记录逐步被冻结；当 active 集合清空时结束第一段。

#### Run 2

重新激活冻结记录后继续：

$$\boxed{14,\ 15,\ 23,\ 31,\ 48,\ 56,\ 60,\ 90,\ 166}$$

#### Run 3

最后剩余：

$$\boxed{8,\ 17,\ 43,\ 100}$$

因此共生成：

$$\boxed{3\text{ 个初始归并段}}.$$

### (2) 第一个初始归并段长度的最大值与最小值

#### 最大值

若后续每个读入记录都不小于当前输出值，则没有记录被冻结，整个文件都可以进入第一个 run：

$$\boxed{L_{max}=n}.$$

例如输入整体非递减就是最直接的构造。

#### 最小值

最初工作区已有 $m$ 个记录，这 $m$ 个记录最终都必须被输出到第一段；随后若每个新读入记录都小于当前 `lastOutput`，它们全部被冻结，第一段在初始 $m$ 个记录输出完后立即结束。

因此：

$$\boxed{L_{min}=m}.$$

## Verification

三个 run 的记录总数：

$$6+9+4=19,$$

恰好覆盖原文件 19 个记录；且每个 run 内部均非递减，没有丢失或重复记录。

边界公式也满足：

$$m\le L_1\le n.$$

## Compression

```text
Replacement Selection
-> 输出 active 中最小值
-> 新记录 >= lastOutput：留在当前 run
-> 新记录 < lastOutput：freeze 到下一 run
-> active 清空才换 run

首 run 长度：m <= L1 <= n
```

## 易错边界

- 置换—选择不等于“每 m 个记录内部排序”。
- 冻结条件比较的是**当前 run 最近输出的关键字**，不是工作区最小值或最初边界。
- Legacy 文本把三个 run 粘连在一行，本解按状态机重新模拟后恢复为 6、9、4 三段。
