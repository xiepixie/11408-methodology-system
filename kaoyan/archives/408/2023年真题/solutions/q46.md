# 408-2023-Q46

> 原题：[[../2023 年全国硕士研究生招生考试#46（8 分）|Q46]]

## Model Anchor

- Topic：blocking 键盘输入的一次完整控制流。
- 题目信号：系统调用、阻塞队列、设备中断、系统缓冲区、就绪队列、返回用户程序全部出现。
- 第一动作：同时画三条线：`task state`、`device/data path`、`CPU control path`；尤其记住 **I/O completion 只让 P runnable，不等于 P 立刻 running**。

## Problem Representation

六个给定操作的因果关系是：

```text
P 发起阻塞式输入系统调用
-> ② P 进入阻塞队列
-> CPU 运行其他进程
-> ⑥ 用户输入字符
-> ④ 启动键盘中断处理程序
-> ③ 驱动从控制器读取字符到系统缓冲区
-> ① 唤醒 P：插入就绪队列
-> scheduler 以后选择 P
-> ⑤ P 从系统调用返回
```

其中“调度/切换”本身没有编号，但必须作为 ① 与 ⑤ 之间的隐含控制事件保留。

## Decision Points

- ② 是 Wait/Block：P 已不具备继续执行条件，所以 CPU 必须换走。
- ① 是 Wakeup：只恢复调度资格，P 先进入 Ready，不应直接写成 Running。
- ③ 是设备相关数据搬运，属于键盘驱动程序职责；中断入口/保存现场与具体读控制器寄存器要分层。

## Solution Chain

### (1) 操作顺序关系

在列出的操作中，①“将 P 插入就绪队列”发生在字符已经从设备取到系统缓冲区之后，因此其前一个操作是：

$$\boxed{③}.$$

P 被唤醒并最终重新获得 CPU 后，才能继续完成阻塞系统调用并返回，因此 ① 后面的下一个已列操作是：

$$\boxed{⑤}.$$

用户按键 ⑥ 使键盘控制器产生中断请求，CPU 响应后启动中断处理程序，因此 ⑥ 后一个操作是：

$$\boxed{④}.$$

所以：

$$\boxed{③\to①\to⑤},\qquad\boxed{⑥\to④}.$$

### (2) 哪一步必然切走 P；何时 P 才能被调度

执行 ② 后，P 已进入阻塞队列：

```text
Running(P) -> Blocked(P)
```

阻塞态线程不能继续占用 CPU，所以：

$$\boxed{②\text{ 之后 CPU 一定切换到其他可运行实体}}.$$

只有完成 ① 后，P 才从等待关系中解除并进入就绪队列：

```text
Blocked(P) -> Ready(P)
```

此后调度程序才有资格选择 P：

$$\boxed{①\text{ 之后}}.$$

### (3) 哪一步属于键盘驱动程序

把字符从键盘控制器的数据寄存器读出并放入 OS 系统缓冲区，是典型的设备驱动数据路径：

$$\boxed{③}.$$

### (4) 中断处理程序执行时 P 与 CPU 的状态

在考试抽象的中断处理阶段，字符尚未完成唤醒链之前，P 仍在等待键盘输入：

$$\boxed{P\text{ 处于阻塞态}}.$$

中断处理程序属于内核代码，需要访问设备控制器和受保护的内核状态，因此 CPU 处于：

$$\boxed{\text{内核态}}.$$

完成 ③ 并执行唤醒后，P 才转为 Ready；即使此时中断处理尚在收尾，也不能把 Ready 直接写成 Running。

## Verification

沿等待条件检查：

```text
输入尚未到达 -> P Blocked
输入到达并被驱动取走 -> 等待条件满足
wakeup -> P Ready
scheduler/dispatch -> P Running
syscall return -> user mode
```

这条链同时解释了为什么 ② 后必须换人、① 后才能被选中、以及 ① 不能直接等于“P 已运行”。

## Compression

```text
blocking input
-> enqueue wait(②)
-> device event(⑥)
-> interrupt(④)
-> driver moves data(③)
-> wake Ready(①)
-> scheduler
-> syscall return(⑤)
```

## 易错边界

- Wakeup ≠ Running；① 只把 P 放回 runnable 集合。
- 中断发生时正在 CPU 上运行的通常是别的进程；中断处理程序并不是“由阻塞的 P 在运行”。
- ③ 属于驱动的数据搬运职责；④ 是中断控制路径，二者不能混成同一个事件。
