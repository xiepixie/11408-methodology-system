# 408-2023-Q01

> 原题：[[../2023 年全国硕士研究生招生考试#1|Q1]]

## Model Anchor

- Topic：顺序表的操作成本。
- 题目信号：**顺序存储 + 已知下标 i**。
- 第一动作：把操作拆成 `Locate` 与 `Update`，看是否需要搜索或移动元素。

## 解题链

顺序表支持按下标直接计算地址：

$$addr(A[i])=base+i\times sizeof(Elem),$$

因此“获取第 i 个元素”不需要遍历，平均时间为 $O(1)$。

按值查找要搜索；插入、删除通常要移动后续元素，平均均为 $O(n)$。

## 选项判断

$$\boxed{D}$$

## Verification

只有 D 的工作量与 $n$ 无关；其余操作至少在一般情况下访问或移动与 $n$ 成比例的元素。

## Compression

```text
顺序表 + 已知下标 -> 地址公式直接定位 -> O(1)
```

## 易错边界

“顺序存储”不意味着所有操作都是 $O(1)$；直接定位是 $O(1)$，插删的移动成本仍要计算。
