# 408-2023-Q19

> 原题：[[../2023 年全国硕士研究生招生考试#19|Q19]]

## Model Anchor

- Topic：五级流水线的数据冒险与控制冒险。
- 题目信号：**有转发处理数据冒险 + 硬件阻塞处理控制冒险**。
- 第一动作：逐条依赖比较 `producer ready` 与 `consumer need`，再单独处理分支后的年轻指令。

## 解题链

依赖关系：

```text
I1 add  -> 产生 s2
I2 load -> 用 s2 作地址，并产生 s3
I3 beq  -> 读取 s3 决定分支
I4 addi -> 位于尚未决出的分支之后
```

I1→I2：ALU 结果可经旁路及时送给 I2 的 EX 段，不必阻塞 I2。

I2→I3：load 的数据到 MEM 之后才可用，而紧随其后的 I3 更早需要 s3，属于 load-use hazard，所以 **I3 必须阻塞**。

I3 是分支指令，题设又明确采用硬件阻塞处理控制冒险，因此在分支结果确定前，后继 **I4 也要被阻塞**。

## 选项判断

$$\boxed{C}$$

## Verification

若没有 I2→I3 的停顿，I3 会在 s3 尚未从存储器返回时使用旧值；若不阻塞 I4，则与题设的控制冒险处理策略矛盾。

## Compression

```text
RAW -> ready vs need
load-use -> I3 stall
branch用硬件阻塞 -> I4 等待分支决定
```

## 易错边界

“有 forwarding”不代表所有 RAW 都零停顿；load-use 是最典型的 ready 晚于 need。
