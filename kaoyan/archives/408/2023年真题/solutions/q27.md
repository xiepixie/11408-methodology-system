# 408-2023-Q27

> 原题：[[../2023 年全国硕士研究生招生考试#27|Q27]]

## Model Anchor

- Topic：执行态线程的状态迁移。
- 题目信号：事件由“当前线程引起/执行”，问可能 `Running -> Ready`。
- 第一动作：先问线程是否仍具备运行条件，只是主动放弃 CPU；若在等待事件，则应进 Blocked。

## 解题链

- 键盘输入是外部事件，不是当前线程主动导致其转为 Ready；
- 缺页异常通常使线程等待页面调入，`Running -> Blocked`；
- 主动出让 CPU 后线程仍然可运行，只是放弃当前处理机，因此 `Running -> Ready`；
- `wait()` 若资源不可得，会使线程等待同步条件，通常 `Running -> Blocked`。

## 选项判断

$$\boxed{C}$$

## Verification

Ready 的定义是“除 CPU 外运行条件均满足”；主动 yield 恰好满足这一状态描述。

## Compression

```text
Running状态题 -> 等事件？Blocked；仍可运行但失去CPU？Ready
主动让出CPU -> Ready
```

## 易错边界

`wait()` 并非一定阻塞，但题目问“可能导致 Running->Ready”，其典型失败路径是 Blocked，不是 Ready。
