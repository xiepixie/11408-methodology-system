# 408-2023-Q20

> 原题：[[../2023 年全国硕士研究生招生考试#20|Q20]]

## Model Anchor

- Topic：非突发总线读取主存块的事务成本。
- 题目信号：64 bit 总线、1 GHz、主存准备 64 bit 需 6 ns、**不支持突发**、块 32 B。
- 第一动作：先算一个 64 bit 数据事务的完整时间，再乘块内事务数。

## 解题链

总线周期：

$$T_{bus}=1/1\text{ GHz}=1\text{ ns}.$$

一次 64 bit 读取至少包含：

```text
地址传送 1 ns
主存准备   6 ns
数据传送   1 ns
```

故一次事务为 8 ns。

主存块 32 B，而每次传 64 bit=8 B：

$$32/8=4\text{ 次事务}.$$

又因不支持突发传送，每次都要重新发送地址，因此：

$$T=4\times8=\boxed{32\text{ ns}}.$$

## 选项判断

$$\boxed{D}$$

## Verification

如果支持 burst，后续数据可能省掉重复地址阶段；题目特意强调“不支持突发”，说明 4 次事务的地址开销都必须保留。

## Compression

```text
块读取 -> 每事务有效字节数 -> 事务数
非burst -> 每次都付 address + memory + data 成本
```

## 易错边界

不能直接用“块大小/总线带宽”得到 4 ns；主存准备时间和协议周期都属于真实串行成本。
