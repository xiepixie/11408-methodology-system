# 408-2023-Q41

> 原题：[[../2023 年全国硕士研究生招生考试#41（13 分）|Q41]]

## Model Anchor

- Topic：邻接矩阵上的入度/出度统计。
- 题目信号：定义 K 顶点为 `outdegree > indegree`，图已经固定采用邻接矩阵。
- 第一动作：先把矩阵的**行/列语义**钉死：`Edge[v][j]` 表示从 v 出发，`Edge[i][v]` 表示进入 v。

## Problem Representation

### Operation Contract

```text
Input : 任意非空有向图 G，邻接矩阵 Edge
Output: 输出所有 out(v) > in(v) 的顶点
Return: K 顶点总数
```

### State / Invariant

对每个顶点 `v`：

```text
outdegree(v) = 第 v 行中非零边数
indegree(v)  = 第 v 列中非零边数
```

只要行、列扫描都覆盖 `0..n-1`，统计值就与图中真实入/出边数一致。

## Decision Points

- 题目已经指定邻接矩阵，不需要另建邻接表。
- 可以对每个顶点分别扫一行一列；也可以一次双循环同时累计所有顶点的入/出度。两者时间复杂度都为 $O(V^2)$。
- 为避免把带权矩阵的权值误加成“度”，代码使用 `Edge[i][j] != 0` 来计边，而不是直接累加边权。

## Solution Chain

### (1) 设计思想

遍历所有顶点。对顶点 `v`，扫描矩阵第 `v` 行统计出度，扫描第 `v` 列统计入度；若

$$outdegree(v)>indegree(v),$$

则输出该顶点并把 K 顶点计数加 1。全部顶点处理完后返回计数。

### (2) C/C++ 实现

```c
int printVertices(MGraph G)
{
    int count = 0;
    int n = G.numVertices;

    for (int v = 0; v < n; ++v) {
        int outdegree = 0;
        int indegree = 0;

        for (int i = 0; i < n; ++i) {
            if (G.Edge[v][i] != 0) ++outdegree; // v -> i
            if (G.Edge[i][v] != 0) ++indegree;  // i -> v
        }

        if (outdegree > indegree) {
            printf("%c ", G.VerticesList[v]);
            ++count;
        }
    }

    return count;
}
```

时间复杂度：

$$\boxed{O(V^2)}.$$

除常数变量外不申请与图规模相关的辅助空间：

$$\boxed{O(1)}.$$

## Verification

每条有向边 $u\to v$ 在扫描过程中恰好：

- 为 `outdegree(u)` 贡献 1；
- 为 `indegree(v)` 贡献 1。

因此全图还有守恒检查：

$$\sum_v outdegree(v)=\sum_v indegree(v)=|E|.$$

这说明行/列方向没有写反。

## Compression

```text
邻接矩阵有向图
-> 行数出度、列数入度
-> 对每个 v 比较 out(v) 与 in(v)
-> out>in 就输出并计数
```

## 易错边界

- `numVertices` 才是顶点循环次数，不能写成 `numEdges`。
- 若矩阵保存的是边权，统计度必须数“非零项个数”，不能把权值直接相加。
- 自环同时贡献一个入度和一个出度，因此不会改变 `out-in` 的符号。
