# 408-2023-Q22

> 原题：[[../2023 年全国硕士研究生招生考试#22|Q22]]

## Model Anchor

- Topic：I/O 控制方式的“谁推进数据搬运”。
- 题目信号：查询、中断、DMA 三种方式并列。
- 第一动作：不要只看“CPU 最终都参与”；先找每个数据传输阶段的 State Owner。

## 解题链

- 查询方式：CPU 执行查询程序，反复检查设备状态并完成传送，A 正确；
- 中断方式：设备就绪后 CPU 执行中断服务程序推进 I/O，B 正确；
- DMA 方式：CPU 负责初始化 DMA 控制器，但大批量数据搬运由 DMA 控制器直接在设备接口与主存之间推进，并不存在 CPU 执行“DMA 传送程序”逐数据搬运，C 错误；
- SSD、网络适配器等高速设备适合 DMA，D 正确。

## 选项判断

$$\boxed{C}$$

## Verification

若 DMA 仍要求 CPU 对每个字/块执行传送程序，就失去了 Direct Memory Access 减少 CPU 搬运开销的核心意义。

## Compression

```text
I/O方式题 -> 先问谁搬数据
poll/interrupt: CPU参与数据搬运
DMA: CPU配置，DMA controller搬运
```

## 易错边界

DMA 完成后仍可能通过中断通知 CPU；“CPU 最后处理 completion”不等于“CPU 执行 DMA 数据传送”。
