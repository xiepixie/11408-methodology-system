# 408-2023-Q12

> 原题：[[../2023 年全国硕士研究生招生考试#12|Q12]]

## Model Anchor

- Topic：CPU 性能指标。
- 题目信号：同时给主频、指令数、平均 CPI。
- 第一动作：所有性能量先回到两个基本式：`IPS=f/CPI` 与 `CPU time=IC×CPI/f`。

## 解题链

指令执行速度：

$$\frac{1.5\times10^9}{1.2}=1.25\times10^9\text{ instr/s}=1.25\text{ GIPS}.$$

用户 CPU 时间：

$$T=\frac{5\times10^5\times1.2}{1.5\times10^9}
=4\times10^{-4}\text{ s}=0.4\text{ ms}.$$

## 选项判断

$$\boxed{C}$$

## Verification

$5\times10^5$ 条指令、约 1 GIPS 的机器，执行时间应是亚毫秒量级，不可能是 $0.4\ \mu s$。

## Compression

```text
主频+CPI -> IPS=f/CPI
IC+CPI+f -> T=IC*CPI/f
```

## 易错边界

GIPS 是“每秒十亿条指令”，CPU time 仍要乘实际指令条数；不能只比较主频。
