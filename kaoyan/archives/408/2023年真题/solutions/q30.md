# 408-2023-Q30

> 原题：[[../2023 年全国硕士研究生招生考试#30|Q30]]

## Model Anchor

- Topic：不同进程共享同一物理页面。
- 题目信号：同一共享数据 `data` 在 R、S 中分别有页号 p1、p2 和页框号 f1、f2。
- 第一动作：把“虚拟名字”和“物理对象”分开：共享要求物理 frame identity 相同，不要求两个进程使用同一 VPN。

## 解题链

不同进程有独立页表，因此同一个共享物理页面可以映射到不同的虚拟页号：

$$p_1\text{ 与 }p_2\text{ 不一定相等}.$$

但若两进程确实共享同一份物理 `data`，对应页表项必须最终指向同一个物理页框：

$$f_1=f_2.$$

## 选项判断

$$\boxed{C}$$

## Verification

共享内存常见模型就是：

```text
R: VPN p1 -> PFN f
S: VPN p2 -> PFN f
```

虚拟地址不同，但访问的是同一物理内容。

## Compression

```text
shared data -> physical frame identity same
per-process VA -> VPN may differ
```

## 易错边界

“相同虚拟地址”既不是共享的必要条件，也不是共享的充分条件；关键是页表是否指向同一物理对象。
