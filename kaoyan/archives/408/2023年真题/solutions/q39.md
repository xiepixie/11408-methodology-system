# 408-2023-Q39

> 原题：[[../2023 年全国硕士研究生招生考试#39|Q39]]

## Model Anchor

- Topic：CIDR 前缀确定网络边界。
- 题目信号：`168.16.84.24/20`，问最小/最大可分配地址。
- 第一动作：先求 `/20` 的第三字节块大小 $2^{8-4}=16$，再找 84 落在哪个 16 地址块。

## 解题链

`/20` 掩码为：

```text
255.255.240.0
```

第三字节每个子网跨度 16：

```text
0~15, 16~31, ..., 80~95, 96~111, ...
```

84 落在 `80~95`，因此：

- 网络地址：`168.16.80.0`；
- 广播地址：`168.16.95.255`；
- 最小可分配：`168.16.80.1`；
- 最大可分配：`168.16.95.254`。

## 选项判断

$$\boxed{B}$$

## Verification

$$84\ \&\ 240=80,$$

按位与得到第三字节网络部分 80，与块边界法一致。

## Compression

```text
/prefix -> block size -> network/broadcast -> usable = +1 / -1
```

## 易错边界

`84` 是主机地址中的第三字节，不代表网络从 84 开始；必须先按 `/20` 对齐到 16 的倍数。
