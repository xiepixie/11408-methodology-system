# 408-2023-Q03

> 原题：[[../2023 年全国硕士研究生招生考试#3|Q3]]

## Model Anchor

- Topic：稀疏矩阵的三元组表示。
- 题目信号：问“除三元组外还必须保存什么”。
- 第一动作：区分**矩阵形状**与“哪些行/列恰好含非零元”的派生统计。

## 解题链

每个三元组只描述一个非零元的 `(row, col, value)`。仅靠这些三元组无法知道矩阵完整的行数和列数，尤其无法表达末尾全零行或全零列。

因此必须额外保存矩阵的：

- 行数 I；
- 列数 III。

“含非零元素的行数/列数”可以从三元组扫描得到，不是表示矩阵所必需的结构参数。

## 选项判断

$$\boxed{A}$$

## Verification

设最后若干行全为 0，则三元组中完全没有这些行的信息；不保存总行数就无法恢复原矩阵维度。

## Compression

```text
稀疏三元组 -> 保存非零元
完整矩阵身份 -> 还必须保存 rows + cols
```

## 易错边界

不要把“可统计得到的信息”与“表示必须保存的信息”混在一起。
