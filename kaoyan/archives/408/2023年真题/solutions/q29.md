# 408-2023-Q29

> 原题：[[../2023 年全国硕士研究生招生考试#29|Q29]]

## Model Anchor

- Topic：抢占式优先级调度。
- 题目信号：新进程到达时优先级可能更高，且数值越大优先权越高。
- 第一动作：固定 `arrival -> candidate set -> max priority -> preempt`，画事件时间线后再算周转时间。

## 解题链

时间线：

```text
0~20   P1   （20 ms 后 P2 到达并抢占）
20~30  P2   （10 ms 后 P3 到达并抢占）
30~43  P3   完成
43~75  P2   剩 32 ms，完成
75~115 P1   剩 40 ms，完成
```

完成时刻：

```text
P1 = 115 ms
P2 = 75 ms
P3 = 43 ms
```

周转时间：

$$T_1=115-0=115,$$
$$T_2=75-20=55,$$
$$T_3=43-30=13.$$

平均：

$$\bar T=\frac{115+55+13}{3}=\frac{183}{3}=61\text{ ms}.$$

## 选项判断

$$\boxed{B}$$

## Verification

三段 CPU 总执行时间 $60+42+13=115$ ms，最后完成时刻正好也是 115 ms，说明时间线没有空洞或重复计时。

## Compression

```text
抢占优先级 -> 只在到达/完成事件点重选 -> 画 timeline -> completion-arrival
```

## 易错边界

“优先级越大越高”由题设明确，不能套用某些系统中“数值越小优先级越高”的约定。
