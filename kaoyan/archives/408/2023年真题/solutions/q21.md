# 408-2023-Q21

> 原题：[[../2023 年全国硕士研究生招生考试#21|Q21]]

## Model Anchor

- Topic：异常/中断的检测时机与请求链路。
- 题目信号：比较 CPU 内部异常、指令边界外部中断、设备中断控制器。
- 第一动作：把每个事件写成 `source -> detector -> response point`。

## 解题链

- 异常通常与当前指令执行有关，CPU 在指令执行过程中检测，A 正确；
- 外部中断通常在指令边界检查并响应，B、C 符合题设的开中断条件；
- 外部设备通过中断控制器向 CPU 提交的是**中断请求**，不是“中断结束信号”。

所以 D 错误。

## 选项判断

$$\boxed{D}$$

## Verification

若设备发的是“结束信号”，CPU 根本没有获得“需要服务”的请求语义；设备完成某事件后应触发 IRQ/request，CPU 再决定是否响应。

## Compression

```text
异常 -> 当前指令内部检测
外部中断 -> 指令边界检查
设备 -> interrupt request，不是 interrupt end
```

## 易错边界

本轮审阅发现 Canonical Source 曾把 D 误写成“发中断请求信号”，那样会使 D 变成正确命题并破坏单选题；已按题意与 legacy 原文恢复为“中断结束信号”。
