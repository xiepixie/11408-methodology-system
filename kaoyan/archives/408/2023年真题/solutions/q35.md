# 408-2023-Q35

> 原题：[[../2023 年全国硕士研究生招生考试#35|Q35]]

## Model Anchor

- Topic：Stop-and-Wait、GBN、SR 的最大窗口与信道利用率。
- 题目信号：三种协议共用 3 bit 序号，SR 又规定发送/接收窗口相等且取最大值。
- 第一动作：先从序号空间得到各协议最大 `Ws`，再比较同一 RTT/帧长下可并行在途帧数。

## 解题链

序号空间：

$$N=2^3=8.$$

- 停-等：$W_s=1$；
- GBN：最大 $W_s=N-1=7$；
- SR：为避免新旧帧歧义且 $W_s=W_r$，有
  $$W_s+W_r\le N,$$
  因而最大 $W_s=W_r=4$。

同一信道、相同帧长与传播条件下，发送窗口越大，最大可保持的在途数据越多，因此：

$$U_1\le U_3\le U_2.$$

## 选项判断

$$\boxed{B}$$

## Verification

窗口上界依次为 `1,4,7`（按 Stop-and-Wait、SR、GBN 排列），所以最大利用率的偏序与之相同；若链路已饱和，允许出现等号。

## Compression

```text
3-bit seq -> N=8
StopWait=1, SR<=4, GBN<=7
同成本模型 -> U1 <= U3 <= U2
```

## 易错边界

SR 的窗口不能也取 7；SR 必须保留至少半个序号空间来区分上一轮迟到帧与新一轮同序号帧。
