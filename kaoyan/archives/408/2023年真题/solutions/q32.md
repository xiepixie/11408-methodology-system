# 408-2023-Q32

> 原题：[[../2023 年全国硕士研究生招生考试#32|Q32]]

## Model Anchor

- Topic：设备分配的候选集与约束。
- 题目信号：类型、权限、占用状态、逻辑/物理映射四类因素。
- 第一动作：把设备分配看成“先过滤合法候选，再选择具体实例”，逐项检查是否影响合法性或可定位性。

## 解题链

设备分配至少要考虑：

1. **设备类型**：请求必须与设备能力匹配；
2. **访问权限**：进程必须有权使用该设备；
3. **占用状态**：独占设备已被占用时不能再次分配；
4. **逻辑设备到物理设备映射**：设备独立性要求系统把逻辑请求解析到可用物理实例。

四项都属于分配决策的约束或路由信息。

## 选项判断

$$\boxed{D}$$

## Verification

任意删去一项都可构造错误分配：类型不匹配、越权、重复独占或无法找到真实设备。

## Compression

```text
设备分配 -> type + permission + occupancy + logical→physical mapping
```

## 易错边界

“设备独立性”不是说分配时无需物理设备映射，而是把映射责任从应用程序移到 OS。
