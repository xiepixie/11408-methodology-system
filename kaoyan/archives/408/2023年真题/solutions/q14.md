# 408-2023-Q14

> 原题：[[../2023 年全国硕士研究生招生考试#14|Q14]]

## Model Anchor

- Topic：IEEE 754 单精度非规格化数。
- 题目信号：机器数 `80200000H` 的阶码字段全 0。
- 第一动作：先分类 `zero/subnormal/normal/inf/NaN`，不能直接套规格化数的隐藏 1。

## 解题链

`80200000H` 中：

- 符号位 $s=1$；
- 阶码 $E=0$；
- 尾数字段非 0，因此是**负的非规格化数**。

非规格化数：

$$x=(-1)^s\times(0.f)_2\times2^{-126}.$$

`0x200000` 对应尾数字段的 $2^{-2}$，所以

$$x=-2^{-2}\times2^{-126}=\boxed{-2^{-128}}.$$

## 选项判断

$$\boxed{A}$$

## Verification

若阶码全 0 且 fraction 非 0，就绝不可能是 NaN；NaN 要求阶码全 1。

## Compression

```text
IEEE754 -> 先看 exponent 分类
E=0,f!=0 -> subnormal -> 无隐藏1，指数固定 -126
```

## 易错边界

非规格化数有效数是 `0.f`，不是规格化数的 `1.f`。
