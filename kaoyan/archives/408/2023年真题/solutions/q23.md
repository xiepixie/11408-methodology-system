# 408-2023-Q23

> 原题：[[../2023 年全国硕士研究生招生考试#23|Q23]]

## Model Anchor

- Topic：宏内核与微内核的机制/代价权衡。
- 题目信号：可靠性、安全性、扩展性、性能四项并列。
- 第一动作：先问“更多服务放到用户态”改变了什么边界，再判断收益与 IPC/切换成本。

## 解题链

微内核只把最核心机制留在内核，把文件系统、驱动等更多服务隔离到用户态进程：

- 故障隔离更好，可靠性更高（II）；
- 特权内核代码更少，攻击面更小，安全性更高（III）；
- 服务模块更容易独立替换/扩展，可扩展性更强（IV）。

代价是服务之间往往需要更多 IPC、模式切换和地址空间切换，因此不能说相对宏内核具有更好的性能（I 不成立）。

## 选项判断

$$\boxed{D}$$

## Verification

如果把“性能也更好”同时当成必然优势，就忽略了微内核设计最经典的隔离收益与通信开销 trade-off。

## Compression

```text
microkernel -> 更小特权边界 -> reliability/security/extensibility ↑
            -> IPC/切换增加 -> performance 不保证更好
```

## 易错边界

这是架构取向的典型权衡，不应把“现代某微内核实现很快”升级成所有微内核的必然性能结论。
