# 408-2023-Q04

> 原题：[[../2023 年全国硕士研究生招生考试#4|Q4]]

## Model Anchor

- Topic：Huffman 树与加权路径长度。
- 题目信号：给出字符频次，问加权平均长度。
- 第一动作：按 Huffman 贪心反复合并当前两个最小权值，并累计每次合并值。

## 解题链

频次为 `3,4,5,6,8,10`。Huffman 合并过程可写成：

```text
3+4=7
5+6=11
7+8=15
10+11=21
15+21=36
```

Huffman 树的加权路径长度等于所有合并值之和：

$$WPL=7+11+15+21+36=90.$$

总频次：

$$3+4+5+6+8+10=36.$$

故加权平均长度：

$$\bar L=\frac{90}{36}=2.5.$$

## 选项判断

$$\boxed{B}$$

## Verification

平均码长必须大于 2 bit 且小于等长编码的 3 bit；2.5 落在合理范围内。

## Compression

```text
Huffman频次 -> 两小合并并累计 -> WPL / 总频次
```

## 易错边界

题目问的是“平均长度”，不是 WPL 本身；最后必须除以总频次。
