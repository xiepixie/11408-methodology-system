# 408-2023-Q10

> 原题：[[../2023 年全国硕士研究生招生考试#10|Q10]]

## Model Anchor

- Topic：排序算法稳定性。
- 题目信号：问“不稳定”的算法集合。
- 第一动作：稳定性只检查**相等关键字的相对次序是否可能改变**，不要和原地性、复杂度混淆。

## 解题链

- 希尔排序：跨较大 gap 的移动可能越过相等元素，**不稳定**；
- 归并排序：合并时相等元素优先取左段即可保持原次序，**稳定**；
- 快速排序：partition 交换可改变相等元素次序，**不稳定**；
- 堆排序：下滤/根尾交换可改变相等元素次序，**不稳定**；
- 基数排序：每一趟稳定分配/收集时整体可保持稳定，**稳定**。

所以不稳定的是 I、III、IV。

## 选项判断

$$\boxed{C}$$

## Verification

用两个相等 key 带不同原始编号即可分别构造 Shell/Quick/Heap 改变相对次序的反例。

## Compression

```text
稳定性 -> 只追踪 equal-key relative order
Shell / Quick / Heap 不稳定
Merge / Radix 稳定
```

## 易错边界

“原地排序”与“稳定排序”是两条独立属性，不能互推。
