# 408-2023-Q09

> 原题：[[../2023 年全国硕士研究生招生考试#9|Q9]]

## Model Anchor

- Topic：开放定址散列表删除后的失败查找。
- 题目信号：**线性探查 + 删除关键字**。
- 第一动作：先画真实表状态，并区分 `EMPTY` 与 `DELETED`；失败查找只能在真正的空槽停止。

## 解题链

$$H(k)=(k+4)\bmod5.$$

依次插入：

```text
2022 -> H=1 -> HT[1]=2022
12   -> H=1 冲突 -> HT[2]=12
25   -> H=4 -> HT[4]=25
```

删除 25 后，4 号槽必须保留删除标记，否则会错误截断其他探查链。

从 5 个初始散列地址开始做失败查找，比较/探查长度分别为：

```text
H0=0 : 1
H0=1 : 3   (1 -> 2 -> 3空)
H0=2 : 2   (2 -> 3空)
H0=3 : 1
H0=4 : 2   (4删除标记 -> 0空)
```

因此

$$ASL_{fail}=\frac{1+3+2+1+2}{5}=\frac95=1.8.$$

## 选项判断

$$\boxed{C}$$

## Verification

若错误地把删除位置 4 当作 `EMPTY`，从 H0=4 的失败查找会提前停止，破坏开放定址的查找不变量。

## Compression

```text
开放定址删除 -> tombstone 不能当空
失败ASL -> 对每个初始地址探查到首个真正 EMPTY
```

## 易错边界

删除标记仍会被探查经过；只有从未占用的空槽才证明该探查链中目标不存在。
