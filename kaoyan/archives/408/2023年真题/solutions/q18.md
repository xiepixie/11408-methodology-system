# 408-2023-Q18

> 原题：[[../2023 年全国硕士研究生招生考试#18|Q18]]

## Model Anchor

- Topic：数据通路中的操作元件与状态元件。
- 题目信号：问“属于操作元件”。
- 第一动作：看元件是否**保存跨时刻状态**；不保存状态、只对当前输入做组合变换的是操作元件。

## 解题链

- ALU：根据当前输入产生运算结果，不保存状态，属于组合逻辑操作元件；
- PC：保存当前/下一指令地址，是状态元件；
- GPRs：寄存器组保存架构状态，是状态元件；
- MUX：根据选择信号从当前输入中选一路输出，是组合逻辑操作元件。

因此属于操作元件的是 I、IV。

## 选项判断

$$\boxed{B}$$

## Verification

断电或跨周期后，ALU/MUX 不需要“记住上一次输入”；PC/GPR 必须保持内容，这正是两类元件的边界。

## Compression

```text
数据通路元件 -> 是否保存状态？
否：ALU/MUX；是：PC/GPR
```

## 易错边界

“寄存器组也参与运算取数”不等于它是组合操作元件；它的核心职责仍是保存状态。
