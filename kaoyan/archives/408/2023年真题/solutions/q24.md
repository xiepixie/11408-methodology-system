# 408-2023-Q24

> 原题：[[../2023 年全国硕士研究生招生考试#24|Q24]]

## Model Anchor

- Topic：中断向量号到处理入口的直接映射。
- 题目信号：对象叫“向量表”，访问键是有限范围的中断类型/向量号。
- 第一动作：看 workload：需要用编号快速定位固定表项，而不是顺序排队或动态插删。

## 解题链

中断向量号天然可作为下标：

$$entry=IVT[vector\_number].$$

数组能够通过基址和固定表项大小直接计算入口地址，满足 $O(1)$ 随机访问；队列和链表都需要额外遍历或维护链接，没有必要。

## 选项判断

$$\boxed{A}$$

## Verification

中断响应路径要求按向量号快速定位处理入口，正是“稠密整数 key -> 直接索引”的 workload。

## Compression

```text
中断向量号 -> 稠密整数索引 -> 数组直接定位
```

## 易错边界

这里比较的是适合保存“向量号→入口”的表结构，不是比较中断请求的排队结构。
