# 408-2023-Q31

> 原题：[[../2023 年全国硕士研究生招生考试#31|Q31]]

## Model Anchor

- Topic：`close()` 与文件对象生命周期。
- 题目信号：文件 F **仅被进程 P 打开并访问**。
- 第一动作：区分名字/磁盘 inode 与“为打开访问而驻留内存的 inode/open-file 状态”。

## 解题链

关闭文件只解除进程的打开引用：

- 不删除目录项，A 错；
- 不删除磁盘 inode，C 错；
- 不等于 unlink，因此磁盘 inode 的链接计数不减，D 错。

因为题设说明只有 P 打开 F，P 关闭后不再有打开引用，文件系统可以释放该文件索引节点对应的**内存驻留状态/内存空间**，故 B 正确。

## 选项判断

$$\boxed{B}$$

## Verification

`close(fd)` 与 `unlink(path)` 的对象不同：前者断开打开引用，后者删除名字边并影响硬链接计数。

## Compression

```text
close -> drop open reference
unlink -> drop directory name/link count
题目只close -> 不动目录项和磁盘inode
```

## 易错边界

“释放内存中的 inode 状态”不等于“释放磁盘 inode”；两者处于不同生命周期层。
