# 408-2023-Q02

> 原题：[[../2023 年全国硕士研究生招生考试#2|Q2]]

## Model Anchor

- Topic：双向链表插入。
- 题目信号：已经执行了两条 `next` 修改语句。
- 第一动作：不要背四句模板，直接恢复插入后的不变量：`p <-> s <-> oldNext`。

## 解题链

设原来 `q=p->next`。执行

```c
s->next = p->next;
p->next = s;
```

后已有：`p->next=s`、`s->next=q`。还缺：

```text
s->prev = p
q->prev = s
```

此时 `s->next->prev` 仍是原来的 `p`，故可先令

```c
s->prev = s->next->prev;
```

再令

```c
s->next->prev = s;
```

恰好对应 C。

## 选项判断

$$\boxed{C}$$

## Verification

最后同时满足 `p->next->prev=p` 与 `s->next->prev=s` 对应的双向一致性，不产生自指或断链。

## Compression

```text
链表改边 -> 先画最终局部拓扑 -> 补齐 next/prev 双向不变量
```

## 易错边界

第二句执行后 `p->next` 已经变成 `s`，因此不能再把 `p->next` 当作原来的后继结点。
