# 408-2023-Q43

> 原题：[[../2023 年全国硕士研究生招生考试#43（12 分）|Q43]]

## Model Anchor

- Topic：数组访问把 **虚拟页面、主存块、Cache 组** 三种粒度串起来。
- 题目信号：页大小、Cache 容量/路数/块大小、二维数组行优先、循环次序同时出现。
- 第一动作：先建立统一地址式
  $$VA(a[i][j])=base+(i\times64+j)\times4,$$
  再分别投影到 page、block、set；不要把三种编号混成一个量。

## Problem Representation

```text
array shape       = 24 × 64
sizeof(int)       = 4 B
array bytes       = 24 × 64 × 4 = 6144 B
base VA           = 00422000H
page size         = 4 KB = 4096 B
cache data        = 8 KB
cache block       = 32 B
associativity     = 4-way
cache lines       = 8192/32 = 256
cache sets        = 256/4 = 64
ints per block    = 32/4 = 8
```

## Decision Points

- 缺页次数看**首次触及页面**，不是看 Cache miss。
- Cache 组号来自块地址对 64 取模；块内偏移 5 bit，组号 6 bit。
- 调换循环后虽然访问步长变大，但 4 路组相联是否发生替换必须真正检查每组同时驻留多少个数组块，不能凭“列访问局部性差”直接宣告命中率下降。

## Solution Chain

### (1) 页面数、缺页次数与页故障地址

数组大小：

$$24\times64\times4=6144\text{ B}=1.5\text{ pages}.$$

起始地址 `00422000H` 正好按 4 KB 对齐，因此数组占两个虚拟页：

```text
00422000H ~ 00422FFFH
00423000H ~ 004237FFH
```

执行前数组不在主存，且之后不发生页面置换，所以每页只在第一次访问时缺页一次：

$$\boxed{2\text{ 次缺页}}.$$

页故障地址分别是每页第一次被访问的地址：

$$\boxed{00422000H,\quad00423000H}.$$

第二个地址对应 `a[16][0]`，因为每行 64×4=256 B，16 行恰为 4096 B。

### (2) 是否具有时间局部性

不考虑 i、j，本程序对数组元素只执行一次写操作：

```text
a[0][0], a[0][1], ..., a[23][63]
```

同一个数组元素不会在短时间内再次访问，因此数组数据访问**没有时间局部性**。

但连续行优先访问具有很强的**空间局部性**；这正是后面每个 Cache block 一次 miss、随后多个 hit 的来源。

### (3) Cache 地址字段与 `a[1][0]`

块大小 32 B：

$$\log_2 32=5,$$

故块内地址为：

$$\boxed{A_4\sim A_0}.$$

Cache 共有 64 组：

$$\log_2 64=6,$$

所以组号为紧邻其上的 6 位：

$$\boxed{A_{10}\sim A_5}.$$

`a[1][0]` 地址：

$$VA=\texttt{00422000H}+1\times64\times4
=\boxed{\texttt{00422100H}}.$$

其主存块号对 64 取模：

$$set=\left(\frac{0x00422100}{32}\right)\bmod64=8.$$

故 Cache 组号为：

$$\boxed{8=001000_2}.$$

### (4) 主存块数与两种循环次序的 Cache 命中率

数组占：

$$\frac{6144}{32}=\boxed{192\text{ 个主存块}}.$$

总数组访问次数：

$$24\times64=1536.$$

#### 原循环：按行连续访问

每个主存块容纳 8 个 int。第一次访问块中第一个元素 miss，随后同块另外 7 个元素 hit：

$$hit\ rate=\frac78=\boxed{87.5\%}.$$

等价地：192 次 compulsory miss，

$$\frac{1536-192}{1536}=87.5\%.$$

#### 调换循环：先 j 后 i

固定 j 时，相邻两次访问：

$$a[i+1][j]-a[i][j]=64\times4=256\text{ B}=8\text{ blocks}.$$

因此 set index 每次增加 8（mod 64），24 行只落入 8 个 set，每个相关 set 同时容纳 3 个不同 tag：

$$24/8=3\text{ lines per set}.$$

Cache 是 4 路组相联，所以这 3 个数组块可以同时驻留，不发生数组自身的冲突替换。对同一个 8 列小组，例如 `j=0..7`，第一次访问每行对应块 miss，随后另外 7 列重新访问同一批块时全部 hit。

因此每个主存块仍然只有第一次访问 miss：

$$\boxed{hit\ rate=87.5\%}.$$

## Verification

三层独立检查：

1. **页面守恒**：6144 B = 4096 B + 2048 B，正好两页；
2. **块守恒**：192 blocks × 8 ints/block = 1536 ints，恰等于数组元素数；
3. **组相联检查**：调换循环后每个相关 set 最多 3 条数组 cache line，小于 4-way 容量，因此不能凭 stride 较大宣称产生 conflict miss。

## Compression

```text
数组地址 = base + (i*64+j)*4
-> page: /4096
-> block: /32
-> set: block mod 64

row-major: 每块 8 int -> 1 miss + 7 hit
column-major: stride=8 blocks -> 每set仅3条数组line < 4-way
-> 两者 hit rate 都 7/8
```

## 易错边界

- “列优先访问空间局部性差”是趋势，不是本题数值结论；必须结合 4-way 容量检查实际冲突。
- Page fault、Cache miss 和主存块不是同一层事件。
- 本题假设数组访问不与其他数据发生 Cache 冲突；若其他数据占用相同 set，调换循环后的结果可能改变。
