# 408-2023-Q06

> 原题：[[../2023 年全国硕士研究生招生考试#6|Q6]]

## Model Anchor

- Topic：无权图最短路。
- 题目信号：所有边权均为 1。
- 第一动作：把“最短路径”翻译成“经过的边数最少”，立即想到 BFS 的分层 frontier。

## 解题链

BFS 从源点按距离层逐层扩展：

```text
第0层：源点
第1层：1条边可达
第2层：2条边可达
...
```

因此顶点第一次被 BFS 发现时，已经获得最少边数路径。

Prim、Kruskal 的目标是最小生成树的**总边权最小**，并不保证从指定源点到每个顶点的树上路径也是最短路径。

故只有 III 一定成立。

## 选项判断

$$\boxed{B}$$

## Verification

构造一个带环的单位权图即可使某棵 MST 中源点到某顶点绕远，而原图存在更短边数路径；所以 MST 目标不能替代 shortest path。

## Compression

```text
单位边权最短路 -> 最少边数 -> BFS 分层首次到达即最短
```

## 易错边界

“所有边权都相等”不会把 MST 问题和单源最短路问题变成同一个优化目标。
