# 408-2023-Q37

> 原题：[[../2023 年全国硕士研究生招生考试#37|Q37]]

## Model Anchor

- Topic：CRC 接收端校验。
- 题目信号：给生成多项式 `10011` 和若干完整接收比特串。
- 第一动作：把每个候选串对 `10011` 做模 2 除法；余数为 0 才能通过 CRC 检查。

## 解题链

对四个候选串分别做 XOR 长除法，余数为：

```text
A 101110000 -> 1100
B 101110100 -> 1000
C 101111000 -> 0100
D 101111100 -> 0000
```

只有 D 能被生成多项式整除，因此接收端 CRC 检查不会检测到错误。

## 选项判断

$$\boxed{D}$$

## Verification

重新以 `10011` 对 D 做模 2 长除，最终余数 4 bit 全 0，满足合法码字条件。

## Compression

```text
CRC候选码字 -> modulo-2 divide by G -> remainder=0 才通过
```

## 易错边界

严格说“余数为 0”表示**未检测到错误**，并不能从理论上证明传输绝对无错；题目采用 408 常规表述“可以断定未发生错误”，按其考试语境选择唯一合法码字 D。
