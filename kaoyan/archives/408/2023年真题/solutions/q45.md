# 408-2023-Q45

> 原题：[[../2023 年全国硕士研究生招生考试#45（7 分）|Q45]]

## Model Anchor

- Topic：用原子 `swap` 建立自旋互斥。
- 题目信号：共享 `lock`，`TRUE` 表示已占用；局部 `key` 与 `lock` 原子交换。
- 第一动作：先写安全不变量：**线程只有在一次原子交换把 `lock` 从 FALSE 改为 TRUE 后，才能进入临界区；退出时必须把 lock 恢复为 FALSE。**

## Problem Representation

正确的 test-and-set 风格状态机应是：

```text
lock = FALSE  -> 临界区空闲
lock = TRUE   -> 某线程持有临界区
```

每个竞争线程使用私有变量：

```text
key = TRUE
```

原子 `swap key, lock` 的效果：

- 若原 `lock=FALSE`：交换后 `key=FALSE, lock=TRUE`，线程成功取得锁；
- 若原 `lock=TRUE`：交换后 `key=TRUE, lock=TRUE`，线程必须继续等待。

## Decision Points

- `swap` 的关键不是“交换功能”本身，而是**读 lock + 写 lock 不可被其他线程插入**。
- 进入区必须循环尝试；一次 `if` 失败后不能让线程继续掉入临界区。
- 退出区是释放 owner 状态，因此必须写 `FALSE`。

## Solution Chain

### (1) 找出并修正错误语句

进入区原语句：

```c
if (key == TRUE)
    swap key, lock;
```

错误在 `if`。如果第一次交换没有取得锁，`key` 仍为 TRUE，但 `if` 已经执行结束，线程会继续进入临界区，破坏互斥。

应改为：

```c
while (key == TRUE)
    swap key, lock;
```

这样只有当某次原子交换读到原 `lock=FALSE`，使 `key` 变成 FALSE 后才能离开循环。

退出区原语句：

```c
lock = TRUE;
```

这会让锁一直保持占用。应改为：

```c
lock = FALSE;
```

因此两处修改为：

$$\boxed{if\to while},\qquad\boxed{lock=TRUE\to lock=FALSE}.$$

完整核心结构为：

```c
bool key = TRUE;
while (key == TRUE)
    swap key, lock;     // atomic

/* critical section */

lock = FALSE;
```

### (2) `newSwap(&key,&lock)` 能否代替原子 `swap`

$$\boxed{\text{不能}}.$$

题图中的 `newSwap()` 本质是三条普通内存操作：

```c
temp = *a;
*a = *b;
*b = temp;
```

它们不是一个不可分割事件。两个线程可以出现如下交错：

```text
T1 读 lock=FALSE
T2 也读 lock=FALSE
T1 写 lock
T2 写 lock
```

于是两个线程都可能认为自己成功获得锁并进入临界区。

硬件 `swap` 指令的必要语义是：

```text
read old lock + write new lock
```

对其他处理器/线程表现为一个原子状态转移。普通函数调用只把几条指令封装起来，并不会自动赋予原子性。

## Verification

检查 Safety：任意时刻若一个线程成功得到 `key=FALSE`，那次原子交换已把 `lock` 置 TRUE；在它释放前，其他线程与 TRUE 交换后得到的 `key` 仍为 TRUE，因此不能越过 while。

检查退出：持锁线程执行 `lock=FALSE` 后，下一竞争线程才可能在一次 swap 后得到 `key=FALSE`。

## Compression

```text
互斥锁题
-> 先写 owner invariant：进入前必须原子地 FALSE->TRUE
-> 失败要 while 重试
-> 退出 TRUE->FALSE
-> 普通函数序列 != atomic instruction
```

## 易错边界

- `while(lock)` 再单独 `lock=TRUE` 也不安全，因为检查与写入之间仍可被抢占；本题安全性来自原子 `swap`。
- 自旋锁保证的是互斥 Safety，不自动保证公平性或无饥饿。
- 函数是否“很短”与是否原子无关；必须由 ISA 原子指令或等价同步原语提供不可分割语义。
