# 408-2023-Q17

> 原题：[[../2023 年全国硕士研究生招生考试#17|Q17]]

## Model Anchor

- Topic：寄存器字段的寻址语义。
- 题目信号：同一个寄存器内容有时是操作数，有时是操作数地址。
- 第一动作：字段位串只给“哪个寄存器”，真正决定如何解释寄存器内容的是**寻址方式**。

## 解题链

若采用寄存器寻址：

```text
register content = operand value
```

若采用寄存器间接寻址：

```text
register content = effective address
operand = M[register content]
```

因此 CPU 区分两种语义的依据是指令规定的操作数寻址方式，而不是寄存器编号或寄存器当前位串。

## 选项判断

$$\boxed{A}$$

## Verification

同一个 R1 完全可以在一条指令中被解释为值，在另一条指令中被解释为地址；寄存器编号本身不变。

## Compression

```text
寄存器字段 -> 先读 addressing mode -> 决定 value 还是 address
```

## 易错边界

“寄存器里恰好存了一个像地址的数”不会自动变成间接寻址；解释权属于 ISA/指令格式。
