# 408-2023-Q28

> 原题：[[../2023 年全国硕士研究生招生考试#28|Q28]]

## Model Anchor

- Topic：进程虚拟地址空间与物理资源的分层。
- 题目信号：把 virtual address space 与 RAM/disk 容量放在一起比较。
- 第一动作：先问该量属于**地址表示上限**还是**当前物理驻留/后备存储容量**。

## 解题链

A：各进程通常拥有独立虚拟地址空间，正确。

B：`malloc()` 返回的是进程可使用的虚拟地址，正确。

C：页表权限可使代码页、数据页具有不同访问权限，正确。

D：虚拟地址空间的理论大小主要由体系结构的虚拟地址宽度和 OS 地址空间布局决定，不是简单由“主存容量 + 硬盘容量”决定，因此错误。

## 选项判断

$$\boxed{D}$$

## Verification

32/64 位虚拟地址空间即使远大于实际 RAM，也仍可合法存在大量尚未映射或未驻留的虚拟区域。

## Compression

```text
virtual space -> address namespace
RAM/disk -> backing/residency resources
两者容量不能直接画等号
```

## 易错边界

虚拟地址可被保留但尚未映射；“有地址范围”不等于“必须有等量物理/磁盘空间立即承载”。
