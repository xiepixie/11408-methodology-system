# 408-2023-Q11

> 原题：[[../2023 年全国硕士研究生招生考试#11|Q11]]

## Model Anchor

- Topic：快速排序一次划分后的枢轴位置。
- 题目信号：给“划分后的序列”，反求 pivot。
- 第一动作：不用模拟某一种 partition 实现；直接检查 pivot 的结构不变量：**左侧都不大于它，右侧都不小于它**。

## 解题链

序列为：

```text
68 11 70 23 80 77 48 | 81 | 93 88
```

以 81 为候选时：

- 左侧 `68,11,70,23,80,77,48` 全部小于 81；
- 右侧 `93,88` 全部大于 81。

因此 81 可以是本次划分后已经到达最终位置的枢轴。

其余候选都能在某一侧找到违反 partition 不变量的元素。

## 选项判断

$$\boxed{D}$$

## Verification

例如若 pivot=80，则右侧仍有 `77,48<80`，直接违反划分后的左右关系。

## Compression

```text
反求QuickSort枢轴 -> 检查 左<=pivot<=右 -> 唯一满足者
```
