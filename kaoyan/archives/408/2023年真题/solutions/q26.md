# 408-2023-Q26

> 原题：[[../2023 年全国硕士研究生招生考试#26|Q26]]

## Model Anchor

- Topic：内核控制流返回用户程序。
- 题目信号：问“操作完成时导致 CPU 从内核态转为用户态”。
- 第一动作：区分**内核内部状态管理动作**和“完成一次用户请求后返回用户态”的边界事件。

## 解题链

阻塞进程、CPU 调度、唤醒进程都属于内核内部机制，它们完成后 CPU 仍可能继续执行内核代码或选择另一个任务，并不必然回到用户态。

用户进程执行系统调用时进入内核；系统调用服务完成并返回调用点时，需要恢复用户上下文并从内核态切回用户态。

## 选项判断

$$\boxed{D}$$

## Verification

“系统调用进入”是 user→kernel；题目问的是操作完成后的方向，因此对应 syscall return 的 kernel→user。

## Compression

```text
mode transition题 -> 找跨 privilege boundary 的 entry/return
system call完成返回 -> kernel -> user
```

## 易错边界

CPU 调度完成不等于一定立即进入用户态；被选中的实体也可能继续走内核返回路径或执行内核线程。
