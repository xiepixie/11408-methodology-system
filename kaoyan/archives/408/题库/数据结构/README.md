## 录入原则

- 保留原题号，便于与来源材料核对。
- 题面与正式答案解析分离；题面文件不放答案。答案页统一采用“答案速查 → 题号跳转 → 逐题解析”，便于做题后快速定位完整解释。
- 能稳定恢复的符号、题号、数组下标、`++/--`、`next/nextval` 等直接校正为可做题版本。
- 若原题存在必要条件缺失或单选不唯一，优先在不改变核心考点的前提下把题面修成自洽版本；答案文件只保留最终结论与解析，不保留临时审阅过程。
- 图题优先重建为可编辑 TikZ，并提供 SVG 视图；图中只恢复题设结构，不加入答案提示。
