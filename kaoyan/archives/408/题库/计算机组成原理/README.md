## 题库组织原则

1. 保留原来源题号，便于回查扫描页。
2. 正式题面只保留题干、选项、表格、代码和必要题图，不混入答案或解析。
3. 正式答案页统一采用“答案速查 → 题号跳转 → 逐题解析”；完整解析按计算机组成原理的 Canonical 模型组织：先确定对象、表示/地址/状态，再走机制链，最后计算并校验；避免只给口诀或答案字母。
4. 数学表达统一为 LaTeX，程序统一为 fenced code block，规则表格统一为 Markdown table。
5. 若题目依赖结构图、数据通路图、Cache/页表字段图等视觉条件，按项目 diagram 语义规范重建 TikZ/SVG，且不得把答案信息画入题图。本批只有规则表格与代码，没有必须重建的语义题图。
6. 本目录是非统考来源练习题库，不因题目与真题相似而标记为 408 真题。
7. 为保留来源连续题号，少量跨科边界题可留在本批次文件中，但正式解析必须显式路由到真正的 Canonical Owner；例如页面置换、缺页修复归操作系统虚拟内存，TLB/MMU 硬件翻译才归 CO-07。
8. 题目若依赖 alignment、DRAM 行数、Bank 请求时序、PC-relative 基准、ISA/ABI 或编译器访存模型等条件，条件必须写进题面；答案文件不得靠“默认经典模型”补关键前提。
