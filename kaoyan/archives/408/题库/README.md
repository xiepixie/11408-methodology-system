# 408 非真题练习题库

本目录保存经过逐题核对的 408 非真题练习题，与 `../YYYY年真题/` 的 Canonical Exam Source 严格隔离。

## 边界

- 这里只保存用户提供或其他非统考来源的练习题，不因题目质量高就标记为“408 真题”。
- 每个学科按来源连续整理；题面与正式答案解析分文件维护，避免做题时答案污染题面。
- 录入前必须逐题检查：题干是否完整、选项是否唯一、术语是否符合 408 教材口径、OCR 是否改变题意。
- 能唯一恢复的 OCR/排版错误直接修正；题目本身缺少必要前提或单选不唯一时，在不改变核心考点的前提下修成自洽版本；无法可靠恢复的内容暂不进入正式题库，不以猜测补全。
- 若原题依赖结构图、状态图、资源分配图等视觉条件，优先重建为可编辑 TikZ/SVG；图中不得补入答案信息。
- 表格优先转成 Markdown 表格；代码使用 fenced code block；数学表达使用 LaTeX。
