# 07｜多播、移动 IP 与路由器｜答案与解析

## 解题总轴

本组题统一围绕三个作用域：

- **Multicast group**：谁属于接收组，在哪些分叉点复制；
- **Mobile identity / locator**：稳定 home address 与当前 care-of locator 分离；
- **Router control / data plane**：routing processor 生成状态，FIB/交换结构执行逐包转发。

## 逐题解析

### 891

**答案：D**

多份单播会随接收者数增加重复发送和共享链路占用，不能说总开销基本不变。组播的核心收益是只在分叉处复制。

### 892

**答案：A**

IPv4 多播映射到 Ethernet 时固定前缀 `01-00-5E`，复制 IP 多播地址低 23 bit；对应结果为 `01-00-5E-57-91-E6`。

### 893

**答案：B**

IPv4 D 类多播地址范围是 `224.0.0.0/4`，228.47.32.45 落在该范围。

### 894

**答案：C**

Mobile IP 注册的核心状态 Owner 是归属代理 HA：它要维护 `home address → care-of address` 绑定。外地代理可参与中继，但不是最终绑定 Owner。

### 895

**答案：C**

Foreign Agent 位于移动结点当前访问的外地/被访网络。

### 896

**答案：A**

发往 home address 的报文先按普通路由到归属网络，由 HA 截获并通过隧道转送到当前 care-of address。

### 897

**答案：B**

经典三角路由模型下，移动结点可按普通路由向通信对端发送；但对端发往其 home address 的返回流量仍先去归属网络，需要移动性重定向。

### 898

**答案：C**

home address 是稳定身份，care-of address 是当前位置 locator；移动时通常变化的是后者。

### 899

**答案：D**

移动结点能直接向外发送，但不能仅靠普通路由让发往 home address 的入站报文自动找到新位置，因此需要 HA/隧道等机制。

### 900

**答案：B**

网桥/交换机默认仍透明转发二层广播；路由器接口终止二层广播，因此能隔离广播域。

### 901

**答案：C**

远距离 LAN 互连既要有网络层互连能力，也需要能跨远距离承载的 WAN/运营商链路技术。

### 902

**答案：C**

多协议路由器可以支持多种网络层协议，并分别按对应三层首部和路由状态转发；这不等于在协议之间自动做翻译。

### 903

**答案：A**

路由器的控制与数据平面都可由软硬件组合实现，FIB 查找尤其常用专用硬件加速，“只能通用软件实现”错误。

### 904

**答案：B**

直接交付要求下一接收者位于直接连接链路上；间接交付本质上由一系列逐跳直接交付串联。II、III 错，I、IV 对。

### 905

**答案：D**

routing processor 运行路由协议、维护 RIB 并安装可转发状态；输入/输出队列和 switching fabric 属于数据面。

### 906

**答案：D**

三个说法分别对应路由器组成、广播域隔离、RIB→FIB 的控制/数据平面关系，均成立。

### 907

**答案：C**

二层交换机理解 Ethernet/MAC 转发即可，不需要理解所有被承载的三层协议；路由器则必须解析它所支持的网络层首部。

### 908

**答案：D**

一个分组通过路由器时依次经历物理接收、链路解封装、网络层处理，再经过新的链路封装和物理发送，因此 1–3 层都参与。

### 909

**答案：C**

IPv4 默认路由是 `/0`，匹配所有目的，但会被任何更长、更具体的前缀覆盖。

### 910

**答案：A**

路由器不会把一个接口收到的普通二层广播透明复制到其他接口，因此每个三层接口边界可形成独立广播域。

### 911

**答案：C**

经典处理复杂度模型中，router 需要解析三层首部、查 FIB、更新 TTL/checksum 等，处理工作多于 hub/bridge/switch。

## 高频模型

### IP 多播地址到 Ethernet MAC 是有损映射

IPv4 D 类地址可变组部分有 28 bit，而 Ethernet 多播只复制低 23 bit，所以会丢 5 bit：

$$
2^5=32
$$

即最多 32 个不同 IPv4 多播组可能映射到同一个二层多播 MAC。网卡按 MAC 过滤后，IP 层仍要二次检查 group address。

### Mobile IP 的核心不是“换 IP”，而是拆开身份与位置

$$
\text{stable home identity}\neq\text{current care-of locator}
$$

HA 的 binding 和 tunnel 正是在这两个对象之间建立映射，因此“能直接发”和“不能按 home address 直接收”可以同时成立。
