# 05｜IP 地址、分片、ARP 与 IPv6｜答案与解析

> 对应题面：[`05_IP地址_分片_ARP与IPv6_选择题.md`](05_IP地址_分片_ARP与IPv6_选择题.md)

## 解题总轴

网络层题固定按这条链走：

$$
\text{Destination IP}
\to \text{Prefix/Scope}
\to \text{Next Hop}
\to \text{Current-link Identity}
\to \text{New Frame}.
$$

主机先判断 same-subnet，路由器对已安装 FIB 做最长前缀匹配；只有 next-hop IP 确定之后，才轮到 ARP。分片题则逐片维护 `payload / total length / offset / MF`。

> 使用方式：先看“答案速查”；需要理解时点击题号跳到逐题解析。原有解析与高频模型完整保留，只改阅读结构。

## 逐题解析

### 827

**答案：C**

路由器在统一网络层语义上互连异构链路，因此两侧物理层、数据链路层都可以不同。

### 828

**答案：D**

拓扑、物理层、链路层实现都可能不同；Ethernet 与 WAN 链路技术互连是典型异构网络。

### 829

**答案：B**

普通路由器跨越不同 L1/L2，但仍需要可互通的网络层协议体系；网络层若也任意不同，就不是普通 IP 路由可透明解决的问题。

### 830

**答案：C**

路由状态按目的前缀/网络聚合，保存下一跳或出接口动作；不保存每台主机的完整端到端路径。

### 831

**答案：B**

报文交换每跳必须收齐整报文再转发，存储与等待粒度大，时延长且不稳定，不适合实时语音。

### 832

**答案：D**

传统虚电路模型依赖沿路径保存状态，中间结点故障会破坏该 VC，因此高故障率环境并不是它的优势场景。

### 833

**答案：D**

同一虚电路的数据分组沿既定逻辑路径转发，正常情况下保持顺序；D 把这一点说反。

### 834

**答案：D**

数据报逐包独立转发，需要完整目的地址；虚电路既可能是临时 SVC，也可能有长期 PVC，不能说全部都是临时连接。

### 835

**答案：C**

虚电路借鉴“先建逻辑路径再传数据”的思想，适合持续通信；它不是独占物理电路。

### 836

**答案：C**

建立阶段需要端点地址来创建 VC 状态；数据阶段可使用短 VC 标识转发。

### 837

**答案：A**

SDN 是控制架构而非物理拓扑；控制器逻辑上独立于 OpenFlow 交换机。II、IV 成立，I、III 错。

### 838

**答案：D**

北向接口连接控制器与应用/策略，南向接口连接控制器与数据平面设备；D 把方向说反。

### 839

**答案：C**

IPv4 IHL 以 4 B 为单位，Fragment Offset 以 8 B 为单位，Total Length 以 1 B 为单位。

### 840

**答案：C**

IHL 计数 32-bit word，总长度逐字节计数。

### 841

**答案：B**

IPv4 checksum 只覆盖首部，按 16 bit 反码加法求和再取反；伪首部属于 TCP/UDP，不属于 IPv4 首部校验。

### 842

**答案：D**

IPv4 分片只在最终目的主机重组，避免中间结点反复重组又再次分片。

### 843

**答案：A**

分片只改变 IP 包装；目的主机重组后恢复原 400 B TCP 报文段，再向传输层交付 400 B。

### 844

**答案：A**

普通转发中 TTL 每跳减 1，因此 IPv4 首部校验和也需更新；无 NAT 时端点 IP 地址保持不变。

### 845

**答案：C**

offset=100 表示原 payload 起点 $100\times8=800$ B；IHL=5→20 B 首部，总长 100 B→payload 80 B，因此字节编号 800–879。

### 846

**答案：D**

MTU 1400、首部 20 B 时，非末片 payload 必须取 8 B 整数倍，最大 $1376$ B；实际三片总长 1396、1396、268 B。同一原 datagram 的 Identification 不变，目的主机按 offset/MF 重组。

### 847

**答案：B**

`132.19.237.5` 不在 `132.19.232.0/22` 的 232–235 范围，但匹配 `/11` 与 `/8`；最长前缀匹配选 `/11`→R2。

### 848

**答案：B**

传统分类默认掩码下，192.46.10.0 是 C 类网络地址；127/8 是 loopback；256 非法；110.47.10.0 在 A 类 `/8` 中是合法主机地址。

### 849

**答案：C**

`/20` 剩 12 host bit，传统可用主机数 $2^{12}-2=4094$。

### 850

**答案：A**

排除 NAT/隧道等改写机制后，源/目的 IP 维持端到端语义；逐跳变化的是 MAC、TTL 等。

### 851

**答案：C**

按 `/24`，`.11.x` 都在同一子网，`.13.25` 才位于另一个 `/24`。`.11.0` 还是网络地址。

### 852

**答案：D**

`/22` 的第三字节块宽为 4；66 落在 64–67，因此网络地址是 `126.166.64.0`，不是给定主机地址。

### 853

**答案：B**

`/29` 每块 8 个地址，`200.15.10.6` 所在块为 `.0–.7`，其中 `.0` 是网络地址、`.7` 是广播地址；广播地址不能配置为默认网关接口地址。

### 854

**答案：B**

IPv4 在 DF 允许时可由路径中路由器分片，但重组只在目的主机完成。

### 855

**答案：C**

已有 `.96/29` 占 `.96–.103`；`.96/28` 覆盖 `.96–.111`，发生重叠，不能再分配。

### 856

**答案：D**

第二字节 12 和 13 已不同，`/16` 不可能同网；选项中只有 `/8` 可同时覆盖。

### 857

**答案：A**

129、130、132、133 的最小共同对齐块是第三字节 128–135，对应 `172.18.128.0/21`。

### 858

**答案：A**

在传统保留 network/broadcast 的模型中，点到点两端需要 2 个可用地址，最小常用块是 `/30`。现代 `/31` 是题目选项外边界。

### 859

**答案：C**

若再取 `.96/27`，结合已给 `.128/26` 后，剩余 `.0–.95` 不能由单个 CIDR 块覆盖，至少还要两个块，最终超过恰好 4 个子网。

### 860

**答案：C**

主机 2 在远端网络，因此主机 1 在 Ethernet 1 上的 next-hop 是 R1：帧目的 MAC=R1 本地接口 MAC；无 NAT 时 IP 目的地址仍是主机 2。

### 861

**答案：A**

四项中 ARP Request 直接使用当前二层广播；大量同时发生最直接制造广播流量。

### 862

**答案：A**

路由器每跳拆掉旧 frame，再按下一跳重新封装当前链路的源/目的 MAC；普通转发不改端到端 IP。

### 863

**答案：D**

RARP 是由硬件地址反查 IP；由 IPv4 next-hop 地址解析当前链路 MAC 是 ARP。

### 864

**答案：A**

`255.255.255.255` 是 limited broadcast，只在本地链路有效，路由器不跨接口转发。

### 865

**答案：C**

ARP 的触发条件是：**已经决定了 next-hop IP，但缓存中没有该 IP→MAC 映射**。接收报文不以先查询源映射为前提。

### 866

**答案：B**

5 个路由器把 A→B 路径分成 6 个相邻 Ethernet 链路段。缓存全空时，每段的发送者都要为本段 next hop 发起一次 ARP Request，共 6 次。

### 867

**答案：B**

`/20` 的第三字节块为 128–143；136 与 130 同属该块，所以甲直接 ARP 乙，帧目的 MAC 是乙。

### 868

**答案：D**

TTL=1 经路由器递减为 0，路由器丢弃并向源端发送 ICMP Time Exceeded。

### 869

**答案：A**

ICMP 报文作为 IP payload 发送，不绕过 IP 直接成为普通二层上层负载。

### 870

**答案：D**

IPv6 使用 128-bit 地址、固定 40 B 基础首部，并取消 IPv4 的 header checksum。

### 871

**答案：D**

显式写出 5 组，`::` 补 3 组 `0000`，各组补齐 4 个十六进制位，得到 `0008:0000:0000:0000:00D0:0123:CDEF:089A`。

### 872

**答案：D**

IPv6 基础首部没有 header checksum；固定 40 B、128-bit 地址，路径路由器不分片。

### 873

**答案：A**

IPv6 router 不做路径分片；过大时丢弃并返回 ICMPv6 Packet Too Big，源端据此调整分组尺寸。

## 高频模型

### ARP 次数不是“路由器数 + 1”的无条件公式

ARP 每次发生都必须同时满足：

1. 当前链路使用 IPv4/Ethernet 式 ARP；
2. 已确定 next-hop IP；
3. next-hop 映射缓存未命中。

866 之所以能得到 6，是因为题干把这三个前提全部补齐了。

### 分片先做 8 B 对齐

非末片 payload：

$$
L_{regular}=8\left\lfloor\frac{MTU-H}{8}\right\rfloor.
$$

`Fragment Offset` 的坐标始终是**原始 IP payload**中的位置，而不是每次二次分片后的局部坐标。
