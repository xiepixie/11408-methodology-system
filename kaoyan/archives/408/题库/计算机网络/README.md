## 使用方式

- 题面文件只保留题干、选项和必要图表，不放答案。
- 答案文件统一采用“答案速查 → 题号跳转 → 逐题解析”；逐题解析再解释判据、状态变化或计算过程。
- 计算题优先写清量的定义、单位和状态时点；协议题优先区分 Scope、State Owner、Protocol/Service 与逐事件状态变化。
- 依赖拓扑的题使用仓库内可维护的 TikZ/SVG 图，不把答案信息画进题图。
