## 最终题库规则

1. **来源题号完整保留。** 475–695 每个题号都有正式题面和答案，不再因重复、简单或旧教材口径而静默删除。
2. **最终题面以“正确、自洽、可训练”为目标。** 明确 OCR 错误直接恢复；原题缺失必要前提、存在双真风险或把旧教材实现写成普遍定律时，允许做最小校订，把决定答案的模型直接写入题干。
3. **题面与答案分离，但答案页必须可快速复习。** `*_选择题.md` 不泄露答案；`*_答案与解析.md` 统一采用“答案速查 → 题号跳转 → 逐题解析”结构。逐题解析至少说清“判断抓手 + 为什么”，计算题保留必要计算过程，不能退化成只有一句抽象关键词的答案表。
4. **代码、公式、表格原生化。** 程序截图恢复为 fenced code，公式使用 LaTeX，结构化数据优先 Markdown table；只有空间关系本身承载题意时才使用 TikZ/SVG。
5. **旧教材模型必须显式命名。** BIOS/MBR、负值信号量、经典 ULT、CHS、传统驱动分层等结论只在题干声明的模型中使用，不升级成现代系统的一般定律。
6. **出现新证据时修改最终题面，而不是重新堆审校文件。** 若后续高清原页或更可靠来源推翻当前恢复结果，直接更新对应题目与答案，并在版本记录中说明即可。
