### 574

```text
semaphore x1 = 1, x2 = 1, y = 1;
int c1 = 0, c2 = 0;

P1() {
    while (1) {
        P(x1);
        if (++c1 == 1) P(y);
        V(x1);

        compute(A);

        P(x1);
        if (--c1 == 0) V(y);
        V(x1);
    }
}

P2() {
    while (1) {
        P(x2);
        if (++c2 == 1) P(y);
        V(x2);

        compute(B);

        P(x2);
        if (--c2 == 0) V(y);
        V(x2);
    }
}
```

B. 进程不会死锁，但是会饥饿  
C. 进程会死锁，但是不会饥饿  
D. 进程会死锁，也会饥饿
