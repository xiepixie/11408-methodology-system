# 408-2020-Q46

## Model Anchor

- Topic：二维数组地址生成 + 二级页表逐级翻译 + 局部性。
- 题目信号：32 位 VA 被切成 `10/10/12`，同时给数组行优先布局和页目录物理基址。
- 第一动作：先生成**唯一虚拟地址**，再逐层拆 `PDE index / PTE index / offset`；不要一上来在十六进制里猜字段。

## Problem Representation

虚拟地址结构：

```text
31                  22 21             12 11            0
+---------------------+-----------------+----------------+
| page directory (10) | page table (10) | offset (12)    |
+---------------------+-----------------+----------------+
```

页大小：

$$2^{12}=4096\text{ B}=4\text{ KB}.$$

数组为 `int a[1024][1024]`，每元素 4 B，按行优先，所以一行大小恰好为

$$1024\times4=4096\text{ B}=1\text{ page}.$$

## Decision Points

1. 地址生成属于语言/数据布局层：`base + (i*1024+j)*4`。
2. PDE 地址由 `page_directory_base + dir_index*4` 得到。
3. PDE 给出的页框号指向**二级页表所在物理页**，不是数组数据页。
4. PTE 地址再由 `second_level_table_base + table_index*4` 得到。

## Solution Chain

### （1）`a[1][2]` 地址及页表项地址

行优先偏移量：

$$
(1\times1024+2)\times4
=1026\times4
=4104
=0x1008.
$$

因此虚拟地址为

$$
0x10800000+0x1008
=\boxed{10801008_H}.
$$

#### 页目录号

$$
Dir=(VA\gg22)=\boxed{0x42}.
$$

#### 二级页号 / 页表索引

$$
PTIndex=(VA\gg12)\ \&\ 0x3FF
=\boxed{0x001}.
$$

页内偏移为 `008H`。

#### 页目录项物理地址

页目录起始物理地址：`00201000H`。每个 PDE 4 B：

$$
PDEAddr
=0x00201000+0x42\times4
=\boxed{00201108_H}.
$$

#### 页表项物理地址

该 PDE 中页框号为 `00301H`，所以对应二级页表的物理页基址为

$$\boxed{00301000_H}.$$

页表索引为 1，每个 PTE 4 B：

$$
PTEAddr
=0x00301000+1\times4
=\boxed{00301004_H}.
$$

### （2）虚拟空间与物理空间是否连续

数组是 C 语言中的连续对象，数组元素地址由统一基址加线性偏移生成，因此其在**虚拟地址空间必须连续**。

请求分页把每个虚页独立映射到任意可用页框，相邻虚页的页框号不必相邻，所以数组在**物理地址空间不要求连续**。

因此：

```text
virtual: continuous
physical: may be non-contiguous
```

### （3）按行还是按列局部性更好？

数组按行优先，每一行又恰好占一页。

按行遍历时地址连续增长 4 B：

```text
a[i][0], a[i][1], a[i][2], ...
```

能连续利用同一 Cache line / 同一页面中的后续数据，空间局部性好。

按列遍历时相邻两次访问跨一整行：

$$stride=1024\times4=4096\text{ B}=1\text{ page}.$$

几乎每次都跳到下一页，对 Cache 与页级工作集都更不友好。

所以

$$\boxed{\text{按行遍历局部性更好}}.$$

## Verification

因为基址 `10800000H` 本身 4 KB 对齐，而每行正好 4 KB：

```text
row 0 -> page 10800H
row 1 -> page 10801H
```

所以 `a[1][2]` 落在下一页、页内偏移 `8H`，与计算出的 `10801008H` 完全吻合。

PDE 地址也可做对齐检查：`0x42*4=0x108`，因此 `00201000H+108H=00201108H`。

## Compression

```text
row-major VA first:
base + (1*1024+2)*4 = 10801008H

VA split 10/10/12:
dir=42H, pte-index=1, offset=8
PDE = 00201000 + 42H*4 = 00201108H
PDE frame 00301H -> PT base 00301000H
PTE = +1*4 = 00301004H

array: virtual contiguous, physical need not
row traversal stride 4B; column stride 4KB
```

## 易错边界

- PDE 里的页框号指向二级**页表**，不是最终数据页；地址翻译必须逐级完成。
- “物理页不连续”不会破坏 C 数组连续性，因为程序只观察虚拟地址。
- 局部性不能只说“行优先所以按行好”；本题还能进一步量化：列遍历 stride 恰好等于 1 页。
