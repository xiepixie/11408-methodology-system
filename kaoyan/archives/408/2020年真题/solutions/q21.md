# 408-2020-Q21

## Model Anchor

- Topic：外部中断的响应条件。
- 题目信号：不可屏蔽中断、可屏蔽中断以及“立即响应”这种绝对表述。
- 第一动作：区分“中断请求已经有效”和“处理器满足响应条件”。

## 解题链

A 正确：不可屏蔽中断不受普通中断允许状态控制。  
B 错误：可屏蔽中断请求有效后，处理器通常还要等待当前指令完成，并检查是否允许中断、该请求是否被屏蔽以及优先级条件，因此不能说“一旦有效就立即响应”。  
C 正确：不可屏蔽中断用于更紧急的事件，优先级高于普通可屏蔽中断。  
D 正确：中断屏蔽字可以改变当前允许响应的中断源，从而影响处理顺序。

## 选项判断

故错误项为 $\boxed{B}$。

## Verification

若普通中断可以在任意指令执行中途立即响应，就难以保持指令执行边界上的体系结构状态一致性，因此 B 的绝对表述不成立。

## Compression

```text
request valid
!= immediate response
response needs instruction boundary + enable/mask/priority checks
```

## 易错边界

不要把“设备发出请求”与“处理器已经响应”视为同一个事件。
