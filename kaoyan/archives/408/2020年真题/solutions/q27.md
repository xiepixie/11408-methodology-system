# 408-2020-Q27

## Model Anchor

- Topic：银行家算法的安全性状态推进。
- 题目信号：给出总资源、Allocation 和 Max，判断安全序列。
- 第一动作：先算 `Available` 与每个进程的 `Need=Max-Allocation`，再按可完成进程推进 Work。

## 解题链

系统资源总量为 `(6,6)`，当前已分配：

$$P_1(2,3)+P_2(2,1)+P_3(1,2)=(5,6),$$

所以

$$Available=(1,0).$$

剩余需求：

```text
P1: (2,1)
P2: (1,0)
P3: (2,2)
```

初始只有 P2 满足 `Need<=Available`。P2 完成并释放 `(2,1)` 后：

$$Work=(3,1).$$

此时 P1 可完成，释放 `(2,3)` 后 `Work=(5,4)`，最后 P3 可完成。

安全序列为

$$P_2\to P_1\to P_3.$$

## 选项判断

故选 $\boxed{B}$。

## Verification

P2 完成后 P3 仍需要 B=2，而 Work 的 B=1，所以 `P2,P3,P1` 并不安全。

## Compression

```text
Available=(1,0)
-> only P2
-> Work=(3,1)
-> P1
-> P3
```

## 易错边界

安全性检查用的是“剩余需求 Need”，进程完成后加回的是“已分配 Allocation”，不能把 Max 直接加回。
