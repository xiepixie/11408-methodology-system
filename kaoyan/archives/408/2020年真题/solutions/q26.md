# 408-2020-Q26

## Model Anchor

- Topic：多级反馈队列（MLFQ）的策略参数。
- 题目信号：问“设计算法时需要考虑哪些因素”。
- 第一动作：把 MLFQ 看成“多个队列 + 队列内策略 + 队列间迁移”的完整 Policy Contract。

## 解题链

I 队列数量决定优先级层次数。  
II 各队列优先级决定 CPU 首先从哪个队列选择。  
III 每个队列内部还需要自己的调度算法/时间片规则。  
IV 进程何时降级、升级或重新进入哪个队列决定反馈机制本身。

四者都是 MLFQ 定义不可缺少的参数。

## 选项判断

故选 $\boxed{D}$。

## Verification

若缺少 IV，系统只剩静态多级队列而没有“反馈”；若缺少 III，同一队列内部无法决定谁运行。

## Compression

```text
MLFQ = queue count + priorities + intra-queue policy + migration rules
```

## 易错边界

多级反馈队列和多级队列的核心区别就是动态迁移规则，不要只看到“多队列”。
