# 408-2020-Q35

## Model Anchor

- Topic：二层/三层设备对冲突域与广播域的切分。
- 题目信号：图中同时出现路由器、以太网交换机和 Hub。
- 第一动作：分别数两种边界：Hub 不切冲突域；Switch 每端口切冲突域但不切广播域；Router 切广播域。

## 解题链

沿题图逐段看：集线器连接的共享介质整体仍是一个冲突域；交换机不同端口属于不同冲突域；路由器接口则把二层广播隔开。

按图中实际连接关系计数：

- 冲突域共有 4 个；
- 广播域由路由器分成 2 个。

## 选项判断

因此为 `(4,2)`，选 $\boxed{C}$。

## Verification

若把 Hub 的每个端口都当作独立冲突域会过计数；若把 Switch 当作广播边界又会把广播域数算大。

## Compression

```text
Hub: collision shared, broadcast shared
Switch: collision split, broadcast shared
Router: broadcast split
-> 4 collision / 2 broadcast
```

## 易错边界

冲突域和广播域必须分两遍数；不要试图用同一条“设备越高级切得越多”口诀一次完成。
