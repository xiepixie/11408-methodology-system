# 408-2020-Q12

## Model Anchor

- Topic：机器字长与部件宽度的 Owner。
- 题目信号：问“位数一定与机器字长相同”。
- 第一动作：先判断每个部件保存/处理的对象是什么，再决定其宽度由谁定义。

## 解题链

I ALU：整数 ALU 的基本运算宽度通常就是机器字长，正确。  
II IR：宽度由**指令字长**决定，指令字长不必等于机器字长，错误。  
III GPR：通用寄存器保存机器基本字长的数据，通常与机器字长一致，正确。  
IV 浮点寄存器：由浮点格式/实现决定，可能宽于机器字长，不能说一定相同。

因此只有 I、III。

## 选项判断

故选 $\boxed{B}$。

## Verification

只需构造“32 位机器 + 64 位浮点寄存器”或“可变长指令”的处理器，就能否定 II/IV 的“一定”。

## Compression

```text
width owner:
ALU/GPR -> machine word
IR -> instruction length
FPR -> FP format/implementation
```

## 易错边界

题目问“一定”时，要区分教材常见实现和架构上必然约束。
