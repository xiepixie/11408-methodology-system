# 408-2020-Q09

## Model Anchor

- Topic：堆的结构不变量。
- 题目信号：判断大根堆能推出哪些全局/局部性质。
- 第一动作：分开“形状约束”和“关键字偏序约束”。

## 解题链

I 对：堆的形状是一棵完全二叉树。  
II 对：完全二叉树天然适合顺序存储。  
III 错：堆只保证父结点不小于孩子，不保证“左子树 < 根 < 右子树”，不是 BST。  
IV 对：根是最大值。除根外任一结点都不大于其祖先，因此全堆的次大值一定是根的某个孩子，即下一层。

所以正确的是 I、II、IV。

## 选项判断

故选 $\boxed{C}$。

## Verification

若次大值位于更深层，则其父结点必须不小于它且不是根，于是存在一个至少同样大的非根结点，矛盾于“次大”。

## Compression

```text
heap = complete-tree shape + parent-child order
-> array yes, BST no
-> second max among root's children
```

## 易错边界

堆序是局部偏序，不是全序；不能据此推导中序有序或子树范围。
