# 408-2020-Q34

## Model Anchor

- Topic：虚电路网络的连接状态与资源承诺。
- 题目信号：判断虚电路是否“必须预分配带宽”。
- 第一动作：区分“建立转发状态”与“预留资源/QoS”，二者不是同一个合同。

## 解题链

A 正确：同一虚电路上的分组沿已建立路径转发，可保持次序。  
B 错误：建立虚电路必须建立连接/转发表状态，但并不要求每条虚电路都预先保留固定带宽；资源预留属于可选的 QoS 机制。  
C 正确：连接建立阶段需要选择路径。  
D 正确：数据传输阶段依靠 VCID 等局部虚电路标识进行转发。

## 选项判断

故错误项为 $\boxed{B}$。

## Verification

若“虚电路=必须带宽预留”，所有无资源预留的虚电路分组网络都会被错误排除；定义的必要条件其实是连接状态与路径绑定。

## Compression

```text
virtual circuit
-> setup path/state
-> forward by VCID
!= mandatory bandwidth reservation
```

## 易错边界

面向连接不等于电路交换；虚电路仍可采用统计复用。
