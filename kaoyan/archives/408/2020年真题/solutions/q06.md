# 408-2020-Q06

## Model Anchor

- Topic：DFS 完成时刻与拓扑偏序。
- 题目信号：有向无环图；访问输出从“进入递归时”移到“退出递归前”。
- 第一动作：问输出发生在顶点的发现时刻还是完成时刻，并把边约束映射到完成顺序。

## 解题链

对 DAG 中任意边 $u\to v$：若 DFS 从 u 能沿该边访问 v，则 v 的递归必须先结束，u 才能退出；即完成顺序中 v 在 u 前。

拓扑序要求 u 在 v 前，而修改后的 DFS 恰好按完成时刻输出，所以对每条边都满足

```text
u -> v   =>   output(v) before output(u)
```

因此输出是拓扑序的逆序，即逆拓扑有序序列。

## 选项判断

故选 $\boxed{B}$。

## Verification

标准拓扑排序的 DFS 做法正是“退出时入栈，最后再逆序输出”；若不逆序，得到的就是逆拓扑序。

## Compression

```text
DFS postorder on DAG
-> child finishes before parent
-> edge u→v gives v before u
-> reverse topological order
```

## 易错边界

DFS 的“发现序”和“完成序”不是一回事；只有完成序反转后才是通常的拓扑序。
