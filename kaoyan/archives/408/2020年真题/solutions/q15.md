# 408-2020-Q15

## Model Anchor

- Topic：TLB 与 Cache 的层级职责、实现介质。
- 题目信号：比较两个“高速缓存”结构，找错误的共同描述。
- 第一动作：分别锁定它们缓存的对象：TLB 缓存地址翻译，Cache 缓存主存块；再比较共同性质。

## 解题链

A 对：二者命中率都受访问局部性影响。  
B 对：TLB miss 需查询主存中的页表；Cache miss 需从下一层存储器/主存取块。  
C 对：Cache miss 处理由硬件完成；TLB miss 在一些体系结构中也可由硬件页表遍历完成，所以“可以由硬件实现”成立。  
D 错：TLB 与 Cache 都要求高速访问，典型实现使用 SRAM/相联存储结构，而不是由 DRAM 组成。

## 选项判断

故选 $\boxed{D}$。

## Verification

若用 DRAM 做一级 Cache/TLB，其访问延迟会接近主存，失去层级加速意义。

## Compression

```text
TLB caches translation
Cache caches data/instruction blocks
both fast -> SRAM-like, not DRAM
```

## 易错边界

TLB miss 与 page fault 不是一回事：TLB miss 仍可能对应驻留页，只需重新获得页表映射。
