# 408-2020-Q20

## Model Anchor

- Topic：异常/中断按事件来源分类。
- 题目信号：缺页、定时器、网络到达混合判断“外部中断”。
- 第一动作：问事件是否由当前指令执行同步触发。

## 解题链

I 缺页：由当前访存指令触发，是同步异常，不属于外部中断。  
II 定时器到时：来自处理器外部/独立计时硬件，与当前指令语义无关，是外部中断。  
III 网络数据包到达：由 I/O 设备异步通知 CPU，是外部中断。

所以只有 II、III。

## 选项判断

故选 $\boxed{C}$。

## Verification

重复执行同一条访存指令，在页仍不驻留时会重复触发缺页；而网络包/定时器到时不由该指令决定，这正是同步与异步的边界。

## Compression

```text
instruction-caused -> exception
external asynchronous event -> interrupt
page fault no; timer/network yes
```

## 易错边界

“缺页会打断程序”不等于它是外部中断；分类看来源，不看是否发生控制转移。
