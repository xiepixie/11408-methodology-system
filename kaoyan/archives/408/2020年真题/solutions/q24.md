# 408-2020-Q24

## Model Anchor

- Topic：文件物理结构的增长能力与访问能力。
- 题目信号：同时要求“长度可变 + 随机访问”。
- 第一动作：把两个需求拆开检查：能否非连续增长？能否由逻辑块号直接定位物理块？

## 解题链

连续分配随机访问好，但文件扩展困难。  
链接分配易增长，但按普通链式结构访问第 k 块需要沿链走，随机访问差。  
索引分配通过索引块保存各数据块地址，文件可按需增加块，同时可以由逻辑块号索引到对应地址，兼顾长度可变和随机访问。  
动态分区是内存管理概念，不是文件磁盘块分配方式。

## 选项判断

故选 $\boxed{A}$。

## Verification

需求合同是两个 AND 条件；只有索引分配同时满足，而不是分别找一个优点最明显的方案。

## Compression

```text
variable size + random access
-> indexed allocation
```

## 易错边界

FAT 改进的链接分配可提升随机访问，但题目问基本“磁盘空间分配方式”时按连续/链接/索引的标准模型判断。
