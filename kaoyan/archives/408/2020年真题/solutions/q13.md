# 408-2020-Q13

## Model Anchor

- Topic：同一比特串的类型化解释。
- 题目信号：机器数固定为 `C8000000H`，类型可能是 int 或 float。
- 第一动作：保持 bits 不变，分别套用补码解释器和 IEEE 754 解释器；不要混合两种语义。

## 解题链

若 x 为 32 位 int，最高位为 1，按补码解释：

$$0xC8000000-2^{32}=-939524096=-7\times2^{27}.$$

这正是 A。

若 x 为 float：符号位为 1，阶码字段为 `10010000₂=144`，真阶

$$E=144-127=17,$$

尾数字段全 0，因此值为

$$-1.0\times2^{17}=-2^{17},$$

不在其余选项中。

## 选项判断

故可能的值是 $\boxed{A}$。

## Verification

同一 32 位模式可对应完全不同数值；本题只需某一种合法类型解释命中选项即可。

## Compression

```text
same bits, two decoders
int: unsigned value - 2^32
float: sign/exponent/fraction
-> A
```

## 易错边界

机器数本身没有“整数/浮点意义”；意义由类型解释规则赋予。
