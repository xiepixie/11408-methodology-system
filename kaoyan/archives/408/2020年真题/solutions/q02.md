# 408-2020-Q02

## Model Anchor

- Topic：栈的状态演化。
- 题目信号：给定确定的 Push/Pop 操作序列。
- 第一动作：逐操作维护“栈内容 + 下一入栈元素”，不要凭印象猜出栈排列。

## 解题链

按题目操作：

```text
Push a       [a]
Push b       [a,b]
Pop          -> b
Push c       [a,c]
Pop          -> c
Push d       [a,d]
Push e       [a,d,e]
Pop          -> e
```

因此前三次出栈依次为

$$b,c,e.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

每次 Pop 都只能取当前栈顶；第二次 Pop 时 a 被 c 压在下面，所以不可能得到 a。

## Compression

```text
state trace -> b -> c -> e
```

## 易错边界

这是“给定操作序列求输出”，不是“判断某排列能否由栈产生”；最稳方法就是直接画状态。
