# 408-2020-Q18

## Model Anchor

- Topic：异常分类与 Trap 的触发语义。
- 题目信号：“自陷/Trap”与外部中断混在一起判断。
- 第一动作：先问事件 Owner：来自当前指令执行，还是来自 CPU 外部异步事件。

## 解题链

Trap 是由执行特定陷阱指令主动触发的**同步异常**，事件与当前指令执行直接相关，不是外部中断，因此 A 错。

B 对：调试器可利用陷阱机制实现断点、单步等。  
C 对：Trap 进入内核态并转到相应异常处理程序。  
D 对：对这种有意触发的陷阱，处理完成后通常从陷阱指令的下一条继续执行。

## 选项判断

故错误项为 $\boxed{A}$。

## Verification

若 Trap 是“外部中断”，它就不应由某条指令精确、同步地产生，这与系统调用/断点的可重复语义冲突。

## Compression

```text
trap = synchronous, instruction-caused exception
not external interrupt
```

## 易错边界

“中断”在中文教材里有时作广义总称；做题时要回到同步异常 vs 异步外部中断的事件来源。
