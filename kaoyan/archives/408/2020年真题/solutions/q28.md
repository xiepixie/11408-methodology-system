# 408-2020-Q28

## Model Anchor

- Topic：请求分页系统的有效访存时间（EAT）。
- 题目信号：问哪些因素影响平均访存时间，选项覆盖 fault probability 与 fault cost。
- 第一动作：先写成本模型：正常访问成本 + 缺页概率 × 缺页额外成本。

## 解题链

请求分页系统可抽象为

$$EAT=(1-p)t_m+p(t_{pf}),$$

其中 $p$ 为缺页率，$t_m$ 为正常内存访问时间，而 $t_{pf}$ 包含缺页处理时的磁盘读写、CPU 执行缺页处理程序以及恢复执行等成本。

因此：

- I 缺页率决定高成本路径出现频率；
- II 磁盘读写时间是缺页服务的主要成本；
- III 内存访问时间影响正常路径和页表/数据访问；
- IV 缺页处理程序的 CPU 时间也是 fault service time 的组成部分。

四项都影响 EAT。

## 选项判断

故选 $\boxed{D}$。

## Verification

即使缺页率很低，磁盘毫秒级成本也可能显著放大平均时间，说明概率与代价两个维度都不能省略。

## Compression

```text
EAT = normal path + P(page fault) × fault service cost
fault cost includes disk + CPU handler
```

## 易错边界

不要把“磁盘时间远大于 CPU 时间”误解成 CPU 时间完全不影响；题目问的是是否影响，不是是否占主导。
