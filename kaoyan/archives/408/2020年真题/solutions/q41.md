# 408-2020-Q41

## Model Anchor

- Topic：三个有序集合中的最小覆盖区间 / 三指针扫描。
- 题目信号：从 3 个升序数组各取一个数，目标是最小化三者两两距离之和。
- 第一动作：先化简目标函数，再寻找哪个状态变量的推进才可能让目标变小；不要直接做 $O(n_1n_2n_3)$ 枚举。

## Problem Representation

设当前三元组的最小值和最大值为

$$m=\min(a,b,c),\qquad M=\max(a,b,c).$$

对任意三个实数，将它们排序成 $x\le y\le z$，则

$$
|x-y|+|y-z|+|z-x|
=(y-x)+(z-y)+(z-x)
=2(z-x).
$$

所以原问题等价于

$$\boxed{\min D=2\min(M-m)}.$$

也就是说，我们真正要找的是：**同时包含 $S_1,S_2,S_3$ 各一个元素的最短数轴区间**。

## Decision Points

### 1. 为什么每次只推进当前最小值对应的指针？

固定当前最小值 $m$ 时，若只增大中间值或最大值，区间右端 $M$ 不会变小，而左端 $m$ 也不变，因此 $M-m$ 不可能下降。

要让区间有机会收缩，必须尝试把当前最小值向右移动。因此：

```text
compare A[i], B[j], C[k]
-> record current range
-> advance pointer owning current minimum
```

这就是本题的单调支配关系。

### 2. 什么时候停止？

任一数组指针到达末尾后，就再也无法组成新的三元组，因此可以停止。若中途得到 $D=0$，这是理论下界，也可立即结束。

## Solution Chain

### （1）算法思想

用三个指针 `i,j,k` 分别指向三个升序数组的当前元素：

1. 计算当前三元组的 `min`、`max`；
2. 用 `2*(max-min)` 更新最优答案；
3. 将当前最小元素所在数组的指针右移一位；
4. 直到任一数组扫描结束。

### （2）C 语言实现

```c
int minDistance(int A[], int n1,
                int B[], int n2,
                int C[], int n3)
{
    int i = 0, j = 0, k = 0;
    int best = INT_MAX;

    while (i < n1 && j < n2 && k < n3) {
        int a = A[i], b = B[j], c = C[k];
        int mn = a, mx = a;

        if (b < mn) mn = b;
        if (c < mn) mn = c;
        if (b > mx) mx = b;
        if (c > mx) mx = c;

        int d = 2 * (mx - mn);
        if (d < best) best = d;
        if (best == 0) break;          // 已达到理论最小值

        // 只有提高当前区间左端，才可能缩短区间
        if (mn == a)
            i++;
        else if (mn == b)
            j++;
        else
            k++;
    }

    return best;
}
```

若希望同时输出最优三元组，只需在 `best` 更新时额外保存当前 `a,b,c`。

### （3）复杂度

三个指针都只单调向右，且不会回退：

$$T(n)=O(n_1+n_2+n_3).$$

除若干标量变量外不需要额外存储：

$$S(n)=O(1).$$

## Verification

题给示例：

```text
S1 = {-1,0,9}
S2 = {-25,-10,10,11}
S3 = {2,9,17,30,41}
```

扫描过程中会到达 `(9,10,9)`：

$$m=9,\quad M=10,$$

于是

$$D=2(10-9)=2,$$

与题目给出的最优值一致。

更关键的是推进规则可证明不会漏解：在当前最小值仍固定时，移动其他两个指针不可能得到更小区间，因此被跳过的状态均被当前状态支配。

## Compression

```text
|a-b|+|b-c|+|c-a|
-> 2(max-min)
-> three sorted arrays = shortest 3-color interval
-> evaluate current triple
-> advance current minimum
-> O(n1+n2+n3), O(1)
```

## 易错边界

- 不能用“三层循环 + 每次算 D”，那是 $O(n_1n_2n_3)$，没有利用升序结构。
- 推进的是**当前最小值**，不是当前最大值。
- 若多个数组同时取得最小值，推进其中任意一个即可保持正确性；若已经 `max==min`，可直接返回 0。
- 目标化简 $D=2(\max-\min)$ 对任意整数都成立，并不依赖数值为正。
