# 408-2020-Q22

## Model Anchor

- Topic：周期挪用 DMA 的总线仲裁与粒度。
- 题目信号：512 B 数据块、32 位缓冲寄存器、cycle stealing。
- 第一动作：先确定一次 DMA 占用总线搬多少数据，再判断 CPU 与 DMA 是“整块互斥”还是“按周期竞争”。

## 解题链

32 位缓冲寄存器一次准备 4 B 数据，所以每准备好一份数据即可发起一次总线请求，A 正确。

周期挪用模式下，为避免设备数据丢失，DMA 在发生总线竞争时通常具有较高优先级，B 正确。

C 错。周期挪用并不是 DMA 在整个 512 B 数据块期间永久占有总线，而是只在每次传送时“挪用”若干总线周期；其余周期 CPU 仍可访问主存。

数据块传输完成后通过中断通知 CPU，D 正确。

## 选项判断

故错误项为 $\boxed{C}$。

## Verification

若整个数据块期间 CPU 都不能访存，那更接近连续占用/块传送，而失去了 cycle stealing 的基本语义。

## Compression

```text
DMA cycle stealing
-> request per buffer unit
-> steal selected bus cycles
-> CPU can use memory between steals
```

## 易错边界

“DMA 直接访问主存”不等于“CPU 在整个 DMA 期间停止访问主存”；要看具体总线控制方式。
