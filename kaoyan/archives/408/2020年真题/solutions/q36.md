# 408-2020-Q36

## Model Anchor

- Topic：停等协议信道利用率与完整周期成本。
- 题目信号：数据帧和 ACK 都是 1000 B，不能忽略 ACK 发送时间。
- 第一动作：定义一个成功发送周期，从数据帧开始发送到 ACK 完整返回，再用“有效数据发送时间 / 周期时间”。

## 解题链

数据帧和 ACK 的发送时延均为

$$t_f=t_{ack}=\frac{1000\times8}{10\,000}=0.8\text{ s}.$$

单向传播时延为 0.2 s，因此一个停等周期为

$$T=0.8+0.2+0.8+0.2=2.0\text{ s}.$$

信道利用率按发送有效数据帧所占时间计：

$$U=\frac{0.8}{2.0}=40\%.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

题目明确 ACK 与数据帧等长，若套“ACK 可忽略”的常见公式会少算 0.8 s，得到错误结果。

## Compression

```text
data tx .8 + prop .2 + ACK tx .8 + prop .2 = 2.0s
U=.8/2=.4
```

## 易错边界

利用率题第一步永远先确认哪些时间项被题目允许忽略；不要默认 ACK 很短。
