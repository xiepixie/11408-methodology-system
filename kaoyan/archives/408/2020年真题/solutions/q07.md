# 408-2020-Q07

## Model Anchor

- Topic：Kruskal 最小生成树与并查集不变量。
- 题目信号：问“加入最小生成树中的边依次是”，不仅要得到 MST，还要遵守按权从小到大的扫描顺序。
- 第一动作：按边权非降序扫描；每条边只问“两个端点当前是否在不同连通分量”。

## 解题链

Kruskal 的状态不是“当前离哪个点近”，而是当前森林的连通分量。根据题图边权排序后，依次检查最小候选边：

```text
(b,f) -> accept
(b,d) -> accept
(a,e) -> accept
(c,e) -> accept
(b,e) -> accept
```

前四条边形成两个尚未连通的分量，最后 `(b,e)` 把它们连接起来；每次加入都没有形成环，5 条边正好连接 6 个顶点。

## 选项判断

与上述接受顺序一致的是 $\boxed{A}$。

## Verification

MST 含 $|V|-1=5$ 条边；接受完第 5 条后全图连通且无环，因此可以停止。

## Compression

```text
sort edges by weight
-> DSU: accept iff components differ
-> 5 accepted edges
-> A
```

## 易错边界

Kruskal 的顺序由**边权**驱动；不能把 Prim 的“从当前树向外扩展”逻辑混进来。
