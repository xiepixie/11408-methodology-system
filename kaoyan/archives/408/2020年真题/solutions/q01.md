# 408-2020-Q01

## Model Anchor

- Topic：对称矩阵压缩存储与地址映射。
- 题目信号：只保存上三角、按列优先、C 数组下标从 0 开始。
- 第一动作：先利用对称性把目标元素映射到已存区域，再计算前缀元素个数。

## 解题链

$m_{7,2}$ 不在上三角，但对称矩阵满足 $m_{7,2}=m_{2,7}$。

按列存上三角时，第 $j$ 列保存 $j$ 个元素。到第 7 列之前已有

$$1+2+\cdots+6=21$$

个元素。$m_{2,7}$ 是第 7 列中的第 2 个，因此其 0 基下标为

$$21+(2-1)=22.$$

## 选项判断

故选 $\boxed{C}$。

## Verification

若按 1 基位置计数，它是第 23 个元素；换成 C 数组下标即 22，和选项 C 一致。

## Compression

```text
symmetric -> (7,2) maps to (2,7)
-> prefix columns 1..6 = 21
-> +1 offset
-> index 22
```

## 易错边界

矩阵下标通常从 1 写，C 数组下标从 0 写；最后必须做一次基准转换。
