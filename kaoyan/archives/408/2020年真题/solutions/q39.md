# 408-2020-Q39

## Model Anchor

- Topic：TCP 序号空间中 SYN / DATA / FIN 的占用。
- 题目信号：给出建立连接时 SYN 的序号和关闭时 FIN 的序号，反推数据字节数。
- 第一动作：建立序号账本：SYN 占 1 个序号，数据每字节占 1 个，FIN 也占 1 个。

## 解题链

甲发送 SYN 时 `seq=1000`，SYN 消耗一个序号，因此第一个应用数据字节的序号是

$$1001.$$

关闭连接时 FIN 的序号为 5001，说明 FIN 之前最后一个数据字节序号是 5000。

应用层数据字节数为

$$5000-1001+1=4000.$$

等价地：

$$5001-1000-1=4000,$$

减去的 1 就是 SYN 占用的序号。

## 选项判断

故选 $\boxed{C}$。

## Verification

序号范围 `1001~5000` 恰有 4000 个整数；FIN 随后占用 5001。

## Compression

```text
SYN seq 1000 consumes 1
DATA starts 1001
FIN seq 5001
-> data bytes = 5001-1001 = 4000
```

## 易错边界

SYN 和 FIN 虽不携带普通应用数据，也各消耗一个 TCP 序号；纯 ACK 不消耗。
