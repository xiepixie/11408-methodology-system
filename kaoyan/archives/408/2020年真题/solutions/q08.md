# 408-2020-Q08

## Model Anchor

- Topic：AOE 网、关键路径与时间余量。
- 题目信号：判断关于关键路径/关键活动的绝对命题。
- 第一动作：先恢复定义：工程工期是源点到汇点的**最长路径长度**，而不是边数最多。

## 解题链

A 错：关键路径按活动持续时间之和定义，不按边数。  
B 对：源点到汇点路径长度最大者决定最早完工时间。  
C 错：关键活动余量为 0，若其增加且仍位于控制工期的路径上，会延长工期。  
D 错：若存在多条关键路径，缩短只属于其中一条的关键活动，不一定缩短总工期，因为另一条关键路径仍控制工期。

## 选项判断

故选 $\boxed{B}$。

## Verification

构造两条等长关键路径即可反驳 D：只缩短其中一条，另一条长度不变，项目最短工期不变。

## Compression

```text
critical path = longest source-sink duration
multiple critical paths -> shortening one activity may not reduce makespan
```

## 易错边界

“关键活动”是当前参数下零余量，不等于“只要缩短它，工期一定下降”。要同时检查是否还有其他关键路径。
