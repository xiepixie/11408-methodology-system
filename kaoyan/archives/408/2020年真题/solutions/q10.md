# 408-2020-Q10

## Model Anchor

- Topic：4 阶 B 树插入与上溢分裂。
- 题目信号：连续插入 8 个关键字，问最终根关键字。
- 第一动作：维护“每结点最多 3 个关键字”的容量不变量；达到 4 个关键字时立即分裂并向父结点提升中间关键字。

## 解题链

依次插入 `5,6,9` 后根为 `[5,6,9]`。插入 13 发生第一次上溢，分裂后中间关键字提升，形成两层树。

随后将 `8,2,12,15` 按搜索路径插入相应叶结点；当叶结点再次上溢时继续“分裂 + 提升”。完成所有调整后，根中保留两个分隔关键字：

$$[6,9].$$

## 选项判断

故选 $\boxed{B}$。

## Verification

最终根有 2 个关键字，因此有 3 棵子树；各子树关键字区间分别满足 `<6`、`(6,9)`、`>9`，并满足 4 阶 B 树结点容量约束。

## Compression

```text
m=4 -> max 3 keys/node
-> insert along search path
-> overflow => split + promote
-> root [6,9]
```

## 易错边界

B 树“阶”约束的是孩子数上限；4 阶树每结点最多 4 个孩子、3 个关键字。
