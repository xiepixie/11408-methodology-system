# 408-2020-Q16

## Model Anchor

- Topic：定长指令字段预算与直接寻址范围。
- 题目信号：16 位指令、48 条指令、4 种寻址方式，操作码和寻址方式位数固定。
- 第一动作：先为“指令种类”和“寻址方式”分配最少位数，剩余位全部属于单地址字段。

## 解题链

48 条指令至少需要

$$\lceil\log_2 48\rceil=6$$

位操作码。4 种寻址方式需要

$$\log_2 4=2$$

位方式字段。

因此 16 位指令中地址码剩余

$$16-6-2=8$$

位。

直接寻址把地址字段直接解释为无符号存储单元地址，因此范围为

$$0\sim(2^8-1)=0\sim255.$$

## 选项判断

故选 $\boxed{A}$。

## Verification

C/D 的对称负数范围更像相对位移的有符号解释，不是直接寻址地址空间。

## Compression

```text
48 ops -> 6 bits
4 modes -> 2 bits
16-6-2 = 8 address bits
-> 0..255
```

## 易错边界

“地址字段有 8 位”不等于永远是无符号；其数值解释取决于寻址方式。本题明确问直接寻址。
