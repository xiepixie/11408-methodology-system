# 408-2020-Q23

## Model Anchor

- Topic：打开文件的多层状态与引用关系。
- 题目信号：多个进程共享同一文件 F，比较系统打开文件表与进程级打开文件表。
- 第一动作：分清文件对象的共享属性与每次打开/每个进程的局部状态。

## 解题链

A 错：共享文件并不意味着只能读，权限允许时可用不同方式打开。  
B 对：按 408 教材抽象，文件 F 的文件级属性由系统打开文件表中的共享表项维护，各进程通过自己的打开文件表引用它。  
C 错：进程级表项可包含不同文件描述符、访问方式/当前位置等局部信息，不要求内容完全相同。  
D 错：一个进程关闭 F 只减少引用；只有最后一个引用关闭后，系统级打开状态才可释放。

## 选项判断

故选 $\boxed{B}$。

## Verification

若任一进程 close 都立即删除系统表项，其他仍在使用 F 的进程会失去其打开状态，显然不成立。

## Compression

```text
file object shared
-> system-level state shared
-> process open entries local references
-> close decrements refcount
```

## 易错边界

文件的“磁盘 inode/FCB”“系统打开状态”“进程文件描述符”是不同层级对象，不要混成一张表。
