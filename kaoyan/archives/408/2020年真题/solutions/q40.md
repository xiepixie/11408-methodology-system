# 408-2020-Q40

## Model Anchor

- Topic：DNS 查询链 + HTTP/TCP 关键路径。
- 题目信号：本地域名服务器递归、外部服务器迭代；问最短/最长端到端时间。
- 第一动作：把 DNS 阶段和 Web 访问阶段分账，再分别找缓存最好情况与完整解析最坏情况。

## 解题链

题设说局域网内主机访问 Internet 上服务器 RTT=10 ms，并忽略其他时延，因此 H 与本地域名服务器之间的本地通信不计。

### 最短

若本地域名服务器已有 `www.abc.com` 的解析缓存，DNS 不产生 Internet RTT。随后：

1. TCP 三次握手：1 RTT；
2. HTTP 请求到收到纯文本页面：1 RTT。

所以

$$T_{min}=2RTT=20\text{ ms}.$$

### 最长

本地域名服务器无缓存，需要依次向：

```text
root -> .com TLD -> abc.com authoritative
```

进行 3 次迭代查询，共 3 RTT；再加 TCP+HTTP 的 2 RTT：

$$T_{max}=5RTT=50\text{ ms}.$$

## 选项判断

故选 $\boxed{D}$。

## Verification

最长路径必须同时包含 3 个外部 DNS RTT 和 2 个 Web RTT；本地递归请求本身按题设忽略，因此不能再加 1 RTT。

## Compression

```text
best: DNS cache + TCP 1RTT + HTTP 1RTT = 20ms
worst: root+TLD+auth 3RTT + TCP+HTTP 2RTT = 50ms
```

## 易错边界

先确认 RTT 的作用域。题目只给“H/本地 DNS 到 Internet 服务器”的 RTT，本地主机到本地 DNS 的时延明确落入“忽略其他时延”。
