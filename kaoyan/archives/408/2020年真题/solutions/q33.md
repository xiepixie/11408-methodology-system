# 408-2020-Q33

## Model Anchor

- Topic：网络协议三要素：语法、语义、时序。
- 题目信号：题图只展示发送方、接收方以及消息交互先后关系。
- 第一动作：问图中到底约束了“报文长什么样”“报文代表什么”还是“何时/按什么顺序交互”。

## 解题链

语法描述报文格式、字段结构和编码；语义规定字段/动作的含义；时序规定事件发生的先后和交互关系。

题图以时间轴形式描述发送方与接收方之间的交互顺序，没有给出报文字段格式，也没有定义字段含义，因此直接体现的是**时序**。

## 选项判断

仅 III，故选 $\boxed{C}$。

## Verification

把图中的时间轴去掉后，图就失去主要信息；这说明其核心不是 syntax 或 semantics，而是 ordering/timing。

## Compression

```text
format -> syntax
meaning -> semantics
ordering/time -> timing
figure shows ordering -> III
```

## 易错边界

协议报文“箭头上写了一个名字”不等于图就描述了语义；要看图是否真正定义了该报文的行为含义。
