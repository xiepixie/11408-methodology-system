# 408-2020-Q04

## Model Anchor

- Topic：森林与二叉树的孩子—兄弟表示、遍历序列重建。
- 题目信号：给出森林对应二叉树的先序/中序信息，求后序。
- 第一动作：先利用遍历对应关系，把问题还原成“已知二叉树先序 + 中序求后序”。

## 解题链

森林 F 的先根遍历对应二叉树 T 的先序遍历，因此

```text
Pre: a b c d e f
In : b a d f e c
```

由先序首元素确定根 a。中序中 a 左侧只有 b，所以左子树为 b；右侧为 `d f e c`。

继续递归重建右子树：其先序为 `c d e f`，根为 c；中序 `d f e c` 表明 c 只有左子树。该左子树先序 `d e f`、中序 `d f e`，根 d，d 的右子树根为 e，e 的左孩子为 f。

因此后序为

```text
b f e d c a
```

## 选项判断

故选 $\boxed{C}$。

## Verification

把得到的树重新做先序和中序，可分别恢复题给两序列，重建闭合。

## Compression

```text
forest traversal -> binary-tree pre/in
-> recursively locate roots
-> post = b f e d c a
```

## 易错边界

不要把森林遍历名称直接套成二叉树后序；先完成表示转换，再按二叉树规则推理。
