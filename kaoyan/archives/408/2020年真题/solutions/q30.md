# 408-2020-Q30

## Model Anchor

- Topic：设备独立性与逻辑设备映射。
- 题目信号：判断“更换物理设备是否影响应用程序”。
- 第一动作：先恢复设备独立性的目标：把应用看到的逻辑名称与具体物理设备解耦。

## 解题链

A 对：很多系统把设备纳入统一文件接口，可通过文件名/设备文件访问。  
B 对：应用使用逻辑设备名而不是硬编码某台物理设备。  
C 对：系统必须维护逻辑设备到物理设备的映射。  
D 错：设备独立性正是为了使物理设备更换后，应用程序无需修改；变化由映射层和驱动层吸收。

## 选项判断

故错误项为 $\boxed{D}$。

## Verification

若每次换设备都必须修改应用，说明应用直接依赖物理设备身份，恰好违背 device independence。

## Compression

```text
application -> logical device -> mapping/driver -> physical device
replace physical device without changing application
```

## 易错边界

设备独立性不表示驱动程序也不需要变化；它保护的是应用层接口稳定。
