# q15_计算机组成原理

## 📋 题目要求 (题面)

下列关于 TLB 和 Cache 的叙述中，错误的是（ ）。

- **A.** 命中率都与程序局部性有关
- **B.** 缺失后都需要去访问主存
- **C.** 缺失处理都可以由硬件实现
- **D.** 都由 DRAM 存储器组成

---

## 💡 答案与深度解析

**【正确答案】**：`D`

**正确答案：D**
Cache 由 SRAM 组成；TLB 通常由相联存储器组成，也可由 SRAM 组成。DRAM 需要不断刷新，性能偏低，不适合组成 TLB 和 Cache 选项 A、B 和 C 都是 TLB 和 Cache 的特点。
