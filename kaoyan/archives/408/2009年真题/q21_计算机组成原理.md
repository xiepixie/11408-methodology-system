# q21_计算机组成原理

## 📋 题目要求 (题面)

假设某计算机的存储系统由 Cache 和主存组成，某程序执行过程中访存 1000 次，其中访问 Cache 缺失（未命中）50 次，则 Cache 的命中率是（）。

- **A.** 5%
- **B.** 9.5%
- **C.** 50%
- **D.** 95%

---

## 💡 答案与深度解析

**【正确答案】**：`D`

**正确答案：D**
命中率 = Cache 命中次数/总访问次数。需要注意的是看清题，题中说明的是缺失 50 次，而不是命中 50 次，仔细审题是做对题的第一步。
