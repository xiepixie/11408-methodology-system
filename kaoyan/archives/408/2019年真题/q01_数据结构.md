# q01_数据结构

## 📋 题目要求 (题面)

设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是（ ）。

```c
x = 0;
while (n >= (x + 1) * (x + 1))
    x = x + 1;
```

- **A.** $O(logn)$
- **B.** $O(n_{1}/2$
- **C.** $O(n)$
- **D.** $O(n_{2}$

---

## 💡 答案与深度解析

**【正确答案】**：`B`

**正确答案：B**
假设第 k 次循环终止，则第 k 次执行时，
 $(x+1)2$ >n
，x 的初始值为 0，第 k 次判断时，x=k-1，即
 $k_{2}$ >n
，
 $k>n_{1}/2$
,，因此该程序段的时间复杂度为
 $O(n_{1}/2$ )
。
