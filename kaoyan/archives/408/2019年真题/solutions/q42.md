# 408-2019-Q42

## Model Anchor

- Topic：满足“动态增长 + 出队空间复用 + 最坏 $O(1)$”的队列表示设计。
- 题目信号：队列占用空间**只增不减**，出队结点不能释放但要复用；入队/出队必须始终 $O(1)$。
- 第一动作：先从操作合同反推表示：顺序表扩容会产生搬移，普通链队列出队若释放结点又不满足“空间只增不减”，因此需要**循环链式存储 + front/rear + 已分配结点循环复用**。

## Problem Representation

把所有曾经申请过的结点组织成一个循环单链表。队列只通过 `front`、`rear` 改变“当前有效区间”，出队结点不 `free()`，而是留在环中等待后续入队复用。

采用一个空闲/哨兵位置区分逻辑队列状态：

```text
有效元素位于 front->next ... rear
front 指向队头元素之前的结点
rear  指向当前队尾元素
```

这样出队只需移动 `front`，入队只需移动 `rear`；只有已经分配的环没有空闲结点时，才申请一个新结点插入环中。

## Decision Points

1. **为什么选链式？** 动态申请一个结点是 $O(1)$，不会像顺序表扩容那样搬动已有元素。
2. **为什么做成循环？** 已出队的旧结点可以从 rear 后方重新走到可复用区。
3. **如何判空？** `front == rear` 表示有效区间为空。
4. **何时需要扩容？** `rear->next == front` 表示 rear 后面已没有现成空闲结点，下一次入队需要新申请结点。

这里的“满”是**已分配存储区暂无可复用空槽**，不是说队列不能继续入队；因为题目允许动态增长。

## Solution Chain

### (1) 存储结构

应选择：

$$\boxed{\text{循环单链表}}.$$

### (2) 初始状态、队空与“队满”条件

初始时先申请 1 个结点 `p`，构成单结点环：

```text
      ┌───────┐
      ▼       │
front,rear -> p
```

即：

```c
p->next = p;
front = rear = p;
```

判空：

```c
front == rear
```

已分配空间无可复用空槽：

```c
rear->next == front
```

初始时两个条件可同时成立：逻辑队列为空，同时现有环里也没有额外数据槽，所以第一次入队需要扩容一个结点。

### (3) 第一个元素入队后

若入队元素为 `x`，先在 `rear` 与 `front` 之间插入新结点 `p`，再让 rear 指向它：

```text
front -> [旧空结点] -> [x] <- rear
  ^                         |
  └─────────────────────────┘
```

### (4) 入队操作

```c
void EnQueue(ElemType x)
{
    // 无现成空闲结点：扩容 1 个结点
    if (rear->next == front) {
        NODE *p = (NODE *)malloc(sizeof(NODE));
        p->next = rear->next;   // 指向 front，保持成环
        rear->next = p;
    }

    // 使用 rear 后面的空闲结点
    rear = rear->next;
    rear->data = x;
}
```

无论是否扩容，都只做常数次指针修改：

$$\boxed{O(1)}.$$

### 出队操作

```c
bool DeQueue(ElemType *x)
{
    if (front == rear)
        return false;           // 队空

    NODE *first = front->next;
    *x = first->data;

    // 不释放任何结点，只移动 front
    front = front->next;
    return true;
}
```

出队后，原 `front` 所在结点进入环上的可复用区域，整个已申请空间不会缩小。

## Verification

四条要求逐项核对：

```text
① 初始为空             -> front == rear
② 入队允许增加空间      -> full-storage 时 malloc 1 node
③ 出队空间可复用        -> 不 free，只移动 front
④ enqueue/dequeue O(1) -> 无遍历、无整体搬移
```

因此 Representation 与题目四个 Contract 完全闭合。

## Compression

```text
space only grows + reuse dequeued nodes + strict O(1)
-> circular linked list
-> front/rear delimit active region
-> rear->next==front: allocate one node
-> dequeue: move front, never free
```

## 易错边界

- 普通动态数组“偶尔 $O(n)$ 扩容”只能做到摊还 $O(1)$，不满足题目“始终 $O(1)$”。
- 普通链队列若出队立即 `free()`，违反“整个队列占用空间只增不减”。
- “rear->next==front”表示现有已分配环无空槽，不是逻辑上禁止入队；本题此时应扩容。
