# 408-2019-Q10

## Model Anchor

- Topic：快速排序每趟形成的 pivot invariant。
- 题目信号：“第二趟结果”不是任意中间序列；每个已处理子区间都会有一个枢轴到达最终位置。
- 第一动作：寻找能够作为第一趟枢轴的元素，再检查第二趟对其左右子区间是否还能各产生合法枢轴。

## 解题链

快速排序一次划分后，枢轴满足：

```text
左侧所有元素 < pivot < 右侧所有元素
```

且该枢轴已经处于最终排序位置。第二趟会继续处理第一趟留下的非空子区间，因此结果中必须能解释出相应的第二层枢轴位置。

A、B 可解释为第一趟以 72 为枢轴，第二趟分别在剩余区间产生合法枢轴；C 可由第一趟以 28 分割，再在左右子区间产生 2、32 等枢轴。

D 中不存在一组第一趟/第二趟枢轴，使所有已确定位置同时满足左右大小关系，因此不可能是第二趟结束状态。

## 选项判断

$$\boxed{D}.$$

## Verification

判断这类题不需要完整复现某一种 partition 代码；只检查“已归位枢轴两侧的偏序不变量”即可排除不可能状态。

## Compression

```text
quicksort pass
-> every processed interval fixes a pivot
-> check left<pivot<right recursively
-> D impossible
```

## 易错边界

“趟”的定义是对所有尚未确定位置的子序列各处理一次，不等同于只调用一次 partition。
