# 408-2019-Q30

## Model Anchor

- Topic：死锁的预防、避免、检测与解除。
- 题目信号：四个陈述混合不同治理阶段。
- 第一动作：先给每个机制定职责：Prevent / Avoid / Detect / Recover。

## 解题链

I. **剥夺资源**可以作为死锁解除手段之一，使某些进程回退/释放资源，正确。

II. **死锁预防**通过破坏四个必要条件之一，从机制上保证死锁不会形成，正确。

III. **银行家算法**解决的是死锁避免：判断资源分配后系统是否仍处于安全状态。安全性判断不等同于“检测当前是否已死锁”，错误。

IV. 死锁意味着存在互相等待而无法推进的一组进程，这些进程处于阻塞/等待状态；至少涉及两个相互依赖的执行实体，正确。

## 选项判断

I、II、IV 正确：

$$\boxed{B}.$$

## Verification

把 Banker 放到时间轴上就很清楚：它在**批准新的资源请求之前**做安全性检查，是避免死锁，而不是等死锁发生后再检测。

## Compression

```text
prevent -> break necessary condition
avoid -> Banker / safe state
detect -> wait-for/resource graph
recover -> preempt/terminate
```

## 易错边界

“unsafe”不等于“deadlocked”；不安全状态只是未来存在进入死锁的可能。
