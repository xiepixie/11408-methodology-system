# 408-2019-Q19

## Model Anchor

- Topic：存储器总线峰值带宽。
- 题目信号：`DDR3-1333 + 64 bit + 3 通道`。
- 第一动作：先算单通道“每秒有效传输次数 × 每次有效数据字节”，再乘并行通道数。

## 解题链

DDR3-1333 的有效数据传输率约为 $1333\times10^6$ 次/s。总线宽度 64 bit=8 B，所以单通道峰值带宽约为

$$1333\times10^6\times8\approx10.66\text{ GB/s}.$$

3 通道可并行传输，因此总带宽约为

$$3\times10.66\approx31.98\text{ GB/s}\approx32\text{ GB/s}.$$

## 选项判断

$$\boxed{B}.$$

## Verification

A 恰好是单通道结果；三通道题若仍选 A，说明漏掉了通道并行这一层。

## Compression

```text
1333 MT/s × 8 B × 3 channels
≈ 32 GB/s
```

## 易错边界

DDR 标称 1333 在这里应按有效传输率使用，不要再额外乘 2，否则会重复计算双沿传输。
