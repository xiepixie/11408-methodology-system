# 408-2019-Q02

## Model Anchor

- Topic：树与左孩子-右兄弟二叉树的遍历对应。
- 题目信号：问的是“树 T 的后根遍历”映射到对应二叉树 BT 的哪种遍历。
- 第一动作：回到表示契约：`left = first child`，`right = next sibling`，再比较递归访问顺序。

## 解题链

树的后根遍历对一个结点的顺序是：

```text
先依次遍历所有孩子子树
-> 最后访问当前结点
```

在左孩子-右兄弟表示中：

- 左子树承载当前结点的第一个孩子及其兄弟链；
- 右子树承载当前结点的后继兄弟。

对二叉树做中序遍历 `left -> root -> right`，恰好先完整处理当前树的孩子，再访问当前根，随后转向兄弟树，因此与树的后根遍历序列一致。

## 选项判断

故选

$$\boxed{B}.$$

## Verification

取根 r 有两个孩子 a、b 的最小例子：树后根为 `a,b,r`；转换后二叉树中 r.left=a、a.right=b，中序同样得到 `a,b,r`。

## Compression

```text
child-sibling representation
+ tree postorder
-> binary inorder
```

## 易错边界

不要把“树的后根”机械对应“二叉树后序”；遍历对应关系由表示方式决定，而不是名称决定。
