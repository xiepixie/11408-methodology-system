# 408-2019-Q16

## Model Anchor

- Topic：时钟周期与指令吞吐的层次边界。
- 题目信号：D 把“时钟沿”直接等同于“开始一条新指令”。
- 第一动作：区分 clock、micro-operation、instruction latency、instruction throughput 四个对象。

## 解题链

A、B、C 都是在描述时钟的来源与周期约束：同步处理器用时钟沿锁存状态，周期必须不短于相邻状态元件之间组合逻辑的关键路径延迟。

但“每来一个时钟脉冲就开始执行一条新指令”并不普遍成立：

- 多周期 CPU 一条指令占多个周期；
- 流水线遇到结构/数据/控制冒险会停顿；
- 某些周期可能只推进一条已在执行中的指令状态。

因此时钟脉冲不是“新指令启动事件”的同义词。

## 选项判断

$$\boxed{D}.$$

## Verification

只需拿多周期 CPU 作反例：若 load 需要若干周期，一个周期后显然不能保证又开始一条新指令。

## Compression

```text
clock edge -> state transition
not necessarily -> new instruction
```

## 易错边界

理想流水线稳态可接近“每周期发射一条”，但这是特定吞吐性质，不是所有处理器的时钟定义。
