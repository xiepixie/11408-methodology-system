# 408-2019-Q35

## Model Anchor

- Topic：滑动窗口序号空间约束。
- 题目信号：3 bit 序号空间、发送窗口 5，问接收窗口最大值。
- 第一动作：先写“旧分组与新分组不能在序号回绕后产生歧义”的窗口不变量。

## 解题链

3 bit 分组序号共有

$$2^3=8$$

个不同编号。

对一般选择重传式滑动窗口，为避免序号回绕后接收方无法区分旧分组和新分组，需要满足

$$W_s+W_r\le 2^k.$$

题中发送窗口

$$W_s=5,$$

因此

$$W_r\le8-5=3.$$

接收窗口最大为 3。

## 选项判断

$$\boxed{B}.$$

## Verification

若取 $W_r=4$，则 $W_s+W_r=9>8$，序号空间不足以把发送方仍可能保留的旧序号与下一轮新序号完全区分。

## Compression

```text
3-bit sequence space = 8
Ws + Wr <= 8
5 + Wr <= 8
-> Wr_max = 3
```

## 易错边界

若题目明确是 GBN，接收窗口通常固定为 1；本题只给一般滑动窗口参数，应按序号空间无歧义约束判断。
