# 408-2019-Q09

## Model Anchor

- Topic：KMP 失配后的模式状态回退。
- 题目信号：问“字符比较次数”，不能只看主串移动了多少位。
- 第一动作：先写模式 `abaabc` 的失败函数，再逐次记录 `(i,j)` 状态；主串指针不因模式回退而回退。

## 解题链

对模式串 `abaabc`，采用常见 0 下标 `next` 定义可得：

```text
S:     a  b  a  a  b  c
index: 0  1  2  3  4  5
next: -1  0  0  1  1  2
```

第一次从 T 开头匹配，前 5 个字符成功，在比较模式 `c` 与主串相应字符时发生失配，共进行了 6 次比较。

失配后主串位置不回退，模式状态由 `j=5` 回退到 `next[5]=2`。随后从模式第 2 位继续，经过 4 次比较完成匹配。

总比较次数为

$$6+4=10.$$

## 选项判断

$$\boxed{B}.$$

## Verification

KMP 的关键不变量是“已经由前缀/后缀信息证明过的主串字符不重新扫描”。若把主串指针也退回，会退化成朴素匹配并得到不同计数。

## Compression

```text
build next
-> mismatch: i stays, j falls
-> 6 + 4 comparisons
-> 10
```

## 易错边界

不同教材的 `next/nextval` 下标定义可能不同，但只要实际 `(i,j)` 状态转移一致，最终比较次数必须一致。
