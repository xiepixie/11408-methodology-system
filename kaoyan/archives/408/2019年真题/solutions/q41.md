# 408-2019-Q41

## Model Anchor

- Topic：单链表原地重排。
- 题目信号：目标序列是 `首、尾、次首、次尾...`，同时要求 $O(1)$ 额外空间和时间尽可能高效。
- 第一动作：不要反复“找尾结点”。先把目标结构拆成三个可线性完成的操作：**找中点 → 后半段逆置 → 两段交替合并**。

## Problem Representation

原链表：

```text
H -> a1 -> a2 -> ... -> ak -> a(k+1) -> ... -> an
```

目标并不是排序，而是重新定义 next：

```text
a1 -> an -> a2 -> a(n-1) -> a3 -> a(n-2) -> ...
```

如果每取一个尾结点都从头扫描，复杂度会退化到 $O(n^2)$。真正的瓶颈是“单链表不能向前走”，所以要先把后半段反转，让原来的尾部顺序变成可顺向扫描。

## Decision Points

1. **如何在 $O(n)$ 内找到分界？** 用快慢指针。
2. **如何在 $O(1)$ 空间得到 `an,a(n-1),...`？** 原地逆置后半段。
3. **如何合并且不丢链？** 每次同时保存两段的 next，再交替穿插。
4. 奇数长度时第一段多一个结点，最终自然留在尾部；偶数长度时两段等长。

## Solution Chain

### 1. 找到前半段末尾

设 `slow`、`fast` 均从首元结点出发，`fast` 每次走两步，`slow` 每次走一步。循环结束时，`slow` 位于前半段最后一个结点。

### 2. 断开并逆置后半段

令

```c
second = slow->next;
slow->next = NULL;
```

再对 `second` 做标准原地逆置，得到：

```text
an -> a(n-1) -> ...
```

### 3. 两段交替合并

```c
void Rearrange(NODE *head)
{
    if (head == NULL || head->next == NULL || head->next->next == NULL)
        return;

    NODE *slow = head->next;
    NODE *fast = head->next;

    // slow 停在前半段最后一个结点
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // 切分
    NODE *second = slow->next;
    slow->next = NULL;

    // 原地逆置后半段
    NODE *pre = NULL, *cur = second;
    while (cur != NULL) {
        NODE *next = cur->next;
        cur->next = pre;
        pre = cur;
        cur = next;
    }

    // 交替穿插
    NODE *p = head->next;
    NODE *q = pre;
    while (q != NULL) {
        NODE *pnext = p->next;
        NODE *qnext = q->next;

        p->next = q;
        q->next = pnext;

        p = pnext;
        q = qnext;
    }
}
```

以 $n=5$ 为例：

```text
原链: a1 a2 a3 | a4 a5
逆置: a1 a2 a3 | a5 a4
合并: a1 a5 a2 a4 a3
```

正是目标序列。

## Verification

### 不变量

合并第 $i$ 次后，前缀已经固定为：

```text
a1, an, a2, a(n-1), ..., ai, a(n-i+1)
```

并且 `p`、`q` 分别指向两段尚未使用的首结点，因此不会重复或遗漏结点。

### 复杂度

- 找中点：$O(n)$；
- 逆置：$O(n)$；
- 合并：$O(n)$。

总时间：

$$\boxed{O(n)}$$

额外空间只使用常数个指针：

$$\boxed{O(1)}.$$

## Compression

```text
首尾交替 + singly linked + O(1) space
-> 找中点
-> 后半段 reverse
-> 两链 zipper merge
-> O(n), O(1)
```

## 易错边界

- 不能用栈保存后半段，否则空间变成 $O(n)$。
- 不能每次从头找尾结点，否则时间变成 $O(n^2)$。
- 合并前必须先保存 `p->next` 和 `q->next`，否则改链后会丢失剩余结点。
