# 408-2019-Q37

## Model Anchor

- Topic：CIDR/VLSM 子网划分的容量分解。
- 题目信号：把一个 `/20` 网络“划分为 5 个子网”，问可能出现的最小子网可分配地址数。
- 第一动作：把整个地址块看成 4096 个地址的二叉切分树；5 个最终子网必须互不重叠并完整覆盖原块。

## 解题链

`/20` 网络共有

$$2^{32-20}=4096$$

个地址。

要恰好得到 5 个 CIDR 子网，可以逐次把一个块二分。为了让其中一个子网尽可能小，同时仍用 5 个叶块覆盖整个 `/20`，一种最不均匀的合法分解为：

```text
/21  -> 2048 addresses
/22  -> 1024
/23  -> 512
/24  -> 256
/24  -> 256
```

总和正好 4096。因此最小子网可以是 `/24`，共有 256 个地址，可分配主机地址数为

$$256-2=254.$$

## 选项判断

$$\boxed{B}.$$

## Verification

若想让最小子网到 `/25`（128 地址），为了保持 CIDR 二叉切分，产生这个 `/25` 必然还会产生其同级兄弟块，继续追溯会使最终叶块数超过 5，无法在只保留 5 个子网时完整覆盖 `/20`。

## Compression

```text
/20 = 4096 addresses
5-leaf binary partition
-> /21 + /22 + /23 + /24 + /24
-> min /24 = 254 usable
```

## 易错边界

“最小子网”不是随便从原网里截一个很小块；所有子网必须是合法 CIDR 块，并共同构成一次完整划分。
