# 408-2019-Q03

## Model Anchor

- Topic：哈夫曼树的结构不变量。
- 题目信号：给“符号数 n”和“哈夫曼树总结点数”。
- 第一动作：先识别哈夫曼树是严格二叉树：每个内部结点恰有两个孩子。

## 解题链

若有 $n$ 个待编码符号，则哈夫曼树有 $n$ 个叶结点。严格二叉树满足

$$n_0=n_2+1,$$

所以内部结点数为 $n-1$，总结点数为

$$n+(n-1)=2n-1.$$

题给

$$2n-1=115,$$

故

$$n=58.$$

## 选项判断

$$\boxed{C}.$$

## Verification

每进行一次“取两个最小权结点并合并”，叶结点数不变而新增一个内部结点；从 n 棵树合并成 1 棵恰做 n-1 次，也得到总结点数 $2n-1$。

## Compression

```text
Huffman tree = full binary tree
leaves=n, internal=n-1
-> total=2n-1
```

## 易错边界

这个结论依赖二叉哈夫曼树；若是 k 叉哈夫曼编码，内部结点关系需要重新推导。
