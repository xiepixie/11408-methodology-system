# 408-2019-Q21

## Model Anchor

- Topic：中断驱动 I/O 的 CPU 时间占用。
- 题目信号：给设备吞吐率、缓冲寄存器宽度、每次中断周期数和 CPU 主频。
- 第一动作：先算“每秒产生多少次中断”，再乘每次中断占用 CPU 的时间。

## 解题链

缓冲寄存器为 32 bit=4 B。设备速率 50 KB/s，按题目常用口径约为 50,000 B/s，因此每秒中断次数最多约为

$$\frac{50000}{4}=12500\text{ 次/s}.$$

每次中断开销 1000 个周期，CPU 主频 1 GHz：

$$t_{int}=\frac{1000}{10^9}=1\ \mu s.$$

所以每秒用于该设备 I/O 的 CPU 时间为

$$12500\times1\ \mu s=0.0125\text{ s},$$

占比

$$\frac{0.0125}{1}=1.25\%.$$

## 选项判断

$$\boxed{A}.$$

## Verification

量纲链闭合：`B/s ÷ B/interrupt = interrupt/s`，再乘 `s/interrupt` 得到 CPU 时间占比。

## Compression

```text
50 KB/s ÷ 4 B = 12.5k interrupts/s
1000 cycles @1GHz = 1 μs
-> 1.25%
```

## 易错边界

先明确“一次中断对应多少数据”。如果设备接口能一次累计更大数据块再中断，中断频率会不同。
