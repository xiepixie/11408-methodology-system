# 408-2019-Q22

## Model Anchor

- Topic：DMA 生命周期与控制权交接。
- 题目信号：四项分别覆盖 `setup -> bus arbitration -> transfer -> completion`。
- 第一动作：按 DMA 生命周期逐阶段找 State Owner，而不是只记“DMA 不经过 CPU”。

## 解题链

DMA 传送的完整链条是：

1. **Setup**：CPU/设备驱动程序把主存地址、传送方向、长度等参数写入 DMA 控制器；I 正确。
2. **Arbitration**：真正访问主存前，DMA 控制器需要请求系统总线使用权；II 正确。
3. **Transfer**：获得总线后，DMA 控制器直接组织外设与主存之间的数据传输，不由 CPU 每字节搬运；III 正确。
4. **Completion**：整个数据块完成后，DMA 以中断通知 CPU，后续收尾由中断服务程序处理；IV 正确。

## 选项判断

四项均正确：

$$\boxed{D}.$$

## Verification

“DMA 不经过 CPU”只描述数据搬运阶段；初始化和结束通知仍需要 CPU 软件参与，这正好解释 I、IV 为什么也正确。

## Compression

```text
Driver setup
-> DMA requests bus
-> DMA transfers directly
-> interrupt on completion
```

## 易错边界

不要把 DMA 理解成“整个 I/O 生命周期完全没有 CPU”；它减少的是 bulk data movement 的 CPU 占用。
