# 408-2019-Q14

## Model Anchor

- Topic：缺页异常的精确恢复语义。
- 题目信号：四项里前三项描述“谁检测、谁处理、从哪里装页”，D 描述“处理后从哪里继续”。
- 第一动作：判断该异常是否要求**重新执行故障指令**。

## 解题链

缺页发生在指令执行过程中进行地址转换时：页表存在位表明目标页当前不在内存，CPU 产生缺页异常，操作系统缺页处理程序把所需页调入、更新页表后返回。

关键点是：发生缺页的那条指令尚未完成其语义。例如一条 load 因目标页不在内存而失败，装入页面以后必须重新执行这条 load，不能跳到下一条指令。

因此 D“回到发生缺页指令的下一条指令”错误。

## 选项判断

$$\boxed{D}.$$

## Verification

若直接执行下一条指令，原 load/store 的状态更新就永久丢失，程序语义被破坏；所以缺页异常必须具有 restartable fault 语义。

## Compression

```text
page not present during translation
-> fault
-> OS loads page + fixes PTE
-> restart faulting instruction
```

## 易错边界

异常返回点取决于异常类型；不能把缺页 fault 与普通 trap/系统调用“返回下一条”混为一谈。
