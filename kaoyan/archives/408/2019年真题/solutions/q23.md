# 408-2019-Q23

## Model Anchor

- Topic：用户级线程与内核级线程的 State Owner。
- 题目信号：判断“谁知道线程、谁维护 TCB、谁负责调度”。
- 第一动作：先问线程状态由用户线程库还是操作系统内核拥有。

## 解题链

- 内核级线程由内核感知并调度，A 正确。
- 用户级线程的线程控制块和调度状态由**用户态线程库**维护，内核往往只看到承载它们的进程/内核实体，因此“OS 为每个用户级线程建立 TCB”错误。
- 用户级线程切换通常不陷入内核，开销小于内核线程切换，C 正确。
- 用户级线程可完全由运行库实现，因此即使 OS 本身不支持内核级线程，也可以提供用户级多线程抽象，D 正确。

## 选项判断

$$\boxed{B}.$$

## Verification

若内核根本不知道某个用户级线程的存在，就不可能为它逐个建立内核 TCB；这是一条直接的 Ownership 校验。

## Compression

```text
ULT state owner = user thread library
KLT state owner = kernel
```

## 易错边界

“线程控制块”这个词要看属于哪一层；用户态线程库也可以有自己的 TCB-like 元数据，但不是由 OS 内核为每个 ULT 建立。
