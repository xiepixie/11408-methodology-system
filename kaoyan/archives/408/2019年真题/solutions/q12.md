# 408-2019-Q12

## Model Anchor

- Topic：冯·诺依曼结构的程序存储思想。
- 题目信号：问“错误的是”，四项分别对应 CPU、二进制编码、存储程序与访存方式。
- 第一动作：区分“指令如何取得”和“操作数可以如何取得”。

## 解题链

冯·诺依曼结构的核心包括：

- 程序由指令序列构成，由 CPU 逐条执行；
- 指令和数据都以二进制形式存放，存储器本身不靠“外观”区分两者；
- 程序执行前，指令和数据需装入存储器；
- 指令通常按 PC 给出的地址取得，而数据可以来自寄存器、立即数字段、主存地址等多种位置。

因此“数据都在指令中直接给出”把立即寻址当成了唯一数据来源，显然错误。

## 选项判断

$$\boxed{C}.$$

## Verification

只要存在一条 load 指令，数据就来自指令给出的地址所指向的存储单元，而不是“直接包含在指令中”，即可构成反例。

## Compression

```text
stored program
-> instruction and data both binary
-> instructions fetched by address
-> operands not necessarily immediate
```

## 易错边界

“形式上无差别”指存储表示，不等于 CPU 不区分当前比特串是指令还是数据；解释权来自执行阶段与控制状态。
