# 408-2019-Q34

## Model Anchor

- Topic：100BaseT 介质契约。
- 题目信号：标准名里 `T` 已经在提示物理介质。
- 第一动作：先解析以太网命名：`100` 表示 100 Mb/s，`Base` 表示基带，`T` 表示 twisted pair。

## 解题链

100BaseT 是快速以太网的双绞线系列标准，使用双绞线作为导向传输介质。

光纤相关快速以太网通常以 `FX` 等后缀标识；同轴电缆是更早期以太网标准中的典型介质。

## 选项判断

$$\boxed{A}.$$

## Verification

直接从标准命名反推即可：`T = Twisted Pair`。

## Compression

```text
100BaseT
-> T = twisted pair
```

## 易错边界

不要把“100 Mbps 以太网可以通过某些光纤标准实现”偷换成“100BaseT 本身使用光纤”；标准后缀决定具体介质。
