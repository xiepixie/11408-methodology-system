# 408-2019-Q05

## Model Anchor

- Topic：AOE 网的事件最早/最迟时间与活动时差。
- 题目信号：求活动 d 的最早、最迟开始时间。
- 第一动作：活动 $(u,v)$ 的开始时间由起点事件控制：最早是 $ve(u)$，最迟是 $vl(v)-w(u,v)$。

## 解题链

由图中前驱约束，活动 d 开始前必须完成到其起点事件的所有前驱活动。正向取最长前驱路径，得到其起点事件最早发生时间为

$$ve=12.$$

整个工程的关键路径长度为 27。反向计算事件最迟发生时间，d 的终点事件最迟为 21；d 持续时间为 7，因此

$$l(d)=21-7=14.$$

故

$$e(d)=12,\qquad l(d)=14.$$

活动 d 有 2 个时间单位余量，不是关键活动。

## 选项判断

$$\boxed{C}.$$

## Verification

$d$ 若在 14 开始，7 个时间单位后恰在 21 到达终点事件，不会推迟 27 的总工期；若晚于 14，则必然影响后续关键约束。

## Compression

```text
activity (u,v,w)
earliest = ve(u)
latest   = vl(v)-w
-> 12,14
```

## 易错边界

AOE 中“事件时间”和“活动开始时间”不是同一个对象；活动的最迟开始时间不能直接拿起点事件的 $vl$。
