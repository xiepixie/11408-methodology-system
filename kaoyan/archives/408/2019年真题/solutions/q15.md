# 408-2019-Q15

## Model Anchor

- Topic：基址寻址、补码位移与大端字节布局。
- 题目信号：同时给 `FF12H` 补码形式地址、32 位基址和大端存储。
- 第一动作：严格分三层：`EA 计算 -> 操作数字节序 -> 找 LSB 地址`。

## 解题链

形式地址 `FF12H` 是 16 位补码：

$$\mathtt{FF12_H}=-238=-\mathtt{EE_H}.$$

基址寻址有效地址为

$$EA=\mathtt{F0000000_H}-\mathtt{EE_H}=\mathtt{EFFFFF12_H}.$$

操作数机器数为 `1234FF00H`。大端方式把最高有效字节放在低地址：

```text
EA+0 : 12H
EA+1 : 34H
EA+2 : FFH
EA+3 : 00H   <- LSB
```

所以 LSB 所在地址为

$$\mathtt{EFFFFF15_H}.$$

## 选项判断

$$\boxed{D}.$$

## Verification

先算地址再谈 endian：大小端只改变多字节对象各字节的地址次序，不改变有效地址本身。

## Compression

```text
FF12h signed = -EEh
EA = F0000000h - EEh = EFFFFF12h
big endian -> LSB at EA+3
-> EFFFFF15h
```

## 易错边界

不要把 `FF12H` 当无符号 65298；题目已明确“补码表示”，必须先符号扩展/解释。
