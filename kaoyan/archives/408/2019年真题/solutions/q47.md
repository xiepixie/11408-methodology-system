# 408-2019-Q47

## Model Anchor

- Topic：二层广播域、三层子网边界、接口寻址与 NAT。
- 题目信号：H1/H2 在 `192.168.1.0/26`，H3/H4 在 `192.168.1.64/26`，R 与内部设备之间还有 `192.168.1.252/30` 点到点网段。
- 第一动作：先按前缀把拓扑切成**三个不同三层 Scope**，再决定哪些位置必须是路由器、哪些位置只需交换机；设备类型不是看图标位置猜，而是看是否跨网络前缀。

## Problem Representation

三个内部三层网络：

```text
LAN-A: 192.168.1.0/26
  H1 = 192.168.1.2/26
  H2 = 192.168.1.3/26
  default gateway = 192.168.1.1

LAN-B: 192.168.1.64/26
  H3 = 192.168.1.66/26
  H4 = 192.168.1.67/26
  default gateway = 192.168.1.65

Transit: 192.168.1.252/30
  R side = 192.168.1.253/30
  other usable address = 192.168.1.254/30
```

交换机不能把两个不同 IP 子网变成一个三层网络；要同时承担 `LAN-A gateway`、`LAN-B gateway` 和 transit 端点，设备 1 必须具备路由功能。

## Decision Points

1. 无 VLAN 交换机只扩展同一广播域，不承担跨子网转发。
2. 路由器每个三层接口都必须属于其所连接的网络，并配置该网络中的合法主机地址。
3. `192.168.x.x` 是私有地址，访问 Internet 时需要在边界路由器 R 做地址转换。
4. `192.168.1.127` 对 `/26` 的 `192.168.1.64/26` 而言是定向广播地址，只在该子网广播；路由器隔离广播域。

## Solution Chain

### (1) 设备 1、2、3 的类型

H1/H2 的默认网关是 `192.168.1.1`；H3/H4 的默认网关是 `192.168.1.65`。这两个地址属于不同 `/26` 子网，因此承担这两个网关接口并连接到 R 的设备必须跨三层转发：

$$\boxed{\text{设备1：路由器}}.$$

设备 2 只连接 LAN-A 内主机，设备 3 只连接 LAN-B 内主机，不需要跨 IP 子网，因此：

$$\boxed{\text{设备2、设备3：以太网交换机}}.$$

### (2) 哪些接口配置 IP？如何配置？

二层交换机用于透明转发，以题目所需的数据转发功能而言不需要给各转发端口配置 IP。

设备 1 是路由器，其 3 个三层接口都必须配置地址。

#### IF1：与 R 相连

R 这一侧为：

```text
192.168.1.253/30
```

`/30` 网络为：

```text
network   192.168.1.252
host      192.168.1.253
host      192.168.1.254
broadcast 192.168.1.255
```

所以设备 1 的 IF1 应取另一可用主机地址：

$$\boxed{192.168.1.254/30}.$$

#### IF2：LAN-A 网关

H1/H2 已配置默认网关 `192.168.1.1`，故：

$$\boxed{IF2=192.168.1.1/26}.$$

#### IF3：LAN-B 网关

H3/H4 默认网关为 `192.168.1.65`，故：

$$\boxed{IF3=192.168.1.65/26}.$$

因此只有设备 1 的三层接口需要上述 IP 配置。

### (3) R 需要提供什么服务？

H1～H4 使用 `192.168.1.0/24` 范围内的私有地址，不能直接作为全球 Internet 路由中的公共源地址。

边界路由器 R 已拥有 Internet 一侧公共地址，因此需要提供：

$$\boxed{NAT\text{（网络地址转换）服务}}.$$

出站时把内部私有源地址转换为可在 Internet 使用的公共地址/端口映射，回包再依据 NAT 状态反向转换。

### (4) H3 向 `192.168.1.127` 发送数据报，谁会接收？

H3 为：

```text
192.168.1.66/26
```

`/26` 掩码把最后一个字节按 64 个地址为一块划分：

```text
192.168.1.64/26
host:      .65 ~ .126
broadcast: .127
```

所以 `192.168.1.127` 是 LAN-B 的广播地址。

设备 3 作为交换机会在 LAN-B 内转发该广播；设备 1 作为路由器不会把该二层/定向广播继续转发到 LAN-A。

因此除发送者 H3 自身外，网络中的目标主机只有：

$$\boxed{H4}.$$

H1、H2 位于 `192.168.1.0/26`，属于另一个广播域，不会收到。

## Verification

### Prefix 验证

```text
H1/H2: 192.168.1.0/26
H3/H4: 192.168.1.64/26
R-link: 192.168.1.252/30
```

三组前缀互不相同，因此设备 1 必须是路由器；若用无 VLAN 交换机无法同时充当这些三层网关。

### IF1 地址验证

`192.168.1.252/30` 只有 `.253`、`.254` 两个可用地址；R 已占 `.253`，所以设备 1 唯一可选 `.254`。

### 广播验证

对 `.66/26`：

$$66\ \&\ 192=64,$$

网络地址 `.64`；该 64 地址块最后一个地址就是 `.127`，故广播判断闭合。

## Compression

```text
prefix first:
LAN-A = .0/26
LAN-B = .64/26
Transit = .252/30

cross-subnet device -> router (device1)
within-subnet devices -> switches (2,3)

IF1=.254/30
IF2=.1/26
IF3=.65/26
private -> Internet -> NAT at R
.127 = broadcast of .64/26 -> H4 receives
```

## 易错边界

- “交换机能连接很多主机”不等于“能充当不同 IP 子网的默认网关”；二层连通与三层路由是不同责任。
- 交换机可能为了管理配置管理 IP，但这不是本题问的转发接口地址要求。
- `192.168.1.127` 不是整个 `192.168.1.0/24` 的广播地址；广播必须结合 H3 的 `/26` Scope 判断。
- NAT 的 State Owner 是边界设备 R，而不是内部设备 1；设备 1 负责内部子网间/到 transit 的路由。
