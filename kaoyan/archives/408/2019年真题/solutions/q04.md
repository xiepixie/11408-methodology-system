# 408-2019-Q04

## Model Anchor

- Topic：AVL 删除/插入后的结构唯一性。
- 题目信号：不是问“仍不仍平衡”，而是问删除 v 再插回后是否恢复**原结构**。
- 第一动作：区分 BST 关键字集合不变量与 AVL 旋转路径；相同关键字集合并不唯一决定 AVL 形态。

## 解题链

AVL 删除和插入都可能触发旋转。旋转保持二叉搜索树的中序关键字序列，却可能改变局部父子关系。因此“删掉再插回”并不是结构上的可逆操作。

- I：即使 v 是叶结点，删除后也可能触发祖先失衡并旋转；再插入 v 时旋转路径可能不同，所以 T1 与 T3 **可能不同**，I 正确。
- II：v 不是叶结点时，也存在删除、替换、再插入后恢复原结构的情形，因此“一定不同”过强，错误。
- III：同理，也不能保证一定相同，错误。

## 选项判断

只有 I 正确：

$$\boxed{A}.$$

## Verification

题图给出的反例/构造正好说明“删除与插入不是互逆变换”。逻辑上只需一个反例即可否定 II 或 III 这类绝对命题。

## Compression

```text
same key set ≠ same AVL shape
rotation path depends on update history
-> only “may differ” is safe
```

## 易错边界

遇到“必然相同/必然不同”，优先找最小反例；不要把 BST 的唯一查找顺序误当成 AVL 结构唯一性。
