# 408-2019-Q18

## Model Anchor

- Topic：流水线 RAW 数据冒险。
- 题目信号：四条指令给出寄存器读写集合，问哪对“不存在数据冒险”。
- 第一动作：先为每条指令写 `Read Set / Write Set`，再找前写后读交集。

## 解题链

四条指令的关键寄存器依赖为：

```text
I1: write s2; read s1,s0
I2: write s3; read t2
I3: write s2; read s2,s3
I4: write memory; read s2,t2
```

因此：

- I1 → I3：I1 写 `s2`，I3 读 `s2`，存在 RAW；
- I2 → I3：I2 写 `s3`，I3 读 `s3`，存在 RAW；
- I3 → I4：I3 写 `s2`，I4 作为 store 数据读取 `s2`，存在 RAW；
- I2 与 I4：I2 写 `s3`，I4 不读 `s3`；两者都读 `t2` 不构成数据冒险。

## 选项判断

$$\boxed{C}.$$

## Verification

“都访问同一个基址寄存器 t2”只是 read-read 共享，不会导致一条指令必须等待另一条生成值。

## Compression

```text
hazard -> previous Write ∩ later Read
I2 writes s3; I4 reads s2,t2
-> empty
```

## 易错边界

store 也会读取寄存器：既读基址，也读待写入内存的数据寄存器；不能把 store 当成“没有源操作数”。
