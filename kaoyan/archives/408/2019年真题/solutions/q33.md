# 408-2019-Q33

## Model Anchor

- Topic：OSI 分层功能定位。
- 题目信号：问“自下而上第 5 层”。
- 第一动作：先数层级，再匹配该层的责任边界。

## 解题链

OSI 七层自下而上为：

```text
1 Physical
2 Data Link
3 Network
4 Transport
5 Session
6 Presentation
7 Application
```

第 5 层是**会话层**，负责会话建立、管理与同步等会话控制功能。

A 差错控制更常由数据链路/传输层承担；B 路由选择属于网络层；D 数据表示转换属于表示层。

## 选项判断

$$\boxed{C}.$$

## Verification

层号是本题第一道 Gate：若先把第 5 层误认成传输层，后续功能判断全部会错。

## Compression

```text
OSI layer 5
-> Session
-> dialog/session management
```

## 易错边界

TCP/IP 模型没有与 OSI 会话层一一对应的独立层，不能把两套层次编号混用。
