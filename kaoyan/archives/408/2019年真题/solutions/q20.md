# 408-2019-Q20

## Model Anchor

- Topic：磁盘物理记录单位与格式化开销。
- 题目信号：四项里 C 把“最小读写单位”写成字节。
- 第一动作：区分接口按字节寻址的逻辑语义与磁盘实际 I/O 传输粒度。

## 解题链

磁盘经过格式化后，扇区除用户数据外还包含地址标识、同步、校验等控制信息，因此格式化容量小于原始非格式化容量。

磁盘 I/O 的最小物理读写单位是**扇区**（现代系统上层还常按块/簇组织），不是单个字节。即使文件接口允许读取某几个字节，底层仍需把包含这些字节的扇区/块读入。

## 选项判断

错误的是 C：

$$\boxed{C}.$$

## Verification

若磁盘真能以一个字节作为独立物理读写单位，就无需扇区结构、扇区地址和扇区校验，这与磁盘组织本身矛盾。

## Compression

```text
logical byte access ≠ physical disk transfer unit
minimum physical unit -> sector
```

## 易错边界

“按字节编址”常见于主存地址空间，不应迁移成“磁盘硬件每次只读一个字节”。
