# 408-2019-Q08

## Model Anchor

- Topic：开放定址散列表的失败查找成本。
- 题目信号：表长 11，但散列函数 `key mod 7`，失败 ASL 的起点只可能是 0～6。
- 第一动作：先构造最终表，再从每个**可能初始散列地址**向后探测到第一个真正空槽。

## 解题链

依次插入 87、40、30、6、11、22、98、20 后，线性探测形成连续占用区。失败查找从 $H(key)\in\{0,1,\ldots,6\}$ 出发，必须一直探测到第一个空位置才停止。

对应 7 个起点的失败查找长度分别为

$$9,8,7,6,5,4,3.$$

因此

$$ASL_{fail}=\frac{9+8+7+6+5+4+3}{7}=6.$$

## 选项判断

$$\boxed{C}.$$

## Verification

分母是 7 而不是表长 11，因为散列函数本身只会产生 0～6 这 7 个初始地址；这是本题最容易漏掉的 State Space 边界。

## Compression

```text
build table
-> failure ends at first EMPTY
-> only hash starts 0..6
-> average = 6
```

## 易错边界

开放定址失败 ASL 的停止条件是首个从未占用的空槽；若存在删除标记，则 DELETED 不能当作失败终点。
