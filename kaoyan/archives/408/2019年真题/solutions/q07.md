# 408-2019-Q07

## Model Anchor

- Topic：排序算法选择的 workload contract。
- 题目信号：问“除时空效率外还要考虑什么”。
- 第一动作：从算法适配条件看，而不是只背某个算法的复杂度表。

## 解题链

排序算法的实际选择至少受以下信息影响：

1. **数据规模**：小规模时简单算法的常数因子可能更优；大规模时渐进复杂度更重要。
2. **存储方式**：顺序表、链表、外存文件支持的操作成本不同，例如随机访问与结点移动代价不同。
3. **稳定性要求**：若记录还有次关键字或业务顺序，稳定性可能是硬约束。
4. **初始状态**：接近有序时插入排序等自适应算法明显受益。

因此 I～IV 都是有效决策变量。

## 选项判断

$$\boxed{D}.$$

## Verification

同一个“排序”母问题，在 n 很小、链式存储、要求稳定、近乎有序四种条件变化下，最佳算法可能不同，说明这些因素都不是装饰信息。

## Compression

```text
choose sort
-> size + representation + stability + initial order
```

## 易错边界

“时间/空间复杂度好”不等于“实际最合适”；算法选择首先是 workload 与表示的匹配问题。
