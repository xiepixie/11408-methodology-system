# 408-2019-Q06

## Model Anchor

- Topic：表达式 DAG 与公共子表达式共享。
- 题目信号：要求“至少”多少个顶点，且表达式中 `(x+y)` 重复出现。
- 第一动作：不要按表达式树逐次复制结点；DAG 的价值就是让相同子表达式共享同一结点。

## 解题链

表达式

$$(x+y)\times\frac{x+y}{x}$$

需要的不同对象只有：

```text
x
 y
 x+y
 (x+y)/x
 (x+y)*((x+y)/x)
```

即两个操作数结点 `x、y` 与三个运算结点 `+、/、*`。

其中两处 `(x+y)` 共享同一个 `+` 结点，不重复建立，因此最少顶点数为

$$2+3=5.$$

## 选项判断

$$\boxed{A}.$$

## Verification

若用普通表达式树，第二处 `(x+y)` 会再复制 `x、y、+`；而 DAG 允许多个父结点指向同一公共子表达式，这正是题目“至少”的压缩来源。

## Compression

```text
DAG -> merge identical subexpressions
{x,y,+,/,*}
-> 5 vertices
```

## 易错边界

只有语义相同、操作数也相同的子表达式才能共享；不能仅因运算符相同就合并结点。
