# 408-2019-Q36

## Model Anchor

- Topic：CSMA/CD 最小帧长与冲突检测时限。
- 题目信号：`100 Mbps + 128 B 最小帧长`，问单向传播时延上限。
- 第一动作：用“发送方必须在发完最短帧前收到最远冲突返回”写出 $T_{frame}\ge2\tau$。

## 解题链

最小帧发送时间为

$$T_{frame}=\frac{128\times8}{100\times10^6}
=10.24\ \mu s.$$

CSMA/CD 要求最坏情况下冲突从发送端传播到最远端再返回发送端，故

$$2\tau\le T_{frame}.$$

因此单向传播时延最大为

$$\tau_{max}=\frac{10.24}{2}=5.12\ \mu s.$$

## 选项判断

$$\boxed{B}.$$

## Verification

若单向时延超过 5.12 μs，发送端可能已经发完 128 B 帧才收到冲突返回，无法保证碰撞检测。

## Compression

```text
128B @100Mb/s = 10.24μs
CSMA/CD: frame_time >= 2τ
-> τ <= 5.12μs
```

## 易错边界

题目问单向传播时延，公式中却是往返传播 $2\tau$；最常见错误就是忘记除以 2。
