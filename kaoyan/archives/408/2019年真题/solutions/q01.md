# 408-2019-Q01

## Model Anchor

- Topic：循环终止条件与复杂度反推。
- 题目信号：循环条件直接比较 `(x+1)^2` 与 `n`。
- 第一动作：不要数语句层数，先求循环退出时 `x` 与 `n` 的数量级关系。

## 解题链

循环持续满足

$$n\ge (x+1)^2.$$

因此 `x` 从 0 逐次加 1，直到接近 $\sqrt n$。循环次数满足

$$x=\Theta(\sqrt n).$$

每轮只做常数次比较、乘法和加法，所以

$$T(n)=\Theta(n^{1/2}).$$

## 选项判断

故选

$$\boxed{B}.$$

## Verification

若 $n=10^4$，循环大约执行 100 次，而不是 $10^4$ 次或 $\log n$ 次，与 $\sqrt n$ 一致。

## Compression

```text
condition contains x^2
-> solve x^2 ≈ n
-> x ≈ √n
-> Θ(√n)
```

## 易错边界

看到 `while` 不能默认 $O(n)$；循环变量与问题规模之间若有平方、指数等关系，应先解终止不等式。
