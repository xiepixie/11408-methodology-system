# 408-2019-Q44

## Model Anchor

- Topic：磁盘几何、SSTF 调度与逻辑簇到物理地址转换。
- 题目信号：同时给柱面/磁道/扇区几何、文件系统簇大小和 SSTF。
- 第一动作：先建立统一单位链：`sector -> cluster -> track -> cylinder`，再做调度；不要直接拿“簇号差”当寻道距离。

## Problem Representation

磁盘几何：

```text
300 cylinders
10 tracks / cylinder
200 sectors / track
512 B / sector
2 sectors / cluster
```

因此：

```text
100 clusters / track
1000 clusters / cylinder
```

寻道成本由**柱面号差**决定，簇号只是文件系统层逻辑编号，必须先映射到柱面。

## Decision Points

1. 容量按物理扇区总数乘每扇区字节数计算。
2. SSTF 比较的是当前磁头与各请求**柱面**的距离。
3. 簇物理地址要逐层做商和余数分解。
4. “簇号 -> CHS”属于设备相关映射，应由设备驱动程序完成，而不是应用程序。

## Solution Chain

### (1) 磁盘容量

总扇区数：

$$300\times10\times200=600000.$$

总容量：

$$600000\times512
=307200000\text{ B}.$$

若按 $1\text{ KB}=1024\text{ B}$：

$$\boxed{300000\text{ KB}}$$

约为 $292.97\text{ MiB}$。

### (2) SSTF 访问顺序

每柱面有：

$$10\times\frac{200}{2}=1000$$

个簇。

所以各请求所在柱面为：

| 簇号 | 柱面号 |
|---:|---:|
| 100260 | 100 |
| 60005 | 60 |
| 101660 | 101 |
| 110560 | 110 |

初始磁头在柱面 85：

```text
|100-85| = 15
|60-85|  = 25
|101-85| = 16
|110-85| = 25
```

先访问 100260。

到柱面 100 后：

```text
to 101 = 1
to 110 = 10
to 60  = 40
```

再访问 101660；随后从 101 到 110 距离 9，小于到 60 的 41，因此访问 110560；最后 60005。

顺序为：

$$\boxed{100260\to101660\to110560\to60005}.$$

### (3) 第 100530 簇的物理地址

每柱面 1000 簇：

$$100530=100\times1000+530,$$

所以柱面号为

$$\boxed{100}.$$

每磁道 100 簇：

$$530=5\times100+30,$$

所以柱面内磁道号为

$$\boxed{5}.$$

每簇 2 个扇区，因此该簇的起始扇区位置为

$$30\times2=60.$$

按题目/标准答案采用 0 起始物理编号，其物理位置可写为：

$$\boxed{(柱面100,\ 磁道5,\ 扇区60)}.$$

将文件系统簇号转换为设备相关物理地址的工作由

$$\boxed{\text{设备驱动程序}}$$

完成。

## Verification

### 容量守恒

每柱面容量：

$$10\times200\times512=1024000\text{ B}.$$

乘 300 仍得 307200000 B，与总扇区法一致。

### 地址反算

```text
cylinder 100 -> 100000 clusters before it
track 5     -> +500 clusters
cluster offset 30 -> +30
```

得到 `100530`，物理地址分解闭合。

## Compression

```text
2 sectors/cluster
-> 100 clusters/track
-> 1000 clusters/cylinder

cluster -> cylinder for SSTF
100260(c100) -> 101660(c101) -> 110560(c110) -> 60005(c60)

100530 -> c100, track5, sector60
```

## 易错边界

- SSTF 依据磁头移动距离，不是簇号数值差。
- “簇”属于文件系统逻辑分配单位，“扇区/柱面/磁道”属于设备几何层；题目故意要求跨层转换。
- legacy 文件名把本题放在“计算机组成原理”，但 2019 真题实际将 Q43～Q44 作为操作系统综合题；本年度已按历史路由覆盖处理。
