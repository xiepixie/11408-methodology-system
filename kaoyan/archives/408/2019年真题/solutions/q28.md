# 408-2019-Q28

## Model Anchor

- Topic：共享段的全局对象与进程局部命名。
- 题目信号：P1、P2 共享同一段 S，问哪项错误。
- 第一动作：区分“同一个物理共享对象”与“每个进程如何给它编号/映射”。

## 解题链

共享段的本质是多个进程的虚拟地址空间映射到同一份共享内存对象：

- 物理内存只需保存一份 S，A 正确；
- 两个进程可以各自在自己的段表中用**不同段号**映射到同一共享段，段号属于进程局部地址空间命名，不要求一致；B 错误；
- 系统可以通过共享段表中的同一对象/表项维护 S 的物理位置、引用等信息，C 正确；
- 只有最后一个使用者也释放后，才可回收该共享段占用的物理内存，D 正确。

## 选项判断

$$\boxed{B}.$$

## Verification

类比共享库：两个进程完全可以把同一物理对象映射到不同虚拟地址；“共享对象相同”不意味着“局部虚拟命名相同”。

## Compression

```text
shared object = global
segment number = per-process local name
-> need not be equal
```

## 易错边界

共享的是段的内容/物理对象，不是强制共享每个进程的段表索引。
