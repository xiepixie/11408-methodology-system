# 408-2019-Q13

## Model Anchor

- Topic：相同位模式在有符号/无符号解释下的语义转换。
- 题目信号：`unsigned short 65535 -> short`，关键不是重新做算术，而是保留低 16 位后换解释合同。
- 第一动作：先写机器位模式，再按目标类型解释。

## 解题链

`unsigned short` 为 16 位时，65535 的位模式为

$$\mathtt{FFFF_H}.$$

赋给同宽 `short` 后，低 16 位位模式保持为 `FFFFH`。将它按 16 位补码解释：

$$\mathtt{FFFF_H}=-1.$$

## 选项判断

$$\boxed{A}.$$

## Verification

16 位补码的 -1 就是所有位全 1；不需要对 65535 再做一次普通十进制范围截断推理。

## Compression

```text
65535 unsigned short
-> FFFFh
-> reinterpret as 16-bit two's complement
-> -1
```

## 易错边界

“数值转换”和“位模式解释”要分开；同宽整型转换时最稳的做法是先锁住实际位模式。
