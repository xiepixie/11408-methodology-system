# q01_数据结构

## 📋 题目要求 (题面)

设 n 是描述问题规模的非负整数，下面程序片段的时间复杂度是（ ）。

```c
x = 2;
while (x < n / 2)
    x = 2 * x;
```

- **A.** $O(logn)$
- **B.** $O(n)$
- **C.** $O(nlog_{2}$
- **D.** $O(n_{2}$

---

## 💡 答案与深度解析

**【正确答案】**：`A`

**正确答案：A**
在程序中，执行频率最高的语句为 `x = x * 2`，设该语句总共执行了 T(n) 次，则
 $2T(n)+1$ ≤n/2
，故
 $T(n)=log_{2}$ (n/2)−1=log2n−2
，得
 $T(n)=O(log_{2}$ n)
。
