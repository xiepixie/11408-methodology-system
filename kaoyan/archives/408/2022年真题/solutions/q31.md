# 408-2022-Q31

## Model Anchor

- Topic：系统调用入口的硬件/软件职责边界。
- 题目信号：问哪些操作“由操作系统完成”。
- 第一动作：把 trap 硬件自动动作与进入内核后的软件现场保存/服务例程分开。

## 解题链

系统调用陷入时，CPU 硬件负责完成必要的控制转移，例如保存断点/程序状态并切换到内核态，因此 I、IV 属于硬件响应部分。

进入内核后，操作系统软件需要保存通用寄存器等现场，并执行相应系统调用服务程序，因此 II、III 由 OS 完成。

## 选项判断

$$\boxed{B}.$$

## Verification

若没有硬件先完成最小安全控制转移，用户程序无法自行执行“切到内核态”这种特权状态变化。

## Compression

```text
trap hardware: PC/PSW + mode switch
OS software: GPR context + syscall service
```

## 易错边界

具体架构自动保存哪些寄存器可能不同；408 稳定边界是“最小陷入控制状态由硬件，完整软件现场与服务逻辑由 OS”。
