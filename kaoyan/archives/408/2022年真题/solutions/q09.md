# 408-2022-Q09

## Model Anchor

- Topic：Hash 的平均查找长度与成本来源。
- 题目信号：问哪些因素影响 ASL。
- 第一动作：把查找成本拆成 `地址分布 -> 冲突频率 -> 冲突后的探测路径`。

## 解题链

- 装填因子决定表有多拥挤，直接影响冲突概率与探测长度；
- 散列函数决定关键字映射是否均匀；
- 冲突解决策略决定发生冲突后还需要比较/探测多少位置。

三者都会改变平均查找长度。

## 选项判断

I、II、III 全部正确：

$$\boxed{D}.$$

## Verification

即使装填因子相同，坏散列函数也可能把大量关键字聚到少数地址；即使函数相同，线性探查与链地址法的成本模型也不同。

## Compression

```text
Hash ASL
= load factor
+ hash distribution
+ collision resolution
```

## 易错边界

“平均 $O(1)$”并不表示 ASL 与这些参数无关；该结论本身就依赖合理装填和散列假设。
