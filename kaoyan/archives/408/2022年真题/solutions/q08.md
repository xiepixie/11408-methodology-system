# 408-2022-Q08

## Model Anchor

- Topic：5 阶 B 树删除与下溢修复。
- 题目信号：删除内部关键字 260，并问调整后根结点的“不可能”结果。
- 第一动作：先确定合法状态：5 阶 B 树非根结点关键字数至少 2、至多 4；内部关键字删除后用前驱/后继替代，再检查借位或合并。

## 解题链

删除 260 有两条主要修复路径：

1. 用前驱 110 替代 260。删除叶层的 110 后发生下溢，可向左兄弟借关键字，父结点中 90/85 随旋转调整，根可形成 `60,85,110,350`。
2. 用后继 280 替代 260。对应子结点下溢且无法借位时，可与相邻兄弟及父分隔关键字合并，根可形成 `60,90,350`；另一合法修复路径可得到 `60,90,280`。

因此 A、B、C 都有合法删除/修复路径作为见证，而 `60,90,110,350` 不能由该删除状态转移得到。

## 选项判断

$$\boxed{D}.$$

## Verification

本题不是“唯一结果”题；B 树删除在前驱/后继替换及左右借位选择上可能存在多种合法实现，所以要对每个候选问“是否存在一条合法修复路径”。

## Compression

```text
B-tree delete
-> predecessor/successor replacement
-> underflow?
-> borrow else merge
-> 用“存在合法路径”筛选候选
```

## 易错边界

不要把某一种教材实现产生的唯一结果误当成 B 树定义本身规定的唯一结果。
