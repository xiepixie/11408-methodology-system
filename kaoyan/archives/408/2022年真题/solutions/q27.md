# 408-2022-Q27

## Model Anchor

- Topic：CPU 特权级与指令权限。
- 题目信号：用户态/内核态能执行哪类指令。
- 第一动作：用集合关系判断：用户态权限是内核态权限的真子集。

## 解题链

用户态程序为了保护系统资源，不能直接执行特权指令，只能执行非特权指令；需要特权服务时通过系统调用/异常进入内核。

内核态不仅可以执行特权指令，也可以执行普通非特权指令，所以 B、D 中的“只能”都错误。

## 选项判断

$$\boxed{C}.$$

## Verification

若内核态只能执行特权指令，则内核连普通算术、访存等普通指令都无法完成，显然不成立。

## Compression

```text
user mode: non-privileged only
kernel mode: privileged + non-privileged
```

## 易错边界

特权级约束的是“哪些操作被允许”，不是给两类指令划出互斥的执行模式。
