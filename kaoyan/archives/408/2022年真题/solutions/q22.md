# 408-2022-Q22

## Model Anchor

- Topic：并行体系结构分类与硬件多线程。
- 题目信号：MIMD/SIMD、SMP、hardware multithreading 混合判断。
- 第一动作：分别判断“执行流数量”“地址空间关系”“单核还是多核”，不要把三条轴混成一种分类。

## 解题链

- 多核处理器可让多个核心执行不同指令流、处理不同数据，属于 MIMD，A 正确；
- 向量处理器对多个数据元素执行同一指令，属于 SIMD，B 正确；
- 硬件多线程可以在**一个处理器核心内部**实现，例如细粒度多线程或 SMT，并非只能用于多核处理器，C 错；
- SMP 的各处理器共享统一物理主存/单一物理地址空间，D 正确。

## 选项判断

$$\boxed{C}.$$

## Verification

“多线程”解决一个核心如何维护/切换多个硬件线程上下文；“多核”解决有多少独立核心，两者可以组合但不存在包含关系。

## Compression

```text
MIMD/SIMD = instruction/data streams
SMT = per-core thread contexts
SMP = shared physical memory
```

## 易错边界

不要把 SMT 等同于多核；一个核心也可以同时暴露多个硬件线程。
