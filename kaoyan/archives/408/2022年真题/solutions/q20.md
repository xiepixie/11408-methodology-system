# 408-2022-Q20

## Model Anchor

- Topic：高级语言到可执行文件的工具链。
- 题目信号：四个阶段排序。
- 第一动作：按中间产物追踪：源文本先展开宏/头文件，再变成汇编，再变成目标机器码，最后解析跨文件符号。

## 解题链

典型流程：

```text
source
-> preprocessing
-> compilation
-> assembly
-> linking
-> executable
```

预处理负责宏与头文件展开；编译把高级语言变成汇编/低级表示；汇编生成可重定位目标文件；链接解析外部符号并形成可执行文件。

## 选项判断

$$\boxed{A}.$$

## Verification

链接必须位于汇编之后，因为链接器处理的是目标文件/库中的符号与重定位信息，而不是高级语言源文本。

## Compression

```text
预处理 -> 编译 -> 汇编 -> 链接
```

## 易错边界

“编译”有时口语上泛指整个构建过程；本题使用的是阶段化工具链含义。
