# 408-2022-Q23

## Model Anchor

- Topic：多道程序系统的目标与资源竞争。
- 题目信号：判断哪些是多道程序系统的必要/必然特征。
- 第一动作：区分“引入多道程序后必须解决的问题”和“可能提升但不单调保证的性能结果”。

## 解题链

多道程序允许多个作业/进程在内存与 CPU/I/O 之间交错，因此支持并发，需要管理共享资源，A、C 正确。多道程序并不逻辑上要求虚拟存储；早期系统也可在无虚存条件下运行，B 正确。

进程数增加只在一定范围内可能提高 CPU 利用率；过多进程会增加切换、内存压力甚至引起抖动，所以“进程数越多 CPU 利用率越高”不是单调真命题。

## 选项判断

$$\boxed{D}.$$

## Verification

用极端反例：当进程数大到物理内存不足、持续缺页时，CPU 可能大量等待换页，利用率反而下降。

## Compression

```text
multiprogramming
-> concurrency + shared-resource management
≠ more processes always better
```

## 易错边界

性能指标通常存在饱和和反噬区间；绝对的“越多越高”优先找反例。
