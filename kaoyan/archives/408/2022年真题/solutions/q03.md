# 408-2022-Q03

## Model Anchor

- Topic：二叉树中序遍历的局部次序约束。
- 题目信号：`p,q` 在中序序列中相邻，且 `p` 在 `q` 前。
- 第一动作：把“相邻”翻译成：两者之间不能再夹入任何被中序访问的结点，再逐种亲属关系构造或否证。

## 解题链

中序次序是 `左子树 -> 根 -> 右子树`。

- I：`q` 是 `p` 的双亲可以发生，例如 `p` 是 `q` 左子树中最后访问的结点。
- II：`q` 是 `p` 的右孩子可以发生，只要 `q` 没有左子树，则访问 `p` 后立即访问 `q`。
- III：`q` 是 `p` 的右兄弟不可能直接相邻。若二者同父且 `p` 在左、`q` 在右，则中序必先访问左子树中的 `p`，再访问双亲，之后才进入右子树中的 `q`；双亲必夹在两者之间。
- IV：`q` 是 `p` 的祖父也可通过合适的左子树结构使二者相邻。

因此只有 III 不可能。

## 选项判断

$$\boxed{B}.$$

## Verification

对 III 做最小反证：兄弟结点若分属父结点左右两侧，中序访问序列中父结点必位于左子树与右子树之间，所以不可能相邻。

## Compression

```text
中序相邻
-> 两点之间不能出现任何结点
-> 兄弟跨父结点
-> parent 必夹在中间
```

## 易错边界

不能仅凭“祖先/后代”判断相邻与否；关键是中序访问时两者之间是否被强制插入其他结点。
