# 408-2022-Q35

## Model Anchor

- Topic：IPv4 前缀与按位与。
- 题目信号：IP + 子网掩码，求网络地址。
- 第一动作：只对发生切分的字节做按位与；前两字节全 1 可直接保留。

## 解题链

掩码

$$255.255.192.0=/18.$$

第三字节：

```text
72  = 01001000
192 = 11000000
AND = 01000000 = 64
```

第四字节清零，所以网络地址为

$$183.80.64.0.$$

## 选项判断

$$\boxed{B}.$$

## Verification

/18 的第三字节块大小为 $256-192=64$，72 落在区间 `[64,127]`，网络起点确为 64。

## Compression

```text
/18 -> third octet block size 64
72 -> [64,127]
network = 183.80.64.0
```

## 易错边界

网络地址不是简单把主机地址最后一个字节置 0；必须由前缀长度决定主机位从哪里开始。
