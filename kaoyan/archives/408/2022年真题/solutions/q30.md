# 408-2022-Q30

## Model Anchor

- Topic：缺页率的决定因素与页缓冲机制边界。
- 题目信号：区分“是否发生缺页”与“缺页后处理多快”。
- 第一动作：问每个因素是否改变进程驻留集/访问轨迹或 victim 选择，而不是只看它是否改善 I/O 性能。

## 解题链

页面置换算法会改变哪些页留在内存；工作集大小反映当前活跃页面需求；进程数量会影响可分配页框和内存压力，因此都可能改变缺页率。

页缓冲队列主要把被换出的页暂时保留在缓冲队列中，以便必要时更快回收/写回，改善缺页处理开销；按本题 408 模型，它不改变页面引用本身以及页面首次被判定“不在驻留集”的概率，因此不会改变缺页率。

## 选项判断

$$\boxed{D}.$$

## Verification

把“事件是否发生”和“事件发生后的代价”分开：页缓冲可降低某些重新调入的 I/O 成本，但不等于改变本题定义下的缺页事件计数。

## Compression

```text
page-fault rate -> residency / workload / replacement
page-buffer queue -> fault handling cost
```

## 易错边界

不同具体 OS 对 buffer/cache 的记账语义可能更复杂；本题按教材中的页面缓冲算法层次判断。
