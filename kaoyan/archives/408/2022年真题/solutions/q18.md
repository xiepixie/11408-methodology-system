# 408-2022-Q18

## Model Anchor

- Topic：ISA 与微体系结构边界。
- 题目信号：判断哪些内容属于“程序员可见的架构契约”。
- 第一动作：问“不同实现能否在保持同一机器代码语义的前提下改变它？”能改变的通常不是 ISA。

## 解题链

I. 指令格式和类型决定机器代码怎样解释，属于 ISA。  
II. CPU 时钟周期属于具体实现性能参数，不属于 ISA。  
III. 通用寄存器的个数和位数决定指令可见状态，属于 ISA。  
IV. 加法器采用哪种进位结构是微体系结构实现细节，不属于 ISA。

所以只有 I、III。

## 选项判断

$$\boxed{B}.$$

## Verification

同一 ISA 可以由不同主频、不同加法器、不同流水深度的 CPU 实现，但寄存器集合和机器指令格式必须保持软件兼容。

## Compression

```text
ISA = software-visible contract
format + registers ✓
clock + adder implementation ✗
```

## 易错边界

“硬件里存在”不等于“属于 ISA”；ISA 与微体系结构是两层。
