# 408-2022-Q21

## Model Anchor

- Topic：中断 I/O 的 producer/consumer 速率约束。
- 题目信号：判断中断方式下外设准备数据、CPU 服务和并发执行的关系。
- 第一动作：区分“设备准备下一数据”和“CPU 处理中断”的时间尺度。

## 解题链

中断 I/O 适合低速字符设备；设备就绪后 CPU 通过中断服务程序参与数据搬运，因此 A、B 正确。设备等待期间 CPU 可以运行其他进程，所以 D 正确。

若外设准备一个新数据所需时间**小于**一次中断处理时间，设备产生数据的速度会快于 CPU 服务速度，可能出现来不及处理的问题。因此题目给出的 C 不是中断 I/O 正常工作的合理要求。

## 选项判断

$$\boxed{C}.$$

## Verification

稳定服务要求长期服务能力至少跟得上到达速率；这里等价于中断处理时间不应超过设备连续产生数据的间隔。

## Compression

```text
interrupt I/O
-> device waits independently
-> CPU handles each event
-> service time must not exceed arrival interval
```

## 易错边界

不要把“设备越快越好”当成接口层结论；过快设备通常应使用 DMA 等批量搬运机制。
