# 408-2022-Q28

## Model Anchor

- Topic：进程状态与等待关系。
- 题目信号：哪些事件“可能”让 Running -> Blocked。
- 第一动作：逐项问：事件是否让进程失去继续运行所需的某个条件，并必须等待外部事件/资源。

## 解题链

I. 读文件若数据尚未就绪，可能等待 I/O，进入阻塞态。  
II. 时间片用完只是失去 CPU，仍具备运行条件，应进入就绪态。  
III. 申请外设若设备不可立即获得，可能等待资源，进入阻塞态。  
IV. `wait()` 若信号量不可满足，会把进程阻塞到等待队列。

因此 I、III、IV 都可能导致阻塞。

## 选项判断

$$\boxed{D}.$$

## Verification

Blocked 的核心不是“没有 CPU”，而是“即使给 CPU 也不能继续”；时间片耗尽不满足这一条件。

## Compression

```text
Running -> Blocked
iff waiting condition not satisfied
I/O / resource / semaphore may block
quantum expiry -> Ready
```

## 易错边界

题干写“可能”，因此读文件、申请外设不要求每次都阻塞，只需存在必须等待的合法情形。
