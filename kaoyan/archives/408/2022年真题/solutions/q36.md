# 408-2022-Q36

## Model Anchor

- Topic：主机接口配置、同网段判定与默认网关。
- 题目信号：图中 H=`192.168.1.60`，路由器接口=`192.168.1.62/27`，另有 `.1/30`。
- 第一动作：默认网关必须与 H 的接口处于同一 IP 子网，先逐候选掩码做 subnet-membership 检查。

## 解题链

若采用 `/27`，掩码为

$$255.255.255.224,$$

子网块大小 32。地址 `.60` 与 `.62` 都位于

$$192.168.1.32/27$$

的可用主机范围 `.33~.62` 中，因此 `.62` 可以直接作为 H 的默认网关。

`.1/30` 属于另一个链路子网，不能作为 H 的直连网关地址。

## 选项判断

$$\boxed{D}.$$

## Verification

$$60\ \&\ 224=32,\qquad 62\ \&\ 224=32,$$

两地址的网络号相同。

## Compression

```text
host .60
-> gateway must be on-link
-> .62/27 shares 192.168.1.32/27
-> /27 + .62
```

## 易错边界

“路由器上某个接口地址”不自动等于默认网关；必须是主机能在本链路直接解析并到达的接口。
