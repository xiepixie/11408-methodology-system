# 408-2022-Q10

## Model Anchor

- Topic：归并排序的核心操作契约。
- 题目信号：问“二路归并操作的功能”，不是问整个归并排序的递归过程。
- 第一动作：区分 `divide` 与 `merge` 两层职责。

## 解题链

二路归并的输入契约是两个已经有序的子表，操作通过比较两个当前首元素，逐步输出较小者，最终得到一个新的有序表。

B、C 描述的是排序过程中的划分/初始分段；D 更接近快速排序 partition 的性质。

## 选项判断

$$\boxed{A}.$$

## Verification

`merge([1,4],[2,3]) -> [1,2,3,4]`，其本质正是“两有序表合一有序表”。

## Compression

```text
Merge ≠ Divide
merge contract:
2 sorted runs -> 1 sorted run
```

## 易错边界

不要把算法名称中的“归并排序”整体过程和其中的 `merge` 原语混成一个定义。
