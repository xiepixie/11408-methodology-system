# 408-2022-Q29

## Model Anchor

- Topic：缺页异常生命周期。
- 题目信号：问 fault handler 中“不一定”发生的操作。
- 第一动作：把必需路径和“只有内存无空闲页框时才触发”的 replacement 分开。

## 解题链

页 b 不在内存，处理缺页至少要：

```text
为 b 获得页框
-> 从外存读入 b
-> 建立 VPN -> PFN 映射
-> 更新页表存在位
-> 重启导致异常的指令
```

如果当前已经有空闲页框，可以直接装入 b，不需要淘汰任何驻留页。只有没有可用页框时才需要 victim selection/replacement。

## 选项判断

不一定发生的是

$$\boxed{A}.$$

## Verification

构造反例：系统有一个空闲页框。此时缺页仍发生，但整个处理过程无需淘汰页。

## Compression

```text
page fault
-> load page + install mapping + valid bit
replacement only if no free frame
```

## 易错边界

缺页异常不等于页面置换；`fault`、`frame allocation`、`victim replacement` 是三个不同决策层。
