# 408-2022-Q38

## Model Anchor

- Topic：TCP 超时后的拥塞窗口状态机。
- 题目信号：`cwnd=16 KB` 时 timeout，MSS=1 KB，问再次到 16 KB 的最少 RTT。
- 第一动作：先执行 timeout 状态转移：`ssthresh <- cwnd/2`，`cwnd <- 1 MSS`，再分慢开始和拥塞避免两段计数。

## 解题链

超时前：

$$cwnd=16\text{ MSS}.$$

超时后：

$$ssthresh=8\text{ MSS},\qquad cwnd=1\text{ MSS}.$$

慢开始：

```text
1 -> 2 -> 4 -> 8
```

需要 3 RTT。

达到阈值后进入拥塞避免，每 RTT 约增加 1 MSS：

```text
8 -> 9 -> ... -> 16
```

再需要 8 RTT。

总计

$$3+8=11\text{ RTT}.$$

## 选项判断

$$\boxed{C}.$$

## Verification

若错误地一直按指数增长，会得到 4 RTT，但这忽略了到达 `ssthresh=8 MSS` 后切换为线性增长。

## Compression

```text
timeout at 16
-> ssthresh=8, cwnd=1
-> SS: 1-2-4-8 = 3 RTT
-> CA: 8...16 = 8 RTT
-> 11 RTT
```

## 易错边界

这里按 408 经典 TCP Reno/Tahoe 超时口径；不要把三次重复 ACK 的恢复规则混进 timeout 分支。
