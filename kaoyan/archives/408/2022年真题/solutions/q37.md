# 408-2022-Q37

## Model Anchor

- Topic：SDN 控制平面与数据平面接口。
- 题目信号：控制器向交换机下发流表。
- 第一动作：先判断通信双方所处层次：控制器到数据平面设备属于 southbound。

## 解题链

SDN 中，北向接口连接控制器与上层网络应用；南向接口连接控制器与数据平面交换设备。题目描述的是控制器向交换机安装流表，因此对应南向接口。

## 选项判断

$$\boxed{B}.$$

## Verification

只要把方向画成 `Application -> Controller -> Switch`，本题发生在后半段。

## Compression

```text
Controller -> Data Plane
= Southbound
```

## 易错边界

东向/西向通常描述控制器或控制域之间的协同，不是本题链路。
