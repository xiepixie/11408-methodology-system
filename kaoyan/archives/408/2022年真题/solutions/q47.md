# 408-2022-Q47

## Model Anchor

- Topic：二层设备边界 + CSMA/CD 时延预算 + DHCP 广播 + 802.11 三地址语义。
- 题目信号：同一题连续切换“广播域/冲突域”“最小帧长”“DHCP 广播”“AP 下行帧地址”。
- 第一动作：每一问重新确认 Scope 和 State Owner；不要用一个“都是局域网”模型贯穿四问。

## Problem Representation

从题图提取关键身份：

```text
R.E0: 192.168.0.1/25
DHCP: 192.168.0.2/25
AP MAC: 00-11-11-11-11-C1
H4 MAC: 00-11-11-11-11-D1
H5 MAC: 00-11-11-11-11-E1
```

题设关系：

```text
H1,H2: same broadcast domain, different collision domains
H2,H3: same collision domain
```

这两条关系已经足够反推设备类型。

## Decision Points

1. Switch 不隔离广播域，但每个端口隔离冲突域；Hub 既不隔离广播域，也不隔离冲突域。
2. CSMA/CD 最远距离由“最小帧发送时间必须覆盖最坏往返传播/设备时延”约束。
3. DHCP 客户端尚无地址时第一步是广播 DISCOVER；二层广播由交换机泛洪，但路由器不会把该二层广播继续转发到其他广播域。
4. 802.11 三地址字段不能按 Ethernet `src/dst` 顺序硬套；要先判断 `To DS / From DS` 方向。

## Solution Chain

### (1) 设备 1、设备 2

H1 与 H2：同广播域、不同冲突域。

这正是二层交换机的典型作用：

```text
same broadcast domain
+ per-port collision isolation
```

所以设备 1 为

$$\boxed{100BaseT\text{ 以太网交换机}}.$$

H2 与 H3 必须处于同一冲突域，因此中间设备不能隔离冲突，只能选择物理层 Hub：

$$\boxed{\text{设备 2 为 100BaseT Hub}}.$$

### (2) H2 与 H3 的最远距离

100BaseT 速率：

$$R=100\text{ Mbps}.$$

以太网最小帧长 64 B，发送时间为

$$
T_{frame}
=\frac{64\times8}{100\times10^6}
=5.12\ \mu s.
$$

为了让最远端碰撞仍能在发送最小帧期间返回发送端，必须满足

$$2T_{oneway}\le5.12\ \mu s.$$

一程包含物理传播和设备 2 的额外延迟：

$$T_{oneway}=\frac{D}{2\times10^8}+1.51\ \mu s.$$

取极限等号：

$$
2\left(\frac{D}{2\times10^8}+1.51\ \mu s\right)=5.12\ \mu s.
$$

于是

$$\frac{D}{2\times10^8}=1.05\ \mu s,$$

$$\boxed{D=210\text{ m}}.$$

### (3) DHCP

H4 尚未获得 IP 配置时首先发送：

$$\boxed{DHCPDISCOVER}.$$

该报文以二层广播承载，因此与 H4 同一广播域中的交换设备会进行泛洪。路由器 E0 接口连接在该广播域上，所以

$$\boxed{E0\text{ 能收到该以太网广播帧}}.$$

S 向 DHCP 服务器所在端口转发时，帧仍然是广播帧，目的 MAC 为

$$\boxed{\texttt{FF-FF-FF-FF-FF-FF}}.$$

注意：E0“收到”广播帧不等于路由器会把该二层广播继续路由到别的广播域。

### (4) H4 → H5 时 H5 收到的 802.11 帧地址

该帧由 AP 发往无线终端 H5，属于从分布系统到无线站点的下行方向：

```text
From DS = 1
To DS   = 0
```

此时三地址语义为：

```text
Address 1 = Receiver / Destination = H5
Address 2 = Transmitter / BSSID    = AP
Address 3 = Original Source        = H4
```

代入题图 MAC：

$$\boxed{Addr1=\texttt{00-11-11-11-11-E1}}$$

$$\boxed{Addr2=\texttt{00-11-11-11-11-C1}}$$

$$\boxed{Addr3=\texttt{00-11-11-11-11-D1}}$$

## Verification

### 设备边界验证

- switch：隔离 collision domain、不隔离 broadcast domain；
- hub：二者都不隔离。

恰好同时满足题设两组关系。

### CSMA/CD 单位验证

$$1.05\ \mu s\times2\times10^8\text{ m/s}=210\text{ m}.$$

往返：

$$2(1.05+1.51)=5.12\ \mu s,$$

正好等于最小帧发送时间。

### 802.11 身份验证

H5 是无线接收者，所以 Address 1 必须是 H5；真正发射无线帧的是 AP，所以 Address 2 必须是 AP；原始发送主机 H4 保留在 Address 3。三个字段角色互不混淆。

## Compression

```text
collision/broadcast domains -> switch vs hub
64B @100M -> 5.12us round-trip budget -> 210m
DHCP first -> DISCOVER broadcast -> FF:FF:FF:FF:FF:FF
AP downlink (FromDS=1):
A1=H5, A2=AP/BSSID, A3=H4
```

## 易错边界

- 交换机不会隔离广播域；路由器才定义三层广播域边界。
- CSMA/CD 约束的是**往返**碰撞传播时间，设备延迟也必须按往返经过次数计入。
- DHCPDISCOVER 的广播帧可以被 E0 接口接收，但普通路由器不会透明转发该二层广播。
- 802.11 的 Address 1/2/3 角色随 `To DS / From DS` 改变，不能固定记成“目的/源/AP”的唯一顺序。
