# 408-2022-Q41

## Model Anchor

- Topic：顺序存储二叉树上的 BST 判定。
- 题目信号：数组中 `-1` 表示不存在结点，要求“尽可能高效”判断是否为二叉搜索树。
- 第一动作：不要为每个结点反复扫描整棵左右子树；把 BST 的全局区间约束压缩成一个可在线验证的不变量：**中序遍历序列严格递增**。

## Problem Representation

顺序存储关系：

```text
node i
left  = 2*i + 1
right = 2*i + 2
```

合法结点满足：

```text
i < ElemNum
SqBiTNode[i] != -1
```

由于题设所有真实结点值均为正整数，可令 `prev=-1` 作为“尚未访问任何结点”的初值。

## Decision Points

1. 直接检查“父 > 左孩子、父 < 右孩子”不够，因为 BST 要约束**整个**左右子树。
2. 对每个结点求左右子树最大/最小会重复工作，最坏可退化到 $O(n^2)$。
3. 中序遍历时只需保存上一个真实结点值 `prev`；若当前值 `<= prev`，立即失败。

## Solution Chain

### 1. 设计思想

对 T 做中序遍历：

```text
left subtree
-> node
-> right subtree
```

若 T 是 BST，则得到的所有真实结点值必须严格递增。遍历时维护 `prev`：

- 当前索引越界或值为 `-1`：该子树为空，返回 true；
- 左子树不是 BST：立即返回 false；
- 当前值 `<= prev`：违反 BST 全序不变量，返回 false；
- 更新 `prev`，继续检查右子树。

### 2. C/C++ 实现

```cpp
bool inorderCheck(const SqBiTree &T, int k, Elemtype &prev) {
    if (k >= T.ElemNum || T.SqBiTNode[k] == -1)
        return true;

    if (!inorderCheck(T, 2 * k + 1, prev))
        return false;

    Elemtype x = T.SqBiTNode[k];
    if (x <= prev)
        return false;
    prev = x;

    return inorderCheck(T, 2 * k + 2, prev);
}

bool isBST(const SqBiTree &T) {
    Elemtype prev = -1;       // 真实结点均为正整数
    return inorderCheck(T, 0, prev);
}
```

### 3. Complexity

每个有效数组位置最多检查一次：

$$T=O(\text{ElemNum}).$$

递归额外空间由树高决定：

$$S=O(h).$$

## Verification

题图 T1 的中序真实结点值严格递增，因此通过；T2 中存在中序次序下降，算法会在第一次违反 `current > prev` 时立即返回 false。

更关键的是，该方法验证的是全局约束。例如根为 10、左孩子 5、但左子树中出现 12 时，单纯父子比较可能漏掉，而中序序列一定出现逆序。

## Compression

```text
BST global invariant
-> inorder must be strictly increasing
-> traverse sequential-tree indices
-> skip -1
-> current <= prev => false
```

## 易错边界

- 必须先判断 `SqBiTNode[k]==-1` 再递归其孩子；不存在的结点不拥有合法子树。
- 若题目允许重复关键字，`<=` 是否违规要按其 BST 定义调整；本题按严格 BST 处理。
- Legacy 代码先递归孩子、后判断当前 `-1`，虽然对规范顺序存储数据未必出错，但没有把“空结点终止子树”的结构不变量放在正确位置。
