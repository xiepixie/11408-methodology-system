# 408-2022-Q39

## Model Anchor

- Topic：TCP 主动关闭时间线与 TIME_WAIT。
- 题目信号：C 主动发送 FIN，给 RTT 和 MSL，分别问 C/S 进入 CLOSED 的最短时间。
- 第一动作：画四次挥手单向传播时间，再把主动关闭方的 `2MSL` 单独叠在最后 ACK 发送之后。

## 解题链

RTT=50 ms，所以单向传播约 25 ms。最短情况下 S 收到 C 的 FIN 后可立即回 ACK 并发送自己的 FIN：

```text
0 ms   C -> S : FIN
25 ms  S 收到 FIN，发送 ACK/FIN
50 ms  C 收到 S 的 FIN，发送最后 ACK，进入 TIME_WAIT
75 ms  S 收到最后 ACK，进入 CLOSED
```

S 因此至少在 75 ms 进入 CLOSED。

C 从 50 ms 起还要等待

$$2MSL=1600\text{ ms},$$

故 C 进入 CLOSED 的时刻为

$$50+1600=1650\text{ ms}.$$

## 选项判断

$$\boxed{D}.$$

## Verification

主动关闭方承担 TIME_WAIT；被动关闭方在收到最终 ACK 后即可 CLOSED，这正好解释两个时间量级差异。

## Compression

```text
FIN timeline: 0 -> 25 -> 50 -> 75 ms
C: 50 + 2MSL = 1650 ms
S: 75 ms
```

## 易错边界

TIME_WAIT 从主动关闭方发送最后 ACK 后开始；不是从第一个 FIN 发出时开始直接加 $2MSL$。
