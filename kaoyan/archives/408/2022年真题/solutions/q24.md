# 408-2022-Q24

## Model Anchor

- Topic：系统初始化与持久化文件系统对象。
- 题目信号：问“操作系统初始化过程中创建”。
- 第一动作：区分运行期内核数据结构与磁盘上早已持久化的文件系统/分区元数据。

## 解题链

中断向量表是 CPU 响应中断时必须依赖的运行期入口映射，系统启动初始化时需要建立/装入。

根目录、索引节点表属于文件系统格式化后持久存在的磁盘结构；硬盘分区表也由分区操作写入磁盘，并非每次 OS 初始化重新创建。

## 选项判断

$$\boxed{A}.$$

## Verification

若每次开机都“创建”根目录、inode 表或分区表，原有文件系统内容会被重建/破坏，显然不符合持久化语义。

## Compression

```text
boot-time runtime structure -> interrupt vector table
persistent disk metadata -> not recreated each boot
```

## 易错边界

“读取/装载已有结构”不等于“创建该结构”。
