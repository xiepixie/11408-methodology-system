# 408-2022-Q45

## Model Anchor

- Topic：目录项、inode 身份、索引块层级与打开文件 I/O。
- 题目信号：目录项只含“文件名 + inode 号”，图中两个名字可指向同一 inode，后面又问 6 MB 文件需要哪级索引。
- 第一动作：固定对象链：`name edge -> inode identity -> index path -> data block`；同 inode 号意味着同一个文件对象，而不是“两个内容恰好相同的文件”。

## Problem Representation

```text
block size = 4 KB
inode size = 256 B
address entry = 4 B
10 direct
1 single indirect
1 double indirect
1 triple indirect
```

一个间接索引块可保存

$$\frac{4\text{ KB}}{4\text{ B}}=1024$$

个块号。

题图关键目录关系：

```text
stu:
  course -> inode 2
  doc    -> inode 10

course:
  course1 -> inode 10
  course2 -> inode 100
```

所以 `doc` 与 `course1` 是两个目录项/名字，但共同引用 inode 10。

## Decision Points

- 目录项内容只按题设字段回答，不擅自加入文件数据块号。
- inode 相同先判断“同一对象”，再由已有数据块信息反推 x。
- 计算读盘次数时先确认哪些层已经在内存；`course` 目录内容已在内存，所以不再读目录块。
- 大文件索引先算数据块数，再按 `direct -> single -> double -> triple` 容量逐层覆盖。

## Solution Chain

### (1) stu 中的目录项

stu 直接包含 `course` 和 `doc`，而目录项定义为“文件名 + inode 号”，故：

$$\boxed{\langle course,2\rangle,\quad \langle doc,10\rangle}.$$

题图未把 `.`、`..` 作为本问需要列出的目录项，因此按给出的目录结构回答这两个用户目录项。

### (2) doc 的磁盘块号 x

`doc` 和 `course1` 的 inode 号都为 10：

$$inode(doc)=inode(course1)=10.$$

它们实际引用同一个文件对象。题图给出 `course1` 的数据位于 30 号磁盘块，因此

$$\boxed{x=30}.$$

这正是硬链接的对象模型：多个目录项可以指向同一 inode。

### (3) 打开并读入 course1 需要几个磁盘块

`course` 目录内容已经在内存，所以可以直接从目录项得到

```text
course1 -> inode 10
```

无需再读 course 的目录块。

之后需要：

1. 读包含 inode 10 的 inode-table 磁盘块，取得其索引信息；
2. 根据 inode 中块号读 course1 的数据块 30。

因此需要

$$\boxed{2\text{ 个磁盘块}}.$$

### (4) course2 增长到 6 MB 时需要哪些间接级别

数据块数：

$$\frac{6\text{ MB}}{4\text{ KB}}=1536.$$

直接地址覆盖 10 块；一级间接覆盖 1024 块，因此

$$10+1024=1034<1536.$$

还剩

$$1536-1034=502$$

个数据块，需要通过二级间接寻址；而二级间接最大可覆盖 $1024^2$ 个数据块，已足够。

所以除了直接地址外，需要使用：

$$\boxed{\text{一级间接地址项和二级间接地址项}}.$$

不需要三级间接。

## Verification

### Identity 验证

两个目录项 inode 都为 10，所以块号不能各自独立；如果把 `doc` 的 x 填成不同块号，就破坏了 `directory entry -> inode -> file data` 的唯一对象链。

### Capacity 验证

$$10<1536<10+1024+1024^2,$$

故 single 不够、double 足够，结论闭合。

## Compression

```text
name -> inode -> blocks
same inode => same file object
course dir cached -> read inode block + data block = 2
6MB / 4KB = 1536 blocks
10 direct + 1024 single < 1536
-> need single + double
```

## 易错边界

- 目录项里的 inode 号不是数据块号。
- “两个文件名不同”不代表对应两个独立 inode；硬链接正是多名字共享 inode。
- 第 (3) 问只说目录内容在内存，没有说 inode 10 已缓存，因此仍需读 inode 所在磁盘块。
- 第 (4) 问问的是使用哪几级**间接地址项**；直接地址当然也会用于文件前 10 个数据块，但不属于“间接级别”。
