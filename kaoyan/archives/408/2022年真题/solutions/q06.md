# 408-2022-Q06

## Model Anchor

- Topic：无向图连通性的边数下界。
- 题目信号：只给 $|V|$、$|E|$ 的数量关系，判断“必然连通/不连通”。
- 第一动作：调用最小连通骨架：含 $n$ 个顶点的连通无向图至少需要 $n-1$ 条边。

## 解题链

若无向图连通，则必含一棵生成树，因此

$$|E|\ge |V|-1.$$

D 给出

$$|V|>|E|+1\iff |E|<|V|-1,$$

直接违反连通图的必要条件，所以一定不连通。

其余选项仅凭边较多或较少都不足以推出对应结论；边可以集中在一个连通分量中，仍留下孤立顶点。

## 选项判断

$$\boxed{D}.$$

## Verification

这是一个必要条件的逆否使用：`connected -> E >= V-1`，因此 `E < V-1 -> disconnected`。

## Compression

```text
无向图连通
-> 至少有 spanning tree
-> E >= V-1
-> E < V-1 必不连通
```

## 易错边界

$E\ge V-1$ 只是连通的必要条件，不是充分条件；边多也可能集中在局部。
