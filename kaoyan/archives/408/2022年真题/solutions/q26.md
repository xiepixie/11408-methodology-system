# 408-2022-Q26

## Model Anchor

- Topic：Banker 安全性检测。
- 题目信号：Allocation / Need / Available 已给，问安全序列个数。
- 第一动作：维护唯一状态量 `Work`；每一步只选择满足 `Need_i <= Work` 的未完成进程，完成后执行 `Work += Allocation_i`。

## 解题链

初始：

$$Work=(1,3,2).$$

由题表，只有 P0 的尚需资源

$$Need_0=(0,2,1)$$

满足 `Need0 <= Work`，所以安全序列第一项被迫是 P0。

P0 完成后释放已分配资源 $(2,0,1)$：

$$Work=(1,3,2)+(2,0,1)=(3,3,3).$$

此时 P1、P2 的 Need 都可满足，因此剩余两者顺序可以任意：

```text
P0 -> P1 -> P2
P0 -> P2 -> P1
```

共 2 个安全序列。

## 选项判断

$$\boxed{B}.$$

## Verification

第一步只有一个候选，第二步后有两个候选，故分支数恰为 $1\times2=2$。

## Compression

```text
Work=Available
-> 找 Need<=Work
-> finish 后 Work += Allocation
-> 数完整可行分支
```

## 易错边界

安全性算法假设进程获得剩余最大需求后能完成并释放**已占有的全部资源**；更新 Work 时加的是 Allocation，不是 Need。
