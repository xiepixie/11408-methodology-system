# 408-2022-Q44

## Model Anchor

- Topic：磁盘 CHS 地址、平均访问时间与周期挪用 DMA。
- 题目信号：几何参数、rpm、平均寻道时间、64 位 DMA 缓冲同时出现。
- 第一动作：把问题拆成三个不同成本对象：`address geometry`、`mechanical latency`、`bus transactions`，不要跨层混算。

## Problem Representation

磁盘：

```text
4 双面盘片 -> 8 个盘面/磁头
每盘面 20000 个磁道 -> 20000 个柱面
每磁道 500 个扇区
每扇区 512 B
转速 7200 rpm
平均寻道 5 ms
DMA 数据粒度 64 bit = 8 B
```

## Decision Points

- CHS 三字段计数按“可取多少不同值”求最小位数。
- 平均访问时间只由本题给出的 `寻道 + 平均旋转等待 + 扇区传输` 构成。
- 周期挪用 DMA 的一次总线请求搬 64 bit；CPU 与 DMA 同时需要主存时，要按 DMA 的实时性优先关系判断仲裁。

## Solution Chain

### (1) 地址信息字段及最小位数

三个字段是：

$$\boxed{\text{柱面号（磁道号）、磁头号（盘面号）、扇区号}}.$$

#### 柱面号

每盘面有 20000 个磁道，同一半径位置构成一个柱面，所以共有 20000 个柱面：

$$\lceil\log_2 20000\rceil=\boxed{15\text{ bit}}.$$

#### 磁头号

4 个双面盘片共有

$$4\times2=8$$

个盘面，因此：

$$\log_2 8=\boxed{3\text{ bit}}.$$

#### 扇区号

每磁道 500 个扇区：

$$\lceil\log_2 500\rceil=\boxed{9\text{ bit}}.$$

### (2) 一个扇区的平均访问时间

一转时间：

$$T_{rev}=\frac{60}{7200}\text{ s}=8.333\text{ ms}.$$

平均旋转等待约半圈：

$$T_{rot}=\frac{8.333}{2}=4.167\text{ ms}.$$

一个扇区的传输时间：

$$T_{trans}=\frac{8.333}{500}\approx0.0167\text{ ms}.$$

所以

$$
T_{avg}=5+4.167+0.0167
\approx\boxed{9.18\text{ ms}}.
$$

### (3) DMA 总线请求次数与总线使用权

一个扇区有

$$512\text{ B}.$$

DMA 数据缓冲区一次搬运 64 bit = 8 B，所以需要

$$\frac{512}{8}=\boxed{64\text{ 次总线请求}}.$$

若 CPU 在检测到 DMA 请求时也要访问主存，采用**周期挪用（cycle stealing）DMA** 时 DMA 控制器可以获得总线使用权，CPU 暂缓一个主存/总线周期。

原因是外设数据到达具有时间约束；DMA 若不能及时完成当前数据交换可能造成设备缓冲溢出或数据丢失，而 CPU 的一次主存访问通常可以延后。因此仲裁时 DMA 请求优先。

## Verification

- $2^{14}=16384<20000<32768=2^{15}$；
- $2^8=256<500<512=2^9$；
- $5+4.167$ 已接近 9.17 ms，单扇区传输仅约 0.017 ms，所以平均访问时间约 9.18 ms 的量级合理；
- $64\times8\text{ B}=512\text{ B}$，DMA 数据量守恒。

## Compression

```text
CHS: 20000 cylinders -> 15b; 8 heads -> 3b; 500 sectors -> 9b
average access = seek + 1/2 rotation + one-sector transfer
DMA requests = 512B / 8B = 64
cycle stealing -> DMA wins bus, CPU waits
```

## 易错边界

- 4 个双面盘片不是 4 个盘面，而是 8 个盘面。
- 平均旋转延迟是半圈，不是一整圈。
- DMA 的 64 位缓冲区决定一次搬运粒度，不是整个扇区只需一次总线请求。
- “DMA 优先”是周期挪用这一题设机制下的仲裁结论，不应推广成所有总线协议的无条件规则。
