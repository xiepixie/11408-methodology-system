# 408-2022-Q16

## Model Anchor

- Topic：组相联 Cache 地址拆分与并行比较。
- 题目信号：32 KB、64 B、8 路，问比较器数量与位数。
- 第一动作：先做 `Tag | Set | Offset` 三分，再用“每路一个 tag 比较器”。

## 解题链

块大小 64 B：

$$offset=\log_2 64=6\text{ bit}.$$

Cache 总块数：

$$32\text{ KB}/64\text{ B}=512.$$

8 路组相联，所以组数：

$$512/8=64=2^6,$$

组号 6 位。于是 Tag 位数：

$$32-6-6=20.$$

一次访问同一组的 8 路 tag 要并行比较，因此比较器数为 8，每个比较 20 位。

## 选项判断

$$\boxed{A}.$$

## Verification

`8 ways -> 8 comparators`，而不是“64 组 -> 64 个比较器”；比较器属于当前被索引组的并行路。

## Compression

```text
64B -> off 6
32KB/64B/8 = 64 sets -> index 6
Tag=32-6-6=20
8-way -> 8 comparators
```

## 易错边界

比较器数量由相联度决定，不由总组数决定。
