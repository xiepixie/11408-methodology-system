# 408-2022-Q11

## Model Anchor

- Topic：排序算法选择与 workload。
- 题目信号：问为什么“选择直接插入排序而不选快速排序”。
- 第一动作：从输入规模、已有序程度、空间、稳定性四个成本维度逐项比较，而不是只背平均复杂度。

## 解题链

I. 大部分元素已有序时，直接插入排序移动/比较次数会显著下降，接近线性；快速排序未必受益。  
II. 数据量很小时，插入排序常数小、实现简单。  
III. 直接插入排序只需常数辅助空间；递归快速排序通常需要递归栈。  
IV. 直接插入排序稳定，而经典快速排序不稳定。

因此四项都可能成为选择直接插入排序的理由。

## 选项判断

$$\boxed{D}.$$

## Verification

排序选择不是只比一个 $O(n\log n)$ 与 $O(n^2)$；当规模小、接近有序或需要稳定/原地时，成本向量会改变最优选择。

## Compression

```text
sort choice
-> input order
-> n
-> extra space
-> stability
```
