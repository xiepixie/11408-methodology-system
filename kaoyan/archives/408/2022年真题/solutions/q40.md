# 408-2022-Q40

## Model Anchor

- Topic：HTTP/1.1 持久连接 + TCP 慢开始时间线。
- 题目信号：已完成 DNS、HTML=1 MSS、图片=3 MSS、忽略发送时延。
- 第一动作：先画 TCP/HTTP 事件轴，再维护服务器端 `cwnd`；HTTP/1.1 复用同一 TCP 连接，不重复握手。

## 解题链

RTT=10 ms。

```text
0~10 ms   TCP 三次握手完成                     1 RTT
10~20 ms  H 请求 HTML，收到 1 MSS HTML         1 RTT
20~30 ms  H 请求图片；服务器可先发送 2 MSS      1 RTT
30~40 ms  ACK 推进窗口后发送剩余 1 MSS           1 RTT
```

解释第三步：HTML 的 1 MSS 已在同一连接上成功传输并被确认，使拥塞窗口可以增长；随后 3 MSS 图片仍至少需要两个发送批次。

因此总时间至少为

$$4RTT=40\text{ ms}.$$

## 选项判断

$$\boxed{B}.$$

## Verification

若把 HTTP/1.1 当成非持久连接，会错误地为图片再加一次 TCP 建连；若忽略 TCP 窗口，又会低估 3 MSS 图片的传输轮次。

## Compression

```text
1 RTT connect
+ 1 RTT HTML
+ 2 RTT image
= 40 ms
```

## 易错边界

“忽略 TCP 段传输时延”不等于忽略 RTT 和拥塞窗口反馈；传播/确认仍决定批次何时能继续。
