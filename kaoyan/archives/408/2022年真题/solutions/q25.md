# 408-2022-Q25

## Model Anchor

- Topic：抢占式优先级调度的事件时间线。
- 题目信号：到达时间、优先级、执行时间同时给出，问调度次数。
- 第一动作：固定规则“数值越小优先级越高”，只在到达/完成等决策事件上重算候选集。

## 解题链

时间线：

```text
0~10    P0
10~15   P2   (P1/P2 同到达，P2 优先级更高)
15~25   P3   (到达后抢占 P2)
25~40   P2   (P3 完成)
40~130  P0   (P2 完成，P0 比 P1 优先)
130~190 P1
```

发生调度决策的时刻为

$$0,10,15,25,40,130,$$

共 6 次。

## 选项判断

$$\boxed{C}.$$

## Verification

四个进程各首次获得 CPU 至少产生 4 次调度，另外 P2、P0 均有被抢占后再次被调度，共再增加 2 次，合计 6。

## Compression

```text
抢占式调度
-> Arrival/Finish 时间轴
-> 每个 decision point 选最高优先级 Ready
-> 数 dispatch 次数
```

## 易错边界

“调度次数”不是简单等于进程数，也不要把每个毫秒或每次状态变化都计为一次调度。
