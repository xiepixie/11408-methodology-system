# 408-2022-Q32

## Model Anchor

- Topic：设备驱动程序与 I/O 控制方式。
- 题目信号：问驱动程序的职责及其与硬件控制机制的关系。
- 第一动作：区分“设备无关层接口”与“驱动针对具体控制器/I/O 方式推进状态”的职责。

## 解题链

驱动程序需要了解具体设备控制器的寄存器、命令和 I/O 控制方式；查询、中断、DMA 的启动与完成路径不同，因此“驱动程序与 I/O 控制方式无关”错误。

初始化设备、发起读写、处理中断/等待等通常都由驱动层参与；进程执行设备 I/O 时若操作不能立即完成，也可能因等待设备而阻塞。因此 B、C、D 可成立。

## 选项判断

$$\boxed{A}.$$

## Verification

若驱动真的与 I/O 控制方式无关，那么从轮询改成 DMA 时无需改变任何设备控制逻辑，这与 DMA 需要配置地址、长度、方向并处理完成事件矛盾。

## Compression

```text
driver = device-specific control
poll / interrupt / DMA change its mechanism
```

## 易错边界

设备独立性主要是上层接口目标；不能反推底层驱动也与硬件机制无关。
