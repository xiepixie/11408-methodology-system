# 408-2022-Q33

## Model Anchor

- Topic：OSI 分层与流量控制 Scope。
- 题目信号：关键词“两个相邻结点间”。
- 第一动作：先定 Scope：一跳相邻结点属于数据链路层；端到端主机进程才进入传输层。

## 解题链

数据链路层负责在一条链路上相邻结点之间组织帧传输，并可实现链路级差错控制和流量控制。

传输层的流量控制面向端系统之间的端到端连接，不是“相邻结点”这一局部范围。

## 选项判断

$$\boxed{B}.$$

## Verification

题眼只要换成“端到端”，Owner 就可能切到传输层；“相邻结点”明确把问题限制在单链路。

## Compression

```text
adjacent nodes -> data link
end-to-end hosts -> transport
```

## 易错边界

同名机制“流量控制”会出现在不同层；先定 Scope 再判断 Owner。
