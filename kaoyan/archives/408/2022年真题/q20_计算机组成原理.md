# q20_计算机组成原理

## 📋 题目要求 (题面)

将高级语言源程序转换为可执行目标文件的主要过程是（ ）。

- **A.** 预处理 → 编译 → 汇编 → 链接
- **B.** 预处理 → 汇编 → 编译 → 链接
- **C.** 预处理 → 编译 → 链接 → 汇编
- **D.** 预处理 → 汇编 → 链接 → 编译

---

## 💡 答案与深度解析

**【正确答案】**：`A`

**正确答案：A**
将源程序转换为可执行目标文件的 过程分为预处理、编译、汇编、链接四个阶段
