# q09_线性代数

## 📋 题目要求 (题面)

设 $A$ 是 $m\times n$ 矩阵， $B$ 是 $n\times m$ 矩阵，则

- **A.** 当 $m>n$ 时，必有行列式 $|AB|\ne 0$ ．
- **B.** 当 $m>n$ 时，必有行列式 $|AB|=0$ ．
- **C.** 当 $n>m$ 时，必有行列式 $|AB|\ne 0$ ．
- **D.** 当 $n>m$ 时，必有行列式 $|AB|=0$ ．

---

## 💡 答案与深度解析

**【正确答案】**：`B`

**正确答案：B** **【解析】** 设A是m×n矩阵，B是n×m矩阵，则AB是m×m方阵。当m>n时，由于rank(A) ≤ n和rank(B) ≤ n，因此rank(AB) ≤ min(rank(A), rank(B)) ≤ n < m。这意味着AB的秩小于其阶数m，故AB是奇异矩阵，行列式|AB| = 0。因此选项B正确。当n>m时，rank(AB) ≤ m，但可能等于m，故|AB|可能不为零，也可能为零，因此选项C和D均错误。选项A与上述结论矛盾，故错误。
