## 三、数学解析与题图绘制标准

1. **LaTeX 数学公式语法标准**：
   - 集合与数列括号安全闭合（如 `$\{a_n\}$`、`$\{(x, y) \mid \dots\}$`）；
   - 分段函数与联立方程统一使用 `\begin{cases} \dots \end{cases}`；
   - 概率测度与条件统一使用 `$P\{ \dots \}$` 与 `\mid`；
   - 极限、双重求和与重音估计量（`\lim`, `\sum`, `\hat{\theta}`, `\bar{X}`）拓扑保真；
   - 填空题标准下划线统一采用 `\underline{\hspace{2.5em}}`，彻底消除 KaTeX Double Subscript 崩溃。
2. **TikZ 双主题解析几何图形**：
   - 所有真题题图由解析几何方程严格计算绘制，杜绝随意手绘；
   - 源码永久沉淀于各年份 `assets/src/*.tex`，并通过 `compile_tikz_to_svg.py` 编译为纯矢量 `path`，全平台零字体依赖。
