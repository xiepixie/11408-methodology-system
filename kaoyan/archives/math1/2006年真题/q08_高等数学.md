# q08_高等数学

## 📋 题目要求 (题面)

设 $f(x,y)$ 为连续函数，则 $\int _{0}^{\frac{\pi}{4}}d\theta \int _{0}^{1}f(r\cos \theta ,r\sin \theta )rdr$ 等于

- **A.** $\int _{0}^{\frac{\sqrt{2}}{2}}dx\int _{x}^{\sqrt{1-x^{2}}}f(x,y)dy$
- **B.** $\int _{0}^{\frac{\sqrt{2}}{2}}dx\int _{0}^{\sqrt{1-x^{2}}}f(x,y)dy$
- **C.** $\int _{0}^{\frac{\sqrt{2}}{2}}dy\int _{y}^{\sqrt{1-y^{2}}}f(x,y)dx$
- **D.** $\int _{0}^{\frac{\sqrt{2}}{2}}dy\int _{0}^{\sqrt{1-y^{2}}}f(x,y)dx$

---

## 💡 答案与深度解析

**【正确答案】**：`C`

**正确答案：C**

**【解析】** 给定的极坐标积分

$$
\int _{0}^{\frac{\pi}{4}}d\theta \int _{0}^{1}f(r\cos \theta ,r\sin \theta )rdr
$$

对应于区域 $D$，其中 $r$ 从 0 到 1， $\theta$ 从 0 到 $\frac{\pi}{4}$。

在直角坐标系中，该区域由以下条件定义：

$$
x^{2}+y^{2}\le 1,x\ge 0,y\ge 0,y\le x.
$$

为了将积分转换为先对 $x$ 积分再对 $y$ 积分的形式，考虑固定 $y$ 时 $x$ 的范围：

$x$ 从 $y$ 到 $\sqrt{1-y^{2}}$，$y$ 的范围从 0 到 $\frac{\sqrt{2}}{2}$ （因为当 $y>\frac{\sqrt{2}}{2}$ 时，不存在满足 $y\le x$ 且 $x^{2}+y^{2}\le 1$ 的点）。

因此，积分变为：

$$
\int _{0}^{\frac{\sqrt{2}}{2}}dy\int _{y}^{\sqrt{1-y^{2}}}f(x,y)dx,
$$

对应选项 **C**。

其他选项分析：

**选项 A**： $y$ 从 $x$ 到 $\sqrt{1-x^{2}}$，对应 $y\ge x$，与区域条件 $y\le x$ 相反。**选项 B**： $y$ 从 0 到 $\sqrt{1-x^{2}}$，覆盖 $\theta$ 从 0 到 $\frac{\pi}{2}$ 的部分区域，不满足 $y\le x$。**选项 D**： $x$ 从 0 到 $\sqrt{1-y^{2}}$，同样覆盖 $\theta$ 从 0 到 $\frac{\pi}{2}$ 的部分区域，未体现 $y\le x$ 的限制。

因此，只有选项 **C** 正确。
