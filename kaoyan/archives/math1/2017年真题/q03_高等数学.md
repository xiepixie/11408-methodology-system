# q03_高等数学

## 📋 题目要求 (题面)

函数 $f(x,y,z)=x^{2}y+z^{2}$ 在点 $(1,2,0)$ 处沿向量 $n=(1,2,2)$ 的方向导数为( )

- **A.** $12$
- **B.** $6$
- **C.** $4$
- **D.** $2$

---

## 💡 答案与深度解析

**【正确答案】**：`D`

**正确答案：D**

【解】 $\frac{\partial f}{\partial x}=2xy$， $\frac{\partial f}{\partial y}=x^{2}$， $\frac{\partial f}{\partial z}=2z$，

$\frac{\partial f}{\partial x} \mid _{(1,2,0)}=4$， $\frac{\partial f}{\partial y} \mid _{(1,2,0)}=1$， $\frac{\partial f}{\partial z} \mid _{(1,2,0)}=0$，

$\cos \alpha =\frac{1}{3}$， $\cos \beta =\frac{2}{3}$， $\cos \gamma =\frac{2}{3}$，

所求的方向导数为 $\frac{\partial f}{\partial n} \mid _{(1,2,0)}=4\times \frac{1}{3}+1\times \frac{2}{3}=2$，应选(D).

【答案】(D).
