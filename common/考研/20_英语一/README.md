# 英语一学科驾驶舱

## 学科母问题

英语一要求从句子结构、指代和篇章关系中恢复作者表达的意义，再用原文证据完成理解、判断和表达任务。

$$
\text{Sentence Structure} \to \text{Reference}
\to \text{Discourse Function} \to \text{Author Intent}
\to \text{Evidence} \to \text{Answer}
$$

## Question Control Adapter

1. 判断任务要求和答案形式；
2. 提取句子主干与修饰层级；
3. 还原代词和抽象名词的指代；
4. 判断句子和段落的篇章功能；
5. 区分作者观点、他人观点和事实材料；
6. 回到原文证据，对比选项或组织表达；
7. 检查偷换范围、无中生有、强加因果和态度强度。

该 Adapter 当前是框架性候选，仍需用真实做题表现校准。
