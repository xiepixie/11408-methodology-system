# 二次型：合同、惯性与正定

> 状态：待人工确认；已发布。Canonical LaTeX 第一版正文与 PDF 已建立，等待内容确认。

## 为什么值得读

二次型和线性算子都可能写成同一张矩阵 \(A\)，但研究对象已经变了：

- \(Ax\) 问“一个向量被送到哪里”；
- \(x^TAx\) 问“一个方向代入后得到多大的二次标量”。

因此二次型真正关心的是：**怎样换变量消掉交叉耦合，以及换坐标以后仍有多少正方向、负方向和零方向。**

## 母问题

> **怎样消除二次项之间的耦合，并识别不依赖坐标的正、负、零方向结构？**

主线是：

```text
二次表达式
-> 对称矩阵 A
-> 变量代换 x = Py
-> 合同 P^T A P
-> 去掉交叉项
-> 标准形
-> 规范形
-> 惯性 / 正定性
```

## 本册覆盖到哪里

本 Topic 负责：

- 二次型的唯一对称矩阵表示；
- 变量代换与合同；
- 配方法与一般合同标准形；
- 正交对角化与主轴；
- 标准形、规范形；
- Sylvester 惯性定理与合同完整分类；
- rank / determinant 在合同下的变化；
- 正定、负定、正半定与不定；
- Sylvester 正定/负定判据及 \(LDL^T\) 的生成解释；
- 半正定不能只检查顺序主子式的边界；
- Rayleigh quotient 只作为 Hessian / 曲率 Bridge 的结构接口。

本 Topic **不负责**：

- 一般线性算子的相似与谱分类；
- Hessian 的微积分构造与多元极值全过程。
