# 向量空间：生成、基与坐标

> 状态：待人工确认；已发布。Canonical LaTeX 第一版正文与 PDF 已建立，等待内容确认。

## 为什么值得读

“这组向量能生成整个空间”和“这组向量能唯一表示每个对象”不是一回事。

只要求生成，你可以不断加向量；但一旦出现冗余，同一个对象就会有多套系数表示。基的意义，就是同时解决两个问题：**不遗漏 + 不重复**。

## 母问题

> **怎样用最少的独立方向覆盖一个空间，并让空间中的每个对象都有唯一坐标？**

主线是：

```text
线性组合
-> span
-> 去掉冗余
-> 基
-> 维数
-> 唯一坐标
```

加入内积后，还会继续得到：

```text
任意无关基
-> 减掉已有方向上的投影
-> 正交基
-> 单位化
```

## 本册覆盖到哪里

本 Topic 负责：

- 线性组合、span、线性相关/无关；
- 极大线性无关组与向量组等价；
- 向量空间、子空间、基与维数；
- 坐标与换基；
- 内积、正交、投影；
- Gram-Schmidt 正交化与正交矩阵的基础性质。

本 Topic 不负责：

- 矩阵/线性映射 rank 的统一机制；
- kernel/image 的完整结构；
- 特征向量与对角化；
- 二次型主轴与惯性。

这些内容分别由 Topic03、Topic05、Topic06 接管。
