# 高等数学旧库迁移与重构规划

状态：架构与 Source Routing 已确认，正文待逐册重构。

## 1. 目标

将旧 `学习领域/归档/高等数学/` 从“教材章节 + 技巧 + 综合题”集合重构为当前认知系统中的稳定资产。

旧笔记只是 Source Corpus，不直接复制为 Canonical Handbook。

迁移目标不是：

$$
\text{Old File}_i\rightarrow\text{New File}_i
$$

而是：

$$
\boxed{
\text{Legacy Corpus}
\xrightarrow{\text{Diff + Split}}
\text{Topic / Internal Bridge / Cross-Subject Bridge / Integration / Rules / Extension}
}
$$

## 2. 强制路由顺序

迁移任何一段旧内容时依次问：

1. 它是在解释一个机制本身吗？→ Topic；
2. 它是在解释两个已有 Owner 为什么能接吗？→ Bridge；
3. 它是在一个完整问题里组合多个成熟模块吗？→ Integration；
4. 它是在告诉做题时看什么、第一步做什么、何时换路吗？→ Rules；
5. 它是真连接但明显超出数学一核心吗？→ Extension；
6. 它只是表面相似、容易诱发错误迁移吗？→ Anti-Bridge；
7. 都不是，或证据不足 → 暂不进入稳定资产。

同一机制只能有一个完整解释 Owner。

## 3. Ownership 层级

### 高数内部

- 12 个 Topic：见 [高等数学 Subject Atlas](README.md)；

### 上移到数学一 Cross-Subject Bridge

以下不再由高数内部重复拥有：

- Jacobian ↔ 行列式 → 数学一 B02；
- Hessian ↔ 二次型 → 数学一 B03；

## 5. 当前最重要的重复消除

迁移时必须主动消除以下旧重复：

1. 极限/连续/导数之间反复出现的“点态 vs 邻域”反例；
2. Topic03 的有限 Taylor 与 Topic11 的 Taylor series；
3. Topic07 的 Jacobian/Hessian 与 Topic08/线代中的 determinant/二次型；
4. Topic05 反常积分与 Topic10 级数判敛；
5. Topic09 四类积分各自重复参数化、定向和对称性规则；
6. 所有“机制说明”和“题目中怎样选机制”的混写。

解决方式不是删知识，而是决定唯一 Owner 后让其他位置 Use / Bridge。

## 6. Main Text / Appendix / Rules 边界

$$
\boxed{MainText=Understanding,\qquad Appendix=Coverage/Extension,\qquad Rules=Operational Control}
$$

旧稿中下列内容默认不抢占主干：

- Fréchet derivative 的一般抽象版本；
- Lebesgue/Tonelli/DCT；
- 完整 Hilbert space 理论；
- companion matrix / matrix exponential；
- 单位根筛选等明显超出数学一核心的工具。

只有它们能显著澄清核心机制时，正文保留最小解释；否则标 Extension 或暂不迁移。

## 7. 逐册工作流程

每处理一个 Topic：

1. 读取该 Topic 的所有 Source Pack，而不是只读同名旧文件；
2. 做 Handbook Diff：保留 / 冲突 / 重复 / 越界 / 缺失；
3. 先锁 Mother Problem 与 Ownership；
4. 按 `Problem → Naive Approach → Failure → Mechanism → Invariant → Cost` 重构正文；
5. 把跨 Owner 内容改成 Use / Bridge；
6. 把操作性技巧分流到 Rules；
7. 加最小反例、边界和独立 Verification；
8. 交用户审阅；
9. 用户确认后再晋升状态并同步依赖/Publication。

## 8. 建设顺序

默认：

`01 → 02 → 03 → 04 → 05 → H-B01~05 → 06 → 07 → 08 → 09 → 10 → 11 → 12 → H-I01 → Cross-Subject Bridges → Integration → Coverage/Rules/Publication`
