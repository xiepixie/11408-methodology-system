# H-B05｜有限 Taylor 模型与无限 Taylor 表示

状态：目录已建立，正文未建。

## Position

高数 Topic03 ↔ Topic11 的内部 Bridge。

## Mother Interface

研究有限阶 Taylor polynomial 作为局部近似，与 Taylor series 作为无限函数表示之间的责任边界：什么时候只是局部模型，什么时候余项能够趋零并恢复原函数。

## Owns

只拥有“finite local model → infinite representation”的升级条件和失败边界；有限阶 Taylor 归 Topic03，幂级数/Taylor series 归 Topic11。

## Uses

Topic03、Topic11。

## Boundary / Anti-Bridge

- 函数有任意阶导数不自动等于其 Taylor series；
- 形式写出 Taylor series 不等于已经证明和函数等于原函数；
- 局部误差控制与级数收敛域是不同问题。
