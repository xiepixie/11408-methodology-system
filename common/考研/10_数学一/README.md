# 数学一学科驾驶舱

## 学科母问题

数学一研究如何在定义和约束允许的范围内，选择合适表征与变换，把目标化为可计算、可证明、可校验的形式。

$$
\text{Object} \to \text{Constraint} \to \text{Structure}
\to \text{Representation} \to \text{Transformation}
\to \text{Invariant} \to \text{Target}
$$

## Question Control Adapter

1. 读目标和输出形式；
2. 扫定义域、非零性、范围和隐含约束；
3. 识别结构与候选表征；
4. 比较正推、逆推、换元、分类和特殊值路径；
5. 执行变换，同时保护等价性和不变量；
6. 用边界、特殊值、量级或回代校验；
7. 写出最小完整得分链。

该 Adapter 当前是框架性候选，仍需用真实做题表现校准。
