## 1. 审计结论

此前《408 协议流程覆盖矩阵》完成的是“旧笔记 / 统一总图 -> 八册 Topic”的 Source Migration 核销，不是“当年考纲 -> Canonical Owner”的逐项覆盖验收。因此“旧 Source 已迁完”不能推出“考纲已覆盖”。

当前优势集中在：性能计算、MAC 随机接入、ARQ、IPv4/转发、路由控制、TCP 状态、拥塞反馈和应用协议流程。

当前主要缺口集中在：网络概述与参考模型、物理介质/接口/设备、数据报与虚电路、纠错编码、轮询/令牌、广域网与 PPP 细节、IPv6 地址、IP 组播、路由器内部组成，以及若干协议首部/设备工作细节。

所以本轮结论是：

```text
Canonical Candidate 已有主干
!= 408 考纲逐项覆盖完成
!= 真题验证成熟
```

## 2. 覆盖等级

- **A｜可直接支撑**：正文有对象、机制、状态/公式、边界和题目调用方式。
- **B｜部分覆盖**：存在机制或一句定位，但不足以独立回答考纲细节题。
- **C｜缺失**：Canonical Topic 中没有可定位的稳定解释。
- **E｜边界扩展**：存在超出考纲的工程校正；不能抵消 Core 缺口。

## 4. 优先级与物理 Owner

### P0：先修复“整块缺失”

1. Subject Atlas Foundation：网络定义/分类、协议-接口-服务、OSI 与 TCP/IP 参考模型。
2. NET01：数据报/虚电路、传输介质、物理接口、repeater/hub、报文交换。
3. NET02：纠错编码、轮询/令牌、WAN、PPP 完整状态与帧模型。
4. NET04：IPv6 地址、IP multicast、Mobile IP Core、路由器设备模型的 Owner 路由。

### P1：补考试细节层

1. Ethernet / 802.3 帧字段和 802.11 基本体系结构。
2. UDP/TCP 首部字段、长度/checksum 与状态机的双向映射。
3. 静态路由、网络层拥塞控制分类、WWW 基本组成。

### P2：Bridge 重构

1. NET-B01 改为按 egress link type 分叉：Ethernet/WLAN 需要 next-hop link identity；PPP 点到点链路不应强制 `NextHopIP -> MAC`。
2. NET-B03 补通用 ARQ frame 序号到 TCP byte 序号、累计 ACK、失序缓存、timer/retransmission 的翻译表。
3. NET-B04 把 `min(rwnd,cwnd)` 扩为带 `FlightSize`、单位、zero-window 与拥塞事件的双反馈模型。
4. 评估 `BDP × Windowed Sending` 与 `MTU/PMTU × Transport Segmentation` 两个 Candidate Bridge；通过 Gate 后再建册。

RIP、OSPF、BGP、PPP 均为 Topic 内协议，不因细节多就各自升级 Bridge。Bridge 只拥有稳定交接，不复制协议正文。
