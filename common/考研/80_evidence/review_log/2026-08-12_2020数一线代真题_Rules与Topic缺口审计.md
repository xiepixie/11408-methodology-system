# 2020 数一线性代数真题 × Rules / Topic 缺口审计

> 日期：2026-08-12
>
> 性质：Evidence 层真题结构审计，不是新的知识 Owner。
>
> 目的：补齐 2021--2025 之前的一年，检查当前六册 Canonical Topic 是否能从对象与表示生成真实考试路径，而不是只覆盖近年题型。
>
> 公开题面核对：N诺考研 2020 数学（一）整卷页面 `https://noobdream.com/Practice/exam_solution/40900/`；新东方 2020 数学一试卷分析 `https://kaoyan.koolearn.com/20191222/1062943.html`。本记录只保留题目结构与系统反馈，不复制完整题面。

## 1. 初等列变换：No Canonical Update

真题表面：矩阵经初等列变换后，判断新旧矩阵之间的乘法关系以及齐次方程是否同解。

当前系统已经能够生成：

- Topic02：行变换 = 左乘可逆初等矩阵，列变换 = 右乘可逆初等矩阵；
- Topic04：行变换可以可逆重写约束并保持原未知量的解集，列变换会重编码输入变量，不能在不跟踪变量代换时声称原齐次系统同解。

因此题面中的关键不是记结论，而是先问“操作发生在输入端还是输出端”。

**结论：No Canonical Update。**

## 2. 空间直线相交 -> 线性表出：No Update

真题把三维直线的“基点 + 方向向量”表示与三个向量之间的线性表出关系连接起来。

交点属于两条直线，意味着同一个向量同时存在两种仿射表示；两式相等后即可整理成一个向量由另外两个向量线性表示。

当前 Topic01 已 Own 线性组合、span 与线性表出；高数空间解析几何只提供题面表示。删掉具体直线以后，并没有产生新的稳定跨科机制 Owner。

**结论：No Update。** 不建立“空间直线 -> 线性表示”独立 Bridge / Rule。

## 3. 结构化四阶 determinant：Rule Support

真题出现具有明显对称/稀疏结构的四阶参数行列式。

当前 R-LA01 的动作“先判结构，再决定计算表示”可以直接覆盖：先观察可制造的零、行列组合与块结构，再选择初等变换/展开；没有必要新建一种行列式题型。

**结论：Rule Support + No Canonical Update。** 这仍是外部题面证据，不代表使用者已经稳定调用 R-LA01。

## 4. 两个非对角实对称矩阵之间的正交变换：Canonical Update + Rule Revision

### 暴露的真实缺口

真题不是要求把一个二次型正交化为对角形，而是已知

\[
Q^TAQ=B,
\]

其中 $A,B$ 都是实对称矩阵，且目标 $B$ 本身仍含交叉项。

此前 Topic06 已说明：实对称矩阵同谱时可正交对角化到同一 $\Lambda$，因此正交相似；但没有把“如何从两套正交特征基直接构造目标 $Q$”写成完整机制。只对角化 $A$ 会停在 $\Lambda$，无法直接落到指定的 $B$。

### Canonical 补法

若按相同特征值顺序取

\[
U^TAU=\Lambda,
\qquad
V^TBV=\Lambda,
\]

则

\[
A=U\Lambda U^T,
\qquad
B=V\Lambda V^T,
\]

于是

\[
\boxed{Q=UV^T}
\]

满足

\[
Q^TQ=I,
\qquad
Q^TAQ=B.
\]

这个构造不是额外题型公式，而是“两个对象 -> 各自自然坐标 -> 公共谱坐标 -> 合成坐标变换”的直接结果。

Owner：

- Topic05 Use：提供实对称谱定理、标准正交特征基；
- Topic06 Own：给定二次型变量变换方向下，解释并构造 $Q^TAQ=B$；
- R-LA18：补充考场调用入口，不重新拥有谱机制。

边界：一般矩阵同谱并不足以推出相似；这里能推出正交相似依赖“双方都实对称”。重特征值时特征子空间内部存在正交自由度，因此 $Q$ 通常不唯一。

**结论：Canonical Update + R-LA18 Revision。**

## 5. $P=(\alpha,A\alpha)$ 与向量多项式关系：No Update

真题给出 $P=(\alpha,A\alpha)$，并只在向量 $\alpha$ 上给出二次作用关系。关键动作是：

1. 由“$\alpha$ 不是特征向量”判断 $\alpha,A\alpha$ 线性无关，因此构成一组基；
2. 不把 $A^2\alpha+A\alpha-6\alpha=0$ 擅自升级成矩阵恒等式；
3. 直接计算 $AP$，把 $A\alpha$、$A^2\alpha$ 在基 $(\alpha,A\alpha)$ 下展开，从而读出 $P^{-1}AP$；
4. 再在这张二维表示矩阵上判断谱与可对角化。

当前 Topic05《抽象作用关系怎样变成一个可计算的表示矩阵？》与 R-LA12 已覆盖这条生成链。

**结论：No Update。** 该题反而验证“先读作用，再造表示矩阵”比把向量关系误写成全局矩阵多项式更稳定。

## 6. 本轮结论

2020 年五个线性代数表面中，四个都能由当前 Canonical 模型直接生成；唯一真实缺口是：

\[
\boxed{\text{两个已知实对称表示} -> \text{公共谱坐标} -> \text{直接合成正交变换}}
\]

因此本轮只做：

1. Topic06 增补“两套自然坐标合成 $Q$”的机制与母例；
2. R-LA18 增补 $Q^TAQ=B$ 且目标 $B$ 非对角时的第一动作与检查；
3. 不新增 Rule，不新增 Bridge，不把一次真题命中当成“已采用”证据。

下一步仍是让使用者本人在陌生题中无提示调用 R-LA18；若不能自然触发，再判断是 Rule 的识别成本过高，还是 Topic05 -> Topic06 的接口仍不够清楚。
