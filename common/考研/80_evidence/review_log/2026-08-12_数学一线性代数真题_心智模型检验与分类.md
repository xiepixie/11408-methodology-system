## 4. 六个 Topic 的对抗测试

### L01：向量空间、生成、基与坐标

真题把向量组包装成空间几何、矩阵列或参数族。稳定第一动作是：

先把向量列成矩阵或写成线性组合，找显式关系或解系数方程，再决定题目问的是 span、秩、坐标还是独立性。

覆盖证据：1987、1988、1992、1997、2003、2007、2009、2012、2014、2017、2019、2020、2022、2023、2024、2025。

边界攻击：向量列成矩阵后若问自由度或核，Owner 转到 L03；空间直线/平面只是向量的仿射表示；正交性只有在出现内积、投影、正交矩阵或二次型主轴时才进入对应接口。

结论：Rule Support / No Canonical Update。

### L02：映射、矩阵与行列式

结构行列式、伴随矩阵、初等变换、矩阵方程、逆矩阵和递推矩阵都可还原为“一般映射的表示”。第一动作是分清左乘、右乘和输入变量是否被重编码。

边界攻击：行变换保持原未知量的齐次解集，列变换通常改变输入坐标；结构行列式先制造结构再计算；伴随矩阵与特征值的交界必须先确认题目问的是映射关系还是谱信息。

结论：Rule Support / No Canonical Update。

### L03：秩、Kernel、Image 与等价

统一压缩为：先问输入方向经过映射后还剩多少独立输出，再用核/像/秩不等式锁定自由度，只有等号链成立时才升级为相等、可逆或同解。

覆盖证据：1992、1993、1996、1997、2004--2008、2010--2014、2017--2025。2025 的 r(A)+r(B)+r(C)=r(ABC)+2n 是等号链代表，不是新公式题型。

主要禁忌：一个秩结论不能越权推出相似或合同。

结论：Rule Support；2023 的分块秩只补了可执行 Rule，不改 L03 本体。

### L04：线性方程组、可达性与解空间

所有形式都还原为 Ax=b：先判 b 是否在 Im A，再用 nullity 计方向，最后给一个特解定位仿射平移。

公共解、几何图形、两组同解都不能跳过增广秩/核的可达性检查。2020 列变换题说明，变量代换未被记录时不能声称原方程同解；2024、2025 的几何包装验证了“方向 + 位置”模型。

结论：Rule Support；R-LA08、R-LA09、R-LA22 已覆盖主要接口。

### L05：特征结构、相似与对角化

真题反复要求从已知作用构造表示，从重根判断特征子空间，从多项式作用读谱，或区分相似与合同。

稳定主链：确认研究的是同一空间上的算子；由特征方程、已知作用或多项式关系得到候选谱；对重根检查 eigenspace 维数；只有特征向量成基才写对角化；最后用 AP=PΛ 或作用关系回代校验。

边界攻击：同特征值不自动相似；实对称矩阵的正交对角化是 L05 的谱机制，二次型惯性与零集属于 L06；正定平方根是谱函数的 Use。

结论：Rule Support；R-LA10--R-LA17、R-LA23 已由真题反复支持。

### L06：二次型、合同、惯性与正定

二次曲面、正惯性指数、正定判别、零集和两个实对称矩阵之间的正交变换，都要求先识别交付目标：只要符号计数就走惯性/合同；要求方向、标准形或 Q 才走谱/正交。

2020 的真实缺口已补入 Canonical Topic06：若 U^T A U=Λ 且 V^T B V=Λ，则直接构造 Q=UV^T，得到 Q^T A Q=B。这是“两个对象各自进入自然坐标，再合成坐标变换”的机制。

其他反复验证：交叉项不等于必须正交对角化；x^T A x=0 先看惯性；单位球面极值先确认是否是有约束的 Rayleigh 商；普适向量不等式通常在问半正定/半负定。

结论：Canonical Update 已完成（2020）+ Rule Support（2021、2024、2025）。

## 5. 模型打磨：由真题得到的稳定主线

### 5.1 把“任务契约”提升为执行入口

跨 39 年最稳定的现象是：同一数表可要求完全不同的交付。矩阵题若问 rank、相似、惯性或具体变换，第一动作不同；二次型题若只问正惯性指数，直接做合同/秩符号分析通常比求全部特征向量更短。

因此执行层的统一主链应写成：

\\[
\\boxed{
\\text{先读交付目标}
\\to\\text{认对象}
\\to\\text{辨表示}
\\to\\text{锁定合法变换}
\\to\\text{选择不变量}
\\to\\text{化为最简合法表示}
\\to\\text{回代校验}
}
\\]

这不是增加机械步骤，而是把目标从复盘问题提升为做题入口；最终交付对象决定哪些不变量值得计算。

### 5.2 六类题的统一做题规则

| 题面信号 | 第一问 | 立即禁止的越权 |
|---|---|---|
| 向量组/参数向量 | 能否写出系数关系？ | 不能看到列矩阵就直接谈相似 |
| 行列式/初等变换 | 左乘还是右乘？结构在哪里？ | 不能把列变换说成原方程同解 |
| 秩/核/像/分块 | 哪个方向被抹掉、哪个方向可达？ | 不能由同秩推出相似/合同 |
| Ax=b/公共解/几何解集 | b 是否在像空间？方向维数多少？ | 不能只给参数而不说明可达性 |
| 特征值/相似/递推 | 研究的是同空间算子吗？重根的 eigenspace 多大？ | 不能由特征值重数直接断言可对角化 |
| 二次型/二次曲面/正定 | 目标是符号、方向还是具体变换？ | 不能把合同、相似、正交合同混为一谈 |

### 5.3 证据状态

- No Update：题面可由现有 Topic/Rule 生成，未暴露稳定知识缺口。
- Rule Support：题面重复支持某个动作，但不能证明学生能独立调用；需另做学生作答或盲测记录。
- Canonical Update：模型缺少可复用机制，已回写唯一 Owner；本轮唯一明确的线代 Canonical Update 是 2020 的双实对称矩阵正交变换构造，且已落入 Topic06 与 R-LA18。
- 待人工复核：题面损坏或版本冲突，不能用来驱动稳定写入。

## 6. 总结与路由

本次真题攻击没有发现需要新增第七个线代 Topic，也没有发现 L01--L06 的根对象划分失效。模型的真正升级点是执行顺序：

交付目标先行 -> 对象/表示分流 -> 合法变换与不变量匹配 -> 最小证明链 -> 计算与回代校验。

本文件留在 Evidence 层；题面分类不等于题目已转写、解答已证明，也不等于 Rules 已被学生采用。下一步最小验证是从每个 Topic 选一题陌生年份，隐藏 Topic 名称，只给题面，让学生口述“目标、对象、第一动作和停止条件”，再把真实 First Divergence 记录到独立诊断证据中。
