## 2. 重组后的母模型

旧稿原先按“定义—工具—题型—口诀”展开。本轮改成一个能生成三类知识的控制模型：

```text
趋近规范
-> 合法邻域/尾部
-> 统一输出控制
-> 所有允许路径一致
-> 与点值接缝
```

- 数列极限与函数极限共享“阈值以后全部输入受控”，但 Allowed Set 分别是离散尾部与去心邻域；
- 夹逼、海涅定理和左右极限分别承担存在性证明/否定；
- 等价无穷小被解释为相对误差趋零，主部相消意味着当前信息精度失效；
- 连续不是新的逼近机制，而是把邻域极限与点值接成同一对象；
- 递推数列被重组为“合法轨道—收敛发动机—不动点筛选”，防止先解不动点方程再假定收敛。

## 4. 保留的深层反例

- $|x|^p\sin(1/x)$：区分有界振荡、包络压制、$O(|x|^p)$ 与 `~`，并把极限接到连续性；
- 两条趋近数列：说明否定极限只需一对冲突，有限条路径相同不能证明存在；
- $x_{n+1}=1-x_n$：说明唯一不动点不能排除二周期；
- Newton 递推：说明不动点只是候选，必须先证明合法轨道与收敛；
- 平方/绝对值隐藏跳跃：说明复合外层可能压缩信息，但不改变原函数的间断事实。
