# 主存与存储硬件：地址怎样落到物理介质

状态：工作稿，待人工确认。

## 1. 母问题

一个物理地址怎样经过芯片选择、阵列译码和时序控制，定位到真实存储元并完成可靠读写？

```text
physical address
-> module / chip select
-> row / column decode
-> sensing or programming
-> data transfer
```

主存不是抽象数组本身，而是用有限引脚、有限阵列端口和有物理缺陷的介质实现该数组。

## 2. 四个容易混淆的粒度

| 粒度 | 回答什么 | 典型对象 |
|---|---|---|
| 编址单位 | 一个地址代表多少信息 | byte / word |
| 存储字 | 一次阵列选中组织出的数据 | 芯片组织中的 $K\times W$ 的 $W$ |
| 总线传输单位 | 一次事务搬多少位 | data bus width / burst |
| Cache line / page | 上层批量搬运与映射粒度 | 不由 DRAM 存储字直接决定 |

它们可能相等，也可能不同。地址线数必须由“可寻址单元数”计算，不能仅由总字节数和机器字长猜测。

## 3. SRAM 与 DRAM：保存状态的两种代价

### SRAM

用双稳态电路维持一位状态，只要供电就不需刷新；读通常非破坏。速度快，但单元晶体管多、密度低、单位成本高，适合 Cache 等小而快的阵列。

### DRAM

用电容电荷表示一位。电荷会泄漏，读出需要感测并通常伴随恢复，因此需要周期性刷新。单元简单、密度高、单位成本低，适合作主存。

共同边界：二者都通常易失；“static”指无需刷新，不代表断电保存。

## 4. DRAM 的生成机制

朴素模型把 DRAM 当作“给地址立即返回”。真实路径至少分为：

```text
row address -> activate row -> sense/amplify row buffer
-> column select -> transfer data
-> precharge / prepare next access
```

### 为什么行列复用

若直接为 $2^n$ 个单元提供一维选择，译码和连线不可扩展。二维阵列把地址拆为 row/column，DRAM 还可在相同地址引脚上分时送入两部分，以减少封装引脚。代价是 RAS/CAS 等时序约束与控制复杂度。

### 为什么刷新按行

激活一行时，感测放大器接收整行微弱电荷并恢复。刷新复用这条路径，周期性激活各行。刷新会占用阵列时间，因此形成可见的带宽/延迟成本。

集中、分散、异步刷新是“刷新周期怎样分布”的不同调度；题目计算必须区分刷新总窗口、行数、单次占用周期和所谓死区。

## 5. 芯片扩展：宽度与字数是两个正交维度

设单片规格 $K\times W$，目标规格 $K'\times W'$：

- **位扩展**：多片共享地址与控制，各提供一部分数据位，使字长从 $W$ 增至 $W'$；
- **字扩展**：高位地址经片选译码选中一组芯片，使字数从 $K$ 增至 $K'$；
- **字位同时扩展**：先按位组成一组，再用片选增加组数。

芯片数：

$$
N=\frac{K'}K\times\frac{W'}W
$$

但地址接线必须另画：片内地址取低位还是题设指定字段，片选由剩余高位和地址范围译码产生。

### 全译码、部分译码与线选

- 全译码检查所有高位，地址范围唯一；
- 部分译码忽略若干高位，硬件少但产生地址重影；
- 线选法更简单，可能浪费地址空间。

“能访问”不等于“地址唯一”，这是扩展题的核心检查。

## 6. 多模块与交叉编址：用并行换带宽

连续地址若轮流分布到多个独立模块，不同模块可重叠工作：

$$
\begin{aligned}
module&=(block/address)\bmod N,\\
local\ address&=\left\lfloor\frac{block/address}{N}\right\rfloor.
\end{aligned}
$$

低位交叉适合连续访问，可提高吞吐；高位编址把连续区域集中在同一模块，更像容量分区。收益取决于模块能否独立工作以及请求是否均匀；热点映射到同一模块仍会冲突。

必须区分：单次访问 latency 未必下降，稳态 bandwidth 可以上升。

## 7. ROM、Flash、HDD 与 SSD 的共同坐标

不要按名词堆介质，统一比较：可否随机访问、最小读/写/擦除粒度、是否易失、耐久、延迟与单位成本。

### Flash / SSD

Flash 通常读写以 page 为粒度、擦除以更大的 block 为粒度；不能简单原地覆盖，控制器用异地更新、映射、垃圾回收和磨损均衡维持块设备接口。代价是写放大与延迟波动。

### HDD

机械访问分解为：

$$
T_{access}=T_{seek}+T_{rotation}+T_{transfer}+T_{controller}
$$

若目标扇区相位随机，平均旋转等待近似半圈：

$$
T_{avg\ rot}=\frac12\cdot\frac{60}{RPM}
$$

CHS 是教学物理模型，LBA 是主机接口的线性抽象；现代设备内部映射会受分区记录、坏块重映射与缓存影响，不能把连续 LBA 无条件等同连续物理扇区。

磁盘调度属于 OS 策略，介质访问成本属于本 Topic。

## 8. 性能坐标

- **Access time / latency**：一个请求从发出到可用；
- **Memory cycle time**：相邻独立访问可启动的间隔，可能大于 access time；
- **Bandwidth**：单位时间有效传输量；
- **Burst**：一次地址阶段后连续传输多个单位，摊薄控制开销；
- **Bank conflict**：并行请求落到同一不可并发资源。

公式使用前先写工作模式。$\text{宽度} \times \text{频率}$ 只有在每周期传输次数、编码开销和总线利用率明确时才是有效带宽。

## 9. 机制边界表

| 机制 | 解决 | 不变量 | 代价/失败条件 | Owner |
|---|---|---|---|---|
| 行列译码 | 降低阵列连线规模 | 地址唯一选中目标 | 译码与时序 | 本 Topic |
| DRAM 刷新 | 抵抗电荷泄漏 | 保持存储内容 | 占用周期 | 本 Topic |
| 多模块交叉 | 提高连续吞吐 | 每个地址映射确定 | 冲突、控制复杂 | 本 Topic |

## 10. 母例：构造主存模块

题设给出目标容量、芯片规格和 CPU 地址空间时：

1. 统一成“字数 × 位数”，确认编址单位；
2. 算位扩展片数，形成一个目标字宽的芯片组；
3. 算字扩展组数；
4. 低位地址接片内地址，高位进入片选译码；
5. 画数据线并联分工与控制线共享关系；
6. 检查目标地址区间、是否全译码、是否地址重影；
7. 若有交叉编址，再单独划分模块号与模块内地址。

## 11. 做题调用协议

1. 标编址单位、总容量、单片组织和总线宽度；
2. 分别计算 word-depth 与 word-width；
3. 地址拆成片内、模块/片选和未用字段；
4. 将读写画成 row/column/transfer 时序；
5. 性能题分 latency、启动间隔、并行模块与有效带宽；
6. 用边界地址和连续地址序列验证映射。

## 12. 最小反例

- DRAM 地址引脚少，不代表可寻址容量小；行列地址可分时复用。
- 低位交叉提升连续吞吐，不代表一次随机访问延迟缩短。
- $64\text{K} \times 8$ 的 8 是每个存储字的数据宽度，不是地址线数。

## 13. 压缩信号
