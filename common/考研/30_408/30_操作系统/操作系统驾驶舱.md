## 科内 Bridge

- VM x File：`mmap`、file-backed page、Page Cache 的共享关系；
- Process x File：fork/dup/close/unlink 中 task、fd table、OFD 与 inode 的引用交接；
- Process x I/O：block、wait queue、completion 和 wakeup；
- Process x Concurrency：等待同步条件与调度状态的接口。

Bridge 只解释接口。Page Cache 的内容身份、驻留映射与 writeback 分别由 File、VM、I/O 提供局部语义。入口见 [OS 科内 Bridge](60_科内桥梁/README.md)。

## Integration

OS 综合册拥有跨 Topic 的完整轨迹，优先母题：

1. 一次 blocking `read()`；
2. `fork()` + COW + file reference；
3. `mmap()` + Page Fault + file-backed page；
4. lock contention -> block -> wake -> reschedule。

任何 Topic 只保留这些过程在本专题内的投影。入口见 [OS 综合专题](70_综合专题/README.md)。

## Question Control Adapter

1. 当前对象和身份是什么？
2. 对象之间有哪些引用、所有权和映射？
3. 对象位于哪个队列、处于什么状态？
4. 什么事件发生？
5. 哪个机制处理事件？
6. 哪个策略在多个合法结果中做选择？
7. 新状态、不变量与成本是什么？
