学习方式

每个单元建议四步：① 先读 HTML 建立最小状态模型；② 只读页面指定的 3–6 个 xv6 源码位置；③ 做 MIT 精选 Lab 或 408 自建短实验；④ 回到 408 真题，用“题面信号 → 对象/队列 → Event → Mechanism → Invariant”复原。目标不是通关 MIT，而是让 408 每个核心抽象都有一个运行过的真实模型。
