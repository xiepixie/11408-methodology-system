# 408 计算机综合复习总览

当前状态：框架已采用，等待首个真实专题闭环。

## 学科母问题

408 研究数据和程序怎样被机器执行、被操作系统管理，并通过网络跨机器通信。

$$
\text{Data} \to \text{Program} \to \text{Machine}
\to \text{OS} \to \text{Network}
$$

四科没有一套可以互相替代的母模型。完整架构见 [408 学科架构](00_统一总图/408%20学科架构.md)。

| 学科 | Question Control Adapter |
| --------------- | --------------------------------------------- |
| 数据结构 | Relation -> Representation -> Operation -> Invariant -> Boundary -> Cost |
| 计算机组成原理 | State -> Location -> Path -> Resource -> Timing -> Commit |
| 操作系统 | Object -> Relation/Queue -> Event -> Mechanism -> Policy -> New State -> Cost |
| 计算机网络 | Scope -> Object/Name -> State Owner -> Event -> Transition -> Feedback -> Cost |
