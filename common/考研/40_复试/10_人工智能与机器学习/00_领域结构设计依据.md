# 人工智能与机器学习领域结构设计依据

> 本文件只记录本次 Atlas 切分的来源比较、设计判断与候选拓扑；**不承担任何 AI 概念的 Canonical Ownership**。最终地图与路由只以同目录 `README.md` 为准。

## 1. 为什么不能直接照一本书的目录切

当前参考资料实际上在回答四个不同层级的问题：

1. **AIMA** 在回答“整个人工智能有哪些能力与问题形态”；
2. **Murphy** 在回答“机器学习怎样用概率与决策论统一”；
3. **Xiaojing Ye** 在回答“现代深度学习怎样沿数学依赖展开”；
4. **Models Demystified** 在回答“一个模型在真实建模流程中怎样被定义、估计、评价、解释和使用”。

所以四本书目录看起来都合理，却不能互相替换。若机械拼接，会把以下不同层级混为一谈：

- **问题形态**：搜索、预测、生成、序贯决策；
- **表示语言**：逻辑、概率分布、函数、图、状态空间；
- **求解机制**：推理、搜索、动态规划、梯度优化、采样；
- **学习机制**：监督、无监督、自监督、强化学习；
- **模型族**：线性模型、树、kernel、神经网络、图模型；
- **应用域**：NLP、CV、机器人、Scientific ML。

我们的 Atlas 必须先把这些层级拆开，再决定哪些值得成为 Topic、Bridge、Integration 或 Direction。

## 2. 四本参考书实际上怎样切整个领域

### 2.1 Russell & Norvig：以“理性智能体”统一整个人工智能

AIMA 第 4 版最重要的不是 28 章目录本身，而是前言和第 2 章给出的统一对象：

```text
Environment
   ↓ percept
Agent
   ↓ action
Environment
```

智能体函数把**感知历史映射为动作**；理性则要求在已有感知与先验知识下选择使期望性能尽可能好的动作。学习负责让智能体减少对设计者先验知识的依赖。

因此 AIMA 的七部分不是简单按“算法名”分类，而是在不断回答智能体需要哪些能力：

```text
AI Foundations / Agent
→ Problem Solving: Search, Game, CSP
→ Knowledge, Reasoning, Planning
→ Uncertainty, Probabilistic Inference, Decision
→ Machine Learning / Deep Learning / RL
→ Language, Vision, Robotics
→ Ethics / Safety / Future
```

**可吸收的设计原则**：

- AI 的 Course-level Mother Model 应该比“机器学习模型”更外层；
- Search、Logic、Probability、Decision、Learning 是不同的智能能力，不应被全部压成 ML；
- NLP / CV / Robotics 更接近复杂能力集成，而不是与 Probability / Optimization 同层的基础机制；
- 环境属性会改变算法选择，问题的“世界条件”必须出现在 Atlas 中。

### 2.2 Kevin Murphy：以 Probability + Bayesian Decision Theory 统一机器学习

Murphy 明确说明这本书不是整个 AI，而是 **ML 的一个概率视角路径**。其主结构是：

```text
Introduction: supervised / unsupervised / RL
→ Part I Foundations
   Probability
   Statistics
   Decision Theory
   Information Theory
   Linear Algebra
   Optimization
→ Part II Linear Models
→ Part III Deep Neural Networks
→ Part IV Nonparametric Models
→ Part V Beyond Supervised Learning
```

这本书的切法混合了两种层级：

- Part I 是**跨模型 Foundation**；
- Part II–IV 主要是**模型族 / inductive bias**；
- Part V 主要是**学习设定与数据结构扩展**。

Murphy 在 Introduction 中强调：概率视角把所有未知量当作随机变量，并把机器学习连接到统计、优化、控制、运筹、信息论等领域。

**可吸收的设计原则**：

- Probability / Statistics / Optimization 是 ML 的共享语言，不能只把它们当作某个单独算法的前置章节；
- “Linear / Neural / Kernel / Tree”是模型族，不等于“Supervised / Unsupervised / RL”这类学习设定；
- Generalization、Decision、Information 不应被算法目录淹没；
- ML 是 AI 的重要组成，但不能把 AI 与 ML 直接画等号。

### 2.3 Xiaojing Ye：以现代深度学习的数学依赖链组织

该书前言明确把深度学习看成数学问题：

- neural network = function approximator；
- training = large-scale non-convex optimization；
- generalization = probability / statistics；
- expressivity / stability / robustness 连接 approximation theory、functional analysis、dynamical systems。

正文只保留五条主线：

```text
Function Approximation / Deep Networks
→ Network Training / Optimization / AutoDiff
→ Deep Optimal Control / Neural ODE
→ Deep Reinforcement Learning
→ Generative Models: VAE / GAN / Diffusion / Flow Matching
```

附录再补 Monte Carlo、Banach / Fixed Point、Information Theory、SDE。

**可吸收的设计原则**：

- 深度学习内部存在一条很强的数学生成链，而不是 CNN/RNN/Transformer 的架构名录；
- Optimization 是“训练执行引擎”，Function Approximation 是“模型表达能力”，两者要分责；
- Optimal Control ↔ RL、ODE/SDE ↔ Generative Models 是真正值得关注的高价值 Bridge；
- 现代生成模型应当在我们的地图中获得独立位置，而不是埋在“深度学习应用”里。

### 2.4 Clark & Berry：以 Modeling Lifecycle 和可解释实践组织

这本书从 `Thinking About Models` 开始，明确区分：

```text
Task
Model
Algorithm
Objective / Evaluation
```

然后按真实建模责任展开：

```text
Linear Model Foundation
→ Understand Model
→ Understand Features
→ Estimation & Optimization
→ Uncertainty
→ GLM / Linear Extensions
→ Core ML Concepts: objective, generalization, regularization, CV, tuning
→ Common ML Models
→ Unsupervised / RL / transfer...
→ Causal Modeling
→ Data Problems
→ Danger Zone
```

**可吸收的设计原则**：

- “模型”“算法”“任务”“估计方法”必须在术语上分开；
- 不能只学如何 fit，还必须知道如何 evaluate、compare、interpret、estimate uncertainty；
- Data quality、model selection、limitations 是所有学习算法的横向检查层；
- 从 linear model 到 neural network 的连续性很适合作为第一条 Integration 学习路线。

## 3. 四种切法的冲突说明了什么

四本书不存在真正冲突，它们在用不同坐标轴看同一个复杂系统。

### Axis A｜外部任务与环境

```text
已知 / 未知
确定 / 随机
完全可观测 / 部分可观测
一次性预测 / 序贯决策
单智能体 / 多智能体
静态数据 / 交互数据
```

这是 AIMA 最强的轴。

### Axis B｜内部表示

```text
State / Graph
Logic / Symbol
Probability Distribution / Graphical Model
Parametric Function
Tree / Kernel / Exemplar
Neural Representation
Latent Variable / Dynamical State
```

这是 AIMA + Murphy + Ye 共同覆盖的轴。

### Axis C｜计算机制

```text
Search
Constraint Propagation
Logical Inference
Probabilistic Inference
Dynamic Programming
Sampling
Gradient / Numerical Optimization
Learning / Parameter Estimation
```

这是我们真正学习“算法”时最需要的轴。

### Axis D｜输出责任

```text
Infer / Explain
Predict
Generate
Plan
Act / Control
```

应用领域只是把这些责任和真实数据结构组合起来。

因此，**我们的目录不能只选择其中一个轴作为文件夹树。** 文件树必须选择最稳定的 Ownership 切法，而其他轴留在 Atlas 作为 Routing Lens。

## 4. 最终切分原则

### 原则 1：Course Atlas 用 Agent / Environment 做最外层 Mother Model

整个人工智能不能用 `Data → Model → Loss → Optimization` 统一，因为 Search、Logic、Planning 等并不天然是“训练一个参数模型”。

更稳的外层循环是：

```text
Environment / Task
→ Observe
→ Represent State / Belief / Knowledge
→ Infer / Predict
→ Search / Plan / Decide
→ Output / Act
→ Receive Data / Feedback
→ Learn / Update
```

并不是每个系统都走完整循环，但它能说明各模块在系统中承担什么责任。

### 原则 2：Topic 按“可独立解释的核心机制”切，不按应用名切

NLP、CV、Robotics 会同时调用 Representation、DL、Probability、Search、Planning、RL，因此优先视为 **Direction / Integration**。

真正的 Core Topic 应该在删掉具体应用后仍然成立。

### 原则 3：Foundation、Topic、Bridge 必须分层

- Linear Algebra / Calculus / basic Probability 是 Foundation / External Use；
- Optimization、Probabilistic Inference 因为拥有足够大的独立机制，进入 Topic；
- `Probability → Loss`、`Dynamic Programming → RL` 等接口进入 Bridge；
- LLM、视觉系统、机器人等真实系统进入 Integration / Direction。

### 原则 4：不按“时代新旧”切

Linear Regression、SVM、Transformer、Diffusion 不是四个同层的时代章节。我们追踪它们各自改变了：

- representation；
- objective；
- inference / optimization；
- data / supervision；
- computation；
- output responsibility。

这样新算法出现时可以挂到旧地图，而不是重建目录。

## 5. 建议的 Core Topic Topology

### AI-T01｜状态空间、搜索、博弈与约束求解

**Mother Question**：解已经隐含在一个巨大可能性空间中时，怎样高效找到满足目标或约束的解？

拥有：state-space search、uninformed / heuristic search、local search、adversarial search、CSP 的核心求解机制。

不拥有：概率信念更新、连续参数训练、未知环境中的 learning。

### AI-T02｜知识表示与符号推理

**Mother Question**：怎样把世界中的事实、关系和规则表示成可计算结构，并推出新结论？

拥有：propositional / first-order logic、unification、forward/backward chaining、resolution、knowledge representation。

不拥有：概率不确定性与统计学习。

### AI-T03｜概率模型与不确定推理

**Mother Question**：未知和噪声无法消除时，怎样表示信念并依据证据更新？

拥有：Bayesian modeling、graphical models、exact/approximate inference、temporal probabilistic models、sampling 的基础机制。

不拥有：模型参数怎样从大量数据训练、策略怎样通过交互学习。

### AI-T04｜统计学习与经典机器学习

**Mother Question**：规则无法手写时，怎样从有限样本选择一个能在未见数据上工作的映射或结构？

拥有：supervised / unsupervised learning 的问题定义、ERM / regularization / generalization，以及 linear/logistic、kNN、tree/ensemble、kernel、PCA、clustering 等经典模型族的核心机制。

不拥有：深层网络本体、通用数值优化理论、完整概率推断。

### AI-T05｜学习中的优化与数值计算

**Mother Question**：当学习或控制被写成 objective 后，怎样有效寻找高质量解？

拥有：first/second-order optimization、SGD、momentum / adaptive methods、constrained / proximal methods、optimization geometry 与收敛直觉。

不拥有：具体模型为什么这样表示、backprop 的网络结构语义、generalization 本身。

### AI-T06｜深度神经网络与表示学习

**Mother Question**：怎样构造可学习的高表达函数，并让复杂表示通过层级计算形成？

拥有：function approximation、MLP、computation graph、backprop、CNN、sequence models、attention、Transformer、representation learning、deep training 的模型侧机制。

使用 AI-T05 完成参数更新，不重新拥有通用优化算法。

### AI-T07｜规划、序贯决策与最优控制

**Mother Question**：当前行动会改变未来状态时，怎样在已知或可建模动态中选择长期最优行为？

拥有：utility / decision theory、dynamic programming、MDP/POMDP、classical planning 的决策接口、optimal control。

与 AI-T01 的边界：Search 负责“在显式可能性空间找路径/解”，本 Topic 负责“未来后果、价值与策略”。

### AI-T08｜强化学习

**Mother Question**：当最优行动不能直接从已知模型算出时，怎样通过交互、奖励与探索学习策略？

拥有：Bellman learning view、MC/TD、Q-learning、policy gradient、actor-critic、model-based/model-free RL、exploration。

使用 AI-T07 的 MDP / value / policy 语言，使用 AI-T06 作为函数逼近器时形成 Deep RL。

### AI-T09｜生成模型

**Mother Question**：怎样学习数据的生成规律，并据此建模、采样或条件生成新对象？

拥有：autoregressive models、VAE、GAN、diffusion、flow / flow matching 的生成机制与比较框架。

使用 AI-T03 的概率语言、AI-T05 的优化、AI-T06 的深度表示；ODE/SDE 作为高阶 Bridge / Extension 按需要引入。

## 6. Atlas Foundation：不再伪装成平行 Topic

下面内容反复被所有 Topic 使用，但当前不单独建立 Handbook：

### F1｜Agent / Task Language

```text
Environment
Percept / Observation
State / Belief / Knowledge
Action / Output
Performance / Utility / Loss
Experience / Data / Feedback
```

### F2｜Modeling Language

必须稳定区分：

```text
Task ≠ Model ≠ Algorithm ≠ Objective ≠ Metric
Representation ≠ Inference ≠ Learning
Training ≠ Generalization
Prediction ≠ Decision
```

### F3｜Mathematical Language

优先 Use 现有数学一 Owner：

- Linear Algebra；
- Calculus / Jacobian / Hessian；
- Probability / Statistics。

AI 领域新增的 Information Theory、Matrix Calculus、SVD/PCA 高维视角、ODE/SDE、Optimal Control 等只在算法真正调用时扩展。

### F4｜Cross-cutting Validation

所有学习型 Topic 都必须回答：

```text
Data quality
Train / validation / test
Objective vs metric
Generalization
Uncertainty / calibration
Model comparison
Interpretability
Failure / distribution shift
Computation cost
```

这些不是“某个模型的附录”，而是算法能否被正确使用的共同检查层。

## 7. Candidate Bridges

优先保留以下接口，暂不全部建册：

1. **AI-B01｜Probability → Estimation / Loss**  
   likelihood、MLE/MAP、cross entropy、KL 怎样把概率模型变成学习目标。

2. **AI-B02｜Differentiation / AutoDiff → Backprop → Optimization**  
   “导数如何得到”与“参数如何更新”分责。

3. **AI-B03｜Search / Planning → Dynamic Programming → Sequential Decision**  
   路径搜索、价值递推和策略优化之间的真正接口。

4. **AI-B04｜Known-model Decision → Reinforcement Learning**  
   从已知 transition / reward 求最优策略，到未知环境中用经验估计 value / policy。

5. **AI-B05｜Probability → Generative Modeling**  
   density、likelihood、latent variable、sampling、score / flow 分别承担什么角色。

6. **AI-B06｜Function Approximation → Value / Policy Approximation**  
   深度网络怎样进入 RL，而不是把“Deep RL”当作完全独立世界。

7. **AI-B07｜Continuous Dynamics → Control / Neural ODE / Diffusion / Flow**  
   当前作为 Candidate / Extension；Xiaojing Ye 的结构表明其数学价值很高，但需要真实学习证据决定是否独立建册。

8. **AI-B08｜Symbolic Representation ↔ Probabilistic Representation**  
   当前只记 Candidate：确定逻辑事实与不确定信念如何连接，等待后续覆盖概率编程/Neuro-symbolic AI 时再判断。

## 8. Integration / Direction Layer

### Core Integration 候选

**AI-I01｜从数据到可用预测器**

```text
Problem
→ Data
→ Representation / Model
→ Probabilistic Assumption or Objective
→ Optimization
→ Validation / Generalization
→ Prediction
→ Decision / Communication
```

第一条教学轨迹采用：

```text
Linear Regression
→ Logistic Regression
→ MLP
```

目的不是比较三个模型“谁更高级”，而是观察同一 modeling pipeline 中 representation、loss、optimization 和 generalization 怎样变化。

**AI-I02｜一个理性智能体的完整闭环**

```text
Observe
→ Update State / Belief
→ Infer
→ Plan / Decide
→ Act
→ Receive Feedback
→ Learn / Update
```

它是未来把 Search、Probability、Planning、RL、Perception 接起来的总验收过程。

### Direction Atlas 候选

下面不作为 Core Topic，而作为将来选择研究方向时的纵向入口：

- NLP / LLM / Agents；
- Computer Vision / Multimodal；
- Robotics / Embodied AI；
- Scientific Machine Learning；
- Graph ML / Recommender Systems；
- Causal ML；
- Learning Theory；
- AI Safety / Alignment。

每个方向必须先说明“它调用哪些 Core Topic / Bridge”，再决定是否值得建立自己的 Topic 树。

## 9. 对原七模块框架的修正

原框架：

```text
Search
Probability
Machine Learning
Optimization
Deep Learning
Reinforcement Learning
Generative AI
```

有三个结构问题：

1. **缺失 Symbolic Knowledge / Reasoning**：这会把 AIMA 的一整类 AI 能力从地图中抹掉；
2. **缺失 Planning / Decision / Control**：会导致 Search 直接跳到 RL，看不见 known-model sequential decision 这一层；
3. **层级混合**：Probability / Optimization 是跨模型机制，Machine Learning 是学习范式，Deep Learning 是模型族，Generative AI 是输出/建模责任，彼此并非严格同层。

新框架不要求它们在哲学上完全同构，而是通过明确 Owner 把层级冲突压到最小：

```text
Search / CSP
Symbolic Reasoning
Probabilistic Inference
Statistical Learning
Optimization
Deep Representation
Sequential Decision / Control
Reinforcement Learning
Generative Modeling
```

应用方向再从这些机制组合产生。

## 10. 当前决策：Area Boundary v1 + Leaf Boundary v1 已锁定

当前已经从“候选拓扑”推进到 **Area-level + Leaf-level Canonical Ownership**：

1. AI Subject Atlas 保留整领域 Mother Question 与 Routing；
2. 八个 Core Area 已分别建立 Canonical Area Atlas README，并锁定 `Owns / Uses / Stop Boundary`；
3. 每个 Area 已进一步锁定 Leaf Topic 的 Mother Responsibility、显式 Stop Boundary 与 Internal Dependency DAG；
4. Cross-Area Bridge、Integration、Research Direction 已分成三个独立 Atlas 入口；
5. Leaf Topic **已有 Canonical 归属但仍不批量建立空 `.tex`**；只有真实学习进入该机制时才物理创建 Handbook；
6. `ownership_matrix.md` 已登记八个 Area 的唯一 Owner，Leaf 级冲突以对应 Area README 为准。

这次 Leaf Boundary 的关键修正包括：Search 内区分 frontier/path、local neighborhood、game tree、CSP；ML 内把 learning contract 与 model families 分开；DL 内把 AutoDiff / Backprop / Optimizer 三分；Decision 内把 MDP / known-model DP / POMDP / control / RL 分开；Generative 内把 Normalizing Flow 与 Flow Matching 分开，并把 Conditional Guidance 降为跨模型 Candidate。

锁定后的原则不是“永远不能改”，而是：**默认相信当前边界；新算法先做 Leaf Owner Diff，再做 Area Owner Diff。只有稳定的新 Mother Question 与独立 State/Mechanism 无法由现有 Leaf/Area 解释时，才允许晋升新 Leaf 或挑战 Area Topology。**

下一步优先用 AI-I01《Linear Regression → Logistic Regression → MLP：什么叫学习？》攻击 Area 30 / 40 / 50 / 60 的真实接口，同时开始第一个 Leaf Handbook；不再继续扩张一级目录。
