\section{知识引入策略}

\teachblock{分离参数的几何意义}{
  当讲分离参数 $a \ge f(x)$ 时，不要只讲代数变形。画一个曲线 $y=f(x)$，然后画一条水平直线 $y=a$。告诉学生：恒成立就是直线永远在曲线“上方”。
}

\section{核心考向突破}

\teacherproblem{例题 1}{分离参数法解决恒成立}
\teachvalue{本题通过典型的二次导数结构，训练学生遇到含参恒成立时的第一反应——分离参数，并能准确求出分离后函数的最值。}

{\small \qOneStem}

\begin{paracol}{2}
\teachblock{标准解答}{
  1. 确定定义域 $x \in (0, +\infty)$。\\
  2. 分离参数得 $a \ge g(x)$。\\
  3. 求导 $g'(x)$，列表分析单调性。\\
  4. 求出 $g(x)$ 的最大值，从而得到 $a$ 的范围。
}

\teachblock{板书建议}{
  重点板书：$a \ge g(x)_{\max}$ 这句话，以及求导后判断符号的那个不等式。
}

\switchcolumn
\teachblock{常见错因}{
  1. \textbf{没看定义域}：直接对整个实数轴求最值。\\
  2. \textbf{分离时变号错误}：除以含 $x$ 的式子时，没判断其正负号，导致不等号方向错乱。
}

\teachblock{追问设计}{
  追问：你刚才除以 $x$ 的时候，为什么不等号没有变方向？（引导说出 $x>0$）
}

\remedy{
  若学生在求导环节算错，课后必须补充“除法求导法则”的专项默写。若分离参数后不等号弄反，安排变式 1 重做。
}
\end{paracol}
