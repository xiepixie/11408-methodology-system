\section{本讲目标}

\begin{itemize}[itemsep=0.3em]
  \item 理解诱导公式的几何对称本质，掌握“奇变偶不变，符号看象限”的底层逻辑。

\end{itemize}

\section{易错自查与课堂反思}

\vspace{0.5em}
\noindent\textbf{本讲我的主要问题集中在（请打勾）：}
\begin{itemize}[itemsep=0.4em]
  \item \checkbox 诱导公式符号记错：在处理 $\cos(\frac{\pi}{2}+\alpha)$ 时，符号没有看原函数（余弦在第二象限为负），而是误看成了变名后的正弦。
  \item \checkbox 象限讨论遗漏：在应用半角公式开平方时，没有根据半角 $\frac{\alpha}{2}$ 的实际象限讨论正负号，直接丢弃了负号或没有保留正负分支。
  \item \checkbox 倍角形式选用不当：在化简如 $\frac{1-\cos 2x}{\sin 2x}$ 等式子时，由于未能熟练应用二倍角公式消去常数 $1$ 而使化简卡壳。
  \item \checkbox 积化和差/和差化积符号记反：特别是在 $\cos x - \cos y$ 的和差化积公式中，漏掉了前面的负号 $-2$；或在积化和差中记错 $\sin\alpha\sin\beta$ 后面两项的减法顺序。
  \item \checkbox 辅助角象限混淆：在化简如 $-\sqrt{3}\sin x + \cos x$ 时，没有看清点 $(-\sqrt{3}, 1)$ 在第二象限，将辅助角 $\varphi$ 错算为 $-\frac{\pi}{6}$ 或者是第一象限的角。
  \item \checkbox 万能公式代数前置条件缺失：在应用万能置换时，未注意到当 $\alpha = \pi + 2k\pi$ 时 $\tan\frac{\alpha}{2}$ 无意义，从而在求值时导致漏解或增根。
\end{itemize}
