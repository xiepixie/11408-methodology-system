\section*{本讲教学目标与思路}

这六道题覆盖了排列组合中最常见的失分点：计数对象不清、组是否有标号判断错误、分类不完整、重复乘排列数、忽略样本空间统一以及把“自动确定”误当成新的选择。
其训练重点不是记忆公式，而是把题目准确翻译成计数模型。

\subsection*{一、核心引子与题感诊断}

\textbf{1. 看到这些条件，应立刻想到什么}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{看到“完全相同的球”}：一种放法只由各盒中的数量决定，不需要选择具体是哪几个球。若盒子有编号，则数量向量有顺序。
    \item \textbf{看到“数量均不同”}：普通隔板法只处理正整数或非负整数条件，不能自动保证变量互不相同。优先把数量从小到大排列，枚举无序数量类型，再分配给有标号盒子。
    \item \textbf{看到“平均分配到甲、乙、丙”}：甲、乙、丙有标号。总分配数可写成 $\binom93\binom63$，不需要再除以 $3!$。
    \item \textbf{看到“每组至少一人、至多两人”}：先由总人数确定容量类型。例如五人分到三个单位，容量只能是 $(2,2,1)$。
    \item \textbf{看到“对应位置高于”}：优先考虑每一列内部交换。如果每列中的两棵树已经确定，则一前一后的两种放法中，恰有一种满足后高前低。
    \item \textbf{看到“某两人同行、某两人不同组”}：先安排这些特殊对象，形成一个“基础占位结构”，再把普通对象补入各单位。
\end{itemize}

\textbf{2. 本类题的常见切入点}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{先明确计数对象}：对象是否互不相同；单位是否有标号；交换两组后是否得到新方案；每组内部是否区分顺序。
    \item \textbf{先确定容量结构}：若人数上下限较严格，应先解方程并结合上下界列出所有可能容量。
    \item \textbf{先安排限制最强的对象}：限制越强的对象越应优先安排。
    \item \textbf{寻找自动确定的步骤}：若某一步在此前选择完成后只有一种合法结果，就不能额外乘计数因子。
\end{itemize}

\subsection*{二、应试方法联系与深度思考}

\textbf{1. 方法的横向联系}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{数量拆分与隔板法}：普通隔板法解决基础条件，附加的互异、奇偶、上下界条件需要另行处理。
    \item \textbf{容量类型与分组问题}：先确定 $(2,2,1)$ 等容量结构，是分配题的常见入口。
    \item \textbf{补集与容斥}：当条件中出现“每个”“至少”“都不缺少”时，应主动检查补集是否更简洁。
    \item \textbf{局部交换对称}：利用局部或列内部独立交换，避免对复杂排列情况进行繁琐的分类。
    \item \textbf{固定高频对象与交集分类}：先固定结构最强、出现次数最多的对象，再按交集大小分类。
    \item \textbf{特殊对象锚定}：先安排同行和不同组的特殊对象，再补入普通对象。
\end{itemize}

\textbf{2. 实战做题启发}
\begin{itemize}[itemsep=0.3em]
    \item \textbf{先写“容量”，再写组合数}：遇到分配题，先写每个单位可能有多少人。后续分类就会非常明确。
    \item \textbf{每乘一个因子，都要说明它对应哪次选择}：无法说明具体选择含义的乘数，往往会造成重复计数。
    \item \textbf{先处理限制最强的对象}：优先处理必须同行、必须分开、不能出现、出现次数最多、可选位置最少的对象。
\end{itemize}
