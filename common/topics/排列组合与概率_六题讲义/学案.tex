\section{核心公式与思维诊断}

\begin{itemize}[itemsep=0.3em]
  \item \textbf{学完本讲后，你应该能够：}
  \item 明确计数对象：对象是否相同？单位是否有标号？
  \item 掌握“先确定容量，再计算组合数”的稳定流程；
  \item 恰当处理必须同行、必须分开、出现最高频的特殊对象；
  \item 灵活运用对称性与容斥原理简化计算。
\end{itemize}
