  \textbf{解题核心主线}：
  \begin{enumerate}[label=\arabic*. , leftmargin=2em, nosep]
    \item \textbf{单变量根式题}：根据根式内部不同的代数结构，选择\textbf{整体换元}或\textbf{三角换元}以消除根号，化归为有理函数或三角函数有界性问题。
    \item \textbf{多变量约束题}：消元是第一要务。掌握\textbf{主元消元}、\textbf{比值消元（齐次化）}与\textbf{轮换消元（乘积相消）}。
    \item \textbf{非齐次分式最值}：利用条件进行\textbf{齐次化构造}（如将 1 替换为 $x+y$ 或其高次方），使分子分母阶数平衡，再换元为一元比值问题。
  \end{enumerate}
\end{tcolorbox}

\freequestionheader
{\small
\qSevenStem
}
\answerblank[13.2cm]{解：}
\postproblem{
  \item 求解含有两个绝对值的不等式，首要任务是求出两个绝对值内部式子的零点；
  \item 根据零点将数轴划分为若干区间（本题为三个区间）进行分段讨论；
  \item 在各个区间内去绝对值解不等式，解出的范围需与当前区间限制取交集，最后对三段范围求并集。
