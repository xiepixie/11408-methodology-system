\section{本讲目标与核心思维}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{第零定义（空间截面定义）}：理解平面截圆锥的夹角关系及离心率统一公式 $e = \frac{\cos\beta}{\cos\alpha}$，攻克立体几何包装下的轨迹大题．
  \item \textbf{第一至第三定义（平面代数定义）}：熟练掌握焦半径、焦点极坐标、焦点弦长、韦达定理坐标积及斜率积结论，能利用定义进行“设而不求”的计算．
\end{itemize}

\section{第一部分：第零定义（空间截面定义）与典型应用}

\subsection*{第一部分：核心引子与题感诊断}

\subsubsection*{1. 本讲用到的核心公式、定理或二级结论}

设圆锥的半顶角（母线与旋转轴线的夹角）为 $\alpha$，截平面与圆锥旋转轴线的夹角为 $\beta$．（以下默认截面不经过圆锥顶点）．

\begin{enumerate}[label=(\arabic*), leftmargin=2em, itemsep=0.3em]
  \item \textbf{圆锥截面类型判断}
    \begin{itemize}[itemsep=0.15em]
      \item 若 $\beta = \frac{\pi}{2}$，截面垂直于轴线，截线为\textbf{圆}；
      \item 若 $\alpha < \beta < \frac{\pi}{2}$，截平面与所有母线都相交，截线为\textbf{椭圆}；
      \item 若 $\beta = \alpha$，截平面平行于且仅平行于一条母线，截线为\textbf{抛物线}；
      \item 若 $0 \le \beta < \alpha$，截平面平行于两条母线，截线为\textbf{双曲线}（完整双曲线需在双圆锥中截得）．
    \end{itemize}

  \item \textbf{圆柱斜截椭圆模型}
    圆柱内放入两个等半径的内切球，球半径为 $R$，球心距为 $O_1O_2$．斜截面同时与两球相切，两个切点即为椭圆焦点．若截线为椭圆，则：
    \[ 2a = \fblank[3cm]{O_1O_2},\quad b = \fblank[2cm]{R},\quad c = \fblank[3cm]{\sqrt{a^2 - b^2}} \]
    若圆柱轴线与斜截面所成的夹角为 $\theta$，则离心率为：
    \[ e = \fblank[2cm]{\cos\theta} \]
    其中当 $\theta = \frac{\pi}{2}$ 时截面为圆，$e = 0$．

  \item \textbf{单圆锥斜截椭圆模型}
    设圆锥母线与轴线夹角为 $\alpha$，斜截面与轴线夹角为 $\beta$．放入两个与圆锥侧面及截面都相切的丹德林球，两球半径为 $R_1, R_2$，球心距为 $d = O_1O_2$．两个切点为椭圆焦点，则：
    \[ 2a = \fblank[4cm]{\sqrt{d^2 - (R_1 - R_2)^2}},\quad 2c = \fblank[4cm]{\sqrt{d^2 - (R_1 + R_2)^2}} \]
    若用角度表示，则有：
    \[ 2a = \fblank[3cm]{d\cos\alpha},\quad 2c = \fblank[3cm]{d\cos\beta} \]
    所以离心率为：
    \[ e = \fblank[3cm]{\frac{\cos\beta}{\cos\alpha}} \quad (\alpha < \beta < \frac{\pi}{2}) \]

  \item \textbf{双圆锥双曲线截面模型}
    两个球分别位于双圆锥的两侧（一上一下），均与圆锥侧面及截面相切，两个切点即为双曲线焦点．设两球半径为 $R_1, R_2$，球心距为 $d = O_1O_2$．则：
    \[ 2a = \fblank[4cm]{\sqrt{d^2 - (R_1 + R_2)^2}},\quad 2c = \fblank[4cm]{\sqrt{d^2 - (R_1 - R_2)^2}} \]
    若用角度表示：
    \[ 2a = \fblank[3cm]{d\cos\alpha},\quad 2c = \fblank[3cm]{d\cos\beta} \]
    所以离心率为：
    \[ e = \fblank[3cm]{\frac{\cos\beta}{\cos\alpha}} > 1 \quad (0 \le \beta < \alpha) \]

  \item \textbf{抛物线模型}
    当截面与圆锥轴线夹角 $\beta = \alpha$ 时，截线为抛物线．此时空间中只有一个丹德林球 $S$ 与圆锥侧面及截面相切：
    \begin{itemize}[itemsep=0.15em]
      \item 球与截面的切点 $F$ 是\textbf{抛物线的焦点}；
      \item 球与圆锥侧面的切圆所在平面与截面的交线 $l$ 是\textbf{抛物线的准线}；
      \item 截线上任意一点 $P$ 均满足：$PF = \fblank[3cm]{d(P, l)}$．
    \end{itemize}
\end{enumerate}

\subsubsection*{2. 看到这些条件，应立刻想到什么}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{看到“圆锥/圆柱、截面、椭圆/双曲线/抛物线”}：优先找出截平面与轴线的线面角 $\beta$ 以及母线与轴线的夹角 $\alpha$．
  \item \textbf{看到“球与圆锥侧面相切、且与截面相切”}：应立刻想到\textbf{丹德林双球（Dandelin Spheres）}．两个切点必然是截口圆锥曲线的焦点，而球与圆锥侧面的接触圆是连结空间母线与平面焦半径的桥梁．
  \item \textbf{看到“从同一动点向同一个球作切线”}：应立刻应用\textbf{切线长定理}，将动点到焦点的距离 $PF_i$ 转化为动点沿着圆锥母线到球的接触圆的距离 $PA$ 或 $PB$．
  \item \textbf{看到“离心率计算”}：在圆锥曲线截面模型中，如果已知 $\alpha$ 和 $\beta$，直接套用公式 $e = \frac{\cos\beta}{\cos\alpha}$，能够极大地避免繁琐的解析几何代数联立与投影计算．
\end{itemize}

\subsubsection*{3. 本类题的常见切入点}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{利用切线长相等进行距离转移}：这是证明第一定义的核心．例如对于椭圆，证明 $PF_1 + PF_2 = 2a$；对于双曲线，证明 $|PF_1 - PF_2| = 2a$．
  \item \textbf{构造直角梯形/直角三角形求长短轴与焦距}：圆锥的轴线、球心、球的切点、切圆的半径等几何元素都在同一轴截面上．连接球心与切线、切面，能够构造直角梯形，平移底边即可获得直角三角形，用于计算球心距 $d$、半径 $R_i$、长轴 $2a$ 与焦距 $2c$．
  \item \textbf{寻找三维图形的对称轴与降维投影}：立体几何中的截面轨迹问题，第一步是明确固定轴线，第二步是求出截面与该轴线的线面角 $\beta$，第三步是直接应用第零定义判定轨迹形状．
\end{itemize}

\subsubsection*{4. 教学与备考价值判断}
本部分的备考价值在于：将高中几何的核心内容（解析几何的圆锥曲线定义、立体几何的线面角及切球）进行大统一．高考或强基竞赛中，常以“正棱锥截面轨迹”、“圆锥内切球截面弦长”或“离心率的极值范围”为背景进行命题，考查学生将三维空间几何降维转化为平面直角三角形和圆锥曲线定义的能力．

\subsection*{第二部分：核心思路提炼与板块重构}

\subsubsection*{一、圆锥曲线为什么叫“圆锥曲线”}

\paragraph*{1. 定理重构}
设圆锥旋转轴线为 $PO$，母线与轴线夹角（半顶角）为 $\alpha$ ($0 < \alpha < \frac{\pi}{2}$)．用一个不过顶点的平面 $\alpha$ 去截圆锥，设平面与轴线的夹角为 $\beta$ ($0 \le \beta \le \frac{\pi}{2}$)：
\[
\text{截口曲线类型} = \begin{cases} 
\beta = \frac{\pi}{2}, & \text{\textbf{圆}} \\
\alpha < \beta < \frac{\pi}{2}, & \text{\textbf{椭圆}} \\
\beta = \alpha, & \text{\textbf{抛物线}} \\
0 \le \beta < \alpha, & \text{\textbf{双曲线}}
\end{cases}
\]

  \textbf{【证明与推导】}

  在截线上任取一点 $P$，过 $P$ 作圆柱的母线，与两球的赤道圆分别交于 $A, B$．

  短半轴 $b = R$，长半轴 $a = \frac{R}{\cos\phi} = \frac{R}{\sin\theta}$．

  所以离心率为：
  \[ e = \frac{c}{a} = \cos\theta \]

  在截线任取点 $P$，连接 $VP$ 延长，分别交两球与侧面的接触圆于 $A, B$．
  
  由切线长定理，$PF_1 = PA$ 且 $PF_2 = PB$．
  
  因此，\[ PF_1 + PF_2 = PA + PB = AB \]
  由于 $A, B$ 分别在两接触圆上，母线段 $AB$ 的长度为恒定的常数．
  
  设球心在轴线上的坐标分别为 $z_1, z_2$．球心到接触圆的高度差为 $R_i \sin\alpha$，所以接触圆到顶点的母线长度为 $s_i = z_i \cos\alpha$．
  
  母线段长度 $AB = s_1 - s_2 = (z_1 - z_2)\cos\alpha = d\cos\alpha$ 为常数．

  综上，椭圆的长轴 $2a = d\cos\alpha$，焦距 $2c = d\cos\beta$．
  
  离心率为：
  \[ e = \frac{c}{a} = \frac{d\cos\beta}{d\cos\alpha} = \frac{\cos\beta}{\cos\alpha} \]
  由于 $\alpha < \beta < \frac{\pi}{2}$，在 $[0, \frac{\pi}{2}]$ 上余弦函数单调递减，得 $\cos\beta < \cos\alpha$，离心率 $0 < e < 1$．

  \textbf{【证明与推导】}
  
  设双圆锥的顶点为 $V$，两内切球分别置于上、下两半圆锥中，球心距为 $d = O_1O_2$，两球与截面的切点分别记为 $F_1, F_2$．
  
  在截线上任取一点 $P$（以在上半支为例），连接 $VP$ 形成母线，其向下方延伸穿过顶点 $V$ 进入下半圆锥．
  
  该母线与上接触圆交于 $A$，与下接触圆交于 $B$．由于点 $P$ 在上接触圆的上方，$A$ 也在上半支，而 $B$ 在下半支，所以顶点 $V$ 必然位于 $A$ 与 $B$ 之间．
  
  根据切线长定理，有 $PF_1 = PA$，$PF_2 = PB$．
  
  因此有：
  \[ |PF_2 - PF_1| = |PB - PA| \]
  因为 $P, A$ 同侧，$B$ 异侧，
  \[ |PB - PA| = |(PV + VB) - (PV - VA)| = VA + VB = AB \]
  即夹在两接触圆之间的母线段 $AB$ 的长度为恒定常数，通过轴截面投影易知 $AB = d\cos\alpha$．
  
  故 $|PF_1 - PF_2| = d\cos\alpha = 2a$ 为定值．由双曲线定义，截口曲线为双曲线，且 $F_1, F_2$ 为两焦点．
  
  两切点在截面上，由于 $O_1F_1 \perp$ 斜截面，$O_2F_2 \perp$ 斜截面，两焦点间距离同样是球心距向量在截面上的正投影：
  \[ 2c = F_1F_2 = d\cos\beta \]
  
  所以离心率为：
  \[ e = \frac{c}{a} = \frac{\cos\beta}{\cos\alpha} \]
  由于 $0 \le \beta < \alpha$，在区间 $[0, \frac{\pi}{2}]$ 内，$\cos\beta > \cos\alpha$，故 $e > 1$．
  
  \item \textbf{模型四：圆锥截面与抛物线}
  
  当 $\beta = \alpha$ 时，截平面恰好平行于圆锥的某一条母线，此时截线为抛物线．

  \textbf{【证明与推导】}
  
  此时空间中只存在一个球 $S$ 与圆锥侧面及截平面 $\alpha$ 同时相切，切点记为 $F$．
  
  球 $S$ 与圆锥侧面的接触圆所在的水平面记为 $\gamma$，它与截面 $\alpha$ 交于直线 $l$．
  
  在截线（抛物线）上任取一点 $P$，连结 $VP$ 交水平面 $\gamma$ 上的接触圆于点 $A$．由切线长定理，有 $PF = PA$．
  
  过 $P$ 分别作水平面 $\gamma$ 及其交线 $l$ 的垂线，垂足分别为 $H$ 和 $D$．由于 $PH \perp \gamma$，且 $PD \perp l$，在直角三角形 $PHD$ 中，由面面夹角性质，$\angle PDH = \frac{\pi}{2} - \alpha$（截平面与水平底面所成二面角）．
  
  所以，点 $P$ 到交线 $l$ 的距离为：
  \[ PD = \frac{PH}{\sin(\frac{\pi}{2} - \alpha)} = \frac{PH}{\cos\alpha} \]
  
  而在圆锥侧面上，点 $P$ 沿母线到水平面 $\gamma$ 上接触圆 $A$ 的距离为 $PA$．由于母线与轴线夹角为 $\alpha$，故母线与水平面的夹角为 $\frac{\pi}{2} - \alpha$．
  
  所以点 $P$ 到水平面 $\gamma$ 的垂直距离为：
  \[ PH = PA \sin(\frac{\pi}{2} - \alpha) = PA \cos\alpha \]
  
  代入上式，得：
  \[ PD = \frac{PA \cos\alpha}{\cos\alpha} = PA \]
  
  由切线长定理 $PF = PA$，我们有 $PF = PD$．
  
  即：动点 $P$ 到定点 $F$（切点）的距离，等于到定直线 $l$（截面与切圆平面的交线）的距离．符合抛物线的第一定义，故 $F$ 是焦点，$l$ 是准线．
\end{enumerate}

\paragraph*{3. 避坑与边界说明}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{夹角定义的基准}：角度 $\beta$ 指的是“平面与轴线所成线面角”，取值范围是 $[0, \frac{\pi}{2}]$，注意不要误用平面法向量与轴线的夹角．
  \item \textbf{退化情形}：若截平面经过圆锥的顶点 $V$：
    \begin{itemize}[itemsep=0.15em]
      \item 当 $\beta > \alpha$ 时，截线退化为\textbf{一个点}（顶点 $V$）；
      \item 当 $\beta = \alpha$ 时，截线退化为\textbf{一条母线}；
      \item 当 $\beta < \alpha$ 时，截线退化为\textbf{相交的两条母线}．
    \end{itemize}
    在普通高考题中，默认截面不过顶点．
\end{itemize}

\subsubsection*{二、方法的横向联系}

\paragraph*{1. 方法的横向联系}
“三维切球 + 切线长转移”是立体几何轨迹问题的终极核心通法．它与以下解析几何板块深度联动：
\begin{itemize}[itemsep=0.2em]
  \item \textbf{解析几何第一定义}：通过把空间母线距离转移为焦半径，提供焦半径和的几何背景．
  \item \textbf{抛物线焦点-准线几何机制}：直接用空间切圆解释了“准线”这一看似抽象的代数概念的几何来源．
  \item \textbf{离心率范围题}：由 $e = \frac{\cos\beta}{\cos\alpha}$ 可知，当截面的倾斜程度受限（如不穿过底面、线面角最大值等）时，离心率的范围自然可以转换为空间线面角的极值问题．
\end{itemize}

\paragraph*{2. 解题策略取舍：通法与巧法}
\begin{itemize}[itemsep=0.2em]
  \item \textbf{代数建系法（通法）}：建立空间直角坐标系，列出圆锥的二次方程 $x^2 + y^2 = z^2 \tan^2\alpha$，以及截平面方程 $Ax + By + Cz + D = 0$，通过代数联立消元化简求出二次曲线的代数式．此方法最为通用，但计算量极大，容易在化简时出错．
  \item \textbf{丹德林几何法（巧法）}：无需写出截线方程，只需利用几何投影和切球关系，直接获得 $2a, 2c$ 与 $e$ 的值．它在选择题、填空题和多选题中具有降维打击般的优势．
  \item \textbf{适用边界}：必须出现“圆柱/圆锥的斜截平面”或“与侧面及截面都相切的球”．如果题目不含空间截面背景，则几何法无从发起．
\end{itemize}

\paragraph*{3. 命题视角的变式与拓展}
若平面不垂直于圆锥的对称主轴面，截口仍然是圆锥曲线，但椭圆的对称轴将不再在对称面上，需要做旋转变换．在高中阶段，默认“截平面垂直于圆锥的主轴截面”，以确保对称性．

\paragraph*{4. 实战做题启发}
\begin{itemize}[itemsep=0.2em]
  \item 看到空间中“等距离”或者“到定线/定点距离夹角为定值”的轨迹，第一反应是寻找空间中的旋转轴，构造圆锥模型，化三维问题为二维截面角比较．
  \item 在求离心率时，时刻注意 $\alpha$ 和 $\beta$ 分别代表哪个角，先在草图上画出轴截面，将球和面投影为二维的“圆与两条相交线”及“切线”．
\end{itemize}

\prehint{
  解答立体几何中关于“空间动点轨迹类型判断”的题目时，请严格按以下步骤：\\
  1. \textbf{寻找轴线}：看题目中哪条直线是固定的（即旋转轴）；\\

  最后比大小：$\beta > \alpha \implies$ 椭圆；$\beta = \alpha \implies$ 抛物线；$\beta < \alpha \implies$ 双曲线．

\section{第二部分：第一定义与标准方程推导}

\subsection*{1. 第一定义回顾}
\begin{itemize}[itemsep=0.4em]
  \item \textbf{椭圆}：平面内到两个定点 $F_1, F_2$ 的距离之和为定值 $2a$（$2a > 2c > 0$）的动点 $P$ 的轨迹．方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$b^2 = a^2 - c^2$）．
  \item \textbf{双曲线}：平面内到两个定点 $F_1, F_2$ 的距离之差的绝对值为定值 $2a$（$2c > 2a > 0$）的动点 $P$ 的轨迹．方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（$b^2 = c^2 - a^2$）．
  \item \textbf{抛物线}：平面内到定点 $F$ 与定直线 $l$（点不在线上）的距离相等的动点 $P$ 的轨迹．方程为 $y^2 = 2px$（焦点 $F(\frac{p}{2},0)$，准线 $x = -\frac{p}{2}$）．
\end{itemize}

\begin{enumerate}
  \item \textbf{明确目标（写出最终式）}：先在草稿纸上写出题目最终要求证或求值的量（如斜率之积 $k_{PA} \cdot k_{PB}$、面积 $S_{\triangle OAB}$）用交点坐标表示的最终代数式；
  \item \textbf{倒推消元方向}：观察最终式中主要是 $x_1, x_2$ 还是 $y_1, y_2$，由此决定：

          \item 若主要含 $x_1, x_2$，优先将直线设为斜截式 $y=kx+m$；
          \item 若主要含 $y_1, y_2$，优先将直线设为横截式 $x=ty+n$；
        \end{itemize}
  \item \textbf{有目的联立}：带着消元目标去套用韦达定理，切忌“一上来就盲目联立，算了一整页才发现消错元”．
\end{enumerate}

\section{第三部分：第二定义与焦点代数性质}
\begin{theorembox}{圆锥曲线第二定义}
平面内到一个定点 $F$ 的距离与到一条定直线 $l$（$F$ 不在 $l$ 上）的距离之比为常数 $e$ 的点的轨迹：
\begin{itemize}[itemsep=0.2em]
  \item 当 $0 < e < 1$ 时，轨迹为\textbf{椭圆}；
  \item 当 $e = 1$ 时，轨迹为\textbf{抛物线}；
  \item 当 $e > 1$ 时，轨迹为\textbf{双曲线}．
\end{itemize}
其中定点 $F$ 为圆锥曲线的焦点，定直线 $l$ 为焦点对应的准线，$e$ 为离心率．
\end{theorembox}

\subsection*{2. 焦半径公式（“左加右减”）}
\begin{enumerate}[label=\arabic*.]
  \item \textbf{椭圆} $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 上任意一点 $P(x_0, y_0)$，焦半径为：
        \[ PF_1 = \fblank[3cm]{a+ex_0},\qquad PF_2 = \fblank[3cm]{a-ex_0} \quad (\text{左加右减}) \]
  \item \textbf{双曲线} $C: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（在右支 $x_0 \ge a$ 上），焦半径为：
        \[ PF_1 = \fblank[3cm]{ex_0+a},\qquad PF_2 = \fblank[3cm]{ex_0-a} \]
  \item \textbf{抛物线} $y^2 = 2px$ 上任意一点 $P(x_0, y_0)$，焦半径为：
        \[ PF = \fblank[3cm]{x_0+\frac{p}{2}} \]
\end{enumerate}

\subsection*{3. 焦点极坐标统一方程}
以圆锥曲线的左焦点（对抛物线为焦点）为极点，以对称轴正方向为极轴建立极坐标系，则椭圆、双曲线和抛物线可统一表示为：
\[ \rho = \fblank[5cm]{\frac{ep}{1-e\cos\theta}} \]
其中 $e$ 为离心率，$p$ 为焦点到相应准线的距离（对椭圆/双曲线为 $p = \frac{b^2}{c}$，对抛物线为焦点到准线距离 $p$）．
\begin{itemize}[itemsep=0.3em]
  \item \textbf{椭圆}（$0<e<1$，$p = \frac{b^2}{c}$，即 $ep = \frac{b^2}{a}$）：
        以左焦点 $F_1$ 为极点，方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{1-e\cos\theta}}$；以右焦点 $F_2$ 为极点，方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{1+e\cos\theta}}$．
  \item \textbf{双曲线}（$e>1$，$p = \frac{b^2}{c}$，即 $ep = \frac{b^2}{a}$）：
        以左焦点 $F_1$ 为极点（右支），方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{1-e\cos\theta}}$；以右焦点 $F_2$ 为极点（右支），方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{e\cos\theta-1}}$．
  \item \textbf{抛物线}（$e=1$，焦点到准线距离 $p$）：
        以焦点 $F$ 为极点，方程为 $\rho = \fblank[3.5cm]{\frac{p}{1-\cos\theta}}$．
\end{itemize}

\subsection*{4. 抛物线焦点弦性质}
过焦点 $F(\frac{p}{2},0)$ 的直线与抛物线 $y^2 = 2px$ 相交于 $P(x_1, y_1)$ 和 $Q(x_2, y_2)$，直线倾斜角为 $\theta$．
\begin{enumerate}[label=\arabic*.]
  \item \textbf{焦点弦焦半径关系}：
        设以 $F$ 为极点，由极坐标方程得焦半径 $PF = \frac{p}{1-\cos\theta}$，则另一端焦半径 $QF = \fblank[3cm]{\frac{p}{1+\cos\theta}}$．
  \item \textbf{焦点弦长公式}：
        \[ PQ = PF + QF = \fblank[4cm]{\frac{2p}{\sin^2\theta}} \]
        当 $\theta = 90^\circ$ 时，焦点弦长取得最小值，称为\textbf{通径}，通径长为 $\fblank[2cm]{2p}$．
  \item \textbf{焦点弦坐标积结论}（联立 $x=my+\frac{p}{2}$ 运用韦达定理）：

  \item \textbf{焦点弦两端切线性质}：

\begin{theorembox}{方法思维点拨：切线“半半法”与直线横纵设法}
\textbf{1. 曲线切线速写：“半半法”}：\\
若已知动点 $P(x_0,y_0)$ 在圆锥曲线上，求在该点处的切线方程，可利用“代数代换”直觉：
\begin{itemize}[itemsep=0.1em]
  \item $x^2 \to x_0 x$，\quad $y^2 \to y_0 y$；
  \item $2x \to x + x_0$，\quad $2y \to y + y_0$．
\end{itemize}
例如：对于抛物线 $y^2 = 2px$，其切线方程为 $y_0 y = p(x+x_0)$．这可极大提高填空选择以及解答题中切线性质判断的效率．\\
\textbf{2. 设直线的“横纵选择”直觉}：\\
我们在解答大题时，应根据最终式的结构有意识地选择直线的表达式：
\begin{itemize}[itemsep=0.15em]
  \item 若目标涉及 $x_1, x_2$ 较多，通常设斜截式 $y=kx+m$；
  \item 若目标涉及 $y_1, y_2$ 较多，或者需要规避斜率不存在的讨论，优先设横截式 $x=ty+n$（对于抛物线焦点弦，强烈推荐设 $x=ty+\frac{p}{2}$，其 $y_1y_2=-p^2$ 的韦达关系通常是代数化简的最短路径）．
\end{itemize}
\end{theorembox}

\section{第四部分：第三定义与斜率积性质}
\begin{theorembox}{圆锥曲线第三定义}
平面内动点 $P$ 到两定点 $A_1(-a,0), A_2(a,0)$（关于原点对称的两点）的斜率乘积等于常数 $k = e^2 - 1 > -1$ 的点的轨迹为椭圆或双曲线（除端点外）：
\begin{itemize}[itemsep=0.2em]
  \item 当 $0 < e^2 < 1$ 时（即 $k \in (-1,0)$），轨迹为\textbf{椭圆}，斜率积 $k_{PA_1} \cdot k_{PA_2} = -\frac{b^2}{a^2}$；
  \item 当 $e^2 > 1$ 时（即 $k > 0$），轨迹为\textbf{双曲线}，斜率积 $k_{PA_1} \cdot k_{PA_2} = \frac{b^2}{a^2}$．
\end{itemize}
\end{theorembox}

\subsection*{核心推广结论 1--8（中点弦与点差法思想来源）}
\begin{enumerate}[label=\arabic*.]
  \item 椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的长轴端点斜率积：$k_{PA} \cdot k_{PB} = \fblank[2.5cm]{-\frac{b^2}{a^2}}$ 
  \item 椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的短轴端点斜率积：$k_{PA} \cdot k_{PB} = \fblank[2.5cm]{-\frac{a^2}{b^2}}$ 
  \item 竖直椭圆 $\frac{y^2}{a^2} + \frac{x^2}{b^2} = 1$ 端点斜率积：长轴端点为 $\fblank[2cm]{-\frac{a^2}{b^2}}$，短轴端点为 $\fblank[2cm]{-\frac{b^2}{a^2}}$．
  \item 双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的实轴端点斜率积：$k_{PA} \cdot k_{PB} = \fblank[2.5cm]{\frac{b^2}{a^2}}$ 
  \item \textbf{对称点推广（结论 5--8）}：若 $A, B$ 是椭圆/双曲线关于原点对称的任意两点，$P$ 为曲线上异于 $A, B$ 的任意点，若斜率存在，其乘积 $k_{PA} \cdot k_{PB}$ 仍为上述定值（椭圆为 $\fblank[2cm]{-\frac{b^2}{a^2}}$ 或 $-\frac{a^2}{b^2}$；双曲线为 $\fblank[2cm]{\frac{b^2}{a^2}}$ 或 $\frac{a^2}{b^2}$）．
\end{enumerate}

\subsection*{中点弦与点差法公式推导}

\begin{theorembox}{什么是点差法？}
\textbf{1. 定义与适用背景}：\\
点差法（Point-Difference Method）是解析几何中解决“中点弦”或“斜率积”问题最核心的“设而不求”技巧。\\
当圆锥曲线的动弦 $PQ$ 被定点 $M(x_0, y_0)$ 平分（即 $M$ 为 $PQ$ 的中点）时，我们利用 $P(x_1,y_1), Q(x_2,y_2)$ 两点在曲线上这一事实，将坐标代入曲线方程并进行\textbf{相减（点差）}，建立弦斜率 $k_{PQ}$ 与中点坐标 $(x_0, y_0)$ 之间的对应关系。\\
\textbf{2. 几何直观示意图}：
\begin{center}
\begin{tikzpicture}[scale=1.2, >=stealth]
  % Axes
  \draw[->, gray!70] (-3.2,0) -- (3.2,0) node[right, scale=0.8] {$x$};
  \draw[->, gray!70] (0,-1.8) -- (0,1.8) node[above, scale=0.8] {$y$};
  \node[below left, scale=0.8] at (0,0) {$O$};
  
  % Ellipse
  \draw[thick] (0,0) ellipse (2.5 and 1.5);
  
  % Points P, Q
  \coordinate (P) at (1.915, 0.964);
  \coordinate (Q) at (-2.349, 0.513);
  \fill (P) circle (1.5pt) node[above right, scale=0.8] {$P(x_1, y_1)$};
  \fill (Q) circle (1.5pt) node[above left, scale=0.8] {$Q(x_2, y_2)$};
  
  % Chord PQ
  \draw[thick, blue] (P) -- (Q);
  
  % Midpoint M
  \coordinate (M) at (-0.217, 0.7385);
  \fill[red] (M) circle (1.8pt) node[below left, scale=0.8, black] {$M(x_0, y_0)$};
  
  % Line OM
  \draw[thick, dashed, red!80!black] (0,0) -- (M);
  
  % Slopes labels
  \node[blue, above, scale=0.8, rotate=6] at (-0.9, 0.8) {$k_{PQ}$};
  \node[red!80!black, right, scale=0.8, rotate=-73] at (-0.1, 0.35) {$k_{OM}$};
\end{tikzpicture}
\end{center}
\end{theorembox}

设椭圆为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\ (a>b>0)$，弦 $PQ$ 的两端点分别为 $P(x_1, y_1)$， $Q(x_2, y_2)$，中点为 $M(x_0, y_0)$．\\
将点 $P, Q$ 代入椭圆方程并作差：
\begin{align*}
  \frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} &= 1 \\
  \frac{x_2^2}{a^2} + \frac{y_2^2}{b^2} &= 1
\end{align*}
两式相减得：
\[ \frac{x_1^2 - x_2^2}{a^2} + \frac{y_1^2 - y_2^2}{b^2} = 0 \implies \frac{(y_1 - y_2)(y_1 + y_2)}{b^2} = -\frac{(x_1 - x_2)(x_1 + x_2)}{a^2} \]
根据中点坐标公式与斜率公式，有 $x_1+x_2 = $ \blank{2cm}，$y_1+y_2 = $ \blank{2cm}，$y_1 - y_2 = k_{PQ}(x_1 - x_2)$，代入整理得：
\[ k_{PQ} \cdot \fblank[3.5cm]{\frac{y_0}{x_0}} = \fblank[3cm]{-\frac{b^2}{a^2}} \]
因为 $k_{OM} = \frac{y_0}{x_0}$，所以椭圆的中点弦斜率积公式为：
\[ k_{PQ} \cdot k_{OM} = \fblank[4cm]{-\frac{b^2}{a^2}} \]

\vspace{0.8em}

\begin{theorembox}{方法思维点拨：第三定义与点差法的几何-代数大统一}
请从“宏观对称性”上体悟解析几何的两大标志性公式：
\begin{enumerate}
  \item \textbf{第三定义（定点与动点）}：圆锥曲线上动点 $P$ 与关于原点对称的两定点 $A, B$ 的斜率积为定值：
        \[ k_{PA} \cdot k_{PB} = \pm \frac{b^2}{a^2} \]
  \item \textbf{中点弦点差法（动弦与中点）}：圆锥曲线任意弦 $PQ$ 的中点为 $M$，则中点与原点连线的斜率 $k_{OM}$ 与弦所在直线斜率 $k_{PQ}$ 乘积为定值：
        \[ k_{PQ} \cdot k_{OM} = \pm \frac{b^2}{a^2} \]
\end{enumerate}
（注：椭圆右侧常数为 $-\frac{b^2}{a^2}$，双曲线为 $\frac{b^2}{a^2}$）．\\
这两个公式具有相同的常数值，其代数本质都是源于曲线方程两式相减的“设而不求”消参机制：
\[ \frac{y_1^2}{b^2} \pm \frac{x_1^2}{a^2} = 1, \quad \frac{y_2^2}{b^2} \pm \frac{x_2^2}{a^2} = 1 \implies \frac{y_1-y_2}{x_1-x_2} \cdot \frac{y_1+y_2}{x_1+x_2} = \mp \frac{b^2}{a^2} \]
牢记这一大统一规律，能帮助你在解析几何“定值/定点”大题中建立极其强大的几何直觉，迅速锁定最终式的常数值。
\end{theorembox}
