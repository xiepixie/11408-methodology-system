\section{备课指导与一轮复习规划}

\begin{teachbox}{本讲课程定位}
本专题旨在帮助一轮复习的学生将圆锥曲线的平面几何定义（第一定义）、代数比值定义（第二定义）、斜率乘积定义（第三定义）以及空间立体切割定义（第零定义）进行大统一．\\
学生往往能够熟记第一定义，但对于后三种定义，尤其是新高考中高频出现的“空间立体图形包装下的圆锥曲线轨迹判断”，极易产生畏难情绪．教师备课时应抓住以下教学核心：
\begin{enumerate}
  \item \textbf{概念大统一}：利用离心率 $e$ 统摄第二、第三和第零定义；
  \item \textbf{代数设而不求}：第三定义是点差法的几何本质，在解析几何大题中具有极高指导价值；
  \item \textbf{空间降维映射}：第零定义轨迹的关键在于找出“圆锥轴线”和两个特征角（母线角 $\theta$、线面角 $\beta$）．
  \item \textbf{运算框架重于孤立公式}：引导学生认识到，解三角形的主线是“边角关系 $\to$ 定理/面积公式 $\to$ 求值”，而圆锥曲线的主线是“几何关系 $\to$ 设点/线 $\to$ 联立与韦达 $\to$ 最终式 $\to$ 定值/定点/范围/最值”．圆锥曲线绝非“公式多一点的解三角形”，定义和公式只是代数入口，最终式与韦达定理构成的全局运算框架才是核心．
\end{enumerate}
\end{teachbox}

\section{板块一：第零定义（空间截面定义）与典型应用}

\subsection*{第一部分：核心引子与题感诊断}

\subsubsection*{1. 本讲用到的核心公式、定理或二级结论}

设圆锥的半顶角（母线与旋转轴线的夹角）为 $\alpha$，截平面与圆锥旋转轴线的夹角为 $\beta$．（以下默认截面不经过圆锥顶点）．

\begin{enumerate}[label=(\arabic*), leftmargin=2em, itemsep=0.3em]
  \item \textbf{圆锥截面类型判断}
    \begin{itemize}[itemsep=0.15em]
      \item 若 $\beta = \frac{\pi}{2}$，截面垂直于轴线，截线为\textbf{圆}；
      \item 若 $\alpha < \beta < \frac{\pi}{2}$，截平面与所有母线都相交，截线为\textbf{椭圆}；
      \item 若 $\beta = \alpha$，截平面平行于且仅平行于一条母线，截线为\textbf{抛物线}；
      \item 若 $0 \le \beta < \alpha$，截平面平行于两条母线，截线为\textbf{双曲线}（完整双曲线需在双圆锥中截得）．
    \end{itemize}

  \item \textbf{圆柱斜截椭圆模型}
    圆柱内放入两个等半径的内切球，球半径为 $R$，球心距为 $O_1O_2$．斜截面同时与两球相切，两个切点即为椭圆焦点．若截线为椭圆，则：
    \[ 2a = \fblank[3cm]{O_1O_2},\quad b = \fblank[2cm]{R},\quad c = \fblank[3cm]{\sqrt{a^2 - b^2}} \]
    若圆柱轴线与斜截面所成的夹角为 $\theta$，则离心率为：
    \[ e = \fblank[2cm]{\cos\theta} \]
    其中当 $\theta = \frac{\pi}{2}$ 时截面为圆，$e = 0$．

  \item \textbf{单圆锥斜截椭圆模型}
    设圆锥母线与轴线夹角为 $\alpha$，斜截面与轴线夹角为 $\beta$．放入两个与圆锥侧面及截面都相切的丹德林球，两球半径为 $R_1, R_2$，球心距为 $d = O_1O_2$．两个切点为椭圆焦点，则：
    \[ 2a = \fblank[4cm]{\sqrt{d^2 - (R_1 - R_2)^2}},\quad 2c = \fblank[4cm]{\sqrt{d^2 - (R_1 + R_2)^2}} \]
    若用角度表示，则有：
    \[ 2a = \fblank[3cm]{d\cos\alpha},\quad 2c = \fblank[3cm]{d\cos\beta} \]
    所以离心率为：
    \[ e = \fblank[3cm]{\frac{\cos\beta}{\cos\alpha}} \quad (\alpha < \beta < \frac{\pi}{2}) \]

  \item \textbf{双圆锥双曲线截面模型}
    两个球分别位于双圆锥的两侧（一上一下），均与圆锥侧面及截面相切，两个切点即为双曲线焦点．设两球半径为 $R_1, R_2$，球心距为 $d = O_1O_2$．则：
    \[ 2a = \fblank[4cm]{\sqrt{d^2 - (R_1 + R_2)^2}},\quad 2c = \fblank[4cm]{\sqrt{d^2 - (R_1 - R_2)^2}} \]
    若用角度表示：
    \[ 2a = \fblank[3cm]{d\cos\alpha},\quad 2c = \fblank[3cm]{d\cos\beta} \]
    所以离心率为：
    \[ e = \fblank[3cm]{\frac{\cos\beta}{\cos\alpha}} > 1 \quad (0 \le \beta < \alpha) \]

  \item \textbf{抛物线模型}
    当截面与圆锥轴线夹角 $\beta = \alpha$ 时，截线为抛物线．此时空间中只有一个丹德林球 $S$ 与圆锥侧面及截面相切：
    \begin{itemize}[itemsep=0.15em]
      \item 球与截面的切点 $F$ 是\textbf{抛物线的焦点}；
      \item 球与圆锥侧面的切圆所在平面与截面的交线 $l$ 是\textbf{抛物线的准线}；
      \item 截线上任意一点 $P$ 均满足：$PF = \fblank[3cm]{d(P, l)}$．
    \end{itemize}
\end{enumerate}

\subsubsection*{2. 看到这些条件，应立刻想到什么}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{看到“圆锥/圆柱、截面、椭圆/双曲线/抛物线”}：优先找出截平面与轴线的线面角 $\beta$ 以及母线与轴线的夹角 $\alpha$．
  \item \textbf{看到“球与圆锥侧面相切、且与截面相切”}：应立刻想到\textbf{丹德林双球（Dandelin Spheres）}．两个切点必然是截口圆锥曲线的焦点，而球与圆锥侧面的接触圆是连结空间母线与平面焦半径的桥梁．
  \item \textbf{看到“从同一动点向同一个球作切线”}：应立刻应用\textbf{切线长定理}，将动点到焦点的距离 $PF_i$ 转化为动点沿着圆锥母线到球的接触圆的距离 $PA$ 或 $PB$．
  \item \textbf{看到“离心率计算”}：在圆锥曲线截面模型中，如果已知 $\alpha$ 和 $\beta$，直接套用公式 $e = \frac{\cos\beta}{\cos\alpha}$，能够极大地避免繁琐的解析几何代数联立与投影计算．
\end{itemize}

\subsubsection*{3. 本类题的常见切入点}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{利用切线长相等进行距离转移}：这是证明第一定义的核心．例如对于椭圆，证明 $PF_1 + PF_2 = 2a$；对于双曲线，证明 $|PF_1 - PF_2| = 2a$．
  \item \textbf{构造直角梯形/直角三角形求长短轴与焦距}：圆锥的轴线、球心、球的切点、切圆的半径等几何元素都在同一轴截面上．连接球心与切线、切面，能够构造直角梯形，平移底边即可获得直角三角形，用于计算球心距 $d$、半径 $R_i$、长轴 $2a$ 与焦距 $2c$．
  \item \textbf{寻找三维图形的对称轴与降维投影}：立体几何中的截面轨迹问题，第一步是明确固定轴线，第二步是求出截面与该轴线的线面角 $\beta$，第三步是直接应用第零定义判定轨迹形状．
\end{itemize}

\subsubsection*{4. 教学与备考价值判断}
本部分的备考价值在于：将高中几何的核心内容（解析几何的圆锥曲线定义、立体几何的线面角及切球）进行大统一．高考或强基竞赛中，常以“正棱锥截面轨迹”、“圆锥内切球截面弦长”或“离心率的极值范围”为背景进行命题，考查学生将三维空间几何降维转化为平面直角三角形和圆锥曲线定义的能力．

\subsection*{第二部分：核心思路提炼与板块重构}

\subsubsection*{一、圆锥曲线为什么叫“圆锥曲线”}

\paragraph*{1. 定理重构}
设圆锥旋转轴线为 $PO$，母线与轴线夹角（半顶角）为 $\alpha$ ($0 < \alpha < \frac{\pi}{2}$)．用一个不过顶点的平面 $\alpha$ 去截圆锥，设平面与轴线的夹角为 $\beta$ ($0 \le \beta \le \frac{\pi}{2}$)：
\[
\text{截口曲线类型} = \begin{cases} 
\beta = \frac{\pi}{2}, & \text{\textbf{圆}} \\
\alpha < \beta < \frac{\pi}{2}, & \text{\textbf{椭圆}} \\
\beta = \alpha, & \text{\textbf{抛物线}} \\
0 \le \beta < \alpha, & \text{\textbf{双曲线}}
\end{cases}
\]

\paragraph*{2. 推导与理解（四大模型详析）}

  由于 $A, B$ 分别在两接触圆上，母线段 $AB$ 的长度为恒定的常数．
  
  设球心在轴线上的坐标分别为 $z_1, z_2$．球心到接触圆的高度差为 $R_i \sin\alpha$，所以接触圆到顶点的母线长度为 $s_i = z_i \cos\alpha$．
  
  母线段长度 $AB = s_1 - s_2 = (z_1 - z_2)\cos\alpha = d\cos\alpha$ 为常数．
  
  所以，对于任意 $P$，其到两定点 $F_1, F_2$ 的距离之和为 $2a = d\cos\alpha$．
  
  同时，切点 $F_1, F_2$ 是球心 $O_1, O_2$ 向斜截面的投影．由于截面与轴线所成角为 $\beta$，
  球心距向量 $\vec{O_1O_2}$（在轴线上）在斜截面上的正投影长度即为焦距 $2c = F_1F_2 = d\cos\beta$．
  
  综上，椭圆的长轴 $2a = d\cos\alpha$，焦距 $2c = d\cos\beta$．
  
  离心率为：
  \[ e = \frac{c}{a} = \frac{d\cos\beta}{d\cos\alpha} = \frac{\cos\beta}{\cos\alpha} \]
  由于 $\alpha < \beta < \frac{\pi}{2}$，在 $[0, \frac{\pi}{2}]$ 上余弦函数单调递减，得 $\cos\beta < \cos\alpha$，离心率 $0 < e < 1$．
  
  \item \textbf{模型三：双圆锥截面与双曲线}

  设双圆锥的顶点为 $V$，两内切球分别置于上、下两半圆锥中，球心距为 $d = O_1O_2$，两球与截面的切点分别记为 $F_1, F_2$．
  
  在截线上任取一点 $P$（以在上半支为例），连接 $VP$ 形成母线，其向下方延伸穿过顶点 $V$ 进入下半圆锥．
  
  该母线与上接触圆交于 $A$，与下接触圆交于 $B$．由于点 $P$ 在上接触圆的上方，$A$ 也在上半支，而 $B$ 在下半支，所以顶点 $V$ 必然位于 $A$ 与 $B$ 之间．
  
  根据切线长定理，有 $PF_1 = PA$，$PF_2 = PB$．
  
  因此有：
  \[ |PF_2 - PF_1| = |PB - PA| \]
  因为 $P, A$ 同侧，$B$ 异侧，
  \[ |PB - PA| = |(PV + VB) - (PV - VA)| = VA + VB = AB \]
  即夹在两接触圆之间的母线段 $AB$ 的长度为恒定常数，通过轴截面投影易知 $AB = d\cos\alpha$．
  
  故 $|PF_1 - PF_2| = d\cos\alpha = 2a$ 为定值．由双曲线定义，截口曲线为双曲线，且 $F_1, F_2$ 为两焦点．

  \[ 2c = F_1F_2 = d\cos\beta \]
  
  所以离心率为：
  \[ e = \frac{c}{a} = \frac{\cos\beta}{\cos\alpha} \]
  由于 $0 \le \beta < \alpha$，在区间 $[0, \frac{\pi}{2}]$ 内，$\cos\beta > \cos\alpha$，故 $e > 1$．

  此时空间中只存在一个球 $S$ 与圆锥侧面及截平面 $\alpha$ 同时相切，切点记为 $F$．
  
  球 $S$ 与圆锥侧面的接触圆所在的水平面记为 $\gamma$，它与截面 $\alpha$ 交于直线 $l$．
  
  在截线（抛物线）上任取一点 $P$，连结 $VP$ 交水平面 $\gamma$ 上的接触圆于点 $A$．由切线长定理，有 $PF = PA$．
  
  过 $P$ 分别作水平面 $\gamma$ 及其交线 $l$ 的垂线，垂足分别为 $H$ 和 $D$．由于 $PH \perp \gamma$，且 $PD \perp l$，在直角三角形 $PHD$ 中，由面面夹角性质，$\angle PDH = \frac{\pi}{2} - \alpha$（截平面与水平底面所成二面角）．
  
  所以，点 $P$ 到交线 $l$ 的距离为：
  \[ PD = \frac{PH}{\sin(\frac{\pi}{2} - \alpha)} = \frac{PH}{\cos\alpha} \]
  
  而在圆锥侧面上，点 $P$ 沿母线到水平面 $\gamma$ 上接触圆 $A$ 的距离为 $PA$．由于母线与轴线夹角为 $\alpha$，故母线与水平面的夹角为 $\frac{\pi}{2} - \alpha$．
  
  所以点 $P$ 到水平面 $\gamma$ 的垂直距离为：
  \[ PH = PA \sin(\frac{\pi}{2} - \alpha) = PA \cos\alpha \]
  
  代入上式，得：
  \[ PD = \frac{PA \cos\alpha}{\cos\alpha} = PA \]
  
  由切线长定理 $PF = PA$，我们有 $PF = PD$．
  
  即：动点 $P$ 到定点 $F$（切点）的距离，等于到定直线 $l$（截面与切圆平面的交线）的距离．符合抛物线的第一定义，故 $F$ 是焦点，$l$ 是准线．
\end{enumerate}

\paragraph*{3. 避坑与边界说明}
\begin{itemize}[itemsep=0.3em]
  \item \textbf{夹角定义的基准}：角度 $\beta$ 指的是“平面与轴线所成线面角”，取值范围是 $[0, \frac{\pi}{2}]$，注意不要误用平面法向量与轴线的夹角．
  \item \textbf{退化情形}：若截平面经过圆锥的顶点 $V$：
    \begin{itemize}[itemsep=0.15em]
      \item 当 $\beta > \alpha$ 时，截线退化为\textbf{一个点}（顶点 $V$）；
      \item 当 $\beta = \alpha$ 时，截线退化为\textbf{一条母线}；
      \item 当 $\beta < \alpha$ 时，截线退化为\textbf{相交的两条母线}．
    \end{itemize}
    在普通高考题中，默认截面不过顶点．
\end{itemize}

\subsubsection*{二、方法的横向联系}

\paragraph*{1. 方法的横向联系}
“三维切球 + 切线长转移”是立体几何轨迹问题的终极核心通法．它与以下解析几何板块深度联动：
\begin{itemize}[itemsep=0.2em]
  \item \textbf{解析几何第一定义}：通过把空间母线距离转移为焦半径，提供焦半径和的几何背景．
  \item \textbf{抛物线焦点-准线几何机制}：直接用空间切圆解释了“准线”这一看似抽象的代数概念的几何来源．
  \item \textbf{离心率范围题}：由 $e = \frac{\cos\beta}{\cos\alpha}$ 可知，当截面的倾斜程度受限（如不穿过底面、线面角最大值等）时，离心率的范围自然可以转换为空间线面角的极值问题．
\end{itemize}

\paragraph*{2. 解题策略取舍：通法与巧法}
\begin{itemize}[itemsep=0.2em]
  \item \textbf{代数建系法（通法）}：建立空间直角坐标系，列出圆锥的二次方程 $x^2 + y^2 = z^2 \tan^2\alpha$，以及截平面方程 $Ax + By + Cz + D = 0$，通过代数联立消元化简求出二次曲线的代数式．此方法最为通用，但计算量极大，容易在化简时出错．
  \item \textbf{丹德林几何法（巧法）}：无需写出截线方程，只需利用几何投影和切球关系，直接获得 $2a, 2c$ 与 $e$ 的值．它在选择题、填空题和多选题中具有降维打击般的优势．
  \item \textbf{适用边界}：必须出现“圆柱/圆锥的斜截平面”或“与侧面及截面都相切的球”．如果题目不含空间截面背景，则几何法无从发起．
\end{itemize}

\paragraph*{3. 命题视角的变式与拓展}
若平面不垂直于圆锥的对称主轴面，截口仍然是圆锥曲线，但椭圆的对称轴将不再在对称面上，需要做旋转变换．在高中阶段，默认“截平面垂直于圆锥的主轴截面”，以确保对称性．

\paragraph*{4. 实战做题启发}
\begin{itemize}[itemsep=0.2em]
  \item 看到空间中“等距离”或者“到定线/定点距离夹角为定值”的轨迹，第一反应是寻找空间中的旋转轴，构造圆锥模型，化三维问题为二维截面角比较．
  \item 在求离心率时，时刻注意 $\alpha$ 和 $\beta$ 分别代表哪个角，先在草图上画出轴截面，将球和面投影为二维的“圆与两条相交线”及“切线”．
\end{itemize}

\prehint{
  解答立体几何中关于“空间动点轨迹类型判断”的题目时，请严格按以下步骤：\\
  1. \textbf{寻找轴线}：看题目中哪条直线是固定的（即旋转轴）；\\
  2. \textbf{确定母线角 $\alpha$}：确定动点与顶点连线跟轴线的夹角定值（或生成母线）；\\
  3. \textbf{计算截面角 $\beta$}：求出动点所在的“切割截面”与旋转轴的线面角．\\
  最后比大小：$\beta > \alpha \implies$ 椭圆；$\beta = \alpha \implies$ 抛物线；$\beta < \alpha \implies$ 双曲线．
}

\begin{teachbox}{第一定义标准方程代数详细推导过程}
教师应在课堂上板书或引导学生复习以下三大圆锥曲线标准方程的代数推导（双根式化简与消参步骤）：
\begin{enumerate}
  \item \textbf{椭圆标准方程推导}：\\
        根据定义 $PF_1 + PF_2 = 2a$，设 $F_1(-c,0), F_2(c,0)$，动点 $P(x,y)$ 满足：
        \[ \sqrt{(x+c)^2+y^2} + \sqrt{(x-c)^2+y^2} = 2a \]
        移项得：
        \[ \sqrt{(x+c)^2+y^2} = 2a - \sqrt{(x-c)^2+y^2} \]
        两边平方展开并整理：
        \[ (x+c)^2+y^2 = 4a^2 - 4a\sqrt{(x-c)^2+y^2} + (x-c)^2+y^2 \]
        \[ x^2+2cx+c^2+y^2 = 4a^2 - 4a\sqrt{(x-c)^2+y^2} + x^2-2cx+c^2+y^2 \]
        \[ 4cx - 4a^2 = -4a\sqrt{(x-c)^2+y^2} \implies a^2 - cx = a\sqrt{(x-c)^2+y^2} \]
        两边再次平方：
        \[ (a^2 - cx)^2 = a^2 \left[ (x-c)^2+y^2 \right] \implies a^4 - 2a^2 cx + c^2 x^2 = a^2 (x^2 - 2cx + c^2 + y^2) \]
        \[ a^4 + c^2 x^2 = a^2 x^2 + a^2 c^2 + a^2 y^2 \implies (a^2 - c^2)x^2 + a^2 y^2 = a^2 (a^2 - c^2) \]
        因 $a > c > 0$，令 $b^2 = a^2 - c^2 > 0$，则方程可写为：
        \[ b^2 x^2 + a^2 y^2 = a^2 b^2 \implies \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \]
  \item \textbf{双曲线标准方程推导}：\\
        根据定义 $|PF_1 - PF_2| = 2a$，设 $F_1(-c,0), F_2(c,0)$，动点 $P(x,y)$ 满足：
        \[ \sqrt{(x+c)^2+y^2} - \sqrt{(x-c)^2+y^2} = \pm 2a \]
        移项并两边平方：
        \[ (x+c)^2+y^2 = 4a^2 \pm 4a\sqrt{(x-c)^2+y^2} + (x-c)^2+y^2 \implies cx - a^2 = \pm a\sqrt{(x-c)^2+y^2} \]
        两边再次平方：
        \[ (cx - a^2)^2 = a^2 \left[ (x-c)^2+y^2 \right] \implies c^2 x^2 - 2a^2 cx + a^4 = a^2 x^2 - 2a^2 cx + a^2 c^2 + a^2 y^2 \]
        \[ (c^2 - a^2)x^2 - a^2 y^2 = a^2 (c^2 - a^2) \]
        因 $c > a > 0$，令 $b^2 = c^2 - a^2 > 0$，则方程可写为：
        \[ b^2 x^2 - a^2 y^2 = a^2 b^2 \implies \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \]
  \item \textbf{抛物线标准方程推导}：\\
        根据定义 $PF = d(P,l)$，设焦点 $F(\frac{p}{2},0)$，准线 $l: x = -\frac{p}{2}$，动点 $P(x,y)$ 满足：
        \[ \sqrt{\left(x-\frac{p}{2}\right)^2+y^2} = x + \frac{p}{2} \]
        两边平方展开：
        \[ x^2 - px + \frac{p^2}{4} + y^2 = x^2 + px + \frac{p^2}{4} \implies y^2 = 2px \]
\end{enumerate}
\end{teachbox}

\begin{teachbox}{最终式思想在代数推导中的首次落地}
\textbf{点拨直觉}：\\
我们在推导椭圆和双曲线标准方程时，为什么要把一个根式移到等号右边再平方？为什么第二次平方时要将含 $x$ 的项移到一侧，含常数的移到另一侧？\\
这正是解析几何中贯穿始终的\textbf{“最终式思想”（End-State Thinking）}：\\
1. \textbf{明确目标}：我们在动笔进行任何代数变形前，脑中必须先明确我们要到达的“最终式”是什么样子的——例如，椭圆的最终式是 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$，这意味着代数式中不能含有任何根式，且 $x^2$ 和 $y^2$ 要在等号同侧，常数项为 $1$。\\
2. \textbf{倒推路径}：为了消除两个根式，直接平方会产生双根式乘积，无法消去根式。因此，必须“分而治之”——移项使两个根式位于等号两侧，平方一次消去一个；整理后再平方一次消去第二个。这就是由最终式结构决定的“两步走”变形路径。\\
在后续的解析几何大题中，不管是定值、定点还是最值问题，我们都应该\textbf{先写出目标物理量（如斜率积、面积）的最终坐标表达式，再根据其结构选择联立方向与消元策略}，避免盲目运算。
\end{teachbox}

\begin{teachbox}{第一定义与焦点性质核心板书内容}
教师在黑板上应重点画出抛物线焦点弦的三个核心几何关系，并补充推导：
\begin{enumerate}
  \item \textbf{圆锥曲线焦点极坐标统一方程的定义法推导}：\\
        根据圆锥曲线第二定义（统一比值定义）：平面内任意圆锥曲线上动点 $P$ 到焦点的距离与到相应准线 $l$ 的距离之比为离心率 $e$．\\
        以左焦点 $F_1$（对抛物线为焦点 $F$）为极点，以对称轴正方向（远离准线方向）为极轴建立极坐标系．此时对应准线位于极点左侧，与极点的距离设为 $p$．\\
        对于极坐标系下曲线上任意一点 $P(\rho, \theta)$，其到焦点的距离为 $PF_1 = \rho$，其极坐标投影横坐标为 $x = \rho\cos\theta$．\\
        因此，点 $P$ 到对应准线的距离为 $d(P,l) = p + \rho\cos\theta$．\\
        由定义：
        \[ \frac{PF_1}{d(P,l)} = e \implies \frac{\rho}{p + \rho\cos\theta} = e \]
        解出极径 $\rho$ 得：
        \[ \rho = e(p + \rho\cos\theta) \implies \rho(1 - e\cos\theta) = ep \implies \rho = \frac{ep}{1-e\cos\theta} \]
        对于椭圆和双曲线，$p = \frac{b^2}{c}$，即 $ep = \frac{b^2}{a}$，方程化为：
        \[ \rho = \frac{b^2/a}{1-e\cos\theta} \]
        对于抛物线，$e=1$，方程化为：
        \[ \rho = \frac{p}{1-\cos\theta} \]
        此推导适用于所有的圆锥曲线，完美实现了焦半径在极坐标系下的代数大统一．
  \item \textbf{直角坐标与极坐标互化推导抛物线焦半径}（供参考对比）：\\
        设点 $P(x_0,y_0)$ 在抛物线 $y^2=2px$ 上，焦点为 $F(\frac{p}{2},0)$．以 $F$ 为极点，对称轴正方向为极轴．\\
        由于极点是 $(\frac{p}{2},0)$，则 $P$ 点的直角坐标可写为 $x_0 = \rho\cos\theta + \frac{p}{2}$．\\
        根据直角坐标下的焦半径公式：
        \[ PF = x_0 + \frac{p}{2} = \rho\cos\theta + p \]
        又因为在极坐标系下 $PF = \rho$，代入得：
        \[ \rho = \rho\cos\theta + p \implies \rho(1-\cos\theta) = p \implies \rho = \frac{p}{1-\cos\theta} \]
  \item \textbf{焦点弦两端切线性质证明要点}：\\
        设 $P(x_1,y_1), Q(x_2,y_2)$，切线方程可写为 $y_1y = p(x+x_1)$ 和 $y_2y = p(x+x_2)$．\\
        联立两切线可求得交点 $S$ 的横坐标：
        \[ x_S = \frac{y_1y_2}{2p} - \frac{x_1+x_2}{2} \]
        代入坐标积结论 $y_1y_2 = -p^2$ 及 $x_1+x_2 = PQ - p$ 可证明其横坐标为 $-\frac{p}{2}$，即点 $S$ 在准线上；\\
        由于 $y_1y_2 = -p^2$，切线斜率乘积为 $\frac{p}{y_1} \cdot \frac{p}{y_2} = \frac{p^2}{y_1y_2} = -1$，故两切线垂直．
\end{enumerate}

\begin{teachbox}{应试直觉：切线“半半法”与直角坐标下的设线选择}
\textbf{1. 切线“半半法”的代数直觉}：\\
我们在写动点 $P(x_0,y_0)$ 处的切线时，可以直接利用“半半法”快速代换写出：
\begin{itemize}[itemsep=0.2em]
  \item 二次项拆成两半，将其中一个变量替换为切点坐标：$x^2 \to x_0x$，$y^2 \to y_0y$；
  \item 一次项平均代换：$2x \to x+x_0$，$2y \to y+y_0$．
\end{itemize}
例如：椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 的切线为 $\frac{x_0x}{a^2}+\frac{y_0y}{b^2}=1$；抛物线 $y^2=2px$ 的切线为 $y_0y=p(x+x_0)$（即 $2px$ 拆为 $p(2x) \to p(x+x_0)$）．这是一种极强且普适的代数速写直觉．\\
\textbf{2. 设线策略中的“横纵选择”与“不对称韦达消元”}：\\
在解析几何联立中，设 $y=kx+m$ 还是 $x=ty+n$？这也是由“最终式”决定的：
\begin{itemize}
  \item \textbf{横设优先} ($y=kx+m$)：当题目最终要求证的物理量（如斜率和、斜率积）天然富含 $x_1, x_2$ 时；
  \item \textbf{纵设优先} ($x=ty+n$)：当目标富含 $y_1, y_2$（如面积高度、弦长）时，或者为避免斜率不存在而需要分类讨论时．对于抛物线焦点弦，由于 $y_1y_2=-p^2$ 极度简洁，通常\textbf{强力推荐设 $x=ty+\frac{p}{2}$}，从而在 $y$ 轴方向应用韦达定理．
\end{itemize}
若遇到不对称韦达（如目标含 $y_1x_2$），应利用直线的关系式 $x_2=ty_2+n$ 将所有 $x$ 替换为 $y$，再利用韦达关系 $y_1+y_2$ 和 $y_1y_2$ 进行消元，这是消除代数不对称性的标准通法．
\end{teachbox}

\subsection*{附：学案焦点性质公式梳理与填空答案}

\subsubsection*{2. 焦半径公式（“左加右减”）}
\begin{enumerate}[label=\arabic*.]
  \item \textbf{椭圆} $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的焦半径公式：
        \[ PF_1 = \fblank[3cm]{a+ex_0},\qquad PF_2 = \fblank[3cm]{a-ex_0} \quad (\text{左加右减}) \]
  \item \textbf{双曲线} $C: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（右支 $x_0 \ge a$）：
        \[ PF_1 = \fblank[3cm]{ex_0+a},\qquad PF_2 = \fblank[3cm]{ex_0-a} \]
  \item \textbf{抛物线} $y^2 = 2px$ 的焦半径公式：
        \[ PF = \fblank[3cm]{x_0+\frac{p}{2}} \]
\end{enumerate}

\subsubsection*{3. 焦点极坐标统一方程}
以圆锥曲线的左焦点（对抛物线为焦点）为极点，以对称轴正方向为极轴建立极坐标系，则椭圆、双曲线和抛物线可统一表示为：
\[ \rho = \fblank[5cm]{\frac{ep}{1-e\cos\theta}} \]
其中 $e$ 为离心率，$p$ 为焦点到相应准线的距离（对椭圆/双曲线为 $p = \frac{b^2}{c}$，对抛物线为焦点到准线距离 $p$）．
\begin{itemize}[itemsep=0.3em]
  \item \textbf{椭圆}（$0<e<1$，$p = \frac{b^2}{c}$，即 $ep = \frac{b^2}{a}$）：
        以左焦点 $F_1$ 为极点，方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{1-e\cos\theta}}$；以右焦点 $F_2$ 为极点，方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{1+e\cos\theta}}$．
  \item \textbf{双曲线}（$e>1$，$p = \frac{b^2}{c}$，即 $ep = \frac{b^2}{a}$）：
        以左焦点 $F_1$ 为极点（右支），方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{1-e\cos\theta}}$；以右焦点 $F_2$ 为极点（右支），方程为 $\rho = \fblank[3.5cm]{\frac{b^2/a}{e\cos\theta-1}}$．
  \item \textbf{抛物线}（$e=1$，焦点到准线距离 $p$）：
        以焦点 $F$ 为极点，方程为 $\rho = \fblank[3.5cm]{\frac{p}{1-\cos\theta}}$．
\end{itemize}

\subsubsection*{4. 抛物线焦点弦性质}
过焦点 $F(\frac{p}{2},0)$ 的直线与抛物线 $y^2 = 2px$ 相交于 $P(x_1, y_1)$ 和 $Q(x_2, y_2)$，直线倾斜角为 $\theta$．
\begin{enumerate}[label=\arabic*.]
  \item \textbf{焦点弦焦半径关系}：
        设以 $F$ 为极点，由极坐标方程得焦半径 $PF = \frac{p}{1-\cos\theta}$，则另一端焦半径 $QF = \fblank[3cm]{\frac{p}{1+\cos\theta}}$．
  \item \textbf{焦点弦长公式}：
        \[ PQ = PF + QF = \fblank[4cm]{\frac{2p}{\sin^2\theta}} \]
        当 $\theta = 90^\circ$ 时，焦点弦长取得最小值，称为\textbf{通径}，通径长为 $\fblank[2cm]{2p}$．
  \item \textbf{焦点弦坐标积结论}：
        \[ y_1y_2 = \fblank[2.5cm]{-p^2},\qquad x_1x_2 = \fblank[2.5cm]{\frac{p^2}{4}} \]
        过 $x$ 轴定点 $(t,0)$ 直线：
        \[ y_1y_2 = \fblank[2.5cm]{-2pt},\qquad x_1x_2 = \fblank[2.5cm]{t^2} \]
  \item \textbf{焦点弦两端切线性质}：
        切线交点 $S$ 在准线 $\fblank[2cm]{x = -\frac{p}{2}}$ 上；两切线垂直，$\angle PSQ = \fblank[1.5cm]{90^\circ}$；$\fblank[3cm]{SF \perp PQ}$．
\end{enumerate}

\subsection*{附：学案斜率积推广结论与填空答案}
\begin{enumerate}[label=\arabic*.]
  \item 椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的长轴端点斜率积：$k_{PA} \cdot k_{PB} = \fblank[2.5cm]{-\frac{b^2}{a^2}}$ 
  \item 椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的短轴端点斜率积：$k_{PA} \cdot k_{PB} = \fblank[2.5cm]{-\frac{a^2}{b^2}}$

  \item 双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的实轴端点斜率积：$k_{PA} \cdot k_{PB} = \fblank[2.5cm]{\frac{b^2}{a^2}}$ 
  \item 对称点推广：斜率乘积 $k_{PA} \cdot k_{PB}$ 仍为上述定值（椭圆为 $\fblank[2cm]{-\frac{b^2}{a^2}}$；双曲线为 $\fblank[2cm]{\frac{b^2}{a^2}}$）．
\end{enumerate}

\subsection*{中点弦与点差法（方法解构与公式推导）}

\begin{teachbox}{什么是点差法？}
\textbf{1. 定义与适用背景}：\\
点差法（Point-Difference Method）是解析几何中解决“中点弦”或“斜率积”问题最核心的“设而不求”技巧。\\
当圆锥曲线的弦 $PQ$ 被定点 $M(x_0, y_0)$ 平分（即 $M$ 是 $PQ$ 的中点）时，我们不需要联立直线方程与曲线方程求出 $P, Q$ 的具体坐标，而是直接利用 $P, Q$ 两点在曲线上这一几何事实，将两点坐标代入曲线方程并进行\textbf{作差}，从而直接建立\textbf{弦斜率 $k_{PQ}$} 与\textbf{中点坐标 $(x_0, y_0)$} 之间的代数关系。\\
\textbf{2. 几何直观示意图}：
\begin{center}

  \draw[->, gray!70] (-3.2,0) -- (3.2,0) node[right, scale=0.8] {$x$};

\begin{teachbox}{以椭圆为例的点差法推导步骤}
设椭圆为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\ (a>b>0)$，弦 $PQ$ 的端点为 $P(x_1, y_1)$， $Q(x_2, y_2)$，中点为 $M(x_0, y_0)$．\\
\textbf{第一步：点在曲线上（代入方程）}
\[ \frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} = 1 \quad \text{---(1)} \]
\[ \frac{x_2^2}{a^2} + \frac{y_2^2}{b^2} = 1 \quad \text{---(2)} \]
\textbf{第二步：两式相减（“点差”的由来）}
(1) 式减去 (2) 式得：
\[ \frac{x_1^2 - x_2^2}{a^2} + \frac{y_1^2 - y_2^2}{b^2} = 0 \implies \frac{y_1^2 - y_2^2}{b^2} = -\frac{x_1^2 - x_2^2}{a^2} \]
\textbf{第三步：平方差公式展开}
\[ \frac{(y_1 - y_2)(y_1 + y_2)}{b^2} = -\frac{(x_1 - x_2)(x_1 + x_2)}{a^2} \]
\textbf{第四步：代入斜率与中点关系}
因为 $M(x_0, y_0)$ 是 $PQ$ 中点，所以由中点公式有：$x_1 + x_2 = 2x_0$， $y_1 + y_2 = 2y_0$．\\
又因为弦 $PQ$ 的斜率存在，有 $y_1 - y_2 = k_{PQ}(x_1 - x_2)$，代入上式得：
\[ \frac{k_{PQ}(x_1 - x_2) \cdot 2y_0}{b^2} = -\frac{(x_1 - x_2) \cdot 2x_0}{a^2} \]
两边同时消去 $2(x_1 - x_2)$，得到：
\[ k_{PQ} \cdot \frac{y_0}{x_0} = -\frac{b^2}{a^2} \]
因为 $k_{OM} = \frac{y_0}{x_0}$ 是中点 $M$ 与原点 $O$ 连线的斜率，故最终形式为：
\[ k_{PQ} \cdot k_{OM} = -\frac{b^2}{a^2} \]
\textbf{总结}：对于双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，利用相同方法可得 $k_{PQ} \cdot k_{OM} = \frac{b^2}{a^2}$；对于抛物线 $y^2 = 2px$，可得 $k_{PQ} \cdot y_0 = p$（即 $k_{PQ} \cdot 2y_0 = 2p$）．
\end{teachbox}

\begin{teachbox}{教学直觉：第三定义与中点弦点差法的代数-几何大统一}
教师应引导高分学生在宏观上理解解析几何的对称与大统一：
\begin{itemize}[itemsep=0.4em]
  \item \textbf{第三定义（几何形态）}：若动点 $P$ 与关于原点对称的两定点 $A, B$（在曲线上）连线的斜率乘积存在，则有：
        \[ k_{PA} \cdot k_{PB} = \pm \frac{b^2}{a^2} \]
        （椭圆为 $-\frac{b^2}{a^2}$，双曲线为 $\frac{b^2}{a^2}$）．
  \item \textbf{中点弦点差法（运动形态）}：若任意弦 $PQ$ 的中点为 $M$，则中点与原点连线的斜率 $k_{OM}$ 与弦所在直线的斜率 $k_{PQ}$ 乘积存在，其值为：
        \[ k_{PQ} \cdot k_{OM} = \pm \frac{b^2}{a^2} \]
  \item \textbf{大统一的本质}：为什么这两组公式在形式上完全对称，且右端常数完全一致？\\
        因为从射影几何和对称性的角度来看，第三定义是“静止的定点与动点关系”；而点差法是“运动的弦及其中心对称关系”。当我们令第三定义中的两定点 $A, B$ 的中点 $O$ 与原点重合，其本质上也是弦 $AB$ 与以 $P$ 为对称中心的图形系统投影。两式相减的“设而不求”代数机制：
        \[ \frac{y_1^2}{b^2} + \frac{x_1^2}{a^2} = 1, \qquad \frac{y_2^2}{b^2} + \frac{x_2^2}{a^2} = 1 \implies \frac{y_1^2-y_2^2}{x_1^2-x_2^2} = \frac{y_1-y_2}{x_1-x_2} \cdot \frac{y_1+y_2}{x_1+x_2} = -\frac{b^2}{a^2} \]
        这说明圆锥曲线上任意两点的斜率积（对应点差）都共享了相同的代数根源。让学生在默写和证明时，将这两者融会贯通，能极大提升其审题敏锐度。
\end{itemize}
\end{teachbox}
