## 基本信息

- **专题名称**: 三角函数 \(\omega\) 范围问题
- **时长**: 120 分钟
- **适用对象**: 高一同步强化 / 高三一轮复习
- **核心思想**: 统一变量法（相位区间模型）

## 教学目标

- [ ] 理解相位 \(\theta = \omega x + \varphi\) 的几何意义与区间长度 \(\Delta\theta = \omega(b-a)\) 的关系。
- [ ] 掌握“特征点计数”的边界分析方法：第 \(n\) 个点必入，第 \(n+1\) 个点必出，并能精确区分开闭区间端点等号。
- [ ] 能够处理区间包含问题（如单调性、恒非负、无零点），并能对多区间条件准确求交集。
- [ ] 掌握“距离分析法”求解离散频率 \(\omega\)，并能熟练结合单调方向进行代回验证。
- [ ] 掌握“滑动区间模型”的分析方法，理解初相位 \(\varphi\) 任意时，区间长度与特征点间距的制约关系。

## 专题边界

### 覆盖范围
- 形如 \(f(x) = A\sin(\omega x+\varphi)+b\) 和 \(f(x) = A\cos(\omega x+\varphi)+b\) 的函数在给定区间上的参数范围问题。
- 平移变换、对称中心、对称轴、最值点、单调区间与零点避让的综合应用。
- 离散候选频率的估算与逐一验证法。

### 不覆盖
- 正切函数的范围与性质。
- 复杂的三角恒等变形（如多角化简、降幂公式等），本专题重点在于 \(\omega\) 引起的相位变动。
- 三角函数在实际生活或物理波动中的应用建模。

## 方法链条

```
第一步：令 θ = ωx + φ，将自变量 x 范围 [a, b] 转化为相位区间 [ωa+φ, ωb+φ]
  ↓
第二步：明确题意限制（零点数、对称轴数、单调性、恒正/负、无零点）
  ↓
第三步：
  ├─ 特征点计数：写出点列 x_k = g(k, ω)，列出 x_{n-1} ∈ I 且 x_n ∉ I 的边界不等式
  ├─ 区间包含：将单调/恒正区间转化为相位区间的超集，列出端点包含不等式组
  ├─ 距离法（离散 ω）：计算对称中心与轴的距离，表示为 ω = h(k)，结合区间长度估算上限，再代回检验
  └─ 滑动区间（φ 可变）：计算区间长度 L = ω(b-a)，平移区间以包含恰好 n 个点，利用间距列出 L 范围
  ↓
第四步：精确核对开闭区间端点等号，求交集并写出最终范围
```

## 核心公式与特征相位

- **正弦特征**：对称轴 \(\theta=\frac{\pi}{2}+k\pi\)，零点/中心 \(\theta=k\pi\)，增区间 \([-\frac{\pi}{2}+2k\pi, \frac{\pi}{2}+2k\pi]\)。
- **余弦特征**：对称轴 \(\theta=k\pi\)，零点/中心 \(\theta=\frac{\pi}{2}+k\pi\)，非负区间 \([-\frac{\pi}{2}+2k\pi, \frac{\pi}{2}+2k\pi]\)。
- **距离公式**：正弦函数相邻对称中心与对称轴的距离为 \(\frac{T}{4} = \frac{\pi}{2\omega}\) 的奇数倍。

## 易错点

1. **等号错判**：在特征点计数中，忽视开区间和闭区间的差异，导致边界点等号漏写或多写。
2. **多分支遗漏**：在处理离散 \(\omega\) 时，忘记整数 \(k\) 存在多个有效取值，或者对单调方向不做检验导致保留了错误的极值穿过点。
3. **滑动区间算错**：没有搞清楚极值点/零点之间的交替间距。如余弦零点 \(\cos\theta=1/2\) 之间的距离是交替的（\(\frac{2\pi}{3}\) 和 \(\frac{4\pi}{3}\)），不能简单使用平均周期。
