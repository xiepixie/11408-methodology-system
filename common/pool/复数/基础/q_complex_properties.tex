\newcommand{\qComplexPropertiesStem}{设 \(z = 3 + 2i\)，则 \hfill （\quad）}

\newcommand{\qComplexPropertiesOptions}{%
  \mcoptions[2]{\(\overline{z} = 3 - 2i\)}{\(|z| = 5\)}{\(z^2 = 5 + 12i\)}{\(\dfrac{z + 3}{z - i} \in \mathbb{R}\)}%
}

\newcommand{\qComplexPropertiesAnswer}{ACD}

\newcommand{\qComplexPropertiesSolution}{%
  【解题思路】\\
  本题为复数基本运算的多选题。分别对各个选项进行计算和判断：A 选项考查共轭复数的概念（虚部变号）；B 选项考查复数模的计算；C 选项考查复数的乘法与平方运算；D 选项考查复数的商及实虚部判定，可先将代数式写出，再通过代数化简判定其是否为实数。\\
  【解析计算】\\
  已知复数 \(z = 3 + 2i\)。\\
  对于 A 选项：共轭复数 \(\overline{z} = 3 - 2i\)，故 A 正确；\\
  对于 B 选项：模为 \(|z| = \sqrt{3^2 + 2^2} = \sqrt{13} \neq 5\)，故 B 错误；\\
  对于 C 选项：计算 \(z^2 = (3 + 2i)^2 = 9 + 12i + 4i^2 = 9 + 12i - 4 = 5 + 12i\)，故 C 正确；\\
  对于 D 选项：代入得：\\
  \(\dfrac{z + 3}{z - i} = \dfrac{3 + 2i + 3}{3 + 2i - i} = \dfrac{6 + 2i}{3 + i} = \dfrac{2(3 + i)}{3 + i} = 2 \in \mathbb{R}\)，故 D 正确。\\
  综上所述，正确的选项为 A、C、D。\\
  故选 A、C、D。%
}

\newcommand{\qComplexPropertiesDiagnosis}{%
  学生在计算模时可能将虚部平方写成 \((2i)^2 = -4\) 从而得出 \(\sqrt{9-4} = \sqrt{5}\)，或误记模的公式。而在 D 选项中，有部分学生可能直接进行繁琐的“分母实数化”计算，未能发现分子分母间存在 2 倍的提取公因式关系。%
}

\newcommand{\qComplexPropertiesTeachingNotes}{%
  讲评复数小题时，应提示学生注意观察数值特征。如 D 选项中的 \(\dfrac{6+2i}{3+i}\)，直接提取分子的公因式 2 即可直接得出，避免盲目进行分母实数化，提升计算效率和敏锐度。%
}
