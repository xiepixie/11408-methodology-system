\newcommand{\qSolidCubeMinStem}{在正方体 \(ABCD-A_1B_1C_1D_1\) 中，\(AB = \dfrac{4}{3}\sqrt{3}\)。若动点 \(E\) 为该正方体内一点，且 \(AE = 1\)，则 \(|\vec{AC_1} - \vec{AE}|\) 的最小值为 \hfill （\quad）}

\newcommand{\qSolidCubeMinOptions}{%
  \mcoptions[4]{\(2\)}{\(3\)}{\(4\)}{\(5\)}%
}

\newcommand{\qSolidCubeMinAnswer}{B}

\newcommand{\qSolidCubeMinSolution}{%
  根据向量减法的几何意义，有 \(\vec{AC_1} - \vec{AE} = \vec{EC_1}\)。
  因此，\(|\vec{AC_1} - \vec{AE}|\) 的最小值即为动点 \(E\) 到顶点 \(C_1\) 的距离的最小值。
  因为点 \(E\) 为正方体内的一点，且满足 \(AE = 1\)，所以点 \(E\) 在以 \(A\) 为球心、\(1\) 为半径的球面上。
  在正方体中，体对角线 \(AC_1\) 的长度为 \(AC_1 = \sqrt{3} AB = \sqrt{3} \times \dfrac{4}{3}\sqrt{3} = 4\)。
  因为点 \(C_1\) 与球心 \(A\) 的距离为 \(4\)，球面半径为 \(1\)，且点 \(C_1\) 显然在球外，
  所以球面上点 \(E\) 到点 \(C_1\) 的最小距离为：
  \(|\vec{EC_1}|_{\min} = AC_1 - AE = 4 - 1 = 3\)。
  故选 B。%
}
