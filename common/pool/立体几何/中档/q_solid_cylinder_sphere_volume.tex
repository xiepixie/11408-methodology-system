\newcommand{\qSolidCylinderSphereVolumeAnswer}{B}

\newcommand{\qSolidCylinderSphereVolumeSolution}{%
  设球半径为 $R$，圆柱底面半径为 $r$，圆柱高为 $h$。

  过球心作包含圆柱轴线的截面，得到一个矩形内接于圆。
  因此有
  \[
    R^2=r^2+\left(\frac h2\right)^2.
  \]

  由题意，球的直径为 $2$，所以 $R=1$；圆柱的高为 $h=1$。
  代入得
  \[
    r^2=1^2-\left(\frac12\right)^2=\frac34.
  \]

  所以圆柱体积为
  \[
    V=\pi r^2h=\pi\cdot\frac34\cdot1=\frac{3\pi}{4}.
  \]

  故选 B。%
}

\newcommand{\qSolidCylinderSphereVolumeDiagnosis}{%
  本题考查圆柱外接球的轴截面模型。学生常见错误是把球半径直接当作圆柱底面半径，忽略圆柱高的一半也占用了球半径。%
}

\newcommand{\qSolidCylinderSphereVolumeTeachingNotes}{%
  \item \textbf{模型入口}：让学生画出轴截面，看到“球半径、底面半径、半高”构成直角三角形。
  \item \textbf{得分公式}：$R^2=r^2+\left(\frac h2\right)^2$。
  \item \textbf{课堂追问}：为什么用 $\frac h2$，而不是 $h$？因为球心在上下底面圆心连线的中点。
}
